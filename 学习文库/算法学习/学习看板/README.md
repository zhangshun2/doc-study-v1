# 算法学习看板

Obsidian 打开 [[学习看板/算法学习.base|算法学习 Bases 看板]] 后，可以筛选到期回访、尚未独立实现、可独立实现、可迁移、错因分布、专题覆盖、核心卡、概念卡、跨题对照和 Java API。筛出题目后，从 [[学习看板/单题复习工作台|单题复习工作台]] 逐段重建推导链。

生成网站还提供 `#/review` 推导链复习视图。它先展示唯一主线“七阶段、九次交接”，并给出一条覆盖九次交接的两数之和短示范；八个自然问题和验收表只用于完成后的查漏。阶段 3 固定拆成对象、最笨过程、第一次变化三张卡；交接 6 不出现具体方法名或结构名，交接 8 才比较候选，交接 9 再进入代码和反例。
日期、掌握阶段和独立次数只帮助选题，不表示这一轮已经学会。该视图只读取标准题解属性区，
不会保存第二份排期，也不是打卡或完成度面板。

## Markdown 回退索引

### 到期回访（低权重）

只在标准题解（`type == "problem"`）中把 `reviewStatus` 设为 `"待复习"`，并填写 `nextReview`。当天到期且状态仍为待复习的题目会进入 Bases 的“到期回访（低权重）”视图。核心卡、深挖文档和 Java 卡不生成同题第二份复习任务。

回访提醒只负责决定先打开哪一道题。真正执行的是一轮完整链重建：原题事实、人话扩写、对象与最小人工过程、
第一次变化、约束与候选池、第二次变化、候选比较与方向确认，然后才是状态、更新、不变量、代码、反例和闭卷重建。

### 尚未独立实现

筛选 `mastery` 为 `"未学"` 或 `"已理解"` 的题目。前者表示还没有建立模型，后者表示能读懂或复述，但还没有真实作答证据。

### 可独立实现

筛选 `mastery` 为 `"可独立实现"`。只有后续独立完成并达到标准，才把掌握阶段从“已理解”提升到这里。

### 可迁移

筛选 `mastery` 为 `"可迁移"`。这一阶段表示能用同一模型解释新题、改写条件或指出模型失效边界。

### 错因分布

按 `errorTags` 分组统计。建议优先使用稳定短标签，例如：

| 标签 | 含义 |
| --- | --- |
| `边界` | 空输入、单位置、全负、重复值等 |
| `更新顺序` | 查询与写入、先删与后删、状态覆盖次序错误 |
| `不变量` | 无法说明每一步为什么保持不变 |
| `结构选择` | 数据结构与核心操作不匹配 |
| `复杂度` | 复杂度错误或与实现不一致 |
| `题意` | 把子串当子序列、把排名当去重等 |

### 专题覆盖

按 `primaryPattern` 分组查看题目、核心卡和 Java 依赖。深挖文档仍保留在 [[建模专题/README|建模专题索引]]。

### 概念卡速查

按 `type == "concept"` 查看跨题概念卡。概念卡使用与单题相同的掌握阶段和复习状态，但索引页 `README.md` 不进入卡片视图。

### 跨题对照速查

按 `type == "comparison-topic"` 查看集中比较多道题的对照页。对照页使用独立的 `relatedProblems` 属性标明覆盖题号。

### 数据维护

- `mastery` 与 `reviewStatus` 是两个独立维度：“可迁移”的题仍可以处于“待复习”。
- 同一道题只有一个复习调度源：`题目/<主题型>/...` 下的标准题解。
- `lastReviewed` 只在真实执行过一轮复写后填写；`independentAttempts` 只在没有看答案或关键提示时增加。
- 现有题目保守迁移为 `已理解`，不自动认定为可独立实现。
- 题目事实哈希、链接、模板、核心卡与概念卡长度、对照代码一致性和 Java 运行由根目录校验入口统一检查。

维护规则见 [[AGENTS|算法学习目录维护约定]]，完整导航见 [[README|算法学习总索引]]。
