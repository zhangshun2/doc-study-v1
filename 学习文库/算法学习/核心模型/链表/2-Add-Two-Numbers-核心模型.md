# 2. 两数相加：核心模型

> **双轨阅读：** [[题目/链表/2-Add-Two-Numbers.md|标准题解]]

## 一句话本质

这就是小学竖式加法从个位向高位进行的过程。逆序链表消除了“先走到尾部”的麻烦。每轮计算： sum = x + y + carry 当前结果位 = sum % 10 下一轮进位 = sum / 10

## 直观画面与扩题

像整理一列只能看见下一节的车厢，改线前必须先记住还没接上的部分。

在本题中，对象是 **节点引用和尚未重新连接的剩余链**；把它从“枚举全部可能”改写为“只维护影响下一步的最少信息”。

## 关系重写

## 最小演算

官方首例输入：`l1 = [2,4,3], l2 = [5,6,4]`，输出：`[7,0,8]`。

1. **初始状态：** 使用虚拟头节点 dummy 简化结果链表首节点的创建。
2. **触发事件：** 某条链表已经结束时，该位按 0 处理。
3. **结束条件：** 进入第 k 轮时，结果链表已经正确保存了答案最低的 k 位，carry 是这 k 位运算产生、需要交给第 k+1 位的唯一进位。
4. **核对首例：** 按上述状态与事件逐步更新，最终应得到题面给出的输出；若结果不符，优先检查状态初始化、更新先后顺序和边界收缩方向。

## 为什么成立

进入第 k 轮时，结果链表已经正确保存了答案最低的 k 位，carry 是这 k 位运算产生、需要交给第 k+1 位的唯一进位。本轮按十进制加法规则产生第 k 位与新进位，因此不变量继续成立。所有节点和进位处理完后，结果的每一位都正确。

## 代码映射

```text
1. 使用虚拟头节点 dummy 简化结果链表首节点的创建。
2. 只要 l1、l2 或 carry 仍有内容，就生成一个结果节点。
3. 某条链表已经结束时，该位按 0 处理。
```

## 复杂度

- 时间复杂度：O(max(m,n))。
- 空间复杂度：除返回链表外为 O(1)；返回链表占 O(max(m,n))。

## 30 秒识别信号

- 主题型：`链表`
- 切入点：逆序存储使链表头正好对应十进制最低位。

## 最小反例与易错点

- 循环条件不能只有 l1 != null && l2 != null，否则较长链表的剩余部分会丢失。
- 循环条件也不能漏掉 carry != 0，例如 999 + 1 需要额外节点 1。
