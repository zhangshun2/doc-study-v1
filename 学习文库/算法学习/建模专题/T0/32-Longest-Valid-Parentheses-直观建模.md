# 32. 最长有效括号：从未匹配位置长出的区间边界

> **双轨入口：** [[题目/栈/32-Longest-Valid-Parentheses.md|标准题解]] · [[核心模型/栈/32-Longest-Valid-Parentheses-核心模型.md|核心模型]]

## 1. 题意：最长连续有效段

输入只含左右圆括号，要求最长有效连续子串的长度。题目中的“连续”比“括号能否配对”更严格。字符串 `")()())"` 里虽然可以找到多个离散括号对，但最长连续有效段只有 `"()()"` 长度 4。

若只判断整个字符串是否有效，扫描结束后看余额是否为零即可。这里要求任意子串的最大长度，因此还要知道有效段从哪里开始，以及哪些字符已经永久切断了一段连续区间。

示例 `s = "(()"` 的答案为 2，示例 `s = ""` 的答案为 0。输入长度可达 30000，所以每到一个位置重新检查所有起点不可取，目标应是一次或常数次扫描。

## 2. 暴力基线

最直接的模型是枚举所有起点和终点，再对每个子串扫描一次判断是否有效。区间数量是 `O(n^2)`，每个区间检查最坏 `O(n)`，总时间为 `O(n^3)`。

可以稍微改进：固定起点向右扫描，同时保存当前余额。余额不会为负且最终为零时，就得到一个有效段。这样时间降为 `O(n^2)`，但每一个起点仍会重新读取大量相同后缀。

动态规划也是可靠基线。令 `dp[i]` 表示以下标 `i` 结尾的最长有效后缀，遇到 `)` 时根据前一个字符是 `(` 还是 `)` 做转移。它能达到线性时间，但状态转移需要同时查看前一位、匹配位置以及更早的前缀。

## 3. 浪费点：重复寻找同一条左边界

看输入 `")()())"`。暴力起点模型处理下标 1 时会扫描出 `"()"`，处理下标 3 时又会重新扫描出 `"()"`，却没有人保存“下标 0 的右括号已经无法再参与未来配对”这一结论。

一个无法匹配的右括号会永久切断其左右两侧的连续性。例如下标 0 的 `)` 已经不可能被未来字符修复，因此它右侧的有效段永远不需要跨过它。对每个起点重新搜索，实际上是在重复发现同一道断点。

另一个浪费点是把所有左括号都当作潜在起点。从左向右扫描时，最近一个尚未匹配的左括号才是当前右括号唯一可能完成的配对。使用后进先出的访问顺序最自然，这说明数据结构选择会从关系中自然出现，而不是从题型名称中猜出来。

## 4. 视角转换：栈顶就是左边界

不要把栈理解为“保存所有还没配对的括号字符”，而要把它改写成“保存最近一条尚未消除的边界”。初始下标 `-1` 是一个虚拟断点，表示从字符串开头到当前位置都可以成为有效段。

当读到一个左括号时，它可能成为未来最晚闭合的关系，所以压入它的下标。当读到一个右括号时，最近一个左括号可以完成匹配，因此先弹出栈顶。如果弹出后栈为空，说明当前右括号没有可配对的左侧对象，它本身成为新的断点；如果栈不为空，扫描位置减去新的栈顶就是当前有效段的长度。

这个转换把“区间从哪里开始”从反复搜索改成了常数时间读取栈顶。

## 5. 状态与不变量

对象是每个括号字符及其下标，关系是右括号匹配最近一个尚未匹配的左括号，方向严格从左到右。状态可以写成：

```text
unmatched：保存未配对的左括号下标，并在需要时保存最近断点
best：扫描至今出现的最大有效长度
```

不变量是：每处理完一个字符，栈中从底到顶保持递增下标；除最底部可能存在的断点外，其余元素都是尚未匹配的左括号；栈顶是当前有效段左侧最近边界。

初始压入 `-1`，让第一段可以从下标 0 开始。遇到匹配失败时压入当前右括号下标，保证下一段不会跨越该字符。

## 6. 结构选择：为什么是栈而不是队列

圆括号的嵌套要求最近打开的左括号最先闭合。若使用队列，先进入的旧下标会先被取出，无法处理 `(()())` 这种局部嵌套。栈的后进先出顺序正好对应“最近未完成关系优先完成”。

这里也不需要哈希表。扫描只需要访问最近一个未匹配位置，不需要按值查找。数组虽然能模拟栈，但 `ArrayDeque<Integer>` 语义清楚，并且避免在对象栈中频繁装箱的额外接口噪声。

## 7. 演算：`")()())"`

初始状态为栈 `[-1]`，`best = 0`。

1. 下标 0 是 `)`。弹出 `-1` 后栈为空，压入 0，作为新的左边界。
2. 下标 1 是 `(`，压入 1。栈变为 `[0, 1]`。
3. 下标 2 是 `)`。弹出 1，栈顶变为 0。当前位置减栈顶得到 `2 - 0 = 2`，更新 `best = 2`。
4. 下标 3 是 `(`，压入 3。栈变为 `[0, 3]`。
5. 下标 4 是 `)`。弹出 3，栈顶仍为 0，得到 `4 - 0 = 4`，更新 `best = 4`。
6. 下标 5 是 `)`。弹出 0 后栈为空，压入 5。它右侧已经没有字符，最终答案仍为 4。

## 8. 正确性：边界为什么不会漏

对于任意一个成功匹配的右括号，其匹配对象一定是栈中最近尚未使用的左括号；如果该左括号和当前右括号组成的区间内还有不成对字符，栈在扫描到这些字符时已经按同样规则把它们处理掉。因此当前下标减去栈顶，恰好是以下标为末端的最长有效段。

对于无法匹配的右括号，栈为空说明它左侧没有任何可用左括号。它不可能被未来字符补成合法配对，也不可能出现在某个有效连续段的内部，所以把它作为新断点是安全的。

最后取所有成功匹配位置的最大长度，不会漏掉任何一个有效子串的结束位置，也不会把断点错误计入长度。

## 9. 复杂度

时间复杂度为 `O(n)`。每个字符进入循环一次，每个下标最多入栈一次、出栈一次，栈操作均为常数时间。

空间复杂度为 `O(n)`。最坏情况下输入全是左括号，所有下标都会留在栈中。字符串本身不计入额外空间。

## 10. 可迁移模型卡

可迁移的模型是“未匹配位置边界”：用单调位置栈保存最近仍未解决的边界，用当前位置减去栈顶得到当前区间长度。它与柱状图最大矩形中的高度边界、温度数组中下一个更大元素的位置栈有共同结构。

迁移时要检查三件事：题目是否要求连续区间，失败状态是否能永久切断旧区间，当前元素是否只需要访问最近一个未解决位置。三者同时满足时，下标栈通常比动态规划更直观。
