# Java 算法速查索引

这些卡片只回答算法实现中反复遇到的具体问题：什么场景选它、如何构造、关键操作返回什么、复杂度是什么、空值与装箱有什么陷阱，以及和哪些题目直接相关。

## 集合

- [[Java速查/集合/Map-Set.md|Map / Set]]：配对查询、频次统计、历史状态、去重和分组。

## 线性结构

- [[Java速查/线性结构/Deque-Stack.md|Deque / Stack]]：栈、队列、双端队列、BFS 前沿和 DFS 显式栈。

## 选择结构

- [[Java速查/选择结构/PriorityQueue-Comparator.md|PriorityQueue / Comparator]]：持续取最小或最大、Top K、合并有序流和自定义排序。

## 基础工具

- [[Java速查/基础工具/Arrays-StringBuilder.md|Arrays / StringBuilder]]：数组填充、排序、复制、二分搜索和可变字符串构造。
- [[Java速查/基础工具/Math-位运算.md|Math / 位运算]]：最值、绝对值、溢出保护和位级状态。

## 使用顺序

1. 先读“典型场景”，判断问题需要的核心操作。
2. 再核对“返回值语义”和“空值或装箱”，避免把查询失败当成数值零。
3. 最后看“关联题目”，回到真实代码中确认调用顺序。
