# 搜索目标与不变量

## 一句话本质

目标决定搜索要保存什么、何时可以结束。连通块、任意一条路径、无权最短路和全部方案，看似都会“走格子”，但正确性依据并不相同。

## 直观过程

岛屿数量问的是整张地图分成多少块，所以必须穷尽每个未访问连通区域，再统计数量。单词搜索只问是否存在一条匹配路径，一旦找到就可以停止，不必枚举其他路径。单词接龙问最少要走几步，搜索必须按距离从近到远展开，第一次到达终点才有“最短”含义。全排列和子集问的是全部方案，即使已经找到一个结果，也必须继续探索其他分支。

同一个动作“进入邻居”，在不同目标下的后果完全不同。目标没有说清楚，程序就可能少搜、多搜或过早结束。

## 对象与状态

状态必须足够区分未来行为。岛屿的外层位置和访问标记足够，因为过往具体路线不再影响剩余连通块。单词搜索还要保存当前匹配到第几个字符以及当前路径，因为同一格子在不同路径位置上含义不同。最短路的 BFS 状态还要携带层数或距离。枚举方案的状态则要保存当前已经选择的内容，否则无法生成结果。

不变量是状态与目标的连接线。它必须回答：如果进入当前状态时这句话为真，经过合法事件后为什么仍然为真，以及答案为什么会在正确的时刻出现。

## 不变量

- 连通块目标：未访问陆地仍属于未统计区域，已处理区域不会再贡献新连通块。
- 路径存在目标：当前递归路径与目标序列的已匹配前缀完全一致。
- 无权最短路目标：队列按距离非递减处理，首次到达某节点时记录的距离最短。
- 全部方案目标：每个合法方案至少对应一条搜索路径，每条搜索路径只产生一个合法结果。

## 最小演算

假设无权图从 `A` 到 `D` 有两条路线：`A-B-D` 和 `A-C-C2-D`。BFS 先处理距离为一的 `B` 和 `C`，再处理距离为二的 `D`。第一次发现 `D` 时，边数是二，所以答案必然最短。

如果改用深度优先并沿第一条路线走到 `D`，它也可能先找到路线，但那条路线不一定更短。DFS 可以判断“能不能到”，不能仅凭第一次到达就判断“最少几步”。

## 适用信号

- 只要“存在”：找到一个合法结果即可结束，通常关注成功返回。
- 要“全部”：搜索树或状态空间的每个合法叶子都必须处理。
- 要“最少”：先确认每条变化代价相同，再按层级扩展；边权不同需要换成最短路模型。
- 要“数量”：分清是在数连通块、路径、组合，还是在数不同状态。

## 最小反例

在无权图中，刚发现终点就当作最短答案，在 DFS 顺序下可能记录一条较长路径。反例不复杂：先沿很长的分支到达终点，再返回短分支。第一次发现发生过，但“第一次发现的路径最短”这个不变量并不成立。

## 代码映射

```text
1. 根据目标选择结束条件:
2. if 目标 == 存在:
3.     找到第一个合法结果时返回 true
4. if 目标 == 最短:
5.     按层级搜索
6.     第一次到达目标时返回当前距离
7. if 目标 == 全部:
8.     到达叶子时复制并保存结果
9.     继续所有剩余分支
10. if 目标 == 连通块:
11.     完整处理一个区域后再继续外层扫描
```
