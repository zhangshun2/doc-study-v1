建议按下面的依赖顺序学习。前一张卡解释不清时，不急着进入后一张。

## 单题层如何分工

- 想知道题目事实和权威 Java，打开标准题解。
- 想快速回忆一题的对象、状态、最小演算，打开核心模型。
- 想知道标准模型是怎样试错得到的，打开完整建模。
- 想把多道题的相同判断沉淀成一个思维工具，回到这里的对应概念卡。

概念卡只通过稳定链接连接代表题，不复制单题正文。后续新增主题时，仍从“对象、关系、状态、事件、目标”开始，不能先把算法名称当作结论。
