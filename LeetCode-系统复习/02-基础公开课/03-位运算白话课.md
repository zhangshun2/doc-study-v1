# 位运算白话课

## 1. 把整数看成一排开关

整数在机器里用固定宽度的二进制位保存。每一位只有 0 或 1，可以把它想成一个关闭或打开的开关。位运算让我们对这排开关逐位操作。

先只看四位非负数：`6` 写成 `0110`，`3` 写成 `0011`。

| 运算 | 逐位规则 | 例子 |
| --- | --- | --- |
| `&` 与 | 两边都是 1 才得 1 | `0110 & 0011 = 0010`，结果 2 |
| `|` 或 | 至少一边是 1 就得 1 | `0110 | 0011 = 0111`，结果 7 |
| `^` 异或 | 两边不同得 1，相同得 0 | `0110 ^ 0011 = 0101`，结果 5 |
| `~` 取反 | 每一位 0/1 翻转 | Java 中对 32 位 `int` 的每一位翻转 |

## 2. 为什么异或能消掉成对元素

异或一个值两次会还原：`x ^ x = 0`。异或 0 不改变原值：`x ^ 0 = x`。由于运算顺序可以交换和结合，数组里每个成对出现的值最终互相抵消，只剩单独出现的值。

```java
int answer = 0;
for (int value : nums) {
    answer ^= value;
}
```

这里的写法成立，依赖题目保证“其余值恰好出现两次”；若次数关系变了，抵消结论就不成立。

## 3. 与掩码配合

掩码是一个二进制图案，用来只观察或修改某几位。

```java
int lowestBit = value & 1; // 查看最右边一位：0 偶，1 奇
boolean isOdd = (value & 1) != 0;
int valueWithoutLowestOne = value & (value - 1);
```

`value & (value - 1)` 会把最右边的那个 1 清成 0。原因是减 1 会让最右边的 1 变 0，并把它右侧的 0 变成 1；与原值相与后，这些右侧新出现的 1 被清掉。

## 4. 移位

```java
int doubled = value << 1;     // 对非负且不溢出的数，相当于乘 2
int halved = value >> 1;      // 右移一位；负数会保留符号位
int unsigned = value >>> 1;   // 左侧补 0
```

Java 的 `int` 固定 32 位，`long` 固定 64 位。移位并不自动检查溢出。负数采用补码表示，因此初学阶段不要只画无符号小数位来解释负值的位运算。

## 5. 读位技巧的顺序

遇到压缩写法时，按这个顺序展开：先写参与运算的二进制位；逐位做规则；把结果转回十进制；最后解释这题为何恰好需要这个结果。括号要写清楚，例如 `(value & 1) == 1`。

位运算是可选表达方式。若普通循环和计数数组更容易解释、复杂度也满足题目限制，可以先使用普通版本，再记住位版本的适用条件。
