# 单题长时段与保存点规则

这份规则不再把固定的 20、30 或 40 分钟当成学习目标。你可以连续投入较长时间，把一道题的完整因果链走完；保存点的作用是防止中断后丢失上下文，不是催你结束，也不是用“按时完成”制造新的打卡要求。

真正需要限制的不是总时长，而是没有新证据的原地循环。链条能继续变清楚时，可以继续；同一处反复尝试却无法说明缺失关系时，应该保存断点，去补那一个桥接。

实际做题先打开 [[单题推导标准卡|单题推导标准卡]]；完整原因和新手示例见 [[人类读题与算法确认|人类读题与算法确认]]；四道真实题目的逐段推导与自评见 [[人类推导样板与评分|人类推导样板与评分]]。

八个自然问题嵌在下面七段里：问题 1 对应第 1 段，问题 2 对应第 2 段，问题 3 和问题 4 同属第 3 段，问题 5 到问题 8 依次对应第 4 到第 7 段。不要先把八问一次答完，再回头补过程。

## 第一层：从题面到算法方向

| 阶段 | 这一段先问什么 | 能继续往下走时 |
| --- | --- | --- |
| 1. 只读原题事实 | 输入、输出、示例、保证和禁止分别是什么？ | 能分开事实、推导和未知，先不急着给方法命名 |
| 2. 扩写题干 | 谁拿着什么，从哪里开始，重复做什么，何时停止？ | 别人按你的话能走一遍，每条扩写都能指回原句 |
| 3. 当前困惑、对象、过程和第一次变化 | 我具体卡在哪句，做完什么纸面动作后多出了什么证据？题目里有哪些对象和关系，人会怎样做，什么因此发生变化？ | 有当前困惑、实际动作、新增证据、对象身份、完整时间顺序、变化前后和答案时刻 |
| 4. 范围、预算和功能候选 | 每轮大约做多少操作，哪些量级不够，由当前操作能想到哪些待验证方向？ | 能分开官方约束、操作预算和功能候选 |
| 5. 第二次捕捉变化 | 这是重复查询、候选失效还是子问题复用？什么信息值得留下？ | 能指出重复劳动、候选寿命和所需操作 |
| 6. 确认算法方向 | 哪个具体候选真正支持当前操作和预算？ | 能比较候选并说出选择、代价和失效条件 |

数据范围只能做排除，不能直接推出“使用哈希表”或“使用双指针”。候选池必须同时来自当前过程需要的操作和范围允许的预算。只有第二次变化和方向确认句完整，才进入第二层。

## 第二层：方向确认后的模型链

| 推导段 | 现在要回答什么 | 想清后能说出什么 |
| --- | --- | --- |
| 1. 状态定义 | 每个变量在题目世界里表示什么？ | 不看代码也能完整定义 |
| 2. 初始、停止和答案时机 | 从哪里开始，何时结束，结果何时确定？ | 最小例子能对应每个初始值 |
| 3. 一次状态转移 | 当前事件读取什么、计算什么、写入什么？ | 能预测并手算下一轮 |
| 4. 更新顺序 | 为什么不能交换查询、写入和删除？ | 能说出交换后的具体错误 |
| 5. 不变量与正确性 | 为什么不会漏、不会多、不会误删？ | 理由依赖的条件可逐条指出 |
| 6. 结构与操作 | 所需操作与结构代价是否匹配？ | 能和更简单结构作具体比较 |
| 7. 伪代码和 Java | 每段代码对应哪个对象、状态和动作？ | 关键行位置与变量含义可解释 |
| 8. 反例与闭卷重建 | 模型何时失效，能否独立重来？ | 有反例、代码、自测和独立重建记录 |

前六段只负责从题面走到算法方向；第七段才负责模型、代码和反例。只说出算法名，还不能说明人为什么想到这里；代码能运行，也不能替代状态、顺序和不变量的解释。两条线都走通，才算本轮完整链闭合。

## 长时段怎么用

状态允许且链路仍在推进时，可以连续完成多个确认点，直到这一轮链路闭合。中途不要求按固定分钟切题，也不要求为了“短时高效”把推导压缩成摘要。

开始前只做两个选择：

1. **完整链**：今天主要把一道题从题意走到独立代码。
2. **断点推进**：今天只处理其中一段，例如补齐“状态与更新”到“不变量”的桥接。

两者都不是半途而废。区别只是本次明确推进了哪一段，而不是用题号数量计算成果。

## 什么时候保存并停止

- 同一处连续尝试两次，仍没有新证据或新的可检验判断：停止原地重试，写下最早断点。
- 已经知道缺失的关系，但需要查讲解：只补那一段，不顺手扩展成多套解法。
- 编译错误完成两轮有目的的定位后仍无法解释：保存输入、报错、当前判断，下一次从该处开始。
- 题干理解不稳：只核对输入、输出、约束和术语，不基于猜测写完整代码。
- 情绪明显升高、身体不适或无法维持注意力：立即停止，不补偿、不在下一时段追题量。
- 链路已经闭合：记录真实证据后结束，不需要为了达到某个时长继续重复。

停止句只需要写清：

```text
已经确认到：第 ___ 段，证据是 ______
最早未确认的是：______
下一次第一件事：______
```

这不叫欠账，而是保留长时段工作的接续点。

## 记录字段

`题号｜本次模式（完整链/断点）｜确认到第几段｜参考使用位置｜最早断点｜下一次第一步｜实际耗时（可选）`

测试用例由你自己挑选并手算。课程不代替你做边界穷举；每次至少留下一个由你设计、能检查当前理解的输入。
