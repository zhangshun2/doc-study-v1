# 回溯与选择搜索

这组用你已有的 DFS 基础练习：每次递归具体增加了哪个选择，返回时恢复什么。先把过程和代码骨架写稳，再讨论剪枝。

## P0

- [ ] [17 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)：每层给当前数字选一个字母。
- [ ] [22 括号生成](https://leetcode.cn/problems/generate-parentheses/)：每次选择后检查括号前缀是否合法。
- [ ] [39 组合总和](https://leetcode.cn/problems/combination-sum/)：决定候选能否重复选择及下一层起点。
- [ ] [46 全排列](https://leetcode.cn/problems/permutations/)：记录每个数字是否已在当前排列中使用。
- [ ] [78 子集](https://leetcode.cn/problems/subsets/)：每个元素选择加入或跳过。

## P1

- [ ] [79 单词搜索](https://leetcode.cn/problems/word-search/)：网格路径上的访问状态只对当前搜索路径有效。
- [ ] [494 目标和](https://leetcode.cn/problems/target-sum/)：枚举正负选择；随后与 DP 版本对照。

## P2

- [ ] [301 删除无效的括号](https://leetcode.cn/problems/remove-invalid-parentheses/)：按删除层数扩展，保证首次出现有效解时删除数最少。
