# 动态规划

你不需要一开始就从题面直接猜出表格。先把每个小问题用一句话定义，再把当前答案拆成可能的最后一步。对于很难直觉化的题，可以把清晰的状态定义、转移和实现作为需要复现的基准。

## 每题的状态卡

只要记录下次可复现所需的最小内容：

1. `dp[i]` 或 `dp[i][j]` 用一句完整中文表示什么。
2. 当前答案的最后一步有哪些来源。
3. 初始化哪个最小子问题，为什么。
4. 遍历顺序如何保证依赖已经算出。
5. 最终答案从哪个位置读取。

掌握后再记滚动数组等压缩技巧。压缩若影响直观性，保留更容易复现的版本。
