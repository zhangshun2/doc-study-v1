# 排序与区间

本组先练“比较顺序如何让下一步变简单”。排序题优先放在整个路线开头；区间、双指针或堆是排序后的应用，不要求每题都从零讲排序算法本身。

## P0

- [ ] [15 三数之和](https://leetcode.cn/problems/3sum/)：排序后固定一项，双指针收缩。
- [ ] [56 合并区间](https://leetcode.cn/problems/merge-intervals/)：按左端点排序后合并相邻重叠段。
- [ ] [75 颜色分类](https://leetcode.cn/problems/sort-colors/)：有限取值下原地分区。

## P1

- [ ] [31 下一个排列](https://leetcode.cn/problems/next-permutation/)：从右侧找可增大的位置，再重排尾部。
- [ ] [49 字母异位词分组](https://leetcode.cn/problems/group-anagrams/)：排序字符生成分组键；也可与哈希表对照。
- [ ] [148 排序链表](https://leetcode.cn/problems/sort-list/)：链表归并排序和指针操作。
- [ ] [215 数组中的第 K 个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)：快速选择或堆；先固定一种清晰版本。
- [ ] [347 前 K 个高频元素](https://leetcode.cn/problems/top-k-frequent-elements/)：频次统计后排序、堆或桶。
- [ ] [581 最短无序连续子数组](https://leetcode.cn/problems/shortest-unsorted-continuous-subarray/)：比较原序列和排序后的错位范围。

## P2

无。排序章节先覆盖能复用到其他题的主体方法；困难题留在其主要模型章节。
