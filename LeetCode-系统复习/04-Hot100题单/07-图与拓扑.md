# 图与拓扑

常规 DFS/BFS 你已经比较熟悉，所以这里以复现为主。拓扑放最后，是因为它需要把“等待的前置任务数量如何变化”落实到代码中。

## P0

- [ ] [200 岛屿数量](https://leetcode.cn/problems/number-of-islands/)：一个格子连到哪些邻格，访问后如何避免重复扩展。

## P1

- [ ] [207 课程表](https://leetcode.cn/problems/course-schedule/)：每门课还剩多少前置课；完成一课后哪些等待数减一。

## P2

- [ ] [287 寻找重复数](https://leetcode.cn/problems/find-the-duplicate-number/)：把“当前数字指向下一个下标”后寻找环；归入本章复查它的映射。
- [ ] [399 除法求值](https://leetcode.cn/problems/evaluate-division/)：变量间的带权关系，沿路径组合权值。

拓扑题的固定实现先选一种：Kahn 入度队列或 DFS 三色。不要一题同时背两份代码；另一种只需读懂，等第一种稳定后再扩展。
