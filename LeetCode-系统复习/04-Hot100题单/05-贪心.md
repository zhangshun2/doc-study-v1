# 贪心与局部选择

这些题的训练目标不是“猜一个最优选择”，而是把选择说清楚，并记住足以支持实现的理由。遇到抽象证明短期不顺时，允许记住基准版本和它的适用条件，先做重复。

## P0

- [ ] [55 跳跃游戏](https://leetcode.cn/problems/jump-game/)：维护目前最远能到哪里。
- [ ] [121 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)：每个卖出日只需此前最低买入价。
- [ ] [122 买卖股票的最佳时机 II](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/)：把连续上涨拆成可累计的相邻收益。
- [ ] [169 多数元素](https://leetcode.cn/problems/majority-element/)：候选与其他值成对抵消，依赖多数元素一定存在。

## P1

- [ ] [406 根据身高重建队列](https://leetcode.cn/problems/queue-reconstruction-by-height/)：排序后逐个插入到符合前面人数的位置。
- [ ] [621 任务调度器](https://leetcode.cn/problems/task-scheduler/)：先安排出现次数最多的任务，再填冷却空隙。

## 每题只保留四条

`目标是什么｜局部选择是什么｜适用条件是什么｜我能复述的理由是什么`

理由可以用小规模手算或交换说明展开，不需要每次把完整形式化证明重写一遍。若几轮之后仍卡在理由，记录它并转到代码重复，不把这件事拖成整晚的理论追问。
