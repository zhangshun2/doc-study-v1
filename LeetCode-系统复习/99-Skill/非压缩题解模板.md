# 非压缩题解模板

> 这份模板给 AI 和学习者共用。它不把专家答案切成几段，而是规定一个还不知道方法的人，现场怎样让下一份证据出现。
>
> 唯一现场顺序是“七阶段、九交接”。九问只在完成后定位最早断点，不是动手前要背的待办。

## 唯一现场顺序：七阶段、九交接

```text
阶段 1：交接 1  原题事实
阶段 2：交接 2  人话扩写
阶段 3：交接 3  对象
        交接 4  最笨但正确的过程
        交接 5  第一次变化与答案确定时刻
阶段 4：交接 6  数据范围与慢过程预算
阶段 5：交接 7  第二次变化
阶段 6：交接 8  候选比较与方向确认
阶段 7：交接 9  状态、更新顺序、不变量、代码、反例
```

每次交接现场只写五句：

```text
我现在只能确认：______
它还不够回答：______
因此现在只做：______
做完必须多出的证据：______
证据不足就退回：______
```

下一问必须由上一份证据留下的空缺产生。回答它只能使用一条原句、一个最小例子、一次手算、一次预算或一项候选比较。

九个现场问题互不替代：

```text
1. 我读到什么？
2. 这句话具体让我先做什么？
3. 这里面谁是一个独立对象？
4. 最笨的人会怎样走一遍？
5. 哪一刻真正发生了变化，答案何时确定？
6. 最大输入下，这个笨过程会重复多少，范围先缩小哪些方向？
7. 带着代价重看，哪份信息真的重复、失效、复用或必须保序？
8. 证据最后支持哪个方向，另一个候选为什么不够？
9. 这个方向怎样变成状态、顺序、不变量、代码和反例？
```

三条硬规则：

1. **题目事实错误一票否决。**
2. **流畅解释、知道方法名和代码跑通都不等于理解。**
3. **闭卷后必须重新生成判断，不能只复述最终答案。**

如果已经知道答案，开头必须声明“事后校验”。把方法名当成“记忆候选，不是题目事实”，暂时撤掉它的证明资格，再按下面的证据重新走。

## 九字段完成留痕

现场推进时只写上面的五句。整道题完成以后，再为每次交接留下同一组九项：

```text
小白此刻真正的原话疑问：______
为什么这个疑问现在才出现：______
纸上实际做了什么：______
做完后新增了什么证据：______
这份证据只能说明什么：______
它还不能说明什么：______
因此下一问只能是什么：______
回答它需要什么证据：______
如果答不出，退回哪里：______
```

九项不是作文格式。它们分别防止：

- 用专家式提问替换小白真正会说的话；
- 把后一步的答案提前塞进当前一步；
- 只写“想了想”，没有纸面动作；
- 把旧知识冒充成刚得到的证据；
- 让一个例子承担超出它范围的结论；
- 跳过当前证据无法回答的部分；
- 一次跨过多个认知台阶；
- 没想清下一步需要什么观察就继续写；
- 链条断了以后从最终答案重讲。

没有形成候选时写“没有形成候选”；没有发生真实转折时写“没有发生转折”。不要为了显得像新手补造“我一开始以为”。

## 九次交接的唯一门槛

| 交接 | 阶段 | 小白此刻只能问什么 | 纸上动作 | 允许新增的证据 | 禁止提前出现 |
| --- | --- | --- | --- | --- | --- |
| 1. 原题事实 | 1 | 题目到底给了我什么，要我交回什么？ | 圈返回要求，分栏抄输入、输出、保证、禁止、示例和未知 | 每项都能指回原句 | 方法名、结构名、复杂度结论、脑补条件 |
| 2. 人话扩写 | 2 | 一个普通人拿着什么，从哪里开始，下一步做什么，何时停止？ | 替换代词，逐句写动作、顺序、停止条件和它防住的错误 | 一条别人能按时间执行的人话过程 | 优化理由、答案时刻、题面没有的规则 |
| 3. 对象 | 3 | 这里面谁是一个独立对象，值和位置怎样分开？ | 圈身份条件；把相同值放在不同位置；写关系和结果归属 | 每个对象的身份、位置或时间、关系和目标 | 代码容器、把相同值合成一个对象 |
| 4. 最笨但正确的过程 | 3 | 照最直接的人类办法，第一眼先看谁，接着看谁，何时停？ | 用一个最小完整例子逐行演算：看到谁、处理谁、做什么、为何继续 | 一条能复走的人工过程 | 优化理由、用输入输出摘要代替演算 |
| 5. 第一次变化 | 3 | 谁因哪个事件从什么状态变成什么状态，答案凭什么此刻确定？ | 标出谁发生变化、触发事件、变化前、变化后、答案确定时刻和为什么不是更早或更晚 | 第一次变化和答案确定时刻 | 保存什么、最终结构、优化结论 |
| 6. 数据范围 | 4 | 慢过程最坏重复多少次，范围允许保留哪些量级，哪些方向只能先算待验证？ | 抄全约束，选最坏输入，数一轮核心动作并乘轮数；把脑中方向另栏写成待验证假设 | 官方约束、自己的操作预算、被排除的复杂度家族，以及未获证明资格的待验证方向 | 未标记的方法名、直接选择方向，或把范围当算法暗号 |
| 7. 第二次变化 | 5 | 带着代价重看，哪份信息会重复读取、过期、复用或必须保序？ | 回到同一条人工过程，用最小例子逐类取证，再把需要写成操作动词 | 四类现象的发生状态，以及所需操作 | 具体容器、伪代码、尚未比较的最终方向 |
| 8. 方向确认 | 6 | 哪个候选真能承担这些操作，另一个为什么不够？ | 逐项比较支持、缺口、失效条件和代价，写完整因果句 | 有取舍依据的方向确认句 | 只有方法名、提前写完整代码 |
| 9. 完整思维链 | 7 | 对象怎样变成状态，先更新谁，为什么不会漏？ | 逐段接对象、动作、操作、状态、代码、顺序、不变量和反例 | 可闭卷重建的完整链 | 更换方向、用运行通过补推导 |

## 写作前先记录真实起点

- 我已经会什么：
- 真实初始理解（没有形成候选就写“没有形成候选”）：
- 哪条题目事实支持、推翻或暂时保留它：
- 哪条题目事实还不能支持它：
- 我现在还不知道什么：
- 下一个最小问题：
- 什么具体证据会让我保留或改变这个判断：

### 现场动作记录

每推进一小步，先留下实际做过的动作和它新增的证据：

```text
当前最早空缺：______
第一件实际做的纸面动作：______
做完后多出的证据：______
此刻真实候选：______（没有形成候选就写“没有形成候选”）
下一步只问：______
```

动作至少要能指出圈了哪句原题、补了哪一行过程、走了哪个例子、数了哪一轮重复，或比较了哪项操作。只写“想了想”“分析了一下”不算。

### 推理转折记录

只有现场真的出现判断变化时才填；没有发生转折就写“没有发生转折”：

```text
我原来看到或以为：______
当时支持它的证据是：______
后来哪个最小例子、原句或约束让它不能继续：______
因此我现在只修正：______
我接下来做的纸面动作是：______
做完以后，哪项证据能告诉我可以继续：______
```

## 交接 1：原题事实

先贴原句，不先写概括。题解、标签和讨论区暂时关闭。

```text
小白此刻真正的原话疑问：这些字到底让我交回什么？
为什么这个疑问现在才出现：刚打开题目，只有题面文字，还不知道哪些事实重要。
纸上实际做了什么：圈出返回要求，把输入、输出、保证、禁止和示例分开抄。
做完后新增了什么证据：一份有来源的题目事实表。
这份证据只能说明什么：题目明确写了什么。
它还不能说明什么：一个普通人应按什么顺序动手。
因此下一问只能是什么：拿着这些对象，我第一步做什么？
回答它需要什么证据：逐句替换代词后的可执行过程。
如果答不出，退回哪里：原句，逐字检查输入、输出和返回形式。
```

| 原句 | 我现在能确认的事实 | 来源（事实 / 推导 / 推测） | 我不能自行补上的假设 |
| --- | --- | --- | --- |
|  |  |  |  |

- 输入对象：
- 输出结果：
- 题目明确保证：
- 题目明确禁止：
- 目前仍然未知：
- 本次真实初始理解：
- 此刻真实候选：没有形成候选。
- 如果现场出现过题面没有保证的自然假设，写明它；没有就写“没有形成额外假设”。

如果脑中先出现方法名，只能记成“记忆候选，不是题目事实”。此时它没有证明资格。

## 交接 2：人话扩写

扩写不是换同义词，而是让另一个人真的能在纸上开始。

| 原句 | 新增了什么对象、动作、身份或顺序 | 新增了什么停止条件或禁止项 | 忽略后具体错在哪 | 来源 |
| --- | --- | --- | --- | --- |
|  |  |  |  | 事实 / 推导 / 推测 |

```text
小白此刻真正的原话疑问：我手里拿着什么，第一步先碰谁？
为什么这个疑问现在才出现：题目事实已经分开，但它们仍是静态文字。
纸上实际做了什么：替换代词，把承载判断的句子按时间连起来。
做完后新增了什么证据：一条普通人能照着执行的人话过程。
这份证据只能说明什么：怎样机械地执行题意。
它还不能说明什么：值、位置和身份是否已经分清。
因此下一问只能是什么：这里面谁是一个独立对象？
回答它需要什么证据：身份、位置和关系的纸面证据。
如果答不出，退回哪里：原句，检查被忽略的动作或停止条件。
```

完成时必须能写出：

```text
我手里有：______
我从：______ 开始
我反复做：______
条件“______”意味着我不能：______
当：______ 时停止
我最后要交出：______
```

别人只读这段文字就能按顺序演完，才算通过。此时仍然不需要方法名。

## 交接 3：对象

人话过程能走，但值和位置还可能混在一起。先做一个能产生身份证据的纸面动作，再填对象表。

```text
小白此刻真正的原话疑问：两个值相同，它们算同一个东西吗？
为什么这个疑问现在才出现：过程里已经出现对象，但还没有比较它们的位置和身份。
纸上实际做了什么：把两个相同的值写在两个不同位置或时间下。
做完后新增了什么证据：值可以相同，对象身份仍然不同。
这份证据只能说明什么：哪些属性和位置不能合并。
它还不能说明什么：一个普通人按什么顺序把它们走完。
因此下一问只能是什么：照最直接的人类办法，第一眼先看谁？
回答它需要什么证据：最小完整例子的逐行手算。
如果答不出，退回哪里：人话扩写，确认结果绑定在哪个对象上。
```

| 题目对象 | 值和状态 | 身份由什么决定 | 位置或时间 | 从何时有效到何时失效 | 和谁发生关系 | 最终要得到什么 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

要求返回原下标时，两个相同的值不能合并成一个没有位置的对象。

## 交接 4：最笨但正确的过程

对象分清后，用一个最小但完整的例子，按人最直接会做的顺序走一遍。不要先问高效做法。

```text
小白此刻真正的原话疑问：我现在到底按什么顺序执行？
为什么这个疑问现在才出现：对象已经分清，但它们在时间上的先后还不知道。
纸上实际做了什么：用一个最小完整例子逐行写“看到谁、处理谁、做什么、为何继续”。
做完后新增了什么证据：一条能复走的慢过程。
这份证据只能说明什么：最直接的办法怎样得到完全正确的答案。
它还不能说明什么：哪一刻答案从“没有”变成“确定”。
因此下一问只能是什么：过程中第一次真正变化的是谁？
回答它需要什么证据：谁发生变化、变化前、触发事件、变化后、答案确定时刻，以及为什么不是更早或更晚。
如果答不出，退回哪里：对象表和最小例子。
```

| 步骤 | 我现在看见什么 | 这一步处理谁 | 具体做什么 | 做完后什么变了 | 为什么还能继续 |
| --- | --- | --- | --- | --- | --- |
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |

如果某一步只能靠“然后算法会……”补上，说明现场还没有人工过程。例子太复杂就缩小；看不到关键关系就增加一个能触发关系的对象。

## 交接 5：第一次变化与答案确定时刻

过程走完后，才允许观察哪一刻状态改变。

```text
小白此刻真正的原话疑问：哪一刻什么对象变了，答案什么时候才真的确定？
为什么这个疑问现在才出现：完整过程已经走完，第一次停止或状态改变现在才可见。
纸上实际做了什么：在过程里标出第一次变化和写下答案的动作。
做完后新增了什么证据：谁发生变化、变化前、触发事件、变化后、答案确定时刻，以及为什么不是更早或更晚。
这份证据只能说明什么：过程里第一次发生了什么。
它还不能说明什么：这份慢是否值得优化，也不能说明应该保存什么。
因此下一问只能是什么：这种慢过程最坏会重复多少次？
回答它需要什么证据：官方约束、最坏输入和操作预算。
如果答不出，退回哪里：交接 4 的人工过程。
```

```text
谁发生变化：______
触发事件：______
变化前：______
变化后：______
答案确定时刻：______
为什么不是更早或更晚：______
```

求最大值、最小值、最近值这类题，第一次算出候选通常只算第一次状态变化；只有题目保证唯一，或已经证明其余候选都被淘汰，才叫答案确定时刻。

## 交接 6：数据范围与慢过程预算

第一次变化说明过程里发生了什么，但没有说明这份慢是否值得处理。因此现在才读完整约束。

```text
小白此刻真正的原话疑问：这份慢过程在最坏输入上要重复多少次？
为什么这个疑问现在才出现：没有完整人工过程，就没有资格数它的重复。
纸上实际做了什么：抄全约束，选最坏输入，数一轮核心动作并乘轮数。
做完后新增了什么证据：官方约束、自己的操作预算和被排除的复杂度家族。
这份证据只能说明什么：哪些量级不能稳定承受最坏输入。
它还不能说明什么：具体应该保存什么，也不能把脑中冒出的方向当成已确认答案。
因此下一问只能是什么：带着代价重看，哪份信息真的被重复读取或失效？
回答它需要什么证据：同一条人工过程上的最小重复例子。
如果答不出，退回哪里：交接 4 和交接 5。
```

```text
慢过程重复的核心动作：______
每一轮大约做多少次：______
最多有多少轮：______
合起来大约是：______
```

| 官方约束 | 限制了什么 | 慢过程最坏预算 | 排除哪些复杂度家族 | 仍保留哪些功能方向 | 还缺什么证据 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

读完范围后想起熟悉方法很常见。不要删除这个记忆，也不要让它直接当结论；另开一栏把它写成待验证方向：

```text
范围后想到的方向：______（没有形成方向就写“没有形成方向”）
它可能消除的重复或失效工作：______
它依赖的题目条件：______
最坏预算是否允许：______
目前仍缺少什么过程证据：______
它还不能被选为主方向，因为：______
```

六项没有写全，方法名只是记忆泄漏。范围只能排除复杂度家族；待验证方向仍要在交接 7 回到过程取证，在交接 8 才获得被选择和拒绝的资格。

## 交接 7：第二次变化

第二次变化不是把第一次变化重说一遍，也不是直接说“优化暴力”。带着交接 6 的代价，回到同一条人工过程，逐类取证：

| 现象 | 小白要问 | 需要的证据 | 本次结论 |
| --- | --- | --- | --- |
| 重复查询 | 同一个问题会不会被以后再问一次？ | 哪份历史能回答，未来读取值、位置还是次数 | 发生 / 没有形成该现象 |
| 候选失效 | 哪个事件后，一批对象已经不可能产生答案？ | 失效条件是什么，为什么能安全丢掉 | 发生 / 没有形成该现象 |
| 子问题复用 | 不同路径会不会到达同一个更小问题？ | 重复出现的最小例子和需要保存的结果 | 发生 / 没有形成该现象 |
| 顺序约束 | 新对象从哪一端加入，又从哪一端结算？ | 为什么这个顺序不会漏掉仍可能的候选 | 发生 / 没有形成该现象 |

```text
小白此刻真正的原话疑问：新事件到来时，为什么会有旧信息同时失效？
为什么这个疑问现在才出现：已经知道慢过程可能有重复，才回来看同一事件被谁重复参与。
纸上实际做了什么：回到最小例子，逐类标出重复、失效、复用或顺序。
做完后新增了什么证据：真实发生的现象和所需操作。
这份证据只能说明什么：未来需要查、加、删、取极值或保序。
它还不能说明什么：哪个具体容器承担这些操作。
因此下一问只能是什么：哪个候选支持这些操作，代价是否允许？
回答它需要什么证据：候选逐项比较。
如果答不出，退回哪里：交接 4；没有预算则退回交接 6。
```

把真实发生的变化翻译成操作，而不是容器：

```text
需要加入什么：______
需要查询什么：______
需要删除或结算什么：______
读取和删除必须遵守什么顺序：______
```

没有发生某类现象就写“没有形成该现象”，不能补一个听起来合理、现场却没出现过的现象。

## 交接 8：候选比较与方向确认

操作需求已经具体，才允许具体方法名进入比较。

```text
小白此刻真正的原话疑问：为什么不是继续重扫，也不是另一个熟悉方向？
为什么这个疑问现在才出现：操作需求刚刚具体，候选才有可比对象。
纸上实际做了什么：比较每个候选的支持、缺口、失效条件和代价。
做完后新增了什么证据：完整方向确认句。
这份证据只能说明什么：当前候选能承担已确认的操作和预算。
它还不能说明什么：状态变量、更新顺序和代码怎样落地。
因此下一问只能是什么：怎样把对象变成状态并保证更新顺序？
回答它需要什么证据：状态、转移、不变量和反例。
如果答不出，退回哪里：交接 7 的操作需求。
```

| 候选 | 支持哪些操作 | 缺少什么 | 何时失效 | 时间、空间和额外维护代价 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

没有真实歧义时，不必为凑数量编一个自己从未考虑过的方案。可以写“没有形成第二个真实候选”，但至少要说明当前方向为什么能承担交接 7 的操作。

完整方向确认句必须是一句因果链：

> 因为慢过程在 ______ 上重复，最坏预算是 ______；第二次变化证明未来需要 ______ 操作；候选 A 支持 ______，但缺少 ______；候选 B 能承担 ______，代价是 ______；所以当前方向选择 ______。

方法名可以在这里出现，但不能代替前面的证据。

## 交接 9：状态、更新顺序、不变量、代码、反例

方向已确认，不再比较新方向。按下面顺序逐段接上：

1. 每个状态在题目世界里代表哪个对象，覆盖什么，不覆盖什么；
2. 初始值、停止条件和答案写入时机对应什么现实动作；
3. 一次转移拆成读取、计算、写入；
4. 交换两个更新动作，用最小输入证明具体错误；
5. 写不变量，解释为什么不会漏、不会重复、为什么可以安全删除；
6. 从操作反推结构，再写伪代码和 Java；
7. 关键代码逐段映射回题目对象、人工动作和操作需求；
8. 用反例、边界和闭卷重建检查整条链。

```text
小白此刻真正的原话疑问：这些变量到底各代表谁，先更新谁才不会互相污染？
为什么这个疑问现在才出现：方向已经确认，代码才有资格落地。
纸上实际做了什么：把对象、动作、操作、状态和代码逐行映射，并交换更新顺序做反例。
做完后新增了什么证据：状态语义、更新顺序、不变量和反例。
这份证据只能说明什么：当前实现能接回人工过程。
它还不能说明什么：另一条算法方向是否更好，这里不再比较。
因此下一问只能是什么：换一个边界或闭卷重写时，哪一处会最先断？
回答它需要什么证据：最小反例、边界输入和闭卷重建。
如果答不出，退回哪里：最先说不清的交接；方向无依据回交接 8。
```

| 题目对象 | 人工过程里的动作 | 第二次变化提出的操作要求 | 状态变量 | 伪代码 | Java 代码位置 | 更新顺序或不变量 | 对应反例 |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |

最小反例必须写完整：

```text
最小输入：______
原本应保持的不变量或更新顺序：______
如果破坏它，具体哪一步先算错：______
错误输出：______
修复动作：______
```

只写“可能出错”不够。反例必须真的让状态、不变量或更新顺序失效，并指出错误最早发生在哪一步。

## 题解正文最小结构

```markdown
## 现场声明
## 交接 1：原题事实
## 交接 2：人话扩写
## 交接 3：对象
## 交接 4：最笨但正确的过程
## 交接 5：第一次变化与答案确定时刻
## 交接 6：数据范围与慢过程预算
## 交接 7：第二次变化
## 交接 8：候选比较与方向确认
## 交接 9：状态、更新顺序、不变量、代码、反例
## 复杂度与最终检查
```

每次交接的正文先保留现场五句和对应的纸面证据；整篇完成后的复盘区再补九字段留痕。不用“分析题意”“核心就是”“显然”替代中间因果。长题解可以增加小节，但不能合并或调换九次交接。

## 完成后的九问只用于诊断

做完一整条现场后，可以用下面九问定位最早断点。它们不是第二套现场主线，也不能在开始前逐条背诵：

| 事后问题 | 对应交接 |
| --- | --- |
| 题目给了我什么，要我交回什么？ | 1 |
| 一个普通人在纸上第一步做什么？ | 2 |
| 有哪些对象，谁和谁有关系？ | 3 |
| 最笨但正确的过程怎样走？ | 4 |
| 哪一刻什么变了，答案何时确定？ | 5 |
| 最坏重复多少，范围排除哪些复杂度家族？ | 6 |
| 哪份信息会重复、过期、复用或必须保序？ | 7 |
| 哪个候选能承担操作，完整方向确认句是什么？ | 8 |
| 对象怎样变成状态、顺序、不变量、代码和反例？ | 9 |

九问只帮助回查，不改变现场顺序；交接 9 不能反过来替交接 3 到 8 补证据。

## 现场生成与反写检查

每次换问前只写五句：

```text
我现在只能确认：______
它还不够回答：______
因此现在只做：______
做完必须多出的证据：______
证据不足就退回：______
```

一次只跨一个认知台阶。当前一问只能用一条原句、一个最小例子、一次手算、一次预算或一项候选比较回答。

写完后再做两项反写检查：

1. 隐藏最终方法名后，整条推导是否仍然成立？
2. 删掉当前证据后，下一问是否自然消失？

如果证据没了，下一问还照常存在，说明它来自答案而不是现场。已知答案时，先标“事后校验”。

## 卡住时只留现场五句

```text
我现在只能确认：______
它还不够回答：______
因此现在只做：______
做完必须多出的证据：______
证据不足就退回：______
```

写不出“这个空缺正在阻碍什么”，通常说明还没有认真读题或手算。下一问要小到能当场用原句、例子或一次演算回答。

## 发布前验收

逐项回答，不能用“感觉讲通了”代替：

- 九次交接是否完整且顺序正确？
- 每次交接现场是否有五句证据边界，完成后的九字段留痕是否齐全？
- 阶段 3 是否分别完成对象、慢过程、第一次变化？
- 交接 6 的方法名是否只出现在“待验证方向”里，并写全六项缺失证据？
- 交接 7 是否位于交接 6 之后、交接 8 之前？
- 交接 8 之前是否没有提前宣布最终方向？
- 方向确认句是否能从操作需求和预算逐段读出来？
- 交接 9 是否把变量、更新顺序、不变量、代码位置和反例逐段接回人工过程？
- 隐藏方法名后整条推导是否仍然成立？
- 闭卷后能否重新生成判断，而不是只背结论？

完整标准见 [[../05-单题流程/单题推导标准卡|单题推导标准卡]]；四道题的新手现场见 [[../05-单题流程/人类推导样板与评分|人类推导样板与评分]]。
