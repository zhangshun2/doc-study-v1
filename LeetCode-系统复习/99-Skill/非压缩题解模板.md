# 非压缩题解模板

> 这是给 AI 和学习者共同使用的题解基准。它保留“一个还不知道答案的人怎样从题面想到算法，再怎样验证算法”的中间过程，不把关键观察压缩成一个标签或公式。

> 写作时沿着 [[../05-单题流程/单题推导标准卡|单题推导标准卡]] 往下走。标题填满不代表推导完整；关键是读者能不能看见当前判断、暂时误解、修正理由和下一步问题。

> 一篇合格题解按七个连续阶段展开：
>
> `读题 -> 扩写 -> 对象、过程、第一次变化 -> 范围与候选 -> 第二次变化 -> 方向确认 -> 推导链`
>
> 第三段和第四段内部各有三个连续小步；前六段把题面推到算法方向，第七段才进入状态和代码。

> 前五段可以写功能候选，但不把最终方法名当成结论；第六段才比较具体方法，第七段才进入状态和代码。
>
> 每一段都有退出条件。不是“这一节写满了”就继续，而是能说出下一段真正需要的那句证据才继续；说不出来就退回对应的最早缺口。
>
> 遇到真实卡点时，再使用下面的断点记录。不要把它机械复制到每个小标题：
>
> `我现在已经能确认：______`
>
> `我现在还不能确定：______`
>
> `这个空缺正在阻碍：______`
>
> `因此下一个最小问题是：______`
>
> `哪一种具体输入、例子、约束或手算结果能回答它：______`

## 开始前：我现在的真实状态

- 我已经会什么：
- 真实初始理解（没有形成候选就写“没有形成候选”，不要为了模板补写“我一开始以为……”）：
- 哪条题目事实支持、推翻或暂时保留它：
- 哪条题目事实还不能支持它：
- 我现在还不知道什么：
- 下一个最小问题：
- 什么具体证据会让我保留或改变这个判断：

如果我已经知道最终方法，先声明这是“事后校验”，暂时把方法名移出前五段，按题目事实和人工过程重新走一遍。不要把记住的结论改写成第一次发现。

每一步都要能回答“为什么现在轮到这一问”。真正卡住时，记录五句现场，而不是只写“不会”：

```text
我现在已经能确认：______
我现在还不能确定：______
这个空缺正在阻碍：______
因此下一个最小问题是：______
哪一种具体输入、例子、约束或手算结果能回答它：______
```

下一问必须来自上一段留下的具体空缺。不要在这里问“这题用什么算法”；等人工过程、预算、第二次变化和操作需求都写出来以后，方向才有资格进入比较。

## 七段退出条件

| 阶段 | 进入下一段前必须能说出什么 | 说不出来时退回 |
| --- | --- | --- |
| 1. 读题 | 输入、输出、示例、保证、禁止和未知能分开；每条有来源；如果现场确实出现了一个题面没有保证的自然假设，能指出来；没有就如实写“没有形成额外假设”；此刻没有方法名 | 回到原句重读；示例不能替代完整规则 |
| 2. 扩写 | 别人只看扩写就能按时间演完；每条新增解释能回到原句；能说出一个条件阻止了什么错误 | 只换同义词或补了不存在的条件，退回第 1 或第 2 段 |
| 3. 对象、过程与第一次变化 | 能分开值、位置和身份；最小完整例子能走到答案；能说出“变化前 -> 触发事件 -> 变化后 -> 答案产生时刻”；没有结构名或优化结论 | 不会走过程，退回第 2 段；能走但说不清变化和答案时机，留在第 3 段 |
| 4. 范围与候选 | 官方约束、自己的操作预算和功能候选分开；慢过程最坏核心操作数有估算；候选来自实际操作需求 | 没数过程，退回第 3 段；把范围当算法暗号，留在第 4 段 |
| 5. 第二次变化 | 能归入重复查询、候选失效、子问题复用、顺序现场或其组合；有最小例子证明；说清未来读取什么、何时失效、需要哪些操作 | 没有具体重复或失效，退回第 3 段；没有预算，退回第 4 段 |
| 6. 方向确认 | 有完整因果句；有真实歧义时比较多个方向；没有真实歧义时说明一个熟悉替代方向为何不适用；不能为了凑数制造假候选 | 候选没有从操作长出来，退回第 5 段；只能报方法名，留在第 6 段 |
| 7. 推导链 | 状态、转移、更新顺序、不变量和代码都能回到题目对象与第二次变化；能闭卷重建 | 模型解释不通，留在第 7 段；发现方向本身没有依据，退回第 6 段 |

提前出现方法名时，不把它删掉装作没想过。把它标成“记忆候选，不是题目事实”，暂时撤掉它的证明资格，补齐前面缺失的对象、过程、预算和操作需求后，再回到第 6 段比较。

通过线：如果读题时确实产生了一个“听起来很自然，但题目没有保证”的假设，能把它指出来并留在证明之外；如果没有，就如实写“没有形成额外假设”，不要为了填表创造一个。暂时不知道可以保留；题目事实写错不能通过。

## 扩写成完整人话过程

先按原句顺序找出会改变动作、限制、顺序或结果的信息，再把这些句子扩写成可执行过程。不要只把原句换成同义词，也不要把不承载判断的句子机械扩写成故事。

| 原句 | 它新增的动作、身份、顺序或限制 | 如果忽略会错在哪 | 来源 |
| --- | --- | --- | --- |
|  |  |  | 事实 / 推导 / 推测 |

> 我手里有 ______；我从 ______ 开始；我反复 ______；条件“______”意味着我不能 ______；当 ______ 时停止；题目最后要交出的是 ______。

每条扩写都要能指回原句。不能把方法名偷偷写进扩写。指不回原句的解释只能标成“推测”，不能拿它继续证明。

- 扩写后仍然不知道的是：
- 这个扩写能排除哪个错误理解：
- 条件“______”防止的具体错误是：
- 答案在哪一类事件之后成为确定结果：

## 数据范围、操作预算与功能候选

- 规模上限：
- 值域和特殊保证：
- 直接过程大约做多少次操作：
- 因此不能依赖：
- 仅凭范围仍不能判断：

分开标注：

- **官方事实：** 题面明确给出的范围或保证。
- **操作预算：** 我根据直接过程估算的操作量。
- **候选方向：** 由“过程需要什么操作 + 预算 + 特殊保证”产生的待验证方法。

把“范围怎样缩小候选”写成可检查的链，而不是一句“所以要用某算法”：

| 约束或保证 | 它限制了哪些规模、值域或操作 | 直接过程因此要做多少工作 | 它排除什么量级或条件 | 仍能继续考虑的功能候选 | 此刻仍不能确定什么 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

数据范围先用来估算慢过程能否承受，再排除明显不够用的复杂度家族；它不直接推出方法名。随后必须把慢过程实际需要的操作和范围允许的预算合在一起，才形成待验证候选。前五段最好先写“需要保留值、位置还是次数”这类功能描述，把具体结构名留到方向比较。

范围缩成候选时必须留下的四行：

```text
官方约束：……
慢过程最坏大约重复：…… 次
因此首先不能稳定依赖：…… 量级
结合过程需要的操作，仍待验证的候选是：……
```

如果最后一行仍写不出，回到人工过程补充“未来需要查询、结算、删除或复用什么”，不要用题目标签填空。

- 这属于重复查询、候选失效还是子问题复用：
- 最昂贵或最频繁的重复动作：

- 哪批候选会失效：
- 哪份状态必须保留，哪份可以丢弃：

新手在这里为什么卡住：

- 这份信息未来是否还会被读取：
- 未来读取时需要值、位置、次数还是有效期：
- 它会在什么事件发生后失效：

第二次变化不是“把第一次变化再说一遍并加一句优化”。它必须指出第一次没有回答的新问题：哪份工作会重复，哪批候选会过期，或哪个子问题会从不同路径再次出现。

| 观察 | 只回答 | 仍然回答不了 |
| --- | --- | --- |
| 第一次变化 | 哪个对象因什么事件从什么状态变成什么状态 | 哪份工作重复、值不值得优化 |
| 第二次变化 | 哪份历史可复用、哪批候选失效、需要什么操作 | 最终结构、完整代码 |

第二次变化必须归入至少一种来源：重复查询且可保留历史、候选在一次事件后失效、重叠子问题可复用、顺序约束要求保留现场。归不进去，说明还没有找到优化入口。

## 候选方向与选择理由

现在才允许具体方法名进入比较。

有真实歧义时，比较多个方向；没有真实歧义时，也必须说明一个熟悉替代方向为什么在当前题目里不适用。不能为了满足“至少两个候选”的表格式要求，临时编一个自己从未认真考虑的方案。

| 候选方案 | 消除哪份重复劳动 | 需要的数据和操作 | 代价或失效条件 |
| --- | --- | --- | --- |
| A |  |  |  |
| 候选 B（仅在存在真实替代方向时填写） |  |  |  |

方向确认句：

> 当前过程反复需要 ______；重新扫描会做 ______ 次操作；因此算法必须支持 ______；方案 A 能提供 ______，方案 B 在 ______ 时失效；所以选择 A。

没有这句话，不进入完整实现。

通过门前逐项自检：

- 我能不能不用方法名复述完整的人工过程？
- 我的候选是否由真实操作和预算共同产生？
- 如果存在真实替代方向，我是否写清了它被什么证据排除；如果没有，我是否说明了为什么它不是一个有效候选？
- 我是否为了模板凑数编造了一个从未认真考虑过的候选？
- 我能否指出下一步状态将覆盖哪些题目对象，以及答案在何时确定？

方向确认前，再检查一次：

- 我是否把官方约束写成了官方推荐算法：
- 我是否把候选名称写成了结论：
- 我是否能指出一个真实未采用候选的具体失效条件，或说明本题为什么没有真实歧义：
- 如果现场确实出现过误判或犹豫，我是否保留了“当时以为……，后来因为……改判”的真实过程；如果没有，是否明确写了“没有形成候选”，而不是补写一段假直觉：
