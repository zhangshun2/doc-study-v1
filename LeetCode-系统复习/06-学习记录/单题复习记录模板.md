# 单题复习记录模板

复制以下内容记录一道题，不要求每次都填得完整。这份记录只保存本次推理、卡点和下次起点；完整 Java、掌握状态与复习日期回到对应标准题解维护，不在此处建立第二套排期。

- 本次：学习 / 复写 / 延迟复测
- 日期与耗时：

- 输入与输出：

回写规则见 [[../../学习文库/算法学习/学习看板/单题复习工作台|单题复习工作台]]。看参考或提示后完成的抄写不计入 `independentAttempts`。
