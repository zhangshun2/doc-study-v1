# 分析法实验

这个目录回答的不是“这道题的标准答案是什么”，而是：

> 同一道题，用哪条人类能自然走通的推导路径，最适合形成稳定判断、快速回忆和实际编码能力？

[[题库与题解生产协议-v2|题库与题解生产协议 v2]] 是题库讲解、单题题解、复习材料和网站阶段页的唯一生产权威。[[../05-单题流程/单题推导标准卡|单题推导标准卡]] 是现场速查入口；这里负责实验、评分和选择。任何实验都先核对问题事实；题面读错时，后续评分和方向选择全部作废。

## 当前结论

四道题的结果支持同一个结论：

```text
人工过程法负责从题面走到第一次变化
-> 第二次变化暴露主要现象
-> 只选一个辅助分析法走完整因果链
-> 其他方向只用于事后查漏
```

| 第二次变化的主要现象 | 使用的辅助分析法 | 代表题 |
| --- | --- | --- |
| 已经出现的信息会被未来反复查询 | 状态生命周期法中的历史保留 | `1. 两数之和` |
| 对象产生后等待、结算或过期 | 状态生命周期法中的等待结算 | `739. 每日温度` |
| 一批候选被同一个事实支配 | 候选淘汰与不变量法 | `11. 盛最多水的容器` |
| 同一个子问题从多条路径重复到达 | 子问题复用法 | `322. 零钱兑换` |

这不是“四道题分别对应四个模板”。共同底座始终是人工过程。辅助方法只有在第二次变化提供了当前题目的具体证据后才能进入，不能根据标签提前选择。

## 为什么适合当前学习者

这套选择针对的不是“多刷几道”，而是以下实际困难：

- 学过很多遍但容易忘，因此需要能从题目对象重新生成方向，不能只背结论。
- 单次可以学习较长时间，因此适合把一条链走到闭合，不按固定分钟切断。
- 情绪状态会波动，因此记录必须围绕“现在确认了什么、哪里断了”，不用完成数、连续天数或“已经学会”来评价。
- 对直接关联的思维链要求高，因此每个结论都要指出上一份证据、当前空缺和下一次可执行动作。
- 更关心实际编码，因此每种分析法都必须能回答：变量对应哪个题目对象、更新顺序错了会怎样、错误最早断在哪一段。

## 使用顺序

第一次进入时：

1. 先读 [[题库与题解生产协议-v2|题库与题解生产协议 v2]]；现场做题时用 [[../05-单题流程/单题推导标准卡|单题推导标准卡]] 速查。
2. 再读 [[四题多路径实验|四题多路径实验]]，看同一道题为什么会出现不同质量的分析路径。
3. 整理一道新题时，按 [[量产与复习协议|量产与复习协议]] 执行，不照抄某一题的结论。
4. 比较两份解释时，按 [[评分与选择规则|评分与选择规则]] 先过事实与因果门槛，再看六维分数。
5. 复习时先重建人的判断过程，再看模型和代码；分数不能代替闭卷重建。

## 边界

- 这里的评分评价的是“分析路径和解释质量”，不是给人打分。
- 实验数据不保存第二份题面、约束或 Java 实现；官方事实仍以 `problems.json` 和标准题解为准。
- 同一道题可以有多条正确算法路径。选择一条作为学习主线，不代表另一条错误。
- 没有真实出现过的候选、犹豫或转折不能补写。实验只记录实际留下的证据。
- 数据范围可以排除复杂度家族，但不能单独证明某个算法正确。
- 不能因为某条路径分数高，就省略状态、更新顺序、不变量、代码映射和反例。
