# 分析法实验协议

> 顺序、字段、门控和验收的唯一生产权威是 [[题库与题解生产协议-v2|题库与题解生产协议 v2]]。本文件只规定怎样做对照实验，不另维护第二套推导顺序。

## 一、实验目的

实验要回答三个可验证的问题：

1. 一条解释能不能让不知道答案的人，从原题事实自然走到算法方向？
2. 换一个同类例子后，这条路径还能不能重新生成关键判断？
3. 写成 Java 后，能不能用这条路径定位更新顺序、边界和不变量错误？

实验不比较“谁写得更像标准答案”，也不比较“谁用的方法名更高级”。

## 二、实验单位

每次实验只处理一道题，并固定以下版本信息：

```text
题号：
官方来源：
事实核对日期：
实验版本：
本次是首次推导还是事后校验：
当前最早空缺：
本次允许回答到哪一阶段：
```

如果已经知道最终方法，必须标成 `事后校验`。这时可以比较解释质量，但不能把自己的记忆倒写成“我一开始自然想到”的现场。

每次实验只改变一个因素。例如：

- 同一道题，比较“标签倒推”和“人工过程法”；
- 同一道题，比较“每天向后重扫”和“等待生命周期”；
- 同一条人工过程，比较“候选失效”和“按值域查询最近位置”；
- 同一条递推关系，比较“朴素 DFS”“BFS 最短路”和“按金额递增的 DP”。

不能在同一轮同时更换题目、事实、判分标准和最终方向，否则无法判断差异来自哪里。

## 三、实验前先固定题目事实

题目事实错误时，后续所有比较作废。开始前先记录：

```text
输入对象与字段：
必须返回什么：
示例实际说明了什么：
明确保证：
明确禁止：
没有保证、不能添加的条件：
事实来源：
```

`problems.json` 是官方题面的结构化快照，具体记录仍回到对应标准题解核对。示例只能帮助理解，不能替代题目规则。

## 四、共同基线

所有对照路径都必须使用 [[题库与题解生产协议-v2#三、九次交接生产表|同一套九次交接]]。实验不重新定义阶段，也不能为了让某个候选得分更高而调整顺序。

实验只增加三个记录：

1. 这条路径第一次出现在哪个阶段；
2. 它在哪个阶段最早失去证据；
3. 以上两项能否由当前题目的原句、最小例子、预算或候选比较复核。

如果路径在某一阶段失去证据，后续内容只作为该路径的失败证据，不再计为完整推导。

## 五、五类分析视角

这五类不是并列模板。人工过程是共同底座，其余四类由第二次变化选择。

### 1. 人工过程法

要产出：

- 一个最小但完整的例子；
- 普通人按时间能执行的动作；
- 每一步前后的变化；
- 答案在何时确定；
- 最直接做法在哪里重复。

它回答“人怎样做这道题”，不提前回答“应该用什么结构”。

### 2. 状态生命周期法

适合对象产生后不会立即结束，需要等待、结算、过期或持续查询的场景。

要产出：

```text
对象何时进入：
谁持有它：
什么事件让它继续等待：
什么事件让它结算或失效：
结算时是否需要原始顺序：
未来读取值、位置、次数还是有效期：
```

### 3. 候选淘汰与不变量法

适合候选集合太多，但一个局部事实能同时排除一批候选的场景。

要产出：

```text
当前候选集合：
当前代表候选：
支配关系：
被一起排除的候选范围：
为什么不会漏掉更优解：
淘汰后集合怎样缩小：
```

只有指针移动，没有“为什么整批候选安全失效”，不算完成。

### 4. 递归职责法

适合问题由相同形状的更小问题组成，或需要显式枚举选择与恢复现场的场景。

要产出：

```text
函数输入代表哪个子问题：
函数承诺返回什么：
当前层怎样使用子结果：
发出多个分支时共享什么：
返回时恢复什么：
```

### 5. 子问题复用法

适合同一个子问题从多条路径重复到达，且答案与到达路径无关的场景。

要产出：

```text
什么信息唯一确定一个子问题：
不同路径为什么得到同一个子问题：
子问题的值是否足以构造更大的问题：
依赖顺序：
答案保存位置：
```

## 六、单条路径的记录格式

每条路径都保留同一组字段，便于事后比较：

```text
路径名称：
首次出现于哪一阶段：
当时支持它的证据：
它想消除的重复劳动或不确定性：
它需要的操作：
它依赖的题目条件：
它在哪一步失效或缺少证据：
事实核对：通过 / 失败
七阶段、九次交接自然可达：通过 / 失败
因果闭包：通过 / 失败
代码映射与反例：通过 / 失败
六维分数：易吸收 / 便于回忆 / 体系关联 / 大脑串联 / 编码定位 / 迁移价值
最终状态：主方向 / 查漏方向 / 淘汰 / 待验证
```

如果当前没有形成候选，直接写 `没有形成候选`。如果没有真实发生转折，写 `没有发生转折`。不要为了看起来像人的思考，补造错误和犹豫。

## 七、对照公平性

比较不同分析法时，先固定以下条件：

1. **同一题面事实。** 不允一条路径使用约束，另一条路径忽略约束。
2. **同一最小例子。** 先让两条路径都走过同一个能暴露关键变化的例子。
3. **同一代码入口。** 允许一篇路径只到方向确认，但进入实现比较时必须使用同一方法签名。
4. **同一判分门槛。** 不能因为熟悉某个方法，就对它跳过事实和因果检查。
5. **同一失败记录。** 错误候选保留在它真正失败的阶段，不把整条路径改写成“后来自然就想到了”。
6. **同一闭卷条件。** 比较回忆质量时，不看原文、题解和代码提示。

如果实验者已经知道答案，必须承认记忆会影响“首次到达”的评估。这时评分重点是解释是否仍然可由题面证据复核，而不是声称自己当时真的不知道。

## 八、什么时候可以停止实验

满足下面四条即可停止当前题目的实验：

1. 事实核对通过，没有缺条件或补条件。
2. 有一条路径从读题到方向确认连续可复核。
3. 至少一个真实替代方向被比较；没有真实替代时，用熟悉方向检查适用边界，并如实说明。
4. 主方向能映射到状态、更新顺序、不变量、代码位置和至少一个反例。

如果同一条路径连续两次尝试仍停留在同一个缺失证据，停止扩写整条题解，只记录：

```text
最早断点：
已有证据：
仍缺的证据：
下一次只做的纸面动作：
什么结果会允许继续：
```

这不是失败统计，也不会产生补课债务。下一次从该断点继续。

## 九、实验输出

一轮实验至少留下：

- 官方事实核对；
- 一条完整主路径；
- 真实出现过的替代或错误路径；
- 每条路径的准入门槛和六维评分；
- 最终主方向与适用边界；
- 一个可执行的复习提取方式；
- 指向标准题解、核心模型或代码的稳定链接。

如果只留下最终方法名和代码，本轮实验没有完成。
