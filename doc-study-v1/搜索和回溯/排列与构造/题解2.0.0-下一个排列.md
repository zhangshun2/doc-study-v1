# 题解2.0.0 下一个排列（LeetCode-31）

## 题解一：官方经典（枢轴 + 最小更大 + 反转后缀）
- 思路：
  1) 从右向左找第一个 `nums[i] < nums[i+1]` 的位置 `i`；
  2) 再从右向左找第一个 `nums[j] > nums[i]` 的位置 `j` 进行交换；
  3) 将 `i+1..n-1` 的后缀整体反转为升序。
- 复杂度：时间 O(n)，空间 O(1)。

```java
import java.util.*;
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) j--;
            swap(nums, i, j);
        }
        reverse(nums, i + 1, n - 1);
    }
    private void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }
    private void reverse(int[] a, int l, int r) { while (l < r) swap(a, l++, r--); }
}
```

## 题解二：通用解法（右侧降序扫描定位“最小更大”）
- 标签：构造、双指针、后缀、字典序
- 思路：右侧降序保证从右向左第一个 `> pivot` 的元素就是最小更大；无需二分，线性即可。

```java
import java.util.*;
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length, i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i < 0) { reverse(nums, 0, n - 1); return; }
        for (int j = n - 1; j > i; j--) {
            if (nums[j] > nums[i]) { swap(nums, i, j); break; }
        }
        reverse(nums, i + 1, n - 1);
    }
    private void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }
    private void reverse(int[] a, int l, int r) { while (l < r) swap(a, l++, r--); }
}
```

## 题解三：最好理解（“先找能增的位，再把后面最小化”）
- 直觉：想要“稍微变大”，就从末尾找第一个能变大的位置，换成刚好更大的数，再把后面变成最小的升序。

## 总结思路
- 三步构造保证是下一个而非更大的某个排列；重复值时“最小更大”依然成立。
