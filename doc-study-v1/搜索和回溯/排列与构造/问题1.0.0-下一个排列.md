# 问题1.0.0 下一个排列（LeetCode-31）

- 难度：中等
- 链接：https://leetcode.cn/problems/next-permutation/

## 概述
将整数数组就地重排为字典序上的下一个更大排列；若不存在更大排列（当前为最大降序），则返回最小排列（整体升序）。

## 问题特征与分析引导
- 局部结构：右侧最长降序后缀；枢轴位 `i` 满足 `nums[i] < nums[i+1]` 且尽可能靠右。
- 枢轴交换：在后缀中找最小的且大于 `nums[i]` 的元素，与之交换，保证增量最小。
- 后缀修复：交换后将后缀从降序改为升序（整体反转），得到下一个排列。
- 边界：若不存在枢轴（完全降序），直接整体反转得到最小排列。

## 可能涉及的知识点
- 右侧降序后缀、枢轴与最小更大元素
- 原地交换与后缀反转（双指针）
- 边界与特例处理（全降序 / 全升序 / 重复值）
