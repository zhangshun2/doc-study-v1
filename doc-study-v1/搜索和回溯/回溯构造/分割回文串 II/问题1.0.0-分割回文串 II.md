# 问题1.0.0 分割回文串 II（LeetCode-132）

- 难度：困难
- 链接：https://leetcode.cn/problems/palindrome-partitioning-ii/

## 概述
给定字符串 `s`，将其分割为若干子串，使每个子串都是回文串，并使分割次数（切割数）最少。返回最少切割数。

## 问题特征与分析引导
- 判定与优化：需要高效判定子串回文；可预处理回文表或中心扩展。
- 动态规划：以最少切割为目标，`dp[i]` 表示前缀最少切割数。

## 可能涉及的知识点
- 回文判定（DP 或中心扩展）
- 最少切割 DP 设计与转移
- 边界处理（整段回文时切割数为 0）
