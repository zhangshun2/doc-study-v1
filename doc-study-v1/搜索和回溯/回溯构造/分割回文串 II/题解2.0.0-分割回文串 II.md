# 题解2.0.0 分割回文串 II（LeetCode-132）

## 题解一：官方经典（预处理回文 + 最少切割 DP）
- 思路：预处理 `pal[i][j]` 是否回文；`dp[i]` 表示 `s[0..i]` 的最少切割数，若 `s[0..i]` 整段回文则 `dp[i]=0`，否则枚举分割点 `j`，转移 `dp[i]=min(dp[i], dp[j-1]+1)`（`s[j..i]` 必须回文）。
- 复杂度：时间 O(n^2)，空间 O(n^2)。

```java
import java.util.*;
class Solution {
    public int minCut(String s) {
        int n = s.length();
        boolean[][] pal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                pal[i][j] = (s.charAt(i) == s.charAt(j)) && (j - i < 2 || pal[i + 1][j - 1]);
            }
        }
        int[] dp = new int[n];
        for (int i = 0; i < n; i++) {
            if (pal[0][i]) { dp[i] = 0; continue; }
            dp[i] = i; // 最差把每个字符切开
            for (int j = 1; j <= i; j++) {
                if (pal[j][i]) dp[i] = Math.min(dp[i], dp[j - 1] + 1);
            }
        }
        return dp[n - 1];
    }
}
```

## 题解二：通用解法（中心扩展 + DP）
- 标签：中心扩展、DP
- 思路：用中心扩展在线更新回文区间，再进行最少切割 DP，空间更省。

## 题解三：最好理解（“先知道哪些段是回文，再把切割尽量少”）
- 直觉：先把所有回文子段找出来，再用 DP 选择最少切割。

## 总结思路
- 预处理 + DP 是标准解；中心扩展可降空间常数。
