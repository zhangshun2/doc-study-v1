## 🎯 算法概述

BFS（广度优先搜索）层序搜索是解决"删除无效的括号"问题的最优方法。核心思想是通过逐层删除字符，天然保证找到的第一个有效解就是删除字符数最少的解。

### 算法特点：
- **最少删除保证**：BFS按层搜索，第一层找到的有效解就是最优解
- **去重优化**：使用HashSet避免重复处理相同字符串
- **智能剪枝**：只删除括号字符，保留所有字母
- **早停机制**：找到有效层后立即停止更深层搜索

## 💻 完整Java实现

```java
import java.util.*;

public class RemoveInvalidParenthesesBFS {
    
    /**
     * BFS方法删除无效括号
     * @param s 输入字符串
     * @return 所有删除最少括号后的有效字符串集合
     */
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        if (s == null) return result;
        
        // 如果原始字符串已经有效，直接返回
        if (isValid(s)) {
            result.add(s);
            return result;
        }
        
        Queue<String> queue = new LinkedList<>();
        Set<String> visited = new HashSet<>();
        boolean found = false;
        
        // 初始化：将原始字符串加入队列
        queue.offer(s);
        visited.add(s);
        
        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            
            // 处理当前层的所有字符串
            for (int i = 0; i < levelSize; i++) {
                String current = queue.poll();
                
                // 检查当前字符串是否有效
                if (isValid(current)) {
                    result.add(current);
                    found = true; // 标记已找到有效层
                }
                
                // 如果已经找到有效字符串，不再生成下一层
                if (found) continue;
                
                // 生成下一层：删除一个字符
                for (int j = 0; j < current.length(); j++) {
                    char c = current.charAt(j);
                    
                    // 只删除括号字符，保留字母
                    if (c != '(' && c != ')') {
                        continue;
                    }
                    
                    // 删除第j个字符
                    String next = current.substring(0, j) + current.substring(j + 1);
                    
                    // 避免重复处理
                    if (!visited.contains(next)) {
                        visited.add(next);
                        queue.offer(next);
                    }
                }
            }
            
            // 如果当前层找到有效字符串，停止搜索
            if (found) break;
        }
        
        return result;
    }
    
    /**
     * 检查字符串括号是否有效
     * @param s 输入字符串
     * @return 是否有效
     */
    private boolean isValid(String s) {
        int balance = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                balance++;
            } else if (c == ')') {
                balance--;
                // 任何时候右括号多于左括号都无效
                if (balance < 0) return false;
            }
        }
        // 最终左右括号数量相等才有效
        return balance == 0;
    }
    
    /**
     * 测试方法
     */
    public static void main(String[] args) {
        RemoveInvalidParenthesesBFS solution = new RemoveInvalidParenthesesBFS();
        
        // 测试用例
        String[] testCases = {
            "()())",
            "(a)())",
            ")(",
            "abc",
            "(((",
            ")))",
            "()())()"
        };
        
        for (String testCase : testCases) {
            List<String> result = solution.removeInvalidParentheses(testCase);
            System.out.println("输入: \"" + testCase + "\"");
            System.out.println("输出: " + result);
            System.out.println("---");
        }
    }
}
```

## 🔍 算法详细解析

### 1. 核心数据结构
```java
Queue<String> queue = new LinkedList<>();  // BFS队列，按层存储待处理字符串
Set<String> visited = new HashSet<>();     // 访问集合，避免重复处理
boolean found = false;                      // 有效层标志
```

### 2. 算法流程
1. **初始化检查**：如果原始字符串有效，直接返回
2. **BFS层序遍历**：
   - 第0层：原始字符串
   - 第1层：删除1个括号的所有可能
   - 第2层：删除2个括号的所有可能
   - ...
3. **有效性检查**：对每个字符串使用 `isValid()` 方法
4. **早停机制**：找到第一个有效层后立即停止

### 3. 关键方法 `isValid()`
```java
private boolean isValid(String s) {
    int balance = 0;
    for (char c : s.toCharArray()) {
        if (c == '(') balance++;
        else if (c == ')') {
            balance--;
            if (balance < 0) return false; // 右括号过多
        }
    }
    return balance == 0; // 最终平衡
}
```

### 4. 优化策略
- **智能删除**：只删除括号字符 `(` 和 `)`，保留所有字母
- **去重优化**：使用HashSet避免重复处理相同字符串
- **层序早停**：找到有效层后立即停止更深层搜索

## ⏱️ 复杂度分析

### 时间复杂度
- **最坏情况**：O(2^n)，需要枚举所有可能的删除组合
- **平均情况**：由于早停机制，通常远好于最坏情况
- **有效性检查**：O(n) 每次检查

### 空间复杂度
- **队列空间**：O(2^n)，存储所有可能的中间状态
- **访问集合**：O(2^n)，存储已访问的字符串
- **总体**：O(2^n)

private int[] calculateRemoveCount(String s) {
    int leftRemove = 0, rightRemove = 0;
    for (char c : s.toCharArray()) {
        if (c == '(') {
            leftRemove++;
        } else if (c == ')') {
            if (leftRemove > 0) {
