## 问题概述
给定一个包含括号和字母的字符串 `s`，需要删除尽可能少的括号，使得结果字符串“括号有效”。要求返回所有可能的结果（不重复）。

注：此处“删除无效的括号”问题对应 LeetCode 301（Remove Invalid Parentheses）。若你仅需返回一个删除最少括号后的有效字符串（LeetCode 1249），可参考“单次线性扫描+栈/计数”的变体题解。

## 题目特征与约束
- 字符集：包含 `'('`, `')'` 与其他字母（其他字符视为普通字符，原样保留）。
- 有效括号定义：
  - 从左到右扫描过程中，任意前缀中 `')'` 的数量不应超过 `'('` 的数量；
  - 全部扫描结束后，`'('` 与 `')'` 总数相等。
- 输出：所有删除最少数量括号后得到的“有效字符串”（去重）。
- 规模：字符串长度 `n`，最坏情况下搜索空间呈指数级，需要强力剪枝与层次控制。

## 思路引导
1) 判断有效性：可用线性扫描维护计数 `balance`，遇 `'('` 加一，遇 `')'` 减一，任何时刻 `balance < 0` 则无效；结束时 `balance == 0` 则有效。
2) 最少删除原则：
   - BFS 层序搜索：每一层只删除一个字符。第一次在某层发现有效字符串时，该层即是“最少删除”层，停止更深层枚举并返回当前层所有有效结果。
   - DFS 剪枝：先计算多余左括号 `remL` 和多余右括号 `remR` 的最小删除数量，随后用回溯在保证 `balance >= 0` 的前提下仅删除必要数量并避免重复。
3) 去重与剪枝：
   - BFS 使用 `visited` 集合避免对同一字符串重复入队。
   - DFS 在相邻相同括号时仅删除第一个，跳过重复删除；对非括号字符直接保留。

## 涉及的知识点拆解
- 括号有效性判断（计数法 / 栈法）
- BFS 层序搜索与“第一次命中即最少删除”的性质
- DFS 回溯与状态剪枝（`balance`、`remL`、`remR`、去重）
- 去重技巧：跳过相邻重复括号的重复删除

## 常见误区与边界条件
- 误区：以栈匹配直接一次性输出一个结果，这对应 1249 题的变体；301 题要求“返回所有最少删除的有效结果”。
- 误区：BFS 找到第一个有效结果后立刻返回单个字符串；正确做法是收集本层所有有效结果，然后停止。
- 边界：
  - 空串 `""` 是有效括号字符串，输出 `[""]`。
  - 全是字母：不需要删除，直接返回原串。
  - 出现大量重复括号：注意 DFS 的跳重去重规则。

## 复杂度直觉
- BFS：最坏情况下遍历到最少删除层前的所有候选，时间复杂度近似指数级；但由于早停（命中有效层即停），实践中表现较好。
- DFS：状态树也呈指数级，剪枝后显著减少搜索；空间复杂度由递归深度与路径存储决定，通常为 `O(n)` 级别。

## 练习建议
- 先做：LeetCode 1249（单个最优结果，线性扫描）
- 再做：LeetCode 301（本题，返回所有最少删除结果）
- 对比练习：Longest Valid Parentheses（最长有效括号，栈/DP）以加深“有效性”直觉。
