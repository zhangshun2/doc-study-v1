题解概述
- 使用 BFS 按“删除次数”为层进行搜索：当某一层出现有效字符串时，即得到“最少删除”的所有解，停止下层搜索。
- 依赖有效判定与去重：使用`isValid`衡量有效性，使用`Set`避免重复状态。

步骤/模板（Java）
```java
import java.util.*;

class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> ans = new ArrayList<>();
        if (s == null) return ans;
        Set<String> visited = new HashSet<>();
        Queue<String> q = new LinkedList<>();
        q.offer(s);
        visited.add(s);
        boolean found = false;

        while (!q.isEmpty()) {
            int size = q.size();
            for (int i = 0; i < size; i++) {
                String cur = q.poll();
                if (isValid(cur)) {
                    ans.add(cur);
                    found = true; // 命中本层有效 → 最少删除层
                }
                if (found) continue; // 本层已有有效结果→不再生成下一层
                for (int j = 0; j < cur.length(); j++) {
                    char c = cur.charAt(j);
                    if (c != '(' && c != ')') continue; // 只删除括号
                    // 跳过相邻重复括号的同位置删除（去重）
                    if (j > 0 && cur.charAt(j) == cur.charAt(j - 1)) continue;
                    String next = cur.substring(0, j) + cur.substring(j + 1);
                    if (visited.add(next)) q.offer(next);
                }
            }
            if (found) break; // 停止更深层搜索，保证最少删除
        }
        return ans;
    }

    private boolean isValid(String s) {
        int bal = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') bal++;
            else if (c == ')') {
                if (bal == 0) return false; // 前缀右括号过多
                bal--;
            }
        }
        return bal == 0; // 最终左右括号相等
    }
}
```

正确性要点
- 层不变式：BFS 的第 k 层对应删除 k 个括号；首次出现有效解的层即为“最少删除”。
- 去重与剪枝：避免同层重复状态，减少队列膨胀；命中有效层后不再生成下一层。

时间与空间复杂度分析
- 最坏情况下状态数呈指数级；但层级停止与去重能显著缓解。
- 每次有效性检测`O(n)`；总复杂度与生成状态数乘以`O(n)`相关。

易错点 Checklist
- 忽略去重导致重复状态爆炸。
- 命中有效层后继续扩展下一层，破坏“最少删除”。
- 对字母做删除（错误），只应对括号进行删除。
- 有效性检测忘记前缀不为负与最终平衡条件。
