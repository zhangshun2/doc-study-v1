题解概述
- 先线性扫描计算需要删除的左括号与右括号数量`removeL/removeR`，再用回溯控制删除配额与`balance`（当前有效性），生成所有最少删除的有效结果。
- 通过跳过相邻相同括号的重复删除与余额剪枝，显著减少搜索空间。

步骤/模板（Java）
```java
import java.util.*;

class Solution {
    public List<String> removeInvalidParentheses(String s) {
        int removeL = 0, removeR = 0;
        // 预处理：计算需要删除的左右括号数
        for (char c : s.toCharArray()) {
            if (c == '(') {
                removeL++;
            } else if (c == ')') {
                if (removeL > 0) removeL--; else removeR++;
            }
        }
        Set<String> res = new HashSet<>();
        dfs(s, 0, new StringBuilder(), 0, removeL, removeR, res);
        return new ArrayList<>(res);
    }

    private void dfs(String s, int idx, StringBuilder path, int balance,
                     int removeL, int removeR, Set<String> res) {
        // 剪枝：余额为负，不可能有效
        if (balance < 0) return;
        // 终止条件
        if (idx == s.length()) {
            if (balance == 0 && removeL == 0 && removeR == 0) {
                res.add(path.toString());
            }
            return;
        }
        char c = s.charAt(idx);
        int len = path.length();

        if (c != '(' && c != ')') {
            // 保留字母
            path.append(c);
            dfs(s, idx + 1, path, balance, removeL, removeR, res);
            path.setLength(len);
            return;
        }

        // 删除分支（若还有删除配额）
        if (c == '(' && removeL > 0) {
            // 跳过连续相同括号的重复删除（只删除第一个）
            dfs(s, idx + 1, path, balance, removeL - 1, removeR, res);
        } else if (c == ')' && removeR > 0) {
            dfs(s, idx + 1, path, balance, removeL, removeR - 1, res);
        }

        // 保留分支
        path.append(c);
        if (c == '(') {
            dfs(s, idx + 1, path, balance + 1, removeL, removeR, res);
        } else { // ')'
            dfs(s, idx + 1, path, balance - 1, removeL, removeR, res);
        }
        path.setLength(len);
    }
}
```

正确性要点
- 预处理得到最少删除配额`removeL/removeR`，回溯过程中严格消耗配额，保证最少删除。
- `balance`维护有效性：任意前缀不为负，结尾必须为零。
- 去重策略：使用`Set`收集结果；同时在删除分支中对连续相同括号仅删除第一个，降低重复。

时间与空间复杂度分析
- 最坏情况下指数级；但配额与余额剪枝显著降低搜索规模，通常表现优于朴素枚举。
- 路径构造使用`StringBuilder`减少中间对象开销。

易错点 Checklist
- 忘记计算并使用`removeL/removeR`，会生成非最优删除的结果。
- 遗漏余额剪枝`balance<0`直接返回，导致无效状态扩散。
- 未跳过连续相同括号的重复删除，结果集重复严重。
- 对字母进行删除（错误），应仅考虑括号的删除与保留。
