## 题解概述（算法选择理由与适配场景）
通过一次线性扫描计算需要最少删除的多余左括号 `remL` 与多余右括号 `remR`，随后用回溯搜索所有满足 `remL==0 && remR==0 && balance==0` 的结果。过程中保持 `balance >= 0`，并对相邻重复括号进行跳重去重，从而显著缩减搜索空间。

## 预处理计算 `remL` 与 `remR`
```
function preprocess(s):
    remL = 0; remR = 0
    for ch in s:
        if ch == '(':
            remL += 1
        else if ch == ')':
            if remL > 0:
                remL -= 1   // 用一个 '(' 来匹配当前 ')'
            else:
                remR += 1   // 多余的 ')'
    return remL, remR
```

## 回溯模板（伪代码）
```
function removeInvalidParentheses(s):
    remL, remR = preprocess(s)
    results = set()
    dfs(index=0, path="", balance=0, remL, remR)
    return list(results)

function dfs(index, path, balance, remL, remR):
    if index == len(s):
        if remL == 0 and remR == 0 and balance == 0:
            results.add(path)
        return

    ch = s[index]
    if ch is letter:
        dfs(index+1, path+ch, balance, remL, remR)
        return

    // ch 是括号的情况
    if ch == '(':
        // 1) 删除当前 '('（仅在 remL>0 时允许）
        if remL > 0:
            // 跳过相邻重复：若有相同连续 '('，只删除第一个
            if not (index>0 and s[index-1]=='(' and last step deleted previous '('):
                dfs(index+1, path, balance, remL-1, remR)
        // 2) 保留当前 '('（增加平衡）
        dfs(index+1, path+'(', balance+1, remL, remR)
    else: // ch == ')'
        // 1) 删除当前 ')'（仅在 remR>0 时允许）
        if remR > 0:
            if not (index>0 and s[index-1]==')' and last step deleted previous ')'):
                dfs(index+1, path, balance, remL, remR-1)
        // 2) 保留当前 ')'（仅在 balance>0 时允许，匹配一个 '('）
        if balance > 0:
            dfs(index+1, path+')', balance-1, remL, remR)
```

实现要点：
- `balance` 表示当前路径中未被匹配的 `'('` 数量，保持 `balance >= 0`。
- 去重：
  - 使用集合 `results` 去重最终结果；
  - 对相邻重复括号，删除时仅删除第一个（可通过在递归参数中携带“上一步是否删除且同类括号”的状态或在循环层面跳重）。
- 非括号字符直接加入 `path`，不影响括号匹配状态。

## 正确性要点
- 预处理确保 `remL+remR` 为最少删除的括号数；回溯仅在此额度内删除，保证“最少删除”。
- `balance` 与约束：任何时刻 `balance < 0` 都不可能形成有效路径，提前剪枝。
- 跳重避免重复删除同一位置或同类相邻括号，保证结果唯一性且减少分支。

## 时间与空间复杂度
- 时间：搜索树为指数级；预处理与剪枝后，实际运行速度大幅提升，常见数据在可接受范围内。
- 空间：递归深度 `O(n)`，路径与结果集按输出规模计。

## 易错点 Checklist
- [ ] 预处理 `remL/remR` 的计算逻辑是否正确（右括号多余计数）。
- [ ] 保留 `')'` 必须在 `balance>0` 时进行，否则无效。
- [ ] 相邻重复括号删除时要跳重，否则产生重复结果。
- [ ] 终止条件必须同时满足 `remL==0 && remR==0 && balance==0`。

## 测试用例设计
常规：
- `"(a)())()"` → `["(a)()()", "(a())()"]`
- `"()())()"` → `["()()()", "(())()"]`

边界：
- 空串 `""` → `[""]`
- 全字母 `"abc"` → `["abc"]`
- 只有右括号 `")))"` → `[""]`
- 只有左括号 `"((("` → `[""]`
- 交错无效 `")("` → `[""]`
