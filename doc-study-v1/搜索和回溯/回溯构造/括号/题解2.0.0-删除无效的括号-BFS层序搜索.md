## 题解概述（算法选择理由与适配场景）
使用 BFS 层序搜索，每一层仅删除一个字符。首次在某层发现有效字符串时，该层即对应“最少删除次数”，收集该层所有有效结果并停止更深层搜索。此方法天然满足“最少删除”约束，且避免深度搜索带来的过度枚举。

## 步骤/模板（伪代码）
```
function removeInvalidParentheses(s):
    if isValid(s): return [s]
    queue = [s]
    visited = {s}
    results = []
    found = false
    while queue not empty:
        levelCount = size(queue)
        for i in 1..levelCount:
            cur = pop(queue)
            if isValid(cur):
                results.append(cur)
                found = true
            if found: continue  // 已命中有效层，不再生成下一层
            for each index j in [0..len(cur)-1]:
                if cur[j] is not '(' or ')': continue
                next = cur[0:j] + cur[j+1:]
                if next not in visited:
                    visited.add(next)
                    queue.push(next)
        if found: break
    return unique(results)

function isValid(str):
    balance = 0
    for ch in str:
        if ch == '(':
            balance += 1
        else if ch == ')':
            balance -= 1
            if balance < 0: return false
    return balance == 0
```

关键点：
- 仅对括号字符进行删除尝试；其他字符原样保留。
- 使用 `visited` 去重，避免同一字符串多次入队。
- 发现有效字符串后，仍需完成本层遍历以收集所有有效结果；随后停止。

## 正确性要点（不变式/证明思路）
- 层序不变式：第 `k` 层表示从原串删除了 `k` 个字符的所有可能字符串。
- 最少删除性质：首次出现有效字符串的层数 `k` 为使字符串有效所需的最少删除数；更深层 `>k` 的结果不再满足“最少删除”，因此停止即可。
- 有效性检测：`isValid` 的前缀约束（`balance` 不为负）与结束约束（`balance` 为 0）构成充分必要条件。

## 时间与空间复杂度分析
- 时间：最坏情况下近似枚举所有删除位置组合，呈指数级；但由于层序早停，实际表现通常较好。
- 空间：`visited` 与队列占用在同一数量级，最坏为候选规模的指数级；通常输入规模限制在几十到一百字符内可接受。

## 易错点 Checklist
- [ ] 命中有效结果后仍需收集本层全部有效字符串，再停止。
- [ ] 删除时仅尝试括号字符，避免无谓分支。
- [ ] 使用 `visited` 集合避免重复入队。
- [ ] `isValid` 中一旦 `balance < 0` 立即返回 `false`。

## 测试用例设计
常规：
- `"(a)())()"` → `["(a)()()", "(a())()"]`
- `"()())()"` → `["()()()", "(())()"]`

边界：
- 空串 `""` → `[""]`
- 全字母 `"abc"` → `["abc"]`
- 只有右括号 `")))"` → `[""]`
- 只有左括号 `"((("` → `[""]`
- 交错无效 `")("` → `[""]`
