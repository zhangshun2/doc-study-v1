题解2.0.0 - 删除无效的括号（Remove Invalid Parentheses, LeetCode 301）

概述：用 BFS 按层删除一个括号，首次出现的有效字符串层即最小删除层，返回该层所有解。也可用回溯计数左右多余括号进行剪枝。

题解一：BFS 最少删除枚举（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> res = new ArrayList<>();
        if (s == null) return res;
        Queue<String> q = new ArrayDeque<>();
        Set<String> vis = new HashSet<>();
        q.offer(s); vis.add(s);
        boolean found = false;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                String cur = q.poll();
                if (isValid(cur)) {
                    res.add(cur);
                    found = true;
                }
                if (found) continue; // 本层已找到有效串，不再生成下一层
                for (int i = 0; i < cur.length(); i++) {
                    char c = cur.charAt(i);
                    if (c != '(' && c != ')') continue;
                    String nxt = cur.substring(0, i) + cur.substring(i + 1);
                    if (vis.add(nxt)) q.offer(nxt);
                }
            }
            if (found) break; // 只返回最小删除层的所有解
        }
        return res;
    }

    private boolean isValid(String s) {
        int bal = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') bal++;
            else if (c == ')') {
                bal--;
                if (bal < 0) return false;
            }
        }
        return bal == 0;
    }
}
```

题解二：回溯剪枝（计算多余左右括号数）

思路：
- 预先统计需删除的左、右括号个数；回溯过程中按计数删除并剪枝，构造所有解。

复杂度：
- 最坏情况下指数级；BFS 保证最小删除层，去重减枝效果好。

思考小结：
- “最少删除且所有解”是 BFS 的天然适配场景。

标签：BFS、回溯、字符串
