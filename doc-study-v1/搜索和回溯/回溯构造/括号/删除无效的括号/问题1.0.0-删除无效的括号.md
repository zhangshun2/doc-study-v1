问题1.0.0 - 删除无效的括号（Remove Invalid Parentheses, LeetCode 301）

概述：删除尽可能少的括号，使字符串成为有效括号字符串，并返回所有可能结果。可用 BFS 层序删除以保证最小删除次数，也可回溯剪枝。

链接：https://leetcode.com/problems/remove-invalid-parentheses/

题目特征与分析：
- 最小改动的所有解：适合 BFS 层级遍历，首层找到解后停止更深层。
- 有效性检查：线性扫描计数。

知识点：
- BFS 状态搜索、字符串有效性判断、去重与剪枝。

输入输出：
- 输入：包含括号与其他字符的字符串。
- 输出：所有最少删除后得到的有效字符串列表。

标签：BFS、回溯构造、字符串、搜索与回溯
