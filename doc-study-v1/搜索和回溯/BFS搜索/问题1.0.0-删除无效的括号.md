# 问题1.0.0-删除无效的括号：层次遍历找最少删除次数

## 📋 题目信息

**LeetCode 301. 删除无效的括号**  
**难度：** 困难  
**链接：** [🔗](https://leetcode.cn/problems/remove-invalid-parentheses/)

## 🎯 问题描述

给你一个由若干括号和字母组成的字符串 `s` ，删除最小数量的无效括号，使得输入的字符串有效。

返回所有可能的结果。答案可以按 **任意顺序** 返回。

**有效括号的定义：**
1. 空字符串或只包含小写字母的字符串总是有效的
2. 如果字符串 `A` 有效，那么字符串 `(A)` 也有效
3. 如果字符串 `A` 和 `B` 都有效，那么字符串 `AB` 也有效

## 📝 示例分析

### 示例 1
```
输入：s = "()())"
输出：["()()", "(())"]

分析：
- 原字符串有3个'('和3个')'，但最后一个')'多余
- 删除最后一个')'：()() ✓
- 删除中间一个')'：(()) ✓
- 最少删除1个字符
```

### 示例 2
```
输入：s = "((("
输出：[""]

分析：
- 只有左括号，没有右括号匹配
- 必须删除所有3个'('
- 结果是空字符串
```

### 示例 3
```
输入：s = "())"
输出：["()"]

分析：
- 有2个'('和3个')'，多了1个')'
- 删除多余的')'得到()
```

## 🔍 问题特征分析

### 核心特征
1. **最优化问题**：寻找删除最少字符的方案
2. **多解问题**：可能存在多个最优解
3. **层次搜索**：BFS天然保证找到的第一层解是最优的
4. **状态去重**：避免重复处理相同的字符串

### 搜索特点
- **广度优先搜索（BFS）**：逐层搜索，第一次找到有效字符串的层就是最优解
- **状态空间**：每个状态是一个可能的字符串
- **状态转移**：从当前字符串删除一个括号得到新状态
- **剪枝优化**：只删除括号，不删除字母

### 约束条件
- `1 <= s.length <= 25`
- `s` 由小写英文字母以及括号 `'('` 和 `')'` 组成
- `s` 中至多含 `20` 个括号

## 🧠 解题思路引导

### BFS思路分析
1. **初始状态**：原始字符串作为起点
2. **层次遍历**：每一层代表删除相同数量字符的所有可能
3. **状态生成**：从当前字符串删除一个括号生成新状态
4. **有效性检查**：检查字符串是否为有效括号序列
5. **最优性保证**：第一次找到有效字符串的层就是最优解

### 关键问题
1. **如何判断括号序列有效？** 计数法：左括号+1，右括号-1，过程中不能为负，最终为0
2. **如何避免重复状态？** 使用Set记录已访问的字符串
3. **如何生成下一层状态？** 遍历字符串，删除每个括号位置
4. **何时停止搜索？** 找到第一个有效字符串的层

## 🎨 算法设计要点

### BFS搜索框架
```java
public List<String> removeInvalidParentheses(String s) {
    List<String> result = new ArrayList<>();
    Queue<String> queue = new LinkedList<>();
    Set<String> visited = new HashSet<>();
    
    queue.offer(s);
    visited.add(s);
    boolean found = false;
    
    while (!queue.isEmpty() && !found) {
        int size = queue.size();
        
        // 处理当前层的所有状态
        for (int i = 0; i < size; i++) {
            String current = queue.poll();
            
            if (isValid(current)) {
                result.add(current);
                found = true;  // 找到最优解层
            }
        }
        
        // 如果当前层没找到解，生成下一层
        if (!found) {
            for (int i = 0; i < size; i++) {
                String current = queue.poll();
                generateNextLevel(current, queue, visited);
            }
        }
    }
    
    return result;
}
```

### 有效性检查
```java
private boolean isValid(String s) {
    int count = 0;
    for (char c : s.toCharArray()) {
        if (c == '(') {
            count++;
        } else if (c == ')') {
            count--;
            if (count < 0) return false;  // 右括号过多
        }
    }
    return count == 0;  // 左右括号平衡
}
```

### 状态生成优化
```java
private void generateNextLevel(String s, Queue<String> queue, Set<String> visited) {
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (c == '(' || c == ')') {  // 只删除括号
            String next = s.substring(0, i) + s.substring(i + 1);
            if (!visited.contains(next)) {
                visited.add(next);
                queue.offer(next);
            }
        }
    }
}
```
