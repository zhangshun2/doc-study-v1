## 题解概述

## 逐行解释（原始方法逻辑）

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        Queue<String> queue = new LinkedList<>();
        Set<String> visited = new HashSet<>();
        
        queue.offer(s);
        visited.add(s);
        boolean found = false;
        
        while (!queue.isEmpty() && !found) {
            int size = queue.size();
            
            // 处理当前层的所有状态
            for (int i = 0; i < size; i++) {
                String current = queue.poll();
                
                if (isValid(current)) {
                    result.add(current);
                    found = true;  // 标记找到最优解层
                }
            }
            
            // 如果当前层没找到解，生成下一层状态
            if (!found) {
                // 重新获取当前层的所有元素来生成下一层
                Set<String> currentLevel = new HashSet<>();
                for (int i = 0; i < size; i++) {
                    String current = queue.poll();
                    currentLevel.add(current);
                }
                
                for (String current : currentLevel) {
                    generateNextLevel(current, queue, visited);
                }
            }
        }
        
        return result;
    }
    
    // 判断括号字符串是否有效
    private boolean isValid(String s) {
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                count++;
            } else if (c == ')') {
                count--;
                if (count < 0) return false;  // 右括号过多
            }
            // 字母字符忽略
        }
        return count == 0;  // 左右括号必须平衡
    }
    
    // 生成下一层状态：删除一个括号
    private void generateNextLevel(String s, Queue<String> queue, Set<String> visited) {
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(' || c == ')') {  // 只删除括号
                String next = s.substring(0, i) + s.substring(i + 1);
                if (!visited.contains(next)) {
                    visited.add(next);
                    queue.offer(next);
                }
            }
        }
    }
}
```

### 解释与提醒
- 队列 `queue` 与集合 `visited` 分别用于层次推进与去重。
- 变量 `found` 用来在“首层命中合法串”后停止下层生成，保证最少删除。
- “当前层处理”循环中将本层元素都 `poll` 出队。
- 随后“重新获取当前层元素”的逻辑存在陷阱：上一轮已 `poll`，队列可能为空，导致无法派生下一层。

## 正确模板（建议替换方法一实现）
采用“单次循环兼顾派生”的写法，确保严格按层推进且无状态丢失：

```java
import java.util.*;
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        Queue<String> queue = new LinkedList<>();
        Set<String> visited = new HashSet<>();
        queue.offer(s);
        visited.add(s);
        boolean found = false;
        
        while (!queue.isEmpty() && !found) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                String cur = queue.poll();
                if (isValid(cur)) {
                    result.add(cur);
                    found = true;
                }
                if (!found) { // 仅在本层未找到解时派生下一层
                    for (int k = 0; k < cur.length(); k++) {
                        char c = cur.charAt(k);
                        if (c != '(' && c != ')') continue; // 只删括号
                        String nxt = cur.substring(0, k) + cur.substring(k + 1);
                        if (visited.add(nxt)) queue.offer(nxt);
                    }
                }
            }
        }
        return result;
    }
    private boolean isValid(String s) {
        int bal = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') bal++;
            else if (c == ')') { bal--; if (bal < 0) return false; }
        }
        return bal == 0;
    }
}
```

### 关键点
- 固定 `size` 后，仅处理当前层元素；下一层派生入队，但不会在本轮被处理。
- 一旦本层有合法结果，设置 `found` 并停止派生，保证返回的都是“最少删除”的解。
- 去重通过 `visited.add(nxt)` 的布尔返回值完成；语义清晰。

## 时间与空间复杂度分析
- 时间：最坏 O(2^n)，但 BFS 在首次命中后停止，通常远小于最坏。
- 空间：队列与 `visited` 在最坏下同量级，取决于可达状态规模。

## 易错点 Checklist
- [ ] 按层处理时确保不混入下一层元素（固定 `size`）
- [ ] 本层命中合法后立即停止派生下一层（保证最少删除）
- [ ] 仅删除括号字符（忽略字母）
- [ ] 使用 `visited` 去重（避免重复状态）
