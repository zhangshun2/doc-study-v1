# 题解2.0.0 单词接龙（LeetCode-127）

## 题解一：官方经典（BFS 最短步数）
- 思路：从 `beginWord` 层序扩张，首次到达 `endWord` 的层数即答案。
- 复杂度：时间 O(N × L × 26)，空间 O(N)。其中 `L` 为词长。

```java
import java.util.*;
class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        if (!dict.contains(endWord)) return 0;
        Deque<String> q = new ArrayDeque<>(); q.offer(beginWord);
        Set<String> vis = new HashSet<>(); vis.add(beginWord);
        int steps = 1;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                String cur = q.poll(); if (cur.equals(endWord)) return steps;
                char[] arr = cur.toCharArray();
                for (int i = 0; i < arr.length; i++) {
                    char old = arr[i];
                    for (char c = 'a'; c <= 'z'; c++) {
                        if (c == old) continue;
                        arr[i] = c; String nxt = new String(arr);
                        if (dict.contains(nxt) && vis.add(nxt)) q.offer(nxt);
                    }
                    arr[i] = old;
                }
            }
            steps++;
        }
        return 0;
    }
}
```

## 题解二：通用解法（双向 BFS）
- 标签：BFS、双向搜索、状态图
- 思路：从两端扩张，减少搜索空间；相交时返回步数。

## 题解三：最好理解（“每次只改一位，谁先到终点谁最短”）
- 直觉：层数就是步数，先遇到 `endWord` 即最短。

## 总结思路
- 单向 BFS 简洁可靠；双向 BFS 对大字典更高效。
