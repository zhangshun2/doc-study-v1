# 问题1.0.0 推箱子（LeetCode-1263）

- 难度：困难
- 链接：https://leetcode.cn/problems/minimum-moves-to-move-a-box-to-their-target-location/

## 概述
在网格中，玩家与箱子和目标位置已知。玩家可以移动到空地，若玩家在箱子相邻且朝箱子将其推向另一侧空地，则箱子移动。求使箱子到达目标位置的最少推箱次数。

## 问题特征与分析引导
- 双层搜索：外层 BFS 以“推箱次数”为层；内层判定“玩家能到达推的位置”。
- 状态设计：箱子位置 + 玩家位置；但常用做法仅以箱子位置为外层状态，内层做可达判定。

## 可能涉及的知识点
- BFS（外层推箱步数）
- 玩家可达性（箱子视为障碍的 BFS）
