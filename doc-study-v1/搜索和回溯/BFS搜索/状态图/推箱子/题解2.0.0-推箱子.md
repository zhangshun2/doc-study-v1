# 题解2.0.0 推箱子（LeetCode-1263）

## 题解一：官方经典（两层 BFS）
- 思路：外层以箱子位置 + 推入方向为状态，尝试四方向推；内层用 BFS 检查玩家能否站到推箱所需的反方向位置。
- 复杂度：时间取决于状态空间，外层近 O(m·n)，内层 BFS 多次；空间 O(m·n)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int minPushBox(char[][] grid) {
        int m = grid.length, n = grid[0].length; int sx=0, sy=0, bx=0, by=0, tx=0, ty=0;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (grid[i][j] == 'S') { sx = i; sy = j; }
            else if (grid[i][j] == 'B') { bx = i; by = j; }
            else if (grid[i][j] == 'T') { tx = i; ty = j; }
        }
        Deque<int[]> q = new ArrayDeque<>(); boolean[][] vis = new boolean[m][n];
        q.offer(new int[]{bx, by, sx, sy}); vis[bx][by] = true; int pushes = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int[] cur = q.poll(); int cbx = cur[0], cby = cur[1], psx = cur[2], psy = cur[3];
                if (cbx == tx && cby == ty) return pushes;
                for (int k = 0; k < 4; k++) {
                    int nbx = cbx + DIR[k], nby = cby + DIR[k+1]; // 箱子被推后的位置
                    int reqx = cbx - DIR[k], reqy = cby - DIR[k+1]; // 玩家需要站的位置（箱子反方向）
                    if (!in(m,n,nbx,nby) || !in(m,n,reqx,reqy) || grid[nbx][nby] == '#' || grid[reqx][reqy] == '#') continue;
                    if (canReach(grid, psx, psy, reqx, reqy, cbx, cby)) {
                        if (!vis[nbx][nby]) { vis[nbx][nby] = true; q.offer(new int[]{nbx, nby, cbx, cby}); }
                    }
                }
            }
            pushes++;
        }
        return -1;
    }
    private boolean in(int m, int n, int x, int y){ return x>=0 && x<m && y>=0 && y<n; }
    private boolean canReach(char[][] g, int sx, int sy, int tx, int ty, int bx, int by) {
        int m = g.length, n = g[0].length; boolean[][] vis = new boolean[m][n]; Deque<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{sx, sy}); vis[sx][sy] = true;
        while (!q.isEmpty()) {
            int[] cur = q.poll(); int x = cur[0], y = cur[1];
            if (x == tx && y == ty) return true;
            for (int k = 0; k < 4; k++) {
                int nx = x + DIR[k], ny = y + DIR[k+1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                if (vis[nx][ny] || g[nx][ny] == '#' || (nx == bx && ny == by)) continue; // 箱子视为障碍
                vis[nx][ny] = true; q.offer(new int[]{nx, ny});
            }
        }
        return false;
    }
}
```

## 题解二：通用解法（状态压缩/双向搜索）
- 标签：BFS、可达性、剪枝
- 思路：也可记玩家位置，或用双向；核心仍是外层度量推次数，内层判人可达。

## 题解三：最好理解（“每次只考虑能站位就推一步，层数就是推数”）
- 直觉：推一次算一步；能站位就能推，层数即答案。

## 总结思路
- 双层搜索是范式；关键在于人可达性的高效判定。
