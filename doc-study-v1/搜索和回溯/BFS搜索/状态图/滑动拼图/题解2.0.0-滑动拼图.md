# 题解2.0.0 滑动拼图（LeetCode-773）

## 题解一：官方经典（BFS 状态搜索）
- 思路：将 `2x3` 转为字符串状态，按空格位置的可交换索引生成新状态；首次到达目标时返回步数。
- 复杂度：时间 O(状态数 × 邻接度)，空间 O(状态数)。

```java
import java.util.*;
class Solution {
    private static final int[][] NEI = {
        {1, 3},    // idx 0
        {0, 2, 4}, // idx 1
        {1, 5},    // idx 2
        {0, 4},    // idx 3
        {1, 3, 5}, // idx 4
        {2, 4}     // idx 5
    };
    public int slidingPuzzle(int[][] board) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < 2; i++) for (int j = 0; j < 3; j++) sb.append(board[i][j]);
        String start = sb.toString(), target = "123450";
        if (start.equals(target)) return 0;
        Deque<String> q = new ArrayDeque<>(); Set<String> vis = new HashSet<>();
        q.offer(start); vis.add(start); int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                String cur = q.poll(); if (cur.equals(target)) return steps;
                int z = cur.indexOf('0');
                for (int nxtPos : NEI[z]) {
                    String nxt = swap(cur, z, nxtPos);
                    if (vis.add(nxt)) q.offer(nxt);
                }
            }
            steps++;
        }
        return -1;
    }
    private String swap(String s, int i, int j) {
        char[] a = s.toCharArray(); char t = a[i]; a[i] = a[j]; a[j] = t; return new String(a);
    }
}
```

## 题解二：通用解法（A* 启发式）
- 标签：A*、启发函数
- 思路：以曼哈顿距离作为启发式；实现复杂，但在大状态空间中更高效。

## 题解三：最好理解（“每步只交换空格和邻居，层数就是步数”）
- 直觉：谁先到达目标谁最短，BFS 即保证最短步数。

## 总结思路
- BFS 足以解决 `2x3`；更大拼图可考虑 A*。
