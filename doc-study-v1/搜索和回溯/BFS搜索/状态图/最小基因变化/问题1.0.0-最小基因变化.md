# 问题1.0.0 最小基因变化（LeetCode-433）

- 难度：中等
- 链接：https://leetcode.cn/problems/minimum-genetic-mutation/

## 概述
基因字符串由 `A/C/G/T` 组成，长度固定。每次变化只能改变一个字符且结果必须在基因库 `bank` 中。给定起始与目标，求最少变化次数；不可达返回 `-1`。

## 问题特征与分析引导
- 图建模：以基因串为节点，边为“一位不同且在库中”。
- 搜索：无权图最短路，使用 BFS。
- 去重：`visited` 控制已访问基因，避免环与重复。

## 可能涉及的知识点
- 字符串邻接判断与枚举变体
- BFS 队列与步数计数
- 访问标记与基因库哈希
