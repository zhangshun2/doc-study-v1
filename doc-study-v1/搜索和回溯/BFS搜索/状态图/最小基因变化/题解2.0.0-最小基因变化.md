# 题解2.0.0 最小基因变化（LeetCode-433）

## 题解一：官方经典（BFS 枚举变体）
- 思路：将 `bank` 放入集合；从起始串出发，每次尝试在每个位置替换为 `A/C/G/T` 的其他字符，形成在库且未访问的串入队；到达目标返回步数。
- 复杂度：时间 O(L·Σ·|bank|) 近似，空间 O(|bank|)。

```java
import java.util.*;
class Solution {
    private static final char[] GENES = {'A','C','G','T'};
    public int minMutation(String start, String end, String[] bank) {
        Set<String> set = new HashSet<>(Arrays.asList(bank));
        if (!set.contains(end)) return -1;
        Deque<String> q = new ArrayDeque<>(); q.offer(start);
        Set<String> vis = new HashSet<>(); vis.add(start);
        int steps = 0, L = start.length();
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                String cur = q.poll(); if (cur.equals(end)) return steps;
                char[] arr = cur.toCharArray();
                for (int i = 0; i < L; i++) {
                    char old = arr[i];
                    for (char c : GENES) {
                        if (c == old) continue; arr[i] = c;
                        String nxt = new String(arr);
                        if (set.contains(nxt) && vis.add(nxt)) q.offer(nxt);
                    }
                    arr[i] = old;
                }
            }
            steps++;
        }
        return -1;
    }
}
```

## 题解二：通用解法（预构图/邻接表）
- 标签：BFS、状态图、变体枚举

## 题解三：最好理解（“每次改一位，能到库里的就继续”）
- 直觉：逐层累积变化次数，到达目标时层数即最少变化。

## 总结思路
- BFS 逐层改动与去重控制即可；哈希集合提升查找效率。
