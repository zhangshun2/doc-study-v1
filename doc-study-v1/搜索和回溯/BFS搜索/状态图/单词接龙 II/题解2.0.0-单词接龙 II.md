# 题解2.0.0 单词接龙 II（LeetCode-126）

## 题解一：官方经典（BFS + DFS 回溯）
- 思路：BFS 记录每词的层次与下一层邻居，DFS 在严格递增层次的邻接中构造所有最短路径。
- 复杂度：时间依赖解空间，BFS O(N × L × 26)；空间 O(N)。

```java
import java.util.*;
class Solution {
    public List<List<String>> findLadders(String beginWord, String endWord, List<String> wordList) {
        Set<String> dict = new HashSet<>(wordList);
        List<List<String>> res = new ArrayList<>();
        if (!dict.contains(endWord)) return res;
        dict.add(beginWord);
        Map<String, List<String>> next = new HashMap<>();
        Map<String, Integer> dist = new HashMap<>();
        bfs(beginWord, endWord, dict, next, dist);
        if (!dist.containsKey(endWord)) return res;
        List<String> path = new ArrayList<>(); path.add(beginWord);
        dfs(beginWord, endWord, next, dist, path, res);
        return res;
    }
    private void bfs(String begin, String end, Set<String> dict, Map<String, List<String>> next, Map<String, Integer> dist) {
        for (String w : dict) next.put(w, new ArrayList<>());
        Deque<String> q = new ArrayDeque<>(); q.offer(begin); dist.put(begin, 0);
        boolean found = false;
        while (!q.isEmpty() && !found) {
            int sz = q.size();
            Set<String> layerVisited = new HashSet<>();
            for (int i = 0; i < sz; i++) {
                String cur = q.poll(); int d = dist.get(cur);
                for (String nei : neighbors(cur, dict)) {
                    next.get(cur).add(nei);
                    if (!dist.containsKey(nei)) {
                        if (layerVisited.add(nei)) q.offer(nei);
                        dist.put(nei, d + 1);
                        if (nei.equals(end)) found = true;
                    }
                }
            }
        }
    }
    private void dfs(String cur, String end, Map<String, List<String>> next, Map<String, Integer> dist, List<String> path, List<List<String>> res) {
        if (cur.equals(end)) { res.add(new ArrayList<>(path)); return; }
        for (String nei : next.get(cur)) {
            if (dist.getOrDefault(nei, Integer.MAX_VALUE) == dist.get(cur) + 1) {
                path.add(nei); dfs(nei, end, next, dist, path, res); path.remove(path.size() - 1);
            }
        }
    }
    private List<String> neighbors(String s, Set<String> dict) {
        List<String> ans = new ArrayList<>(); char[] arr = s.toCharArray();
        for (int i = 0; i < arr.length; i++) {
            char old = arr[i];
            for (char c = 'a'; c <= 'z'; c++) {
                if (c == old) continue; arr[i] = c; String t = new String(arr);
                if (dict.contains(t)) ans.add(t);
            }
            arr[i] = old;
        }
        return ans;
    }
}
```

## 题解二：通用解法（双向 BFS + 回溯）
- 标签：双向搜索、回溯
- 思路：从两端扩张，记录相遇层的邻接，再回溯构造路径；实现更复杂但搜索更少。

## 题解三：最好理解（“先找到最短层次，再沿层次回溯出所有路径”）
- 直觉：层次递增保证路径最短，DFS 只在最短层的邻接中行走。

## 总结思路
- BFS+DFS 是标准范式，注意剪枝与层次边构造。
