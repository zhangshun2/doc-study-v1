# 问题1.0.0 打开转盘锁（LeetCode-752）

- 难度：中等
- 链接：https://leetcode.cn/problems/open-the-lock/

## 概述
四位数转盘锁，每位可向上/向下转动一格（`0-9` 循环），给定若干死锁状态 `deadends` 与目标 `target`，从初始 `0000` 出发，求最少转动次数；不可达返回 `-1`。

## 问题特征与分析引导
- 状态图：每个状态与其临近 8 个状态相连。
- 多源/单源 BFS：单源从 `0000` 出发，避开死锁与重复访问。
- 去重：`visited` 集合避免回环。

## 可能涉及的知识点
- 状态枚举与邻居生成
- BFS 队列与层次计数
- 死锁集合与访问标记
