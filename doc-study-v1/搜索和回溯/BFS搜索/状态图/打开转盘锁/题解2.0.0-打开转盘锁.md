# 题解2.0.0 打开转盘锁（LeetCode-752）

## 题解一：官方经典（BFS 层序 + 邻居生成）
- 思路：将 `deadends` 放入集合，从 `0000` 开始层序扩张，生成每位 +1/-1 的新状态；首次到达 `target` 时层数即答案。
- 复杂度：时间 O(状态数 × 8)，空间 O(状态数)。

```java
import java.util.*;
class Solution {
    public int openLock(String[] deadends, String target) {
        Set<String> dead = new HashSet<>(Arrays.asList(deadends));
        if (dead.contains("0000")) return -1;
        Deque<String> q = new ArrayDeque<>(); Set<String> vis = new HashSet<>();
        q.offer("0000"); vis.add("0000"); int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                String cur = q.poll(); if (cur.equals(target)) return steps;
                char[] arr = cur.toCharArray();
                for (int i = 0; i < 4; i++) {
                    char c = arr[i];
                    char up = c == '9' ? '0' : (char)(c + 1);
                    char down = c == '0' ? '9' : (char)(c - 1);
                    arr[i] = up; String s1 = new String(arr); arr[i] = c;
                    arr[i] = down; String s2 = new String(arr); arr[i] = c;
                    if (!dead.contains(s1) && vis.add(s1)) q.offer(s1);
                    if (!dead.contains(s2) && vis.add(s2)) q.offer(s2);
                }
            }
            steps++;
        }
        return -1;
    }
}
```

## 题解二：通用解法（双向 BFS）
- 标签：BFS、双向搜索、状态图
- 思路：从起点与终点双向扩张，减少搜索空间；但需处理死锁与相交判定。

## 题解三：最好理解（“每一步只转一格，谁先到目标谁最短”）
- 直觉：层序即步数，先到即最短。

## 总结思路
- 单向 BFS 最简单；双向 BFS 在大状态图下更高效。
