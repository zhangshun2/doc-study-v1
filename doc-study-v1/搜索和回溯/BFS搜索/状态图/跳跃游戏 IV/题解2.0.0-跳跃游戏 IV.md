# 题解2.0.0 跳跃游戏 IV（LeetCode-1345）

## 题解一：官方经典（哈希映射 + BFS）
- 思路：建值到索引列表的映射，BFS 扩张 `i-1,i+1` 与同值索引；同值列表在使用后清空以降复杂度。
- 复杂度：时间 O(n)，空间 O(n)。

```java
import java.util.*;
class Solution {
    public int minJumps(int[] arr) {
        int n = arr.length; if (n <= 1) return 0;
        Map<Integer, List<Integer>> mp = new HashMap<>();
        for (int i = 0; i < n; i++) mp.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
        Deque<Integer> q = new ArrayDeque<>(); boolean[] vis = new boolean[n];
        q.offer(0); vis[0] = true; int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int i = q.poll(); if (i == n - 1) return steps;
                int[] cand = {i - 1, i + 1};
                for (int nxt : cand) if (nxt >= 0 && nxt < n && !vis[nxt]) { vis[nxt] = true; q.offer(nxt); }
                List<Integer> same = mp.get(arr[i]);
                if (same != null) {
                    for (int nxt : same) if (!vis[nxt]) { vis[nxt] = true; q.offer(nxt); }
                    same.clear(); // 剪枝
                }
            }
            steps++;
        }
        return -1;
    }
}
```

## 题解三：最好理解（“同值位置一股脑用掉，然后只走左右”）
- 直觉：同值跳法在第一次展开后就没必要再重复查找。

## 总结思路
