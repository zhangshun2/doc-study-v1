# 题解2.0.0 地图分析（LeetCode-1162）

## 题解一：官方经典（多源 BFS 求最大层数）
- 思路：所有陆地入队向外扩张，记录最后一层扩张到的海洋的距离；无海洋或无陆地则 `-1`。
- 复杂度：时间 O(m·n)，空间 O(m·n)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int maxDistance(int[][] grid) {
        int m = grid.length, n = grid[0].length; Deque<int[]> q = new ArrayDeque<>();
        int land = 0, water = 0;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (grid[i][j] == 1) { q.offer(new int[]{i, j}); land++; }
            else water++;
        }
        if (land == 0 || water == 0) return -1;
        int dist = -1;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int[] cur = q.poll(); int x = cur[0], y = cur[1];
                for (int d = 0; d < 4; d++) {
                    int nx = x + DIR[d], ny = y + DIR[d+1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n || grid[nx][ny] != 0) continue;
                    grid[nx][ny] = grid[x][y] + 1; q.offer(new int[]{nx, ny});
                }
            }
            dist++;
        }
        return dist;
    }
}
```

- 标签：BFS、距离、网格
- 思路：也可维护独立距离矩阵，陆地为 0，海洋为 INF，扩张更新更短距离。

## 题解三：最好理解（“从陆地一起出发，走到最远的那片海”）
- 直觉：同时扩张，最后抵达的海就是最远的海。

## 总结思路
- 多源 BFS 足够；边界与初始情况判定要正确。
