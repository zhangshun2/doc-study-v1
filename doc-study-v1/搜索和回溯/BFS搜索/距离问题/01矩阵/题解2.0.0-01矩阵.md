题解2.0.0 - 01矩阵（01 Matrix, LeetCode 542）

概述：将所有 0 入队，层序扩散更新四邻的距离（上一层距离+1），直到覆盖所有 1。

题解一：多源 BFS（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int[][] updateMatrix(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[][] dist = new int[m][n];
        boolean[][] vis = new boolean[m][n];
        Queue<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 0) { q.offer(new int[]{i, j}); vis[i][j] = true; }
            }
        }
        int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int[] mv : d) {
                int nx = cur[0] + mv[0], ny = cur[1] + mv[1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n || vis[nx][ny]) continue;
                dist[nx][ny] = dist[cur[0]][cur[1]] + 1;
                vis[nx][ny] = true;
                q.offer(new int[]{nx, ny});
            }
        }
        return dist;
    }
}
```

复杂度：
- O(R·C)，空间 O(R·C)。

思考小结：
- 多源起点一次遍历即可得到所有点最短距离，避免对每个 1 独立 BFS 的高复杂度。
