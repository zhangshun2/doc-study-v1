题解2.0.0 - 墙与门（Walls and Gates, LeetCode 286）

概述：将所有门(0)入队，逐层向四邻扩散，遇到 INF 时更新为当前距离+1 并入队。

题解一：多源 BFS 原地更新（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    private static final int INF = 2147483647;
    public void wallsAndGates(int[][] rooms) {
        int m = rooms.length, n = rooms[0].length;
        Queue<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (rooms[i][j] == 0) q.offer(new int[]{i, j});
            }
        }
        int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int[] mv : d) {
                int nx = cur[0] + mv[0], ny = cur[1] + mv[1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                if (rooms[nx][ny] == INF) {
                    rooms[nx][ny] = rooms[cur[0]][cur[1]] + 1;
                    q.offer(new int[]{nx, ny});
                }
            }
        }
    }
}
```

复杂度：
- O(m·n)，空间 O(m·n)。

思考小结：
- 多源入队能一次遍历得到所有点的最短距离。

标签：BFS、距离、网格
