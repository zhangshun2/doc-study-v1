问题1.0.0 - 墙与门（Walls and Gates, LeetCode 286）

概述：给定一个包含 INF、-1、0 的房间网格，其中 0 为门、-1 为墙、INF 为空房间。将每个空房间填上到最近门的距离。采用多源 BFS。

链接：https://leetcode.com/problems/walls-and-gates/

题目特征与分析：
- 多源 BFS 距离填充：所有门同时入队，扩散更新最短距离。
- 原地更新：避免额外空间。

知识点：
- BFS 距离、网格搜索、原地更新。

输入输出：
- 输入：整数网格 `rooms`（INF=2147483647）。
- 输出：原地填充距离后网格。

标签：BFS、距离问题、网格、搜索与回溯
