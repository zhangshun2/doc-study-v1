## 问题概述
删除无效的括号，要求返回所有通过删除最少字符后得到的合法括号字符串。为何 BFS 能保证“删除数最少”？如何避免写法上的陷阱？

## 题目特征与约束
- 输入：包含括号与字母的字符串，长度 `n`
- 输出：所有最少删除后合法的字符串（可能不止一个）
- 合法判定：括号平衡，且任意前缀中右括号不超过左括号
- 要求：删除最少字符；字母不删；去重避免重复状态

## 思路引导
- 用 BFS 的“层”代表删除次数：0 层是原串，1 层是删除一个字符后集合，依次类推。
- 首次在某一层发现合法字符串，意味着该层对应的删除次数是最小的；返回该层所有合法结果即可。
- 使用 `visited` 去重，避免重复状态导致爆炸或无效循环。

## 涉及的知识点拆解
- BFS 层次搜索：按队列批处理固定层大小，以保证“同层同步处理”。
- 合法性检查：线性扫描计数，遇右括号且计数为负立即非法；最终计数为零才合法。
- 次层状态生成：仅对括号字符进行删除；字母保留；派生新字符串入队。

## 常见误区与边界条件
- 误区1：清空了当前层队列后再去派生下一层，导致无法获取当前层元素来生成下一层（应在处理当前层的循环中或先收集后派生）。
- 误区2：未使用 `visited` 去重，状态数指数膨胀严重。
- 误区3：派生时删除所有字符包含字母，违背题意（应只删括号）。
- 边界：空串合法；全字母串合法（无需删除）；仅右括号开头立即判非法。

## 复杂度直觉
- 时间：最坏接近 O(2^n)；但 BFS 在首次找到合法层后即停止，具备“最少删除”的剪枝效果。
- 空间：队列与 `visited` 通常也是指数级最坏；但去重至关重要。

## 练习建议（变体与扩展）
- 仅删除无效右括号（单向不平衡）
- 处理多种括号类型：`()[]{}`（需匹配规则与优先级）
- 优先返回字典序最小的合法串（可在派生或收集阶段排序）
