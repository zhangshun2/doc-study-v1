# 题解2.0.0 访问所有节点的最短路径（LeetCode-847）

## 题解一：官方经典（位压多源 BFS）
- 思路：将 `(node, mask)` 入队，扩张到邻居 `(nei, mask | (1<<nei))`；首次达到 `mask == all` 的层数即答案。
- 复杂度：时间 O(n·2^n)，空间 O(n·2^n)。

```java
import java.util.*;
class Solution {
    public int shortestPathLength(int[][] graph) {
        int n = graph.length; int target = (1 << n) - 1;
        Deque<int[]> q = new ArrayDeque<>(); boolean[][] vis = new boolean[n][1 << n];
        for (int i = 0; i < n; i++) { q.offer(new int[]{i, 1 << i}); vis[i][1 << i] = true; }
        int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int[] cur = q.poll(); int u = cur[0], mask = cur[1];
                if (mask == target) return steps;
                for (int v : graph[u]) {
                    int nmask = mask | (1 << v);
                    if (!vis[v][nmask]) { vis[v][nmask] = true; q.offer(new int[]{v, nmask}); }
                }
            }
            steps++;
        }
        return 0;
    }
}
```

## 题解二：通用解法（SPFA/DP 辅助剪枝）
- 标签：位压、DP、剪枝
- 思路：用 `dp[node][mask]` 记录最短步数，结合队列优化剪枝扩张。

## 题解三：最好理解（“背着访问集合走，凑满所有节点就结束”）
- 直觉：状态里装“走到哪 + 走过谁”，层序即最短步数。

- 位压 BFS 模板题；多源初始化常用。
