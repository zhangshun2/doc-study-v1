问题1.0.0 - 迷宫 III（The Maze III, LeetCode 499）

概述：在滚动迷宫中从起点到“洞”，求最短路径；若有多条最短路径，返回字典序最小的路径字符串。用 Dijkstra，比较距离与路径字符串。

链接：https://leetcode.com/problems/the-maze-iii/

题目特征与分析：
- 变权最短路 + 字典序优先：优先队列按（距离，字典序）排序。
- 滚动中遇洞即停下，记录步数与路径。

知识点：
- Dijkstra、字典序比较、滚动网格。

输入输出：
- 输入：`maze`、`ball`、`hole`。
- 输出：最短路径字符串或 "impossible"。

标签：Dijkstra、最短路径、字典序、网格搜索、搜索与回溯
