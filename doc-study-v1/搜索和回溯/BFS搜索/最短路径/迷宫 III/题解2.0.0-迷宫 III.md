题解2.0.0 - 迷宫 III（The Maze III, LeetCode 499）

概述：在滚动过程中若到达洞则停下，使用 Dijkstra 维护当前点到各停点的最短距离与对应路径字符串。

题解一：Dijkstra + 字典序（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    static class State {
        int x, y, dist; String path;
        State(int x, int y, int dist, String path) { this.x = x; this.y = y; this.dist = dist; this.path = path; }
    }

    public String findShortestWay(int[][] maze, int[] ball, int[] hole) {
        int m = maze.length, n = maze[0].length;
        int[][] best = new int[m][n];
        String[][] bestPath = new String[m][n];
        for (int i = 0; i < m; i++) Arrays.fill(best[i], Integer.MAX_VALUE);
        PriorityQueue<State> pq = new PriorityQueue<>((a, b) -> {
            if (a.dist != b.dist) return a.dist - b.dist;
            return a.path.compareTo(b.path);
        });
        best[ball[0]][ball[1]] = 0; bestPath[ball[0]][ball[1]] = "";
        pq.offer(new State(ball[0], ball[1], 0, ""));
        int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
        char[] dirCh = {'d','u','r','l'};
        while (!pq.isEmpty()) {
            State cur = pq.poll();
            if (cur.dist > best[cur.x][cur.y]) continue;
            if (cur.x == hole[0] && cur.y == hole[1]) return cur.path;
            for (int k = 0; k < 4; k++) {
                int[] mv = d[k]; char ch = dirCh[k];
                int nx = cur.x, ny = cur.y, steps = 0;
                while (nx + mv[0] >= 0 && nx + mv[0] < m && ny + mv[1] >= 0 && ny + mv[1] < n && maze[nx + mv[0]][ny + mv[1]] == 0) {
                    nx += mv[0]; ny += mv[1]; steps++;
                    if (nx == hole[0] && ny == hole[1]) break;
                }
                int nd = cur.dist + steps; String np = cur.path + ch;
                if (nd < best[nx][ny] || (nd == best[nx][ny] && (bestPath[nx][ny] == null || np.compareTo(bestPath[nx][ny]) < 0))) {
                    best[nx][ny] = nd; bestPath[nx][ny] = np;
                    pq.offer(new State(nx, ny, nd, np));
                }
            }
        }
        return "impossible";
    }
}
```

复杂度：
- O(m·n·log(m·n))，空间 O(m·n)。

思考小结：
- 注意滚动时洞的提前停下；路径字符串作为次序关键字。

标签：Dijkstra、字典序、滚动网格
