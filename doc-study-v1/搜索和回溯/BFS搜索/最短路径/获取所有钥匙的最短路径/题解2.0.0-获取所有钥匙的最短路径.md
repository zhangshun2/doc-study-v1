# 题解2.0.0 获取所有钥匙的最短路径（LeetCode-864）

## 题解一：官方经典（位压 BFS）
- 思路：状态 `(x,y,mask)`，遇到钥匙则置位，遇到锁则判断是否已持有；首次使 `mask==all` 的层数即答案。
- 复杂度：时间 O(m·n·2^K)，空间 O(m·n·2^K)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int shortestPathAllKeys(String[] grid) {
        int m = grid.length, n = grid[0].length(); int sx=0, sy=0, keys=0;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            char c = grid[i].charAt(j);
            if (c == '@') { sx = i; sy = j; }
            else if ('a' <= c && c <= 'f') keys = Math.max(keys, c - 'a' + 1);
        }
        int target = (1 << keys) - 1; boolean[][][] vis = new boolean[m][n][1 << keys];
        Deque<int[]> q = new ArrayDeque<>(); q.offer(new int[]{sx, sy, 0}); vis[sx][sy][0] = true;
        int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int[] cur = q.poll(); int x = cur[0], y = cur[1], mask = cur[2];
                if (mask == target) return steps;
                for (int k = 0; k < 4; k++) {
                    int nx = x + DIR[k], ny = y + DIR[k+1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    char c = grid[nx].charAt(ny);
                    if (c == '#') continue;
                    int nmask = mask;
                    if ('a' <= c && c <= 'f') nmask |= (1 << (c - 'a'));
                    if ('A' <= c && c <= 'F' && (nmask & (1 << (c - 'A'))) == 0) continue; // 无钥匙过不去
                    if (!vis[nx][ny][nmask]) { vis[nx][ny][nmask] = true; q.offer(new int[]{nx, ny, nmask}); }
                }
            }
            steps++;
        }
        return -1;
    }
}
```

## 题解二：通用解法（双向/启发式）
- 标签：位压、剪枝
- 思路：也可做启发式剪枝，但模板位压 BFS 足够。

## 题解三：最好理解（“背着钥匙集合走，拿齐所有钥匙就结束”）
- 直觉：状态里带着已拿钥匙，层数就是步数。

## 总结思路
- 位压 BFS 是标准解法；合理剪枝可提速。
