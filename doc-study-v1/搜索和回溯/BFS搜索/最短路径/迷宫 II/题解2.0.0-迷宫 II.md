题解2.0.0 - 迷宫 II（The Maze II, LeetCode 505）

概述：用 Dijkstra 在“停点图”上求最短距离，滚动过程中累计步数作为边权。

题解一：Dijkstra（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int shortestDistance(int[][] maze, int[] start, int[] destination) {
        int m = maze.length, n = maze[0].length;
        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[start[0]][start[1]] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[2]));
        pq.offer(new int[]{start[0], start[1], 0});
        int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int x = cur[0], y = cur[1], cd = cur[2];
            if (cd > dist[x][y]) continue;
            for (int[] mv : d) {
                int nx = x, ny = y, steps = 0;
                while (nx + mv[0] >= 0 && nx + mv[0] < m && ny + mv[1] >= 0 && ny + mv[1] < n && maze[nx + mv[0]][ny + mv[1]] == 0) {
                    nx += mv[0]; ny += mv[1]; steps++;
                }
                if (cd + steps < dist[nx][ny]) {
                    dist[nx][ny] = cd + steps;
                    pq.offer(new int[]{nx, ny, dist[nx][ny]});
                }
            }
        }
        int ans = dist[destination[0]][destination[1]];
        return ans == Integer.MAX_VALUE ? -1 : ans;
    }
}
```

复杂度：
- O(m·n·log(m·n))，滚动开销与 PQ 操作；空间 O(m·n)。

思考小结：
- 变权边需用 Dijkstra；BFS 不适用于可变滚动步长的最短路。

标签：Dijkstra、最短路、滚动网格
