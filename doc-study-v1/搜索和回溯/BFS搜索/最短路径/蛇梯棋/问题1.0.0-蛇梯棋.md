# 问题1.0.0 蛇梯棋（LeetCode-909）

- 难度：中等
- 链接：https://leetcode.cn/problems/snakes-and-ladders/

## 概述
在 `n x n` 蛇梯棋盘上，从格子 `1` 出发，每次掷骰子前进 `1..6` 步，若落在蛇或梯子的格子则移动到指定位置，求达到 `n^2` 的最少步数；不可达返回 `-1`。

## 问题特征与分析引导
- 蛇梯映射：棋盘编号为“自底向上、交替方向”计数。
- BFS：层序扩张，处理蛇梯跳转后的实际位置，访问标记避免重复。

## 可能涉及的知识点
- 坐标与编号转换
- BFS 层序与剪枝（超过 `n^2` 直接跳过）
