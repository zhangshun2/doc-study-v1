# 题解2.0.0 蛇梯棋（LeetCode-909）

## 题解一：官方经典（BFS + 编号映射）
- 思路：对当前位置尝试 `+1..+6`，转换到棋盘坐标，若有蛇/梯则跳转；首次到达终点层数即答案。
- 复杂度：时间 O(n^2)，空间 O(n^2)。

```java
import java.util.*;
class Solution {
    public int snakesAndLadders(int[][] board) {
        int n = board.length; Deque<Integer> q = new ArrayDeque<>();
        boolean[] vis = new boolean[n * n + 1]; q.offer(1); vis[1] = true; int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int cur = q.poll(); if (cur == n * n) return steps;
                for (int d = 1; d <= 6; d++) {
                    int nxt = cur + d; if (nxt > n * n) break;
                    int[] rc = get(n, nxt); int val = board[rc[0]][rc[1]];
                    if (val != -1) nxt = val;
                    if (!vis[nxt]) { vis[nxt] = true; q.offer(nxt); }
                }
            }
            steps++;
        }
        return -1;
    }
    private int[] get(int n, int num) {
        int r = n - 1 - (num - 1) / n; // 从底部向上
        int c = (num - 1) % n;
        if (((n - 1 - r) % 2) == 1) c = n - 1 - c; // 奇数行反向
        return new int[]{r, c};
    }
}
```

## 题解二：通用解法（双向 BFS）
- 标签：BFS、剪枝
- 思路：理论可双向，但蛇梯跳转复杂且状态空间较小，单向足够。

## 题解三：最好理解（“把棋盘编号排好，遇到蛇梯就顺着跳”）
- 直觉：层序就是步数，先到终点即最少。

## 总结思路
- 关键是编号映射与跳转；BFS 可靠简洁。
