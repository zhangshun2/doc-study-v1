# 题解2.0.0 公交路线（LeetCode-815）

## 题解一：官方经典（按线路 BFS）
- 思路：维护队列为当前可达站点；当站点属于某线路时，把该线路未访问过且上面的所有站点入队，并把线路标记访问；层次步数 +1 表示乘坐一次新线路。
- 复杂度：时间近似 O(总站点 + 线路展开)，空间 O(总站点)。

```java
import java.util.*;
class Solution {
    public int numBusesToDestination(int[][] routes, int source, int target) {
        if (source == target) return 0;
        Map<Integer, List<Integer>> mp = new HashMap<>();
        for (int i = 0; i < routes.length; i++) {
            for (int stop : routes[i]) mp.computeIfAbsent(stop, k -> new ArrayList<>()).add(i);
        }
        Deque<Integer> q = new ArrayDeque<>(); q.offer(source);
        Set<Integer> visStop = new HashSet<>(); visStop.add(source);
        boolean[] visRoute = new boolean[routes.length];
        int buses = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int stop = q.poll(); if (stop == target) return buses;
                for (int r : mp.getOrDefault(stop, Collections.emptyList())) {
                    if (visRoute[r]) continue; visRoute[r] = true;
                    for (int nxt : routes[r]) if (visStop.add(nxt)) q.offer(nxt);
                }
            }
            buses++;
        }
        return -1;
    }
}
```

## 题解二：通用解法（站点图 BFS）
- 标签：BFS、哈希、最短路径
- 思路：也可把站点两两连边（同线路站点），但边数可能巨大，按线路展开更优。

## 题解三：最好理解（“每乘一次车算一步，能到的站点一股脑加入队列”）
- 直觉：步数代表换乘次数，层层扩张站点直到到达目标。

## 总结思路
- 按线路展开是主流解法；合理的去重与映射是效率关键。
