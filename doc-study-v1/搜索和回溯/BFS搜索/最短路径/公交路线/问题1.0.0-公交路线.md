# 问题1.0.0 公交路线（LeetCode-815）

- 难度：困难
- 链接：https://leetcode.cn/problems/bus-routes/

## 概述
给定若干公交线路（每条线路有多个站点），从起点站 `source` 到终点站 `target`，问至少乘坐几次公交可以到达；不可达返回 `-1`。

## 问题特征与分析引导
- 图建模：构建 `站点 -> 所属线路` 的映射；BFS 以“乘坐线路次数”为层数。
- 去重：同一线路只乘坐一次；同一站点不要重复入队。
- 规模：总站点数可能较大，需用哈希与优化。

## 可能涉及的知识点
- 哈希映射 `stop -> routes` 构建
- BFS 层次（按线路计数）与访问标记
- 剪枝与早停策略
