# 题解2.0.0 网格中消除障碍的最短路径（LeetCode-1293）

## 题解一：官方经典（BFS 状态扩维）
- 思路：队列存 `(x,y,k_left)`，遇到障碍且 `k_left>0` 可消除并继续；用 `vis[x][y][k_left]` 去重。
- 复杂度：时间 O(m·n·k)，空间 O(m·n·k)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int shortestPath(int[][] grid, int k) {
        int m = grid.length, n = grid[0].length;
        boolean[][][] vis = new boolean[m][n][k + 1];
        Deque<int[]> q = new ArrayDeque<>(); q.offer(new int[]{0, 0, k}); vis[0][0][k] = true;
        int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int[] cur = q.poll(); int x = cur[0], y = cur[1], r = cur[2];
                if (x == m - 1 && y == n - 1) return steps;
                for (int d = 0; d < 4; d++) {
                    int nx = x + DIR[d], ny = y + DIR[d+1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    int nr = r - grid[nx][ny]; if (nr < 0) continue;
                    if (!vis[nx][ny][nr]) { vis[nx][ny][nr] = true; q.offer(new int[]{nx, ny, nr}); }
                }
            }
            steps++;
        }
        return -1;
    }
}
```

## 题解二：通用解法（最佳剩余记忆）
- 标签：BFS、剪枝
- 思路：也可维护 `best[x][y]` 表示当前到达此格的最大剩余 `k`，仅在更优时入队。

## 题解三：最好理解（“背着还能消多少障碍去走最短路”）
- 直觉：剩余越多越好，状态中带上它，层序即步数。

## 总结思路
- 扩维 BFS 是稳定做法；剪枝能显著降复杂度。
