# 问题1.0.0 网格中消除障碍的最短路径（LeetCode-1293）

- 难度：困难
- 链接：https://leetcode.cn/problems/shortest-path-in-a-grid-with-obstacles-elimination/

## 概述
在 `0/1` 网格中，`1` 表示障碍，给定可消除障碍数 `k`，从 `(0,0)` 到 `(m-1,n-1)` 的最少步数；不可达返回 `-1`。

## 问题特征与分析引导
- 状态扩展：状态需包含坐标与剩余消除次数。
- 去重：同一格保留“用更多剩余 k 到达”的更优状态。

## 可能涉及的知识点
- BFS 状态设计（x, y, k_left）
- 访问标记与剪枝策略
