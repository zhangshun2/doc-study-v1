题解2.0.0 - 最少的骑士移动次数（Minimum Knight Moves, LeetCode 1197）

概述：利用目标对称性，将坐标取绝对值限制搜索到第一象限附近，用 BFS 分层扩展到目标。

题解一：BFS + 边界剪枝（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int minKnightMoves(int x, int y) {
        int tx = Math.abs(x), ty = Math.abs(y);
        int minX = -2, minY = -2, maxX = tx + 2, maxY = ty + 2;
        boolean[][] vis = new boolean[maxX - minX + 1][maxY - minY + 1];
        Queue<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{0, 0});
        vis[0 - minX][0 - minY] = true;
        int[][] d = {{1,2},{2,1},{2,-1},{1,-2},{-1,-2},{-2,-1},{-2,1},{-1,2}};
        int step = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int[] cur = q.poll();
                if (cur[0] == tx && cur[1] == ty) return step;
                for (int[] mv : d) {
                    int nx = cur[0] + mv[0], ny = cur[1] + mv[1];
                    if (nx < minX || nx > maxX || ny < minY || ny > maxY) continue;
                    if (!vis[nx - minX][ny - minY]) {
                        vis[nx - minX][ny - minY] = true;
                        q.offer(new int[]{nx, ny});
                    }
                }
            }
            step++;
        }
        return -1;
    }
}
```

复杂度：
- 近似 O(tx·ty)，边界剪枝有效减少搜索空间。

思考小结：
- 取绝对值 + 有限边界是关键剪枝，避免无限图的盲目扩展。

标签：BFS、最短路径、网格搜索
