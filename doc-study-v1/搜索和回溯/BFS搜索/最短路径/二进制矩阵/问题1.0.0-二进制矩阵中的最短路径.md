# 问题1.0.0 二进制矩阵中的最短路径（LeetCode-1091）

- 难度：中等
- 链接：https://leetcode.cn/problems/shortest-path-in-binary-matrix/

## 概述
给定 `n x n` 的二进制矩阵，`0` 表示可通行、`1` 表示障碍。求从左上角 `(0,0)` 到右下角 `(n-1,n-1)` 的最短路径长度，允许 8 方向移动；若不存在返回 `-1`。

## 问题特征与分析引导
- 搜索结构：网格图的无权最短路，适合 BFS 层序扩张。
- 方向：8 邻域（含对角）；需要完整的方向数组。
- 边界与起点：起点或终点为 `1` 则直接不可达。

## 可能涉及的知识点
- 多方向 BFS 模板与层次计数
- 访问标记与原地修改
- 早停策略（达到终点即返回当层步数）
