题解2.0.0 - 开锁（Open the Lock, LeetCode 752）

概述：从 "0000" 开始 BFS，层序扩展到所有可达状态，遇到 `target` 返回步数；利用集合跳过死锁并记录已访问。

题解一：BFS + 邻居生成（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int openLock(String[] deadends, String target) {
        Set<String> dead = new HashSet<>(Arrays.asList(deadends));
        String start = "0000";
        if (dead.contains(start)) return -1;
        if (start.equals(target)) return 0;
        Set<String> vis = new HashSet<>();
        Queue<String> q = new ArrayDeque<>();
        q.offer(start); vis.add(start);
        int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                String cur = q.poll();
                if (cur.equals(target)) return steps;
                for (String nxt : neighbors(cur)) {
                    if (!dead.contains(nxt) && vis.add(nxt)) q.offer(nxt);
                }
            }
            steps++;
        }
        return -1;
    }
    private List<String> neighbors(String s) {
        List<String> res = new ArrayList<>();
        char[] a = s.toCharArray();
        for (int i = 0; i < 4; i++) {
            char c = a[i];
            char up = c == '9' ? '0' : (char)(c + 1);
            char down = c == '0' ? '9' : (char)(c - 1);
            a[i] = up; res.add(new String(a)); a[i] = c;
            a[i] = down; res.add(new String(a)); a[i] = c;
        }
        return res;
    }
}
```

复杂度：
- 状态空间最多 10^4，边最多约 8×10^4，时间 O(10^4)，空间 O(10^4)。

思考小结：
- 层序 BFS 保证首次到达目标即为最短步数；使用 `visited` 防止重复。

标签：BFS、最短路、状态图
