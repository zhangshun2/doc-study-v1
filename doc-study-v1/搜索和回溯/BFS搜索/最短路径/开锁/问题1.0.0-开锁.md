问题1.0.0 - 开锁（Open the Lock, LeetCode 752）

概述：四位数锁从 "0000" 开始，每次可旋转一位向上或向下，给定死锁组合与目标，求最少步数到达目标。用 BFS 最短路径。

链接：https://leetcode.com/problems/open-the-lock/

题目特征与分析：
- 状态图搜索：每个状态有最多 8 个邻居。
- 禁止状态：需要跳过死锁组合。

知识点：
- BFS 最短路径、状态图建模、邻居生成。

输入输出：
- 输入：`deadends`、`target`。
- 输出：最少步数或 -1。

标签：BFS、最短路径、状态图、搜索与回溯
