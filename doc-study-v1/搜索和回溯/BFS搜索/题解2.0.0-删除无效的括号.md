# 题解2.0.0-删除无效的括号：BFS层次搜索最优解法

## 🎯 解题思路

删除无效的括号是典型的最优化搜索问题。核心思想是：
1. 使用BFS层次搜索，每一层代表删除相同数量的字符
2. 第一次找到有效字符串的层就是最优解（删除字符数最少）
3. 使用Set去重，避免重复处理相同的字符串状态
4. 只删除括号字符，保留所有字母

## 💻 完整代码实现

### 方法一：标准BFS搜索（推荐）

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        Queue<String> queue = new LinkedList<>();
        Set<String> visited = new HashSet<>();
        
        queue.offer(s);
        visited.add(s);
        boolean found = false;
        
        while (!queue.isEmpty() && !found) {
            int size = queue.size();
            
            // 处理当前层的所有状态
            for (int i = 0; i < size; i++) {
                String current = queue.poll();
                
                if (isValid(current)) {
                    result.add(current);
                    found = true;  // 标记找到最优解层
                }
            }
            
            // 如果当前层没找到解，生成下一层状态
            if (!found) {
                // 重新获取当前层的所有元素来生成下一层
                Set<String> currentLevel = new HashSet<>();
                for (int i = 0; i < size; i++) {
                    String current = queue.poll();
                    currentLevel.add(current);
                }
                
                for (String current : currentLevel) {
                    generateNextLevel(current, queue, visited);
                }
            }
        }
        
        return result;
    }
    
    // 判断括号字符串是否有效
    private boolean isValid(String s) {
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                count++;
            } else if (c == ')') {
                count--;
                if (count < 0) return false;  // 右括号过多
            }
            // 字母字符忽略
        }
        return count == 0;  // 左右括号必须平衡
    }
    
    // 生成下一层状态：删除一个括号
    private void generateNextLevel(String s, Queue<String> queue, Set<String> visited) {
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(' || c == ')') {  // 只删除括号
                String next = s.substring(0, i) + s.substring(i + 1);
                if (!visited.contains(next)) {
                    visited.add(next);
                    queue.offer(next);
                }
            }
        }
    }
}
```

### 方法二：优化的BFS（避免重复处理）

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        Queue<String> queue = new LinkedList<>();
        Set<String> visited = new HashSet<>();
        
        queue.offer(s);
        visited.add(s);
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            List<String> currentLevel = new ArrayList<>();
            
            // 收集当前层的所有字符串
            for (int i = 0; i < size; i++) {
                String current = queue.poll();
                currentLevel.add(current);
                
                if (isValid(current)) {
                    result.add(current);
                }
            }
            
            // 如果找到了有效字符串，直接返回（保证最优）
            if (!result.isEmpty()) {
                return result;
            }
            
            // 生成下一层状态
            for (String current : currentLevel) {
                generateNextLevel(current, queue, visited);
            }
        }
        
        return result;
    }
    
    private boolean isValid(String s) {
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                count++;
            } else if (c == ')') {
                count--;
                if (count < 0) return false;
            }
        }
        return count == 0;
    }
    
    private void generateNextLevel(String s, Queue<String> queue, Set<String> visited) {
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(' || s.charAt(i) == ')') {
                String next = s.substring(0, i) + s.substring(i + 1);
                if (!visited.contains(next)) {
                    visited.add(next);
                    queue.offer(next);
                }
            }
        }
    }
}
```

### 方法三：DFS + 剪枝优化

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        
        // 计算需要删除的左右括号数量
        int leftRemove = 0, rightRemove = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                leftRemove++;
            } else if (c == ')') {
                if (leftRemove > 0) {
                    leftRemove--;
                } else {
                    rightRemove++;
                }
            }
        }
        
        dfs(s, 0, leftRemove, rightRemove, 0, new StringBuilder(), result);
        return result;
    }
    
    private void dfs(String s, int index, int leftRemove, int rightRemove, 
                     int open, StringBuilder path, List<String> result) {
        // 递归终止条件
        if (index == s.length()) {
            if (leftRemove == 0 && rightRemove == 0 && open == 0) {
                result.add(path.toString());
            }
            return;
        }
        
        char c = s.charAt(index);
        
        // 选择1：删除当前字符（如果是括号且还需要删除）
        if ((c == '(' && leftRemove > 0) || (c == ')' && rightRemove > 0)) {
            dfs(s, index + 1, 
                leftRemove - (c == '(' ? 1 : 0), 
                rightRemove - (c == ')' ? 1 : 0), 
                open, path, result);
        }
        
        // 选择2：保留当前字符
        path.append(c);
        if (c == '(') {
            dfs(s, index + 1, leftRemove, rightRemove, open + 1, path, result);
        } else if (c == ')' && open > 0) {
            dfs(s, index + 1, leftRemove, rightRemove, open - 1, path, result);
        } else if (c != '(' && c != ')') {
            dfs(s, index + 1, leftRemove, rightRemove, open, path, result);
        }
        path.deleteCharAt(path.length() - 1);  // 回溯
    }
}
```

## 🔍 算法分析

### 时间复杂度
- **BFS方法**：O(2^n)，最坏情况下需要尝试删除每个括号
- **DFS方法**：O(2^n)，但剪枝效果更好
- n为字符串长度

### 空间复杂度
- **BFS方法**：O(2^n)，队列和visited集合的空间
- **DFS方法**：O(n)，递归栈空间

## 🚀 优化技巧

### 1. 预计算删除数量
```java
private int[] calculateRemoveCount(String s) {
    int leftRemove = 0, rightRemove = 0;
    for (char c : s.toCharArray()) {
        if (c == '(') {
            leftRemove++;
        } else if (c == ')') {
            if (leftRemove > 0) {
                leftRemove--;
            } else {
                rightRemove++;
            }
        }
    }
    return new int[]{leftRemove, rightRemove};
}
```

### 2. 避免重复删除
```java
private void generateNextLevel(String s, Queue<String> queue, Set<String> visited) {
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (c == '(' || c == ')') {
            // 避免删除连续相同的括号产生重复结果
            if (i > 0 && s.charAt(i) == s.charAt(i - 1)) continue;
            
            String next = s.substring(0, i) + s.substring(i + 1);
            if (!visited.contains(next)) {
                visited.add(next);
                queue.offer(next);
            }
        }
    }
}
```

### 3. 双向BFS优化
```java
public List<String> removeInvalidParentheses(String s) {
    // 从两个方向同时搜索，减少搜索空间
    Set<String> forward = new HashSet<>();
    Set<String> backward = new HashSet<>();
    forward.add(s);
    
    while (!forward.isEmpty()) {
        // 检查当前层是否有有效字符串
        for (String str : forward) {
            if (isValid(str)) {
                return new ArrayList<>(forward);
            }
        }
        
        // 生成下一层
        Set<String> nextLevel = new HashSet<>();
        for (String str : forward) {
            generateNextLevel(str, nextLevel);
        }
        forward = nextLevel;
    }
    
    return new ArrayList<>();
}
```

## 🎯 核心要点总结

### BFS搜索模板
1. **层次遍历**：每层代表删除相同数量的字符
2. **最优性保证**：第一次找到有效字符串的层就是最优解
3. **状态去重**：使用Set避免重复处理
4. **状态生成**：从当前字符串删除一个括号

### 关键技巧
- **有效性检查**：计数法判断括号是否平衡
- **只删除括号**：保留所有字母字符
- **去重优化**：避免处理重复状态

### 算法选择
- **BFS**：保证找到最优解，代码清晰
- **DFS**：剪枝效果好，空间效率高
- **预处理**：提前计算删除数量，减少搜索空间
