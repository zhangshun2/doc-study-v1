# 问题1.0.0-腐烂的橘子：最短时间使所有橘子腐烂（多源BFS）

## 问题描述
在一个 `m×n` 的网格中：
- `0` 表示空单元格
- `1` 表示新鲜橘子
- `2` 表示腐烂橘子

每分钟，腐烂橘子会使其上下左右相邻的新鲜橘子腐烂。求使所有橘子腐烂所需的最短分钟数；若无法全部腐烂，返回 `-1`。

## 输入输出
- 输入：二维整数数组 `grid`
- 输出：整数，最短分钟数或 `-1`

## 示例
```plain
输入：[[2,1,1],[1,1,0],[0,1,1]]
输出：4
```

## 特征提炼
- 传播模型：层次扩张，天然适合 BFS
- 多源起点：初始所有 `2` 同时为腐烂源头
- 终止条件：新鲜橘子数归零；若被隔离则无法传播

## 思路引导
- 将所有腐烂橘子入队作为第 0 分钟层；统计新鲜橘子数量
- 按层出队，向四邻传播，腐烂新鲜橘子并入队下一层
- 记录最后一次腐烂发生的分钟数；若结束后仍有新鲜橘子，返回 `-1`

## 可能涉及的知识点
- 多源 BFS（同时入队）
- 层次遍历与时间刻度同步
- 边界与越界检查

## 复杂度预期
- 时间：O(mn)
- 空间：O(mn)（队列与访问标记）

## 学习重点
- 多源起点如何初始化与计时
- 层序 BFS 与“时间”的一一对应
- 无法腐烂的判定逻辑与实现细节
