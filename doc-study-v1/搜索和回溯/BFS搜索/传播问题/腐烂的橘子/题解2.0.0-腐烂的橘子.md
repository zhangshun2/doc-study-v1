题解2.0.0 - 腐烂的橘子（Rotting Oranges, LeetCode 994）

概述：多源 BFS。将所有腐烂橘子入队，层序扩散使相邻新鲜橘子腐烂；统计时间与剩余新鲜橘子。

题解一：多源 BFS（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> q = new ArrayDeque<>();
        int fresh = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) q.offer(new int[]{i, j});
                else if (grid[i][j] == 1) fresh++;
            }
        }
        if (fresh == 0) return 0;
        int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
        int time = 0;
        while (!q.isEmpty() && fresh > 0) {
            for (int sz = q.size(); sz > 0; sz--) {
                int[] cur = q.poll();
                for (int[] mv : d) {
                    int nx = cur[0] + mv[0], ny = cur[1] + mv[1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    if (grid[nx][ny] == 1) {
                        grid[nx][ny] = 2;
                        fresh--;
                        q.offer(new int[]{nx, ny});
                    }
                }
            }
            time++;
        }
        return fresh == 0 ? time : -1;
    }
}
```

复杂度：
- O(m·n)，空间 O(m·n)。

思考小结：
- 多源入队与层次推进即可自然求得最短时间。
