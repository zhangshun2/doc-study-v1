# 问题1.0.0 扫雷游戏（LeetCode-529）

- 难度：中等
- 链接：https://leetcode.cn/problems/minesweeper/

## 概述
给定扫雷棋盘与一次点击坐标，按照扫雷规则更新棋盘：点击雷则变 `X`；点击空格则显示相邻雷数，若为 `0` 则递归展开邻居。

## 问题特征与分析引导
- 邻域：使用 8 个方向统计相邻雷数。
- 展开规则：相邻雷数为 0 时标记为 `B` 并继续向外展开；否则显示数字并停止。
- 访问控制：只在 `E`（未揭示空格）上展开，避免重复访问。

## 可能涉及的知识点
- DFS/BFS 的 8 邻域处理
- 递归展开与边界判断
