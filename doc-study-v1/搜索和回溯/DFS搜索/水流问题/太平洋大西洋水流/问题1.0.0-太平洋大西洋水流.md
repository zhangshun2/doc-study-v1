问题1.0.0 - 太平洋大西洋水流（Pacific Atlantic Water Flow, LeetCode 417）

概述：给定高度矩阵，水能从高到低或相同高度向四邻流动。求同时能流到太平洋与大西洋的坐标。逆向思维：从海岸向内 DFS/BFS，按高度非降扩展。

链接：https://leetcode.com/problems/pacific-atlantic-water-flow/

题目特征与分析：
- 逆向可达性：从边界出发，满足 `nextHeight >= currentHeight`。
- 两次搜索：分别标记能到太平洋与大西洋，取交集。

知识点：
- DFS/BFS 可达性、逆向扩展、网格搜索。

输入输出：
- 输入：高度矩阵 `heights`。
- 输出：坐标列表。

标签：DFS、BFS、可达性、网格、搜索与回溯
