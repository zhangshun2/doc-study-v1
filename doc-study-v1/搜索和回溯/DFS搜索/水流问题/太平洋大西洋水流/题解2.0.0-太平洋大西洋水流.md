题解2.0.0 - 太平洋大西洋水流（Pacific Atlantic Water Flow, LeetCode 417）

概述：分别从两海岸线作为多源起点（左/上为太平洋，右/下为大西洋）进行 DFS，按高度非降扩展，最后取两者交集。

题解一：双源 DFS（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    private int m, n;
    private int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        m = heights.length; n = heights[0].length;
        boolean[][] pac = new boolean[m][n];
        boolean[][] atl = new boolean[m][n];
        for (int i = 0; i < m; i++) { dfs(heights, pac, i, 0, -1); dfs(heights, atl, i, n - 1, -1); }
        for (int j = 0; j < n; j++) { dfs(heights, pac, 0, j, -1); dfs(heights, atl, m - 1, j, -1); }
        List<List<Integer>> ans = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (pac[i][j] && atl[i][j]) ans.add(Arrays.asList(i, j));
            }
        }
        return ans;
    }
    private void dfs(int[][] h, boolean[][] vis, int x, int y, int prev) {
        if (x < 0 || x >= m || y < 0 || y >= n || vis[x][y] || h[x][y] < prev) return;
        vis[x][y] = true;
        for (int[] mv : d) dfs(h, vis, x + mv[0], y + mv[1], h[x][y]);
    }
}
```

复杂度：
- O(R·C)，空间 O(R·C)。

思考小结：
- 从海向内做非降扩展等价于从高处向海水可达判定。

标签：DFS、可达性、网格
