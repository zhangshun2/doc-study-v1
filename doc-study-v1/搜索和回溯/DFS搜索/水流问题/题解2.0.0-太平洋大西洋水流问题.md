# 题解2.0.0 太平洋大西洋水流问题（LeetCode-417）

## 题解一：官方经典（双 DFS 反向标记）
- 思路：从太平洋边界与大西洋边界分别出发，反向条件为 `nextHeight >= curHeight`；最终收集两者都为真处。
- 复杂度：时间 O(m·n)，空间 O(m·n)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1, 0, -1, 0, 1};
    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        boolean[][] p = new boolean[m][n], a = new boolean[m][n];
        for (int i = 0; i < m; i++) { dfs(heights, p, i, 0); dfs(heights, a, i, n - 1); }
        for (int j = 0; j < n; j++) { dfs(heights, p, 0, j); dfs(heights, a, m - 1, j); }
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) if (p[i][j] && a[i][j]) res.add(Arrays.asList(i, j));
        return res;
    }
    private void dfs(int[][] h, boolean[][] vis, int x, int y) {
        if (vis[x][y]) return; vis[x][y] = true;
        for (int d = 0; d < 4; d++) {
            int nx = x + DIR[d], ny = y + DIR[d + 1];
            if (nx < 0 || nx >= h.length || ny < 0 || ny >= h[0].length) continue;
            if (h[nx][ny] >= h[x][y]) dfs(h, vis, nx, ny);
        }
    }
}
```

## 题解二：通用解法（双 BFS 反向标记）
- 标签：多源 BFS、反向可达、边界
- 思路：海岸线作为初始队列，层次扩展满足 `nextHeight >= curHeight` 的邻居。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1, 0, -1, 0, 1};
    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        boolean[][] p = new boolean[m][n], a = new boolean[m][n];
        Deque<int[]> qp = new ArrayDeque<>(), qa = new ArrayDeque<>();
        for (int i = 0; i < m; i++) { qp.offer(new int[]{i, 0}); p[i][0] = true; qa.offer(new int[]{i, n - 1}); a[i][n - 1] = true; }
        for (int j = 0; j < n; j++) { qp.offer(new int[]{0, j}); p[0][j] = true; qa.offer(new int[]{m - 1, j}); a[m - 1][j] = true; }
        bfs(heights, p, qp); bfs(heights, a, qa);
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) if (p[i][j] && a[i][j]) res.add(Arrays.asList(i, j));
        return res;
    }
    private void bfs(int[][] h, boolean[][] vis, Deque<int[]> q) {
        int m = h.length, n = h[0].length;
        while (!q.isEmpty()) {
            int[] cur = q.poll(); int x = cur[0], y = cur[1];
            for (int d = 0; d < 4; d++) {
                int nx = x + DIR[d], ny = y + DIR[d + 1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n || vis[nx][ny]) continue;
                if (h[nx][ny] >= h[x][y]) { vis[nx][ny] = true; q.offer(new int[]{nx, ny}); }
            }
        }
    }
}
```

## 题解三：最好理解（“从海边逆流而上，能被两边到达的格子”）
- 直觉：从两条海岸线同时逆流标记，最终取交集。

## 总结思路
- 反向思考能把复杂条件转为简单的可达性；双可达交集即答案。
