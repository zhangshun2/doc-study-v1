# 问题1.0.0 太平洋大西洋水流问题（LeetCode-417）

- 难度：中等
- 链接：https://leetcode.cn/problems/pacific-atlantic-water-flow/

## 概述
给定高度矩阵，水从高处流向低处或相同高度。求所有既能流到太平洋（上边/左边）又能流到大西洋（下边/右边）的坐标。

## 问题特征与分析引导
- 反向搜索：与其从每个格子向外试，不如从海岸线向内“反向流动”（只从低到高或相等），标记可达。
- 双可达：分别标记太平洋可达与大西洋可达，取两者交集。
- 状态：`visitedP` 与 `visitedA` 两个布尔矩阵。

## 可能涉及的知识点
- 多源 DFS/BFS 的反向思考
- 边界初始化与方向条件
