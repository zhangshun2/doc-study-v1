# 问题1.0.0 岛屿数量（LeetCode-200）

- 难度：中等
- 链接：https://leetcode.cn/problems/number-of-islands/

## 概述
给定由 `'1'`（陆地）和 `'0'`（水域）构成的二维网格，计算岛屿的数量。岛屿由相邻（上下左右）陆地单元格连接而成。

## 问题特征与分析引导
- 搜索结构：网格图搜索，典型 DFS/BFS；访问到一个陆地后需要整块“淹没”。
- 计数策略：每次从未访问的陆地启动一次搜索，完成即计数 +1。
- 状态维护：可用原地修改或 `visited` 标记避免重复访问。

## 可能涉及的知识点
- 网格 DFS/BFS 的边界判断与访问标记
- 原地修改与回退的取舍（本题无需回退，直接“淹没”）
- 并查集（Union-Find）作为替代方案
