# 题解2.0.0 飞地的数量（LeetCode-1020）

## 题解一：官方经典（边界多源 BFS）
- 思路：把位于边界的所有陆地入队，向内扩张并标记为海洋；最后统计剩余陆地个数。
- 复杂度：时间 O(m·n)，空间 O(m·n)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int numEnclaves(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Deque<int[]> q = new ArrayDeque<>();
        // 边界入队
        for (int i = 0; i < m; i++) {
            if (grid[i][0] == 1) { q.offer(new int[]{i, 0}); grid[i][0] = 0; }
            if (grid[i][n-1] == 1) { q.offer(new int[]{i, n-1}); grid[i][n-1] = 0; }
        }
        for (int j = 0; j < n; j++) {
            if (grid[0][j] == 1) { q.offer(new int[]{0, j}); grid[0][j] = 0; }
            if (grid[m-1][j] == 1) { q.offer(new int[]{m-1, j}); grid[m-1][j] = 0; }
        }
        while (!q.isEmpty()) {
            int[] cur = q.poll(); int x = cur[0], y = cur[1];
            for (int d = 0; d < 4; d++) {
                int nx = x + DIR[d], ny = y + DIR[d+1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n || grid[nx][ny] != 1) continue;
                grid[nx][ny] = 0; q.offer(new int[]{nx, ny});
            }
        }
        int ans = 0;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) if (grid[i][j] == 1) ans++;
        return ans;
    }
}
```

## 题解二：通用解法（DFS 淹没）
- 标签：DFS、边界、淹没
- 思路：先 DFS 淹没所有与边界连通的陆地，再统计剩余陆地。

## 题解三：最好理解（“把能到边的陆地冲走，剩下的就是飞地”）
- 直觉：边界出发，凡是能连过去的都不计入飞地。

## 总结思路
- 边界泛洪是关键；最后计数即可。
