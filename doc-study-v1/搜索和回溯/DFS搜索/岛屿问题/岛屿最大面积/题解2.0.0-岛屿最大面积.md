题解2.0.0 - 岛屿最大面积（Max Area of Island, LeetCode 695）

概述：遍历网格，遇到 1 启动 DFS 统计该连通块面积并更新最大值。访问过的格设为 0 表示淹没。

题解一：DFS 统计面积（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    private int rows, cols;
    public int maxAreaOfIsland(int[][] grid) {
        rows = grid.length; cols = grid[0].length;
        int best = 0;
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == 1) best = Math.max(best, dfs(grid, i, j));
            }
        }
        return best;
    }
    private int dfs(int[][] g, int x, int y) {
        if (x < 0 || x >= rows || y < 0 || y >= cols || g[x][y] == 0) return 0;
        g[x][y] = 0;
        int area = 1;
        area += dfs(g, x + 1, y);
        area += dfs(g, x - 1, y);
        area += dfs(g, x, y + 1);
        area += dfs(g, x, y - 1);
        return area;
    }
}
```

复杂度：
- O(R·C)，空间 O(1) 原地标记。

思考小结：
- 与 200 题类似，返回值变为最大连通块大小。

标签：DFS、网格、连通块面积
