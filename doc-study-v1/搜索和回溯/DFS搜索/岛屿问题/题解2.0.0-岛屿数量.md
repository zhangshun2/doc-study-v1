# 题解2.0.0 岛屿数量（LeetCode-200）

## 题解一：官方经典（DFS 淹没法）
- 思路：遍历网格，遇到 `'1'` 计数 +1 并用 DFS 将整块陆地改为 `'0'`（原地标记），防止二次计数。
- 复杂度：时间 O(m·n)，空间 O(m·n)（递归栈最坏）。

```java
import java.util.*;
class Solution {
    public int numIslands(char[][] grid) {
        int m = grid.length, n = grid[0].length, ans = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '1') { ans++; dfs(grid, i, j); }
            }
        }
        return ans;
    }
    private void dfs(char[][] g, int x, int y) {
        if (x < 0 || x >= g.length || y < 0 || y >= g[0].length || g[x][y] != '1') return;
        g[x][y] = '0';
        dfs(g, x + 1, y); dfs(g, x - 1, y); dfs(g, x, y + 1); dfs(g, x, y - 1);
    }
}
```

## 题解二：通用解法（BFS 队列）
- 标签：网格、BFS、回溯、原地标记
- 思路：遇到 `'1'` 入队并原地改为 `'0'`，层次扩展四邻陆地，整块淹没后计数完成。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1, 0, -1, 0, 1};
    public int numIslands(char[][] grid) {
        int m = grid.length, n = grid[0].length, ans = 0;
        Deque<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (grid[i][j] != '1') continue;
            ans++; grid[i][j] = '0'; q.offer(new int[]{i, j});
            while (!q.isEmpty()) {
                int[] cur = q.poll(); int x = cur[0], y = cur[1];
                for (int d = 0; d < 4; d++) {
                    int nx = x + DIR[d], ny = y + DIR[d + 1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    if (grid[nx][ny] == '1') { grid[nx][ny] = '0'; q.offer(new int[]{nx, ny}); }
                }
            }
        }
        return ans;
    }
}
```

## 题解三：并查集（Union-Find）
- 直觉：把所有陆地点作为节点，连接相邻陆地，最终统计不重复的连通块数量。

```java
import java.util.*;
class Solution {
    public int numIslands(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] parent = new int[m * n]; Arrays.fill(parent, -1);
        int count = 0;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (grid[i][j] == '1') { int id = i * n + j; parent[id] = id; count++; }
        }
        int[] DIR = {1, 0, -1, 0, 1};
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (grid[i][j] != '1') continue;
            int id = i * n + j;
            for (int d = 0; d < 4; d++) {
                int ni = i + DIR[d], nj = j + DIR[d + 1];
                if (ni < 0 || ni >= m || nj < 0 || nj >= n || grid[ni][nj] != '1') continue;
                int nid = ni * n + nj;
                count -= union(parent, id, nid);
            }
        }
        return count;
    }
    private int find(int[] p, int x) { return p[x] == x ? x : (p[x] = find(p, p[x])); }
    private int union(int[] p, int a, int b) {
        int pa = find(p, a), pb = find(p, b);
        if (pa == pb) return 0; p[pa] = pb; return 1;
    }
}
```

## 总结思路
- DFS/BFS 原地淹没最直观；并查集适合需要连通块数量的场景。边界与访问标记是关键。
