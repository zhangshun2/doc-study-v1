# 题解2.0.0 岛屿的最大面积（LeetCode-695）

## 题解一：官方经典（DFS 面积累加）
- 思路：遇到 `1` 触发 DFS，递归累计面积并原地改为 `0`；维护全局最大值。
- 复杂度：时间 O(m·n)，空间 O(m·n)。

```java
import java.util.*;
class Solution {
    public int maxAreaOfIsland(int[][] grid) {
        int m = grid.length, n = grid[0].length, best = 0;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (grid[i][j] == 1) best = Math.max(best, dfs(grid, i, j));
        }
        return best;
    }
    private int dfs(int[][] g, int x, int y) {
        if (x < 0 || x >= g.length || y < 0 || y >= g[0].length || g[x][y] != 1) return 0;
        g[x][y] = 0; // 原地标记
        return 1 + dfs(g, x + 1, y) + dfs(g, x - 1, y) + dfs(g, x, y + 1) + dfs(g, x, y - 1);
    }
}
```

## 题解二：通用解法（BFS 面积累加）
- 标签：网格、BFS、面积累计
- 思路：队列扩展，统计每次出队的单元数作为当前岛屿面积。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1, 0, -1, 0, 1};
    public int maxAreaOfIsland(int[][] g) {
        int m = g.length, n = g[0].length, best = 0;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (g[i][j] != 1) continue;
            int area = 0; Deque<int[]> q = new ArrayDeque<>();
            g[i][j] = 0; q.offer(new int[]{i, j});
            while (!q.isEmpty()) {
                int[] cur = q.poll(); area++; int x = cur[0], y = cur[1];
                for (int d = 0; d < 4; d++) {
                    int nx = x + DIR[d], ny = y + DIR[d + 1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    if (g[nx][ny] == 1) { g[nx][ny] = 0; q.offer(new int[]{nx, ny}); }
                }
            }
            best = Math.max(best, area);
        }
        return best;
    }
}
```

## 题解三：最好理解（“淹没时顺便计数”）
- 直觉：把一整块岛淹没，淹没多少格就是它的面积，维护最大即可。
