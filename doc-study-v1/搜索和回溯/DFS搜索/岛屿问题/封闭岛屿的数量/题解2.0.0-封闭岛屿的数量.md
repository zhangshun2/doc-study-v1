# 题解2.0.0 封闭岛屿的数量（LeetCode-1254）

## 题解一：官方经典（先清边界再计数）
- 思路：先把所有与边界相连的 `0` 变为 `1`；随后对每个剩余 `0` 做一次 DFS/BFS 并计数。
- 复杂度：时间 O(m·n)，空间 O(m·n)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int closedIsland(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 清理边界相连的 0
        for (int i = 0; i < m; i++) { dfs(grid, i, 0); dfs(grid, i, n-1); }
        for (int j = 0; j < n; j++) { dfs(grid, 0, j); dfs(grid, m-1, j); }
        int ans = 0;
        for (int i = 1; i < m-1; i++) for (int j = 1; j < n-1; j++) if (grid[i][j] == 0) { ans++; dfs(grid, i, j); }
        return ans;
    }
    private void dfs(int[][] g, int x, int y) {
        int m = g.length, n = g[0].length;
        if (x < 0 || x >= m || y < 0 || y >= n || g[x][y] == 1) return;
        g[x][y] = 1;
        for (int d = 0; d < 4; d++) dfs(g, x + DIR[d], y + DIR[d+1]);
    }
}
```

## 题解二：通用解法（返回闭合性 DFS）
- 标签：DFS、判断闭合
- 思路：DFS 返回布尔值，若触及边界则为非闭合；合并子结果判断整块是否闭合。

## 题解三：最好理解（“把靠边的清掉，剩下的里侧岛就是答案”）
- 直觉：从边界出发淹没，内部剩余的都是封闭岛屿。

## 总结思路
- 两步法高效可靠：清边界 + 计数。
