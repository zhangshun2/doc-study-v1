题解2.0.0 - 岛屿数量（Number of Islands, LeetCode 200）

概述：遍历网格，遇到 '1' 启动 DFS/BFS 将其所在连通块全部标为 '0'，并计数 +1。

题解一：DFS 洪水填充（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    private int rows, cols;
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        rows = grid.length; cols = grid[0].length;
        int count = 0;
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == '1') {
                    dfs(grid, i, j);
                    count++;
                }
            }
        }
        return count;
    }
    private void dfs(char[][] g, int x, int y) {
        if (x < 0 || x >= rows || y < 0 || y >= cols || g[x][y] != '1') return;
        g[x][y] = '0';
        dfs(g, x + 1, y);
        dfs(g, x - 1, y);
        dfs(g, x, y + 1);
        dfs(g, x, y - 1);
    }
}
```

复杂度：
- O(R·C)，空间 O(1)（原地标记）。

思考小结：
- 原地淹没简洁高效；BFS 也可等价实现。
