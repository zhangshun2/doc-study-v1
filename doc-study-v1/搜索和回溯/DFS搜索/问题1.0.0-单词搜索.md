# 问题1.0.0-单词搜索：二维网格中的路径搜索

## 📋 题目信息

**LeetCode 79. 单词搜索**  
**难度：** 中等  
**链接：** [🔗](https://leetcode.cn/problems/word-search/)

## 🎯 问题描述

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` ，如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中"相邻"单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

## 📝 示例分析

### 示例 1
```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
输出：true

网格可视化：
A → B → C ↓
S   F   C   S
A   D   E ← E
```

### 示例 2
```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
输出：true

路径：S → E → E
```

### 示例 3
```
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
输出：false

解释：无法形成有效路径，因为不能重复使用同一个单元格
```

## 🔍 问题特征分析

### 核心特征
1. **二维网格搜索**：在二维字符数组中寻找路径
2. **路径约束**：只能通过相邻（上下左右）单元格移动
3. **访问限制**：同一单元格不能重复访问
4. **顺序匹配**：必须按照单词的字母顺序匹配

### 搜索特点
- **深度优先搜索（DFS）**：需要探索所有可能的路径
- **回溯机制**：当路径不匹配时需要回退并尝试其他方向
- **状态管理**：需要记录已访问的单元格，避免重复访问

### 约束条件
- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

## 🧠 解题思路引导

### 思路分析
1. **起点选择**：遍历网格，找到与单词首字母匹配的位置作为起点
2. **DFS搜索**：从起点开始，向四个方向（上下左右）递归搜索
3. **匹配验证**：检查当前位置字符是否与目标字符匹配
4. **边界处理**：检查坐标是否越界，是否已访问
5. **回溯操作**：搜索失败时恢复访问状态

### 关键问题
1. **如何避免重复访问？** 使用visited数组或原地标记
2. **如何进行四方向搜索？** 使用方向数组或直接枚举
3. **何时进行回溯？** 当前路径搜索完成后恢复状态
4. **如何判断搜索成功？** 当匹配字符数等于单词长度

## 🎨 算法设计要点

### DFS搜索框架
```java
boolean dfs(char[][] board, String word, int index, int i, int j, boolean[][] visited) {
    // 1. 成功条件：匹配完整个单词
    if (index == word.length()) return true;
    
    // 2. 边界检查：越界、已访问、字符不匹配
    if (i < 0 || i >= m || j < 0 || j >= n || visited[i][j] || board[i][j] != word.charAt(index)) {
        return false;
    }
    
    // 3. 标记访问
    visited[i][j] = true;
    
    // 4. 四方向递归搜索
    boolean found = dfs(board, word, index + 1, i + 1, j, visited) ||
                   dfs(board, word, index + 1, i - 1, j, visited) ||
                   dfs(board, word, index + 1, i, j + 1, visited) ||
                   dfs(board, word, index + 1, i, j - 1, visited);
    
    // 5. 回溯：恢复访问状态
    visited[i][j] = false;
    
    return found;
}
```

### 优化考虑
1. **原地标记**：直接修改board数组，避免额外空间
2. **早期剪枝**：字符不匹配时立即返回
3. **方向数组**：使用dx、dy数组简化方向遍历
