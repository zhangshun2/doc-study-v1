# 问题1.0.0 被围绕的区域（LeetCode-130）

- 难度：中等
- 链接：https://leetcode.cn/problems/surrounded-regions/

## 概述
`X/O` 网格中，将所有被 `X` 完全包围的 `O` 改为 `X`。与边界相连（直接或间接）的 `O` 不改变。

## 问题特征与分析引导
- 关键观察：只要 `O` 能与边界上的 `O` 连通，就不应被翻转。
- 搜索策略：从所有边界上的 `O` 出发做 DFS/BFS，把连通的 `O` 标记为“安全”，最后将未标记的 `O` 翻转为 `X`。
- 状态：原地临时标记（如 `'#'`）或 `visited` 数组。

## 可能涉及的知识点
- 边界多源搜索（DFS/BFS）
- 原地标记与后处理翻转
- 并查集作为替代方案（虚拟边界节点）
