# 题解2.0.0 被围绕的区域（LeetCode-130）

## 题解一：官方经典（边界多源 DFS + 原地标记）
- 思路：从四条边上的 `O` 启动 DFS，将连通的 `O` 改为 `'#'`；遍历全图，把 `O` 翻转为 `X`，把 `'#'` 还原为 `O`。
- 复杂度：时间 O(m·n)，空间 O(m·n)。

```java
import java.util.*;
class Solution {
    public void solve(char[][] board) {
        int m = board.length, n = board[0].length;
        for (int i = 0; i < m; i++) {
            if (board[i][0] == 'O') dfs(board, i, 0);
            if (board[i][n - 1] == 'O') dfs(board, i, n - 1);
        }
        for (int j = 0; j < n; j++) {
            if (board[0][j] == 'O') dfs(board, 0, j);
            if (board[m - 1][j] == 'O') dfs(board, m - 1, j);
        }
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (board[i][j] == 'O') board[i][j] = 'X';
            else if (board[i][j] == '#') board[i][j] = 'O';
        }
    }
    private void dfs(char[][] b, int x, int y) {
        if (x < 0 || x >= b.length || y < 0 || y >= b[0].length || b[x][y] != 'O') return;
        b[x][y] = '#'; dfs(b, x + 1, y); dfs(b, x - 1, y); dfs(b, x, y + 1); dfs(b, x, y - 1);
    }
}
```

## 题解二：通用解法（BFS）
- 标签：多源 BFS、边界、翻转
- 思路：将边界所有 `O` 入队并标记，层次扩展，最后统一翻转。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1, 0, -1, 0, 1};
    public void solve(char[][] b) {
        int m = b.length, n = b[0].length; Deque<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < m; i++) {
            if (b[i][0] == 'O') { b[i][0] = '#'; q.offer(new int[]{i, 0}); }
            if (b[i][n - 1] == 'O') { b[i][n - 1] = '#'; q.offer(new int[]{i, n - 1}); }
        }
        for (int j = 0; j < n; j++) {
            if (b[0][j] == 'O') { b[0][j] = '#'; q.offer(new int[]{0, j}); }
            if (b[m - 1][j] == 'O') { b[m - 1][j] = '#'; q.offer(new int[]{m - 1, j}); }
        }
        while (!q.isEmpty()) {
            int[] cur = q.poll(); int x = cur[0], y = cur[1];
            for (int d = 0; d < 4; d++) {
                int nx = x + DIR[d], ny = y + DIR[d + 1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n || b[nx][ny] != 'O') continue;
                b[nx][ny] = '#'; q.offer(new int[]{nx, ny});
            }
        }
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (b[i][j] == 'O') b[i][j] = 'X'; else if (b[i][j] == '#') b[i][j] = 'O';
        }
    }
}
```

## 题解三：并查集（虚拟边界）
- 直觉：给边界一个虚拟根，所有与边界连通的 `O` 与它联通；最终将不与虚拟根同集合的 `O` 翻转为 `X`。

## 总结思路
- 从边界出发的多源搜索最直观；并查集可作为思维替代。
