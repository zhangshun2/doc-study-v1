问题1.0.0 - 不同路径 III（Unique Paths III, LeetCode 980）

概述：在网格中从起点到终点，要求恰好访问每个非障碍格一次，统计这样的路径数。用 DFS 回溯计数，维护剩余可访问单元的计数。

链接：https://leetcode.com/problems/unique-paths-iii/

题目特征与分析：
- 网格回溯计数：每次移动到未访问的有效格。
- 计数约束：到达终点时剩余计数必须为 0 才计入答案。

知识点：
- DFS 回溯、状态恢复、网格遍历。

输入输出：
- 输入：网格，-1 障碍，0 空地，1 起点，2 终点。
- 输出：有效路径总数。

标签：DFS、回溯、网格搜索、搜索与回溯
