题解2.0.0 - 不同路径 III（Unique Paths III, LeetCode 980）

概述：计数型回溯。先统计可访问的非障碍格数量（含起点、终点），DFS 过程中每访问一个格减少计数，抵达终点时计数为 0 才记入答案。

题解一：DFS 回溯计数（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    private int rows, cols;
    private int targetCount;
    private int ans = 0;

    public int uniquePathsIII(int[][] grid) {
        rows = grid.length; cols = grid[0].length;
        int sx = 0, sy = 0;
        targetCount = 0;
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] != -1) targetCount++; // 可访问含起终点
                if (grid[i][j] == 1) { sx = i; sy = j; }
            }
        }
        dfs(grid, sx, sy, 1); // 起点已访问计数1
        return ans;
    }

    private void dfs(int[][] g, int x, int y, int visited) {
        if (g[x][y] == 2) { // 终点
            if (visited == targetCount) ans++;
            return;
        }
        int t = g[x][y];
        g[x][y] = -1; // 标记访问
        int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
        for (int[] mv : d) {
            int nx = x + mv[0], ny = y + mv[1];
            if (nx < 0 || nx >= rows || ny < 0 || ny >= cols) continue;
            if (g[nx][ny] == 0 || g[nx][ny] == 2) {
                dfs(g, nx, ny, visited + 1);
            }
        }
        g[x][y] = t; // 恢复
    }
}
```

复杂度：
- 最坏情况下指数级，但障碍与终点约束显著剪枝；网格较小可接受。

思考小结：
- 用“剩余/已访问计数”作为全局约束，避免重复路径计数。

标签：DFS、回溯、网格计数
