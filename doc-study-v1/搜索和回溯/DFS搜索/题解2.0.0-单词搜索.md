# 题解2.0.0-单词搜索：DFS深度优先搜索完整解法

## 🎯 解题思路

单词搜索是典型的二维网格DFS搜索问题。核心思想是：
1. 遍历网格找到单词首字母作为起点
2. 从起点开始DFS搜索，向四个方向递归
3. 使用visited数组避免重复访问
4. 搜索完成后回溯恢复状态

## 💻 完整代码实现

### 方法一：标准DFS + visited数组

```java
class Solution {
    private int m, n;
    private int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
    
    public boolean exist(char[][] board, String word) {
        m = board.length;
        n = board[0].length;
        boolean[][] visited = new boolean[m][n];
        
        // 遍历网格，寻找起点
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == word.charAt(0)) {
                    if (dfs(board, word, 0, i, j, visited)) {
                        return true;
                    }
                }
            }
        }
        return false;
    }
    
    private boolean dfs(char[][] board, String word, int index, int i, int j, boolean[][] visited) {
        // 成功条件：匹配完整个单词
        if (index == word.length()) {
            return true;
        }
        
        // 边界检查
        if (i < 0 || i >= m || j < 0 || j >= n || 
            visited[i][j] || board[i][j] != word.charAt(index)) {
            return false;
        }
        
        // 标记当前位置已访问
        visited[i][j] = true;
        
        // 四方向递归搜索
        for (int[] dir : directions) {
            int newI = i + dir[0];
            int newJ = j + dir[1];
            if (dfs(board, word, index + 1, newI, newJ, visited)) {
                visited[i][j] = false; // 恢复状态
                return true;
            }
        }
        
        // 回溯：恢复访问状态
        visited[i][j] = false;
        return false;
    }
}
```

### 方法二：原地标记优化（推荐）

```java
class Solution {
    private int m, n;
    
    public boolean exist(char[][] board, String word) {
        m = board.length;
        n = board[0].length;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, word, 0, i, j)) {
                    return true;
                }
            }
        }
        return false;
    }
    
    private boolean dfs(char[][] board, String word, int index, int i, int j) {
        // 成功条件
        if (index == word.length()) return true;
        
        // 边界检查
        if (i < 0 || i >= m || j < 0 || j >= n || board[i][j] != word.charAt(index)) {
            return false;
        }
        
        // 原地标记：保存原字符并标记为已访问
        char temp = board[i][j];
        board[i][j] = '#'; // 标记已访问
        
        // 四方向递归搜索
        boolean found = dfs(board, word, index + 1, i + 1, j) ||
                       dfs(board, word, index + 1, i - 1, j) ||
                       dfs(board, word, index + 1, i, j + 1) ||
                       dfs(board, word, index + 1, i, j - 1);
        
        // 回溯：恢复原字符
        board[i][j] = temp;
        
        return found;
    }
}
```

## 🔍 算法分析

### 时间复杂度
- **最坏情况**：O(M × N × 4^L)
  - M × N：遍历所有起点
  - 4^L：每个位置最多4个方向，最大深度为L（单词长度）
- **实际情况**：由于剪枝，通常远小于最坏情况

### 空间复杂度
- **方法一**：O(M × N + L)，visited数组 + 递归栈
- **方法二**：O(L)，仅递归栈空间

## 🚀 优化技巧

### 1. 早期剪枝
```java
// 在开始搜索前检查字符频率
private boolean canFormWord(char[][] board, String word) {
    Map<Character, Integer> boardCount = new HashMap<>();
    Map<Character, Integer> wordCount = new HashMap<>();
    
    // 统计board中字符频率
    for (char[] row : board) {
        for (char c : row) {
            boardCount.put(c, boardCount.getOrDefault(c, 0) + 1);
        }
    }
    
    // 统计word中字符频率
    for (char c : word.toCharArray()) {
        wordCount.put(c, wordCount.getOrDefault(c, 0) + 1);
    }
    
    // 检查是否有足够的字符
    for (char c : wordCount.keySet()) {
        if (boardCount.getOrDefault(c, 0) < wordCount.get(c)) {
            return false;
        }
    }
    return true;
}
```

// 从两端开始搜索，选择较少起点的方向
public boolean exist(char[][] board, String word) {
    if (word == null || word.length() == 0) return true;
    
    // 统计首尾字符在board中的出现次数
    char first = word.charAt(0);
    char last = word.charAt(word.length() - 1);
    int firstCount = 0, lastCount = 0;
    
    for (char[] row : board) {
        for (char c : row) {
            if (c == first) firstCount++;
            if (c == last) lastCount++;
        }
    }
    
    // 选择出现次数较少的字符作为起点
    if (firstCount > lastCount) {
        word = new StringBuilder(word).reverse().toString();
    }
    
    // 继续正常搜索...
}

## 🎯 核心要点总结

### DFS搜索模板
1. **递归终止条件**：匹配完整个单词
2. **边界检查**：越界、已访问、字符不匹配
3. **状态标记**：标记当前位置已访问
4. **递归搜索**：向四个方向继续搜索
5. **状态恢复**：回溯时恢复访问状态

### 关键技巧
- **原地标记**：节省空间，直接修改board
- **方向数组**：简化四方向遍历代码
- **早期剪枝**：字符频率检查，减少无效搜索

### 常见错误
1. **忘记回溯**：搜索完成后不恢复visited状态
2. **边界处理**：没有正确检查数组越界
3. **重复访问**：没有标记已访问的位置

## 🧩 方法三：Trie树 + DFS（扩展思路）

> 说明：Trie 更适用于“单词搜索 II（多词）”，但也可用于本题作为统一搜索框架的练习与扩展。

```java
class SolutionTrie {
    static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean end;
    }

    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        TrieNode root = buildTrie(word);

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, i, j, root)) return true;
            }
        }
        return false;
    }

    private TrieNode buildTrie(String word) {
        TrieNode root = new TrieNode();
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = Character.toLowerCase(c) - 'a';
            if (idx < 0 || idx >= 26) continue; // 非字母字符的健壮性处理
            if (node.children[idx] == null) node.children[idx] = new TrieNode();
            node = node.children[idx];
        }
        node.end = true;
        return root;
    }

    private boolean dfs(char[][] board, int r, int c, TrieNode node) {
        if (r < 0 || r >= board.length || c < 0 || c >= board[0].length) return false;
        char ch = board[r][c];
        if (ch == '#') return false;

        int idx = Character.toLowerCase(ch) - 'a';
        if (idx < 0 || idx >= 26 || node.children[idx] == null) return false;

        node = node.children[idx];
        if (node.end) return true; // 匹配到完整单词

        board[r][c] = '#';
        boolean found = dfs(board, r + 1, c, node) ||
                        dfs(board, r - 1, c, node) ||
                        dfs(board, r, c + 1, node) ||
                        dfs(board, r, c - 1, node);
        board[r][c] = ch;
        return found;
    }
}
```

### 复杂度与适用性
- 单词搜索 I（单词唯一）：时间复杂度与标准DFS同阶，常数开销略大；优势在于统一到“字典搜索”框架
- 单词搜索 II（多词搜索）：Trie 显著减少重复匹配，综合复杂度优于逐词DFS
