# 题解2.0.0-岛屿数量：连通分量DFS搜索解法

## 🎯 解题思路

岛屿数量是典型的连通分量计数问题。核心思想是：
1. 遍历网格，寻找未访问的陆地('1')
2. 每发现一个陆地，岛屿数量+1
3. 使用DFS标记当前岛屿的所有连通陆地
4. 继续遍历，寻找下一个岛屿

## 💻 完整代码实现

### 方法一：DFS + 原地标记（推荐）

```java
class Solution {
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        
        int m = grid.length;
        int n = grid[0].length;
        int count = 0;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '1') {
                    count++;           // 发现新岛屿
                    dfs(grid, i, j);   // 标记整个岛屿
                }
            }
        }
        
        return count;
    }
    
    private void dfs(char[][] grid, int i, int j) {
        int m = grid.length;
        int n = grid[0].length;
        
        // 边界检查：越界或已访问(水域)
        if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == '0') {
            return;
        }
        
        // 标记当前陆地为已访问
        grid[i][j] = '0';
        
        // 四方向递归搜索
        dfs(grid, i + 1, j);  // 下
        dfs(grid, i - 1, j);  // 上
        dfs(grid, i, j + 1);  // 右
        dfs(grid, i, j - 1);  // 左
    }
}
```

### 方法二：DFS + visited数组

```java
class Solution {
    private int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
    
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        
        int m = grid.length;
        int n = grid[0].length;
        boolean[][] visited = new boolean[m][n];
        int count = 0;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '1' && !visited[i][j]) {
                    count++;
                    dfs(grid, i, j, visited);
                }
            }
        }
        
        return count;
    }
    
    private void dfs(char[][] grid, int i, int j, boolean[][] visited) {
        int m = grid.length;
        int n = grid[0].length;
        
        if (i < 0 || i >= m || j < 0 || j >= n || 
            visited[i][j] || grid[i][j] == '0') {
            return;
        }
        
        visited[i][j] = true;
        
        for (int[] dir : directions) {
            dfs(grid, i + dir[0], j + dir[1], visited);
        }
    }
}
```

### 方法三：BFS广度优先搜索

```java
class Solution {
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        
        int m = grid.length;
        int n = grid[0].length;
        int count = 0;
        int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '1') {
                    count++;
                    
                    // BFS标记整个岛屿
                    Queue<int[]> queue = new LinkedList<>();
                    queue.offer(new int[]{i, j});
                    grid[i][j] = '0';
                    
                    while (!queue.isEmpty()) {
                        int[] curr = queue.poll();
                        
                        for (int[] dir : directions) {
                            int newI = curr[0] + dir[0];
                            int newJ = curr[1] + dir[1];
                            
                            if (newI >= 0 && newI < m && newJ >= 0 && newJ < n && 
                                grid[newI][newJ] == '1') {
                                queue.offer(new int[]{newI, newJ});
                                grid[newI][newJ] = '0';
                            }
                        }
                    }
                }
            }
        }
        
        return count;
    }
}
```

## 🔍 算法分析

### 时间复杂度
- **O(M × N)**：每个位置最多被访问一次
- M为行数，N为列数

### 空间复杂度
- **方法一（原地标记）**：O(M × N)，递归栈空间
- **方法二（visited数组）**：O(M × N)，额外数组 + 递归栈
- **方法三（BFS）**：O(min(M, N))，队列空间

## 🚀 优化技巧

### 1. 递归优化（避免栈溢出）
```java
private void dfsIterative(char[][] grid, int startI, int startJ) {
    Stack<int[]> stack = new Stack<>();
    stack.push(new int[]{startI, startJ});
    
    while (!stack.isEmpty()) {
        int[] curr = stack.pop();
        int i = curr[0], j = curr[1];
        
        if (i < 0 || i >= grid.length || j < 0 || j >= grid[0].length || 
            grid[i][j] == '0') {
            continue;
        }
        
        grid[i][j] = '0';
        
        // 四方向入栈
        stack.push(new int[]{i + 1, j});
        stack.push(new int[]{i - 1, j});
        stack.push(new int[]{i, j + 1});
        stack.push(new int[]{i, j - 1});
    }
}
```

### 2. 并查集解法
```java
class UnionFind {
    private int[] parent;
    private int count;
    
    public UnionFind(char[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        parent = new int[m * n];
        count = 0;
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '1') {
                    parent[i * n + j] = i * n + j;
                    count++;
                }
            }
        }
    }
    
    public int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    public void union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX != rootY) {
            parent[rootX] = rootY;
            count--;
        }
    }
    
    public int getCount() {
        return count;
    }
}

public int numIslands(char[][] grid) {
    if (grid == null || grid.length == 0) return 0;
    
    int m = grid.length;
    int n = grid[0].length;
    UnionFind uf = new UnionFind(grid);
    int[][] directions = {{0, 1}, {1, 0}};
    
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == '1') {
                for (int[] dir : directions) {
                    int newI = i + dir[0];
                    int newJ = j + dir[1];
                    if (newI < m && newJ < n && grid[newI][newJ] == '1') {
                        uf.union(i * n + j, newI * n + newJ);
                    }
                }
            }
        }
    }
    
    return uf.getCount();
}
```

## 🎯 核心要点总结

### DFS连通分量模板
1. **外层遍历**：逐个检查每个位置
2. **发现起点**：遇到未访问的目标元素时计数+1
3. **DFS标记**：标记整个连通分量
4. **继续搜索**：寻找下一个连通分量

### 关键技巧
- **原地标记**：直接修改原数组，节省空间
- **边界检查**：防止数组越界
- **状态判断**：区分已访问和未访问状态

### 算法选择
- **DFS**：代码简洁，递归实现自然
- **BFS**：避免递归栈溢出，适合大数据
- **并查集**：适合动态连通性问题
