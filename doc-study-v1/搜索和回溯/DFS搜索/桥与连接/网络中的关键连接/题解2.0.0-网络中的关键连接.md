题解2.0.0 - 网络中的关键连接（Critical Connections in a Network, LeetCode 1192）

概述：Tarjan 算法。DFS 过程中为每个点记录发现时间 `dfn` 与最低可达时间 `low`，若存在边 (u, v) 满足 `low[v] > dfn[u]` 则是桥。

题解一：Tarjan 低链接（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    private int time = 0;

    public List<List<Integer>> criticalConnections(int n, List<List<Integer>> connections) {
        List<Integer>[] g = new ArrayList[n];
        for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
        for (List<Integer> e : connections) {
            int u = e.get(0), v = e.get(1);
            g[u].add(v); g[v].add(u);
        }
        int[] dfn = new int[n]; Arrays.fill(dfn, -1);
        int[] low = new int[n];
        List<List<Integer>> res = new ArrayList<>();
        for (int i = 0; i < n; i++) if (dfn[i] == -1) dfs(i, -1, g, dfn, low, res);
        return res;
    }

    private void dfs(int u, int parent, List<Integer>[] g, int[] dfn, int[] low, List<List<Integer>> res) {
        dfn[u] = low[u] = time++;
        for (int v : g[u]) {
            if (v == parent) continue;
            if (dfn[v] == -1) {
                dfs(v, u, g, dfn, low, res);
                low[u] = Math.min(low[u], low[v]);
                if (low[v] > dfn[u]) res.add(Arrays.asList(u, v));
            } else {
                low[u] = Math.min(low[u], dfn[v]);
            }
        }
    }
}
```

复杂度：
- O(n + m)，空间 O(n + m)。

思考小结：
- 注意区分父边与回边；多分量时需从每个未访问点启动 DFS。

标签：Tarjan、桥、DFS
