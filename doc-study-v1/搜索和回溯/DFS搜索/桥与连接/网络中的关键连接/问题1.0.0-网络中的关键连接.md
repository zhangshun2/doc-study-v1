问题1.0.0 - 网络中的关键连接（Critical Connections in a Network, LeetCode 1192）

概述：给定无向连通图，找出所有桥（关键连接）。删除桥会使图的连通分量增加。用 Tarjan 算法（DFS 低链接值）求解。

链接：https://leetcode.com/problems/critical-connections-in-a-network/

题目特征与分析：
- 桥的判定：对边 (u, v)，若 `low[v] > dfn[u]` 则 (u, v) 为桥。
- 需构建邻接表并在 DFS 中维护时间戳与低链接值。

知识点：
- Tarjan 算法、DFS、低链接值、桥判定。

输入输出：
- 输入：节点数 n 与边集 connections（0-index）。
- 输出：所有桥边列表。

标签：DFS、Tarjan、桥与连接、搜索与回溯
