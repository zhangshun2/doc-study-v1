# 题解2.0.0 最短的桥（LeetCode-934）

## 题解一：官方经典（DFS + 多源 BFS）
- 思路：DFS 找到第一个岛并把其所有格子入队；BFS 扩张到水面，第一次遇到另一个岛的格子时返回层数。
- 复杂度：时间 O(m·n)，空间 O(m·n)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int shortestBridge(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Deque<int[]> q = new ArrayDeque<>(); boolean found = false;
        for (int i = 0; i < m && !found; i++) {
            for (int j = 0; j < n && !found; j++) {
                if (grid[i][j] == 1) { dfs(grid, i, j, q); found = true; }
            }
        }
        int steps = 0;
        while (!q.isEmpty()) {
            for (int sz = q.size(); sz > 0; sz--) {
                int[] cur = q.poll(); int x = cur[0], y = cur[1];
                for (int d = 0; d < 4; d++) {
                    int nx = x + DIR[d], ny = y + DIR[d+1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    if (grid[nx][ny] == 1) return steps; // 接触另一个岛
                    if (grid[nx][ny] == 0) { grid[nx][ny] = -1; q.offer(new int[]{nx, ny}); }
                }
            }
            steps++;
        }
        return -1;
    }
    private void dfs(int[][] g, int x, int y, Deque<int[]> q) {
        int m = g.length, n = g[0].length;
        if (x < 0 || x >= m || y < 0 || y >= n || g[x][y] != 1) return;
        g[x][y] = -1; q.offer(new int[]{x, y});
        for (int d = 0; d < 4; d++) dfs(g, x + DIR[d], y + DIR[d+1], q);
    }
}
```
