题解2.0.0 - 图像渲染（Flood Fill, LeetCode 733）

概述：对与起点同色的连通区域进行 DFS，将像素染成新颜色；遇到不同色或越界终止。

题解一：DFS 洪水填充（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    private int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
    public int[][] floodFill(int[][] image, int sr, int sc, int newColor) {
        int old = image[sr][sc];
        if (old == newColor) return image;
        dfs(image, sr, sc, old, newColor);
        return image;
    }
    private void dfs(int[][] img, int x, int y, int old, int nc) {
        if (x < 0 || x >= img.length || y < 0 || y >= img[0].length) return;
        if (img[x][y] != old) return;
        img[x][y] = nc;
        for (int[] mv : d) dfs(img, x + mv[0], y + mv[1], old, nc);
    }
}
```

复杂度：
- O(R·C)，空间 O(1) 额外（递归栈除外）。

思考小结：
- 先判断起始像素是否与新颜色相同，避免无限递归。
