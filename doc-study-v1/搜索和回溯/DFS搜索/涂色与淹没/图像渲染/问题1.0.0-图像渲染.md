问题1.0.0 - 图像渲染（Flood Fill, LeetCode 733）

概述：从起点像素出发，将与其颜色相同且四向连通的区域全部替换为新颜色。可用 DFS/BFS 洪水填充。

链接：https://leetcode.com/problems/flood-fill/

题目特征与分析：
- 洪水填充：仅在原始颜色区域内扩展，四方向。
- 原地更新：避免额外空间，注意越界与颜色判断。

知识点：
- DFS/BFS 洪水填充、边界判定、网格搜索。

输入输出：
- 输入：图像 `image`、起点 `(sr, sc)`、新颜色 `newColor`。
- 输出：更新后的图像。

标签：DFS、BFS、洪水填充、网格、搜索与回溯
