🔄 递归回溯
解题思路：递归构建决策树，每层做选择，递归返回时撤销选择。
适用场景：枚举所有可能的组合/排列/子集，或生成满足条件的序列。
核心模板：选择 → 递归 → 撤销选择
- 17 电话号码的字母组合：
  - 思路：按数字位置递归，每层选择该数字对应的一个字母
- 22 括号生成：
  - 思路：递归添加左括号或右括号，用计数约束保证合法性
- 39 组合总和：
  - 思路：递归选择数字，用 start 避免重复，用 sum 剪枝
- 46 全排列：
  - 思路：递归选择未使用的数字，用 used[] 标记状态
- 78 子集：
  - 思路：递归决定每个元素选或不选，每个节点都是答案

🌊 广度优先搜索（BFS）
解题思路：层序遍历，逐层扩展状态，保证最短路径/最少操作。
适用场景：求最短距离、最少步数、最少删除等最优解问题。
核心模板：队列 + visited + 层序处理
- 301 删除无效的括号：
  - 思路：每层删除一个字符，第一次得到合法括号串就是最少删除

🗺️ 深度优先搜索（DFS）
解题思路：递归探索连通区域，标记访问状态，统计或查找目标。
适用场景：网格遍历、连通性问题、路径查找。
核心模板：递归 + visited + 边界检查
- 79 单词搜索：
  - 思路：从每个位置开始 DFS 匹配单词，回溯时恢复 visited
- 200 岛屿数量：
  - 思路：遇到陆地就 DFS 标记整个岛屿，统计岛屿数量

📊 图算法
解题思路：构建图结构，使用特定图算法解决依赖关系问题。
适用场景：依赖关系、拓扑排序、环检测。
核心模板：邻接表 + 特定算法（拓扑排序/DFS/BFS）
- 207 课程表：
  - 思路：构建课程依赖图，拓扑排序检测是否有环

🔢 数组操作
解题思路：直接操作数组元素，不需要搜索，按特定规则变换。
适用场景：排列变换、数学规律、贪心策略。
核心模板：找规律 + 直接操作
- 31 下一个排列：
  - 思路：找下降点 → 找替换元素 → 交换 → 反转后缀

💡 动态规划
解题思路：将搜索问题转化为状态转移，避免重复计算。
适用场景：搜索空间过大，存在重叠子问题的优化场景。
核心模板：状态定义 + 转移方程 + 边界条件
- 494 目标和：
  - 思路：转化为子集和问题，用 DP 求解 sum=(S+target)/2

问答式沟通快速模板（每题复用）
- 状态：本题最少需要哪些变量刻画进度？
- 分支：每步有哪些选择？是否需要 start/used[]？
- 约束/剪枝：哪些条件可提前剪掉？
- 去重：是否存在重复路径？同层/全局如何去重？
- 终止：何时收集答案？是否需要合法性判断？
- 复杂度/替代：分支因子与深度如何？是否存在更优（BFS/DP/拓扑）？
