## 1️⃣ 下一个排列 (LeetCode 31)

### 📝 题目描述

整数数组的一个 **排列** 就是将其所有成员按序列排列。例如，`arr = [1,2,3]`，以下数组都可以认为是 `arr` 的排列：`[1,2,3]`, `[1,3,2]`, `[3,1,2]`, `[2,3,1]`。

**下一个排列** 的算法将整数重新排列成字典序下一个更大的排列。如果这样的排列不存在，则将其重新排列成最小的排列（即升序排列）。

必须 **原地** 修改，只允许使用额外常数空间。

**示例 1：**

```plain
输入：nums = [1,2,3]
输出：[1,3,2]
```

**示例 2：**

```plain
输入：nums = [3,2,1]
输出：[1,2,3]
```

**示例 3：**

```plain
输入：nums = [1,1,5]
输出：[1,5,1]
```

### 🔧 基础解法：两次扫描 + 一次反转

**解题思路：**

下一个排列的找法遵循以下规律：

1. **从右向左** 找到第一个 `nums[i] < nums[i+1]` 的位置 `i`，这是需要调整的位置
2. **从右向左** 找到第一个 `nums[j] > nums[i]` 的位置 `j`
3. **交换** `nums[i]` 和 `nums[j]`
4. **反转** `i+1` 到末尾的部分，使其变为最小排列

```java
class Solution {
    public void nextPermutation(int[] nums) {
        if (nums == null || nums.length <= 1) {
            return;
        }
        
        int n = nums.length;
        int i = n - 2;
        
        // 步骤 1: 从右向左找到第一个 nums[i] < nums[i+1]
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        // 步骤 2: 如果找到了这样的 i
        if (i >= 0) {
            int j = n - 1;
            // 从右向左找到第一个 nums[j] > nums[i]
            while (j >= 0 && nums[j] <= nums[i]) {
                j--;
            }
            // 交换 nums[i] 和 nums[j]
            swap(nums, i, j);
        }
        
        // 步骤 3: 反转 i+1 到末尾的部分
        reverse(nums, i + 1, n - 1);
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    
    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            swap(nums, start, end);
            start++;
            end--;
        }
    }
}
```

**复杂度分析：**

- 时间复杂度：O(n)，最多扫描两次数组，反转一次
- 空间复杂度：O(1)，只使用常数额外空间

### 🚀 进阶解法：使用库函数（仅供理解）

```java
import java.util.Arrays;

class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        
        // 找到第一个下降点
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        if (i >= 0) {
            // 找到右边比 nums[i] 大的最小元素
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--;
            }
            swap(nums, i, j);
        }
        
        // 反转后缀
        reverse(nums, i + 1, n - 1);
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    
    private void reverse(int[] nums, int start, int end) {
        int left = start, right = end;
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```

**复杂度分析：**

- 时间复杂度：O(n)
- 空间复杂度：O(1)

### ⚠️ 易错点

1. **边界条件**：数组长度为 0 或 1 时直接返回
2. **降序排列**：当整个数组是降序时，i 会变成 -1，此时直接反转整个数组
3. **相等元素**：找 i 和 j 时要注意是 `>=` 和 `<=`，不是 `>` 和 `<`
4. **原地修改**：题目要求原地修改，不能创建新数组
5. **反转范围**：反转的是 `i+1` 到末尾，不是 `i` 到末尾

## 2️⃣ 课程表 (LeetCode 207)

### 📝 题目描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1`。

在选修某些课程之前需要一些先修课程。给定先修课程数组 `prerequisites`，其中 `prerequisites[i] = [ai, bi]`，表示如果要学习课程 `ai` 则 **必须** 先学习课程 `bi`。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true`；否则，返回 `false`。

**示例 1：**

```plain
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0。这是可能的。
```

**示例 2：**

```plain
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，你需要先完成课程 0；并且学习课程 0 之前，你必须先完成课程 1。这是不可能的。
```

### 🔧 基础解法：DFS 检测环

**解题思路：**

将课程看作图的节点，先修关系看作有向边。问题转化为：**判断有向图中是否存在环**。

使用 DFS 遍历，用三个状态标记节点：
- `0`：未访问
- `1`：正在访问（在当前 DFS 路径中）
- `2`：已访问完成

如果在 DFS 过程中遇到状态为 `1` 的节点，说明存在环。

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 构建邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        
        for (int[] prereq : prerequisites) {
            // prereq[0] 依赖于 prereq[1]
            graph.get(prereq[1]).add(prereq[0]);
        }
        
        // 0: 未访问，1: 访问中，2: 已完成
        int[] visited = new int[numCourses];
        
        // 对每个节点进行 DFS
        for (int i = 0; i < numCourses; i++) {
            if (visited[i] == 0) {
                if (hasCycle(graph, visited, i)) {
                    return false;
                }
            }
        }
        
        return true;
    }
    
    private boolean hasCycle(List<List<Integer>> graph, int[] visited, int node) {
        // 如果当前节点正在访问中，说明有环
        if (visited[node] == 1) {
            return true;
        }
        
        // 如果已经访问完成，无需再次检查
        if (visited[node] == 2) {
            return false;
        }
        
        // 标记为正在访问
        visited[node] = 1;
        
        // 遍历所有邻居
        for (int neighbor : graph.get(node)) {
            if (hasCycle(graph, visited, neighbor)) {
                return true;
            }
        }
        
        // 标记为已完成
        visited[node] = 2;
        
        return false;
    }
}
```

**复杂度分析：**

- 时间复杂度：O(V + E)，V 是课程数，E 是先修关系数
- 空间复杂度：O(V + E)，邻接表和 visited 数组

### 🚀 进阶解法：BFS 拓扑排序（Kahn 算法）

**解题思路：**

使用拓扑排序的思想：

1. 计算每个节点的入度
2. 将入度为 0 的节点加入队列
3. 依次取出队列中的节点，将其邻居的入度减 1
4. 如果邻居入度变为 0，加入队列
5. 最后检查处理的节点数是否等于总课程数

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 构建邻接表和入度数组
        List<List<Integer>> graph = new ArrayList<>();
        int[] inDegree = new int[numCourses];
        
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        
        for (int[] prereq : prerequisites) {
            // prereq[0] 依赖于 prereq[1]
            graph.get(prereq[1]).add(prereq[0]);
            inDegree[prereq[0]]++;
        }
        
        // 将所有入度为 0 的节点加入队列
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.offer(i);
            }
        }
        
        // 记录已完成的课程数
        int completedCourses = 0;
        
        while (!queue.isEmpty()) {
            int node = queue.poll();
            completedCourses++;
            
            // 遍历所有邻居
            for (int neighbor : graph.get(node)) {
                inDegree[neighbor]--;
                if (inDegree[neighbor] == 0) {
                    queue.offer(neighbor);
                }
            }
        }
        
        // 如果所有课程都能完成，返回 true
        return completedCourses == numCourses;
    }
}
```

**复杂度分析：**

- 时间复杂度：O(V + E)
- 空间复杂度：O(V + E)

### 🚀 最优解法：DFS 迭代实现

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }
        
        for (int[] prereq : prerequisites) {
            graph.get(prereq[1]).add(prereq[0]);
        }
        
        int[] visited = new int[numCourses];
        
        for (int i = 0; i < numCourses; i++) {
            if (visited[i] == 0 && hasCycle(graph, visited, i)) {
                return false;
            }
        }
        
        return true;
    }
    
    private boolean hasCycle(List<List<Integer>> graph, int[] visited, int start) {
        Stack<Integer> stack = new Stack<>();
        stack.push(start);
        
        while (!stack.isEmpty()) {
            int node = stack.peek();
            
            if (visited[node] == 1) {
                // 第二次访问，标记为已完成
                visited[node] = 2;
                stack.pop();
                continue;
            }
            
            if (visited[node] == 2) {
                stack.pop();
                continue;
            }
            
            // 第一次访问，标记为访问中
            visited[node] = 1;
            
            // 将所有未访问的邻居加入栈
            for (int neighbor : graph.get(node)) {
                if (visited[neighbor] == 1) {
                    return true; // 发现环
                }
                if (visited[neighbor] == 0) {
                    stack.push(neighbor);
                }
            }
        }
        
        return false;
    }
}
```

**复杂度分析：**

- 时间复杂度：O(V + E)
- 空间复杂度：O(V + E)

### ⚠️ 易错点

1. **图的方向**：`prerequisites[i] = [ai, bi]` 表示 `bi → ai`，不要搞反
2. **三状态标记**：必须区分"访问中"和"已完成"，否则会误判
3. ** disconnected 图**：图可能不连通，需要对所有节点进行遍历
4. **自环**：虽然题目一般不会出现，但要考虑 `[i, i]` 这种情况
5. **重复边**：输入中可能有重复的先修关系，不影响算法但要注意

## 3️⃣ 删除无效括号 (LeetCode 301)

### 📝 题目描述

给你一个由若干括号和字母组成的字符串 `s`，删除最小数量的无效括号，使得输入的字符串有效。

返回所有可能的结果。答案可以按 **任意顺序** 返回。

**有效括号字符串定义：**

- 空字符串或只包含小写字母的字符串是有效的
- 如果 `A` 是有效的，则 `(A)` 是有效的
- 如果 `A` 和 `B` 是有效的，则 `AB` 是有效的

**示例 1：**

```plain
输入：s = "()())()"
输出：["(())()","()()()"]
```

**示例 2：**

```plain
输入：s = "(a)())()"
输出：["(a())()","(a)()()"]
```

**示例 3：**

```plain
输入：s = ")("
输出：[""]
```

### 🔧 基础解法：回溯 + 剪枝

**解题思路：**

1. 首先统计需要删除的左括号和右括号的数量
2. 使用回溯尝试删除每个括号
3. 剪枝优化：
   - 如果当前右括号数量超过左括号，剪枝
   - 如果剩余括号不足以达到平衡，剪枝
   - 连续相同括号只删除第一个，避免重复

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        removeInvalidParenthesesHelper(s, result, 0, 0, 0, 0);
        return result;
    }
    
    private void removeInvalidParenthesesHelper(String s, List<String> result, 
                                                 int start, int lastRemove, 
                                                 int openToRemove, int closeToRemove) {
        // 如果需要删除的括号都为 0，检查是否有效
        if (openToRemove == 0 && closeToRemove == 0) {
            if (isValid(s)) {
                result.add(s);
            }
            return;
        }
        
        for (int i = start; i < s.length(); i++) {
            // 跳过非括号字符
            if (s.charAt(i) != '(' && s.charAt(i) != ')') {
                continue;
            }
            
            // 避免重复：如果当前字符和前一个字符相同，且前一个字符没被删除，跳过
            if (i > lastRemove && s.charAt(i) == s.charAt(i - 1)) {
                continue;
            }
            
            // 尝试删除当前字符
            String next = s.substring(0, i) + s.substring(i + 1);
            
            // 如果要删除左括号
            if (openToRemove > 0 && s.charAt(i) == '(') {
                removeInvalidParenthesesHelper(next, result, i, i, 
                                                openToRemove - 1, closeToRemove);
            }
            // 如果要删除右括号
            else if (closeToRemove > 0 && s.charAt(i) == ')') {
                removeInvalidParenthesesHelper(next, result, i, i, 
                                                openToRemove, closeToRemove - 1);
            }
        }
    }
    
    private boolean isValid(String s) {
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                count++;
            } else if (c == ')') {
                count--;
                if (count < 0) {
                    return false;
                }
            }
        }
        return count == 0;
    }
}
```

**复杂度分析：**

- 时间复杂度：O(2^n * n)，n 是字符串长度
- 空间复杂度：O(n)，递归调用栈

### 🚀 进阶解法：BFS（最优解）

**解题思路：**

BFS 可以保证找到删除最少括号的结果：

1. 将原字符串加入队列
2. 每次从队列取出一个字符串，检查是否有效
3. 如果有效，加入结果集，并标记已找到答案
4. 如果无效，生成所有删除一个括号的可能结果，加入下一层
5. 一旦找到有效结果，不再处理更深层

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        if (s == null) {
            return result;
        }
        
        Set<String> visited = new HashSet<>();
        Queue<String> queue = new LinkedList<>();
        
        queue.offer(s);
        visited.add(s);
        
        boolean found = false;
        
        while (!queue.isEmpty()) {
            String current = queue.poll();
            
            // 检查是否有效
            if (isValid(current)) {
                result.add(current);
                found = true;
            }
            
            // 如果已经找到答案，只处理当前层
            if (found) {
                continue;
            }
            
            // 生成所有删除一个括号的可能
            for (int i = 0; i < current.length(); i++) {
                // 跳过非括号字符
                if (current.charAt(i) != '(' && current.charAt(i) != ')') {
                    continue;
                }
                
                String next = current.substring(0, i) + current.substring(i + 1);
                
                if (!visited.contains(next)) {
                    visited.add(next);
                    queue.offer(next);
                }
            }
        }
        
        return result;
    }
    
    private boolean isValid(String s) {
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                count++;
            } else if (c == ')') {
                count--;
                if (count < 0) {
                    return false;
                }
            }
        }
        return count == 0;
    }
}
```

**复杂度分析：**

- 时间复杂度：O(2^n * n)，最坏情况
- 空间复杂度：O(2^n)，队列和 visited 集合

### 🚀 最优解法：优化的回溯

**解题思路：**

先统计需要删除的左右括号数量，然后进行有针对性的回溯：

```java
class Solution {
    public List<String> removeInvalidParentheses(String s) {
        List<String> result = new ArrayList<>();
        
        // 统计需要删除的左右括号数量
        int leftToRemove = 0, rightToRemove = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                leftToRemove++;
            } else if (c == ')') {
                if (leftToRemove > 0) {
                    leftToRemove--;
                } else {
                    rightToRemove++;
                }
            }
        }
        
        backtrack(s, 0, leftToRemove, rightToRemove, 0, result, new StringBuilder());
        return result;
    }
    
    private void backtrack(String s, int index, int leftToRemove, int rightToRemove,
                           int openCount, List<String> result, StringBuilder path) {
        // 处理完所有字符
        if (index == s.length()) {
            if (leftToRemove == 0 && rightToRemove == 0 && openCount == 0) {
                result.add(path.toString());
            }
            return;
        }
        
        char c = s.charAt(index);
        int len = path.length();
        
        if (c != '(' && c != ')') {
            // 非括号字符，直接添加
            path.append(c);
            backtrack(s, index + 1, leftToRemove, rightToRemove, openCount, result, path);
            path.setLength(len);
        } else if (c == '(') {
            // 选择 1: 删除这个左括号
            if (leftToRemove > 0) {
                backtrack(s, index + 1, leftToRemove - 1, rightToRemove, openCount, result, path);
            }
            
            // 选择 2: 保留这个左括号
            path.append(c);
            backtrack(s, index + 1, leftToRemove, rightToRemove, openCount + 1, result, path);
            path.setLength(len);
        } else { // c == ')'
            // 选择 1: 删除这个右括号
            if (rightToRemove > 0) {
                backtrack(s, index + 1, leftToRemove, rightToRemove - 1, openCount, result, path);
            }
            
            // 选择 2: 保留这个右括号（只有在有匹配的左括号时）
            if (openCount > 0) {
                path.append(c);
                backtrack(s, index + 1, leftToRemove, rightToRemove, openCount - 1, result, path);
                path.setLength(len);
            }
        }
    }
}
```

**复杂度分析：**

- 时间复杂度：O(2^n * n)
- 空间复杂度：O(n)，递归调用栈

### ⚠️ 易错点

1. **去重**：连续相同的括号只删除第一个，避免重复结果
2. **最小删除**：BFS 天然保证删除最少，回溯需要先统计需要删除的数量
3. **有效性检查**：不仅要左右括号数量相等，还要保证任何时候右括号不超过左括号
4. **空结果**：如果所有括号都要删除，返回 `[""]` 而不是空列表
5. **非括号字符**：字母等非括号字符要保留，不影响括号匹配

## 4️⃣ 目标和 (LeetCode 494)

### 📝 题目描述

给你一个非负整数数组 `nums` 和一个整数 `target`。

向数组中的每个整数前添加 `'+'` 或 `'-'`，然后串联起所有整数，可以构造一个表达式。

返回可以通过上述方法构造的、运算结果等于 `target` 的不同表达式的数目。

**示例 1：**

```plain
输入：nums = [1,1,1,1,1], target = 3
输出：5
解释：
-1+1+1+1+1 = 3
```

**示例 2：**

```plain
输入：nums = [1], target = 1
输出：1
```

### 🔧 基础解法：回溯（暴力搜索）

**解题思路：**

对每个数字，可以选择加号或减号，递归遍历所有可能的组合。

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        return backtrack(nums, 0, 0, target);
    }
    
    private int backtrack(int[] nums, int index, int currentSum, int target) {
        // base case: 处理完所有数字
        if (index == nums.length) {
            return currentSum == target ? 1 : 0;
        }
        
        // 选择加号
        int add = backtrack(nums, index + 1, currentSum + nums[index], target);
        
        // 选择减号
        int subtract = backtrack(nums, index + 1, currentSum - nums[index], target);
        
        return add + subtract;
    }
}
```

**复杂度分析：**

- 时间复杂度：O(2^n)，每个数字有 2 种选择
- 空间复杂度：O(n)，递归调用栈

### 🚀 进阶解法：回溯 + 记忆化

**解题思路：**

使用备忘录记录 `(index, currentSum)` 的状态，避免重复计算。

```java
class Solution {
    private Map<String, Integer> memo;
    
    public int findTargetSumWays(int[] nums, int target) {
        memo = new HashMap<>();
        return backtrack(nums, 0, 0, target);
    }
    
    private int backtrack(int[] nums, int index, int currentSum, int target) {
        // base case
        if (index == nums.length) {
            return currentSum == target ? 1 : 0;
        }
        
        // 检查备忘录
        String key = index + "," + currentSum;
        if (memo.containsKey(key)) {
            return memo.get(key);
        }
        
        // 选择加号或减号
        int result = backtrack(nums, index + 1, currentSum + nums[index], target)
                   + backtrack(nums, index + 1, currentSum - nums[index], target);
        
        memo.put(key, result);
        return result;
    }
}
```

**复杂度分析：**

- 时间复杂度：O(n * sum)，sum 是数组元素和
- 空间复杂度：O(n * sum)，备忘录大小

### 🚀 最优解法：动态规划（0-1 背包）

**解题思路：**

将问题转化为 0-1 背包问题：

假设加号的数字和为 `P`，减号的数字和为 `N`，则：
- `P - N = target`
- `P + N = sum`（数组总和）

解得：`P = (target + sum) / 2`

问题转化为：从数组中选择若干数字，使其和为 `P`，有多少种选法？

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }
        
        // 如果 target 超出范围，或 (target + sum) 是奇数，无解
        if (Math.abs(target) > sum || (target + sum) % 2 != 0) {
            return 0;
        }
        
        int positiveSum = (target + sum) / 2;
        
        // dp[i] 表示和为 i 的组合数
        int[] dp = new int[positiveSum + 1];
        dp[0] = 1; // 和为 0 有一种方法：什么都不选
        
        // 0-1 背包
        for (int num : nums) {
            for (int j = positiveSum; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }
        
        return dp[positiveSum];
    }
}
```

**复杂度分析：**

- 时间复杂度：O(n * sum)，n 是数组长度，sum 是数组元素和
- 空间复杂度：O(sum)，dp 数组

### 🚀 最优解法：动态规划（二维 DP）

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int num : nums) {
            sum += num;
        }
        
        // 边界检查
        if (Math.abs(target) > sum || (target + sum) % 2 != 0) {
            return 0;
        }
        
        int positiveSum = (target + sum) / 2;
        int n = nums.length;
        
        // dp[i][j] 表示前 i 个数字组成和为 j 的方法数
        int[][] dp = new int[n + 1][positiveSum + 1];
        dp[0][0] = 1;
        
        for (int i = 1; i <= n; i++) {
            int num = nums[i - 1];
            for (int j = 0; j <= positiveSum; j++) {
                // 不选当前数字
                dp[i][j] = dp[i - 1][j];
                
                // 选当前数字
                if (j >= num) {
                    dp[i][j] += dp[i - 1][j - num];
                }
            }
        }
        
        return dp[n][positiveSum];
    }
}
```

**复杂度分析：**

- 时间复杂度：O(n * sum)
- 空间复杂度：O(n * sum)

### ⚠️ 易错点

1. **边界条件**：`target` 可能为负数，要取绝对值判断
2. **奇偶性**：`(target + sum)` 必须是偶数，否则无解
3. **0 的处理**：数组中可能有 0，`+0` 和 `-0` 是两种不同方法
4. **dp 初始化**：`dp[0] = 1` 表示和为 0 有一种方法（什么都不选）
5. **遍历顺序**：0-1 背包内层循环要从大到小遍历，避免重复使用同一元素
6. **溢出问题**：sum 可能很大，注意整数溢出
