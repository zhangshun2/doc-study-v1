# 搜索与回溯：知识点梳理与题目分类（LeetCode 热题 11 项）

目的
- 统一本专题的学习与问答方式：先“引导思路”，再“知识点说明”，最后“按知识点分类题目”。
- 后续每道题的“问题文档”和“题解文档”会单独输出，不与本梳理文档合并。

一、引导：统一解题思路
- 明确搜索空间：问题的所有可能解构成的“决策树”。
- 定义状态与路径：用最少的变量刻画当前选择（index/坐标、path、sum、used[]、计数等）。
- 明确分支规则：每一步有哪些可选决策（选择/不选择、下一候选、上下左右、下一个字符等）。
- 约束与剪枝：在“不可能”或“无效”的分支尽早停止（越早剪枝越省时）。
- 终止条件：达到目标状态时记录答案（长度满足、计数满足、连接合法、和为目标等）。
- 路径恢复：递归返回前撤销本层选择（backtrack），保持状态一致性。
- 复杂度意识：分支因子与深度决定时间复杂度，剪枝/去重/缓存是优化关键。

二、核心知识点清单
1) 回溯通用模板与变量设计
- 状态：index/层数、path/当前构造、used[]/可用性、sum/计数器等。
- 分支：循环候选（start 起点控制是否可重复）、二选一（+/-）、字符映射等。
- 终止：index==n、path 满足长度/数量、sum==target、括号计数合法等。
- 路径恢复：选择→递归→撤销，保证上一层不被污染。

2) 剪枝策略与去重
- 剪枝：越界/非法（计数不合法、sum 超 target）、不可达（剩余最优也无法达成）。
- 去重：排序 + 跳过相同元素（同层去重）、集合判重（BFS/全局）。

3) 枚举类（排列/组合/子集）
- 组合：有顺序控制的选择问题（start 控制位置，避免重复）。
- 排列：全局 used[] 标记，保证同一个元素不会重复使用；路径长度达成时入答案。
- 子集：“选/不选”二叉决策树，或顺序遍历逐层扩展。

4) 网格/字符串 DFS 与 visited 管理
- 网格：边界判断、visited 标记（或原地修改），递归探索四/八方向。
- 字符串：基于 index 递归构造；字符映射与路径构造配合。

5) 图搜索与拓扑排序
- 邻接表 + 入度数组；BFS 按入度为 0 的点逐步出队，检测是否存在环。

6) BFS 层次搜索（最少操作/最短修改）
- 典型用于“最少删除/最短步数”等场景；visited 全局去重，层序保证最优。

7) 搜索与 DP 的转换
- 当搜索空间过大时，考虑状态压缩与 DP（如 494 目标和 转化为子集和）。

8) 复杂度与工程实践
- 分支因子×深度的指数级增长是常态；剪枝/去重/缓存是优化核心。
- 代码工程：命名清晰、状态最小化、提前返回、避免重复计算。

三、题目按知识点分类与要点
A. 回溯通用模板：组合/排列/子集
- 17 电话号码的字母组合
  - 要点：数字→字母映射；按 index 递归，每层分支是该数字对应的所有字母；无须去重。
  - 关注：path 构造、终止 index==digits.length。
- 39 组合总和
  - 要点：候选可重复使用；start 控制下次选择的起点；常见剪枝 sum>target（排序后可提前 break）。
  - 关注：避免同层重复；无须全局去重（元素可多次使用）。
- 46 全排列
  - 要点：全局 used[] 标记，确保元素一次路径只用一次；路径长度==n 时入答案。
  - 关注：撤销 used[] 与 path，保证回溯正确。
- 78 子集
  - 要点：“选/不选”二叉决策树或顺序迭代生成；每个节点都是一个合法子集。
  - 关注：不需要去重（若输入无重复），有重复时需排序 + 同层去重。

B. 括号构造与合法性
- 22 括号生成
  - 要点：计数约束与剪枝：右括号数量不得超过左括号；左括号最多 n；当 left==right==n 时入答案。
  - 关注：典型合法性剪枝，显著降低分支。
- 301 删除无效的括号
  - 要点：建议 BFS 求最少删除；同层生成所有删除一个字符的字符串，合法即收敛；visited 去重。
  - 关注：合法性检查 O(n)、最短优先保证最少删除；也可回溯尝试删除但需小心去重。

C. 网格/字符串搜索
- 79 单词搜索
  - 要点：网格 DFS + visited；从每个起点尝试匹配 word；回溯撤销 visited。
  - 关注：边界条件、字符匹配与回溯撤销顺序。
- 200 岛屿数量
  - 要点：DFS/BFS flood fill；遍历每个格子，遇到“1”做整块标记并计数。
  - 关注：visited 管理（或原地置 0/2），避免重复访问。

D. 图与拓扑
- 207 课程表
  - 要点：构图（邻接表）+ 入度数组；BFS 出队入度为 0 的点，统计能否拓扑排序完成。
  - 关注：环检测（是否所有节点都被处理）。

E. 排列序列操作（非回溯）
- 31 下一个排列
  - 要点：序列的字典序下一个排列：找下降点→右侧最小大于它的元素→交换→反转尾部。
  - 关注：属于序列操作/贪心思路，不需要搜索/回溯。

F. 搜索与 DP 转换
- 494 目标和
  - 要点：搜索视角是“每个数取 + 或 -”，形成二叉决策树；更优解法是转化为子集和：sum(P)=(S+target)/2。
  - 关注：当 (S+target) 为奇数或 <0 时无解；推荐 DP 降维优化。

四、问答式沟通清单（面向每道题）
- 状态：本题应该用哪些变量刻画当前进度？
- 分支：本题每一步有哪些选择？是否需要 start/used[]？
- 约束：哪些条件不合法？能否在分支前剪掉？
- 去重：是否存在重复路径？如何同层/全局去重？
- 终止：何时收集答案？是否需要判合法性（如括号）？
- 复杂度：分支因子与深度？有无更优（如 BFS/DP/拓扑）？
