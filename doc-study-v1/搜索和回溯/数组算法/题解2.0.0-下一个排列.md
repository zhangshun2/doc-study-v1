# 题解2.0.0-下一个排列：三步法实现字典序的下一个排列

## 🎯 解题概述

下一个排列问题的核心是**模拟手工寻找下一个字典序排列的过程**。通过观察排列规律，我们可以总结出一个**三步算法**：找递减位置、找替换数字、反转后缀。

**核心思路：** 从右往左找到第一个可以增大的位置，用比它大的最小数字替换，然后将后面部分变为最小排列。

## 💡 解法一：标准三步法

### 算法思路
1. **找递减位置**：从右往左找第一个 `nums[i] < nums[i+1]`
2. **找替换数字**：从右往左找第一个 `nums[j] > nums[i]`
3. **交换并反转**：交换后将i+1到末尾反转为升序

### Java实现
```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        
        // 步骤1：从右往左找第一个递减位置
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        // 步骤2：如果找到递减位置，寻找替换数字
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--;
            }
            // 交换nums[i]和nums[j]
            swap(nums, i, j);
        }
        
        // 步骤3：反转i+1到末尾的部分
        reverse(nums, i + 1, n - 1);
    }
    
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    
    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            swap(nums, start, end);
            start++;
            end--;
        }
    }
}
```

## 💡 解法三：一次遍历优化

### 算法思路
在寻找递减位置的同时记录可能的替换位置，减少遍历次数。

### Java实现
```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        int i = n - 2;
        
        // 从右往左找第一个递减位置
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        if (i >= 0) {
            // 从右往左找第一个大于nums[i]的数
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--;
            }
            
            // 交换
            int temp = nums[i];
            nums[i] = nums[j];
            nums[j] = temp;
        }
        
        // 反转i+1到末尾
        int left = i + 1, right = n - 1;
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```

## 📊 算法分析

### 时间复杂度
- **最坏情况：** O(n)
  - 寻找递减位置：O(n)
  - 寻找替换数字：O(n)
  - 反转操作：O(n)
  - 总体：O(n)

- **最好情况：** O(1)
  - 当最后两个数字可以直接交换时

### 空间复杂度
- **空间复杂度：** O(1)
  - 只使用了常数个额外变量
  - 原地修改数组

## 🔍 执行演示

### 示例：nums = [1,2,3]

```
初始状态：[1, 2, 3]

步骤1：寻找递减位置
从右往左：3 > 2，继续
         2 > 1，找到i=1 (nums[1]=2)

步骤2：寻找替换数字
从右往左找大于nums[1]=2的数：
         nums[2]=3 > 2，找到j=2

步骤3：交换nums[1]和nums[2]
交换后：[1, 3, 2]

步骤4：反转i+1到末尾
i+1=2到末尾只有一个元素，无需反转

最终结果：[1, 3, 2]
```

### 示例：nums = [2,3,1]

```
初始状态：[2, 3, 1]

步骤1：寻找递减位置
从右往左：1 < 3，继续
         3 > 2，找到i=0 (nums[0]=2)

步骤2：寻找替换数字
从右往左找大于nums[0]=2的数：
         nums[2]=1 < 2，继续
         nums[1]=3 > 2，找到j=1

步骤3：交换nums[0]和nums[1]
交换后：[3, 2, 1]

步骤4：反转i+1到末尾
反转位置1到2：[3, 1, 2]

最终结果：[3, 1, 2]
```

### 示例：nums = [3,2,1] (最大排列)

```
初始状态：[3, 2, 1]

步骤1：寻找递减位置
从右往左：1 < 2，继续
         2 < 3，继续
         i = -1 (未找到递减位置)

步骤2：跳过交换步骤

步骤3：反转整个数组
反转位置0到2：[1, 2, 3]

最终结果：[1, 2, 3]
```

## ⚡ 优化技巧

### 1. 早期终止
```java
// 如果数组长度小于2，直接返回
if (nums.length <= 1) return;
```

### 2. 位运算优化交换
```java
private void swap(int[] nums, int i, int j) {
    if (i != j) {
        nums[i] ^= nums[j];
        nums[j] ^= nums[i];
        nums[i] ^= nums[j];
    }
}
```

### 3. 二分查找优化（当数组很大时）
```java
// 在有序的后缀中使用二分查找替换数字
private int binarySearchGreater(int[] nums, int start, int end, int target) {
    while (start <= end) {
        int mid = start + (end - start) / 2;
        if (nums[mid] > target) {
            end = mid - 1;
        } else {
            start = mid + 1;
        }
    }
    return start;
}
```

## 📝 核心模板总结

### 下一个排列模板
```java
public void nextPermutation(int[] nums) {
    int n = nums.length;
    
    // 1. 找递减位置
    int i = n - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) {
        i--;
    }
    
    // 2. 找替换数字并交换
    if (i >= 0) {
        int j = n - 1;
        while (nums[j] <= nums[i]) {
            j--;
        }
        swap(nums, i, j);
    }
    
    // 3. 反转后缀
    reverse(nums, i + 1, n - 1);
}
```

### 通用反转模板
```java
private void reverse(int[] nums, int start, int end) {
    while (start < end) {
        swap(nums, start++, end--);
    }
}
```

## 🎯 关键技巧

1. **从右往左扫描**：找到第一个可以增大的位置
2. **贪心选择**：选择比当前数字大的最小数字
3. **反转操作**：将后缀变为最小排列
4. **边界处理**：最大排列需要变为最小排列

## ⚠️ 常见错误

1. **扫描方向错误**：从左往右扫描无法找到正确位置
2. **比较条件错误**：使用`>`而不是`>=`导致重复元素处理错误
3. **反转范围错误**：忘记反转i+1到末尾的部分
4. **边界处理遗漏**：最大排列的特殊情况处理
