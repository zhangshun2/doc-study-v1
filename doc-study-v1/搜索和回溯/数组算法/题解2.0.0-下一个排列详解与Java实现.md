# 题解2.0.0-下一个排列：字典序算法的完整实现与深度解析

## 🎯 算法核心思想

下一个排列问题的本质是在所有排列的字典序中找到当前排列的下一个。这个问题可以通过模拟手工寻找下一个排列的过程来解决。

### 🔍 核心观察
1. **从右往左找递减点**：找到第一个可以增大的位置
2. **找最小的替换数**：在右侧找到比该位置大的最小数
3. **交换并重排**：交换后将右侧部分变为最小排列

## 📊 算法步骤详解

### 步骤分解
```
以 [1,2,3,4,5] → [1,2,4,3,5] 为例：

1. 从右往左找递减点：
   [1,2,3,4,5]
        ↑ i=2 (nums[2]=3 < nums[3]=4)

2. 从右往左找替换数：
   [1,2,3,4,5]
          ↑ j=3 (nums[3]=4 > nums[2]=3)

3. 交换 nums[i] 和 nums[j]：
   [1,2,4,3,5]

4. 反转 i+1 到末尾：
   [1,2,4,3,5] → [1,2,4,3,5] (已经是升序)
```

## 💻 Java代码实现

### 标准解法
```java
/**
 * LeetCode 31. 下一个排列
 * 
 * 算法思路：
 * 1. 从右往左找第一个递减位置i (nums[i] < nums[i+1])
 * 2. 从右往左找第一个大于nums[i]的数字位置j
 * 3. 交换nums[i]和nums[j]
 * 4. 反转i+1到末尾的部分，使其变为升序
 * 
 * 时间复杂度：O(n)
 * 空间复杂度：O(1)
 */
public class NextPermutation {
    
    /**
     * 寻找下一个排列的主方法
     * @param nums 输入的整数数组
     */
    public void nextPermutation(int[] nums) {
        if (nums == null || nums.length <= 1) {
            return;
        }
        
        int n = nums.length;
        
        // 步骤1：从右往左找第一个递减位置
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        // 步骤2：如果找到了递减位置，寻找替换数字
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) {
                j--;
            }
            // 步骤3：交换nums[i]和nums[j]
            swap(nums, i, j);
        }
        
        // 步骤4：反转i+1到末尾的部分
        reverse(nums, i + 1, n - 1);
    }
    
    /**
     * 交换数组中两个位置的元素
     */
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    
    /**
     * 反转数组中指定范围的元素
     */
    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            swap(nums, start, end);
            start++;
            end--;
        }
    }
}
```

```java
/**
 * 下一个排列 - 详细版本
 * 包含完整的步骤说明和边界处理
 */
public class NextPermutationDetailed {
    
    public void nextPermutation(int[] nums) {
        if (nums == null || nums.length <= 1) {
            return; // 空数组或单元素数组无需处理
        }
        
        int n = nums.length;
        
        // ========== 步骤1：寻找递减点 ==========
        // 从右往左找第一个 nums[i] < nums[i+1] 的位置
        // 这个位置是我们需要增大的位置
        int i = findDecreasingPoint(nums);
        
        // ========== 步骤2：寻找替换数字 ==========
        if (i >= 0) {
            // 如果找到了递减点，从右往左找第一个大于nums[i]的数
            int j = findReplacementNumber(nums, i);
            
            // ========== 步骤3：交换 ==========
            swap(nums, i, j);
        }
        
        // ========== 步骤4：反转后续部分 ==========
        // 将i+1到末尾的部分反转，使其变为升序（最小排列）
        reverse(nums, i + 1, n - 1);
    }
    
    /**
     * 寻找递减点：从右往左找第一个nums[i] < nums[i+1]的位置
     * @param nums 输入数组
     * @return 递减点的索引，如果不存在返回-1
     */
    private int findDecreasingPoint(int[] nums) {
        int i = nums.length - 2;
        
        // 从倒数第二个元素开始向左扫描
        while (i >= 0 && nums[i] >= nums[i + 1]) {
            i--;
        }
        
        return i; // 返回-1表示整个数组是递减的（最大排列）
    }
    
    /**
     * 寻找替换数字：从右往左找第一个大于nums[i]的数
     * @param nums 输入数组
     * @param i 需要被替换的位置
     * @return 替换数字的索引
     */
    private int findReplacementNumber(int[] nums, int i) {
        int j = nums.length - 1;
        
        // 从右往左找第一个大于nums[i]的数
        while (nums[j] <= nums[i]) {
            j--;
        }
        
        return j;
    }
    
    /**
     * 交换数组中两个位置的元素
     */
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
    
    /**
     * 反转数组中指定范围的元素
     */
    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            swap(nums, start, end);
            start++;
            end--;
        }
    }
}
```

## 📈 算法复杂度分析

### 时间复杂度：O(n)
- **寻找递减点**：最坏情况下扫描整个数组，O(n)
- **寻找替换数字**：最坏情况下扫描到数组开头，O(n)
- **交换操作**：O(1)
- **反转操作**：最坏情况下反转整个数组，O(n)
- **总时间复杂度**：O(n)

### 空间复杂度：O(1)
- 只使用了常数个额外变量
- 所有操作都是原地进行的

```java
/**
 * 寻找上一个排列（字典序中的前一个）
 */
public void previousPermutation(int[] nums) {
    int n = nums.length;
    
    // 从右往左找第一个递增位置
    int i = n - 2;
    while (i >= 0 && nums[i] <= nums[i + 1]) {
        i--;
    }
    
    if (i >= 0) {
        // 从右往左找第一个小于nums[i]的数
        int j = n - 1;
        while (nums[j] >= nums[i]) {
            j--;
        }
        swap(nums, i, j);
    }
    
    // 反转i+1到末尾的部分
    reverse(nums, i + 1, n - 1);
}
```

### 2. 第k个排列
```java
/**
 * 直接计算第k个排列（不需要逐个生成）
 */
public String getPermutation(int n, int k) {
    java.util.List<Integer> numbers = new java.util.ArrayList<>();
    int[] factorial = new int[n];
    
    // 计算阶乘
    factorial[0] = 1;
    for (int i = 1; i < n; i++) {
        factorial[i] = factorial[i - 1] * i;
        numbers.add(i);
    }
    numbers.add(n);
    
    k--; // 转换为0索引
    
    StringBuilder result = new StringBuilder();
    for (int i = n; i > 0; i--) {
        int index = k / factorial[i - 1];
        k %= factorial[i - 1];
        
        result.append(numbers.get(index));
        numbers.remove(index);
    }
    
    return result.toString();
}
```

## 🧠 核心思想总结

### 贪心策略
1. **最小增量原则**：寻找能够增大的最右位置
2. **最小替换原则**：选择比当前数字大的最小数字
3. **最小排列原则**：交换后将后续部分变为最小排列

### 双指针技巧
1. **从右往左扫描**：寻找关键位置
2. **范围反转**：使用双指针反转数组片段

### 模拟思想
1. **模拟手工过程**：算法步骤对应人工寻找下一个排列的过程
2. **分步骤处理**：将复杂问题分解为简单步骤

## 💡 学习要点与记忆技巧

### 记忆口诀
```
从右找递减，从右找替换
交换后反转，下个排列现
```

### 关键理解
1. **为什么从右往左找？** 因为我们要找最小的增量
2. **为什么要反转？** 因为交换后右侧部分是递减的，需要变为最小排列
3. **边界情况是什么？** 最大排列（完全递减）需要变为最小排列

### 常见错误
1. **忘记反转操作**：只交换不反转会得到错误结果
2. **边界处理不当**：没有处理最大排列的情况
3. **索引越界**：在寻找过程中没有检查边界
