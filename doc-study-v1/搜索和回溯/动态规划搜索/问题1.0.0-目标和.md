# 问题1.0.0-目标和：01背包问题的变种

## 📋 题目信息

**LeetCode 494. 目标和**  
**难度：** 中等  
**链接：** [🔗](https://leetcode.cn/problems/target-sum/)

## 🎯 问题描述

给你一个非负整数数组 `nums` 和一个整数 `target` 。

向数组中的每个整数前添加 `'+'` 或 `'-'` ，然后串联起所有整数，可以构造一个 **表达式** ：

- 例如，`nums = [2, 1]` ，可以在每个整数前添加 `'+'` 或 `'-'` ，得到四种不同的表达式：
  - `+2+1 = 3`
  - `+2-1 = 1`  
  - `-2+1 = -1`
  - `-2-1 = -3`

返回可以使最终表达式等于 `target` 的不同 **表达式的数目**。

## 📝 示例分析

### 示例 1
```
输入：nums = [1,1,1,1,1], target = 3
输出：5

解释：一共有 5 种方法让最终目标和为 3：
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

### 示例 2
```
输入：nums = [1], target = 1
输出：1

解释：只有一种方法：+1 = 1
```

### 示例 3
```
输入：nums = [1], target = 2
输出：0

解释：无法达到目标和 2
```

## 🔍 问题特征分析

### 核心特征
1. **符号选择问题**：每个数字前可以选择+或-号
2. **组合计数问题**：求满足条件的方案数
3. **子集划分问题**：可以转化为子集和问题
4. **动态规划问题**：具有最优子结构和重叠子问题

### 问题转化
设正数集合为P，负数集合为N，则有：
- `sum(P) - sum(N) = target`
- `sum(P) + sum(N) = sum(nums)`

解得：`sum(P) = (target + sum(nums)) / 2`

**转化后的问题：** 在nums中选择一些数字，使其和等于`(target + sum(nums)) / 2`的方案数。

### 约束条件
- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 1000`
- `0 <= sum(nums[i]) <= 1000`
- `-1000 <= target <= 1000`

## 🧠 解题思路引导

### 思路一：暴力递归（DFS）
- 对每个数字选择+或-，递归计算所有可能
- 时间复杂度：O(2^n)

### 思路二：记忆化搜索
- 在递归基础上添加记忆化，避免重复计算
- 时间复杂度：O(n × sum)

### 思路三：动态规划（01背包）
- 转化为子集和问题，使用01背包求解
- 时间复杂度：O(n × sum)

### 思路四：优化动态规划
- 使用一维数组优化空间复杂度
- 空间复杂度：O(sum)

## 🎨 算法设计要点

### 问题转化的关键
```java
// 1. 检查是否有解
int sum = Arrays.stream(nums).sum();
if (target > sum || target < -sum || (target + sum) % 2 == 1) {
    return 0;
}

// 2. 转化为子集和问题
int targetSum = (target + sum) / 2;
```

### 动态规划状态定义
- `dp[i][j]`：使用前i个数字，和为j的方案数
- 状态转移：`dp[i][j] = dp[i-1][j] + dp[i-1][j-nums[i-1]]`

### 边界条件
- `dp[0][0] = 1`：不选任何数字，和为0的方案数为1
- `dp[0][j] = 0` (j > 0)：不选任何数字，和不为0的方案数为0
