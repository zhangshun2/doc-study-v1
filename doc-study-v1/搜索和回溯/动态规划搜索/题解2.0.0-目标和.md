# 题解2.0.0-目标和：从递归到动态规划的四种解法

## 🎯 解题概述

目标和问题可以通过**数学转化**将符号选择问题转换为**01背包问题**。核心思路是将数组分为正数集合P和负数集合N，通过数学推导得到：`sum(P) = (target + sum(nums)) / 2`。

**解法进化路径：** 暴力递归 → 记忆化搜索 → 二维DP → 一维DP优化

## 💡 解法一：暴力递归（DFS）

### 算法思路
对每个数字选择+或-号，递归计算所有可能的组合。

### Java实现
```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        return dfs(nums, 0, 0, target);
    }
    
    private int dfs(int[] nums, int index, int currentSum, int target) {
        // 递归终止条件
        if (index == nums.length) {
            return currentSum == target ? 1 : 0;
        }
        
        // 选择+号和-号两种情况
        int positive = dfs(nums, index + 1, currentSum + nums[index], target);
        int negative = dfs(nums, index + 1, currentSum - nums[index], target);
        
        return positive + negative;
    }
}
```

**时间复杂度：** O(2^n)  
**空间复杂度：** O(n) - 递归栈深度

## 💡 解法二：记忆化搜索

### 算法思路
在递归基础上添加记忆化，避免重复计算相同的子问题。

### Java实现
```java
class Solution {
    private Map<String, Integer> memo = new HashMap<>();
    
    public int findTargetSumWays(int[] nums, int target) {
        return dfs(nums, 0, 0, target);
    }
    
    private int dfs(int[] nums, int index, int currentSum, int target) {
        // 递归终止条件
        if (index == nums.length) {
            return currentSum == target ? 1 : 0;
        }
        
        // 检查记忆化
        String key = index + "," + currentSum;
        if (memo.containsKey(key)) {
            return memo.get(key);
        }
        
        // 递归计算
        int positive = dfs(nums, index + 1, currentSum + nums[index], target);
        int negative = dfs(nums, index + 1, currentSum - nums[index], target);
        int result = positive + negative;
        
        // 存储结果
        memo.put(key, result);
        return result;
    }
}
```

**时间复杂度：** O(n × sum)  
**空间复杂度：** O(n × sum)

## 💡 解法三：动态规划（二维数组）

### 数学转化
设正数集合为P，负数集合为N：
- `sum(P) - sum(N) = target`
- `sum(P) + sum(N) = sum(nums)`

解得：`sum(P) = (target + sum(nums)) / 2`

**问题转化：** 在nums中选择子集，使其和等于`(target + sum(nums)) / 2`的方案数。

### Java实现
```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = Arrays.stream(nums).sum();
        
        // 检查是否有解
        if (target > sum || target < -sum || (target + sum) % 2 == 1) {
            return 0;
        }
        
        int targetSum = (target + sum) / 2;
        return subsetSum(nums, targetSum);
    }
    
    private int subsetSum(int[] nums, int targetSum) {
        int n = nums.length;
        // dp[i][j] 表示使用前i个数字，和为j的方案数
        int[][] dp = new int[n + 1][targetSum + 1];
        
        // 初始化：不选任何数字，和为0的方案数为1
        for (int i = 0; i <= n; i++) {
            dp[i][0] = 1;
        }
        
        // 状态转移
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j <= targetSum; j++) {
                // 不选择当前数字
                dp[i][j] = dp[i - 1][j];
                
                // 选择当前数字（如果可以选择）
                if (j >= nums[i - 1]) {
                    dp[i][j] += dp[i - 1][j - nums[i - 1]];
                }
            }
        }
        
        return dp[n][targetSum];
    }
}
```

**时间复杂度：** O(n × targetSum)  
**空间复杂度：** O(n × targetSum)

## 💡 解法四：动态规划（一维数组优化）

### 算法思路
使用滚动数组优化空间复杂度，从右到左更新避免重复使用。

### Java实现
```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = Arrays.stream(nums).sum();
        
        // 检查是否有解
        if (target > sum || target < -sum || (target + sum) % 2 == 1) {
            return 0;
        }
        
        int targetSum = (target + sum) / 2;
        
        // dp[j] 表示和为j的方案数
        int[] dp = new int[targetSum + 1];
        dp[0] = 1; // 和为0的方案数为1
        
        // 遍历每个数字
        for (int num : nums) {
            // 从右到左更新，避免重复使用
            for (int j = targetSum; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }
        
        return dp[targetSum];
    }
}
```

**时间复杂度：** O(n × targetSum)  
**空间复杂度：** O(targetSum)

## 📊 算法分析

### 复杂度对比
| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|------------|------------|------|
| 暴力递归 | O(2^n) | O(n) | 简单直观，效率低 |
| 记忆化搜索 | O(n×sum) | O(n×sum) | 避免重复计算 |
| 二维DP | O(n×targetSum) | O(n×targetSum) | 经典01背包 |
| 一维DP | O(n×targetSum) | O(targetSum) | 空间优化 |

### 适用场景
- **数据规模小**：使用暴力递归或记忆化搜索
- **数据规模中等**：使用二维DP
- **空间要求严格**：使用一维DP优化

public int countSubsetSum(int[] nums, int target) {
    int[] dp = new int[target + 1];
    dp[0] = 1; // 和为0的方案数为1

## 🎯 关键技巧

1. **问题转化**：将符号选择问题转化为子集和问题
2. **数学推导**：通过方程组求解目标子集和
3. **空间优化**：使用一维数组代替二维数组
4. **更新顺序**：从右到左更新避免重复使用

## ⚠️ 常见错误

1. **转化条件检查**：忘记检查`(target + sum) % 2 == 1`的情况
2. **边界初始化**：`dp[0] = 1`的含义理解错误
3. **更新顺序**：一维DP中从左到右更新导致重复使用
4. **溢出问题**：在极端情况下可能发生整数溢出
