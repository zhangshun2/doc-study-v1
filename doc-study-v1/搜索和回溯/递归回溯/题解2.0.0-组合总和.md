# 题解2.0.0 组合总和（LeetCode-39）

## 题解一：官方经典（排序 + 回溯 + 剪枝）
- 思路：排序后从 `start` 开始遍历，选择 `c[i]` 加入路径，递归到 `remain - c[i]`，允许 `i` 继续选择（可重复使用）。当 `remain == 0` 收集结果。
- 复杂度：时间取决于解空间，空间 O(n) 递归深度。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> res = new ArrayList<>();
        dfs(candidates, target, 0, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] c, int remain, int start, List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) { res.add(new ArrayList<>(path)); return; }
        for (int i = start; i < c.length; i++) {
            if (c[i] > remain) break;
            path.add(c[i]);
            dfs(c, remain - c[i], i, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解二：通用解法（枚举次数 + 回溯）
- 标签：回溯、剪枝、组合枚举
- 思路：对于每个元素枚举选择的次数 `k`，将 `k` 次加入路径，再递归到下一个索引；更易于理解选择与约束的关系。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> res = new ArrayList<>();
        dfs(candidates, target, 0, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] c, int remain, int idx, List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) { res.add(new ArrayList<>(path)); return; }
        if (idx == c.length) return;
        int val = c[idx];
        for (int k = 0; k * val <= remain; k++) {
            for (int t = 0; t < k; t++) path.add(val);
            dfs(c, remain - k * val, idx + 1, path, res);
            for (int t = 0; t < k; t++) path.remove(path.size() - 1);
        }
    }
}
```

## 题解三：最好理解（“能选就选，选多次也行，超了就停”）
- 直觉：按索引往后选，遇到可选的数就加入，多选几次直到超过目标就停止回退。

## 总结思路
- 索引与非降序路径保证不重；排序 + 剪枝显著减少搜索量。
