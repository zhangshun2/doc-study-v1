# 问题1.0.0 电话号码的字母组合（LeetCode-17）

- 难度：中等
- 链接：https://leetcode.cn/problems/letter-combinations-of-a-phone-number/

## 概述
给定仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。数字到字母的映射与手机按键相同。

## 问题特征与分析引导
- 输入特征：长度 `n` 最多 4~5 的常规面试范围；每位数字映射 3~4 个字母。
- 输出特征：组合数量为各位映射字母数的乘积，爆炸式增长，适合回溯（DFS）生成。
- 约束特征：顺序不要求固定，但通常按输入顺序展开；去重不涉及（映射不重复）。

## 可能涉及的知识点
- 递归回溯模板：路径、选择列表、退出条件
- 字符串构造优化：`StringBuilder` vs 字符串拼接
- 宽度优先（BFS）生成 vs 深度优先（DFS）回溯
- 映射表的构造与访问（数组/哈希）
