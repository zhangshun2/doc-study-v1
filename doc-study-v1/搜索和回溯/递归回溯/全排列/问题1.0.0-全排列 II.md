# 问题1.0.0 全排列 II（LeetCode-47）

- 难度：中等
- 链接：https://leetcode.cn/problems/permutations-ii/

## 概述
给定可能包含重复数字的数组，返回所有不重复的全排列。

## 问题特征与分析引导
- 重复与去重：输入存在重复，结果要求唯一排列；回溯时需控制同一层的相同值选择顺序。
- 路径结构：每个位置选择一个未使用的元素；到达长度 `n` 收集结果。
- 去重策略：排序后，若当前值与前一个值相同且前一个值在本层未被使用，则跳过。

## 可能涉及的知识点
- 回溯模板：`used[]` 标记与路径构造
- 排序 + 相邻重复剪枝（`!used[i-1]`）
- 计数法（频次数组）生成所有排列
