# 题解2.0.0 全排列 II（LeetCode-47）

## 题解一：官方经典（排序 + used[] + 剪枝）
- 思路：先排序，回溯时跳过“同层重复”（`i>0 && nums[i]==nums[i-1] && !used[i-1]`）；用 `used[]` 控制选过的元素；路径长度到 `n` 收集结果。
- 复杂度：时间为结果规模 `O(n * k)`（`k` 为不重复排列数），空间 O(n)。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        dfs(nums, used, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue; // 剪枝
            used[i] = true; path.add(nums[i]);
            dfs(nums, used, path, res);
            path.remove(path.size() - 1); used[i] = false;
        }
    }
}
```

## 题解二：通用解法（频次数组回溯）
- 标签：回溯、去重、频次构造
- 思路：先统计每个数的频次，回溯时对每个不同值尝试减少频次并加入路径，直到长度 `n`；天然不重复。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        Map<Integer, Integer> cnt = new LinkedHashMap<>();
        for (int x : nums) cnt.put(x, cnt.getOrDefault(x, 0) + 1);
        int m = cnt.size();
        int[] vals = new int[m];
        int[] freq = new int[m];
        int idx = 0; for (Map.Entry<Integer,Integer> e : cnt.entrySet()) { vals[idx] = e.getKey(); freq[idx] = e.getValue(); idx++; }
        List<List<Integer>> res = new ArrayList<>();
        dfs(vals, freq, nums.length, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] vals, int[] freq, int n, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == n) { res.add(new ArrayList<>(path)); return; }
        for (int i = 0; i < vals.length; i++) {
            if (freq[i] == 0) continue;
            freq[i]--; path.add(vals[i]);
            dfs(vals, freq, n, path, res);
            path.remove(path.size() - 1); freq[i]++;
        }
    }
}
```

## 题解三：最好理解（“同样的数，必须按固定顺序用”）
- 直觉：排序后，同值要先用前面的再用后面的；如果前面的同值还没用，就不能用后面的，避免重复排列。

## 总结思路
- 相邻重复剪枝是核心；频次构造法从根源避免重复且实现简洁。
