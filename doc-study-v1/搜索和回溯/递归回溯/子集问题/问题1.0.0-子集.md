# 问题1.0.0 子集（LeetCode-78）

- 难度：中等
- 链接：https://leetcode.cn/problems/subsets/

## 概述
给定互不相同的整数数组，返回所有可能的子集（幂集）。

## 问题特征与分析引导
- 结果规模：幂集大小 `2^n`；指数增长，适合回溯或迭代生成。
- 约束特征：元素互不相同，无需去重；子集内元素顺序不重要。
- 生成方式：逐个元素“选/不选”两分支；或迭代把当前元素加入已有所有子集。

## 可能涉及的知识点
- 回溯模板：二叉选择（选/不选）
- 迭代生成：累计扩展法（从已有子集派生新子集）
- 复杂度评估：时间与空间受结果规模主导
