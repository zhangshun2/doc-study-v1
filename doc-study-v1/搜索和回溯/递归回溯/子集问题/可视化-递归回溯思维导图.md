## 🎯 关键概念可视化

### 1. Path的变化轨迹
```
时间线: ──→──→──→──→──→──→──→──→──→
Path:   []  [1] [1,2] [1,2,3] [1,2] [1] [1,3] [1] [] [2] [2,3] [2] [] [3] []
操作:   收集 +1   +2     +3     -3   -2   +3   -3  -1  +2   +3   -3  -2  +3  -3
```

### 2. Start参数的作用域
```
Level 0: start=0, 可选择 [1,2,3]
    │
    ├─ Level 1: start=1, 可选择 [2,3]  (选择了1)
    │     │
    │     ├─ Level 2: start=2, 可选择 [3]  (选择了2)
    │     └─ Level 2: start=3, 可选择 []   (选择了3)
    │
    ├─ Level 1: start=2, 可选择 [3]    (选择了2)
    └─ Level 1: start=3, 可选择 []     (选择了3)
```

### 3. 递归调用栈
```
调用栈深度:
┌─────────────┐ ← Level 3: backtrack(nums, 3, [1,2,3], res)
├─────────────┤ ← Level 2: backtrack(nums, 2, [1,2], res)
├─────────────┤ ← Level 1: backtrack(nums, 1, [1], res)
└─────────────┘ ← Level 0: backtrack(nums, 0, [], res)
```

## 🎮 游戏化理解：迷宫探索

```
想象你在一个迷宫中，每个房间都有宝藏：

房间布局:
┌─────┐    ┌─────┐    ┌─────┐
│ []  │────│ [1] │────│[1,2]│
│ 💎  │    │ 💎  │    │ 💎  │
└─────┘    └─────┘    └─────┘
   │          │          │
   │       ┌─────┐    ┌─────┐
   │       │[1,3]│    │[1,2,│
   │       │ 💎  │    │ 3]💎│
   │       └─────┘    └─────┘
   │
┌─────┐    ┌─────┐
│ [2] │────│[2,3]│
│ 💎  │    │ 💎  │
└─────┘    └─────┘
   │
┌─────┐
│ [3] │
│ 💎  │
└─────┘

规则:
1. 进入每个房间都要收集宝藏 (收集当前path)
2. 只能向"数字更大"的房间移动 (start控制)
3. 探索完一条路径要原路返回 (撤销操作)
4. 确保探索所有可能的路径
```

    1 2 3 4

## 💡 记忆口诀

```
🎵 递归回溯小口诀 🎵

进门就拍照 (收集当前状态)
选路往前跑 (选择元素递归)
走到头就回 (递归结束返回)
清理再换道 (撤销后继续循环)

只往后面选 (start控制方向)
不走回头路 (避免重复组合)
每条路都试 (完整遍历)
宝藏全收集 (所有子集)
```
