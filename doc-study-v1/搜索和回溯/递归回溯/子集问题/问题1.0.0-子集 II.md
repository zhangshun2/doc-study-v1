# 问题1.0.0 子集 II（LeetCode-90）

- 难度：中等
- 链接：https://leetcode.cn/problems/subsets-ii/

## 概述
给定可能包含重复元素的整数数组，返回所有不重复的子集。

## 问题特征与分析引导
- 重复与去重：输入存在重复，结果需唯一；在同一层（同一深度）避免重复选择相同值。
- 生成规模：幂集的去重版本，排序 + 去重控制生成过程。
- 两类方案：回溯（层内去重）与迭代（记录上一轮新增范围）。

## 可能涉及的知识点
- 排序 + 层内去重（`i>start && nums[i]==nums[i-1]`）
- 迭代法中的“起始索引控制”（只在上一轮新增的子集基础上扩展重复值）
- 复杂度：时间 O(n·2^n)，空间 O(2^n)
