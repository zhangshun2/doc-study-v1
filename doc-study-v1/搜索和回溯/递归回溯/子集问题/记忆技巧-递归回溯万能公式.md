## 🚀 万能模板（背这一个打天下）

### 🔥 黄金模板（5行代码搞定一切）
```java
void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path));           // 1. 收集结果
    for (int i = start; i < nums.length; i++) {  // 2. 遍历选择
        path.add(nums[i]);                       // 3. 做选择
        backtrack(nums, i + 1, path, result);   // 4. 递归
        path.remove(path.size() - 1);           // 5. 撤销选择
    }
}
```

## 📝 万能填空题（闭眼都能写）

### 模板1：子集问题
```java
void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> result) {
    result.add(new ArrayList<>(path));           // 收集
    for (int i = start; i < nums.length; i++) {  // 遍历
        path.add(nums[i]);                       // 选择
        backtrack(nums, i + 1, path, result);   // 递归
        path.remove(path.size() - 1);           // 撤销
    }
}
```

### 模板2：组合问题
```java
void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> result, int target) {
    if (target == 0) {                           // 收集条件
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < nums.length; i++) {  // 遍历
        if (nums[i] > target) break;             // 剪枝
        path.add(nums[i]);                       // 选择
        backtrack(nums, i, path, result, target - nums[i]); // 递归
        path.remove(path.size() - 1);           // 撤销
    }
}
```

### 模板3：排列问题
```java
void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> result) {
    if (path.size() == nums.length) {            // 收集条件
        result.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {      // 遍历
        if (used[i]) continue;                   // 跳过已用
        used[i] = true;                          // 标记
        path.add(nums[i]);                       // 选择
        backtrack(nums, used, path, result);     // 递归
        path.remove(path.size() - 1);           // 撤销
        used[i] = false;                         // 撤销标记
    }
}
```

## 🎯 常见错误及记忆方法

### 错误1：忘记 new ArrayList
```java
// 错误
result.add(path);

// 正确
result.add(new ArrayList<>(path));

// 记忆：拍照要复印，不能直接给原件
```

### 错误2：递归传递错误
```java
// 错误
backtrack(nums, start + 1, path, result);

// 正确
backtrack(nums, i + 1, path, result);

// 记忆：传递的是"下一个位置"，不是"当前位置+1"
```

### 错误3：remove位置错误
```java
// 错误
path.remove(0);
path.remove(i);

// 正确
path.remove(path.size() - 1);

// 记忆：撤销最后一个选择，就像撤销最后一步棋
```
