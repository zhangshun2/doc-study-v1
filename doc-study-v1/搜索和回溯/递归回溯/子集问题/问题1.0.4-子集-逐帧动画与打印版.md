# 问题1.0.4-子集-逐帧动画与打印版

目标：把“枚举起始位置”递归回溯模板中“撤销选择（pop）”的作用讲到一目了然，用逐帧状态图 + 打印日志的方式直观呈现。

## 可观察的关键特征（先建立心智锚点）
- path：临时组合篮子。选了谁，就暂时放进来；撤销选择就把“刚放进去的那一个”拿出来。
- start：本层枚举的起点索引。for 从 i=start 开始，递归时传 i+1，只能“向后选”，避免重复组合。
- 收集时机：子集问题每次进入递归就收集当前 path（包括空集），因为“当前前缀”就是一个有效子集。
- 基本节奏：选 → 递归 → 撤销。撤销一定对应“刚才那个选”，让状态回到本层 for 开始时的样子，好继续试“兄弟分支”。

## 极简直觉：试衣间/购物篮类比
- 你在每一层 for 循环里“挑选一个新衣服（元素）”放进购物篮 path。
- 走进下一间试衣间（递归），继续只从“后面的衣架（start 之后）”挑选。
- 试完出来，把刚才试的那件衣服拿出购物篮（pop），回到这一层继续试下一件（兄弟分支）。

## 逐帧动画示例一：nums = [1, 2]

我们用帧（Frame）来表示“进入递归”的瞬间状态（收集 path 的时机），并标注选择与撤销。

初始进入：Frame A
- start=0
- path=[]（收集空集）
- for: i=0..1

选择 i=0（选 1）→ 进入下一层：Frame B
- start=1
- path=[1]（收集 [1]）
- for: i=1..1
  - 选择 i=1（选 2）→ 进入下一层：Frame C
    - start=2
    - path=[1,2]（收集 [1,2]）
    - for 结束 → 返回上一层
  - 撤销选择：pop 2 → path=[1]
- 本层 for 结束 → 返回上一层
- 撤销选择：pop 1 → path=[]

回到 Frame A 的兄弟分支：选择 i=1（选 2）→ 进入下一层：Frame D
- start=2
- path=[2]（收集 [2]）
- for 结束 → 返回上一层
- 撤销选择：pop 2 → path=[]

最终收集到：[], [1], [1,2], [2]

把握关键：每次返回上一层，必须 pop 掉“刚才那一次选”，否则 path 会残留上层试过的元素，污染兄弟分支的起点。

## 逐帧动画示例二：nums = [1, 2, 3]

仅展示主干，关注“选 → 递归 → 撤销”的节奏。

Frame A：start=0, path=[]（收集 []），for i=0..2
- 选 1 → Frame B：start=1, path=[1]（收集 [1]），for i=1..2
  - 选 2 → Frame C：start=2, path=[1,2]（收集 [1,2]），for i=2..2
    - 选 3 → Frame D：start=3, path=[1,2,3]（收集 [1,2,3]）→ 返回
    - 撤销：pop 3 → path=[1,2]
  - 本层结束 → 撤销：pop 2 → path=[1]
  - 选 3 → Frame E：start=3, path=[1,3]（收集 [1,3]）→ 返回
  - 撤销：pop 3 → path=[1]
- 本层结束 → 撤销：pop 1 → path=[]
- 选 2 → Frame F：start=2, path=[2]（收集 [2]），for i=2..2
  - 选 3 → Frame G：start=3, path=[2,3]（收集 [2,3]）→ 返回
  - 撤销：pop 3 → path=[2]
- 本层结束 → 撤销：pop 2 → path=[]
- 选 3 → Frame H：start=3, path=[3]（收集 [3]）→ 返回
- 撤销：pop 3 → path=[]

最终：[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]

## 打印版（建议你亲手跑一下）

下面这段 Java 代码会在“选/撤销/进入/退出”时打印 path 和 start，把抽象节奏变为可视日志。

```java
import java.util.*;

public class SubsetTrace {
    public static List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        backtrack(nums, 0, path, res);
        return res;
    }

    private static void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
        System.out.println("ENTER start=" + start + ", path=" + path);
        res.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            System.out.println("  choose i=" + i + " (" + nums[i] + ") before: path=" + path);
            path.add(nums[i]);
            backtrack(nums, i + 1, path, res);
            System.out.println("  pop i=" + i + " (" + nums[i] + ") before pop: path=" + path);
            path.remove(path.size() - 1);
            System.out.println("  after pop: path=" + path);
        }
        System.out.println("EXIT  start=" + start + ", path=" + path);
    }

    public static void main(String[] args) {
        int[] nums = {1, 2, 3};
        List<List<Integer>> res = subsets(nums);
        System.out.println("Result=" + res);
    }
}
```

你会看到类似这样的片段（节选）：
```
ENTER start=0, path=[]
  choose i=0 (1) before: path=[]
ENTER start=1, path=[1]
  choose i=1 (2) before: path=[1]
ENTER start=2, path=[1,2]
  choose i=2 (3) before: path=[1,2]
ENTER start=3, path=[1,2,3]
EXIT  start=3, path=[1,2,3]
  pop i=2 (3) before pop: path=[1,2,3]
  after pop: path=[1,2]
EXIT  start=2, path=[1,2]
  pop i=1 (2) before pop: path=[1,2]
  after pop: path=[1]
  choose i=2 (3) before: path=[1]
ENTER start=3, path=[1,3]
EXIT  start=3, path=[1,3]
  pop i=2 (3) before pop: path=[1,3]
  after pop: path=[1]
EXIT  start=1, path=[1]
  pop i=0 (1) before pop: path=[1]
  after pop: path=[]
...
Result=[[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]
```
重点观察：“pop 之前 path 的样子”，和“pop 之后 path 的样子”。你会直观感受到 pop 的作用就是“复原到进入本层时的路径”，从而继续兄弟分支枚举。

## 常见误区纠正
- 误区1：以为这是 BFS。否，这个是 DFS（递归回溯）。BFS 会“分层推进”，这里是“一条路走到底再回头”。
- 误区2：以为只有到终点才收集。子集题每一帧（每次进入递归）都收集当前 path，因为任何前缀都代表一个有效子集。
- 误区3：以为可以不 pop。若不 pop，兄弟分支的起点就被前一次选择污染，枚举将错误或重复。
- 误区4：不理解 start 的意义。start 控制“只向后选”，这是组合问题避免不同顺序重复的关键（如 [1,2] 和 [2,1] 只保留一个）。
