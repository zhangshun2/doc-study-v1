# 题解2.0.0 子集 II（LeetCode-90）

## 题解一：官方经典（排序 + 回溯 + 层内去重）
- 思路：排序后在 `for` 循环中跳过同层的重复值；递归推进 `start=i+1` 保证组合路径非降序且不重复。
- 复杂度：时间 O(n·2^n)，空间 O(2^n)。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        dfs(nums, 0, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {
        res.add(new ArrayList<>(path));
        for (int i = start; i < nums.length; i++) {
            if (i > start && nums[i] == nums[i - 1]) continue; // 层内去重
            path.add(nums[i]);
            dfs(nums, i + 1, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解二：通用解法（迭代 + 上一轮新增范围控制）
- 标签：回溯、迭代、去重、层内控制
- 思路：排序后，若当前元素与前一个相同，则只从“上一轮新增的子集”开始扩展；否则从整个结果集合扩展。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        res.add(new ArrayList<>());
        int prevAddedStart = 0; // 上一轮新增的起始索引
        for (int i = 0; i < nums.length; i++) {
            int start = 0;
            int size = res.size();
            if (i > 0 && nums[i] == nums[i - 1]) start = prevAddedStart; // 只在上一轮新增中扩展
            prevAddedStart = size; // 更新本轮新增的起点（旧size）
            for (int j = start; j < size; j++) {
                List<Integer> cur = new ArrayList<>(res.get(j));
                cur.add(nums[i]);
                res.add(cur);
            }
        }
        return res;
    }
}
```

## 题解三：最好理解（“重复值只在新生成的子集上扩展”）
- 直觉：重复的数不要从所有子集扩展，只从上一轮刚生成的子集扩展，避免重复。

## 总结思路
- 层内去重与“上一轮新增范围”是两个等价的思路；排序是前提。
