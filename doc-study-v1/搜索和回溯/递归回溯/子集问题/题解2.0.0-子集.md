## 题解一：官方经典（迭代扩展法）
- 思路：维护结果列表，初始为 `[[]]`；每读入一个元素，就把它加入当前所有子集生成新子集并追加到结果中。
- 复杂度：时间 O(n·2^n)，空间 O(2^n)。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        res.add(new ArrayList<>());
        for (int x : nums) {
            int size = res.size();
            for (int i = 0; i < size; i++) {
                List<Integer> cur = new ArrayList<>(res.get(i));
                cur.add(x);
                res.add(cur);
            }
        }
        return res;
    }
}
```

## 题解二：通用解法（回溯：选/不选）
- 标签：回溯、子集枚举、二叉选择
- 思路：对每个位置做两种选择：选或不选；到达末尾时收集路径。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(nums, 0, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] nums, int idx, List<Integer> path, List<List<Integer>> res) {
        if (idx == nums.length) { res.add(new ArrayList<>(path)); return; }
        // 不选
        dfs(nums, idx + 1, path, res);
        // 选择
        path.add(nums[idx]);
        dfs(nums, idx + 1, path, res);
        path.remove(path.size() - 1);
    }
}
```

## 题解三：最好理解（“每个元素要么选，要么不选”）
- 直觉：逐个元素决定是否加入，穷举所有可能的选择集合。

## 总结思路
- 回溯与迭代本质等价；迭代更易实现，回溯更贴近二叉选择的思维。
