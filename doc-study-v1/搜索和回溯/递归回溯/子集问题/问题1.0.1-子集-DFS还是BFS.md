# 问题1.0.1-子集-DFS还是BFS

## 问题描述
在《问题1.0.0-子集.md》的第 49-64 行，采用“选择/不选择”的递归写法，有同学觉得这更像“广度优先（BFS）”。到底该如何区分这段代码是 DFS（回溯）还是 BFS？

## 引导思路
- 从“递归调用顺序”与“调用栈行为”来判断：是否是沿着一条路径一直深入到叶子，然后再回退？
- 从“结果生成顺序”来判断：是否是一层一层地按元素个数扩展（0 个、1 个、2 个…）？
- 从“数据结构”来判断：是否使用了队列（Queue）进行逐层处理，还是依赖函数调用栈与路径临时变量（path）？

## 可观察特征（针对第 49-64 行）
- 函数以 index 为“深度”，每次递归只推进一个元素的选择状态（不选/选），直到 index == len(nums) 才收集结果。
- 使用 path.append / path.pop 在同一条路径上做选择与回退（典型回溯痕迹）。
- 不存在按“层”的概念进行队列式推进，因此不是 BFS。

## 可能涉及的知识点
- 回溯（Depth-First Search，DFS）：决策树、路径变量、边界条件、回退（pop）。
- 广度优先（Breadth-First Search，BFS）：队列、层序展开、迭代式逐层构造。
- 子集问题的两种常见生成方式：回溯（DFS）与迭代扩展（类 BFS）。
