# 题解2.0.9-子集问题完整解法指南

## 🎯 问题回顾

**LeetCode 78. 子集**

给你一个整数数组 `nums`，数组中的元素**互不相同**。返回该数组所有可能的子集（幂集）。

**示例**：
```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

## 🔍 问题特征分析

### 关键特征
1. **幂集问题**：需要生成所有可能的子集
2. **包含空集**：`[]` 也是一个有效子集
3. **长度可变**：子集长度从 0 到 n
4. **每个节点都是答案**：与排列不同，递归的每个节点都代表一个有效子集

### 数学性质
- **子集总数**：2^n 个（每个元素选择或不选择）
- **决策过程**：对每个元素做二元选择

## 🚀 解法一：选择/不选择模式

### 核心思想
对每个元素都有两种选择：**选择** 或 **不选择**

### 代码实现
```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    
    backtrack(nums, 0, path, result);
    return result;
}

private void backtrack(int[] nums, int index, 
                      List<Integer> path, List<List<Integer>> result) {
    // 1. 终止条件：遍历完所有元素
    if (index == nums.length) {
        result.add(new ArrayList<>(path));
        return;
    }
    
    // 2. 不选择当前元素
    backtrack(nums, index + 1, path, result);
    
    // 3. 选择当前元素
    path.add(nums[index]);
    backtrack(nums, index + 1, path, result);
    path.remove(path.size() - 1);  // 撤销选择
}
```

### 执行过程（nums = [1,2,3]）
```
                    []
                 /      \
            不选1          选1
           /      \      /      \
       不选2      选2   不选2     选2
      /    \    /   \   /   \   /    \
   不选3  选3 不选3 选3 不选3 选3 不选3  选3
    []   [3]  [2] [2,3] [1] [1,3] [1,2] [1,2,3]
```

## 🎪 解法二：枚举起始位置模式（推荐）

### 核心思想
从每个位置开始，选择后续的元素，使用 `startIndex` 避免重复

### 代码实现
```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    
    backtrack(nums, 0, path, result);
    return result;
}

private void backtrack(int[] nums, int startIndex,
                      List<Integer> path, List<List<Integer>> result) {
    // 1. 收集当前子集（每个节点都是有效子集）
    result.add(new ArrayList<>(path));
    
    // 2. 遍历选择列表
    for (int i = startIndex; i < nums.length; i++) {
        // 3. 做选择
        path.add(nums[i]);
        
        // 4. 递归（从下一个位置开始）
        backtrack(nums, i + 1, path, result);
        
        // 5. 撤销选择
        path.remove(path.size() - 1);
    }
}
```

### 执行过程可视化
```
调用 backtrack(nums, 0, [], result)
├─ 收集 [] → result = [[]]
├─ i=0: 选择1
│  ├─ path=[1], 调用 backtrack(nums, 1, [1], result)
│  │  ├─ 收集 [1] → result = [[], [1]]
│  │  ├─ i=1: 选择2
│  │  │  ├─ path=[1,2], 调用 backtrack(nums, 2, [1,2], result)
│  │  │  │  ├─ 收集 [1,2] → result = [[], [1], [1,2]]
│  │  │  │  ├─ i=2: 选择3
│  │  │  │  │  ├─ path=[1,2,3], 调用 backtrack(nums, 3, [1,2,3], result)
│  │  │  │  │  │  └─ 收集 [1,2,3] → result = [[], [1], [1,2], [1,2,3]]
│  │  │  │  │  └─ 撤销3, path=[1,2]
│  │  │  │  └─ 循环结束
│  │  │  └─ 撤销2, path=[1]
│  │  ├─ i=2: 选择3
│  │  │  ├─ path=[1,3], 调用 backtrack(nums, 3, [1,3], result)
│  │  │  │  └─ 收集 [1,3] → result = [[], [1], [1,2], [1,2,3], [1,3]]
│  │  │  └─ 撤销3, path=[1]
│  │  └─ 循环结束
│  └─ 撤销1, path=[]
├─ i=1: 选择2
│  ├─ path=[2], 调用 backtrack(nums, 2, [2], result)
│  │  ├─ 收集 [2] → result = [..., [2]]
│  │  ├─ i=2: 选择3
│  │  │  ├─ path=[2,3], 调用 backtrack(nums, 3, [2,3], result)
│  │  │  │  └─ 收集 [2,3] → result = [..., [2,3]]
│  │  │  └─ 撤销3, path=[2]
│  │  └─ 循环结束
│  └─ 撤销2, path=[]
├─ i=2: 选择3
│  ├─ path=[3], 调用 backtrack(nums, 3, [3], result)
│  │  └─ 收集 [3] → result = [..., [3]]
│  └─ 撤销3, path=[]
└─ 循环结束

最终结果：[[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]
```

## ⚡ 解法三：位运算枚举

### 核心思想
用二进制位表示每个元素的选择状态，1表示选择，0表示不选择

### 代码实现
```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    int n = nums.length;
    
    // 遍历所有可能的二进制状态：0 到 2^n-1
    for (int mask = 0; mask < (1 << n); mask++) {
        List<Integer> subset = new ArrayList<>();
        
        // 检查每一位
        for (int i = 0; i < n; i++) {
            // 如果第i位为1，选择nums[i]
            if ((mask & (1 << i)) != 0) {
                subset.add(nums[i]);
            }
        }
        
        result.add(subset);
    }
    
    return result;
}
```

### 位运算过程（nums = [1,2,3]）
```
mask = 000 (0) → 不选任何元素 → []
mask = 001 (1) → 选择nums[0] → [1]
mask = 010 (2) → 选择nums[1] → [2]
mask = 011 (3) → 选择nums[0],nums[1] → [1,2]
mask = 100 (4) → 选择nums[2] → [3]
mask = 101 (5) → 选择nums[0],nums[2] → [1,3]
mask = 110 (6) → 选择nums[1],nums[2] → [2,3]
mask = 111 (7) → 选择所有元素 → [1,2,3]
```

## 📊 三种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|------------|------------|------|------|
| 选择/不选择 | O(2^n × n) | O(n) | 思路最清晰 | 递归深度深 |
| 枚举起始位置 | O(2^n × n) | O(n) | 代码简洁，面试推荐 | 需理解去重原理 |
| 位运算 | O(2^n × n) | O(1) | 效率最高，无递归 | 不够直观 |

## 💡 关键理解点

### 1. 为什么每个节点都收集？
```java
// 子集问题：每个节点都是有效子集
result.add(new ArrayList<>(path));  // 在递归开始就收集

// 对比：排列问题只在叶子节点收集
if (path.size() == nums.length) {
    result.add(new ArrayList<>(path));  // 只在满足条件时收集
}
```

### 2. startIndex的作用
```java
// 有startIndex：避免重复
for (int i = startIndex; i < nums.length; i++)
// [1,2,3] → 生成 [1,2], [1,3], [2,3] ✅

// 无startIndex：会产生重复
for (int i = 0; i < nums.length; i++)
// [1,2,3] → 生成 [1,2], [2,1], [1,3], [3,1], [2,3], [3,2] ❌
```

### 3. 撤销的时机
```java
path.add(nums[i]);        // 做选择
backtrack(nums, i + 1, path, result);  // 递归
path.remove(path.size() - 1);  // 撤销选择（关键！）
```
