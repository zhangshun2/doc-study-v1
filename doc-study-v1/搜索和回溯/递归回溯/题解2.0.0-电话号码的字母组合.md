# 题解2.0.0 电话号码的字母组合（LeetCode-17）

## 题解一：官方经典（回溯 DFS 构造）
- 思路：从第 0 位数字开始递归，每次选择该位映射的一个字母加入路径，进入下一位；当路径长度等于输入长度时收集结果。
- 复杂度：时间约为乘积规模，空间 O(n) 递归深度。

```java
import java.util.*;
class Solution {
    private static final String[] map = {
        "",    "",    "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
    };
    public List<String> letterCombinations(String digits) {
        List<String> res = new ArrayList<>();
        if (digits == null || digits.length() == 0) return res;
        StringBuilder path = new StringBuilder();
        dfs(digits, 0, path, res);
        return res;
    }
    private void dfs(String d, int idx, StringBuilder path, List<String> res) {
        if (idx == d.length()) { res.add(path.toString()); return; }
        String letters = map[d.charAt(idx) - '0'];
        for (int i = 0; i < letters.length(); i++) {
            path.append(letters.charAt(i));
            dfs(d, idx + 1, path, res);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
```

## 题解二：通用解法（队列 BFS 逐位扩展）
- 标签：回溯、DFS、BFS、组合构造
- 思路：使用队列从空串开始，逐位展开，将当前队列中的每个项与该位的所有字母组合成新项入队。

```java
import java.util.*;
class Solution {
    private static final String[] map = {
        "",    "",    "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"
    };
    public List<String> letterCombinations(String digits) {
        List<String> res = new ArrayList<>();
        if (digits == null || digits.length() == 0) return res;
        Deque<String> q = new ArrayDeque<>();
        q.offer("");
        for (int i = 0; i < digits.length(); i++) {
            String letters = map[digits.charAt(i) - '0'];
            int size = q.size();
            for (int s = 0; s < size; s++) {
                String base = q.poll();
                for (int k = 0; k < letters.length(); k++) q.offer(base + letters.charAt(k));
            }
        }
        res.addAll(q); return res;
    }
}
```

## 题解三：最好理解（“每一位选一个字母，递归到底”）
- 直觉：每个数字位都要选择它映射的一个字母，选完所有位就得到一个组合，把所有选择路径都走一遍即可。

## 总结思路
- DFS 与 BFS 等价于不同的枚举顺序；DFS 更贴近回溯模板，BFS 有助于理解逐位扩展。
