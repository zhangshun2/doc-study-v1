# 问题1.0.0 括号生成（LeetCode-22）

- 难度：中等
- 链接：https://leetcode.cn/problems/generate-parentheses/

## 概述
给定 `n`，生成 `n` 对括号的所有有效组合。

## 问题特征与分析引导
- 输入特征：单个整数 `n`，范围常见为 1~10。
- 输出特征：数量为第 `n` 个卡特兰数，指数增长，必须剪枝，否则爆炸。
- 有效性特征：任何前缀中左括号数量必须 ≥ 右括号数量；最终左右括号各为 `n`。

## 可能涉及的知识点
- 回溯 + 剪枝：约束驱动的选择（还能放左括号/右括号）
- 卡特兰数与括号合法性计数
- 生成树的状态定义：已放的左右括号计数
