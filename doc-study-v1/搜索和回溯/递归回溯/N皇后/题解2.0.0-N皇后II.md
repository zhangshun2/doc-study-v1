题解2.0.0 - N 皇后 II（N-Queens II, LeetCode 52）

概述：同 N 皇后，使用冲突数组回溯但仅统计方案数量。

题解一：回溯计数（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    int ans = 0; boolean[] col, diag, anti;
    public int totalNQueens(int n) {
        col = new boolean[n]; diag = new boolean[2*n]; anti = new boolean[2*n];
        dfs(0, n);
        return ans;
    }
    private void dfs(int r, int n) {
        if (r == n) { ans++; return; }
        for (int c = 0; c < n; c++) {
            int d = r + c, a = r - c + n;
            if (!col[c] && !diag[d] && !anti[a]) {
                col[c] = diag[d] = anti[a] = true;
                dfs(r + 1, n);
                col[c] = diag[d] = anti[a] = false;
            }
        }
    }
}
```

复杂度：
- 同 N 皇后；只计数不构造解列表。
