# 题解2.0.0 N皇后 II（LeetCode-52）

## 题解一：官方经典（集合占用 + 计数）
- 思路：同 51，但在到达行 `n` 时计数 `ans++`；不构造棋盘。

```java
import java.util.*;
class Solution {
    int ans = 0, n;
    Set<Integer> cols = new HashSet<>();
    Set<Integer> d1 = new HashSet<>();
    Set<Integer> d2 = new HashSet<>();
    public int totalNQueens(int n) { this.n = n; dfs(0); return ans; }
    private void dfs(int r) {
        if (r == n) { ans++; return; }
        for (int c = 0; c < n; c++) {
            if (cols.contains(c) || d1.contains(r - c) || d2.contains(r + c)) continue;
            cols.add(c); d1.add(r - c); d2.add(r + c);
            dfs(r + 1);
            cols.remove(c); d1.remove(r - c); d2.remove(r + c);
        }
    }
}
```

## 题解二：通用解法（位掩码计数）
- 标签：回溯、位运算、计数
- 思路：与 51 的位掩码一致，但仅返回总数。

```java
import java.util.*;
class Solution {
    int n, ans = 0;
    public int totalNQueens(int n) { this.n = n; dfs(0, 0, 0, 0); return ans; }
    private void dfs(int r, int cols, int d1, int d2) {
        if (r == n) { ans++; return; }
        int avail = ((1 << n) - 1) & ~(cols | d1 | d2);
        while (avail != 0) {
            int pick = avail & -avail; avail -= pick;
            dfs(r + 1, cols | pick, (d1 | pick) << 1, (d2 | pick) >> 1);
        }
    }
}
```
