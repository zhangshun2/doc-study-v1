题解2.0.0 - N 皇后（N-Queens, LeetCode 51）

概述：使用三类布尔数组 `col`、`diag`、`anti` 检查列与对角线占用，逐行放置并回溯构造所有解。

题解一：回溯 + 冲突数组（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    List<List<String>> ans = new ArrayList<>();
    boolean[] col, diag, anti;
    char[][] board;
    public List<List<String>> solveNQueens(int n) {
        col = new boolean[n]; diag = new boolean[2*n]; anti = new boolean[2*n];
        board = new char[n][n]; for (char[] r : board) Arrays.fill(r, '.');
        backtrack(0, n);
        return ans;
    }
    private void backtrack(int r, int n) {
        if (r == n) { ans.add(toList()); return; }
        for (int c = 0; c < n; c++) {
            int d = r + c, a = r - c + n;
            if (!col[c] && !diag[d] && !anti[a]) {
                col[c] = diag[d] = anti[a] = true;
                board[r][c] = 'Q';
                backtrack(r + 1, n);
                board[r][c] = '.';
                col[c] = diag[d] = anti[a] = false;
            }
        }
    }
    private List<String> toList() {
        List<String> out = new ArrayList<>();
        for (char[] r : board) out.add(new String(r));
        return out;
    }
}
```

复杂度：
- 解空间复杂，时间近似 O(n!)；空间 O(n^2) 用于棋盘构造。

思考小结：
- 用布尔数组进行 O(1) 冲突检测可大幅提升效率；也可用位运算优化。

标签：回溯、棋盘、冲突检测
