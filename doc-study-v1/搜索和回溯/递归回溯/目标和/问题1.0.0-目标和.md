# 问题1.0.0 目标和（LeetCode-494）

- 难度：中等
- 链接：https://leetcode.cn/problems/target-sum/

## 概述
给定非负整数数组 `nums` 和目标值 `target`，将每个数字前添加 `+` 或 `-` 使表达式的值等于 `target`，求有多少种方法。

## 问题特征与分析引导
- 选择结构：每个位置两种选择（加或减），朴素 DFS 为 `2^n`；可用记忆化或转化为子集和计数。
- 经典转化：设正号部分为 `P`，负号部分为 `N`，则 `P - N = target` 且 `P + N = sum`，得 `P = (sum + target)/2`，转为计数子集和为 `P` 的方法数。

## 可能涉及的知识点
- 回溯 + 记忆化搜索
- 动态规划：子集和计数（背包）
- BFS层序搜索：状态空间探索
- 边界校验：`sum + target` 必须为偶数且 `P >= 0`
