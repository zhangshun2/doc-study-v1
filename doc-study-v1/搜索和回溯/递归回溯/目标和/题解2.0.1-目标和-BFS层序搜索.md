## 方法一：BFS层序搜索（状态空间探索）

### 算法思路
使用BFS按层处理每个数字，每层代表处理到某个索引位置时的所有可能累计和及其出现次数。通过哈希表记录每个状态的方案数，避免重复计算。

### 复杂度分析
- **时间复杂度**：O(n × S)，其中S是累计和的范围
- **空间复杂度**：O(S)，哈希表存储状态
- **优势**：避免递归栈溢出，状态转移清晰可见

### Java实现
```java
import java.util.*;

class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        // 使用Map记录每个累计和的出现次数
        Map<Integer, Integer> dp = new HashMap<>();
        dp.put(0, 1); // 初始状态：和为0有1种方法
        
        for (int num : nums) {
            Map<Integer, Integer> nextDp = new HashMap<>();
            
            // 遍历当前所有可能的状态
            for (Map.Entry<Integer, Integer> entry : dp.entrySet()) {
                int currentSum = entry.getKey();
                int count = entry.getValue();
                
                // 两种选择：加当前数字或减当前数字
                int addSum = currentSum + num;
                int subtractSum = currentSum - num;
                
                // 更新新状态的出现次数
                nextDp.put(addSum, nextDp.getOrDefault(addSum, 0) + count);
                nextDp.put(subtractSum, nextDp.getOrDefault(subtractSum, 0) + count);
            }
            
            dp = nextDp; // 移动到下一层
        }
        
        return dp.getOrDefault(target, 0);
    }
}
```

### 执行过程演示
以 `nums = [1,1,1,1,1]`, `target = 3` 为例：

| 处理数字 | 当前状态（和:次数） | 下一层状态（和:次数） |
|----------|---------------------|-----------------------|
| 初始     | {0:1}               | -                     |
| 数字1    | {0:1}               | {1:1, -1:1}           |
| 数字1    | {1:1, -1:1}         | {2:1, 0:2, -2:1}      |
| 数字1    | {2:1, 0:2, -2:1}    | {3:1, 1:3, -1:3, -3:1} |
| 数字1    | {3:1, 1:3, -1:3, -3:1} | {4:1, 2:4, 0:6, -2:4, -4:1} |
| 数字1    | {4:1, 2:4, 0:6, -2:4, -4:1} | {5:1, 3:5, 1:10, -1:10, -3:5, -5:1} |

最终结果为5，即和为3有5种方法。

## 方法二：优化版BFS（使用数组替代Map）

### 优化思路
由于累计和的范围有限（-sum ~ +sum），可以使用数组来替代HashMap，提高性能。

### Java实现
```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int num : nums) sum += num;
        
        // 累计和范围：-sum 到 +sum，共 2*sum+1 种可能
        int range = 2 * sum + 1;
        
        // 初始化DP数组，偏移量为sum（让索引0对应和-sum）
        int[] dp = new int[range];
        dp[sum] = 1; // 初始状态：和为0（对应索引sum）
        
        for (int num : nums) {
            int[] nextDp = new int[range];
            
            for (int s = 0; s < range; s++) {
                if (dp[s] == 0) continue;
                
                // 计算新的和对应的索引
                int addIndex = s + num;
                int subtractIndex = s - num;
                
                if (addIndex >= 0 && addIndex < range) {
                    nextDp[addIndex] += dp[s];
                }
                if (subtractIndex >= 0 && subtractIndex < range) {
                    nextDp[subtractIndex] += dp[s];
                }
            }
            
            dp = nextDp;
        }
        
        // 目标值对应的索引：target + sum
        int targetIndex = target + sum;
        if (targetIndex < 0 || targetIndex >= range) return 0;
        return dp[targetIndex];
    }
}
```

## 方法三：记忆化DFS（递归+缓存）

### Java实现
```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        // 使用备忘录缓存 (index, currentSum) 的结果
        Map<String, Integer> memo = new HashMap<>();
        return dfs(nums, 0, 0, target, memo);
    }
    
    private int dfs(int[] nums, int index, int currentSum, int target, Map<String, Integer> memo) {
        if (index == nums.length) {
            return currentSum == target ? 1 : 0;
        }
        
        String key = index + "," + currentSum;
        if (memo.containsKey(key)) {
            return memo.get(key);
        }
        
        // 两种选择：加当前数字或减当前数字
        int addWays = dfs(nums, index + 1, currentSum + nums[index], target, memo);
        int subtractWays = dfs(nums, index + 1, currentSum - nums[index], target, memo);
        
        int totalWays = addWays + subtractWays;
        memo.put(key, totalWays);
        
        return totalWays;
    }
}
```

## 性能对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|------------|------------|----------|
| BFS层序搜索(Map) | O(n × S) | O(S) | 中等规模，需要状态可视化 |
| BFS层序搜索(数组) | O(n × S) | O(S) | 大规模，性能要求高 |
| 记忆化DFS | O(n × S) | O(n × S) | 递归深度可控时 |
| DP数学转化 | O(n × P) | O(P) | P较小时最优 |

## 易错点Checklist

1. ✅ 初始状态正确设置：和为0有1种方法
2. ✅ 状态转移时累加计数，不是重置
3. ✅ 处理边界情况：目标值可能超出合理范围
4. ✅ 使用合适的哈希键避免状态冲突
5. ✅ 数组版本注意索引偏移量的处理

## 总结
BFS层序搜索提供了直观的状态转移视角，特别适合理解问题的本质。对于"目标和"问题，多种方法各有优劣，应根据具体场景选择合适的方法。
