## 题解一：官方经典（转化为子集和计数 DP）
- 思路：令 `P = (sum + target)/2`，若不合法直接返回 0；用一维 DP `dp[s]` 表示恰好和为 `s` 的方法数，遍历每个数 `x`，倒序更新 `dp[s] += dp[s-x]`。
- 复杂度：时间 O(n·P)，空间 O(P)。

```java
import java.util.*;
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0; for (int x : nums) sum += x;
        int v = sum + target; if ((v & 1) == 1) return 0;
        int P = v / 2; if (P < 0) return 0;
        int[] dp = new int[P + 1]; dp[0] = 1;
        for (int x : nums) {
            for (int s = P; s >= x; s--) dp[s] += dp[s - x];
        }
        return dp[P];
    }
}
```

## 题解二：通用解法（DFS + 记忆化）
- 标签：回溯、记忆化、子集和
- 思路：记忆 `(idx, curSum)` 的方案数，递归加或减当前值；避免重复子问题。

```java
import java.util.*;
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        Map<String, Integer> memo = new HashMap<>();
        return dfs(nums, 0, 0, target, memo);
    }
    private int dfs(int[] a, int i, int sum, int target, Map<String,Integer> memo) {
        if (i == a.length) return sum == target ? 1 : 0;
        String key = i + "," + sum;
        Integer cached = memo.get(key);
        if (cached != null) return cached;
        int ans = dfs(a, i + 1, sum + a[i], target, memo) + dfs(a, i + 1, sum - a[i], target, memo);
        memo.put(key, ans); return ans;
    }
}
```

## 题解三：最好理解（“每个数加或减，统计能达到目标的条数”）
- 直觉：两种选择形成二叉树，记忆化避免重复计算；也可用 DP 直接数子集和的条数。

## 总结思路
- DP 转化是最稳健方案；记忆化 DFS 易实现且在规模适中时表现良好。
