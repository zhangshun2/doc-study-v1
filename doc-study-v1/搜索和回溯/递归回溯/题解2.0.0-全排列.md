# 题解2.0.0 全排列（LeetCode-46）

## 题解一：官方经典（回溯 + used[]）
- 思路：用布尔数组标记已使用元素，将未使用元素依次加入路径，递归到长度 `n` 收集结果。
- 复杂度：时间为结果规模 `O(n * n!)`，空间 O(n) 递归深度。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        boolean[] used = new boolean[nums.length];
        List<Integer> path = new ArrayList<>();
        dfs(nums, used, path, res);
        return res;
    }
    private void dfs(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true;
            path.add(nums[i]);
            dfs(nums, used, path, res);
            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

## 题解二：通用解法（nextPermutation 枚举字典序）
- 标签：回溯、生成、字典序、构造
- 思路：先排序得到最小排列，然后重复调用“下一个排列”，直到返回到最大排列；每次记录一个结果。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        while (true) {
            List<Integer> cur = new ArrayList<>();
            for (int x : nums) cur.add(x);
            res.add(cur);
            if (!next(nums)) break;
        }
        return res;
    }
    private boolean next(int[] a) {
        int n = a.length, i = n - 2;
        while (i >= 0 && a[i] >= a[i + 1]) i--;
        if (i < 0) return false;
        int j = n - 1; while (a[j] <= a[i]) j--;
        swap(a, i, j); reverse(a, i + 1, n - 1); return true;
    }
    private void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }
    private void reverse(int[] a, int l, int r) { while (l < r) swap(a, l++, r--); }
}
```

## 题解三：最好理解（“每次挑一个没用过的，凑满就收集”）
- 直觉：在剩余元素里逐个尝试，把所有可能的顺序都枚举一遍。

## 总结思路
- `used[]` 的标记-回退是关键；字典序枚举适合法条明确的迭代生成。
