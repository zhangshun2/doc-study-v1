1. **模板相似性高** - 可以直接套用子集问题的思路

#### 新增学习点
- **约束条件设计**：左括号数量 ≤ n，右括号数量 ≤ 左括号数量

- **状态参数**：除了path，还需要left和right计数器

- **目标约束管理**：如何在递归过程中跟踪当前和值
- **剪枝优化**：如何通过排序和提前终止提高效率

## 💡 核心模板对比

### 子集问题模板（基础）
```java
void backtrack(int[] nums, int startIndex, List<Integer> path) {
    result.add(new ArrayList<>(path));  // 收集结果
    
    for (int i = startIndex; i < nums.length; i++) {
        path.add(nums[i]);              // 选择
        backtrack(nums, i + 1, path);   // 递归
        path.remove(path.size() - 1);   // 撤销
    }
}
```

### 括号生成模板（约束条件）
```java
void backtrack(int n, int left, int right, StringBuilder path) {
    if (path.length() == 2 * n) {      // 终止条件
        result.add(path.toString());
        return;
    }
    
    if (left < n) {                    // 约束：左括号数量
        path.append('(');
        backtrack(n, left + 1, right, path);
        path.deleteCharAt(path.length() - 1);
    }
    
    if (right < left) {                // 约束：右括号数量
        path.append(')');
        backtrack(n, left, right + 1, path);
        path.deleteCharAt(path.length() - 1);
    }
}
```

### 组合总和模板（重复选择）
```java
void backtrack(int[] candidates, int target, int startIndex, List<Integer> path) {
    if (target == 0) {                 // 终止条件
        result.add(new ArrayList<>(path));
        return;
    }
    
    for (int i = startIndex; i < candidates.length; i++) {
        if (target - candidates[i] < 0) break;  // 剪枝
        
        path.add(candidates[i]);
        backtrack(candidates, target - candidates[i], i, path);  // 注意：i而不是i+1
        path.remove(path.size() - 1);
    }
}
```

### 全排列模板（状态管理）
```java
void backtrack(int[] nums, boolean[] used, List<Integer> path) {
    if (path.size() == nums.length) {  // 终止条件
        result.add(new ArrayList<>(path));
        return;
    }
    
    for (int i = 0; i < nums.length; i++) {  // 注意：从0开始
        if (used[i]) continue;         // 跳过已使用的元素
        
        path.add(nums[i]);
        used[i] = true;                // 标记使用
        backtrack(nums, used, path);
        used[i] = false;               // 撤销标记
        path.remove(path.size() - 1);
    }
}
```
