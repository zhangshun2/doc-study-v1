# 题解2.0.0 组合（LeetCode-77）

## 题解一：官方经典（回溯 + 剪枝）
- 思路：从 `start` 开始选择下一个数加入路径，递归到长度 `k` 收集；按剩余数量进行剪枝。
- 复杂度：时间为结果规模，空间 O(k)。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(1, n, k, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int start, int n, int k, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == k) { res.add(new ArrayList<>(path)); return; }
        for (int i = start; i <= n; i++) {
            int need = k - path.size();
            int remain = n - i + 1;
            if (remain < need) break; // 剪枝
            path.add(i);
            dfs(i + 1, n, k, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解二：通用解法（迭代字典序生成）
- 标签：组合、迭代、字典序
- 思路：用一个长度为 `k` 的数组维护当前组合，按字典序迭代生成下一个组合（类似生成器）。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> res = new ArrayList<>();
        int[] comb = new int[k];
        for (int i = 0; i < k; i++) comb[i] = i + 1;
        while (true) {
            List<Integer> cur = new ArrayList<>();
            for (int x : comb) cur.add(x);
            res.add(cur);
            int idx = k - 1;
            while (idx >= 0 && comb[idx] == n - (k - 1 - idx)) idx--;
            if (idx < 0) break;
            comb[idx]++;
            for (int j = idx + 1; j < k; j++) comb[j] = comb[j - 1] + 1;
        }
        return res;
    }
}
```

## 题解三：最好理解（“从小到大挑够k个，不够就停”）
- 直觉：按递增挑选，不回头；剩下的数加起来都不够就停止。

## 总结思路
- 回溯更直观，迭代生成器便于理解字典序；剪枝能显著提速。
