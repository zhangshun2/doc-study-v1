# 题解2.0.0 非递减子序列（LeetCode-491）

## 题解一：官方经典（回溯 + 层内去重）
- 思路：用 `last` 表示路径最后一个值（或用 `Integer.MIN_VALUE` 表示未选），本层用 `Set` 记录已选过的值，避免重复；长度 ≥ 2 时收集。
- 复杂度：时间受解空间影响，空间 O(n)。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> findSubsequences(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(nums, 0, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] a, int idx, List<Integer> path, List<List<Integer>> res) {
        if (path.size() >= 2) res.add(new ArrayList<>(path));
        Set<Integer> used = new HashSet<>();
        for (int i = idx; i < a.length; i++) {
            if (!used.add(a[i])) continue; // 层内去重
            if (path.isEmpty() || a[i] >= path.get(path.size() - 1)) {
                path.add(a[i]);
                dfs(a, i + 1, path, res);
                path.remove(path.size() - 1);
            }
        }
    }
}
```

## 题解二：通用解法（记录 last 并剪枝）
- 标签：回溯、层内去重、子序列
- 思路：携带 `last` 参数用于比较，仍在本层用 `Set` 去重，逻辑更清晰。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> findSubsequences(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(nums, 0, Integer.MIN_VALUE, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] a, int idx, int last, List<Integer> path, List<List<Integer>> res) {
        if (path.size() >= 2) res.add(new ArrayList<>(path));
        Set<Integer> used = new HashSet<>();
        for (int i = idx; i < a.length; i++) {
            if (!used.add(a[i])) continue;
            if (a[i] < last) continue;
            path.add(a[i]);
            dfs(a, i + 1, a[i], path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解三：最好理解（“每层不要重复用同样的数，序列要不减”）
- 直觉：对每个起点往后选，选的数要不小于上一个；同一层相同值只用一次，避免得到重复序列。

## 总结思路
- 层内去重是关键；携带 `last` 或从路径末尾取值均可；长度过滤在进入下一层时即可收集。
