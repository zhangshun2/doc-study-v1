# 问题1.0.0 非递减子序列（LeetCode-491）

- 难度：中等
- 链接：https://leetcode.cn/problems/non-decreasing-subsequences/

## 概述
返回所有不严格递减（即非递减）且长度至少为 2 的子序列（保持原始相对顺序），输入可能包含重复元素，结果不能重复。

## 问题特征与分析引导
- 约束：子序列需要满足当前选择的值 `>=` 上一个选择的值。
- 去重：同一层（同一起点位置）不能选择相同值多次，需使用“层内去重集合”。
- 生成规模：受分布影响，典型回溯枚举。

## 可能涉及的知识点
- 回溯模板：保持最后选择值，按索引推进
- 层内去重：使用 `Set<Integer>` 控制本层已用值
- 结果长度过滤（至少为 2）
