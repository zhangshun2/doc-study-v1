# 问题1.0.0-电话号码的字母组合

## 原题链接
[LeetCode 17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

## 题目描述

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

![电话按键映射](https://assets.leetcode-cn.com/aliyun-lc-upload/uploads/2021/11/09/200px-telephone-keypad2svg.png)

## 示例

### 示例 1：
```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

### 示例 2：
```
输入：digits = ""
输出：[]
```

### 示例 3：
```
输入：digits = "2"
输出：["a","b","c"]
```

## 约束条件

- `0 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字。

## 数字字母映射表

| 数字 | 对应字母 |
|------|----------|
| 2    | abc      |
| 3    | def      |
| 4    | ghi      |
| 5    | jkl      |
| 6    | mno      |
| 7    | pqrs     |
| 8    | tuv      |
| 9    | wxyz     |

## 问题特征分析

1. **组合枚举问题**：需要枚举所有可能的字母组合
2. **递归结构**：每个数字位置都需要选择一个对应的字母
3. **决策树**：每层决策选择当前数字对应的一个字母
4. **无重复**：每个数字位置只能选择一次，不存在重复选择问题
5. **固定长度**：结果字符串长度等于输入数字字符串长度

## 核心思路

这是一个典型的**递归回溯**问题：
- **状态**：当前处理到第几个数字（index）、当前构建的字符串（path）
- **选择**：当前数字对应的所有字母
- **递归**：处理下一个数字位置
- **终止条件**：处理完所有数字位置

## 解题框架

```
递归函数(当前位置index, 当前路径path):
    if index == digits.length:
        收集当前路径到结果集
        return
    
    for 当前数字对应的每个字母:
        path.append(字母)        # 做选择
        递归函数(index+1, path)  # 递归
        path.pop()              # 撤销选择（回溯）
```
