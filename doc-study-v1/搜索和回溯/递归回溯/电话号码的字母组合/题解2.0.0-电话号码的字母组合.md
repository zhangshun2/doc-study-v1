# 题解2.0.0-电话号码的字母组合

## 问题回顾
[LeetCode 17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。答案可以按**任意顺序**返回。

## 核心分析

### 问题本质
这是一个**多叉树遍历**问题，每个数字对应多个字母选择，需要枚举所有可能的组合路径。

### 关键特征
1. **固定长度**：结果字符串长度等于输入数字串长度
2. **多叉选择**：每个位置有2-4个字母可选
3. **顺序相关**：按数字顺序选择字母
4. **无重复**：每个数字只能选择一次

## 解法一：递归回溯（标准模板）

### 核心思路
对每个数字位置，尝试所有可能的字母选择，递归构建组合。

```java
class Solution {
    // 数字到字母的映射
    private static final String[] PHONE_MAP = {
        "",     // 0
        "",     // 1
        "abc",  // 2
        "def",  // 3
        "ghi",  // 4
        "jkl",  // 5
        "mno",  // 6
        "pqrs", // 7
        "tuv",  // 8
        "wxyz"  // 9
    };
    
    public List<String> letterCombinations(String digits) {
        List<String> result = new ArrayList<>();
        if (digits == null || digits.length() == 0) {
            return result;
        }
        
        StringBuilder path = new StringBuilder();
        backtrack(digits, 0, path, result);
        return result;
    }
    
    private void backtrack(String digits, int index, StringBuilder path, List<String> result) {
        // 递归终止条件：已处理完所有数字
        if (index == digits.length()) {
            result.add(path.toString());
            return;
        }
        
        // 获取当前数字对应的字母
        char digit = digits.charAt(index);
        String letters = PHONE_MAP[digit - '0'];
        
        // 尝试当前数字的每个字母
        for (char letter : letters.toCharArray()) {
            path.append(letter);                    // 选择
            backtrack(digits, index + 1, path, result);  // 递归
            path.deleteCharAt(path.length() - 1);   // 撤销选择（回溯）
        }
    }
}
```

### 执行过程可视化（digits = "23"）
```
                    ""
                 /  |  \
               a    b    c
            /  |  \ /|\ /|\
           ad ae af bd be bf cd ce cf

结果：["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]
```

## 解法二：迭代构建

### 核心思路
从空字符串开始，每次处理一个数字，将现有所有组合与新数字的字母进行拼接。

```java
class Solution {
    private static final String[] PHONE_MAP = {
        "",     // 0
        "",     // 1
        "abc",  // 2
        "def",  // 3
        "ghi",  // 4
        "jkl",  // 5
        "mno",  // 6
        "pqrs", // 7
        "tuv",  // 8
        "wxyz"  // 9
    };
    
    public List<String> letterCombinations(String digits) {
        List<String> result = new ArrayList<>();
        if (digits == null || digits.length() == 0) {
            return result;
        }
        
        result.add("");  // 初始化为空字符串
        
        for (char digit : digits.toCharArray()) {
            String letters = PHONE_MAP[digit - '0'];
            List<String> newCombinations = new ArrayList<>();
            
            // 对每个现有组合，拼接当前数字的每个字母
            for (String combination : result) {
                for (char letter : letters.toCharArray()) {
                    newCombinations.add(combination + letter);
                }
            }
            
            result = newCombinations;
        }
        
        return result;
    }
}
```

### 构建过程（digits = "23"）
```
初始: [""]
处理'2': ["a", "b", "c"]
处理'3': ["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]
```

## 解法三：队列BFS

### 核心思路
使用队列进行广度优先搜索，逐层构建所有可能的组合。

```java
class Solution {
    private static final String[] PHONE_MAP = {
        "",     // 0
        "",     // 1
        "abc",  // 2
        "def",  // 3
        "ghi",  // 4
        "jkl",  // 5
        "mno",  // 6
        "pqrs", // 7
        "tuv",  // 8
        "wxyz"  // 9
    };
    
    public List<String> letterCombinations(String digits) {
        List<String> result = new ArrayList<>();
        if (digits == null || digits.length() == 0) {
            return result;
        }
        
        Queue<String> queue = new LinkedList<>();
        queue.offer("");
        
        for (char digit : digits.toCharArray()) {
            String letters = PHONE_MAP[digit - '0'];
            int size = queue.size();
            
            // 处理当前层的所有组合
            for (int i = 0; i < size; i++) {
                String current = queue.poll();
                
                // 为当前组合添加新字母
                for (char letter : letters.toCharArray()) {
                    queue.offer(current + letter);
                }
            }
        }
        
        result.addAll(queue);
        return result;
    }
}
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| 递归回溯 | O(3^m × 4^n) | O(m + n) | m为对应3个字母的数字个数，n为对应4个字母的数字个数 |
| 迭代构建 | O(3^m × 4^n) | O(3^m × 4^n) | 需要存储所有中间结果 |
| 队列BFS | O(3^m × 4^n) | O(3^m × 4^n) | 队列存储当前层所有组合 |

## 方法对比与选择

### 递归回溯（推荐用于面试）
**优点：**
- 思路清晰，符合回溯模板
- 空间复杂度最优（只有递归栈）
- 代码简洁易懂

**缺点：**
- 有递归栈开销
- 深度较大时可能栈溢出

### 迭代构建（适合理解过程）
**优点：**
- 构建过程直观
- 无递归开销
- 易于理解组合生成过程

**缺点：**
- 空间使用较多
- 需要频繁创建新列表

### 队列BFS（适合层次遍历思维）
**优点：**
- 层次清晰，便于理解
- 可以控制每层的处理
- 无递归栈限制

**缺点：**
- 空间复杂度高
- 代码相对复杂

## 关键要点总结

1. **映射表设计**：使用数组存储数字到字母的映射，访问效率O(1)
2. **边界处理**：空字符串输入需要返回空列表
3. **字符串构建**：StringBuilder比String拼接效率更高
4. **回溯模板**：选择 → 递归 → 撤销选择

## 常见变形题

1. **限制组合长度**：添加长度约束条件
2. **字母去重**：如果数字可能重复，需要去重处理
3. **字典序输出**：要求按字典序返回结果

## 实战建议

1. **面试首选**：递归回溯方法，代码简洁清晰
2. **优化技巧**：使用StringBuilder避免字符串频繁创建
3. **扩展思考**：理解多叉树遍历的本质
4. **记忆要点**：数字键盘映射要熟记
