# 问题1.0.0 组合总和（LeetCode-39）

- 难度：中等
- 链接：https://leetcode.cn/problems/combination-sum/

## 概述
给定候选数组 `candidates`（正整数且可重复使用）和目标值 `target`，找出所有唯一组合使得数字之和为 `target`。答案中同一数字可以无限次使用。

## 问题特征与分析引导
- 生成规模：组合数量不定，受 `target` 与候选值分布影响；典型回溯枚举路径。
- 去重约束：按索引递增选择保证不产生排列重复；路径保持非降序。
- 剪枝策略：排序后若 `c[i] > remain` 直接 break；或按“枚举次数”减少递归层数。

## 可能涉及的知识点
- 回溯模板：`start` 控制可选范围，允许重复选择同一元素
- 排序 + 剪枝（上界剪枝 / 终止条件）
- 与 40、216 的差异（不可重复 / 固定次数）
