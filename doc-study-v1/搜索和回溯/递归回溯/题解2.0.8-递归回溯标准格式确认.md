```
进入递归

初始化一个for循环往后递归

    用当前元素的下一个进行递归
    撤回当前元素
```

## 📝 标准代码模板

### Java版本
```java
public void backtrack(参数列表) {
    // 1. 终止条件（收集结果）
    if (满足条件) {
        result.add(new ArrayList<>(path));
        return;
    }
    
    // 2. for循环遍历选择列表
    for (int i = startIndex; i < nums.length; i++) {
        // 3. 做选择（添加当前元素）
        path.add(nums[i]);
        
        // 4. 递归（用下一个位置继续）
        backtrack(i + 1, 其他参数);
        
        // 5. 撤销选择（回溯）
        path.remove(path.size() - 1);
    }
}
```

## 🔍 每个步骤的作用

### 1. 终止条件
- **作用**：决定什么时候停止递归
- **必要性**：防止无限递归，收集有效结果

### 2. for循环遍历
- **作用**：遍历当前层可以选择的所有元素
- **必要性**：确保所有可能的选择都被考虑

### 3. 做选择（添加元素）
- **作用**：将当前元素加入路径
- **必要性**：构建当前的解决方案

### 4. 递归调用
- **作用**：进入下一层，继续构建解决方案
- **必要性**：实现深度优先搜索

### 5. 撤销选择（回溯）
- **作用**：恢复到选择前的状态
- **必要性**：确保不同分支之间不互相影响

## 🎪 形象比喻

想象你在**试衣间**：

1. **进入试衣间**（进入递归）
2. **穿上一件衣服**（添加当前元素）
3. **照镜子看效果**（for循环考虑搭配）
   - **再穿一件**（添加下一个元素）
   - **继续搭配**（递归调用）
   - **脱掉刚穿的**（撤销选择）
4. **尝试下一件衣服**（循环继续）

## 💡 关键理解

### 为什么要撤销？
```java
// 不撤销的话：
path = [1]
add(2) → path = [1,2]
递归返回后，path还是[1,2]
add(3) → path = [1,2,3] ❌ 错误！应该是[1,3]

// 撤销后：
path = [1]
add(2) → path = [1,2]
递归返回后，remove(2) → path = [1]
add(3) → path = [1,3] ✅ 正确！
```
