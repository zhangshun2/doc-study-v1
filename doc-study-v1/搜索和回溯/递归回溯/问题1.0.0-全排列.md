# 问题1.0.0 全排列（LeetCode-46）

- 难度：中等
- 链接：https://leetcode.cn/problems/permutations/

## 概述
给定互不相同的整数数组，返回所有可能的全排列。

## 问题特征与分析引导
- 结果规模：`n!` 级别，指数增长；典型回溯枚举。
- 约束特征：元素各不相同，无需去重；每个元素恰好出现一次。
- 路径结构：选择列表为未使用的元素集合；路径长度达到 `n` 时收集结果。

## 可能涉及的知识点
- 回溯模板：`used[]` 标记与路径构造
- 生成顺序控制：字典序 / 插入式构造 / nextPermutation 枚举
- 时间与空间复杂度评估（结果规模主导）
