# 题解2.0.0 解数独（LeetCode-37）

## 题解一：官方经典（行列宫占用 + 回溯）
- 思路：预处理三类占用状态，递归扫描空格尝试 `1..9`，合法则填入并更新状态，失败回退；全局完成即返回。
- 复杂度：最坏情况指数级；占用剪枝显著降低搜索量。

```java
import java.util.*;
class Solution {
    boolean[][] row = new boolean[9][10];
    boolean[][] col = new boolean[9][10];
    boolean[][] box = new boolean[9][10];
    public void solveSudoku(char[][] board) {
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                char c = board[i][j];
                if (c != '.') {
                    int d = c - '0';
                    row[i][d] = col[j][d] = box[boxId(i, j)][d] = true;
                }
            }
        }
        dfs(board, 0, 0);
    }
    private boolean dfs(char[][] b, int i, int j) {
        if (i == 9) return true;
        if (j == 9) return dfs(b, i + 1, 0);
        if (b[i][j] != '.') return dfs(b, i, j + 1);
        for (int d = 1; d <= 9; d++) {
            int k = boxId(i, j);
            if (row[i][d] || col[j][d] || box[k][d]) continue;
            row[i][d] = col[j][d] = box[k][d] = true;
            b[i][j] = (char)('0' + d);
            if (dfs(b, i, j + 1)) return true;
            b[i][j] = '.';
            row[i][d] = col[j][d] = box[k][d] = false;
        }
        return false;
    }
    private int boxId(int i, int j) { return (i / 3) * 3 + (j / 3); }
}
```

## 题解二：通用解法（位掩码优化）
- 标签：回溯、剪枝、位运算、约束满足
- 思路：用 `int` 位掩码记录占用，提高检查与更新效率；其余流程同回溯。

```java
import java.util.*;
class Solution {
    int[] row = new int[9], col = new int[9], box = new int[9];
    public void solveSudoku(char[][] b) {
        for (int i = 0; i < 9; i++) for (int j = 0; j < 9; j++) {
            if (b[i][j] != '.') set(i, j, b[i][j] - '0', true);
        }
        dfs(b, 0, 0);
    }
    private boolean dfs(char[][] b, int i, int j) {
        if (i == 9) return true;
        if (j == 9) return dfs(b, i + 1, 0);
        if (b[i][j] != '.') return dfs(b, i, j + 1);
        int mask = ~(row[i] | col[j] | box[id(i, j)]) & 0x3FE; // 10 位有效（1..9）
        for (int d = 1; d <= 9; d++) if ((mask & (1 << d)) != 0) {
            set(i, j, d, true); b[i][j] = (char)('0' + d);
            if (dfs(b, i, j + 1)) return true;
            b[i][j] = '.'; set(i, j, d, false);
        }
        return false;
    }
    private void set(int i, int j, int d, boolean on) {
        int bit = 1 << d; int k = id(i, j);
        if (on) { row[i] |= bit; col[j] |= bit; box[k] |= bit; }
        else { row[i] &= ~bit; col[j] &= ~bit; box[k] &= ~bit; }
    }
    private int id(int i, int j) { return (i / 3) * 3 + (j / 3); }
}
```

## 题解三：最好理解（“尝试合法数字，不行就回退”）
- 直觉：每个空格试 `1..9`，只填不冲突的；走不通就撤销继续试下一个。

## 总结思路
- 占用状态加速检查；位掩码进一步优化；选择顺序（候选最少优先）可再提速。
