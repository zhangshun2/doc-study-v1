# 问题1.0.0 解数独（LeetCode-37）

- 难度：困难
- 链接：https://leetcode.cn/problems/sudoku-solver/

## 概述
将部分填充的 `9×9` 数独按规则填满，返回一个可行解（保证有解）。规则：每行、每列、每个 `3×3` 宫内的数字 `1-9` 不重复。

## 问题特征与分析引导
- 约束满足：典型回溯问题，每格尝试 `1..9`，不满足约束则回退。
- 状态结构：行/列/宫的占用状态；优先选择候选数更少的格可加速（可选优化）。
- 终止条件：所有空格被合法数字填充。

## 可能涉及的知识点
- 行/列/宫的布尔占用或位掩码（bitmask）
- 回溯与剪枝、选择顺序优化（MRV启发式）
- 原地修改与回退
