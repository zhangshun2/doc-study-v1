题解2.0.0 - 数独求解（Sudoku Solver, LeetCode 37）

概述：用回溯尝试在空格填 1-9，维护三类布尔约束（行、列、宫），若冲突则回退；填满即返回。

题解一：回溯 + 约束数组（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    boolean[][] row = new boolean[9][10];
    boolean[][] col = new boolean[9][10];
    boolean[][] box = new boolean[9][10];
    public void solveSudoku(char[][] board) {
        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                if (board[i][j] != '.') {
                    int d = board[i][j] - '0';
                    row[i][d] = col[j][d] = box[(i/3)*3 + j/3][d] = true;
                }
            }
        }
        dfs(board, 0, 0);
    }
    private boolean dfs(char[][] b, int i, int j) {
        if (i == 9) return true;
        if (j == 9) return dfs(b, i + 1, 0);
        if (b[i][j] != '.') return dfs(b, i, j + 1);
        int bi = (i/3)*3 + j/3;
        for (int d = 1; d <= 9; d++) {
            if (!row[i][d] && !col[j][d] && !box[bi][d]) {
                b[i][j] = (char)('0' + d);
                row[i][d] = col[j][d] = box[bi][d] = true;
                if (dfs(b, i, j + 1)) return true;
                b[i][j] = '.';
                row[i][d] = col[j][d] = box[bi][d] = false;
            }
        }
        return false;
    }
}
```

复杂度：
- 搜索树规模取决于输入，常用剪枝能显著降低回溯开销。

思考小结：
- 约束数组实现高效合法性检查；也可用位掩码进一步优化。
