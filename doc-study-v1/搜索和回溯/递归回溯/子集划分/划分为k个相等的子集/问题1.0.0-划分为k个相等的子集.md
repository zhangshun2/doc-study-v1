# 问题1.0.0 划分为k个相等的子集（LeetCode-698）

- 难度：中等
- 链接：https://leetcode.cn/problems/partition-to-k-equal-sum-subsets/

## 概述
给定数组 `nums` 与整数 `k`，能否把数组分成 `k` 个子集，使每个子集的元素和相等。

## 问题特征与分析引导
- 目标和：总和必须能被 `k` 整除，且最大元素不超过目标值。
- 回溯搜索：按桶（子集）构造，尝试把元素放入当前桶，达到目标后进入下一个桶。
- 剪枝：排序降序、跳过重复、桶首失败剪枝等。

## 可能涉及的知识点
- 递归回溯与状态剪枝
- 目标和拆分与排序优化
- 访问标记与重复元素处理
