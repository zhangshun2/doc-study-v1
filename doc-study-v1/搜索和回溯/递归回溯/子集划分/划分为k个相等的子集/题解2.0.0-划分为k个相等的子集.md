# 题解2.0.0 划分为k个相等的子集（LeetCode-698）

## 题解一：官方经典（桶回溯 + 剪枝）
- 思路：计算目标 `target = sum/k`，数组降序，回溯放入桶；达到目标进入下一桶；用访问标记与剪枝降低搜索量。
- 复杂度：最坏指数级，剪枝后可过；空间 O(n)。

```java
import java.util.*;
class Solution {
    public boolean canPartitionKSubsets(int[] nums, int k) {
        int sum = 0; for (int x : nums) sum += x;
        if (sum % k != 0) return false; int target = sum / k;
        Arrays.sort(nums); int n = nums.length; if (nums[n-1] > target) return false;
        boolean[] used = new boolean[n];
        return dfs(nums, used, k, 0, 0, target);
    }
    private boolean dfs(int[] nums, boolean[] used, int k, int start, int cur, int target) {
        if (k == 1) return true; // 剩余最后一桶必然可成
        if (cur == target) return dfs(nums, used, k - 1, 0, 0, target);
        for (int i = start; i < nums.length; i++) {
            if (used[i]) continue;
            if (cur + nums[i] > target) continue;
            used[i] = true;
            if (dfs(nums, used, k, i + 1, cur + nums[i], target)) return true;
            used[i] = false;
            if (cur == 0) break; // 桶首放这个失败，后面同层等价
            while (i + 1 < nums.length && nums[i] == nums[i + 1]) i++; // 跳重
        }
        return false;
    }
}
```

## 题解二：通用解法（位压 DP）
- 标签：位压、子集和、DP
- 思路：用 `mask` 表示选取集合，DP 记录当前子集和模 `target`，复杂度较高但可优化。

## 题解三：最好理解（“一个桶一个桶凑满，凑满换下一个”）
- 直觉：把大的先放，尽快达到目标，失败就回退。

## 总结思路
- 回溯 + 剪枝是主流；位压 DP 作为备选。
