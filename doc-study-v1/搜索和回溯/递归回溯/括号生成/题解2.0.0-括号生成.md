# 题解2.0.0-括号生成

## 问题回顾
[LeetCode 22. 括号生成](https://leetcode.cn/problems/generate-parentheses/)

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且**有效的**括号组合。

## 核心分析

### 问题本质
这是一个**约束条件下的组合生成**问题，需要在满足括号匹配规则的前提下，生成所有可能的括号序列。

### 关键约束
1. **左括号数量** = **右括号数量** = n
2. **任意前缀中**，左括号数量 ≥ 右括号数量
3. **最终长度**：2n

### 状态定义
- `left`：已使用的左括号数量
- `right`：已使用的右括号数量
- `path`：当前构建的括号序列

## 解法一：递归回溯（推荐）

### 核心思路
在每个位置选择放置左括号或右括号，通过约束条件进行剪枝。

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        StringBuilder path = new StringBuilder();
        backtrack(n, 0, 0, path, result);
        return result;
    }
    
    private void backtrack(int n, int left, int right, StringBuilder path, List<String> result) {
        // 递归终止条件：括号序列构建完成
        if (path.length() == 2 * n) {
            result.add(path.toString());
            return;
        }
        
        // 选择1：添加左括号（条件：左括号数量 < n）
        if (left < n) {
            path.append('(');
            backtrack(n, left + 1, right, path, result);
            path.deleteCharAt(path.length() - 1);  // 回溯
        }
        
        // 选择2：添加右括号（条件：右括号数量 < 左括号数量）
        if (right < left) {
            path.append(')');
            backtrack(n, left, right + 1, path, result);
            path.deleteCharAt(path.length() - 1);  // 回溯
        }
    }
}
```

### 执行过程可视化（n = 3）
```
                    ""
                    |
                   "("
                /       \
            "(("           "()"
           /    \         /    \
       "((("   "(())"   "()("   "()()"
        |       |        |       |
    "((()))"  "(())()"  "()(("  "()()()"
              |          |
           "(()))()"   "()(())"
                       |
                   "()(())()"

有效结果：["((()))", "(()())", "(())()", "()(())", "()()()"]
```

## 解法二：动态规划

### 核心思路
利用已知的小规模结果，构建大规模的解。对于n对括号，可以分解为：`(` + i对括号 + `)` + (n-1-i)对括号

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<List<String>> dp = new ArrayList<>();
        
        // 初始化：dp[0] = [""]
        dp.add(Arrays.asList(""));
        
        for (int i = 1; i <= n; i++) {
            List<String> current = new ArrayList<>();
            
            // 枚举左侧括号内的对数
            for (int j = 0; j < i; j++) {
                List<String> left = dp.get(j);      // j对括号
                List<String> right = dp.get(i - 1 - j);  // (i-1-j)对括号
                
                // 组合：( + left + ) + right
                for (String l : left) {
                    for (String r : right) {
                        current.add("(" + l + ")" + r);
                    }
                }
            }
            
            dp.add(current);
        }
        
        return dp.get(n);
    }
}
```

### DP构建过程
```
dp[0] = [""]
dp[1] = ["()"]
dp[2] = ["(())", "()()"]
dp[3] = ["((()))", "(()())", "(())()", "()(())", "()()()"]
```

## 解法三：BFS层次遍历

### 核心思路
使用队列进行广度优先搜索，逐层构建有效的括号序列。

```java
class Solution {
    static class Node {
        String str;
        int left;
        int right;
        
        Node(String str, int left, int right) {
            this.str = str;
            this.left = left;
            this.right = right;
        }
    }
    
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        Queue<Node> queue = new LinkedList<>();
        
        queue.offer(new Node("", 0, 0));
        
        while (!queue.isEmpty()) {
            Node current = queue.poll();
            
            // 如果序列长度达到2n，加入结果
            if (current.str.length() == 2 * n) {
                result.add(current.str);
                continue;
            }
            
            // 尝试添加左括号
            if (current.left < n) {
                queue.offer(new Node(current.str + "(", current.left + 1, current.right));
            }
            
            // 尝试添加右括号
            if (current.right < current.left) {
                queue.offer(new Node(current.str + ")", current.left, current.right + 1));
            }
        }
        
        return result;
    }
}
```

## 解法四：暴力枚举 + 验证

### 核心思路
生成所有可能的2^(2n)种括号序列，然后验证每个序列是否有效。

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        char[] current = new char[2 * n];
        generateAll(current, 0, result);
        return result;
    }
    
    private void generateAll(char[] current, int pos, List<String> result) {
        if (pos == current.length) {
            if (isValid(current)) {
                result.add(new String(current));
            }
            return;
        }
        
        current[pos] = '(';
        generateAll(current, pos + 1, result);
        
        current[pos] = ')';
        generateAll(current, pos + 1, result);
    }
    
    private boolean isValid(char[] chars) {
        int balance = 0;
        for (char c : chars) {
            if (c == '(') {
                balance++;
            } else {
                balance--;
            }
            if (balance < 0) {
                return false;
            }
        }
        return balance == 0;
    }
}
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| 递归回溯 | O(4^n / √n) | O(n) | 卡特兰数，递归栈深度为2n |
| 动态规划 | O(4^n / √n) | O(4^n / √n) | 需要存储所有中间结果 |
| BFS遍历 | O(4^n / √n) | O(4^n / √n) | 队列存储所有状态 |
| 暴力枚举 | O(2^(2n) × n) | O(n) | 生成所有序列并验证 |

## 方法对比与选择

### 递归回溯（强烈推荐）
**优点：**
- 思路清晰，符合问题本质
- 空间复杂度最优
- 有效剪枝，避免无效计算
- 代码简洁易懂

**缺点：**
- 递归栈开销

### 动态规划（适合理解递推关系）
**优点：**
- 体现问题的递推结构
- 无递归开销
- 可以复用子问题结果

**缺点：**
- 空间复杂度高
- 代码相对复杂

### BFS遍历（适合理解状态转移）
**优点：**
- 状态转移清晰
- 可以控制搜索过程

**缺点：**
- 空间复杂度高
- 需要额外的状态类

### 暴力枚举（不推荐）
**优点：**
- 思路简单直接

**缺点：**
- 效率极低
- 大量无效计算

## 关键要点总结

1. **约束条件**：
   - 左括号数量 ≤ n
   - 右括号数量 ≤ 左括号数量
   - 最终长度 = 2n

2. **剪枝策略**：
   - 左括号用完时，不能再添加左括号
   - 右括号数量达到左括号数量时，不能再添加右括号

3. **状态管理**：
   - 用left和right记录已使用的括号数量
   - 用path记录当前构建的序列

4. **回溯模板**：选择 → 递归 → 撤销选择

## 数学背景：卡特兰数

n对括号的有效组合数量等于第n个卡特兰数：
```
C(n) = (2n)! / ((n+1)! × n!) = (1/(n+1)) × C(2n, n)
```

前几项：1, 1, 2, 5, 14, 42, 132...
