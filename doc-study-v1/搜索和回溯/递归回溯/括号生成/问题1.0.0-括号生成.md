# 问题1.0.0-括号生成

## 原题链接
[LeetCode 22. 括号生成](https://leetcode.cn/problems/generate-parentheses/)

## 题目描述

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

## 示例

### 示例 1：
```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

### 示例 2：
```
输入：n = 1
输出：["()"]
```

## 约束条件

- `1 <= n <= 8`

## 有效括号的规则

1. **配对规则**：每个左括号 `(` 都必须有一个对应的右括号 `)`
2. **顺序规则**：在任意位置，右括号的数量不能超过左括号的数量
3. **总数规则**：最终左括号和右括号的数量都必须等于 `n`

## 问题特征分析

1. **生成所有可能**：需要枚举所有有效的括号组合
2. **约束条件**：不是任意组合，必须满足括号匹配规则
3. **递归结构**：每个位置可以选择放左括号或右括号
4. **剪枝优化**：可以通过约束条件提前剪掉无效分支
5. **固定长度**：结果字符串长度固定为 `2*n`

## 核心思路

这是一个**带约束的递归回溯**问题：
- **状态**：当前字符串（path）、已使用的左括号数量（left）、已使用的右括号数量（right）
- **选择**：在当前位置放左括号或右括号
- **约束**：
  - 左括号数量不能超过 `n`
  - 右括号数量不能超过左括号数量
  - 右括号数量不能超过 `n`
- **终止条件**：左括号和右括号都用完了（各用了 `n` 个）

## 决策树示例（n=2）

```
                    ""
                 /      \
            "("(left=1)   X (right>left，剪枝)
           /          \
    "(("(left=2)   "())"(left=1,right=1)
       |               /        \
   "(())"         "()("      "())"
   (完成)         (left=2)     (完成)
                     |
                 "()()"
                 (完成)
```

## 解题框架

```
递归函数(当前路径path, 左括号数left, 右括号数right):
    if left == n and right == n:
        收集当前路径到结果集
        return
    
    if left < n:                    # 可以添加左括号
        path.append('(')            # 做选择
        递归函数(path, left+1, right)  # 递归
        path.pop()                  # 撤销选择
    
    if right < left:                # 可以添加右括号
        path.append(')')            # 做选择
        递归函数(path, left, right+1)  # 递归
        path.pop()                  # 撤销选择
```

## 关键约束分析

1. **left < n**：确保左括号不超过限制
2. **right < left**：确保任意时刻右括号不超过左括号（保证有效性）
3. **right < n**：确保右括号不超过限制（其实由前两个条件已经保证）
