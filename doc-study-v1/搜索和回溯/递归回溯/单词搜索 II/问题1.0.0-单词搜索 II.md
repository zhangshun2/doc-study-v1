# 问题1.0.0 单词搜索 II（LeetCode-212）

- 难度：困难
- 链接：https://leetcode.cn/problems/word-search-ii/

## 概述
给定 `m×n` 字母网格 `board` 与单词列表 `words`，返回所有能在网格中按相邻单元（上下左右）顺序拼出的单词。每个单元在一个单词中只能使用一次。

## 问题特征与分析引导
- 搜索规模：对每个起点 DFS，朴素按所有单词逐个匹配会超时。
- 剪枝关键：将 `words` 构建为前缀树（Trie），在 DFS 中按前缀推进，遇到“无此前缀”立即剪枝。
- 结果去重：同一单词可能被多次找到（不同路径），找到一次后可在 Trie 中将该终止节点的 `word` 清空（或用布尔标记）避免重复收集。

## 可能涉及的知识点
- Trie 前缀树构建与搜索剪枝
- 网格 DFS 回溯与原地标记
- 结果去重与性能优化（删除已匹配词、频次预检）
