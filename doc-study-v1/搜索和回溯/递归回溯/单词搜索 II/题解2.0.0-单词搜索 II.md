# 题解2.0.0 单词搜索 II（LeetCode-212）

## 题解一：官方经典（Trie + DFS 回溯 + 原地标记）
- 思路：将 `words` 建成 Trie，遍历每个起点 `(i,j)` 进行 DFS，沿着前缀树推进；当节点存有 `word` 则收集并清空避免重复；格子用原地特殊字符临时标记，递归结束回退还原。
- 复杂度：构建 Trie O(Σ总长度)，搜索最坏 O(m·n·4^L)；剪枝大幅降低实际复杂度。

```java
import java.util.*;
class Solution {
    static class TrieNode {
        TrieNode[] ch = new TrieNode[26];
        String word;
    }
    public List<String> findWords(char[][] board, String[] words) {
        TrieNode root = build(words);
        int m = board.length, n = board[0].length;
        List<String> res = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dfs(board, i, j, root, res);
            }
        }
        return res;
    }
    private void dfs(char[][] b, int x, int y, TrieNode node, List<String> res) {
        char c = b[x][y];
        if (c == '#') return;
        TrieNode nxt = node.ch[c - 'a'];
        if (nxt == null) return;
        if (nxt.word != null) { res.add(nxt.word); nxt.word = null; }
        b[x][y] = '#';
        if (x > 0) dfs(b, x - 1, y, nxt, res);
        if (x + 1 < b.length) dfs(b, x + 1, y, nxt, res);
        if (y > 0) dfs(b, x, y - 1, nxt, res);
        if (y + 1 < b[0].length) dfs(b, x, y + 1, nxt, res);
        b[x][y] = c;
    }
    private TrieNode build(String[] words) {
        TrieNode root = new TrieNode();
        for (String w : words) {
            TrieNode cur = root;
            for (int i = 0; i < w.length(); i++) {
                int idx = w.charAt(i) - 'a';
                if (cur.ch[idx] == null) cur.ch[idx] = new TrieNode();
                cur = cur.ch[idx];
            }
            cur.word = w;
        }
        return root;
    }
}
```

## 题解二：通用解法（Trie + visited[][] + 方向数组）
- 标签：字典树、DFS、回溯、剪枝
- 思路：使用 `visited` 显式标记，方向数组统一四邻迭代；与原地标记等价，便于理解状态。

```java
import java.util.*;
class Solution {
    static class TrieNode { TrieNode[] ch = new TrieNode[26]; String word; }
    private static final int[] DIR = {1, 0, -1, 0, 1};
    public List<String> findWords(char[][] board, String[] words) {
        TrieNode root = build(words);
        int m = board.length, n = board[0].length;
        List<String> res = new ArrayList<>();
        boolean[][] vis = new boolean[m][n];
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) dfs(board, i, j, root, vis, res);
        return res;
    }
    private void dfs(char[][] b, int x, int y, TrieNode node, boolean[][] vis, List<String> res) {
        if (vis[x][y]) return;
        TrieNode nxt = node.ch[b[x][y] - 'a'];
        if (nxt == null) return;
        if (nxt.word != null) { res.add(nxt.word); nxt.word = null; }
        vis[x][y] = true;
        for (int d = 0; d < 4; d++) {
            int nx = x + DIR[d], ny = y + DIR[d + 1];
            if (nx < 0 || nx >= b.length || ny < 0 || ny >= b[0].length) continue;
            dfs(b, nx, ny, nxt, vis, res);
        }
        vis[x][y] = false;
    }
    private TrieNode build(String[] words) {
        TrieNode root = new TrieNode();
        for (String w : words) {
            TrieNode cur = root;
            for (int i = 0; i < w.length(); i++) {
                int idx = w.charAt(i) - 'a';
                if (cur.ch[idx] == null) cur.ch[idx] = new TrieNode();
                cur = cur.ch[idx];
            }
            cur.word = w;
        }
        return root;
    }
}
```

## 题解三：最好理解（“建前缀树，逐格匹配；匹配到就收集并剪掉”）
- 直觉：用前缀树快速判断“能否继续匹配”，减少无效搜索；找到单词后清空该终止标记避免重复。

## 总结思路
- Trie 是核心剪枝；原地标记或 visited 等价；收集后清空避免重复。
