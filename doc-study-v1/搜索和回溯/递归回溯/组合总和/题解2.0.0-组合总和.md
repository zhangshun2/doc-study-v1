# 题解2.0.0-组合总和

## 问题回顾
[LeetCode 39. 组合总和](https://leetcode.cn/problems/combination-sum/)

给你一个**无重复元素**的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为目标数 `target` 的所有**不同组合**。

`candidates` 中的**同一个**数字可以**无限制重复被选取**。如果至少一个数字的被选数量不同，则两个组合是不同的。

## 核心分析

### 问题本质
这是一个**带约束的组合搜索**问题，需要在允许重复使用元素的情况下，找到所有和为目标值的组合。

### 关键特征
1. **元素可重复使用**：同一个数字可以被选择多次
2. **无重复元素**：数组中没有重复数字
3. **组合问题**：不考虑顺序，[2,2,3] 和 [2,3,2] 是同一个组合
4. **目标约束**：组合的和必须等于target

### 搜索策略
- **剪枝条件**：当前和 > target 时停止搜索
- **去重策略**：通过控制搜索起始位置避免重复组合
- **递归选择**：每个位置可以选择当前元素或跳过当前元素

## 解法一：递归回溯（推荐）

### 核心思路
对于每个候选数字，有两种选择：选择它（可以继续选择）或跳过它。通过递归搜索所有可能的组合。

```java
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        backtrack(candidates, target, 0, path, result);
        return result;
    }
    
    private void backtrack(int[] candidates, int target, int start, 
                          List<Integer> path, List<List<Integer>> result) {
        // 递归终止条件
        if (target == 0) {
            result.add(new ArrayList<>(path));  // 找到一个有效组合
            return;
        }
        
        // 遍历候选数字
        for (int i = start; i < candidates.length; i++) {
            // 剪枝：如果当前数字大于剩余目标，跳过
            if (candidates[i] > target) {
                continue;
            }
            
            // 选择当前数字
            path.add(candidates[i]);
            
            // 递归搜索（注意：可以重复使用，所以起始位置仍为i）
            backtrack(candidates, target - candidates[i], i, path, result);
            
            // 回溯：撤销选择
            path.remove(path.size() - 1);
        }
    }
}
```

## 解法二：递归回溯（优化版）

### 核心思路
先对数组排序，利用排序后的性质进行更有效的剪枝。

```java
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> result = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        
        // 排序以便剪枝
        Arrays.sort(candidates);
        
        backtrack(candidates, target, 0, path, result);
        return result;
    }
    
    private void backtrack(int[] candidates, int target, int start, 
                          List<Integer> path, List<List<Integer>> result) {
        if (target == 0) {
            result.add(new ArrayList<>(path));
            return;
        }
        
        for (int i = start; i < candidates.length; i++) {
            // 剪枝：由于数组已排序，后面的数字都会更大
            if (candidates[i] > target) {
                break;  // 直接跳出循环
            }
            
            path.add(candidates[i]);
            backtrack(candidates, target - candidates[i], i, path, result);
            path.remove(path.size() - 1);
        }
    }
}
```

## 解法三：动态规划

### 核心思路
使用动态规划的思想，dp[i] 表示和为 i 的所有组合。

```java
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        // dp[i] 存储和为 i 的所有组合
        List<List<List<Integer>>> dp = new ArrayList<>();
        
        // 初始化
        for (int i = 0; i <= target; i++) {
            dp.add(new ArrayList<>());
        }
        dp.get(0).add(new ArrayList<>());  // 和为0的组合是空集
        
        // 遍历每个候选数字
        for (int candidate : candidates) {
            // 更新所有可能的和
            for (int i = candidate; i <= target; i++) {
                // 如果 dp[i - candidate] 有解，则可以构造 dp[i]
                for (List<Integer> combination : dp.get(i - candidate)) {
                    List<Integer> newCombination = new ArrayList<>(combination);
                    newCombination.add(candidate);
                    dp.get(i).add(newCombination);
                }
            }
        }
        
        return dp.get(target);
    }
}
```

## 解法四：BFS层次搜索

### 核心思路
使用队列进行广度优先搜索，每一层代表一个选择的深度。

```java
class Solution {
    static class Node {
        List<Integer> path;
        int sum;
        int start;
        
        Node(List<Integer> path, int sum, int start) {
            this.path = new ArrayList<>(path);
            this.sum = sum;
            this.start = start;
        }
    }
    
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> result = new ArrayList<>();
        Queue<Node> queue = new LinkedList<>();
        
        queue.offer(new Node(new ArrayList<>(), 0, 0));
        
        while (!queue.isEmpty()) {
            Node current = queue.poll();
            
            if (current.sum == target) {
                result.add(current.path);
                continue;
            }
            
            if (current.sum > target) {
                continue;
            }
            
            for (int i = current.start; i < candidates.length; i++) {
                List<Integer> newPath = new ArrayList<>(current.path);
                newPath.add(candidates[i]);
                queue.offer(new Node(newPath, current.sum + candidates[i], i));
            }
        }
        
        return result;
    }
}
```

## 解法五：记忆化搜索

### 核心思路
使用记忆化避免重复计算相同的子问题。

```java
class Solution {
    private Map<String, List<List<Integer>>> memo = new HashMap<>();
    
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);
        return dfs(candidates, target, 0);
    }
    
    private List<List<Integer>> dfs(int[] candidates, int target, int start) {
        String key = target + "," + start;
        if (memo.containsKey(key)) {
            return memo.get(key);
        }
        
        List<List<Integer>> result = new ArrayList<>();
        
        if (target == 0) {
            result.add(new ArrayList<>());
            memo.put(key, result);
            return result;
        }
        
        for (int i = start; i < candidates.length; i++) {
            if (candidates[i] > target) {
                break;
            }
            
            List<List<Integer>> subResult = dfs(candidates, target - candidates[i], i);
            for (List<Integer> combination : subResult) {
                List<Integer> newCombination = new ArrayList<>();
                newCombination.add(candidates[i]);
                newCombination.addAll(combination);
                result.add(newCombination);
            }
        }
        
        memo.put(key, result);
        return result;
    }
}
```

## 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| 递归回溯 | O(N^(T/M)) | O(T/M) | N为数组长度，T为target，M为最小元素 |
| 回溯优化 | O(N^(T/M)) | O(T/M) | 排序后剪枝更有效 |
| 动态规划 | O(N × T × K) | O(T × K) | K为平均组合数量 |
| BFS搜索 | O(N^(T/M)) | O(N^(T/M)) | 队列存储所有状态 |
| 记忆化搜索 | O(N × T) | O(N × T) | 避免重复计算 |

## 方法对比与选择

### 递归回溯（强烈推荐）
**优点：**
- 思路清晰，符合问题本质
- 代码简洁易懂
- 空间复杂度相对较低
- 容易添加剪枝优化

**缺点：**
- 在某些情况下可能有重复计算

### 动态规划（适合理解状态转移）
**优点：**
- 避免重复计算
- 状态转移清晰

**缺点：**
- 空间复杂度较高
- 代码相对复杂

### BFS搜索（适合理解搜索过程）
**优点：**
- 搜索过程可视化
- 可以控制搜索深度

**缺点：**
- 空间复杂度高
- 需要额外的状态管理

## 关键要点总结

1. **去重策略**：
   - 通过控制搜索起始位置避免重复组合
   - 保证组合的字典序

2. **剪枝优化**：
   - 当前和超过目标时停止搜索
   - 排序后可以提前终止循环

3. **重复使用**：
   - 递归时起始位置保持为当前位置
   - 允许同一元素被多次选择

4. **状态管理**：
   - path记录当前组合
   - target记录剩余目标值
   - start记录搜索起始位置
