# 题解2.0.0 组合总和 III（LeetCode-216）

## 题解一：官方经典（递增回溯 + 和剪枝）
- 思路：从 `start` 开始选数加入路径，维护剩余和 `remain` 与剩余数量 `need`，不满足上下界时剪枝；长度到 `k` 且 `remain==0` 收集。
- 复杂度：时间受解空间影响，空间 O(k)。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> combinationSum3(int k, int n) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(1, k, n, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int start, int k, int remain, List<Integer> path, List<List<Integer>> res) {
        int need = k - path.size();
        if (need == 0) { if (remain == 0) res.add(new ArrayList<>(path)); return; }
        // 剪枝：剩余数量与和的上下界
        int maxSum = 0, minSum = 0;
        for (int i = 0; i < need; i++) { maxSum += (9 - i); minSum += (start + i); }
        if (remain < minSum || remain > maxSum) return;
        for (int x = start; x <= 9; x++) {
            path.add(x);
            dfs(x + 1, k, remain - x, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解二：通用解法（上界剪枝 + 提前停止）
- 标签：回溯、剪枝、组合
- 思路：在循环中根据 `x` 的最大可能贡献进行剪枝（若 `remain - x < 0` 则 break），提升效率。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> combinationSum3(int k, int n) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(1, k, n, new ArrayList<>(), res); return res;
    }
    private void dfs(int start, int k, int remain, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == k) { if (remain == 0) res.add(new ArrayList<>(path)); return; }
        for (int x = start; x <= 9; x++) {
            if (remain - x < 0) break;
            path.add(x);
            dfs(x + 1, k, remain - x, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解三：最好理解（“从小到大挑 k 个，和刚好 n”）
- 直觉：递增挑选，长度达标时检查和是否正好；不可能凑够时提前返回。

## 总结思路
- 关键在剪枝：数量与和的上下界、循环中的上界剪枝；有序递增保证不重。
