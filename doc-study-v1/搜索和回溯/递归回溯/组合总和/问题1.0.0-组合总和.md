# 问题1.0.0-组合总和

## 原题链接
[LeetCode 39. 组合总和](https://leetcode.cn/problems/combination-sum/)

## 题目描述

给你一个 **无重复元素** 的整数数组 `candidates` 和一个目标整数 `target` ，找出 `candidates` 中可以使数字和为目标数 `target` 的 所有 **不同组合** ，并以列表形式返回。你可以按 **任意顺序** 返回这些组合。

`candidates` 中的 **同一个** 数字可以 **无限制重复被选取** 。如果至少一个数字的被选数量不同，则两个组合是不同的。 

对于给定的输入，保证和为 `target` 的不同组合数少于 150 个。

## 示例

### 示例 1：
```
输入：candidates = [2,3,6,7], target = 7
输出：[[2,2,3],[7]]
解释：
2 和 3 可以形成一组候选，2 + 2 + 3 = 7 。注意 2 可以使用多次。
7 也是一个候选， 7 = 7 。
仅有这两种组合。
```

### 示例 2：
```
输入：candidates = [2,3,5], target = 8
输出：[[2,2,2,2],[2,3,3],[3,5]]
```

### 示例 3：
```
输入：candidates = [2], target = 1
输出：[]
```

## 约束条件

- `1 <= candidates.length <= 30`
- `2 <= candidates[i] <= 40`
- `candidates` 中的所有元素 **互不相同**
- `1 <= target <= 40`

## 问题特征分析

1. **组合问题**：需要找出所有可能的数字组合
2. **可重复选择**：同一个数字可以被选择多次
3. **目标约束**：组合的和必须等于target
4. **无重复组合**：避免生成重复的组合（如[2,3]和[3,2]视为同一组合）
5. **剪枝机会**：当前和超过target时可以提前终止

## 核心思路

这是一个**带剪枝的递归回溯**问题：
- **状态**：当前组合（path）、当前和（sum）、搜索起始位置（start）
- **选择**：从start位置开始的所有候选数字
- **约束**：当前和不能超过target
- **去重策略**：使用start参数确保组合的有序性，避免重复

## 去重原理

为了避免重复组合，我们使用 `start` 参数：
- 每次递归时，只考虑从 `start` 位置开始的候选数字
- 这样确保了组合中数字的相对顺序，避免了 `[2,3]` 和 `[3,2]` 这样的重复

## 剪枝优化

1. **和剪枝**：当 `sum > target` 时直接返回
2. **排序剪枝**：如果数组已排序，当 `sum + candidates[i] > target` 时可以break
3. **提前终止**：当 `sum == target` 时找到答案，直接返回

## 决策树示例

```
candidates = [2,3,6,7], target = 7

                    []
                 /  |  |  \
            [2]     [3]  [6] [7]
           / | | \   |    X   ✓
      [2,2] [2,3] [2,6] [2,7] [3,3] [3,6] [3,7]
       / |    ✓    X     X     X     X     X
  [2,2,2] [2,2,3] 
    / |     ✓
[2,2,2,2] [2,2,3,3]
   X        X

✓ = sum == target，收集答案
X = sum > target，剪枝
```

## 解题框架

```
递归函数(当前组合path, 当前和sum, 搜索起始位置start):
    if sum == target:
        收集当前组合到结果集
        return
    
    if sum > target:        # 剪枝
        return
    
    for i in range(start, len(candidates)):
        num = candidates[i]
        if sum + num > target:  # 排序后可以break
            break
        
        path.append(num)                    # 做选择
        递归函数(path, sum + num, i)        # 递归（注意是i不是i+1，允许重复选择）
        path.pop()                          # 撤销选择
```

## 关键点说明

1. **start参数**：确保组合有序，避免重复
2. **递归时传入i**：允许重复选择同一个数字
3. **sum参数**：避免重复计算当前和
4. **排序优化**：可以提前break，提高效率
