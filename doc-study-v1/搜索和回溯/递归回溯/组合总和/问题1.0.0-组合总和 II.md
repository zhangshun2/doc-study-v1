# 问题1.0.0 组合总和 II（LeetCode-40）

- 难度：中等
- 链接：https://leetcode.cn/problems/combination-sum-ii/

## 概述
给定候选数组 `candidates`（可能包含重复值，每个元素只能使用一次）和目标值 `target`，找出所有和为 `target` 的唯一组合。答案不要求顺序，但组合内数字按非降序排列。

## 问题特征与分析引导
- 重复与去重：输入可能有重复值，但每个元素只能使用一次，且结果不能出现重复组合。
- 生成规模：受 `target` 与候选分布影响，典型回溯搜索；排序与剪枝显著减少分支。
- 剪枝点：排序后，若 `c[i] > remain` 可直接 `break`；在同一层（同一深度）跳过相同值避免重复组合。

## 可能涉及的知识点
- 回溯模板：`start` 控制下一层可选范围（一次性使用元素）
- 排序 + 层内去重（`i > start && c[i] == c[i-1]` 跳过）
- 与 39 的区别：40 不允许重复使用同一元素；去重逻辑不同
