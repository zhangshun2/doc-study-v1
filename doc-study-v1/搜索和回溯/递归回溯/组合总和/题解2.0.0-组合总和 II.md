# 题解2.0.0 组合总和 II（LeetCode-40）

## 题解一：官方经典（排序 + 回溯 + 层内去重）
- 思路：先排序，回溯时从 `start` 开始遍历；对于同一层的重复值直接跳过（`i > start && c[i] == c[i-1]`）；选择 `c[i]` 后递归到 `i+1`（一次性使用）。当 `remain == 0` 收集路径。
- 复杂度：时间取决于解空间，排序 O(n log n)，搜索分支经剪枝后较少；空间 O(n) 递归深度。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> res = new ArrayList<>();
        dfs(candidates, target, 0, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] c, int remain, int start, List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) { res.add(new ArrayList<>(path)); return; }
        for (int i = start; i < c.length; i++) {
            if (i > start && c[i] == c[i - 1]) continue; // 层内去重
            if (c[i] > remain) break; // 剪枝
            path.add(c[i]);
            dfs(c, remain - c[i], i + 1, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解二：通用解法（used[] + 相邻重复剪枝）
- 标签：回溯、剪枝、层内去重、一次性使用
- 思路：同样排序，但用 `used[]` 辅助去重：如果 `i>0 && c[i]==c[i-1] && !used[i-1]`，表示同一层重复选择，跳过；选择后 `used[i]=true`，递归到 `i+1`。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);
        List<List<Integer>> res = new ArrayList<>();
        boolean[] used = new boolean[candidates.length];
        dfs(candidates, target, 0, used, new ArrayList<>(), res);
        return res;
    }
    private void dfs(int[] c, int remain, int start, boolean[] used, List<Integer> path, List<List<Integer>> res) {
        if (remain == 0) { res.add(new ArrayList<>(path)); return; }
        for (int i = start; i < c.length; i++) {
            if (i > start && c[i] == c[i - 1]) continue;
            if (c[i] > remain) break;
            used[i] = true; path.add(c[i]);
            dfs(c, remain - c[i], i + 1, used, path, res);
            path.remove(path.size() - 1); used[i] = false;
        }
    }
}
```

## 题解三：最好理解（“同层不重复、只用一次”）
- 直觉：排序后，当前层每个相同数只尝试一次，选了某个数就进入下一层（因为每个元素只能用一次），当正好凑齐目标就收集。

## 总结思路
- 排序 + 层内去重是核心；索引前进保证元素只用一次；超过剩余直接剪枝。
