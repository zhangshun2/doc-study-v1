# 问题1.0.0 组合总和 III（LeetCode-216）

- 难度：中等
- 链接：https://leetcode.cn/problems/combination-sum-iii/

## 概述
从数字 `1..9` 中选出 `k` 个不重复的数，使其和为 `n`，返回所有可能组合（组合内按升序）。

## 问题特征与分析引导
- 选择范围：固定为 `1..9`；不重复使用；组合长度恰好为 `k`。
- 剪枝策略：剩余可选数量与目标剩余和的上下界；当和或数量不可能满足时提前停止。
- 路径结构：递增选择，保证不重与有序。

## 可能涉及的知识点
- 回溯模板：`start` 控制递增选择
- 剪枝：剩余数量与剩余和上下界
