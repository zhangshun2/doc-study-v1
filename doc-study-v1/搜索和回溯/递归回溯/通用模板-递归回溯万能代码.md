# 通用模板-递归回溯万能代码

## 🎯 万能模板

### 基础框架（适用于所有回溯问题）
```java
public class BacktrackTemplate {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    
    public List<List<Integer>> solve(int[] nums) {
        backtrack(nums, 0);
        return result;
    }
    
    private void backtrack(int[] nums, int startIndex) {
        // 1. 终止条件
        if (满足条件) {
            result.add(new ArrayList<>(path));
            return;
        }
        
        // 2. 遍历选择列表
        for (int i = startIndex; i < nums.length; i++) {
            // 3. 做选择
            path.add(nums[i]);
            
            // 4. 递归
            backtrack(nums, i + 1);
            
            // 5. 撤销选择
            path.remove(path.size() - 1);
        }
    }
}
```

## 📋 具体问题模板

### 1. 子集问题模板
```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    
    backtrack(nums, 0, path, result);
    return result;
}

private void backtrack(int[] nums, int startIndex, 
                      List<Integer> path, List<List<Integer>> result) {
    // 每个节点都是一个有效子集
    result.add(new ArrayList<>(path));
    
    for (int i = startIndex; i < nums.length; i++) {
        path.add(nums[i]);
        backtrack(nums, i + 1, path, result);
        path.remove(path.size() - 1);
    }
}
```

### 2. 组合问题模板
```java
public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    
    backtrack(n, k, 1, path, result);
    return result;
}

private void backtrack(int n, int k, int startIndex,
                      List<Integer> path, List<List<Integer>> result) {
    // 终止条件：路径长度等于k
    if (path.size() == k) {
        result.add(new ArrayList<>(path));
        return;
    }
    
    for (int i = startIndex; i <= n; i++) {
        path.add(i);
        backtrack(n, k, i + 1, path, result);
        path.remove(path.size() - 1);
    }
}
```

### 3. 全排列问题模板
```java
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    boolean[] used = new boolean[nums.length];
    
    backtrack(nums, path, used, result);
    return result;
}

private void backtrack(int[] nums, List<Integer> path, 
                      boolean[] used, List<List<Integer>> result) {
    // 终止条件：路径长度等于数组长度
    if (path.size() == nums.length) {
        result.add(new ArrayList<>(path));
        return;
    }
    
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue; // 跳过已使用的元素
        
        path.add(nums[i]);
        used[i] = true;
        backtrack(nums, path, used, result);
        used[i] = false;
        path.remove(path.size() - 1);
    }
}
```

### 4. 组合总和模板
```java
public List<List<Integer>> combinationSum(int[] candidates, int target) {
    List<List<Integer>> result = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    
    backtrack(candidates, target, 0, path, result);
    return result;
}

private void backtrack(int[] candidates, int target, int startIndex,
                      List<Integer> path, List<List<Integer>> result) {
    // 终止条件
    if (target == 0) {
        result.add(new ArrayList<>(path));
        return;
    }
    if (target < 0) return;
    
    for (int i = startIndex; i < candidates.length; i++) {
        path.add(candidates[i]);
        // 可以重复使用，所以传入i而不是i+1
        backtrack(candidates, target - candidates[i], i, path, result);
        path.remove(path.size() - 1);
    }
}
```

## 🔧 模板使用指南

### 步骤1：确定问题类型
- **子集**：收集所有可能的子集
- **组合**：固定长度的组合
- **排列**：考虑顺序的排列
- **分割**：字符串或数组的分割

### 步骤2：修改终止条件
```java
// 子集：每个节点都收集
result.add(new ArrayList<>(path));

// 组合：长度达到要求
if (path.size() == k) { ... }

// 排列：使用完所有元素
if (path.size() == nums.length) { ... }

// 目标和：和等于目标值
if (sum == target) { ... }
```

### 步骤3：调整循环起点
```java
// 子集/组合：避免重复，从startIndex开始
for (int i = startIndex; i < nums.length; i++)

// 排列：可以从任意位置开始，但要跳过已使用
for (int i = 0; i < nums.length; i++) {
    if (used[i]) continue;
}

// 可重复使用：传入当前索引
backtrack(nums, i, ...);  // 可重复
backtrack(nums, i + 1, ...);  // 不可重复
```

## 🔍 调试技巧

### 添加打印语句
```java
private void backtrack(int[] nums, int startIndex) {
    System.out.println("进入递归，当前路径：" + path + "，起始索引：" + startIndex);
    
    if (满足条件) {
        System.out.println("找到解：" + path);
        result.add(new ArrayList<>(path));
        return;
    }
    
    for (int i = startIndex; i < nums.length; i++) {
        System.out.println("选择元素：" + nums[i]);
        path.add(nums[i]);
        
        backtrack(nums, i + 1);
        
        path.remove(path.size() - 1);
        System.out.println("撤销元素：" + nums[i] + "，当前路径：" + path);
    }
    
    System.out.println("退出递归，当前路径：" + path);
}
```

## 🎯 常见错误与解决

### 错误1：忘记撤销
```java
// ❌ 错误
path.add(nums[i]);
backtrack(nums, i + 1);
// 忘记撤销

// ✅ 正确
path.add(nums[i]);
backtrack(nums, i + 1);
path.remove(path.size() - 1);
```

### 错误2：引用问题
```java
// ❌ 错误
result.add(path); // 添加的是引用

// ✅ 正确
result.add(new ArrayList<>(path)); // 添加副本
```

### 错误3：索引错误
```java
// ❌ 子集问题用了排列的循环
for (int i = 0; i < nums.length; i++)

// ✅ 子集问题应该用startIndex
for (int i = startIndex; i < nums.length; i++)
```
