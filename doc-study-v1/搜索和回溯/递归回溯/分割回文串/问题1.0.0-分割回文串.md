# 问题1.0.0 分割回文串（LeetCode-131）

- 难度：中等
- 链接：https://leetcode.cn/problems/palindrome-partitioning/

## 概述
将字符串分割为若干子串，使每个子串都是回文；返回所有可能的分割方案。

## 问题特征与分析引导
- 路径结构：起始指针从左到右前进，每次选择一个回文子串作为一步；到达末尾收集方案。
- 回文判断：可在搜索中即时判断，或预处理 `isPal[i][j]` 表加速。
- 生成规模：受字符串结构影响，典型回溯；预处理可显著降耗。

## 可能涉及的知识点
- 回溯模板：起点推进 + 子串选择
- 回文判定优化：DP 预处理 vs 即时双指针
- 复杂度：时间取决于方案数，空间 O(n^2)（若预处理）或 O(n)（即时判定）
