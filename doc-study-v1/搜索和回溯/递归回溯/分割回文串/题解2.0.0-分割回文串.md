# 题解2.0.0 分割回文串（LeetCode-131）

## 题解一：官方经典（DP 预处理 + 回溯）
- 思路：先用 DP 预处理 `isPal[i][j]`，再回溯：若 `isPal[pos][end]` 为真，就把 `s[pos..end]` 加入路径并递归到 `end+1`。
- 复杂度：DP 预处理 O(n^2)，搜索视方案数而定；空间 O(n^2)。

```java
import java.util.*;
class Solution {
    public List<List<String>> partition(String s) {
        int n = s.length();
        boolean[][] isPal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                if (s.charAt(i) == s.charAt(j) && (j - i <= 2 || isPal[i + 1][j - 1])) {
                    isPal[i][j] = true;
                }
            }
        }
        List<List<String>> res = new ArrayList<>();
        dfs(s, 0, isPal, new ArrayList<>(), res);
        return res;
    }
    private void dfs(String s, int pos, boolean[][] isPal, List<String> path, List<List<String>> res) {
        if (pos == s.length()) { res.add(new ArrayList<>(path)); return; }
        for (int end = pos; end < s.length(); end++) {
            if (!isPal[pos][end]) continue;
            path.add(s.substring(pos, end + 1));
            dfs(s, end + 1, isPal, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解二：通用解法（即时判定 + 回溯）
- 标签：回溯、回文判定、DP优化
- 思路：不做预处理，选择子串时用双指针即时判断是否回文，代码更直观但可能重复判断。

```java
import java.util.*;
class Solution {
    public List<List<String>> partition(String s) {
        List<List<String>> res = new ArrayList<>();
        dfs(s, 0, new ArrayList<>(), res);
        return res;
    }
    private void dfs(String s, int pos, List<String> path, List<List<String>> res) {
        if (pos == s.length()) { res.add(new ArrayList<>(path)); return; }
        for (int end = pos; end < s.length(); end++) {
            if (!isPal(s, pos, end)) continue;
            path.add(s.substring(pos, end + 1));
            dfs(s, end + 1, path, res);
            path.remove(path.size() - 1);
        }
    }
    private boolean isPal(String s, int l, int r) {
        while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false;
        return true;
    }
}
```

## 题解三：最好理解（“从左到右切分，遇到回文就深入”）
- 直觉：每次从当前位置尝试所有可能的回文子串，收集到末尾形成一个方案；回退换切分点继续。

## 总结思路
- DP 预处理能显著降耗；即时判定更简洁；两者可按场景取舍。
