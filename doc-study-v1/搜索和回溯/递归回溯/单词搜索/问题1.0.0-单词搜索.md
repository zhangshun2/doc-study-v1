# 问题1.0.0 单词搜索（LeetCode-79）

- 难度：中等
- 链接：https://leetcode.cn/problems/word-search/

## 概述
给定 `m×n` 的字母网格 `board` 和单词 `word`，判断 `word` 是否存在于网格中。单词必须按相邻单元（上下左右）顺序构成，每个单元只能使用一次。

## 问题特征与分析引导
- 路径与约束：路径为相邻格的串联，不能重复使用格子；符合典型 DFS 回溯。
- 剪枝策略：首字符匹配起点；字符频次预检（板上某字符出现次数少于单词中出现次数则直接失败）。
- 记忆结构：`visited` 或原地标记避免重复使用。

## 可能涉及的知识点
- 网格 DFS 回溯与边界判断
- 原地修改与回退（临时标记）
- 预检剪枝（频次或方向顺序优化）
