# 题解2.0.0 单词搜索（LeetCode-79）

## 题解一：官方经典（DFS 回溯 + 原地标记）
- 思路：对每个起点进行 DFS，匹配当前字符后将该格临时改为特殊标记，递归四方向；失败则回退还原。匹配到末尾返回成功。
- 复杂度：最坏 O(m·n·4^L)，空间 O(L) 递归深度，`L` 为单词长度。

```java
import java.util.*;
class Solution {
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        // 频次预检：若板上某字符不足，直接失败
        int[] need = new int[128], have = new int[128];
        for (char c : word.toCharArray()) need[c]++;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) have[board[i][j]]++;
        for (int c = 0; c < 128; c++) if (need[c] > have[c]) return false;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (dfs(board, word, 0, i, j)) return true;
        }
        return false;
    }
    private boolean dfs(char[][] b, String w, int k, int i, int j) {
        if (k == w.length()) return true;
        if (i < 0 || i >= b.length || j < 0 || j >= b[0].length) return false;
        if (b[i][j] != w.charAt(k)) return false;
        char tmp = b[i][j]; b[i][j] = '#'; // 原地标记
        boolean ok = dfs(b, w, k + 1, i + 1, j) || dfs(b, w, k + 1, i - 1, j) ||
                     dfs(b, w, k + 1, i, j + 1) || dfs(b, w, k + 1, i, j - 1);
        b[i][j] = tmp; // 回退还原
        return ok;
    }
}
```

## 题解二：通用解法（visited[][] 标记 + 方向数组）
- 标签：网格、DFS、回溯、剪枝
- 思路：显式 `visited` 数组控制使用状态，方向数组统一迭代四邻。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1, 0, -1, 0, 1};
    public boolean exist(char[][] board, String word) {
        int m = board.length, n = board[0].length;
        int[] need = new int[128], have = new int[128];
        for (char c : word.toCharArray()) need[c]++;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) have[board[i][j]]++;
        for (int c = 0; c < 128; c++) if (need[c] > have[c]) return false;
        boolean[][] vis = new boolean[m][n];
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (dfs(board, word, 0, i, j, vis)) return true;
        }
        return false;
    }
    private boolean dfs(char[][] b, String w, int k, int x, int y, boolean[][] vis) {
        if (k == w.length()) return true;
        if (x < 0 || x >= b.length || y < 0 || y >= b[0].length) return false;
        if (vis[x][y] || b[x][y] != w.charAt(k)) return false;
        vis[x][y] = true;
        for (int d = 0; d < 4; d++) {
            int nx = x + DIR[d], ny = y + DIR[d + 1];
            if (dfs(b, w, k + 1, nx, ny, vis)) { vis[x][y] = false; return true; }
        }
        vis[x][y] = false; return false;
    }
}
```

## 题解三：最好理解（“逐字匹配，走不通就回退”）
- 直觉：每次匹配一个字符，走一步看四周能不能继续；走不通就退回去换条路。

## 总结思路
- 原地标记与 `visited` 都可，关键是正确回退；频次预检能减少起点尝试。
