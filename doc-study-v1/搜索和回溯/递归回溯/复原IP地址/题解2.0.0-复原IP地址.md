题解2.0.0 - 复原 IP 地址（Restore IP Addresses, LeetCode 93）

概述：回溯分成 4 段，段长 1-3，检查数值在 0-255 且前导零规则，达到 4 段且用尽字符串则加入答案。

题解一：回溯构造（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    List<String> ans = new ArrayList<>();
    public List<String> restoreIpAddresses(String s) {
        backtrack(s, 0, new ArrayList<>());
        return ans;
    }
    private void backtrack(String s, int idx, List<String> parts) {
        if (parts.size() == 4) {
            if (idx == s.length()) ans.add(String.join(".", parts));
            return;
        }
        int remain = s.length() - idx;
        int slots = 4 - parts.size();
        if (remain < slots || remain > 3 * slots) return;
        for (int len = 1; len <= 3 && idx + len <= s.length(); len++) {
            String seg = s.substring(idx, idx + len);
            if (seg.length() > 1 && seg.charAt(0) == '0') break;
            int val = Integer.parseInt(seg);
            if (val <= 255) {
                parts.add(seg);
                backtrack(s, idx + len, parts);
                parts.remove(parts.size() - 1);
            }
        }
    }
}
```

复杂度：
- 分支有限，最坏枚举约 O(3^4) 级别，检查常数开销。

思考小结：
- 剩余长度剪枝能减少无效搜索；前导零规则需优先检查。

标签：回溯、字符串、剪枝
