# 题解2.0.0 括号生成（LeetCode-22）

## 题解一：官方经典（回溯 + 剪枝）
- 思路：用两个计数 `left`、`right` 表示已放置的左右括号数。只要 `left < n` 就能放 `(`；只要 `right < left` 就能放 `)`。当 `left == right == n` 收集路径。
- 复杂度：时间为结果规模（卡特兰数），空间 O(n)（递归深度）。

```java
import java.util.*;
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        StringBuilder path = new StringBuilder();
        dfs(n, 0, 0, path, res);
        return res;
    }
    private void dfs(int n, int left, int right, StringBuilder path, List<String> res) {
        if (left == n && right == n) { res.add(path.toString()); return; }
        if (left < n) {
            path.append('(');
            dfs(n, left + 1, right, path, res);
            path.deleteCharAt(path.length() - 1);
        }
        if (right < left) {
            path.append(')');
            dfs(n, left, right + 1, path, res);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
```

## 题解二：通用解法（队列 BFS 层次生成）
- 标签：回溯、剪枝、BFS、生成树
- 思路：队列保存三元组 `(串, left, right)`，分别尝试入队 `(` 和 `)` 的扩展（受约束限制）。当抵达 `left==right==n` 入结果。

```java
import java.util.*;
class Solution {
    static class Node { String s; int left, right; Node(String s, int l, int r){ this.s=s; this.left=l; this.right=r; }}
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        Deque<Node> q = new ArrayDeque<>();
        q.offer(new Node("", 0, 0));
        while (!q.isEmpty()) {
            Node cur = q.poll();
            if (cur.left == n && cur.right == n) { res.add(cur.s); continue; }
            if (cur.left < n) q.offer(new Node(cur.s + '(', cur.left + 1, cur.right));
            if (cur.right < cur.left) q.offer(new Node(cur.s + ')', cur.left, cur.right + 1));
        }
        return res;
    }
}
```

## 题解三：最好理解（“能放左就放左，能放右就放右”）
- 直觉：在任何前缀中，左括号不能少于右括号，因此每一步的选择由约束决定；走到长度 `2n` 时即得到一个合法序列。

## 总结思路
- 剪枝规则是核心：`right <= left`，且左右最多各 `n`；用 `StringBuilder` 优化路径构造。
