## 🎯 高级搜索算法总结
### 🔑 搜索算法完整分类
1. **深度优先搜索(DFS)**
    - 递归实现：简洁但可能栈溢出
    - 迭代实现：使用栈，避免栈溢出
    - 应用场景：路径搜索、连通性检测、拓扑排序
2. **广度优先搜索(BFS)**
    - 队列实现：层次遍历
    - 双端队列：0-1 BFS优化
    - 应用场景：最短路径、最小步数、层次问题
3. **回溯算法**
    - 排列组合：生成所有可能的排列组合
    - 约束满足：N皇后、数独等问题
    - 路径搜索：迷宫、单词搜索等
4. **高级搜索技术**
    - A*算法：启发式搜索
    - 双向搜索：从起点和终点同时搜索
    - 迭代加深：限制搜索深度的DFS
    - 分支限界：最优化问题的搜索

### 📝 搜索优化技巧总结
1. **剪枝优化**
    - 可行性剪枝：提前判断不可能的分支
    - 最优性剪枝：当前解已经不如已知最优解
    - 对称性剪枝：利用问题的对称性
    - 启发式剪枝：利用问题特性进行剪枝
2. **状态压缩**
    - 位运算：用二进制表示状态
    - 哈希：将复杂状态映射为简单标识
    - 滚动数组：优化空间复杂度
3. **记忆化搜索**
    - 避免重复计算
    - 状态缓存
    - 动态规划的递归实现

## 1️⃣1️⃣ 单词搜索 (LeetCode 79)
### 📝 题目描述
给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word`。如果 `word` 存在于网格中，返回 `true`；否则，返回 `false`。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中"相邻"单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

**示例 1：**

```plain
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
输出：true
```

**示例 2：**

```plain
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
输出：true
```

**示例 3：**

```plain
输入：board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
输出：false
```

### 🔧 基础解法：DFS回溯
```java
class Solution {
    private int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
    
    public boolean exist(char[][] board, String word) {
        int m = board.length;
        int n = board[0].length;
        
        // 从每个位置开始尝试
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, word, i, j, 0)) {
                    return true;
                }
            }
        }
        
        return false;
    }
    
    private boolean dfs(char[][] board, String word, int row, int col, int index) {
        // 边界检查
        if (row < 0 || row >= board.length || col < 0 || col >= board[0].length) {
            return false;
        }
        
        // 字符不匹配或已访问
        if (board[row][col] != word.charAt(index)) {
            return false;
        }
        
        // 找到完整单词
        if (index == word.length() - 1) {
            return true;
        }
        
        // 标记当前位置为已访问
        char temp = board[row][col];
        board[row][col] = '#';
        
        // 向四个方向搜索
        for (int[] dir : directions) {
            int newRow = row + dir[0];
            int newCol = col + dir[1];
            
            if (dfs(board, word, newRow, newCol, index + 1)) {
                board[row][col] = temp; // 恢复
                return true;
            }
        }
        
        // 回溯：恢复当前位置
        board[row][col] = temp;
        return false;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(m * n * 4^L)，L是单词长度
+ 空间复杂度：O(L)，递归调用栈

### 🚀 进阶解法：多重优化剪枝
```java
class Solution {
    private int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
    
    public boolean exist(char[][] board, String word) {
        int m = board.length;
        int n = board[0].length;
        
        // 优化1：字符频率统计
        int[] boardCount = new int[128];
        int[] wordCount = new int[128];
        
        for (char[] row : board) {
            for (char c : row) {
                boardCount[c]++;
            }
        }
        
        for (char c : word.toCharArray()) {
            wordCount[c]++;
            if (boardCount[c] < wordCount[c]) {
                return false; // 字符数量不足
            }
        }
        
        // 优化2：如果末尾字符出现频率更低，反转单词
        if (boardCount[word.charAt(0)] > boardCount[word.charAt(word.length() - 1)]) {
            word = new StringBuilder(word).reverse().toString();
        }
        
        // 优化3：从出现频率最低的字符开始搜索
        char startChar = word.charAt(0);
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == startChar && dfs(board, word, i, j, 0)) {
                    return true;
                }
            }
        }
        
        return false;
    }
    
    private boolean dfs(char[][] board, String word, int row, int col, int index) {
        if (index == word.length()) {
            return true;
        }
        
        if (row < 0 || row >= board.length || col < 0 || col >= board[0].length ||
            board[row][col] != word.charAt(index)) {
            return false;
        }
        
        char temp = board[row][col];
        board[row][col] = '#';
        
        // 优化4：提前检查剩余字符是否足够
        boolean found = false;
        for (int[] dir : directions) {
            if (dfs(board, word, row + dir[0], col + dir[1], index + 1)) {
                found = true;
                break;
            }
        }
        
        board[row][col] = temp;
        return found;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(m * n * 4^L)，但实际运行更快
+ 空间复杂度：O(L)

### 🚀 最优解法：Trie树+并行搜索
```java
class Solution {
    class TrieNode {
        TrieNode[] children = new TrieNode[26];
        String word;
        
        public TrieNode() {
            word = null;
        }
    }
    
    private int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
    
    public boolean exist(char[][] board, String word) {
        // 构建Trie树（适用于多单词搜索的扩展）
        TrieNode root = buildTrie(new String[]{word});
        
        int m = board.length;
        int n = board[0].length;
        
        // 字符频率优化
        int[] boardFreq = new int[26];
        for (char[] row : board) {
            for (char c : row) {
                if (c >= 'a' && c <= 'z') {
                    boardFreq[c - 'a']++;
                } else if (c >= 'A' && c <= 'Z') {
                    boardFreq[c - 'A']++;
                }
            }
        }
        
        // 检查字符频率
        int[] wordFreq = new int[26];
        for (char c : word.toCharArray()) {
            int index = Character.toLowerCase(c) - 'a';
            wordFreq[index]++;
            if (boardFreq[index] < wordFreq[index]) {
                return false;
            }
        }
        
        // DFS搜索
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (dfs(board, i, j, root)) {
                    return true;
                }
            }
        }
        
        return false;
    }
    
    private TrieNode buildTrie(String[] words) {
        TrieNode root = new TrieNode();
        
        for (String word : words) {
            TrieNode node = root;
            for (char c : word.toCharArray()) {
                int index = Character.toLowerCase(c) - 'a';
                if (node.children[index] == null) {
                    node.children[index] = new TrieNode();
                }
                node = node.children[index];
            }
            node.word = word;
        }
        
        return root;
    }
    
    private boolean dfs(char[][] board, int row, int col, TrieNode node) {
        if (row < 0 || row >= board.length || col < 0 || col >= board[0].length) {
            return false;
        }
        
        char c = board[row][col];
        if (c == '#') {
            return false;
        }
        
        int index = Character.toLowerCase(c) - 'a';
        if (index < 0 || index >= 26 || node.children[index] == null) {
            return false;
        }
        
        node = node.children[index];
        if (node.word != null) {
            return true;
        }
        
        board[row][col] = '#';
        
        for (int[] dir : directions) {
            if (dfs(board, row + dir[0], col + dir[1], node)) {
                board[row][col] = c;
                return true;
            }
        }
        
        board[row][col] = c;
        return false;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(m * n * 4^L)
+ 空间复杂度：O(L)

## 📚 搜索与回溯专题总结
### 🎯 核心知识点回顾
#### 1. 基础搜索算法
+ **DFS（深度优先搜索）**：递归实现，适用于路径搜索、连通性检测
+ **BFS（广度优先搜索）**：队列实现，适用于最短路径、层次遍历
+ **回溯算法**：DFS的特殊形式，用于生成所有可能的解

#### 2. 高级搜索技术
+ **双向搜索**：从起点和终点同时搜索，减少搜索空间
+ **A*算法**：启发式搜索，使用估价函数指导搜索方向
+ **迭代加深**：逐步增加搜索深度，结合DFS和BFS的优点
+ **分支限界**：在搜索过程中维护最优解的界限

#### 3. 优化技巧
+ **剪枝优化**：可行性剪枝、最优性剪枝、对称性剪枝
+ **状态压缩**：位运算、哈希等方式压缩状态空间
+ **记忆化搜索**：缓存中间结果，避免重复计算
+ **预处理优化**：提前计算有用信息，加速搜索过程

### 💡 解题模式总结
#### 1. 排列组合问题
+ **全排列**：使用回溯生成所有排列
+ **组合问题**：使用回溯生成所有组合
+ **子集问题**：使用回溯或位运算生成所有子集
+ **分割问题**：回溯+预处理的组合

#### 2. 约束满足问题
+ **N皇后**：经典的约束满足问题
+ **数独求解**：复杂的约束满足问题
+ **图着色**：图论中的约束满足

#### 3. 路径搜索问题
+ **迷宫问题**：DFS/BFS寻找路径
+ **单词搜索**：在矩阵中搜索单词
+ **岛屿问题**：连通性检测

#### 4. 最优化问题
+ **最短路径**：BFS或Dijkstra算法
+ **最小步数**：BFS层次遍历
+ **最优解搜索**：分支限界或动态规划

### 🔄 算法选择指南
#### 何时使用DFS？
+ 需要遍历所有可能的路径
+ 问题具有递归结构
+ 内存限制较严格（相对于BFS）
+ 需要找到一个解即可

#### 何时使用BFS？
+ 寻找最短路径或最小步数
+ 需要层次遍历
+ 解的深度较浅
+ 需要找到最优解

#### 何时使用回溯？
+ 需要生成所有可能的解
+ 问题具有约束条件
+ 可以通过剪枝优化
+ 解空间可以用树结构表示

#### 何时使用并查集？
+ 动态连通性问题
+ 需要快速判断两个元素是否连通
+ 需要合并两个集合
+ 静态图的连通性查询
