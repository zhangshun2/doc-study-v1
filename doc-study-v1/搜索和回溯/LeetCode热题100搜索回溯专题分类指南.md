### 2. 🌊 DFS搜索类型（2题）

**文件夹：** `e:\A_SS\搜索和回溯\DFS搜索\`

| 题号 | 题目 | 难度 | 特征 |
|------|------|------|------|
| 79 | 单词搜索 | 中等 | 二维网格搜索，路径查找 |
| 200 | 岛屿数量 | 中等 | 连通分量，区域标记 |

**核心特征：**
- 深度优先遍历图或网格
- 通常涉及连通性问题
- 需要标记访问状态（visited数组）
- 不需要生成所有解，只需要判断存在性或计数

**解题模板：**
```java
void dfs(int[][] grid, int i, int j, boolean[][] visited) {
    // 边界检查和访问检查
    if (i < 0 || i >= m || j < 0 || j >= n || visited[i][j]) return;
    
    visited[i][j] = true;  // 标记访问
    
    // 四个方向递归搜索
    dfs(grid, i+1, j, visited);
    dfs(grid, i-1, j, visited);
    dfs(grid, i, j+1, visited);
    dfs(grid, i, j-1, visited);
}
```

- 第一次找到的解就是最优解


### 4. 📊 图论算法类型（1题）

**文件夹：** `e:\A_SS\搜索和回溯\图论算法\`

| 题号 | 题目 | 难度 | 特征 |
|------|------|------|------|
| 207 | 课程表 | 中等 | 拓扑排序，环检测 |

**核心特征：**
- 有向图的拓扑排序
- 检测图中是否存在环
- 使用入度数组和队列
- 典型的依赖关系问题

**解题思路：**
1. 构建邻接表和入度数组
2. 将入度为0的节点加入队列
3. 逐个处理队列中的节点，更新相邻节点的入度
4. 如果最终处理的节点数等于总节点数，则无环

### 5. 🎯 动态规划搜索类型（1题）

**文件夹：** `e:\A_SS\搜索和回溯\动态规划搜索\`

| 题号 | 题目 | 难度 | 特征 |
|------|------|------|------|
| 494 | 目标和 | 中等 | 背包问题，状态转移 |

**核心特征：**
- 可以用DFS暴力搜索，但更适合动态规划
- 转化为背包问题：找到和为(sum+target)/2的子集
- 状态转移方程：`dp[j] += dp[j-nums[i]]`
- 空间优化：使用一维数组

**两种解法对比：**
- **DFS解法**：时间复杂度O(2^n)，适合理解思路
- **DP解法**：时间复杂度O(n×sum)，更高效

| 题号 | 题目 | 难度 | 特征 |
|------|------|------|------|
| 31 | 下一个排列 | 中等 | 数组操作，字典序 |

**核心特征：**
- 纯数组操作，不涉及搜索
- 字典序的下一个排列
- 三步算法：找降序点→找替换数→翻转后缀

**算法步骤：**
1. 从右向左找第一个降序位置i
2. 从右向左找第一个大于nums[i]的数
3. 交换这两个数
4. 翻转i+1到末尾的部分
