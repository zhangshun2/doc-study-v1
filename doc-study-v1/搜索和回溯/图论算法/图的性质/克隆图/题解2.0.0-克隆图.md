# 题解2.0.0 克隆图（LeetCode-133）

## 题解一：官方经典（DFS 克隆）
- 思路：若节点未被克隆则创建并放入映射；递归克隆其邻居并加入新节点的邻接表。
- 复杂度：时间 O(n+m)，空间 O(n)。

```java
import java.util.*;
class Solution {
    private Map<Node, Node> mp = new HashMap<>();
    public Node cloneGraph(Node node) {
        if (node == null) return null;
        if (mp.containsKey(node)) return mp.get(node);
        Node copy = new Node(node.val, new ArrayList<>()); mp.put(node, copy);
        for (Node nei : node.neighbors) copy.neighbors.add(cloneGraph(nei));
        return copy;
    }
}
// class Node { public int val; public List<Node> neighbors; public Node(int v, List<Node> n){ val=v; neighbors=n; } }
```

## 题解二：通用解法（BFS 克隆）
- 标签：BFS、哈希映射
- 思路：用队列按层遍历，遇到未克隆的节点就创建并加入映射，再将克隆边连接起来。

## 题解三：最好理解（“边走边复制，旧节点指向新节点”）
- 直觉：用一个字典保存“旧 -> 新”，遍历时把邻居也做同样的复制。

## 总结思路
- DFS 与 BFS 等价；关键是映射与邻接关系的维护。
