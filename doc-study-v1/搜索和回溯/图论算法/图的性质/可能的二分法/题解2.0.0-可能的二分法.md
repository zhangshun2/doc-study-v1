题解2.0.0 - 可能的二分法（Possible Bipartition, LeetCode 886）

概述：典型二分图判定。构建邻接表，对每个未染色节点执行 BFS/DFS，尝试 2-染色，若遇到同色冲突则不可二分。

题解一：BFS 染色（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public boolean possibleBipartition(int n, int[][] dislikes) {
        List<Integer>[] g = new ArrayList[n + 1];
        for (int i = 1; i <= n; i++) g[i] = new ArrayList<>();
        for (int[] e : dislikes) {
            int a = e[0], b = e[1];
            g[a].add(b);
            g[b].add(a);
        }
        int[] color = new int[n + 1]; // 0: uncolored, 1/2: colors
        for (int i = 1; i <= n; i++) {
            if (color[i] != 0) continue;
            Queue<Integer> q = new ArrayDeque<>();
            q.offer(i);
            color[i] = 1;
            while (!q.isEmpty()) {
                int u = q.poll();
                for (int v : g[u]) {
                    if (color[v] == 0) {
                        color[v] = 3 - color[u];
                        q.offer(v);
                    } else if (color[v] == color[u]) {
                        return false;
                    }
                }
            }
        }
        return true;
    }
}
```

题解二：DFS 染色（递归）

思路：
- 递归给相邻顶点异色。若遇到冲突返回 false。

复杂度：
- O(n + m)，n 为节点数，m 为边数。

思考小结：
- 多分量时要从所有未访问节点出发。
- 染色数组可复用，避免重复访问。

标签：二分图、图着色、BFS/DFS
