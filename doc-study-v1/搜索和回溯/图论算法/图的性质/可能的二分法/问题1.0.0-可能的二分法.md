问题1.0.0 - 可能的二分法（Possible Bipartition, LeetCode 886）

概述：给定 n 个节点和“互斥”关系 dislikes，判断能否将节点分成两组使得每条互斥边连接的两个节点属于不同组，本质为图的二分性（是否二分图）。

链接：https://leetcode.com/problems/possible-bipartition/

题目特征与分析：
- 无向图二分性判定：等价于图是否可 2-染色。
- 多连通分量：需对每个未访问点进行 BFS/DFS 染色。

知识点：
- 图着色（2-染色）与二分图判定。
- 队列 BFS 或递归 DFS 均可。

输入输出：
- 输入：n 与 dislikes 边集合（1-indexed）。
- 输出：布尔值，能否二分。

标签：图论、二分图、BFS/DFS 染色、搜索与回溯
