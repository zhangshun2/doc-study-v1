题解2.0.0 - 二分图判定（Is Graph Bipartite?, LeetCode 785）

概述：用 BFS/DFS 对未染色节点进行 2-染色，遇到同色冲突则不是二分图。

题解一：BFS 染色（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public boolean isBipartite(int[][] graph) {
        int n = graph.length;
        int[] color = new int[n]; // 0: uncolored, 1/-1: colors
        for (int i = 0; i < n; i++) {
            if (color[i] != 0) continue;
            Queue<Integer> q = new ArrayDeque<>();
            q.offer(i);
            color[i] = 1;
            while (!q.isEmpty()) {
                int u = q.poll();
                for (int v : graph[u]) {
                    if (color[v] == 0) {
                        color[v] = -color[u];
                        q.offer(v);
                    } else if (color[v] == color[u]) {
                        return false;
                    }
                }
            }
        }
        return true;
    }
}
```

复杂度：
- O(n + m)，空间 O(n)。

思考小结：
- 多分量需从每个未染色节点启动；使用 1/-1 两色方便取反。
