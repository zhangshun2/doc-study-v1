题解2.0.0 - 不相邻植花（Flower Planting With No Adjacent, LeetCode 1042）

概述：对每个花园检查邻居已用颜色，选择未使用的最小颜色（1..4）。题目保证总能分配成功。

题解一：贪心图着色（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int[] gardenNoAdj(int n, int[][] paths) {
        List<Integer>[] g = new ArrayList[n];
        for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
        for (int[] e : paths) {
            int a = e[0] - 1, b = e[1] - 1;
            g[a].add(b); g[b].add(a);
        }
        int[] color = new int[n];
        for (int i = 0; i < n; i++) {
            boolean[] used = new boolean[5];
            for (int v : g[i]) used[color[v]] = true;
            for (int c = 1; c <= 4; c++) if (!used[c]) { color[i] = c; break; }
        }
        return color;
    }
}
```

复杂度：
- O(n + m)，空间 O(n + m)。

思考小结：
- 邻居颜色集合很小（≤4），贪心足够覆盖所有情况。

标签：图着色、贪心
