问题1.0.0 - 不相邻植花（Flower Planting With No Adjacent, LeetCode 1042）

概述：给定 n 个花园与路径关系，要求给每个花园染色（1..4）使相邻花园颜色不同。贪心为每个花园选择未被邻居占用的最小色即可。

链接：https://leetcode.com/problems/flower-planting-with-no-adjacent/

题目特征与分析：
- 图着色（局部 4 色）：保证存在解，贪心即可。
- 多分量：按编号遍历，逐个分配颜色。

知识点：
- 图着色、贪心策略、邻居冲突检查。

输入输出：
- 输入：n 与路径 `paths[i] = [u, v]`（1-index）。
- 输出：长度为 n 的颜色数组（1..4）。

标签：图着色、贪心、图的性质、搜索与回溯
