题解2.0.0 - 最终安全状态（Find Eventual Safe States, LeetCode 802）

概述：使用 DFS 颜色标记判断节点是否安全：1表示“访问中”若再次遇到则存在环，2表示“已判定安全”。也可用反图 + 拓扑削减出度。

题解一：DFS 颜色标记（推荐）

思路：
- 对每个点执行 dfs：若遇到访问中的点（color=1）则构成环，当前点不安全；若所有邻居都安全则当前点安全（color=2）。
- 避免重复：节点一旦染色复用结果。

Java 实现：

```java
import java.util.*;

class Solution {
    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;
        int[] color = new int[n]; // 0: unknown, 1: visiting, 2: safe
        List<Integer> res = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (dfs(graph, i, color)) res.add(i);
        }
        return res;
    }

    private boolean dfs(int[][] g, int u, int[] color) {
        if (color[u] != 0) return color[u] == 2;
        color[u] = 1; // visiting
        for (int v : g[u]) {
            if (color[v] == 2) continue;
            if (color[v] == 1 || !dfs(g, v, color)) return false;
        }
        color[u] = 2; // safe
        return true;
    }
}
```

题解二：反图 + 拓扑（出度削减）

思路：
- 建反图，统计每个点的出度。把出度为0的点入队，向前削减其前驱点出度；最终出度为0的点即安全节点。

复杂度：
- DFS：O(n + m)，每边至多访问一次。
- 反图拓扑：O(n + m)。

思考小结：
- “安全”等价于“不在环且不可达环”。两种方法本质上都是在排除环上节点与可达环节点。
- DFS 颜色法实现简洁，反图拓扑在工程上有时更直观。
