问题1.0.0 - 最终安全状态（Find Eventual Safe States, LeetCode 802）

概述：给定有向图，找出所有不会进入环的“最终安全”节点。节点安全当且仅当从它出发的所有路径最终都到达终止节点（出度为0），而不进入任何有向环。

链接：https://leetcode.com/problems/find-eventual-safe-states/

题目特征与分析：
- 有向图与环检测：核心是判断节点是否在环内或可达环。
- 图搜索与标记：可用 DFS 颜色标记（0未访问，1访问中，2安全）避免重复与栈回溯。
- 也可用反图 + 拓扑（出度为0的点入队，逐步削减）作为另一思路。

知识点：
- 图的环检测（DFS 颜色标记法）。
- 拓扑思想（反图、出度削减）。
- 复杂度与剪枝：一次 DFS 标记后复用结果。

输入输出：
- 输入：邻接表 `graph[i]` 为 i 的所有出边终点。
- 输出：升序的所有安全节点编号列表。

标签：图论、DFS、拓扑、环检测、搜索与回溯
