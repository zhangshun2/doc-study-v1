题解2.0.0 - 小镇法官（Find the Town Judge, LeetCode 997）

概述：统计每个人的入度与出度。若存在 i 满足 `in[i] == n-1 && out[i] == 0`，则 i 为法官；否则返回 -1。

题解一：入度/出度统计（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int findJudge(int n, int[][] trust) {
        int[] in = new int[n + 1];
        int[] out = new int[n + 1];
        for (int[] e : trust) {
            int a = e[0], b = e[1];
            out[a]++; in[b]++;
        }
        for (int i = 1; i <= n; i++) {
            if (in[i] == n - 1 && out[i] == 0) return i;
        }
        return -1;
    }
}
```

复杂度：
- O(n + m)，m 为信任关系数，空间 O(n)。

思考小结：
- 直接以入/出度定义判断，无需构图。

标签：图的性质、计数、线性扫描
