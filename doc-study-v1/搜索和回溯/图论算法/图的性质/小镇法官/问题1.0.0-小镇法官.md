问题1.0.0 - 小镇法官（Find the Town Judge, LeetCode 997）

概述：在 n 人的小镇中，若存在一个人被所有人相信且他不相信任何人，则该人是法官。用入度/出度统计判断。

链接：https://leetcode.com/problems/find-the-town-judge/

题目特征与分析：
- 入度/出度判定：法官满足 `in = n-1` 且 `out = 0`。
- 若有多个满足条件人，题设保证至多一个，返回该人编号，否则 -1。

知识点：
- 图的性质、入度/出度、线性扫描。

输入输出：
- 输入：n 与信任关系 `trust[a] = b`。
- 输出：法官编号或 -1。

标签：图的性质、计数判定、搜索与回溯
