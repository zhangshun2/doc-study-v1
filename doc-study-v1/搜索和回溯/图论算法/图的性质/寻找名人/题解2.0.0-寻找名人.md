# 题解2.0.0 寻找名人（LeetCode-277）

## 题解一：官方经典（线性候选 + 验证）
- 思路：先线性确定候选 `cand`，再验证其满足名人条件；不满足返回 `-1`。
- 复杂度：时间 O(n)，空间 O(1)。

```java
/* The knows API is defined in the parent class Relation.
   boolean knows(int a, int b); */
class Solution extends Relation {
    public int findCelebrity(int n) {
        int cand = 0;
        for (int i = 1; i < n; i++) if (knows(cand, i)) cand = i;
        for (int i = 0; i < n; i++) {
            if (i == cand) continue;
            if (knows(cand, i) || !knows(i, cand)) return -1;
        }
        return cand;
    }
}
```

## 题解二：通用解法（双指针淘汰）
- 标签：指针、淘汰、验证
- 思路：也可用双指针两端向内淘汰；本质与线性候选相同。

## 题解三：最好理解（“先找唯一可能的人，再严检是否符合”）
- 直觉：通过关系快速剔除不可能者，最后严格验证。

## 总结思路
- 候选淘汰 + 验证是最优线性解法。
