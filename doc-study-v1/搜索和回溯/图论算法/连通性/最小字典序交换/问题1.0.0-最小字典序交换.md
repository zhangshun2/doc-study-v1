问题1.0.0 - 最小字典序交换（Smallest String With Swaps, LeetCode 1202）

概述：给定字符串 s 和可交换的索引对 pairs，同一连通分量内的索引可以任意交换。通过并查集将索引分组后，分别在分组内排序字符并重组，得到字典序最小字符串。

链接：https://leetcode.com/problems/smallest-string-with-swaps/

题目特征与分析：
- 索引连通分组：并查集合并 pairs。
- 组件内重排：按分组对字符排序并回填。

知识点：
- 并查集、分组与排序、哈希映射。

输入输出：
- 输入：字符串 s，索引对列表 pairs。
- 输出：字典序最小的字符串。

标签：并查集、排序、连通性、搜索与回溯
