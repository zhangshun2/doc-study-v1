题解2.0.0 - 最小字典序交换（Smallest String With Swaps, LeetCode 1202）

概述：用并查集合并索引，按根节点分组，组内将字符排序并按索引序回填，得到最小字符串。

题解一：并查集 + 组内排序（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public String smallestStringWithSwaps(String s, List<List<Integer>> pairs) {
        int n = s.length();
        DSU dsu = new DSU(n);
        for (List<Integer> p : pairs) dsu.union(p.get(0), p.get(1));
        Map<Integer, List<Integer>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) groups.computeIfAbsent(dsu.find(i), k -> new ArrayList<>()).add(i);
        char[] ans = s.toCharArray();
        for (List<Integer> idxs : groups.values()) {
            List<Character> chars = new ArrayList<>();
            for (int i : idxs) chars.add(s.charAt(i));
            Collections.sort(idxs); Collections.sort(chars);
            for (int i = 0; i < idxs.size(); i++) ans[idxs.get(i)] = chars.get(i);
        }
        return new String(ans);
    }
    static class DSU {
        int[] p, r; DSU(int n) { p = new int[n]; r = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) { int pa = find(a), pb = find(b); if (pa == pb) return; if (r[pa] < r[pb]) p[pa] = pb; else if (r[pa] > r[pb]) p[pb] = pa; else { p[pb] = pa; r[pa]++; } }
    }
}
```

复杂度：
- O(n log n)，空间 O(n)。

思考小结：
- 分组内排序 + 索引回填即可；也可用优先队列存组内字符提取。

标签：并查集、分组、排序
