问题1.0.0 - 图中是否存在路径（Find if Path Exists in Graph, LeetCode 1971）

概述：给定无向图与起点、终点，判断是否存在从起点到终点的路径。用 BFS/DFS 可达性判定或并查集。

链接：https://leetcode.com/problems/find-if-path-exists-in-graph/

题目特征与分析：
- 连通性判定：从起点搜索，访问到终点即返回真。
- 多分量：图可能不连通。

知识点：
- BFS/DFS、连通性、并查集（可选）。

输入输出：
- 输入：`n`，`edges`，`source`，`destination`。
- 输出：布尔值，是否可达。

标签：可达性、BFS、DFS、连通性、搜索与回溯
