题解2.0.0 - 图中是否存在路径（Find if Path Exists in Graph, LeetCode 1971）

概述：构建邻接表，从 `source` 起做 BFS，若遇到 `destination` 即返回 true，遍历结束未遇到则 false。

题解一：BFS 可达性（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public boolean validPath(int n, int[][] edges, int source, int destination) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) { g.get(e[0]).add(e[1]); g.get(e[1]).add(e[0]); }
        boolean[] vis = new boolean[n];
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(source); vis[source] = true;
        while (!q.isEmpty()) {
            int u = q.poll();
            if (u == destination) return true;
            for (int v : g.get(u)) if (!vis[v]) { vis[v] = true; q.offer(v); }
        }
        return source == destination;
    }
}
```

复杂度：
- O(n + m)，空间 O(n + m)。

思考小结：
- BFS/DFS 等价；并查集也可预处理连通性后查询两点是否同集合。

标签：可达性、BFS、DFS、连通性
