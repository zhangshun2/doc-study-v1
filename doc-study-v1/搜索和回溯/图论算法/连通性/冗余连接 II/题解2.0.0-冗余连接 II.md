# 题解2.0.0 冗余连接 II（LeetCode-685）

## 题解一：官方经典（入度检查 + 并查集）
- 思路：
  1) 找入度为 2 的节点，记录两条父边 `cand1`（先出现）与 `cand2`（后出现）；
  2) 在并查集中“忽略 cand2”做合并，若出现环，则返回 `cand1`（删除其使树合法）；否则若无环，返回 `cand2`。
  若没有入度 2，则直接并查集判环，返回成环的那条边。
- 复杂度：时间 O(E α(V))，空间 O(V)。

```java
import java.util.*;
class Solution {
    public int[] findRedundantDirectedConnection(int[][] edges) {
        int n = edges.length;
        int[] parent = new int[n + 1];
        for (int i = 1; i <= n; i++) parent[i] = i;
        int[] cand1 = null, cand2 = null;
        // 找入度为2的节点，记录两条边
        for (int[] e : edges) {
            int u = e[0], v = e[1];
            if (parent[v] != v) { cand1 = new int[]{parent[v], v}; cand2 = new int[]{u, v}; e[1] = 0; }
            else parent[v] = u;
        }
        DSU dsu = new DSU(n + 1);
        for (int[] e : edges) {
            int u = e[0], v = e[1]; if (v == 0) continue; // 忽略 cand2
            if (dsu.find(u) == dsu.find(v)) {
                if (cand1 != null) return cand1; // 入度2 + 成环
                return e; // 纯成环
            }
            dsu.union(u, v);
        }
        return cand2; // 入度2但不成环
    }
    static class DSU {
        int[] p;
        DSU(int n){ p = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x){ return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b){ a = find(a); b = find(b); p[a] = b; }
    }
}
```

- 直觉：两类异常分别定位，组合讨论给出唯一解。

## 总结思路
- 按入度优先 + 并查集判环是标准范式，边删除策略清晰。
