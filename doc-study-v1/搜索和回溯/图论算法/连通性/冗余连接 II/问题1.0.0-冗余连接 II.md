# 问题1.0.0 冗余连接 II（LeetCode-685）

- 难度：困难
- 链接：https://leetcode.cn/problems/redundant-connection-ii/

## 概述
在有向图中，给出一棵根为未知的有向树，但额外加了一个边导致不再是树。需要删除一条边，使其恢复为有向树。返回需要删除的边（若有多条，返回出现最晚的那条）。

## 问题特征与分析引导
- 两种异常：
  - 有节点入度为 2（两个父亲）
  - 存在有向环
- 处理顺序：先定位入度为 2 的节点并标记可候选删除的边，再用并查集判环并决定返回哪条边。

## 可能涉及的知识点
- 并查集（无向判环的等价性）
- 入度统计与候选边记录
- 组合讨论与返回策略
