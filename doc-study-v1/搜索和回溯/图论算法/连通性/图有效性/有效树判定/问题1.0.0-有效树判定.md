问题1.0.0 - 有效树判定（Graph Valid Tree, LeetCode 261）

概述：给定节点数和无向边列表，判断图是否为树。树的判定条件：边数为 n-1 且图连通且无环。并查集或 DFS 均可实现。

链接：https://leetcode.com/problems/graph-valid-tree/

题目特征与分析：
- 判定条件：`edges.length == n-1` 且无环且连通。
- 并查集：合并边两端，若出现同根则有环。

知识点：
- 并查集、连通性、环检测。

输入输出：
- 输入：`n`，`edges`。
- 输出：是否为树。

标签：连通性、并查集、环检测、搜索与回溯
