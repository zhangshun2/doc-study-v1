# 问题1.0.0 冗余连接（LeetCode-684）

- 难度：中等
- 链接：https://leetcode.cn/problems/redundant-connection/

## 概述
给定无向图的边列表，起初是树（连通无环），但加上一条边后形成了环。返回导致出现环的那条边（若有多条，返回最后出现的那条）。

## 问题特征与分析引导
- 连通性与成环判定：并查集（Union-Find）可在线判定新增边是否导致环。
- 返回规则：遇到首次使两个端点已连通的边即为冗余边；遍历顺序自然满足“最后出现”。

## 可能涉及的知识点
- 并查集：路径压缩与按秩合并
- 成环判定与边遍历
