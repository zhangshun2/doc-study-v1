# 题解2.0.0 冗余连接（LeetCode-684）

## 题解一：官方经典（并查集在线判环）
- 思路：初始化并查集，遍历每条边，若两端已在同一集合则该边即冗余边；否则合并。
- 复杂度：时间近似 O(E α(V))，空间 O(V)。

```java
class Solution {
    public int[] findRedundantConnection(int[][] edges) {
        int n = edges.length; DSU dsu = new DSU(n + 1);
        for (int[] e : edges) {
            int u = e[0], v = e[1];
            if (dsu.find(u) == dsu.find(v)) return e;
            dsu.union(u, v);
        }
        return new int[]{-1, -1};
    }
    static class DSU {
        int[] p, r;
        DSU(int n){ p = new int[n]; r = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x){ return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b){ a = find(a); b = find(b); if (a == b) return; if (r[a] < r[b]) p[a] = b; else if (r[a] > r[b]) p[b] = a; else { p[b] = a; r[a]++; } }
    }
}
```

## 题解二：通用解法（DFS 判环）
- 标签：DFS、判环、连通性
- 思路：逐条加边并用 DFS 检查是否存在环；实现简单但效率较低。

## 题解三：最好理解（“并查集：如果已经连上，再连就成环”）
- 直觉：两个点本来就能互通，再加一条边必然产生环。

## 总结思路
- 并查集是最优；遍历边即可找到冗余边。
