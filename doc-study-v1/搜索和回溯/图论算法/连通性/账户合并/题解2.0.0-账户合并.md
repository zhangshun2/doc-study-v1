题解2.0.0 - 账户合并（Accounts Merge, LeetCode 721）

概述：为每个邮箱分配唯一 id，用并查集把同一账户的邮箱合并到同一集合。最后按集合 root 聚合邮箱，排序后输出。

题解一：并查集合并 + 哈希分组（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public List<List<String>> accountsMerge(List<List<String>> accounts) {
        Map<String, Integer> emailId = new HashMap<>();
        Map<String, String> emailName = new HashMap<>();
        int id = 0;
        // 第一次遍历：为每个邮箱分配 id，并记录邮箱对应名字
        for (List<String> acc : accounts) {
            String name = acc.get(0);
            for (int i = 1; i < acc.size(); i++) {
                String email = acc.get(i);
                if (!emailId.containsKey(email)) emailId.put(email, id++);
                emailName.put(email, name);
            }
        }
        DSU dsu = new DSU(id);
        // 第二次遍历：把同一账户的所有邮箱并到同一集合
        for (List<String> acc : accounts) {
            int first = emailId.get(acc.get(1));
            for (int i = 2; i < acc.size(); i++) {
                dsu.union(first, emailId.get(acc.get(i)));
            }
        }
        // 分组：root -> emails
        Map<Integer, List<String>> groups = new HashMap<>();
        for (String email : emailId.keySet()) {
            int root = dsu.find(emailId.get(email));
            groups.computeIfAbsent(root, k -> new ArrayList<>()).add(email);
        }
        // 输出：按字典序排序，并以名字开头
        List<List<String>> res = new ArrayList<>();
        for (List<String> emails : groups.values()) {
            Collections.sort(emails);
            String name = emailName.get(emails.get(0));
            List<String> item = new ArrayList<>();
            item.add(name);
            item.addAll(emails);
            res.add(item);
        }
        return res;
    }

    static class DSU {
        int[] p, r;
        DSU(int n) { p = new int[n]; r = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa == pb) return;
            if (r[pa] < r[pb]) p[pa] = pb;
            else if (r[pa] > r[pb]) p[pb] = pa;
            else { p[pb] = pa; r[pa]++; }
        }
    }
}
```

复杂度：
- O(E α(E) + E log E)，E 为邮箱总数。

思考小结：
- 名字取法：同一集合内任一邮箱的名字一致，用第一个即可。
- 两次遍历更稳妥：先确定并查集规模，再合并。

标签：并查集、哈希、分组排序

题解二：图连通分量（BFS/DFS）
- 将邮箱作为节点，账户内邮箱两两相连，最后对连通分量进行分组与排序，复杂度同量级。
