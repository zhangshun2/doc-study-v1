题解2.0.0 - 由斜杠划分的区域（Regions Cut By Slashes, LeetCode 959）

概述：将每个网格划分为 4 个三角形（上、右、下、左），按字符内部合并；再将相邻格的对应三角形合并，最终连通分量数即为区域数。

题解一：并查集 4-三角形建模（推荐）

建模规则：
- 每格索引基 `base = (i * n + j) * 4`，三角形编号 0:上,1:右,2:下,3:左。
- 字符为空格 ' '：合并 0,1,2,3。
- 字符为 '/'：合并 0-3、1-2。
- 字符为 '\\'：合并 0-1、2-3。
- 相邻合并：右邻合并 当前1 与 右邻3；下邻合并 当前2 与 下邻0。

Java 实现：

```java
import java.util.*;

class Solution {
    public int regionsBySlashes(String[] grid) {
        int n = grid.length;
        DSU dsu = new DSU(n * n * 4);
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int base = (i * n + j) * 4;
                char c = grid[i].charAt(j);
                if (c == ' ') {
                    dsu.union(base + 0, base + 1);
                    dsu.union(base + 0, base + 2);
                    dsu.union(base + 0, base + 3);
                } else if (c == '/') {
                    dsu.union(base + 0, base + 3);
                    dsu.union(base + 1, base + 2);
                } else if (c == '\\') {
                    dsu.union(base + 0, base + 1);
                    dsu.union(base + 2, base + 3);
                }
                // 右邻合并
                if (j + 1 < n) {
                    int rightBase = (i * n + (j + 1)) * 4;
                    dsu.union(base + 1, rightBase + 3);
                }
                // 下邻合并
                if (i + 1 < n) {
                    int downBase = ((i + 1) * n + j) * 4;
                    dsu.union(base + 2, downBase + 0);
                }
            }
        }
        int count = 0;
        for (int x = 0; x < n * n * 4; x++) {
            if (dsu.find(x) == x) count++;
        }
        return count;
    }

    static class DSU {
        int[] p, r;
        DSU(int n) { p = new int[n]; r = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa == pb) return;
            if (r[pa] < r[pb]) p[pa] = pb;
            else if (r[pa] > r[pb]) p[pb] = pa;
            else { p[pb] = pa; r[pa]++; }
        }
    }
}
```

复杂度：
- O(n^2 α(n^2))，近似线性。空间 O(n^2)。

思考小结：
- 关键在于正确的三角形划分与相邻合并规则。
