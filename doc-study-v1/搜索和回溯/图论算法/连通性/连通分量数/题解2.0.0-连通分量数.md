题解2.0.0 - 连通分量数（Number of Connected Components in an Undirected Graph, LeetCode 323）

概述：用并查集合并所有边的两个端点，最后统计有多少不同的父节点（根），即分量数。也可用 DFS/BFS 遍历计数。

题解一：并查集（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int countComponents(int n, int[][] edges) {
        DSU dsu = new DSU(n);
        for (int[] e : edges) dsu.union(e[0], e[1]);
        int cnt = 0;
        for (int i = 0; i < n; i++) if (dsu.find(i) == i) cnt++;
        return cnt;
    }

    static class DSU {
        int[] p, r;
        DSU(int n) { p = new int[n]; r = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa == pb) return;
            if (r[pa] < r[pb]) p[pa] = pb;
            else if (r[pa] > r[pb]) p[pb] = pa;
            else { p[pb] = pa; r[pa]++; }
        }
    }
}
```

复杂度：
- 近似 O(n + m α(n))，空间 O(n)。

思考小结：
- 连通性计数题用并查集实现最简洁稳妥。
