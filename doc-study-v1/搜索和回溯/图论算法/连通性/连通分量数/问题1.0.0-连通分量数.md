问题1.0.0 - 连通分量数（Number of Connected Components in an Undirected Graph, LeetCode 323）

概述：给定 n 个节点与无向边集，统计图的连通分量数量。可用 DFS/BFS 或并查集实现。

链接：https://leetcode.com/problems/number-of-connected-components-in-an-undirected-graph/

题目特征与分析：
- 无向图连通性：常见的基础题。
- 并查集更简洁：将每条边两端合并，最后数根节点数。

知识点：
- 并查集、DFS/BFS 遍历、连通性判定。

输入输出：
- 输入：节点数 n 与边集 edges。
- 输出：连通分量数量。

标签：连通性、并查集、DFS/BFS、搜索与回溯
