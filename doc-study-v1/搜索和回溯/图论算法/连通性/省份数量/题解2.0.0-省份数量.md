题解2.0.0 - 省份数量（Number of Provinces, LeetCode 547）

概述：并查集将有边的两端合并，最终统计根节点数量即为省份数。

题解一：并查集（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        DSU dsu = new DSU(n);
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (isConnected[i][j] == 1) dsu.union(i, j);
            }
        }
        int cnt = 0;
        for (int i = 0; i < n; i++) if (dsu.find(i) == i) cnt++;
        return cnt;
    }

    static class DSU {
        int[] p, r;
        DSU(int n) { p = new int[n]; r = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa == pb) return;
            if (r[pa] < r[pb]) p[pa] = pb;
            else if (r[pa] > r[pb]) p[pb] = pa;
            else { p[pb] = pa; r[pa]++; }
        }
    }
}
```

复杂度：
- 近似 O(n^2 α(n))，空间 O(n)。

思考小结：
- 矩阵输入用并查集更直观；DFS 也可等价实现。

标签：连通性、并查集
