题解2.0.0 - 移除最多的石头（Most Stones Removed with Same Row or Column, LeetCode 947）

概述：用并查集在石头索引之间合并：同一行的石头合并，同一列的石头合并。最终答案为 `n - 分量数`。

题解一：并查集按行列合并（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int removeStones(int[][] stones) {
        int n = stones.length;
        DSU dsu = new DSU(n);
        Map<Integer, Integer> rowRep = new HashMap<>();
        Map<Integer, Integer> colRep = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int r = stones[i][0], c = stones[i][1];
            if (rowRep.containsKey(r)) dsu.union(i, rowRep.get(r)); else rowRep.put(r, i);
            if (colRep.containsKey(c)) dsu.union(i, colRep.get(c)); else colRep.put(c, i);
        }
        Set<Integer> roots = new HashSet<>();
        for (int i = 0; i < n; i++) roots.add(dsu.find(i));
        return n - roots.size();
    }
    static class DSU {
        int[] p, r; DSU(int n) { p = new int[n]; r = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) { int pa = find(a), pb = find(b); if (pa == pb) return; if (r[pa] < r[pb]) p[pa] = pb; else if (r[pa] > r[pb]) p[pb] = pa; else { p[pb] = pa; r[pa]++; } }
    }
}
```

复杂度：
- O(n α(n))，空间 O(n)。

思考小结：
- 通过行/列代表合并可避免 O(n^2) 检查；结果为总数减分量数。

标签：并查集、连通分量
