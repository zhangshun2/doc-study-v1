问题1.0.0 - 移除最多的石头（Most Stones Removed with Same Row or Column, LeetCode 947）

概述：同一行或同一列的石头可视为连通，移除的最大数量为总石头数减去连通分量数。用并查集按行列将石头合并。

链接：https://leetcode.com/problems/most-stones-removed-with-same-row-or-column/

题目特征与分析：
- 行列连通：同一行/列的石头属于同一分量。
- 合并策略：使用哈希映射按行/列合并到代表石头。

知识点：
- 并查集、连通分量计数、哈希映射。

输入输出：
- 输入：石头坐标数组 `stones[i] = [r, c]`。
- 输出：可移除的最多石头数量。

标签：并查集、连通性、搜索与回溯
