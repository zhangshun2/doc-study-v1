问题1.0.0 - 交换字符串中的元素（Smallest String With Swaps, LeetCode 1202）

概述：给定字符串与若干可交换位置对 (i, j)，可在同连通块内任意交换字符。求按字典序最小的结果字符串。

链接：https://leetcode.com/problems/smallest-string-with-swaps/

题目特征与分析：
- 并查集将索引按交换关系分成连通块。
- 每个块内字符排序后按索引填回。

知识点：
- 并查集、分组、优先队列或排序。

输入输出：
- 输入：字符串 s 与交换对 pairs。
- 输出：字典序最小的字符串。

标签：并查集、字符串、分组与排序、搜索与回溯
