题解2.0.0 - 交换字符串中的元素（Smallest String With Swaps, LeetCode 1202）

概述：用并查集将位置按交换关系分块，每块内字符排序后再按索引取用即可得到最小字典序字符串。

题解一：并查集 + 分组排序（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public String smallestStringWithSwaps(String s, List<List<Integer>> pairs) {
        int n = s.length();
        DSU dsu = new DSU(n);
        for (List<Integer> e : pairs) {
            dsu.union(e.get(0), e.get(1));
        }
        Map<Integer, PriorityQueue<Character>> group = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int root = dsu.find(i);
            group.computeIfAbsent(root, k -> new PriorityQueue<>()).offer(s.charAt(i));
        }
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            int root = dsu.find(i);
            sb.append(group.get(root).poll());
        }
        return sb.toString();
    }

    static class DSU {
        int[] p, r;
        DSU(int n) { p = new int[n]; r = new int[n]; for (int i = 0; i < n; i++) p[i] = i; }
        int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
        void union(int a, int b) {
            int pa = find(a), pb = find(b);
            if (pa == pb) return;
            if (r[pa] < r[pb]) p[pa] = pb;
            else if (r[pa] > r[pb]) p[pb] = pa;
            else { p[pb] = pa; r[pa]++; }
        }
    }
}
```

复杂度：
- 并查集合并近似线性，分组后排序/堆操作总体 O(n log n)。

思考小结：
- 使用最小堆能自然按需取出字典序最小字符；也可先排序再按索引弹出。

标签：并查集、分组排序、字符串
