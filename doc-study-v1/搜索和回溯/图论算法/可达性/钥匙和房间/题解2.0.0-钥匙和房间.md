题解2.0.0 - 钥匙和房间（Keys and Rooms, LeetCode 841）

概述：用 BFS/DFS 从 0 号房间开始，拿到钥匙就访问对应房间，最终判断访问计数是否为 n。

题解一：BFS 可达性（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size();
        boolean[] vis = new boolean[n];
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(0); vis[0] = true;
        int cnt = 0;
        while (!q.isEmpty()) {
            int u = q.poll(); cnt++;
            for (int v : rooms.get(u)) {
                if (!vis[v]) { vis[v] = true; q.offer(v); }
            }
        }
        return cnt == n;
    }
}
```

复杂度：
- O(n + m)，空间 O(n)。

思考小结：
- 可达性问题的直接模型；使用队列或栈均可。

标签：可达性、BFS、DFS
