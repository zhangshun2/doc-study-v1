# 问题1.0.0 除法求值（LeetCode-399）

- 难度：中等
- 链接：https://leetcode.cn/problems/evaluate-division/

## 概述
给定若干等式 `a / b = k` 与若干查询 `x / y`，返回每个查询的值；不可达或不存在返回 `-1.0`。

## 问题特征与分析引导
- 图建模：变量为节点，边权为乘法比值；双向边 `a->b:k` 与 `b->a:1/k`。
- 搜索：对每次查询可用 BFS/DFS 累乘路径权重。
- 去重：访问标记避免环与重复。

## 可能涉及的知识点
- 哈希映射与邻接表
- BFS/DFS 搜索与权重累计
- 并查集（加权 Union-Find）可作为替代方案
