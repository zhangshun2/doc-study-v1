# 题解2.0.0 除法求值（LeetCode-399）

## 题解一：官方经典（DFS/BFS 累乘）
- 思路：建图后对查询 `x/y` 从 `x` 出发搜索到 `y`，沿途累乘边权；不可达返回 `-1.0`。
- 复杂度：时间 O(Q × (V+E)) 近似，空间 O(V+E)。

```java
import java.util.*;
class Solution {
    public double[] calcEquation(List<List<String>> equations, double[] values, List<List<String>> queries) {
        Map<String, List<Pair>> g = new HashMap<>();
        for (int i = 0; i < equations.size(); i++) {
            String a = equations.get(i).get(0), b = equations.get(i).get(1);
            double k = values[i];
            g.computeIfAbsent(a, t -> new ArrayList<>()).add(new Pair(b, k));
            g.computeIfAbsent(b, t -> new ArrayList<>()).add(new Pair(a, 1.0 / k));
        }
        double[] ans = new double[queries.size()];
        for (int i = 0; i < queries.size(); i++) {
            String s = queries.get(i).get(0), t = queries.get(i).get(1);
            if (!g.containsKey(s) || !g.containsKey(t)) { ans[i] = -1.0; continue; }
            ans[i] = bfs(g, s, t);
        }
        return ans;
    }
    private double bfs(Map<String, List<Pair>> g, String s, String t) {
        Deque<String> q = new ArrayDeque<>(); q.offer(s);
        Map<String, Double> val = new HashMap<>(); val.put(s, 1.0);
        while (!q.isEmpty()) {
            String u = q.poll(); if (u.equals(t)) return val.get(u);
            for (Pair e : g.getOrDefault(u, Collections.emptyList())) {
                if (!val.containsKey(e.to)) { val.put(e.to, val.get(u) * e.w); q.offer(e.to); }
            }
        }
        return -1.0;
    }
    static class Pair { String to; double w; Pair(String t, double w){ this.to=t; this.w=w; } }
}
```

## 题解二：通用解法（加权并查集）
- 标签：并查集、权重、路径压缩
- 思路：维护父节点与到父的权重，查询时若同集合则通过权重比计算结果；实现较复杂但查询快。

## 题解三：最好理解（“把变量连成有权图，沿路径把比例乘起来”）
- 直觉：从出发变量走到目标变量，沿途乘边权即答案。

## 总结思路
- 图搜索直观易实现；并查集适合高查询量场景。
