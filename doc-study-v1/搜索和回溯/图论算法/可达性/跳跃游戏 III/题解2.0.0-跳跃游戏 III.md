# 题解2.0.0 跳跃游戏 III（LeetCode-1306）

## 题解一：官方经典（BFS 可达性）
- 思路：队列从 `start` 出发，扩张到两个候选索引，越界或访问过则跳过；遇到值为 `0` 返回 `true`。
- 复杂度：时间 O(n)，空间 O(n)。

```java
import java.util.*;
class Solution {
    public boolean canReach(int[] arr, int start) {
        int n = arr.length; boolean[] vis = new boolean[n];
        Deque<Integer> q = new ArrayDeque<>(); q.offer(start); vis[start] = true;
        while (!q.isEmpty()) {
            int i = q.poll(); if (arr[i] == 0) return true;
            int a = i + arr[i], b = i - arr[i];
            if (a >= 0 && a < n && !vis[a]) { vis[a] = true; q.offer(a); }
            if (b >= 0 && b < n && !vis[b]) { vis[b] = true; q.offer(b); }
        }
        return false;
    }
}
```

## 题解二：通用解法（DFS）
- 标签：DFS、可达性
- 思路：递归尝试两方向；访问标记防止无限循环。

## 题解三：最好理解（“从起点试两跳，能落到 0 即成功”）
- 直觉：沿着可选跳法搜索，见到 0 就返回。

## 总结思路
- BFS/DFS 均可，访问标记与边界是关键。
