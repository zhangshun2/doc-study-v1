# 题解2.0.0 钥匙和房间（LeetCode-841）

## 题解一：官方经典（DFS 可达性）
- 思路：从房间 `0` 出发，遇到钥匙就访问对应房间；最终判断访问数量是否为 `n`。
- 复杂度：时间 O(n + m)，空间 O(n)。

```java
import java.util.*;
class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size(); boolean[] vis = new boolean[n];
        dfs(rooms, 0, vis);
        for (boolean b : vis) if (!b) return false;
        return true;
    }
    private void dfs(List<List<Integer>> rooms, int u, boolean[] vis) {
        if (vis[u]) return; vis[u] = true;
        for (int v : rooms.get(u)) dfs(rooms, v, vis);
    }
}
```

## 题解二：通用解法（BFS 可达性）
- 标签：BFS、队列、图
- 思路：用队列迭代扩张，拿到钥匙就把对应房间入队，访问标记去重。

```java
import java.util.*;
class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size(); boolean[] vis = new boolean[n];
        Deque<Integer> q = new ArrayDeque<>(); vis[0] = true; q.offer(0);
        while (!q.isEmpty()) {
            int u = q.poll();
            for (int v : rooms.get(u)) {
                if (!vis[v]) { vis[v] = true; q.offer(v); }
            }
        }
        for (boolean b : vis) if (!b) return false; return true;
    }
}
```

## 题解三：最好理解（“拿到钥匙就开门，直到没有新房间”）
- 直觉：不断取钥匙开新房间，最后看是否全部进入。

## 总结思路
- 可达性搜索直接判断是否能访问所有节点；DFS/BFS 都可。
