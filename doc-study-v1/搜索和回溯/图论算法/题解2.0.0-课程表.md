# 题解2.0.0-课程表：拓扑排序的两种实现方法

## 🎯 解题概述

课程表问题本质上是**有向图的环检测问题**。我们需要判断课程依赖关系是否形成环，如果有环则无法完成所有课程。

**核心思路：** 使用拓扑排序算法，如果能完成拓扑排序说明无环，否则有环。

## 💡 解法一：Kahn算法（BFS + 入度）

### 算法思路
1. 构建有向图的邻接表表示
2. 计算每个节点的入度
3. 将入度为0的节点加入队列
4. 不断取出入度为0的节点，更新其邻接节点的入度
5. 如果处理的节点数等于总节点数，说明无环

### Java实现
```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 建图：使用邻接表
        List<Integer>[] graph = new List[numCourses];
        int[] indegree = new int[numCourses];
        
        // 初始化邻接表
        for (int i = 0; i < numCourses; i++) {
            graph[i] = new ArrayList<>();
        }
        
        // 构建图并计算入度
        for (int[] prerequisite : prerequisites) {
            int course = prerequisite[0];      // 要学的课程
            int preCourse = prerequisite[1];   // 先修课程
            
            graph[preCourse].add(course);      // preCourse → course
            indegree[course]++;                // course的入度+1
        }
        
        // 2. 将所有入度为0的节点加入队列
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) {
                queue.offer(i);
            }
        }
        
        // 3. 拓扑排序
        int processedCount = 0;
        while (!queue.isEmpty()) {
            int currentCourse = queue.poll();
            processedCount++;
            
            // 处理当前课程的所有后续课程
            for (int nextCourse : graph[currentCourse]) {
                indegree[nextCourse]--;
                
                // 如果后续课程的入度变为0，加入队列
                if (indegree[nextCourse] == 0) {
                    queue.offer(nextCourse);
                }
            }
        }
        
        // 4. 判断是否处理了所有课程
        return processedCount == numCourses;
    }
}
```

## 💡 解法二：DFS + 三色标记法

### 算法思路
1. 使用三种状态标记节点：未访问(0)、访问中(1)、已完成(2)
2. 对每个未访问的节点进行DFS
3. 如果在DFS过程中遇到"访问中"的节点，说明有环
4. 如果所有节点都能正常完成DFS，说明无环

### Java实现
```java
class Solution {
    private List<Integer>[] graph;
    private int[] state; // 0:未访问, 1:访问中, 2:已完成
    
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1. 建图
        graph = new List[numCourses];
        state = new int[numCourses];
        
        for (int i = 0; i < numCourses; i++) {
            graph[i] = new ArrayList<>();
        }
        
        for (int[] prerequisite : prerequisites) {
            int course = prerequisite[0];
            int preCourse = prerequisite[1];
            graph[preCourse].add(course);
        }
        
        // 2. 对每个未访问的节点进行DFS
        for (int i = 0; i < numCourses; i++) {
            if (state[i] == 0) {
                if (hasCycle(i)) {
                    return false; // 发现环
                }
            }
        }
        
        return true; // 无环
    }
    
    private boolean hasCycle(int course) {
        if (state[course] == 1) {
            return true; // 发现环：遇到访问中的节点
        }
        
        if (state[course] == 2) {
            return false; // 已完成的节点，无需重复访问
        }
        
        // 标记为访问中
        state[course] = 1;
        
        // 递归访问所有邻接节点
        for (int nextCourse : graph[course]) {
            if (hasCycle(nextCourse)) {
                return true;
            }
        }
        
        // 标记为已完成
        state[course] = 2;
        return false;
    }
}
```

## 📊 算法分析

### 时间复杂度
- **Kahn算法：** O(V + E)
  - V：课程数量（节点数）
  - E：先修关系数量（边数）
  - 每个节点和边都只被访问一次

- **DFS算法：** O(V + E)
  - 每个节点最多被访问两次（访问中→已完成）
  - 每条边被遍历一次

### 空间复杂度
- **Kahn算法：** O(V + E)
  - 邻接表：O(V + E)
  - 入度数组：O(V)
  - 队列：O(V)

- **DFS算法：** O(V + E)
  - 邻接表：O(V + E)
  - 状态数组：O(V)
  - 递归栈：O(V)

## 🔍 执行演示

### 示例：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]

```
图结构：
0 → 1 → 3
↓     ↗
2 ----

入度：[0, 1, 1, 2]
```

**Kahn算法执行过程：**
```
初始队列：[0] (入度为0)
处理节点0：count=1, 更新入度[0,0,0,2], 队列[1,2]
处理节点1：count=2, 更新入度[0,0,0,1], 队列[2]
处理节点2：count=3, 更新入度[0,0,0,0], 队列[3]
处理节点3：count=4, 队列[]
结果：count(4) == numCourses(4) → true
```

## 📝 核心模板总结

### Kahn算法模板
```java
public boolean topologicalSort(int n, int[][] edges) {
    // 1. 建图和计算入度
    List<Integer>[] graph = new List[n];
    int[] indegree = new int[n];
    
    for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
    for (int[] edge : edges) {
        graph[edge[1]].add(edge[0]);
        indegree[edge[0]]++;
    }
    
    // 2. 初始化队列
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < n; i++) {
        if (indegree[i] == 0) queue.offer(i);
    }
    
    // 3. 拓扑排序
    int count = 0;
    while (!queue.isEmpty()) {
        int node = queue.poll();
        count++;
        for (int next : graph[node]) {
            if (--indegree[next] == 0) {
                queue.offer(next);
            }
        }
    }
    
    return count == n;
}
```

### DFS环检测模板
```java
private boolean hasCycle(int node) {
    if (state[node] == 1) return true;  // 发现环
    if (state[node] == 2) return false; // 已访问
    
    state[node] = 1; // 标记访问中
    for (int next : graph[node]) {
        if (hasCycle(next)) return true;
    }
    state[node] = 2; // 标记已完成
    return false;
}
```

## 🎯 关键技巧

1. **图的表示**：邻接表比邻接矩阵更适合稀疏图
2. **入度计算**：正确理解边的方向和入度的关系
3. **状态管理**：DFS中的三色标记法是环检测的经典技巧
4. **边界处理**：空图、单节点图等特殊情况

## ⚠️ 常见错误

1. **边的方向搞反**：`[a,b]`表示b→a，不是a→b
2. **入度计算错误**：要统计指向节点的边数
3. **状态标记混乱**：DFS中忘记恢复状态或标记错误
4. **队列初始化遗漏**：忘记将初始入度为0的节点加入队列
