# 问题1.0.0 K站中转内最便宜的航班（LeetCode-787）

- 难度：中等
- 链接：https://leetcode.cn/problems/cheapest-flights-within-k-stops/

## 概述
给定航班信息 `flights`（边 `u->v`，费用 `w`）、城市数 `n`、起点 `src`、终点 `dst`，求不超过 `K` 次中转的最小费用；不可达返回 `-1`。

## 问题特征与分析引导
- 最短路的“边数限制”：路径的边数 ≤ `K+1`。
- 适配算法：限制边数的最短路可用“分层 Bellman-Ford/DP”。
- Dijkstra变体：带“停站数”的堆优化需要状态扩维与剪枝。

## 可能涉及的知识点
- Bellman-Ford（按轮次松弛）
- 限制边数的最短路模型（层次 DP）
- 优先队列 + 状态扩维（城市 + 已用中转数）
