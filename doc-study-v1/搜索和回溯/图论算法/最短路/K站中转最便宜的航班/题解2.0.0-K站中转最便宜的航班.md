# 题解2.0.0 K站中转内最便宜的航班（LeetCode-787）

## 题解一：官方经典（限制边数的 Bellman-Ford）
- 思路：`dist[i]` 为恰好 ≤ 当前轮的最小费用，每轮复制旧数组并按边松弛，循环 `K+1` 次。
- 复杂度：时间 O(K·E)，空间 O(V)。

```java
import java.util.*;
class Solution {
    public int findCheapestPrice(int n, int[][] flights, int src, int dst, int K) {
        final int INF = 1_000_000_000;
        int[] dist = new int[n]; Arrays.fill(dist, INF); dist[src] = 0;
        for (int i = 0; i <= K; i++) {
            int[] nd = dist.clone();
            for (int[] e : flights) {
                int u = e[0], v = e[1], w = e[2];
                if (dist[u] != INF) nd[v] = Math.min(nd[v], dist[u] + w);
            }
            dist = nd;
        }
        return dist[dst] >= INF ? -1 : dist[dst];
    }
}
```

## 题解二：通用解法（堆优化 Dijkstra + 中转计数）
- 标签：最短路、优先队列、状态扩展
- 思路：状态 `(city, stops, cost)` 入堆，限制 `stops <= K+1`，对每城维护“在不同停站数下的最优成本”。

## 题解三：最好理解（“最多走 K+1 条边的最短路”）
- 直觉：用“分轮次”放宽边数，逐步更新可达城市的最低费用。

## 总结思路
- 边数受限时 Bellman-Ford 直接有效；堆优化需小心状态维度。
