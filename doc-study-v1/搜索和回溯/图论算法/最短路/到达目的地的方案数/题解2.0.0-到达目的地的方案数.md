题解2.0.0 - 到达目的地的方案数（Number of Ways to Arrive at Destination, LeetCode 1976）

概述：用 Dijkstra 求最短距离，同时维护 `ways[u]` 为到 u 的最短路径条数；松弛时若新距离更短则覆盖 ways，若相等则累加。

题解一：Dijkstra + 路径计数（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    static final long MOD = 1_000_000_007L;
    public int countPaths(int n, int[][] roads) {
        List<List<int[]>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : roads) { g.get(e[0]).add(new int[]{e[1], e[2]}); g.get(e[1]).add(new int[]{e[0], e[2]}); }
        long[] dist = new long[n]; Arrays.fill(dist, Long.MAX_VALUE / 4);
        long[] ways = new long[n]; ways[0] = 1; dist[0] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[1]));
        pq.offer(new long[]{0, 0});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            int u = (int) cur[0]; long du = cur[1];
            if (du > dist[u]) continue;
            for (int[] nxt : g.get(u)) {
                int v = nxt[0], w = nxt[1];
                long nd = du + w;
                if (nd < dist[v]) {
                    dist[v] = nd;
                    ways[v] = ways[u];
                    pq.offer(new long[]{v, nd});
                } else if (nd == dist[v]) {
                    ways[v] = (ways[v] + ways[u]) % MOD;
                }
            }
        }
        return (int) (ways[n - 1] % MOD);
    }
}
```

复杂度：
- O(m log n)，空间 O(n + m)。

思考小结：
- 计数逻辑与最短路松弛同步；注意用 long 存距离并处理模数。
