问题1.0.0 - 到达目的地的方案数（Number of Ways to Arrive at Destination, LeetCode 1976）

概述：给定 n 个点和带权无向边 roads，求从 0 到 n-1 的最短路径条数，答案对 1e9+7 取模。需用 Dijkstra 计算最短距并统计路径条数。

链接：https://leetcode.com/problems/number-of-ways-to-arrive-at-destination/

题目特征与分析：
- 变权图最短路：Dijkstra 维护最短距离。
- 路径计数：当遇到同样最短距离时累加路径条数；更短则覆盖。

知识点：
- Dijkstra、最短路径计数、优先队列、模运算。

输入输出：
- 输入：节点数 n、边列表 `roads[i] = [u, v, w]`。
- 输出：从 0 到 n-1 的最短路径条数（模 1e9+7）。

标签：Dijkstra、最短路、路径计数、搜索与回溯
