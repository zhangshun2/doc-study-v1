题解2.0.0 - 网络延迟时间（Network Delay Time, LeetCode 743）

概述：用 Dijkstra 计算从 k 到各点的最短距离，取最大值即为答案，若有 INF 则不可达返回 -1。

题解一：Dijkstra（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        List<List<int[]>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : times) g.get(e[0] - 1).add(new int[]{e[1] - 1, e[2]});
        int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE / 4);
        dist[k - 1] = 0;
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[1]));
        pq.offer(new int[]{k - 1, 0});
        while (!pq.isEmpty()) {
            int[] cur = pq.poll(); int u = cur[0], du = cur[1];
            if (du > dist[u]) continue;
            for (int[] nxt : g.get(u)) {
                int v = nxt[0], w = nxt[1];
                if (du + w < dist[v]) { dist[v] = du + w; pq.offer(new int[]{v, dist[v]}); }
            }
        }
        int ans = 0;
        for (int d : dist) { if (d >= Integer.MAX_VALUE / 8) return -1; ans = Math.max(ans, d); }
        return ans;
    }
}
```

复杂度：
- O(m log n)，空间 O(n + m)。

思考小结：
- 取最短路数组的最大值作为延迟时间；注意节点下标从 1 转 0。

标签：Dijkstra、单源最短路
