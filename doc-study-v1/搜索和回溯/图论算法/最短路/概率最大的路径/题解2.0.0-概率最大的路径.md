# 题解2.0.0 概率最大的路径（LeetCode-1514）

## 题解一：官方经典（最大堆 Dijkstra）
- 思路：`dist[u]` 为到 `u` 的最大成功概率；每次取当前概率最大节点扩张，遇到终点可早停返回。
- 复杂度：时间 O((V+E) log V)，空间 O(V+E)。

```java
import java.util.*;
class Solution {
    static class Edge { int v; double p; Edge(int v, double p){ this.v = v; this.p = p; } }
    public double maxProbability(int n, int[][] edges, double[] succProb, int start, int end) {
        List<Edge>[] g = new ArrayList[n];
        for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
        for (int i = 0; i < edges.length; i++) {
            int u = edges[i][0], v = edges[i][1]; double p = succProb[i];
            g[u].add(new Edge(v, p)); g[v].add(new Edge(u, p));
        }
        double[] dist = new double[n]; dist[start] = 1.0;
        PriorityQueue<double[]> pq = new PriorityQueue<>((a, b) -> Double.compare(b[0], a[0]));
        pq.offer(new double[]{1.0, start}); boolean[] vis = new boolean[n];
        while (!pq.isEmpty()) {
            double[] cur = pq.poll(); double prob = cur[0]; int u = (int)cur[1];
            if (u == end) return prob; if (vis[u]) continue; vis[u] = true;
            for (Edge e : g[u]) {
                double np = prob * e.p;
                if (np > dist[e.v]) { dist[e.v] = np; pq.offer(new double[]{np, e.v}); }
            }
        }
        return 0.0;
    }
}
```

## 题解二：通用解法（取对数转加法）
- 标签：对数变换、最短路
- 思路：对概率取 `-log` 转为最短路；但需注意精度与路径还原。

## 题解三：最好理解（“每次挑当前成功率最高的路继续走”）
- 直觉：最大堆保证总是以最高成功概率扩展。

## 总结思路
- 最大堆 Dijkstra 直观有效；对数法也可行但实现复杂度更高。
