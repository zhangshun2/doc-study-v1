# 问题1.0.0 水位上升的泳池中游泳（LeetCode-778）

- 难度：困难
- 链接：https://leetcode.cn/problems/swim-in-rising-water/

## 概述
给定 `grid` 表示时间 `t` 时可游泳的高度上限为 `t`。从 `(0,0)` 到 `(n-1,n-1)` 的最早时间即为路径上格子值的最大值的最小化。返回该最小值。

## 问题特征与分析引导
- 路径代价为路径上最大的格子值（最大边权的最小化）。
- 算法：Dijkstra（松弛为 `max`）或二分阈值 + BFS 验证。

## 可能涉及的知识点
- 网格最短路（取最大）
- 二分答案与可达性
