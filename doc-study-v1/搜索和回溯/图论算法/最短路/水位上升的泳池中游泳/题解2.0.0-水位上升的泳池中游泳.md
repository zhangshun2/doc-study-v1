# 题解2.0.0 水位上升的泳池中游泳（LeetCode-778）

## 题解一：官方经典（Dijkstra 变体）
- 思路：`dist[x][y]` 为到达该点路径上最大格子值的最小可能；每次取当前最小 `dist` 点扩张，松弛为 `nd = max(d, grid[nx][ny])`。
- 复杂度：时间 O(n^2 log n^2)，空间 O(n^2)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int swimInWater(int[][] grid) {
        int n = grid.length; int[][] dist = new int[n][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        dist[0][0] = grid[0][0]; pq.offer(new int[]{dist[0][0], 0, 0});
        boolean[][] vis = new boolean[n][n];
        while (!pq.isEmpty()) {
            int[] cur = pq.poll(); int d = cur[0], x = cur[1], y = cur[2];
            if (vis[x][y]) continue; vis[x][y] = true;
            if (x == n - 1 && y == n - 1) return d;
            for (int k = 0; k < 4; k++) {
                int nx = x + DIR[k], ny = y + DIR[k + 1];
                if (nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                int nd = Math.max(d, grid[nx][ny]);
                if (dist[nx][ny] > nd) { dist[nx][ny] = nd; pq.offer(new int[]{nd, nx, ny}); }
            }
        }
        return -1;
    }
}
```

## 题解二：通用解法（二分 + BFS）
- 标签：二分、BFS
- 思路：二分时间阈值 `T`，判断是否存在路径使经过的格子值 ≤ `T`（BFS 可达）。

## 题解三：最好理解（“同时度量‘时间最高值’最小化的路径”）
- 直觉：路径代价由最难的一步决定，用 Dijkstra 的“max 松弛”即可。

## 总结思路
- 两种主流解法都稳定；Dijkstra 更直观。
