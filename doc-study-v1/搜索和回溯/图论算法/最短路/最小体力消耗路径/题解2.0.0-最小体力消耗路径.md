# 题解2.0.0 最小体力消耗路径（LeetCode-1631）

## 题解一：官方经典（Dijkstra 变体）
- 思路：`dist[x][y]` 为到 `(x,y)` 的路径上最大边权的最小可能值；松弛为 `nd = max(curDist, w)`。
- 复杂度：时间 O(mn log mn)，空间 O(mn)。

```java
import java.util.*;
class Solution {
    private static final int[] DIR = {1,0,-1,0,1};
    public int minimumEffortPath(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        dist[0][0] = 0; pq.offer(new int[]{0, 0, 0});
        boolean[][] vis = new boolean[m][n];
        while (!pq.isEmpty()) {
            int[] cur = pq.poll(); int d = cur[0], x = cur[1], y = cur[2];
            if (vis[x][y]) continue; vis[x][y] = true;
            if (x == m - 1 && y == n - 1) return d;
            for (int k = 0; k < 4; k++) {
                int nx = x + DIR[k], ny = y + DIR[k + 1];
                if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                int w = Math.abs(heights[nx][ny] - heights[x][y]);
                int nd = Math.max(d, w);
                if (dist[nx][ny] > nd) { dist[nx][ny] = nd; pq.offer(new int[]{nd, nx, ny}); }
            }
        }
        return 0;
    }
}
```

## 题解二：通用解法（二分 + BFS）
- 标签：二分、BFS、网格
- 思路：二分体力阈值 `T`，判断是否存在路径使所有边权 ≤ `T`（BFS 可达）。

## 题解三：最好理解（“要么直接走最不吃力的路，要么试阈值能否通”）
- 直觉：Dijkstra 是最直接的；二分则是“试探可行阈值”。

## 总结思路
- Dijkstra 变体更直观；二分在某些常数下更快。
