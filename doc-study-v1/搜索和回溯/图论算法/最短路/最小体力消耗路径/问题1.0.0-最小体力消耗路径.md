# 问题1.0.0 最小体力消耗路径（LeetCode-1631）

- 难度：中等
- 链接：https://leetcode.cn/problems/path-with-minimum-effort/

## 概述
在高差网格中，从左上角到右下角的路径的“体力消耗”为路径上边的最大高度差，求使该值最小的路径的体力消耗。

## 问题特征与分析引导
- 边权定义：相邻格子的边权为高度差绝对值；路径代价为边权的最大值。
- 算法适配：Dijkstra 变体（松弛为 `max`）或二分阈值 + BFS 验证。

## 可能涉及的知识点
- 网格图最短路（Dijkstra 取 `max`）
- 二分答案与可达性验证（BFS/DFS）
