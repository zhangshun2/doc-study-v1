# 问题1.0.0-课程表：拓扑排序检测环

## 📋 题目信息

**LeetCode 207. 课程表**  
**难度：** 中等  
**链接：** [🔗](https://leetcode.cn/problems/course-schedule/)

## 🎯 问题描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。

在选修某些课程之前需要一些先修课程。先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]` ，表示如果要学习课程 `ai` 则 **必须** 先学习课程 `bi` 。

- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0` ，你需要先完成课程 `1` 。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true` ；否则，返回 `false` 。

## 📝 示例分析

### 示例 1
```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true

解释：
- 总共有2门课程
- 学习课程1之前，需要先完成课程0
- 学习顺序：0 → 1
- 可以完成所有课程
```

### 示例 2
```
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false

解释：
- 总共有2门课程  
- 学习课程1之前，需要先完成课程0
- 学习课程0之前，需要先完成课程1
- 形成循环依赖：0 → 1 → 0
- 无法完成所有课程
```

### 示例 3
```
输入：numCourses = 3, prerequisites = [[1,0],[2,1]]
输出：true

解释：
- 学习顺序：0 → 1 → 2
- 可以完成所有课程
```

## 🔍 问题特征分析

### 核心特征
1. **有向图问题**：课程和先修关系构成有向图
2. **环检测问题**：如果图中有环，则无法完成所有课程
3. **拓扑排序**：如果能进行拓扑排序，说明无环
4. **依赖关系**：先修课程是后续课程的依赖

### 图论概念
- **节点**：每门课程是图中的一个节点
- **有向边**：`[a, b]` 表示从课程b到课程a的有向边（b → a）
- **入度**：指向某节点的边的数量（有多少先修课程）
- **出度**：从某节点出发的边的数量（是多少课程的先修课程）

### 约束条件
- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= 5000`
- `prerequisites[i].length == 2`
- `0 <= ai, bi < numCourses`
- `prerequisites[i]` 中的所有课程对 **互不相同**

## 🧠 解题思路引导

### 思路分析
1. **建图**：根据先修关系构建有向图
2. **计算入度**：统计每个课程的先修课程数量
3. **拓扑排序**：使用Kahn算法进行拓扑排序
4. **环检测**：如果能完成拓扑排序，说明无环

### 关键问题
1. **如何表示图？** 使用邻接表存储有向图
2. **如何计算入度？** 遍历所有边，统计指向每个节点的边数
3. **如何进行拓扑排序？** 使用队列，从入度为0的节点开始
4. **如何判断有环？** 拓扑排序处理的节点数是否等于总节点数

## 🎨 算法设计要点

### Kahn算法框架
```java
public boolean canFinish(int numCourses, int[][] prerequisites) {
    // 1. 建图和计算入度
    List<Integer>[] graph = new List[numCourses];
    int[] indegree = new int[numCourses];
    
    for (int i = 0; i < numCourses; i++) {
        graph[i] = new ArrayList<>();
    }
    
    for (int[] pre : prerequisites) {
        int course = pre[0];
        int preCourse = pre[1];
        graph[preCourse].add(course);  // preCourse → course
        indegree[course]++;            // course的入度+1
    }
    
    // 2. 将入度为0的节点加入队列
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++) {
        if (indegree[i] == 0) {
            queue.offer(i);
        }
    }
    
    // 3. 拓扑排序
    int count = 0;
    while (!queue.isEmpty()) {
        int course = queue.poll();
        count++;
        
        // 处理当前课程的后续课程
        for (int nextCourse : graph[course]) {
            indegree[nextCourse]--;
            if (indegree[nextCourse] == 0) {
                queue.offer(nextCourse);
            }
        }
    }
    
    // 4. 判断是否处理了所有课程
    return count == numCourses;
}
```

### 算法步骤详解
1. **建图**：构建邻接表表示的有向图
2. **计算入度**：统计每个节点的入度
3. **初始化队列**：将所有入度为0的节点加入队列
4. **拓扑排序**：
   - 从队列中取出一个节点
   - 将其所有邻接节点的入度减1
   - 如果某个邻接节点入度变为0，加入队列
5. **环检测**：检查处理的节点数是否等于总节点数
