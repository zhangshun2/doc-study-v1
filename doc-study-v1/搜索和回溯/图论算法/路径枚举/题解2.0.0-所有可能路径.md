# 题解2.0.0 所有可能路径（LeetCode-797）

## 题解一：官方经典（DFS 路径回溯）
- 思路：从 `0` 出发，路径入栈；到达 `n-1` 时收集副本；返回时出栈。
- 复杂度：时间取决于路径数量，空间 O(n)。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> allPathsSourceTarget(int[][] graph) {
        List<List<Integer>> res = new ArrayList<>();
        List<Integer> path = new ArrayList<>(); path.add(0);
        dfs(graph, 0, path, res); return res;
    }
    private void dfs(int[][] g, int u, List<Integer> path, List<List<Integer>> res) {
        int n = g.length;
        if (u == n - 1) { res.add(new ArrayList<>(path)); return; }
        for (int v : g[u]) {
            path.add(v);
            dfs(g, v, path, res);
            path.remove(path.size() - 1);
        }
    }
}
```

## 题解二：通用解法（BFS 路径队列）
- 标签：BFS、路径枚举、队列
- 思路：队列元素保存完整路径，扩张时将邻居追加成新路径入队；到达 `n-1` 收集。

```java
import java.util.*;
class Solution {
    public List<List<Integer>> allPathsSourceTarget(int[][] graph) {
        List<List<Integer>> res = new ArrayList<>();
        Deque<List<Integer>> q = new ArrayDeque<>(); q.offer(Arrays.asList(0));
        int n = graph.length;
        while (!q.isEmpty()) {
            List<Integer> path = q.poll(); int u = path.get(path.size() - 1);
            if (u == n - 1) { res.add(path); continue; }
            for (int v : graph[u]) {
                List<Integer> np = new ArrayList<>(path); np.add(v); q.offer(np);
            }
        }
        return res;
    }
}
```

## 题解三：最好理解（“一路向终点走，走到就把这条路记录下来”）
- 直觉：回溯走所有可能分支，遇到终点就留下一条路径。

## 总结思路
- DAG 场景下 DFS 最简洁；BFS 路径队列也易于理解。
