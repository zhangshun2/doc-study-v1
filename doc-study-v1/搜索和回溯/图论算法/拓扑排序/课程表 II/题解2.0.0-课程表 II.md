# 题解2.0.0 课程表 II（LeetCode-210）

## 题解一：官方经典（Kahn 输出拓扑序）
- 思路：与 207 相同，但出队时将课程加入结果列表；若最终课程数不足说明有环。
- 复杂度：时间 O(n+m)，空间 O(n+m)。

```java
import java.util.*;
class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) g.add(new ArrayList<>());
        int[] indeg = new int[numCourses];
        for (int[] e : prerequisites) { g.get(e[1]).add(e[0]); indeg[e[0]]++; }
        Deque<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.offer(i);
        int[] order = new int[numCourses]; int idx = 0;
        while (!q.isEmpty()) {
            int u = q.poll(); order[idx++] = u;
            for (int v : g.get(u)) { if (--indeg[v] == 0) q.offer(v); }
        }
        if (idx < numCourses) return new int[0]; return order;
    }
}
```

## 题解二：通用解法（DFS 后序栈）
- 标签：DFS、拓扑
- 思路：后序加入栈，最终逆序为拓扑序；发现回边则返回空。

## 题解三：最好理解（“每拿到一门课就解锁后续，按解锁顺序输出”）
- 直觉：不断拿无前置课程，按拿的顺序就是一个可行拓扑序。

## 总结思路
- Kahn 输出拓扑序最直观；DFS 后序也可但需细致的环检测。
