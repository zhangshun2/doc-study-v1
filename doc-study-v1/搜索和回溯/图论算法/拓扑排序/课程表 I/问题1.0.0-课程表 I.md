问题1.0.0 - 课程表 I（Course Schedule, LeetCode 207）

概述：给定课程数与先修关系，判断是否能完成所有课程。本质为有向图是否无环，可用 BFS 拓扑或 DFS 判断环。

链接：https://leetcode.com/problems/course-schedule/

题目特征与分析：
- 有向图环检测：拓扑排序计数是否覆盖所有节点。
- 入度统计：入度为 0 的节点先入队。

知识点：
- 拓扑排序、BFS、有向图环。

输入输出：
- 输入：`numCourses`、`prerequisites[i] = [a, b]` 表示修 a 需先修 b。
- 输出：是否能完成所有课程。

标签：拓扑排序、BFS、图的性质、搜索与回溯
