问题1.0.0 - 最小高度树（Minimum Height Trees, LeetCode 310）

概述：给定无向连通图（树）含 n 个节点与边集，要求选择若干根使得生成的树高度最小。答案为树的“中心”节点，使用拓扑剥叶（BFS削减度数）寻找。

链接：https://leetcode.com/problems/minimum-height-trees/

题目特征与分析：
- 树的中心：一颗树的中心最多两个，反复删除叶子最终剩余即为中心。
- 拓扑剥叶：用队列层次删除所有度为1的节点，直到剩余节点数≤2。

知识点：
- 拓扑思想、队列层序、图的度数削减。

输入输出：
- 输入：n 与边集 `edges`（0-index）。
- 输出：所有中心节点编号列表。

标签：拓扑、BFS、图论、搜索与回溯
