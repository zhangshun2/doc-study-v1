题解2.0.0 - 最小高度树（Minimum Height Trees, LeetCode 310）

概述：用“拓扑剥叶法”寻找树的中心。每轮从队列取出所有叶子削减其邻居度，直到剩余≤2 个节点，这些节点即答案。

题解一：拓扑剥叶（推荐）

Java 实现：

```java
import java.util.*;

class Solution {
    public List<Integer> findMinHeightTrees(int n, int[][] edges) {
        if (n == 1) return Collections.singletonList(0);
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        int[] deg = new int[n];
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
            deg[e[0]]++; deg[e[1]]++;
        }
        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++) if (deg[i] == 1) q.offer(i);
        int remain = n;
        while (remain > 2) {
            int sz = q.size();
            remain -= sz;
            for (int i = 0; i < sz; i++) {
                int u = q.poll();
                for (int v : g.get(u)) {
                    if (--deg[v] == 1) q.offer(v);
                }
            }
        }
        List<Integer> res = new ArrayList<>();
        while (!q.isEmpty()) res.add(q.poll());
        return res;
    }
}
```

复杂度：
- O(n)，每条边访问常数次；空间 O(n)。

思考小结：
- 树中心最多两个；层次剥叶是高效且直观的求法。

标签：拓扑、BFS、度数削减
