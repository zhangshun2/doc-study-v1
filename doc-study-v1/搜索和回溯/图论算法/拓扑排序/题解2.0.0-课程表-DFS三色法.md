## 标准化模型（DFS 三色法）

模型梳理
- 邻接表存出边：`[a, b]`表示`b → a`（先学 b 再学 a），每个桶存“后继节点”。
- 状态数组`state`：`0=未访问`，`1=进行中（栈内）`，`2=已完成（栈外）`。
- 外层遍历所有课程：对每个`state[u]==0`的课程执行`dfs(u)`。
- DFS入栈设`state[u]=1`，退出前必须设`state[u]=2`（关键）。

算法流程
- 遇到`state[u]==1`：回到递归栈内，存在环，返回`false`。
- 遇到`state[u]==2`：该节点已完成，剪枝返回`true`。
- 设为进行中后遍历所有后继`v`：只要`dfs(v)==false`，立即返回`false`。
- 遍历结束将`state[u]=2`，返回`true`；外层若任何`dfs(u)==false`则整体`false`。

伪代码模板（Java风格）
```java
// 构图（邻接表存出边：b -> a）
List<List<Integer>> table = new ArrayList<>(n);
for (int i = 0; i < n; i++) {
    table.add(new ArrayList<>());
}
for (int[] p : prerequisites) {
    table.get(p[1]).add(p[0]); // b -> a
}

int[] states = new int[n]; // 0=未访问, 1=进行中, 2=已完成

boolean dfs(int stateIndex) {
    if (states[stateIndex] == 1) return false; // 回到栈内 → 判环
    if (states[stateIndex] == 2) return true;  // 已完成 → 剪枝
    states[stateIndex] = 1;                    // 入栈：进行中
    for (int nextNode : table.get(stateIndex)) {
        if (!dfs(nextNode)) return false;
    }
    states[stateIndex] = 2;                    // 出栈：已完成（关键！）
    return true;
}

boolean canFinish(int n, int[][] prerequisites) {
    // ... 构图如上
    for (int stateIndex = 0; stateIndex < n; stateIndex++) {
        if (states[stateIndex] == 0 && !dfs(stateIndex)) return false;
    }
    return true;
}
```

复杂度
- 构图：`O(m)`（m为边数）。
- DFS整图：`O(n+m)`（每点每边至多访问一次）。
- 邻接表访问后继的代价为`O(出度)`，优于邻接矩阵的`O(n)`。

易错点 Checklist
- 构图方向写反：将`[a,b]`误作`a → b`；应为`b → a`。
- 忘记在 DFS 退出时设置`state[u]=2`，会误判环或导致重复遍历。
- 将“未处理（0）”误当作环的判定条件；正确判环条件是“遇到进行中（1）”。
- 邻接表遍历时误称“前置节点”，在课程表约定下应称“后继节点”。

快速记忆卡片
- 先构图为邻接表（出边：`b → a`）。
- 三色：`0/1/2`=未访问/进行中/已完成。
- 命中`1`判环，命中`2`剪枝。
- 入栈设`1`，出栈设`2`；有一个后继失败即失败。
- 外层对所有未访问节点启动 DFS；全通过返回`true`。

题解概述
- 使用 DFS 对有向图进行环检测，三色标记（0=未访问，1=访问中，2=访问完）。在递归过程中若遇到再次访问“访问中”的节点（回边），则存在环不可完成。

方便记忆的模板口诀
- 三色法：0 未访问 → 1 访问中 → 2 访问完；遇 1 即回边 → 有环 → false
- D-S-C：DFS（递归）→ State（三色）→ Cycle（回边判环）

Java 代码（DFS 三色标记）
```java
import java.util.*;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1) 建图（邻接表）
        List<List<Integer>> table = new ArrayList<>(numCourses);
        for (int i = 0; i < numCourses; i++) {
            table.add(new ArrayList<>());
        }
        for (int[] p : prerequisites) {
            table.get(p[1]).add(p[0]); // b -> a
        }
        // 2) 三色状态数组：0=未访问；1=访问中；2=访问完
        int[] states = new int[numCourses];
        // 3) 对每个节点执行 DFS，若发现环则不可完成
        for (int stateIndex = 0; stateIndex < numCourses; stateIndex++) {
            if (states[stateIndex] == 0 && !dfs(stateIndex, table, states)) return false;
        }
        return true;
    }

    private boolean dfs(int stateIndex, List<List<Integer>> table, int[] states) {
        states[stateIndex] = 1; // 进入：标记为访问中
        for (int nextNode : table.get(stateIndex)) {
            if (states[nextNode] == 1) return false; // 回到访问中 → 回边 → 有环
            if (states[nextNode] == 0 && !dfs(nextNode, table, states)) return false; // 未访问则继续 DFS
        }
        states[stateIndex] = 2; // 退出：标记为访问完
        return true;
    }
}
```
