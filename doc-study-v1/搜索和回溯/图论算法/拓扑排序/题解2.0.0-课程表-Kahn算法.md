题解概述
- 使用入度数组 + 邻接表 + 队列实现 Kahn 拓扑排序，逐步移除入度为 0 的课程并传播影响，最终处理数量是否等于课程总数决定是否可完成。

方便记忆的模板口诀
- 建图 → 入度 → 队列 → BFS → 计数 == numCourses
- I-Q-Q-C：Indegree（入度）→ Queue（队列）→ Queue loop（循环）→ Count（计数）

Java 代码（Kahn 拓扑排序）
```java
import java.util.*;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 1) 建图与入度
        List<List<Integer>> adj = new ArrayList<>();
        int[] indeg = new int[numCourses];
        for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());
        for (int[] p : prerequisites) {
            int a = p[0], b = p[1];
            adj.get(b).add(a);
            indeg[a]++;
        }
        // 2) 队列初始化（入度为 0 的课程）
        ArrayDeque<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.offer(i);
        // 3) BFS 拓扑过程
        int count = 0;
        while (!q.isEmpty()) {
            int u = q.poll();
            count++;
            for (int v : adj.get(u)) {
                if (--indeg[v] == 0) q.offer(v);
            }
        }
        // 4) 若处理完所有课程则可完成
        return count == numCourses;
    }
}
```

逐行注释（从上到下解释代码）
- import java.util.*; 引入常用集合类（ArrayList、ArrayDeque、List 等），便于建图与队列实现。
- class Solution { 定义题目要求的类名，在线判题环境会自动调用该类。
- public boolean canFinish(int numCourses, int[][] prerequisites) { 题目函数签名：numCourses 为课程总数，prerequisites 为先修关系数组。
- List<List<Integer>> adj = new ArrayList<>(); 创建邻接表（有向图），adj[u] 存储所有从 u 指向的后继课程 v。
- int[] indeg = new int[numCourses]; 创建入度数组，indeg[v] 表示课程 v 的前驱数量（需要先完成的课程数）。
- for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>()); 为每个课程初始化一条后继列表，保证所有课程都有桶位。
- for (int[] p : prerequisites) { 遍历先修关系，每个 p 是长度为 2 的数组。
- int a = p[0], b = p[1]; 取出依赖边 b -> a，学习 a 之前必须先学 b。
- adj.get(b).add(a); 在邻接表中添加边 b -> a，表示 b 的后继包含 a。
- indeg[a]++; 将 a 的入度（前驱数量）加一。
- ArrayDeque<Integer> q = new ArrayDeque<>(); 使用双端队列作为我们的 BFS 队列。
- for (int i = 0; i < numCourses; i++) if (indeg[i] == 0) q.offer(i); 将所有入度为 0 的课程入队，这些课程当前即可学习。
- int count = 0; 初始化计数器，记录我们已经“拓扑移除”的课程数量。
- while (!q.isEmpty()) { 循环处理队列直到为空。
- int u = q.poll(); 弹出一个当前可学习的课程 u（入度为 0）。
- count++; 处理课程 u，计数加一。
- for (int v : adj.get(u)) { 遍历 u 的所有后继课程 v（受 u 影响的课程）。
- if (--indeg[v] == 0) q.offer(v); 将 v 的入度减一；若降为 0，说明前驱都已满足，v 入队。
- return count == numCourses; 若最终处理的课程数等于课程总数，说明无环且可完成，否则有环不可完成。

测试建议（可自测样例）
- numCourses=2, prerequisites=[[1,0]] → true
- numCourses=2, prerequisites=[[1,0],[0,1]] → false
- numCourses=4, prerequisites=[[1,0],[2,1],[3,2]] → true

记忆关键点
- 有向图 + 入度数组 + 队列。
- 没有入度的先学，学完后把影响传给后继（入度减一）。
- 最后“学到的课程数”是否覆盖所有课程。
