# 问题1.0.0 课程表（LeetCode-207）

- 难度：中等
- 链接：https://leetcode.cn/problems/course-schedule/

## 概述
给定 `numCourses` 与若干先修关系 `prerequisites`，判断是否可以完成所有课程（即图中是否存在环）。

## 问题特征与分析引导
- 拓扑结构：有向图，判断是否存在环。
- 两大方法：Kahn 算法（BFS 入度为 0）与 DFS 递归检测环（颜色标记）。

## 可能涉及的知识点
- 拓扑排序与入度管理
- DFS 颜色法（0/1/2：未访问/访问中/已访问）
- 图的构建与连通分量处理
