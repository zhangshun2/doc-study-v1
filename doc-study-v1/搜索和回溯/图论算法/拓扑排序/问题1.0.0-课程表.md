# 问题1.0.0-课程表（Course Schedule 207）

问题概述
- 给定课程总数 numCourses（课程编号为 0..numCourses-1）以及若干先修关系 prerequisites，其中每个关系 [a, b] 表示要学习课程 a 必须先完成课程 b。请判断是否可以完成所有课程，即是否存在一种学习顺序满足所有先修要求。

题目特征获取（如何从题意抽取可解信息）
- 结构抽象：课程与依赖可抽象为“有向图”，顶点是课程，边 b -> a 表示 b 是 a 的先修课。
- 核心判断：能否完成所有课程 ⇔ 图是否“无环”（DAG）。存在环意味着互相依赖造成“死锁”，无法完成。
- 可解路径：若图是 DAG，则存在拓扑排序序列（拓扑序是满足先修关系的线性序）。

引导思路（从直觉到算法）
1) 图建模：
   - 使用邻接表表示图结构：graph[b] 中存储所有依赖 b 的课程 a。
   - 同时维护每个课程的入度 indegree[a]：有多少先修课程指向 a。
2) 两种经典判环/拓扑方案：
   - 方案 A：Kahn 算法（BFS 拓扑排序）
     - 入度为 0 的课程优先学习；学习后把它对后继课程的影响（入度减 1）传递；若最终处理的课程数 == numCourses，则无环；否则有环。
   - 方案 B：DFS 三色标记（递归判环）
     - 对每个课程进行 DFS，使用状态 0/1/2（未访问/访问中/访问完）标记；在“访问中”再次进入同一节点，说明存在环；整个 DFS 无“回到访问中”的情况则无环。
3) 选择建议：
   - 若需要构造一个合法学习序列（拓扑序），用 Kahn 更直接。
   - 若只判环或图较稀疏、递归更符合实现习惯，可用 DFS 三色法。

可能涉及的知识点（分主题梳理）
- 图的表示：邻接表、入度数组、边的有向性质。
- 拓扑排序：Kahn 算法与 DFS 拓扑。
- 有向图环检测：访问中回边（back-edge）即环。
- 队列与递归栈：Kahn 使用队列；DFS 使用递归栈/显式栈。
- 复杂度：构图与遍历通常为 O(V+E)，空间为 O(V+E)。

边界与异常情况（务必在实现前明确）
- prerequisites 为空：必然可以完成，结果为 true。
- numCourses=0：按题意通常不出现，若出现可视为 trivially true（无课可学）。
- 自环依赖 [a, a]：立即判为不可完成。
- 重复依赖边：构图时可能导致入度叠加；可按题意保留或去重（通常保留不会影响正确性）。
- 离散课程：图不一定连通，需覆盖所有课程顶点。

与专题的关系（归档位置）
- 本题属于“搜索和回溯/图论算法/拓扑排序”范畴，核心是判环与拓扑序是否存在。

思考题与扩展练习（加深理解）
- 扩展一：LeetCode 210 课程表 II（要求输出可行的学习顺序）。
- 扩展二：给定任意有向图，判定是否是 DAG（与本题等价）。
- 扩展三：若需要选择任意一组课程使其互不冲突（无依赖环），如何处理？

实现前的检查清单（自检指南）
- 邻接表与入度是否正确构建？
- Kahn：初始队列是否只包含入度为 0 的课程？每弹出一次是否正确减少后继入度？
- DFS：三色标记是否在进入与退出节点时正确更新？是否防止重复扫描（visited）？
- 全覆盖：是否处理所有课程编号，即使它们没有出入边？
