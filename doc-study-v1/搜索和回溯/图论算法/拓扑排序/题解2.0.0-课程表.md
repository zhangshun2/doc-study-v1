# 题解2.0.0-课程表（拓扑排序与环检测）

题解概述
- 将课程与先修关系抽象为有向图，判断是否存在环：无环则可以完成所有课程（存在拓扑序）；有环则不可完成。
- 提供两种经典解法：
  - 方法一：Kahn 算法（BFS 拓扑排序）
  - 方法二：DFS 三色标记（递归判环）

方法一：Kahn 算法（BFS 拓扑排序）
- 思路要点：
  1) 统计每个课程的入度 indegree。
  2) 将所有入度为 0 的课程入队（先学它们）。
  3) 不断出队课程 u，并对 u 的所有后继 v 执行入度减一；若 v 的入度降为 0，则入队。
  4) 最终被出队的课程数量 count 若等于 numCourses，说明无环；否则有环。
- 正确性直觉：
  - 若有环，则环内所有节点的入度都至少为 1（彼此相互依赖），无法进入队列，导致 count < numCourses。
  - 若无环，必然逐步存在入度为 0 的节点可被移除并传播影响，最终处理完所有节点。
- 复杂度：
  - 时间 O(V+E)：构图与每条边的入度转移仅常数开销。
  - 空间 O(V+E)：邻接表与队列。
- 伪代码：
  - 构图与入度：
    - for each [a, b] in prerequisites: add edge b->a; indegree[a]++
  - 初始化队列：
    - queue = { all nodes with indegree == 0 }
  - BFS 主循环：
    - while queue not empty:
      - u = queue.pop()
      - count++
      - for v in adj[u]:
        - indegree[v]--
        - if indegree[v] == 0: queue.push(v)
  - 返回 count == numCourses

方法二：DFS 三色标记（递归判环）
- 思路要点：
  1) 使用状态数组 state：0=未访问，1=访问中，2=访问完。
  2) 对每个节点执行 dfs(u)：
     - 标记为访问中 state[u]=1
     - 遍历所有后继 v：
       - 若 state[v]==1，则遇到回边（环）⇒ false
       - 若 state[v]==0，继续 dfs(v)；若返回 false ⇒ false
     - 完成后标记访问完 state[u]=2 ⇒ true
  3) 只要任一 dfs 返回 false，则存在环；全部返回 true ⇒ 无环。
- 正确性直觉：
  - 在 DFS 栈上再次访问“访问中”的节点即遇到回边，形成环。
- 复杂度：
  - 时间 O(V+E)：每个节点与边最多访问一次。
  - 空间 O(V+E)：邻接表与递归栈。
- 伪代码：
  - for u in 0..numCourses-1:
    - if state[u]==0 and dfs(u)==false: return false
  - return true

实现注意事项（避免踩坑）
- 图建模：
  - 邻接表需覆盖所有课程编号，即使某些课程没有出边。
  - 若存在重复边，Kahn 会导致 indegree 计数更大，但不影响正确性；如需精细控制可去重。
- 边界处理：
  - prerequisites 为空 ⇒ 直接返回 true。
  - 自环 [a,a] ⇒ 直接返回 false。
- 可靠性：
  - Kahn 中队列初始化必须只包含入度为 0 的课程。
  - DFS 中 state 标记的设置与恢复要严格按“进入=1、退出=2”进行。

单测样例设计（覆盖典型场景）
- 基本可完成：numCourses=2, prerequisites=[[1,0]] ⇒ true
- 基本不可完成（环）：numCourses=2, prerequisites=[[1,0],[0,1]] ⇒ false
- 多链叠加：numCourses=4, prerequisites=[[1,0],[2,1],[3,2]] ⇒ true
- 自环：numCourses=1, prerequisites=[[0,0]] ⇒ false
- 离散与重复边：numCourses=3, prerequisites=[[1,0],[1,0]] ⇒ true

方法选择建议（何时用哪种）
- 若需要输出学习顺序：优先使用 Kahn（同时构造拓扑序）。
- 若只判环且图较稀疏、递归自然：DFS 三色法更为简洁。

复杂度与可扩展性总结
- 两法均为 O(V+E) 时间与 O(V+E) 空间，具有良好扩展性，适合大规模课程依赖。

结论
- 本题的本质是“有向图环检测 ⇔ 拓扑序存在”。任取 Kahn 或 DFS 三色标记即可高效解决，依据需求选择具体实现形式。
