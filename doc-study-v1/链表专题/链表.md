## 技巧1 快慢指针 
> 常用于 环形链表 ,找中点.找到符合整个长度百分比的某个长度,比如找中点,找二分之类的
>



可以通过slow和fast两个节点做处理

在方法内的赋值逻辑全部被默认为空间复杂度O(1)

所以可以放心写



slow找下一个,fast找下一个的下一个

因为slow肯定会走到终点



且fast走的始终比slow快一倍

所以在slow走到终点之前,fast已经开始走第二遍了,所以fast的next从环结束的地方在重新走一遍环

肯定会追上较慢的节点

### 注意点 节点和节点val
如果没有重复的数值,才可以单独针对val去比对

如果值可能重复,比较环的时候就要比较节点本身了.这样比对的就是对应的内存节点





## 技巧2: 翻转链表


可以用来比对中位数等等



[206. 反转链表 - 力扣（LeetCode）](https://leetcode.cn/problems/reverse-linked-list/submissions/659577944/)



先存储后续节点

然后把当前节点的next的指针指向当前节点,这样指向就翻转了

这时候head节点就是新的cur节点,重新赋值cur节点.cur节点用来存储翻转指向之后的新链表的位置

然后这时候需要循环处理后续节点 , next节点赋值给head继续循环就好了

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode cur = null;
        while(head != null){
            ListNode next  = head.next;
            head.next = cur;
            cur = head;
            head = next;
        }
        return cur;
    }
}
```



## 技巧3: 临时节点


可以初始化一个新的节点,最后通过输出新节点的next来组装

所有的值也拼接在这个新节点的next上



这样遇到可以初始化在新的链表上的

或者说是可以在栈内挪动对应的链表节点的位置的,就可以写





## 技巧4: 成环思想


判断链表是否相交



比如链表a长度x.链表b长度y

两个如果相交

如果完全长度相同,则直接遍历就能判断是否有相交节点



如果长度不同

那么假设ab都是环

且二者环的长度都是a+b

则在环的遍历过程中,一定会找到对应的相交节点

[160. 相交链表 - 力扣（LeetCode）](https://leetcode.cn/problems/intersection-of-two-linked-lists/)





注意区分a和headA,这种临时节点和原先节点

这是如果不想交的话,也不会死循环的关键;

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if(headA == null || headB == null){
            return null;
        }
        ListNode a = headA,b = headB;
        while(a != b){
            a = (a==null ? headB : a.next);
            b = (b == null ? headA : b.next);
        }

        return a;
    }
}
```

## 回文链表
[234. 回文链表 - 力扣（LeetCode）](https://leetcode.cn/problems/palindrome-linked-list/)

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public boolean isPalindrome(ListNode head) {
        
        if(head.next == null){
            return true;
        }
        if(head.next.next == null){
            return head.val == head.next.val;
        }

        ListNode center = getCenter(head);
        ListNode after = reverse(center.next);
        ListNode c1 = head,c2 = after;
        boolean res = true;
        while(res && c2!=null){
            if(c1.val != c2.val){
                return false;
            }
            c1 = c1.next;
            c2 = c2.next;
        }
        center.next = reverse(after);
        return res;
    }

    public ListNode getCenter(ListNode head){
        ListNode s = head, f= head;
        while(f.next != null && f.next.next != null){
            s = s.next;
            f = f.next.next;
        }
        return s;
    }

    public ListNode reverse(ListNode head){
        ListNode cur = null;
        ListNode temp = head;
        while(temp != null){
            ListNode next = temp.next;
            temp.next = cur;
            cur = temp;
            temp = next;
        }
        return cur;
    }

    
}
```

## 两数相加


需要考虑的东西

技巧3的临时节点, 后续节点.next关系式依赖于临时节点是处理的

余数ys的概念

因为两数之和,最小是0+0,最大是9+9

所以val+val的和>=10 , ys=1 ,和=和-10;

否则正常累计,ys=0;

同样的存在一个遍历终点问题



a和b不一定等长

所以这里需要遍历到最长的一端.





可以总结一些题型上的方法论了



1. 查看条件,确认必定生效的条件,减少遍历次数
2. 但凡设计到后续节点.一定会通过技巧3临时节点去找后续
3. 简单题本身就是技巧,比如翻转链表和涉及到快门指针的
4. 需要确认链条的遍历长度
5. 细节确认,尽可能不修改原先链的结构,反正怎么赋值栈内都是O(1)的时间复杂度,处理完链条尽可能的去还原

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode cur = new ListNode(-1);
        ListNode c1 = l1,c2 = l2;
        ListNode temp = cur;
        int ys = 0;
        while(c1 != null || c2!=null){
            int res = ys + (c1==null ?0:c1.val)+(c2==null?0:c2.val);
            ys = res>=10 ? 1 : 0;
            res = res>=10 ? res-10:res;
            temp.next = new ListNode(res);
            temp = temp.next;
            c1 = c1 == null ? null :c1.next;
            c2 = c2 == null ? null : c2.next;
        }

        if(ys > 0){
            temp.next = new ListNode(ys);
        }
        return cur.next;
    }
}
```
