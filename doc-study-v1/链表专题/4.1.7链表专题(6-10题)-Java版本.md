## 1️⃣ K 个一组翻转链表 (LeetCode 25)
### 📝 题目描述
给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

**示例 1：**

```plain
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

**示例 2：**

```plain
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

### 🔧 基础解法：迭代 + 分组翻转
```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null || k == 1) {
            return head;
        }
        
        // 检查是否有足够的节点进行翻转
        ListNode current = head;
        int count = 0;
        while (current != null && count < k) {
            current = current.next;
            count++;
        }
        
        // 如果有k个节点，则进行翻转
        if (count == k) {
            // 翻转前k个节点
            current = reverseKGroup(current, k);
            
            // 翻转当前k个节点
            while (count > 0) {
                ListNode temp = head.next;
                head.next = current;
                current = head;
                head = temp;
                count--;
            }
            head = current;
        }
        
        return head;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，其中n是链表长度
+ 空间复杂度：O(n/k)，递归调用栈的深度

### 🚀 进阶解法：迭代 + 辅助函数
```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        
        ListNode prevGroupEnd = dummy;
        
        while (true) {
            // 检查剩余节点是否足够k个
            ListNode kthNode = getKthNode(prevGroupEnd, k);
            if (kthNode == null) {
                break;
            }
            
            ListNode nextGroupStart = kthNode.next;
            
            // 翻转当前组
            ListNode[] reversed = reverseGroup(prevGroupEnd.next, kthNode);
            ListNode groupStart = reversed[0];
            ListNode groupEnd = reversed[1];
            
            // 连接翻转后的组
            prevGroupEnd.next = groupStart;
            groupEnd.next = nextGroupStart;
            
            // 更新prevGroupEnd为下一轮的准备
            prevGroupEnd = groupEnd;
        }
        
        return dummy.next;
    }
    
    // 获取从start开始的第k个节点
    private ListNode getKthNode(ListNode start, int k) {
        while (start != null && k > 0) {
            start = start.next;
            k--;
        }
        return start;
    }
    
    // 翻转从start到end的链表段
    private ListNode[] reverseGroup(ListNode start, ListNode end) {
        ListNode prev = end.next;
        ListNode current = start;
        
        while (prev != end) {
            ListNode next = current.next;
            current.next = prev;
            prev = current;
            current = next;
        }
        
        return new ListNode[]{end, start};
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

**解题思路：**

1. 分组处理：每k个节点为一组
2. 检查剩余节点数量，不足k个则保持原序
3. 翻转每一组，并正确连接前后组
4. 使用辅助函数提高代码可读性

## 2️⃣ 旋转链表 (LeetCode 61)
### 📝 题目描述
给你一个链表的头节点 `head`，旋转链表，将链表每个节点向右移动 `k` 个位置。

**示例 1：**

```plain
输入：head = [1,2,3,4,5], k = 2
输出：[4,5,1,2,3]
```

**示例 2：**

```plain
输入：head = [0,1,2], k = 4
输出：[2,0,1]
```

### 🔧 基础解法：找到旋转点
```java
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) {
            return head;
        }
        
        // 计算链表长度并找到尾节点
        ListNode tail = head;
        int length = 1;
        while (tail.next != null) {
            tail = tail.next;
            length++;
        }
        
        // 计算实际需要旋转的步数
        k = k % length;
        if (k == 0) {
            return head;
        }
        
        // 找到新的尾节点（倒数第k+1个节点）
        ListNode newTail = head;
        for (int i = 0; i < length - k - 1; i++) {
            newTail = newTail.next;
        }
        
        // 新的头节点
        ListNode newHead = newTail.next;
        
        // 断开连接
        newTail.next = null;
        
        // 连接原尾节点到原头节点
        tail.next = head;
        
        return newHead;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，其中n是链表长度
+ 空间复杂度：O(1)

### 🚀 进阶解法：环形链表
```java
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) {
            return head;
        }
        
        // 计算链表长度并形成环
        ListNode tail = head;
        int length = 1;
        while (tail.next != null) {
            tail = tail.next;
            length++;
        }
        tail.next = head;  // 形成环
        
        // 计算实际旋转步数
        k = k % length;
        
        // 找到新的尾节点位置
        int stepsToNewTail = length - k;
        ListNode newTail = head;
        for (int i = 1; i < stepsToNewTail; i++) {
            newTail = newTail.next;
        }
        
        // 新的头节点
        ListNode newHead = newTail.next;
        
        // 断开环
        newTail.next = null;
        
        return newHead;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

**解题思路：**

1. 计算链表长度，处理k大于链表长度的情况
2. 找到旋转的分割点：倒数第k+1个节点
3. 重新连接链表：新尾节点断开，原尾节点连接原头节点

## 3️⃣ 删除排序链表中的重复元素 II (LeetCode 82)
### 📝 题目描述
给定一个已排序的链表的头 `head`，删除原始链表中所有重复数字的节点，只留下不同数字的节点。返回已排序的链表。

**示例 1：**

```plain
输入：head = [1,2,3,3,4,4,5]
输出：[1,2,5]
```

**示例 2：**

```plain
输入：head = [1,1,1,2,3]
输出：[2,3]
```

### 🔧 基础解法：双指针
```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        
        ListNode prev = dummy;
        ListNode current = head;
        
        while (current != null) {
            // 检查是否有重复
            if (current.next != null && current.val == current.next.val) {
                int duplicateVal = current.val;
                
                // 跳过所有重复的节点
                while (current != null && current.val == duplicateVal) {
                    current = current.next;
                }
                
                // 连接prev到current（跳过了所有重复节点）
                prev.next = current;
            } else {
                // 没有重复，正常移动
                prev = current;
                current = current.next;
            }
        }
        
        return dummy.next;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，其中n是链表长度
+ 空间复杂度：O(1)

### 🚀 进阶解法：递归
```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        
        if (head.val == head.next.val) {
            // 当前节点有重复，跳过所有重复节点
            int duplicateVal = head.val;
            while (head != null && head.val == duplicateVal) {
                head = head.next;
            }
            // 递归处理剩余部分
            return deleteDuplicates(head);
        } else {
            // 当前节点无重复，保留并递归处理后续
            head.next = deleteDuplicates(head.next);
            return head;
        }
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(n)，递归调用栈

**解题思路：**

1. 使用虚拟头节点简化边界处理
2. 遇到重复元素时，跳过所有相同值的节点
3. 保持prev指针指向最后一个确定保留的节点

## 4️⃣ 删除排序链表中的重复元素 (LeetCode 83)
### 📝 题目描述
给定一个已排序的链表的头 `head`，删除所有重复的元素，使每个元素只出现一次。返回已排序的链表。

**示例 1：**

```plain
输入：head = [1,1,2]
输出：[1,2]
```

**示例 2：**

```plain
输入：head = [1,1,2,3,3]
输出：[1,2,3]
```

### 🔧 基础解法：迭代
```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null) {
            return head;
        }
        
        ListNode current = head;
        
        while (current.next != null) {
            if (current.val == current.next.val) {
                // 删除重复节点
                current.next = current.next.next;
            } else {
                // 移动到下一个节点
                current = current.next;
            }
        }
        
        return head;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，其中n是链表长度
+ 空间复杂度：O(1)

### 🚀 进阶解法：递归
```java
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        
        if (head.val == head.next.val) {
            // 跳过重复节点，继续递归
            return deleteDuplicates(head.next);
        } else {
            // 保留当前节点，递归处理后续
            head.next = deleteDuplicates(head.next);
            return head;
        }
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(n)，递归调用栈

**解题思路：**

1. 遍历链表，比较相邻节点的值
2. 如果相同则删除后一个节点
3. 如果不同则移动到下一个节点
4. 注意与LeetCode 82的区别：这里保留一个重复元素

## 5️⃣ 分隔链表 (LeetCode 86)
### 📝 题目描述
给你一个链表的头节点 `head` 和一个特定值 `x`，请你对链表进行分隔，使得所有小于 `x` 的节点都出现在大于或等于 `x` 的节点之前。

你应当保留两个分区中每个节点的初始相对位置。

**示例 1：**

```plain
输入：head = [1,4,3,2,5,2], x = 3
输出：[1,2,2,4,3,5]
```

**示例 2：**

```plain
输入：head = [2,1], x = 2
输出：[1,2]
```

### 🔧 基础解法：双链表
```java
class Solution {
    public ListNode partition(ListNode head, int x) {
        // 创建两个虚拟头节点
        ListNode smallDummy = new ListNode(0);
        ListNode largeDummy = new ListNode(0);
        
        ListNode small = smallDummy;
        ListNode large = largeDummy;
        
        // 遍历原链表，分别连接到两个链表
        while (head != null) {
            if (head.val < x) {
                small.next = head;
                small = small.next;
            } else {
                large.next = head;
                large = large.next;
            }
            head = head.next;
        }
        
        // 连接两个链表
        large.next = null;  // 避免环
        small.next = largeDummy.next;
        
        return smallDummy.next;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，其中n是链表长度
+ 空间复杂度：O(1)

### 🚀 进阶解法：原地分隔
```java
class Solution {
    public ListNode partition(ListNode head, int x) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        
        ListNode prev = dummy;
        ListNode current = head;
        
        // 找到第一个大于等于x的节点
        while (current != null && current.val < x) {
            prev = current;
            current = current.next;
        }
        
        // current现在指向第一个>=x的节点
        ListNode largeStart = prev;
        
        while (current != null) {
            if (current.val < x) {
                // 将小于x的节点移到前面
                prev.next = current.next;
                current.next = largeStart.next;
                largeStart.next = current;
                largeStart = current;
                current = prev.next;
            } else {
                prev = current;
                current = current.next;
            }
        }
        
        return dummy.next;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

**解题思路：**

1. 双链表方法：分别维护小于x和大于等于x的两个链表
2. 遍历原链表，根据节点值分别连接到对应链表
3. 最后将两个链表连接起来
4. 注意避免形成环

## 📚 总结
### 🎯 核心知识点
1. **分组处理**：K个一组的翻转操作
2. **环形链表**：临时形成环简化操作
3. **重复元素处理**：区分删除所有重复vs保留一个
4. **双链表技巧**：分离后重新组合
5. **边界条件**：空链表、单节点等特殊情况

### 💡 解题模式
+ **分组翻转**：递归或迭代处理每k个节点
+ **旋转操作**：找到分割点，重新连接
+ **去重操作**：根据要求选择保留策略
+ **分隔操作**：双链表分别收集，最后合并
+ **指针操作**：prev、current、next三指针协作

### 🔄 刷题建议
1. **掌握翻转技巧**：单个翻转、分组翻转、部分翻转
2. **理解双指针应用**：快慢指针、前后指针
3. **熟练处理边界**：空链表、单节点、特殊k值
4. **练习递归思维**：分解子问题，合并结果
5. **注意内存管理**：避免内存泄漏和环形引用
