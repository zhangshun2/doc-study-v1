## 1️⃣ 两数相加 (LeetCode 2)
### 📝 题目描述
给你两个非空的链表，表示两个非负的整数。它们每位数字都是按照逆序的方式存储的，并且每个节点只能存储一位数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

**示例 1：**

```plain
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
解释：342 + 465 = 807.
```

**示例 2：**

```plain
输入：l1 = [0], l2 = [0]
输出：[0]
```

### 🔧 基础解法：模拟加法过程
```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;
        int carry = 0;
        
        while (l1 != null || l2 != null || carry != 0) {
            int sum = carry;
            
            if (l1 != null) {
                sum += l1.val;
                l1 = l1.next;
            }
            
            if (l2 != null) {
                sum += l2.val;
                l2 = l2.next;
            }
            
            carry = sum / 10;
            current.next = new ListNode(sum % 10);
            current = current.next;
        }
        
        return dummy.next;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(max(m, n))，其中m和n分别是两个链表的长度
+ 空间复杂度：O(max(m, n))，新链表的长度最多为较长链表长度+1

### 🚀 进阶解法：递归实现
```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        return addTwoNumbers(l1, l2, 0);
    }
    
    private ListNode addTwoNumbers(ListNode l1, ListNode l2, int carry) {
        // 递归终止条件
        if (l1 == null && l2 == null && carry == 0) {
            return null;
        }
        
        int sum = carry;
        
        if (l1 != null) {
            sum += l1.val;
            l1 = l1.next;
        }
        
        if (l2 != null) {
            sum += l2.val;
            l2 = l2.next;
        }
        
        ListNode result = new ListNode(sum % 10);
        result.next = addTwoNumbers(l1, l2, sum / 10);
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(max(m, n))
+ 空间复杂度：O(max(m, n))，递归调用栈的深度

**解题思路：**

1. 模拟手工加法过程，从低位到高位逐位相加
2. 维护进位carry，处理不同长度的链表
3. 使用虚拟头节点简化边界处理

## 2️⃣ 删除链表的倒数第 N 个结点 (LeetCode 19)
### 📝 题目描述
给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**

```plain
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**示例 2：**

```plain
输入：head = [1], n = 1
输出：[]
```

### 🔧 基础解法：两次遍历
```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        // 第一次遍历：计算链表长度
        int length = 0;
        ListNode current = head;
        while (current != null) {
            length++;
            current = current.next;
        }
        
        // 计算要删除的节点位置（从前往后数）
        int targetIndex = length - n;
        
        // 如果要删除头节点
        if (targetIndex == 0) {
            return head.next;
        }
        
        // 第二次遍历：找到要删除节点的前一个节点
        current = head;
        for (int i = 0; i < targetIndex - 1; i++) {
            current = current.next;
        }
        
        // 删除节点
        current.next = current.next.next;
        
        return head;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(L)，其中L是链表长度，需要遍历两次
+ 空间复杂度：O(1)

### 🚀 进阶解法：双指针一次遍历
```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        
        ListNode fast = dummy;
        ListNode slow = dummy;
        
        // fast指针先走n+1步
        for (int i = 0; i <= n; i++) {
            fast = fast.next;
        }
        
        // fast和slow同时移动，直到fast到达末尾
        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }
        
        // 此时slow指向要删除节点的前一个节点
        slow.next = slow.next.next;
        
        return dummy.next;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(L)，只需要一次遍历
+ 空间复杂度：O(1)

**解题思路：**

1. 使用快慢双指针，快指针先走n+1步
2. 然后快慢指针同时移动，当快指针到达末尾时
3. 慢指针正好指向要删除节点的前一个节点
4. 使用虚拟头节点处理删除头节点的边界情况

## 3️⃣ 合并两个有序链表 (LeetCode 21)
### 📝 题目描述
将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**示例 1：**

```plain
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

**示例 2：**

```plain
输入：l1 = [], l2 = []
输出：[]
```

### 🔧 基础解法：迭代
```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;
        
        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                current.next = list1;
                list1 = list1.next;
            } else {
                current.next = list2;
                list2 = list2.next;
            }
            current = current.next;
        }
        
        // 连接剩余的节点
        if (list1 != null) {
            current.next = list1;
        } else {
            current.next = list2;
        }
        
        return dummy.next;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(m + n)，其中m和n分别是两个链表的长度
+ 空间复杂度：O(1)

### 🚀 进阶解法：递归
```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        // 递归终止条件
        if (list1 == null) {
            return list2;
        }
        if (list2 == null) {
            return list1;
        }
        
        // 递归合并
        if (list1.val <= list2.val) {
            list1.next = mergeTwoLists(list1.next, list2);
            return list1;
        } else {
            list2.next = mergeTwoLists(list1, list2.next);
            return list2;
        }
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(m + n)
+ 空间复杂度：O(m + n)，递归调用栈的深度

**解题思路：**

1. 比较两个链表头节点的值，选择较小的作为结果链表的下一个节点
2. 递归处理剩余部分，或迭代处理直到一个链表为空
3. 将非空链表的剩余部分直接连接到结果链表末尾

## 4️⃣ 合并K个升序链表 (LeetCode 23)
### 📝 题目描述
给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

**示例 1：**

```plain
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到：
1->1->2->3->4->4->5->6
```

### 🔧 基础解法：逐一合并
```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) {
            return null;
        }
        
        ListNode result = lists[0];
        
        for (int i = 1; i < lists.length; i++) {
            result = mergeTwoLists(result, lists[i]);
        }
        
        return result;
    }
    
    private ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode current = dummy;
        
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) {
                current.next = l1;
                l1 = l1.next;
            } else {
                current.next = l2;
                l2 = l2.next;
            }
            current = current.next;
        }
        
        current.next = (l1 != null) ? l1 : l2;
        
        return dummy.next;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(kN)，其中k是链表个数，N是所有链表中节点总数
+ 空间复杂度：O(1)

### 🚀 进阶解法：分治合并
```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) {
            return null;
        }
        
        return mergeKLists(lists, 0, lists.length - 1);
    }
    
    private ListNode mergeKLists(ListNode[] lists, int left, int right) {
        if (left == right) {
            return lists[left];
        }
        
        if (left > right) {
            return null;
        }
        
        int mid = left + (right - left) / 2;
        
        ListNode leftList = mergeKLists(lists, left, mid);
        ListNode rightList = mergeKLists(lists, mid + 1, right);
        
        return mergeTwoLists(leftList, rightList);
    }
    
    private ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        if (l1 == null) return l2;
        if (l2 == null) return l1;
        
        if (l1.val <= l2.val) {
            l1.next = mergeTwoLists(l1.next, l2);
            return l1;
        } else {
            l2.next = mergeTwoLists(l1, l2.next);
            return l2;
        }
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(N log k)，其中k是链表个数，N是所有节点总数
+ 空间复杂度：O(log k)，递归调用栈的深度

**解题思路：**

1. 使用分治思想，将k个链表分成两半
2. 递归合并左半部分和右半部分
3. 最后合并两个已排序的链表
4. 时间复杂度从O(kN)优化到O(N log k)

## 5️⃣ 两两交换链表中的节点 (LeetCode 24)
### 📝 题目描述
给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**示例 1：**

```plain
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

**示例 2：**

```plain
输入：head = []
输出：[]
```

### 🔧 基础解法：迭代
```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;
        
        while (prev.next != null && prev.next.next != null) {
            // 需要交换的两个节点
            ListNode first = prev.next;
            ListNode second = prev.next.next;
            
            // 执行交换
            prev.next = second;
            first.next = second.next;
            second.next = first;
            
            // 移动prev指针
            prev = first;
        }
        
        return dummy.next;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，其中n是链表长度
+ 空间复杂度：O(1)

### 🚀 进阶解法：递归
```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        // 递归终止条件：节点数少于2个
        if (head == null || head.next == null) {
            return head;
        }
        
        // 保存第二个节点
        ListNode second = head.next;
        
        // 递归处理剩余部分
        head.next = swapPairs(second.next);
        
        // 交换前两个节点
        second.next = head;
        
        // 返回新的头节点（原来的第二个节点）
        return second;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(n)，递归调用栈的深度

**解题思路：**

1. 迭代方法：使用三个指针prev、first、second进行交换
2. 递归方法：先递归处理后面的部分，再交换前两个节点
3. 关键是正确处理指针的重新连接

1. **虚拟头节点**：简化边界条件处理
2. **双指针技巧**：快慢指针、前后指针的应用
3. **递归思想**：将复杂问题分解为子问题
4. **分治算法**：优化时间复杂度的重要手段
5. **指针操作**：链表节点的增删改查

### 💡 解题模式
+ **加法模拟**：逐位处理，注意进位
+ **倒数第N个**：双指针一次遍历
+ **合并链表**：比较节点值，递归或迭代
+ **分治合并**：减少重复计算，优化复杂度
+ **节点交换**：正确处理指针重连

### 🔄 刷题建议
1. **掌握基本操作**：链表的遍历、插入、删除
2. **熟练使用虚拟头节点**：简化边界处理
3. **理解双指针技巧**：快慢指针的各种应用
4. **练习递归思维**：分解问题，找到递归关系
