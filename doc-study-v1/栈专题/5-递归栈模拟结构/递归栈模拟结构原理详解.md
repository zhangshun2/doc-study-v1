# 递归栈模拟结构原理详解
## 📚 递归栈模拟的基本概念
### 什么是递归栈模拟？
递归栈模拟（Recursive Stack Simulation）是指**使用显式栈来模拟递归调用过程**的技术。它将递归算法转换为迭代算法，避免了系统调用栈的限制。

### 为什么需要递归栈模拟？
```plain
递归 vs 栈模拟对比：

递归方式：                    栈模拟方式：
系统调用栈                    显式栈结构
┌─────────────┐              ┌─────────────┐
│ factorial(3)│              │ State(3)    │
├─────────────┤              ├─────────────┤
│ factorial(2)│              │ State(2)    │
├─────────────┤              ├─────────────┤
│ factorial(1)│              │ State(1)    │
├─────────────┤              ├─────────────┤
│ factorial(0)│              │ State(0)    │
└─────────────┘              └─────────────┘

优势：                        优势：
- 代码简洁                    - 避免栈溢出
- 逻辑清晰                    - 内存可控
                             - 可中断恢复
                             - 便于调试
```

### 核心转换思想
1. **状态保存**：将递归调用的参数和局部变量保存到栈中
2. **控制流模拟**：使用循环和状态机模拟递归的调用和返回
3. **结果传递**：通过栈在不同层级间传递计算结果

**栈模拟版本：**

```java
/**
 * 阶乘计算的栈模拟实现
 */
public class FactorialStackSimulation {
    
    public long factorial(int n) {
        if (n <= 1) return 1;
        
        Deque<FactorialState> stack = new ArrayDeque<>();
        stack.push(new FactorialState(n, FactorialState.Phase.ENTER));
        
        long result = 1;
        
        while (!stack.isEmpty()) {
            FactorialState current = stack.peek();
            
            switch (current.phase) {
                case ENTER:
                    if (current.n <= 1) {
                        current.result = 1;
                        current.phase = FactorialState.Phase.RETURN;
                    } else {
                        current.phase = FactorialState.Phase.PROCESS;
                        // 模拟递归调用 factorial(n-1)
                        stack.push(new FactorialState(current.n - 1, 
                                                    FactorialState.Phase.ENTER));
                    }
                    break;
                    
                case PROCESS:
                    // 这个阶段在子调用返回后执行
                    current.phase = FactorialState.Phase.RETURN;
                    break;
                    
                case RETURN:
                    FactorialState state = stack.pop();
                    if (!stack.isEmpty()) {
                        // 将结果传递给父调用
                        FactorialState parent = stack.peek();
                        if (parent.phase == FactorialState.Phase.PROCESS) {
                            parent.result = parent.n * state.result;
                        }
                    } else {
                        // 最终结果
                        result = state.result;
                    }
                    break;
            }
        }
        
        return result;
    }
    
    static class FactorialState {
        enum Phase { ENTER, PROCESS, RETURN }
        
        int n;
        Phase phase;
        long result;
        
        FactorialState(int n, Phase phase) {
            this.n = n;
            this.phase = phase;
        }
    }
}
```

```java
/**
 * 二叉树中序遍历的栈模拟
 */
public class TreeTraversalStackSimulation {
    
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;
        
        Deque<TraversalState> stack = new ArrayDeque<>();
        stack.push(new TraversalState(root, TraversalState.Phase.ENTER));
        
        while (!stack.isEmpty()) {
            TraversalState current = stack.peek();
            
            switch (current.phase) {
                case ENTER:
                    if (current.node == null) {
                        stack.pop();
                    } else {
                        current.phase = TraversalState.Phase.LEFT;
                        // 模拟递归调用左子树
                        stack.push(new TraversalState(current.node.left, 
                                                    TraversalState.Phase.ENTER));
                    }
                    break;
                    
                case LEFT:
                    // 左子树处理完毕，访问当前节点
                    result.add(current.node.val);
                    current.phase = TraversalState.Phase.RIGHT;
                    // 模拟递归调用右子树
                    stack.push(new TraversalState(current.node.right, 
                                                TraversalState.Phase.ENTER));
                    break;
                    
                case RIGHT:
                    // 右子树处理完毕，当前节点处理完成
                    stack.pop();
                    break;
            }
        }
        
        return result;
    }
    
    static class TraversalState {
        enum Phase { ENTER, LEFT, RIGHT }
        
        TreeNode node;
        Phase phase;
        
        TraversalState(TreeNode node, Phase phase) {
            this.node = node;
            this.phase = phase;
        }
    }
    
    static class TreeNode {
        int val;
        TreeNode left;
        TreeNode right;
        
        TreeNode(int val) { this.val = val; }
    }
}
```

```java
/**
 * 快速排序的栈模拟实现
 */
public class QuickSortStackSimulation {
    
    public void quickSort(int[] arr) {
        if (arr.length <= 1) return;
        
        Deque<SortState> stack = new ArrayDeque<>();
        stack.push(new SortState(0, arr.length - 1, SortState.Phase.ENTER));
        
        while (!stack.isEmpty()) {
            SortState current = stack.peek();
            
            switch (current.phase) {
                case ENTER:
                    if (current.low >= current.high) {
                        stack.pop();
                    } else {
                        current.pivot = partition(arr, current.low, current.high);
                        current.phase = SortState.Phase.LEFT;
                        // 模拟递归调用左半部分
                        stack.push(new SortState(current.low, current.pivot - 1, 
                                                SortState.Phase.ENTER));
                    }
                    break;
                    
                case LEFT:
                    current.phase = SortState.Phase.RIGHT;
                    // 模拟递归调用右半部分
                    stack.push(new SortState(current.pivot + 1, current.high, 
                                            SortState.Phase.ENTER));
                    break;
                    
                case RIGHT:
                    // 左右两部分都处理完毕
                    stack.pop();
                    break;
            }
        }
    }
    
    private int partition(int[] arr, int low, int high) {
        int pivot = arr[high];
        int i = low - 1;
        
        for (int j = low; j < high; j++) {
            if (arr[j] <= pivot) {
                i++;
                swap(arr, i, j);
            }
        }
        
        swap(arr, i + 1, high);
        return i + 1;
    }
    
    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
    
    static class SortState {
        enum Phase { ENTER, LEFT, RIGHT }
        
        int low, high;
        int pivot;
        Phase phase;
        
        SortState(int low, int high, Phase phase) {
            this.low = low;
            this.high = high;
            this.phase = phase;
        }
    }
}
```

### 1. 表达式求值的递归下降解析

```java
/**
 * 递归下降解析器的栈模拟
 */
public class ExpressionParserStackSimulation {
    
    public double evaluate(String expression) {
        char[] chars = expression.toCharArray();
        return parseExpression(chars, new int[]{0});
    }
    
    /**
     * 栈模拟版本的表达式解析
     */
    public double parseExpressionStack(char[] chars) {
        Deque<ParseState> stack = new ArrayDeque<>();
        stack.push(new ParseState(ParseState.Type.EXPRESSION, 0));
        
        double result = 0;
        
        while (!stack.isEmpty()) {
            ParseState current = stack.peek();
            
            switch (current.type) {
                case EXPRESSION:
                    // 解析表达式：term (('+' | '-') term)*
                    current.type = ParseState.Type.TERM;
                    stack.push(new ParseState(ParseState.Type.TERM, current.pos));
                    break;
                    
                case TERM:
                    // 解析项：factor (('*' | '/') factor)*
                    current.type = ParseState.Type.FACTOR;
                    stack.push(new ParseState(ParseState.Type.FACTOR, current.pos));
                    break;
                    
                case FACTOR:
                    // 解析因子：number | '(' expression ')'
                    if (current.pos < chars.length && chars[current.pos] == '(') {
                        current.pos++; // 跳过 '('
                        current.type = ParseState.Type.EXPRESSION;
                        stack.push(new ParseState(ParseState.Type.EXPRESSION, current.pos));
                    } else {
                        // 解析数字
                        current.result = parseNumber(chars, current);
                        current.type = ParseState.Type.RETURN;
                    }
                    break;
                    
                case RETURN:
                    ParseState state = stack.pop();
                    if (!stack.isEmpty()) {
                        stack.peek().result = state.result;
                        stack.peek().pos = state.pos;
                    } else {
                        result = state.result;
                    }
                    break;
            }
        }
        
        return result;
    }
    
    private double parseNumber(char[] chars, ParseState state) {
        double num = 0;
        while (state.pos < chars.length && Character.isDigit(chars[state.pos])) {
            num = num * 10 + (chars[state.pos] - '0');
            state.pos++;
        }
        return num;
    }
    
    // 原始递归版本（用于对比）
    private double parseExpression(char[] chars, int[] pos) {
        double result = parseTerm(chars, pos);
        
        while (pos[0] < chars.length && (chars[pos[0]] == '+' || chars[pos[0]] == '-')) {
            char op = chars[pos[0]++];
            double term = parseTerm(chars, pos);
            result = (op == '+') ? result + term : result - term;
        }
        
        return result;
    }
    
    private double parseTerm(char[] chars, int[] pos) {
        double result = parseFactor(chars, pos);
        
        while (pos[0] < chars.length && (chars[pos[0]] == '*' || chars[pos[0]] == '/')) {
            char op = chars[pos[0]++];
            double factor = parseFactor(chars, pos);
            result = (op == '*') ? result * factor : result / factor;
        }
        
        return result;
    }
    
    private double parseFactor(char[] chars, int[] pos) {
        if (chars[pos[0]] == '(') {
            pos[0]++; // 跳过 '('
            double result = parseExpression(chars, pos);
            pos[0]++; // 跳过 ')'
            return result;
        }
        
        double num = 0;
        while (pos[0] < chars.length && Character.isDigit(chars[pos[0]])) {
            num = num * 10 + (chars[pos[0]] - '0');
            pos[0]++;
        }
        
        return num;
    }
    
    static class ParseState {
        enum Type { EXPRESSION, TERM, FACTOR, RETURN }
        
        Type type;
        int pos;
        double result;
        
        ParseState(Type type, int pos) {
            this.type = type;
            this.pos = pos;
        }
    }
}
```

### 2. 回溯算法的栈模拟
```java
/**
 * N皇后问题的栈模拟实现
 */
public class NQueensStackSimulation {
    
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> result = new ArrayList<>();
        
        Deque<BacktrackState> stack = new ArrayDeque<>();
        stack.push(new BacktrackState(new int[n], 0, BacktrackState.Phase.ENTER));
        
        while (!stack.isEmpty()) {
            BacktrackState current = stack.peek();
            
            switch (current.phase) {
                case ENTER:
                    if (current.row == n) {
                        // 找到一个解
                        result.add(generateBoard(current.queens, n));
                        stack.pop();
                    } else {
                        current.phase = BacktrackState.Phase.TRY_POSITION;
                        current.col = 0;
                    }
                    break;
                    
                case TRY_POSITION:
                    if (current.col < n) {
                        if (isValid(current.queens, current.row, current.col)) {
                            // 尝试在当前位置放置皇后
                            current.queens[current.row] = current.col;
                            current.phase = BacktrackState.Phase.RECURSE;
                            
                            // 模拟递归调用下一行
                            int[] newQueens = current.queens.clone();
                            stack.push(new BacktrackState(newQueens, current.row + 1, 
                                                        BacktrackState.Phase.ENTER));
                        } else {
                            // 当前位置无效，尝试下一列
                            current.col++;
                        }
                    } else {
                        // 当前行所有位置都尝试过，回溯
                        stack.pop();
                    }
                    break;
                    
                case RECURSE:
                    // 子问题处理完毕，尝试下一列
                    current.col++;
                    current.phase = BacktrackState.Phase.TRY_POSITION;
                    break;
            }
        }
        
        return result;
    }
    
    private boolean isValid(int[] queens, int row, int col) {
        for (int i = 0; i < row; i++) {
            if (queens[i] == col || 
                queens[i] - i == col - row || 
                queens[i] + i == col + row) {
                return false;
            }
        }
        return true;
    }
    
    private List<String> generateBoard(int[] queens, int n) {
        List<String> board = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            char[] row = new char[n];
            Arrays.fill(row, '.');
            row[queens[i]] = 'Q';
            board.add(new String(row));
        }
        return board;
    }
    
    static class BacktrackState {
        enum Phase { ENTER, TRY_POSITION, RECURSE }
        
        int[] queens;
        int row;
        int col;
        Phase phase;
        
        BacktrackState(int[] queens, int row, Phase phase) {
            this.queens = queens;
            this.row = row;
            this.phase = phase;
        }
    }
}
```

## 🔍 递归栈模拟的设计模式
### 1. 转换步骤
| 步骤 | 递归版本 | 栈模拟版本 |
| --- | --- | --- |
| **1. 识别状态** | 函数参数+局部变量 | 状态对象封装 |
| **2. 划分阶段** | 递归调用前后 | 状态机阶段 |
| **3. 保存上下文** | 系统调用栈 | 显式栈结构 |
| **4. 控制流转** | 函数调用返回 | 循环+状态切换 |


### 2. 通用模板
```java
/**
 * 递归栈模拟通用模板
 */
public class RecursiveStackTemplate<T, R> {
    
    public R simulate(T initialInput) {
        Deque<SimulationState<T, R>> stack = new ArrayDeque<>();
        stack.push(createInitialState(initialInput));
        
        R result = null;
        
        while (!stack.isEmpty()) {
            SimulationState<T, R> current = stack.peek();
            
            switch (current.getPhase()) {
                case ENTER:
                    if (isBaseCase(current)) {
                        current.setResult(handleBaseCase(current));
                        current.setPhase(Phase.RETURN);
                    } else {
                        current.setPhase(Phase.PROCESS);
                        // 添加子问题到栈中
                        addSubproblems(stack, current);
                    }
                    break;
                    
                case PROCESS:
                    // 处理子问题返回的结果
                    processSubresults(current);
                    current.setPhase(Phase.RETURN);
                    break;
                    
                case RETURN:
                    SimulationState<T, R> completed = stack.pop();
                    if (!stack.isEmpty()) {
                        // 将结果传递给父问题
                        propagateResult(stack.peek(), completed);
                    } else {
                        // 最终结果
                        result = completed.getResult();
                    }
                    break;
            }
        }
        
        return result;
    }
    
    // 抽象方法，由具体实现类重写
    protected abstract SimulationState<T, R> createInitialState(T input);
    protected abstract boolean isBaseCase(SimulationState<T, R> state);
    protected abstract R handleBaseCase(SimulationState<T, R> state);
    protected abstract void addSubproblems(Deque<SimulationState<T, R>> stack, 
                                         SimulationState<T, R> current);
    protected abstract void processSubresults(SimulationState<T, R> state);
    protected abstract void propagateResult(SimulationState<T, R> parent, 
                                          SimulationState<T, R> child);
    
    enum Phase { ENTER, PROCESS, RETURN }
    
    static abstract class SimulationState<T, R> {
        protected Phase phase;
        protected R result;
        
        public Phase getPhase() { return phase; }
        public void setPhase(Phase phase) { this.phase = phase; }
        public R getResult() { return result; }
        public void setResult(R result) { this.result = result; }
    }
}
```

## 🚀 性能分析与优化
### 时间复杂度
+ **基本操作**：与递归版本相同
+ **额外开销**：状态对象创建和管理
+ **优化空间**：减少不必要的状态保存

### 空间复杂度
+ **栈空间**：O(递归深度) - 与递归版本相同
+ **状态对象**：额外的内存开销
+ **优化策略**：重用状态对象，减少内存分配

### 优化技巧
1. **状态对象池**：重用状态对象减少GC压力
2. **延迟计算**：只在需要时计算结果
3. **尾递归优化**：识别尾递归并优化为循环
4. **批量处理**：合并多个简单状态

```java
/**
 * 优化的递归栈模拟
 */
public class OptimizedRecursiveStack {
    private final ObjectPool<State> statePool = new ObjectPool<>(State::new);
    
    public int optimizedFactorial(int n) {
        Deque<State> stack = new ArrayDeque<>();
        State initial = statePool.acquire();
        initial.reset(n, Phase.ENTER);
        stack.push(initial);
        
        int result = 1;
        
        try {
            while (!stack.isEmpty()) {
                State current = stack.peek();
                
                switch (current.phase) {
                    case ENTER:
                        if (current.n <= 1) {
                            current.result = 1;
                            current.phase = Phase.RETURN;
                        } else {
                            current.phase = Phase.PROCESS;
                            State child = statePool.acquire();
                            child.reset(current.n - 1, Phase.ENTER);
                            stack.push(child);
                        }
                        break;
                        
                    case PROCESS:
                        current.phase = Phase.RETURN;
                        break;
                        
                    case RETURN:
                        State completed = stack.pop();
                        if (!stack.isEmpty()) {
                            State parent = stack.peek();
                            if (parent.phase == Phase.PROCESS) {
                                parent.result = parent.n * completed.result;
                            }
                        } else {
                            result = completed.result;
                        }
                        statePool.release(completed);
                        break;
                }
            }
        } finally {
            // 清理剩余状态对象
            while (!stack.isEmpty()) {
                statePool.release(stack.pop());
            }
        }
        
        return result;
    }
    
    static class State {
        int n;
        Phase phase;
        int result;
        
        void reset(int n, Phase phase) {
            this.n = n;
            this.phase = phase;
            this.result = 0;
        }
    }
    
    enum Phase { ENTER, PROCESS, RETURN }
}
```

+ **对比验证**：与递归版本对比结果

### 3. 适用场景
