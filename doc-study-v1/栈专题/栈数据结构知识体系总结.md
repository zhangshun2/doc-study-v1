## 🎯 栈的基础理论
### 定义与特性
**栈（Stack）** 是一种线性数据结构，遵循 **LIFO（Last In, First Out）** 原则，即后进先出。

```java
/**
 * 栈的抽象数据类型定义
 */
public interface Stack<T> {
    void push(T item);      // 入栈：将元素压入栈顶
    T pop();                // 出栈：移除并返回栈顶元素
    T peek();               // 查看：返回栈顶元素但不移除
    boolean isEmpty();      // 判空：检查栈是否为空
    int size();            // 大小：返回栈中元素个数
}
```

### 核心特性
1. **LIFO原则**：最后入栈的元素最先出栈
2. **单端操作**：只能在栈顶进行插入和删除操作
3. **动态大小**：栈的大小可以动态变化
4. **访问限制**：只能访问栈顶元素

### 时间复杂度
| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| push() | O(1) | 在栈顶插入元素 |
| pop() | O(1) | 移除栈顶元素 |
| peek() | O(1) | 查看栈顶元素 |
| isEmpty() | O(1) | 检查是否为空 |
| size() | O(1) | 获取栈大小 |


## 🛠️ 栈的实现方式
### 1. 基于数组的实现
```java
/**
 * 基于数组的栈实现
 * 优点：内存连续，缓存友好，随机访问
 * 缺点：需要预分配空间，可能浪费内存
 */
public class ArrayStack<T> implements Stack<T> {
    private T[] array;
    private int top;
    private int capacity;
    
    @SuppressWarnings("unchecked")
    public ArrayStack(int capacity) {
        this.capacity = capacity;
        this.array = (T[]) new Object[capacity];
        this.top = -1;
    }
    
    @Override
    public void push(T item) {
        if (top >= capacity - 1) {
            resize();
        }
        array[++top] = item;
    }
    
    @Override
    public T pop() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        T item = array[top];
        array[top--] = null;  // 避免内存泄漏
        return item;
    }
    
    @Override
    public T peek() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        return array[top];
    }
    
    @Override
    public boolean isEmpty() {
        return top == -1;
    }
    
    @Override
    public int size() {
        return top + 1;
    }
    
    @SuppressWarnings("unchecked")
    private void resize() {
        capacity *= 2;
        T[] newArray = (T[]) new Object[capacity];
        System.arraycopy(array, 0, newArray, 0, top + 1);
        array = newArray;
    }
}
```

### 2. 基于链表的实现
```java
/**
 * 基于链表的栈实现
 * 优点：动态分配内存，不浪费空间
 * 缺点：额外的指针开销，缓存不友好
 */
public class LinkedStack<T> implements Stack<T> {
    private Node<T> head;
    private int size;
    
    private static class Node<T> {
        T data;
        Node<T> next;
        
        Node(T data) {
            this.data = data;
        }
    }
    
    @Override
    public void push(T item) {
        Node<T> newNode = new Node<>(item);
        newNode.next = head;
        head = newNode;
        size++;
    }
    
    @Override
    public T pop() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        T data = head.data;
        head = head.next;
        size--;
        return data;
    }
    
    @Override
    public T peek() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        return head.data;
    }
    
    @Override
    public boolean isEmpty() {
        return head == null;
    }
    
    @Override
    public int size() {
        return size;
    }
}
```

## 🧠 核心算法与技巧
### 1. 单调栈算法
```java
/**
 * 单调栈核心算法模板
 */
public class MonotonicStackAlgorithm {
    
    // 下一个更大元素（单调递减栈）
    public int[] nextGreaterElement(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        
        // 从右到左遍历
        for (int i = n - 1; i >= 0; i--) {
            // 维护单调递减栈
            while (!stack.isEmpty() && stack.peek() <= nums[i]) {
                stack.pop();
            }
            
            result[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(nums[i]);
        }
        
        return result;
    }
    
    // 柱状图最大矩形（单调递增栈）
    public int largestRectangleArea(int[] heights) {
        Deque<Integer> stack = new ArrayDeque<>();
        int maxArea = 0;
        
        for (int i = 0; i <= heights.length; i++) {
            int currentHeight = (i == heights.length) ? 0 : heights[i];
            
            // 维护单调递增栈
            while (!stack.isEmpty() && currentHeight < heights[stack.peek()]) {
                int height = heights[stack.pop()];
                int width = stack.isEmpty() ? i : i - stack.peek() - 1;
                maxArea = Math.max(maxArea, height * width);
            }
            
            stack.push(i);
        }
        
        return maxArea;
    }
}
```

### 2. 表达式求值算法
```java
/**
 * 表达式求值核心算法
 */
public class ExpressionEvaluationAlgorithm {
    
    // 中缀表达式转后缀表达式
    public String infixToPostfix(String infix) {
        StringBuilder postfix = new StringBuilder();
        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Integer> precedence = Map.of(
            '+', 1, '-', 1, '*', 2, '/', 2, '^', 3
        );
        
        for (char c : infix.toCharArray()) {
            if (Character.isLetterOrDigit(c)) {
                postfix.append(c);
            } else if (c == '(') {
                stack.push(c);
            } else if (c == ')') {
                while (!stack.isEmpty() && stack.peek() != '(') {
                    postfix.append(stack.pop());
                }
                stack.pop(); // 移除 '('
            } else if (precedence.containsKey(c)) {
                while (!stack.isEmpty() && stack.peek() != '(' &&
                       precedence.get(stack.peek()) >= precedence.get(c)) {
                    postfix.append(stack.pop());
                }
                stack.push(c);
            }
        }
        
        while (!stack.isEmpty()) {
            postfix.append(stack.pop());
        }
        
        return postfix.toString();
    }
    
    // 后缀表达式求值
    public int evaluatePostfix(String postfix) {
        Deque<Integer> stack = new ArrayDeque<>();
        
        for (char c : postfix.toCharArray()) {
            if (Character.isDigit(c)) {
                stack.push(c - '0');
            } else {
                int b = stack.pop();
                int a = stack.pop();
                switch (c) {
                    case '+': stack.push(a + b); break;
                    case '-': stack.push(a - b); break;
                    case '*': stack.push(a * b); break;
                    case '/': stack.push(a / b); break;
                }
            }
        }
        
        return stack.pop();
    }
}
```

### 3. 状态管理算法

```java
/**
 * 状态管理核心算法
 */
public class StateManagementAlgorithm {
    
    // 状态保存与恢复
    public String decodeString(String s) {
        Deque<Integer> countStack = new ArrayDeque<>();
        Deque<StringBuilder> stringStack = new ArrayDeque<>();
        StringBuilder currentString = new StringBuilder();
        int count = 0;
        
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                count = count * 10 + (c - '0');
            } else if (c == '[') {
                // 保存当前状态
                countStack.push(count);
                stringStack.push(currentString);
                // 重置状态
                count = 0;
                currentString = new StringBuilder();
            } else if (c == ']') {
                // 恢复状态
                StringBuilder temp = currentString;
                currentString = stringStack.pop();
                int repeatCount = countStack.pop();
                for (int i = 0; i < repeatCount; i++) {
                    currentString.append(temp);
                }
            } else {
                currentString.append(c);
            }
        }
        
        return currentString.toString();
    }
}
```

```java
/**
 * 递归转迭代核心算法
 */
public class RecursionToIterationAlgorithm {
    
    // 二叉树遍历（递归转迭代）
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode current = root;
        
        while (current != null || !stack.isEmpty()) {
            // 一直向左走到底
            while (current != null) {
                stack.push(current);
                current = current.left;
            }
            
            // 处理当前节点
            current = stack.pop();
            result.add(current.val);
            
            // 转向右子树
            current = current.right;
        }
        
        return result;
    }
    
    // DFS遍历（递归转迭代）
    public void dfsIterative(TreeNode root) {
        if (root == null) return;
        
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            
            // 处理当前节点
            process(node);
            
            // 添加子节点（注意顺序）
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
    }
    
    private void process(TreeNode node) {
        System.out.println(node.val);
    }
}
```

```java
/**
 * 浏览器历史记录管理

public class BrowserHistory {
    private Deque<String> history = new ArrayDeque<>();
    private Deque<String> forward = new ArrayDeque<>();
    
    public void visit(String url) {
        history.push(url);
        forward.clear();  // 清空前进历史
    }
    
    public String back() {
        if (history.size() > 1) {
            String current = history.pop();
            forward.push(current);
            return history.peek();
        }
        return history.peek();
    }
    
    public String forward() {
        if (!forward.isEmpty()) {
            String url = forward.pop();
            history.push(url);
            return url;
        }
        return history.peek();
    }
}
```

```java
/**
 * 简单的内存栈管理
 */
public class MemoryStack {
    private byte[] memory;
    private int stackPointer;
    
    public MemoryStack(int size) {
        this.memory = new byte[size];
        this.stackPointer = size;
    }
    
    public int allocate(int size) {
        if (stackPointer - size < 0) {
            throw new OutOfMemoryError("Stack overflow");
        }
        stackPointer -= size;
        return stackPointer;
    }
    
    public void deallocate(int size) {
        stackPointer += size;
        if (stackPointer > memory.length) {
            stackPointer = memory.length;
        }
    }
}
```
