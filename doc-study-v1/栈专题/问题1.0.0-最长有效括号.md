# LeetCode 32. 最长有效括号
## 题目描述
给你一个只包含 '(' 和 ')' 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

## 示例
**示例 1：**

```plain
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**

```plain
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**

```plain
输入：s = ""
输出：0
```

## 提示
+ 0 <= s.length <= 3 * 10^4
+ s[i] 为 '(' 或 ')'

## 理解题目
这道题的关键点在于：

1. 我们需要找的是**连续**的有效括号子串
2. 有效括号是指每个左括号都有对应的右括号将其闭合
3. 我们需要返回的是最长有效括号子串的**长度**

```plain
这与移除无效括号后的长度不同。例如，对于字符串 "(()"：
- 如果是移除无效括号后的长度，结果应该是2（移除第一个左括号后得到"()"）
- 但本题要求的是最长有效括号子串的长度，结果也是2（即"()"）

再举一个更明显的例子，对于字符串 ")()(()"：
- 如果是移除无效括号后的长度，结果应该是4（移除第一个右括号和一个左括号后得到"()()"）
- 但本题要求的是最长有效括号子串的长度，结果是2（最长连续有效子串是"()"）
```

## 思考方向
1. 如何判断一个括号串是否有效？
    - 使用栈结构：遇到左括号入栈，遇到右括号时如果栈顶是左括号则出栈
    - 最终栈为空则整个串有效
2. 如何找到最长的有效子串？
    - 我们需要记录有效子串的起始和结束位置
    - 或者记录每个位置结束的有效子串长度

## 解题思路引导
让我们一步步思考：

1. 首先，我们知道有效括号串的判断可以用栈
2. 但这道题要求的是最长有效子串，我们需要记录长度信息
3. 如果使用栈，我们可以存储括号的下标而不是括号本身
4. 这样当匹配成功时，可以通过下标差计算长度

让我们用一个简单的例子来理解这个思路。以字符串 "(())" 为例：

```plain
字符串: ( ( ) )
下标:   0 1 2 3

初始栈: [-1]  (放入-1作为参考点)

步骤1: 遇到'('(下标0)
栈: [-1, 0]

步骤2: 遇到'('(下标1)  
栈: [-1, 0, 1]

步骤3: 遇到')'(下标2)
- 弹出栈顶1 (匹配左括号)
- 栈变成: [-1, 0]
- 计算长度: 2 - 0 = 2 (当前位置 - 新栈顶)
- 这表示从位置1到位置2形成了长度为2的有效子串

步骤4: 遇到')'(下标3)
- 弹出栈顶0 (匹配左括号)  
- 栈变成: [-1]
- 计算长度: 3 - (-1) = 4 (当前位置 - 新栈顶)
- 这表示从开始到位置3形成了长度为4的有效子串

最终结果: 最长有效括号长度为4
```

**关键理解点：**

1. 栈中存储的是括号的下标，不是括号字符
2. 当右括号匹配成功后，新的栈顶下标表示当前有效子串的"起始参考点"
3. 当前位置减去这个参考点，就是当前有效子串的长度
4. 初始的-1是为了处理边界情况，让计算更简单

这样，栈不仅帮我们匹配括号，还能直接计算出有效子串的长度！
