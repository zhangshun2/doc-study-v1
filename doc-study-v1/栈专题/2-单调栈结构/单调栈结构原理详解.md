# 单调栈结构原理详解
## 📚 单调栈的基本概念
### 什么是单调栈？
单调栈（Monotonic Stack）是一种特殊的栈结构，它在普通栈的基础上增加了**单调性约束**：

+ **单调递增栈**：栈底到栈顶元素严格递增
+ **单调递减栈**：栈底到栈顶元素严格递减

### 单调栈的核心思想
```plain
单调递增栈示意图：

栈顶 → ┌─────┐
      │  8  │ ← 最大元素
      ├─────┤
      │  5  │
      ├─────┤
      │  3  │
      ├─────┤
栈底 → │  1  │ ← 最小元素
      └─────┘

特点：从栈底到栈顶严格递增
```

```plain
单调递减栈示意图：

栈顶 → ┌─────┐
      │  1  │ ← 最小元素
      ├─────┤
      │  3  │
      ├─────┤
      │  5  │
      ├─────┤
栈底 → │  8  │ ← 最大元素
      └─────┘

特点：从栈底到栈顶严格递减
```

## 🔧 单调栈的核心操作
### 1. 单调递增栈的维护过程
**核心规则：** 入栈前，弹出所有大于等于当前元素的栈顶元素

```java
public void pushToIncreasingStack(Deque<Integer> stack, int element) {
    // 维护单调递增性：弹出所有 >= element 的元素
    while (!stack.isEmpty() && stack.peek() >= element) {
        stack.pop();
    }
    // 入栈
    stack.push(element);
}
```

```plain
目标：维护单调递增栈

步骤1：处理元素3
栈：[] → [3]
操作：直接入栈

步骤2：处理元素1
栈：[3]
比较：1 < 3，需要弹出3
栈：[3] → [] → [1]
操作：弹出3，然后1入栈

步骤3：处理元素4
栈：[1]
比较：4 > 1，直接入栈
栈：[1] → [1, 4]

步骤4：处理元素2
栈：[1, 4]
比较：2 < 4，需要弹出4
栈：[1, 4] → [1] → [1, 2]
操作：弹出4，然后2入栈

步骤5：处理元素6
栈：[1, 2]
比较：6 > 2，直接入栈
栈：[1, 2] → [1, 2, 6]

步骤6：处理元素5
栈：[1, 2, 6]
比较：5 < 6，需要弹出6
栈：[1, 2, 6] → [1, 2] → [1, 2, 5]
```

### 1. 通用单调栈模板
```java
import java.util.*;

public class MonotonicStack {
    
    /**
     * 单调递增栈模板
     * @param nums 输入数组
     * @return 处理结果
     */
    public int[] monotonicIncreasingStack(int[] nums) {
        Deque<Integer> stack = new ArrayDeque<>();
        int[] result = new int[nums.length];
        
        for (int i = 0; i < nums.length; i++) {
            // 维护单调递增性
            while (!stack.isEmpty() && nums[stack.peek()] >= nums[i]) {
                int index = stack.pop();
                // 在这里处理被弹出的元素
                result[index] = processElement(index, i, nums);
            }
            stack.push(i);
        }
        
        // 处理栈中剩余元素
        while (!stack.isEmpty()) {
            int index = stack.pop();
            result[index] = processRemaining(index, nums);
        }
        
        return result;
    }
    
    /**
     * 单调递减栈模板
     * @param nums 输入数组
     * @return 处理结果
     */
    public int[] monotonicDecreasingStack(int[] nums) {
        Deque<Integer> stack = new ArrayDeque<>();
        int[] result = new int[nums.length];
        
        for (int i = 0; i < nums.length; i++) {
            // 维护单调递减性

                int index = stack.pop();
                // 在这里处理被弹出的元素
                result[index] = processElement(index, i, nums);
            }
            stack.push(i);
        }
        
        // 处理栈中剩余元素
        while (!stack.isEmpty()) {
            int index = stack.pop();
            result[index] = processRemaining(index, nums);
        }
        
        return result;
    }
    
    // 处理被弹出元素的逻辑（根据具体问题实现）
```

### 2. 单调栈的可视化实现
```java
/**
 * 带可视化功能的单调栈实现
 */
public class VisualMonotonicStack {
    private Deque<Integer> stack;
    private boolean isIncreasing;
    
    public VisualMonotonicStack(boolean isIncreasing) {
        this.stack = new ArrayDeque<>();
        this.isIncreasing = isIncreasing;
    }
    
    public void push(int element) {
        System.out.println("\n=== 处理元素: " + element + " ===");
        System.out.println("当前栈状态: " + stack);
        
        List<Integer> popped = new ArrayList<>();
        
        if (isIncreasing) {
            // 单调递增栈
            while (!stack.isEmpty() && stack.peek() >= element) {
                int poppedElement = stack.pop();
                popped.add(poppedElement);
                System.out.println("弹出元素: " + poppedElement + 
                                 " (因为 " + poppedElement + " >= " + element + ")");
            }
        } else {
            // 单调递减栈
            while (!stack.isEmpty() && stack.peek() <= element) {
                int poppedElement = stack.pop();
                popped.add(poppedElement);
                System.out.println("弹出元素: " + poppedElement + 
                                 " (因为 " + poppedElement + " <= " + element + ")");
            }
        }
        
        stack.push(element);
        System.out.println("入栈元素: " + element);
        System.out.println("新栈状态: " + stack);
        
        if (!popped.isEmpty()) {
            System.out.println("本次弹出的元素: " + popped);
        }
    }
    
    public void showFinalState() {
        System.out.println("\n=== 最终状态 ===");
        System.out.println("栈类型: " + (isIncreasing ? "单调递增" : "单调递减"));
        System.out.println("最终栈: " + stack);
        System.out.println("栈大小: " + stack.size());
    }
    
    // 演示方法
    public static void demo() {
        int[] nums = {3, 1, 4, 2, 6, 5};
        
        System.out.println("输入序列: " + Arrays.toString(nums));
        
        // 演示单调递增栈
        System.out.println("\n" + "=".repeat(50));
        System.out.println("单调递增栈演示");
        System.out.println("=".repeat(50));
        
        VisualMonotonicStack incStack = new VisualMonotonicStack(true);
        for (int num : nums) {
            incStack.push(num);
        }
        incStack.showFinalState();
        
        // 演示单调递减栈
        System.out.println("\n" + "=".repeat(50));
        System.out.println("单调递减栈演示");
        System.out.println("=".repeat(50));
        
        VisualMonotonicStack decStack = new VisualMonotonicStack(false);
        for (int num : nums) {
            decStack.push(num);
        }
        decStack.showFinalState();
    }
}
```

## 🎯 单调栈的典型应用场景
### 1. 寻找下一个更大元素
**问题描述：** 对于数组中的每个元素，找到它右边第一个比它大的元素

```java
/**
 * 下一个更大元素问题
 * 使用单调递减栈解决
 */
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);  // 默认值为-1
    
    Deque<Integer> stack = new ArrayDeque<>();  // 存储索引
    
    for (int i = 0; i < n; i++) {
        // 当前元素比栈顶元素大，说明找到了栈顶元素的下一个更大元素
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
            int index = stack.pop();
            result[index] = nums[i];
        }
        stack.push(i);
    }
    
    return result;
}
```

**过程图解：**

```plain
输入：[2, 1, 2, 4, 3, 1]

i=0, nums[0]=2:
栈：[] → [0]
结果：[-1, -1, -1, -1, -1, -1]

i=1, nums[1]=1:
比较：1 < 2，直接入栈
栈：[0] → [0, 1]
结果：[-1, -1, -1, -1, -1, -1]

i=2, nums[2]=2:
比较：2 > 1，弹出索引1，nums[1]的下一个更大元素是2
栈：[0, 1] → [0] → [0, 2]
结果：[-1, 2, -1, -1, -1, -1]

i=3, nums[3]=4:
比较：4 > 2，弹出索引2，nums[2]的下一个更大元素是4
比较：4 > 2，弹出索引0，nums[0]的下一个更大元素是4
栈：[0, 2] → [0] → [] → [3]
结果：[4, 2, 4, -1, -1, -1]

i=4, nums[4]=3:
比较：3 < 4，直接入栈
栈：[3] → [3, 4]
结果：[4, 2, 4, -1, -1, -1]

i=5, nums[5]=1:
比较：1 < 3，直接入栈
栈：[3, 4] → [3, 4, 5]
结果：[4, 2, 4, -1, -1, -1]

最终结果：[4, 2, 4, -1, -1, -1]
```

### 2. 柱状图中的最大矩形
**问题描述：** 给定柱状图的高度，求能构成的最大矩形面积

```java
/**
 * 柱状图中最大矩形问题
 * 使用单调递增栈解决
 */
public int largestRectangleArea(int[] heights) {
    int n = heights.length;
    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0;
    
    for (int i = 0; i <= n; i++) {
        // 在末尾添加高度为0的柱子，确保所有柱子都被处理
        int currentHeight = (i == n) ? 0 : heights[i];
        
        // 当前高度小于栈顶高度，计算以栈顶为高的矩形面积
        while (!stack.isEmpty() && heights[stack.peek()] > currentHeight) {
            int height = heights[stack.pop()];
            int width = stack.isEmpty() ? i : i - stack.peek() - 1;
            maxArea = Math.max(maxArea, height * width);
        }
        
        stack.push(i);
    }
    
    return maxArea;
}
```

**过程图解：**

```plain
输入：[2, 1, 5, 6, 2, 3]

柱状图：
    6
  5 █
  █ █     3
2 █ █ 2 █
█ █ █ █ █
█ 1 █ █ █
0 1 2 3 4 5

处理过程：
i=0: 栈=[0], 高度=2
i=1: 高度1<2，弹出0，计算面积=2*1=2，栈=[1]
i=2: 栈=[1,2], 高度=5
i=3: 栈=[1,2,3], 高度=6
i=4: 高度2<6，弹出3，计算面积=6*1=6
     高度2<5，弹出2，计算面积=5*2=10
     栈=[1,4]
i=5: 栈=[1,4,5], 高度=3
i=6: 高度0，依次弹出所有元素计算面积

最大面积：10
```

### 3. 接雨水问题
**问题描述：** 给定高度数组，计算能接多少雨水

```java
/**
 * 接雨水问题
 * 使用单调递减栈解决
 */
public int trap(int[] height) {
    Deque<Integer> stack = new ArrayDeque<>();
    int water = 0;
    
    for (int i = 0; i < height.length; i++) {
        // 当前高度大于栈顶高度，可能形成凹槽
        while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
            int bottom = stack.pop();  // 凹槽底部
            
            if (stack.isEmpty()) break;  // 没有左边界
            
            int left = stack.peek();   // 左边界
            int right = i;             // 右边界
            
            // 计算水的高度和宽度
            int h = Math.min(height[left], height[right]) - height[bottom];
            int w = right - left - 1;
            water += h * w;
        }
        stack.push(i);
    }
    
    return water;
}
```

## 🔍 单调栈的核心思想总结
### 1. 设计原则
| 栈类型 | 维护规则 | 适用场景 | 核心思想 |
| --- | --- | --- | --- |
| **单调递增** | 弹出 >= 当前元素 | 寻找右边更小元素 | 保持递增趋势 |
| **单调递减** | 弹出 <= 当前元素 | 寻找右边更大元素 | 保持递减趋势 |


### 2. 问题识别
**何时使用单调栈？**

+ 需要找到**下一个更大/更小**的元素
+ 需要找到**左右边界**的问题
+ 涉及**矩形面积**计算的问题
+ 需要**维护某种单调性**的问题

## 🚀 单调栈的优势与复杂度
### 时间复杂度分析
+ **最优情况**：O(n) - 每个元素最多入栈出栈一次
+ **最坏情况**：O(n) - 即使频繁弹出，总操作数仍为O(n)
+ **平均情况**：O(n) - 线性时间复杂度

### 空间复杂度分析
+ **空间复杂度**：O(n) - 最坏情况下所有元素都在栈中

### 优势特点
1. **高效性**：线性时间解决复杂问题
2. **简洁性**：代码结构清晰，易于理解
3. **通用性**：适用于多种"寻找边界"类问题
4. **可扩展性**：容易扩展到二维问题

## 💡 学习要点与注意事项
### 1. 核心理解
+ **单调性维护**：理解何时弹出元素
+ **索引存储**：通常存储索引而非值
+ **边界处理**：注意数组边界和栈空的情况

### 2. 常见陷阱
+ **弹出条件**：递增栈用`>=`，递减栈用`<=`
+ **索引混淆**：区分存储索引还是值
+ **边界情况**：处理空栈和数组边界
