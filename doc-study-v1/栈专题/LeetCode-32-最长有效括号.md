# LeetCode 32 - 最长有效括号
## 题目描述
**难度：困难**

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

### 示例
**示例 1：**

```plain
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**

```plain
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**

```plain
输入：s = ""
输出：0
```

### 约束条件
+ `0 <= s.length <= 3 * 10^4`
+ `s[i]` 为 `'('` 或 `')'`

## 解题思路
这道题有多种解法，我们重点介绍**栈解法**和**动态规划解法**，因为它们最能体现解题思路的精髓。

### 方法一：栈解法（推荐）
#### 核心思想
使用栈来跟踪括号的匹配情况，同时记录每个位置的索引，通过计算匹配括号之间的距离来求得最长有效括号长度。

#### 算法步骤
1. **初始化栈**：栈中存储字符的索引，初始时压入 -1 作为基准
2. **遍历字符串**：
    - 遇到 `'('`：将当前索引压入栈
    - 遇到 `')'`：
        * 先弹出栈顶元素
        * 如果栈为空，说明当前 `')'` 无法匹配，将当前索引压入栈作为新的基准
        * 如果栈不为空，计算当前索引与栈顶索引的距离，更新最大长度

#### 图解分析
以字符串 `")()())"` 为例：

```plain
初始状态:
栈: [-1]  (基准位置)
字符串: ) ( ) ( ) )
索引:   0 1 2 3 4 5

步骤 1: 遇到 ')' (索引0)
- 弹出栈顶 -1
- 栈为空，将索引 0 压入栈作为新基准
栈: [0]
当前最大长度: 0

步骤 2: 遇到 '(' (索引1)  
- 将索引 1 压入栈

步骤 3: 遇到 ')' (索引2)
- 弹出栈顶 1 (匹配的 '(')
- 栈不为空，栈顶为 0
- 计算长度: 2 - 0 = 2
栈: [0]
当前最大长度: 2

步骤 4: 遇到 '(' (索引3)
- 将索引 3 压入栈  
栈: [0, 3]
当前最大长度: 2

步骤 5: 遇到 ')' (索引4)
- 弹出栈顶 3 (匹配的 '(')
- 栈不为空，栈顶为 0
- 计算长度: 4 - 0 = 4
栈: [0]

- 弹出栈顶 0
- 栈为空，将索引 5 压入栈作为新基准

```

### 方法二：动态规划解法
#### 核心思想
使用动态规划数组 `dp[i]` 表示以索引 `i` 结尾的最长有效括号长度。

#### 状态转移方程
+ 如果 `s[i] == '('`，则 `dp[i] = 0`（左括号不能作为有效括号的结尾）
+ 如果 `s[i] == ')'`：
    - 如果 `s[i-1] == '('`，则 `dp[i] = dp[i-2] + 2`
    - 如果 `s[i-1] == ')'` 且 `dp[i-1] > 0`：
        * 找到与当前 `')'` 匹配的 `'('` 的位置：`j = i - dp[i-1] - 1`
        * 如果 `s[j] == '('`，则 `dp[i] = dp[i-1] + 2 + dp[j-1]`

## 代码实现
### 方法一：栈解法
```java
public class Solution {
    public int longestValidParentheses(String s) {
        int maxLen = 0;
        Deque<Integer> stack = new LinkedList<>();
        stack.push(-1); // 初始基准位置
        
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                // 左括号：压入索引
                stack.push(i);
            } else {
                // 右括号：弹出栈顶
                stack.pop();
                
                if (stack.isEmpty()) {
                    // 栈为空：当前右括号无法匹配，作为新的基准
                    stack.push(i);
                } else {
                    // 栈不为空：计算当前有效括号长度
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        
        return maxLen;
    }
}
```

### 方法二：动态规划解法
```java
public class Solution {
    public int longestValidParentheses(String s) {
        int maxLen = 0;
        int[] dp = new int[s.length()];
        
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == ')') {
                if (s.charAt(i - 1) == '(') {
                    // 情况1: ...()
                    dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
                } else if (dp[i - 1] > 0) {
                    // 情况2: ...))，且前一个)有匹配
                    int j = i - dp[i - 1] - 1;
                    if (j >= 0 && s.charAt(j) == '(') {
                        dp[i] = dp[i - 1] + 2 + (j > 0 ? dp[j - 1] : 0);
                    }
                }
                maxLen = Math.max(maxLen, dp[i]);
            }
        }
        
        return maxLen;
    }
}
```

### 方法三：双向遍历解法（空间优化）
```java
public class Solution {
    public int longestValidParentheses(String s) {
        int left = 0, right = 0, maxLen = 0;
        
        // 从左到右遍历
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                left++;
            } else {
                right++;
            }
            
            if (left == right) {
                maxLen = Math.max(maxLen, 2 * right);
            } else if (right > left) {
                left = right = 0;
            }
        }
        
        left = right = 0;
        
        // 从右到左遍历
        for (int i = s.length() - 1; i >= 0; i--) {
            if (s.charAt(i) == '(') {
                left++;
            } else {
                right++;
            }
            
            if (left == right) {
                maxLen = Math.max(maxLen, 2 * left);
            } else if (left > right) {
                left = right = 0;
            }
        }
        
        return maxLen;
    }
}
```

## 复杂度分析
### 时间复杂度
+ **栈解法**：O(n)，遍历字符串一次
+ **动态规划**：O(n)，遍历字符串一次
+ **双向遍历**：O(n)，遍历字符串两次

### 空间复杂度
+ **栈解法**：O(n)，栈的空间复杂度
+ **动态规划**：O(n)，dp 数组的空间
+ **双向遍历**：O(1)，只使用常数额外空间

## 关键点总结
### 1. 栈解法的精髓
+ **基准位置**：栈底始终保持一个基准位置，用于计算长度
+ **索引存储**：栈中存储的是字符的索引，而不是字符本身
+ **长度计算**：通过当前位置减去栈顶位置得到有效括号长度

### 2. 动态规划的状态设计
+ **状态定义**：`dp[i]` 表示以位置 `i` 结尾的最长有效括号长度
+ **状态转移**：根据当前字符和前一个字符的情况进行转移
+ **边界处理**：注意数组越界的情况

### 3. 双向遍历的思想
+ **左右平衡**：通过统计左右括号数量判断有效性
+ **重置时机**：当右括号多于左括号时重置计数器
+ **双向互补**：单向遍历可能遗漏某些情况，双向遍历确保完整性

### 4. 常见错误
+ **栈为空时的处理**：忘记在栈为空时压入当前索引作为新基准
+ **边界条件**：字符串为空或长度为1的情况
+ **长度计算错误**：混淆字符索引和实际长度的关系
