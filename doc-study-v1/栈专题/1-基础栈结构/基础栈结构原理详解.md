# 基础栈结构原理详解
## 📚 栈的基本概念
### 什么是栈？
栈（Stack）是一种**后进先出（LIFO - Last In First Out）**的线性数据结构。想象一下叠盘子的过程：

+ 最后放上去的盘子最先被拿走
+ 最先放的盘子最后才能拿到

### 栈的核心特性
```plain
栈的LIFO特性示意图：

入栈过程：           出栈过程：
   ↓                   ↑
┌─────┐             ┌─────┐
│  3  │ ← 栈顶      │  3  │ ← 先出
├─────┤             ├─────┤
│  2  │             │  2  │ ← 后出
├─────┤             ├─────┤
│  1  │ ← 栈底      │  1  │ ← 最后出
└─────┘             └─────┘
```

## 🔧 栈的基本操作
### 1. 核心操作详解
| 操作 | 英文名 | 功能描述 | 时间复杂度 |
| --- | --- | --- | --- |
| **入栈** | push | 在栈顶添加元素 | O(1) |
| **出栈** | pop | 移除并返回栈顶元素 | O(1) |
| **查看栈顶** | peek/top | 返回栈顶元素但不移除 | O(1) |
| **判空** | isEmpty | 检查栈是否为空 | O(1) |
| **获取大小** | size | 返回栈中元素个数 | O(1) |

## 💻 Java中的栈实现
### 1. 使用Deque接口（推荐）
```java
import java.util.Deque;
import java.util.ArrayDeque;

public class StackExample {
    public static void main(String[] args) {
        // 创建栈
        Deque<Integer> stack = new ArrayDeque<>();
        
        // 基本操作演示
        System.out.println("=== 栈操作演示 ===");
        
        // 1. 入栈操作
        System.out.println("入栈操作：");
        stack.push(10);
        System.out.println("push(10) → 栈：" + stack);
        
        stack.push(20);
        System.out.println("push(20) → 栈：" + stack);
        
        stack.push(30);
        System.out.println("push(30) → 栈：" + stack);
        
        // 2. 查看栈顶
        System.out.println("\n查看栈顶：");
        System.out.println("peek() → " + stack.peek());
        System.out.println("栈状态：" + stack);
        
        // 3. 出栈操作
        System.out.println("\n出栈操作：");
        System.out.println("pop() → " + stack.pop());
        System.out.println("栈状态：" + stack);
        
        System.out.println("pop() → " + stack.pop());
        System.out.println("栈状态：" + stack);
        
        // 4. 检查栈状态
        System.out.println("\n栈状态检查：");
        System.out.println("isEmpty() → " + stack.isEmpty());
        System.out.println("size() → " + stack.size());
    }
}
```

### 2. 栈的内部实现原理
```java
/**
 * 简化版栈的实现示例
 */
public class SimpleStack<T> {
    private Object[] elements;
    private int top;           // 栈顶指针
    private int capacity;      // 栈容量
    
    public SimpleStack(int capacity) {
        this.capacity = capacity;
        this.elements = new Object[capacity];
        this.top = -1;         // 初始时栈为空
    }
    
    /**
     * 入栈操作
     */
    public void push(T element) {
        if (isFull()) {
            throw new RuntimeException("栈已满");
        }
        elements[++top] = element;
    }
    
    /**
     * 出栈操作
     */
    @SuppressWarnings("unchecked")
    public T pop() {
        if (isEmpty()) {
            throw new RuntimeException("栈为空");
        }
        T element = (T) elements[top];
        elements[top--] = null;  // 避免内存泄漏
        return element;
    }
    
    /**
     * 查看栈顶元素
     */
    @SuppressWarnings("unchecked")
    public T peek() {
        if (isEmpty()) {
            throw new RuntimeException("栈为空");
        }
        return (T) elements[top];
    }
    
    /**
     * 检查栈是否为空
     */
    public boolean isEmpty() {
        return top == -1;
    }
    
    /**
     * 检查栈是否已满
     */
    public boolean isFull() {
        return top == capacity - 1;
    }
    
    /**
     * 获取栈大小
     */
    public int size() {
        return top + 1;
    }
}
```

## 🎯 基础栈的典型应用场景
### 1. 括号匹配问题
**核心思想：** 利用栈的LIFO特性来匹配成对的括号

```java
public boolean isValidParentheses(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    
    for (char c : s.toCharArray()) {
        // 左括号入栈
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);
        } 
        // 右括号匹配
        else if (c == ')' || c == ']' || c == '}') {
            if (stack.isEmpty()) return false;
            
            char top = stack.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                return false;
            }
        }
    }
    
    return stack.isEmpty();
}
```

**过程图解：**

```plain
输入："([{}])"

步骤1：遇到'(' → 入栈
栈：['(']

步骤2：遇到'[' → 入栈
栈：['[', '(']

步骤3：遇到'{' → 入栈
栈：['{', '[', '(']

步骤4：遇到'}' → 与栈顶'{'匹配，出栈
栈：['[', '(']

步骤5：遇到']' → 与栈顶'['匹配，出栈
栈：['(']

步骤6：遇到')' → 与栈顶'('匹配，出栈
栈：[]

结果：栈为空，括号匹配成功
```

### 2. 字符串逆序
**核心思想：** 利用栈的LIFO特性实现字符串逆序

```java
public String reverseString(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    
    // 将字符依次入栈
    for (char c : s.toCharArray()) {
        stack.push(c);
    }
    
    // 依次出栈构建逆序字符串
    StringBuilder result = new StringBuilder();
    while (!stack.isEmpty()) {
        result.append(stack.pop());
    }
    
    return result.toString();
}
```

**过程图解：**

```plain
输入："hello"

入栈过程：
h → [h]
e → [e, h]
l → [l, e, h]
l → [l, l, e, h]
o → [o, l, l, e, h]

出栈过程：
pop() → o, 结果："o"
pop() → l, 结果："ol"
pop() → l, 结果："oll"
pop() → e, 结果："olle"
pop() → h, 结果："olleh"

最终结果："olleh"
```

### 3. 函数调用栈模拟
**核心思想：** 模拟程序运行时的函数调用栈

```java
public class FunctionCallStack {
    private Deque<String> callStack = new ArrayDeque<>();
    
    public void enterFunction(String functionName) {
        callStack.push(functionName);
        System.out.println("进入函数: " + functionName);
        System.out.println("当前调用栈: " + callStack);
    }
    
    public void exitFunction() {
        if (!callStack.isEmpty()) {
            String functionName = callStack.pop();
            System.out.println("退出函数: " + functionName);
            System.out.println("当前调用栈: " + callStack);
        }
    }
    
    public void showCallStack() {
        System.out.println("完整调用栈: " + callStack);
    }
}
```

## 🔍 栈与其他数据结构的对比
| 特性 | 栈 | 队列 | 数组 | 链表 |
| --- | --- | --- | --- | --- |
| **访问方式** | 只能访问栈顶 | 只能访问队头队尾 | 随机访问 | 顺序访问 |
| **插入位置** | 栈顶 | 队尾 | 任意位置 | 任意位置 |
| **删除位置** | 栈顶 | 队头 | 任意位置 | 任意位置 |
| **时间复杂度** | O(1) | O(1) | O(1)/O(n) | O(1)/O(n) |
| **应用场景** | 递归、回溯 | BFS、缓冲 | 随机访问 | 动态插删 |


## 🚀 栈的优势与局限性
### 优势
1. **操作简单**：只有几个基本操作，易于理解和实现
2. **效率高**：所有基本操作都是O(1)时间复杂度
3. **内存友好**：连续内存分配，缓存友好
4. **自然递归**：天然适合处理递归问题

### 局限性
1. **访问受限**：只能访问栈顶元素
2. **容量限制**：基于数组的实现有固定容量
3. **不支持随机访问**：无法直接访问中间元素
4. **栈溢出风险**：递归过深可能导致栈溢出

## 💡 学习要点总结
### 1. 核心概念
+ **LIFO原则**：后进先出是栈的根本特性
+ **栈顶操作**：所有操作都在栈顶进行
+ **状态管理**：通过栈顶指针管理栈的状态

### 2. 实现要点
+ **边界检查**：防止栈溢出和栈下溢
+ **内存管理**：及时清理出栈元素避免内存泄漏
+ **异常处理**：合理处理空栈操作

### 3. 应用思路
+ **匹配问题**：利用LIFO特性处理成对匹配
+ **逆序问题**：天然的逆序处理工具
+ **状态保存**：保存和恢复程序状态

### 4. 选择建议
+ **Java推荐**：使用`Deque<T> stack = new ArrayDeque<>()`
+ **避免使用**：`Stack`类（线程安全但性能较差）
+ **容量规划**：根据实际需求选择合适的初始容量
