# 栈的结构特性与记忆方法
## 栈的核心概念
### 1. 栈的本质 - "盘子堆叠"模型
想象一下餐厅里洗好的盘子是如何堆叠的：

```plain
    ┌─────────┐  ← 栈顶 (Top) - 最后放入的盘子
    │  盘子3  │
    ├─────────┤
    │  盘子2  │
    ├─────────┤
    │  盘子1  │  ← 栈底 (Bottom) - 最先放入的盘子
    └─────────┘
```

**核心特性：LIFO (Last In, First Out) - 后进先出**

+ 最后放入的盘子，最先被取走
+ 只能从顶部操作，不能从中间或底部取盘子

## 栈的三大核心操作
### 1. push() - "推入/压入" 📥
**记忆方法：** 想象用手"推"一个盘子到堆叠的顶部

```java
// push操作示意
Stack<Integer> stack = new Stack<>();

// 初始状态：空栈
// []

stack.push(1);
// [1] ← 栈顶

stack.push(2);
// [1, 2] ← 栈顶

stack.push(3);
// [1, 2, 3] ← 栈顶
```

**记忆口诀：** "Push推上去，新元素在顶部"

### 2. pop() - "弹出/取出" 📤
**记忆方法：** 想象盘子从顶部"弹"出来，就像弹簧一样

```java
// pop操作示意
// 当前栈状态：[1, 2, 3] ← 栈顶

Integer top = stack.pop();  // 返回并移除栈顶元素
// top = 3
// 栈变为：[1, 2] ← 栈顶

Integer second = stack.pop();
// second = 2  
// 栈变为：[1] ← 栈顶
```

**记忆口诀：** "Pop弹出来，拿走顶部元素"

### 3. peek() - "偷看/窥视" 👀
**记忆方法：** 想象你只是"偷看"一眼顶部的盘子，但不拿走

```java
// peek操作示意
// 当前栈状态：[1, 2, 3] ← 栈顶

Integer top = stack.peek();  // 只查看，不移除
// top = 3
// 栈仍然是：[1, 2, 3] ← 栈顶（没有变化）

// 可以多次peek，结果都一样
Integer stillTop = stack.peek();
// stillTop = 3
```

**记忆口诀：** "Peek偷偷看，只看不拿走"

## 形象记忆法
### 1. 餐厅服务员模型
```java
public class RestaurantStack {
    // 想象你是餐厅服务员，手里拿着一摞盘子
    
    public void addPlate(String plate) {
        // push：在最顶部放一个新盘子
        stack.push(plate);
        System.out.println("放入盘子：" + plate + "（在最顶部）");
    }
    
    public String takePlate() {
        // pop：从最顶部拿走一个盘子
        String plate = stack.pop();
        System.out.println("拿走盘子：" + plate + "（从最顶部）");
        return plate;
    }
    
    public String checkTopPlate() {
        // peek：看看最顶部是什么盘子，但不拿走
        String plate = stack.peek();
        System.out.println("查看顶部盘子：" + plate + "（只看不拿）");
        return plate;
    }
}
```

### 2. 浏览器历史记录模型
```java
public class BrowserHistory {
    private Deque<String> history = new ArrayDeque<>();
    
    public void visitPage(String url) {
        // push：访问新页面，加入历史记录顶部
        history.push(url);
        System.out.println("访问页面：" + url);
    }
    
    public String goBack() {
        // pop：后退，移除当前页面，返回上一页
        if (!history.isEmpty()) {
            String currentPage = history.pop();
            System.out.println("从 " + currentPage + " 后退");
            return history.isEmpty() ? "首页" : history.peek();
        }
        return "首页";
    }
    
    public String getCurrentPage() {
        // peek：查看当前页面，不改变历史记录
        return history.isEmpty() ? "首页" : history.peek();
    }
}
```

## 常见错误与记忆技巧
### 1. 容易混淆的地方
```java
// ❌ 常见错误思维
// 以为pop()只是查看，peek()是移除

// ✅ 正确记忆
// pop = 弹出 = 拿走（有动作，会改变栈）
// peek = 偷看 = 只看（无动作，不改变栈）
```

### 2. 记忆助手
**英文联想：**

+ **Push** → 推 → 向上推入
+ **Pop** → 爆炸/弹出 → 元素"爆"出来了
+ **Peek** → 偷看 → 只是看一眼

**中文对应：**

+ Push → 压栈/入栈
+ Pop → 出栈/弹栈  
+ Peek → 查看栈顶

## 实际代码示例
### 1. 基本操作演示
```java
public class StackDemo {
    public static void main(String[] args) {
        Deque<String> stack = new ArrayDeque<>();
        
        // 演示push操作
        System.out.println("=== Push操作演示 ===");
        stack.push("第一本书");
        System.out.println("放入：第一本书，栈：" + stack);
        
        stack.push("第二本书");
        System.out.println("放入：第二本书，栈：" + stack);
        
        stack.push("第三本书");
        System.out.println("放入：第三本书，栈：" + stack);
        
        // 演示peek操作
        System.out.println("\n=== Peek操作演示 ===");
        String top = stack.peek();
        System.out.println("查看栈顶：" + top);
        System.out.println("栈没有变化：" + stack);
        
        // 再次peek
        String stillTop = stack.peek();
        System.out.println("再次查看：" + stillTop);
        System.out.println("栈仍然没变：" + stack);
        
        // 演示pop操作
        System.out.println("\n=== Pop操作演示 ===");
        String removed1 = stack.pop();
        System.out.println("弹出：" + removed1 + "，栈变为：" + stack);
        
        String removed2 = stack.pop();
        System.out.println("弹出：" + removed2 + "，栈变为：" + stack);
        
        String removed3 = stack.pop();
        System.out.println("弹出：" + removed3 + "，栈变为：" + stack);
    }
}
```

### 2. 实际应用场景
#### 括号匹配检查
```java
public class BracketChecker {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                // push：遇到左括号，压入栈
                stack.push(c);
            } else if (c == ')' || c == ']' || c == '}') {
                if (stack.isEmpty()) return false;
                
                // pop：遇到右括号，弹出栈顶进行匹配
                char left = stack.pop();
                if (!isMatching(left, c)) return false;
            }
        }
        
        return stack.isEmpty();
    }
    
    private boolean isMatching(char left, char right) {
        return (left == '(' && right == ')') ||
               (left == '[' && right == ']') ||
               (left == '{' && right == '}');
    }
}
```

#### 计算器表达式求值
```java
public class Calculator {
    public int calculate(String expression) {
        Deque<Integer> stack = new ArrayDeque<>();
        char operator = '+';
        int num = 0;
        
        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            }
            
            if (c == '+' || c == '-' || c == '*' || c == '/' || i == expression.length() - 1) {
                switch (operator) {
                    case '+':
                        stack.push(num);  // 加法：直接压栈
                        break;
                    case '-':
                        stack.push(-num); // 减法：压入负数
                        break;
                    case '*':
                        // 乘法：弹出栈顶，计算后压回
                        stack.push(stack.pop() * num);
                        break;
                    case '/':
                        // 除法：弹出栈顶，计算后压回
                        stack.push(stack.pop() / num);
                        break;
                }
                operator = c;
                num = 0;
            }
        }
        
        // 最后把栈中所有数字相加
        int result = 0;
        while (!stack.isEmpty()) {
            result += stack.pop();
        }
        return result;
    }
}
```

## 记忆检查清单
### 快速自测
1. **push做什么？**
    - [x] 添加元素到栈顶
    - [x] 会改变栈的大小
    - [ ] 无返回值（void）
2. **pop做什么？**
    - [x] 移除并返回栈顶元素
    - [ ] 会改变栈的大小
    - [x] 有返回值
3. **peek做什么？**
    - [x] 只查看栈顶元素
    - [x] 不改变栈的大小
    - [ ] 有返回值

### 记忆口诀总结
```plain
栈像盘子摞一摞，
只能顶部来操作。

Push推入在顶部，
Pop弹出拿走它，
Peek偷看不拿走，
后进先出要记牢！
```
