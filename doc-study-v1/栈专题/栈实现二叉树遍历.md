# 栈实现二叉树遍历
## 概述
栈是一种后进先出（LIFO）的数据结构，非常适合用来模拟递归过程。在二叉树遍历中，我们可以使用栈来替代递归调用，实现迭代版本的遍历算法。

## 栈的基本操作
```java
import java.util.Stack;

// 栈的基本操作
Stack<TreeNode> stack = new Stack<>();
stack.push(node);    // 入栈
TreeNode node = stack.pop();    // 出栈
TreeNode top = stack.peek();    // 查看栈顶元素
boolean isEmpty = stack.isEmpty();    // 判断栈是否为空
```

## 二叉树节点定义
```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

## 前序遍历（栈实现）
前序遍历的顺序是：根 → 左 → 右

```java
import java.util.*;

public List<Integer> preorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    
    Stack<TreeNode> stack = new Stack<>();
    stack.push(root);
    
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.add(node.val);  // 访问根节点
        
        // 关键：先压右子树，再压左子树
        // 这样出栈时就是先左后右
        if (node.right != null) {
            stack.push(node.right);
        }
        if (node.left != null) {
            stack.push(node.left);
        }
    }
    
    return result;
}
```

**栈的作用**：

+ 保存待访问的节点
+ 通过先压右子树再压左子树，确保左子树先被处理

## 中序遍历（栈实现）
中序遍历的顺序是：左 → 根 → 右

```java
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Stack<TreeNode> stack = new Stack<>();
    TreeNode current = root;
    
    while (current != null || !stack.isEmpty()) {
        // 一直向左走，将路径上的节点压栈
        while (current != null) {
            stack.push(current);
            current = current.left;
        }
        
        // 弹出栈顶节点并访问
        current = stack.pop();
        result.add(current.val);
        
        // 转向右子树
        current = current.right;
    }
    
    return result;
}
```

**栈的作用**：

+ 保存从根到当前节点的路径
+ 当到达最左节点时，从栈中弹出节点进行访问

## 后序遍历（栈实现）
后序遍历的顺序是：左 → 右 → 根

### 方法一：单栈 + 标记法
```java
public List<Integer> postorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    
    Stack<TreeNode> stack = new Stack<>();
    TreeNode lastVisited = null;
    TreeNode current = root;
    
    while (current != null || !stack.isEmpty()) {
        if (current != null) {
            // 向左走到底
            stack.push(current);
            current = current.left;
        } else {
            // 查看栈顶节点
            TreeNode peekNode = stack.peek();
            
            // 如果右子树存在且未被访问，转向右子树
            if (peekNode.right != null && lastVisited != peekNode.right) {
                current = peekNode.right;
            } else {
                // 访问节点
                result.add(peekNode.val);
                lastVisited = stack.pop();
            }
        }
    }
    
    return result;
}
```

### 方法二：双栈法
```java
public List<Integer> postorderTraversalTwoStacks(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    
    Stack<TreeNode> stack1 = new Stack<>();  // 遍历栈
    Stack<TreeNode> stack2 = new Stack<>();  // 结果栈
    
    stack1.push(root);
    
    while (!stack1.isEmpty()) {
        TreeNode node = stack1.pop();
        stack2.push(node);
        
        // 先压左子树，再压右子树
        // 得到 根→右→左 的顺序
        if (node.left != null) {
            stack1.push(node.left);
        }
        if (node.right != null) {
            stack1.push(node.right);
        }
    }
    
    // 从第二个栈弹出，得到后序遍历结果
    while (!stack2.isEmpty()) {
        result.add(stack2.pop().val);
    }
    
    return result;
}
```

**栈的作用**：

+ 单栈法：使用lastVisited标记避免重复访问右子树
+ 双栈法：第一个栈用于遍历，第二个栈用于反转顺序

## 栈在遍历中的核心思想
1. **模拟递归**：栈保存了递归调用的上下文信息
2. **控制访问顺序**：通过入栈顺序控制节点的访问顺序
3. **状态保存**：栈保存了遍历过程中的中间状态

## 复杂度分析
| 遍历方式 | 时间复杂度 | 空间复杂度 | 栈最大深度 |
| --- | --- | --- | --- |
| 前序遍历 | O(n) | O(h) | h（树的高度） |
| 中序遍历 | O(n) | O(h) | h（树的高度） |
| 后序遍历（单栈） | O(n) | O(h) | h（树的高度） |
| 后序遍历（双栈） | O(n) | O(n) | n（节点数量） |


## 栈溢出问题
对于极深的树（如链状树），可能导致栈溢出：

```java
// 检查栈深度的示例
public int getMaxStackDepth(TreeNode root) {
    if (root == null) return 0;
    
    Stack<TreeNode> stack = new Stack<>();
    int maxDepth = 0;
    TreeNode current = root;
    
    while (current != null || !stack.isEmpty()) {
        while (current != null) {
            stack.push(current);
            maxDepth = Math.max(maxDepth, stack.size());
            current = current.left;
        }
        current = stack.pop().right;
    }
    
    return maxDepth;
}
```

## 数据结构选择对比
### Stack vs Deque 内存性能分析
| 实现方式 | 基础开销 | 每元素开销 | 缓存友好性 | 推荐度 |
| --- | --- | --- | --- | --- |
| `new Stack<>()` | 60-80字节 | 8字节 | 好 | ❌ 不推荐 |
| `new LinkedList<>()` | 32-36字节 | 36-40字节 | 差 | ❌ 不推荐 |
| `new ArrayDeque<>()` | 92-96字节 | 8字节 | 好 | ✅ 强烈推荐 |


### 详细对比分析
#### 1. Stack类的问题
```java
// 不推荐的写法
Stack<TreeNode> stack = new Stack<>();
```

**问题：**

+ 继承自Vector，携带同步开销
+ 所有方法都是synchronized，单线程下性能损失
+ 设计过时，官方不推荐使用

#### 2. LinkedList的问题
```java
// 内存效率低的写法
Deque<TreeNode> stack = new LinkedList<>();
```

**问题：**

+ 每个节点额外36-40字节开销
+ 内存分散，缓存命中率低
+ 指针追踪影响性能

#### 3. ArrayDeque的优势
```java
// 推荐的写法
Deque<TreeNode> stack = new ArrayDeque<>();
```

**优势：**

+ 无同步开销，性能最佳
+ 数组实现，内存连续，缓存友好
+ 动态扩容策略优化

```java
    private static List<Integer> preorderWithStack(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Stack<TreeNode> stack = new Stack<>();

            TreeNode node = stack.pop();

        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.add(node.val);
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
        return result;
    }
```

## 优化技巧
1. **使用ArrayDeque替代Stack**


2. **预估容量避免扩容**

3. **内存优化的遍历实现**

```java
public List<Integer> optimizedPreorder(TreeNode root) {
    if (root == null) return new ArrayList<>();
    
    List<Integer> result = new ArrayList<>();
    // 使用ArrayDeque，预估容量
    Deque<TreeNode> stack = new ArrayDeque<>(32);
    stack.push(root);
    
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.add(node.val);
        
        // 先右后左，保证左子树先处理
        if (node.right != null) stack.push(node.right);
        if (node.left != null) stack.push(node.left);
    }
    
    return result;
}
```

4. **迭代器模式**

```java
public class TreeIterator implements Iterator<Integer> {
    private Deque<TreeNode> stack = new ArrayDeque<>();
    
    public TreeIterator(TreeNode root) {
        pushLeft(root);
    }
    
    private void pushLeft(TreeNode node) {
        while (node != null) {
            stack.push(node);
            node = node.left;
        }
    }
    
    @Override
    public boolean hasNext() {
        return !stack.isEmpty();
    }
    
    @Override
    public Integer next() {
        TreeNode node = stack.pop();
        pushLeft(node.right);
        return node.val;
    }
}
```
