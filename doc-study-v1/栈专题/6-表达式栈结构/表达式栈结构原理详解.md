# 表达式栈结构原理详解
## 📚 表达式栈的基本概念
### 什么是表达式栈？
表达式栈（Expression Stack）是专门用于**处理数学表达式求值、转换和解析**的栈结构。它是编译器、计算器和数学表达式处理系统的核心组件。

### 表达式的三种表示法
```plain
中缀表达式（Infix）：   3 + 4 * 2
前缀表达式（Prefix）：  + 3 * 4 2
后缀表达式（Postfix）： 3 4 2 * +

转换关系：
中缀 → 后缀 → 求值
  ↓      ↑
  前缀 ←──┘
```

### 为什么需要表达式栈？
1. **运算符优先级处理**：自动处理复杂的优先级规则
2. **括号匹配**：正确处理嵌套的括号结构
3. **表达式转换**：在不同表示法间转换
4. **高效求值**：避免重复解析，提高计算效率

## 🔧 表达式栈的核心算法
### 1. 中缀表达式转后缀表达式（调度场算法）
**核心思想：** 使用操作符栈来处理运算符的优先级和结合性

```java
/**
 * 中缀表达式转后缀表达式
 * 使用Dijkstra的调度场算法（Shunting Yard Algorithm）
 */
public class InfixToPostfixConverter {
    
    // 运算符优先级映射
    private static final Map<Character, Integer> PRECEDENCE = Map.of(
        '+', 1, '-', 1,
        '*', 2, '/', 2,
        '^', 3
    );
    
    // 右结合运算符
    private static final Set<Character> RIGHT_ASSOCIATIVE = Set.of('^');
    
    public String infixToPostfix(String infix) {
        StringBuilder postfix = new StringBuilder();
        Deque<Character> operatorStack = new ArrayDeque<>();
        
        for (char token : infix.toCharArray()) {
            if (Character.isWhitespace(token)) {
                continue;
            }
            
            if (Character.isDigit(token) || Character.isLetter(token)) {
                // 操作数直接输出
                postfix.append(token).append(' ');
                
            } else if (token == '(') {
                // 左括号入栈
                operatorStack.push(token);
                
            } else if (token == ')') {
                // 右括号：弹出直到遇到左括号
                while (!operatorStack.isEmpty() && operatorStack.peek() != '(') {
                    postfix.append(operatorStack.pop()).append(' ');
                }
                operatorStack.pop(); // 弹出左括号
                
            } else if (isOperator(token)) {
                // 运算符：根据优先级和结合性处理
                while (!operatorStack.isEmpty() && 
                       shouldPopOperator(operatorStack.peek(), token)) {
                    postfix.append(operatorStack.pop()).append(' ');
                }
                operatorStack.push(token);
            }
        }
        
        // 弹出剩余的运算符
        while (!operatorStack.isEmpty()) {
            postfix.append(operatorStack.pop()).append(' ');
        }
        
        return postfix.toString().trim();
    }
    
    private boolean isOperator(char c) {
        return PRECEDENCE.containsKey(c);
    }
    
    private boolean shouldPopOperator(char stackTop, char current) {
        if (stackTop == '(') return false;
        
        int stackPrec = PRECEDENCE.getOrDefault(stackTop, 0);
        int currentPrec = PRECEDENCE.getOrDefault(current, 0);
        
        // 左结合：栈顶优先级 >= 当前优先级
        // 右结合：栈顶优先级 > 当前优先级
        if (RIGHT_ASSOCIATIVE.contains(current)) {
            return stackPrec > currentPrec;
        } else {
            return stackPrec >= currentPrec;
        }
    }
}
```

**算法执行过程图解：**

```plain
转换表达式：3 + 4 * 2 - 1

步骤1：读取 '3'
输出：3 
栈：[]

步骤2：读取 '+'
输出：3 
栈：[+]

步骤3：读取 '4'
输出：3 4 
栈：[+]

步骤4：读取 '*'
输出：3 4 
栈：[+, *]  (* 优先级高于 +)

步骤5：读取 '2'
输出：3 4 2 
栈：[+, *]

步骤6：读取 '-'
输出：3 4 2 * +   (弹出 * 和 +，因为 - 优先级不高于它们)
栈：[-]

步骤7：读取 '1'
输出：3 4 2 * + 1 
栈：[-]

步骤8：表达式结束
输出：3 4 2 * + 1 -   (弹出剩余的 -)
栈：[]

最终结果：3 4 2 * + 1 -
```

### 2. 后缀表达式求值
**核心思想：** 使用操作数栈，遇到运算符时弹出操作数进行计算

```java
/**
 * 后缀表达式求值器
 */
public class PostfixEvaluator {
    
    public double evaluate(String postfix) {
        Deque<Double> operandStack = new ArrayDeque<>();
        String[] tokens = postfix.split("\\s+");
        
        for (String token : tokens) {
            if (isNumber(token)) {
                // 操作数入栈
                operandStack.push(Double.parseDouble(token));
                
            } else if (isOperator(token.charAt(0))) {
                // 运算符：弹出操作数计算
                if (operandStack.size() < 2) {
                    throw new IllegalArgumentException("Invalid expression");
                }
                
                double operand2 = operandStack.pop();
                double operand1 = operandStack.pop();
                double result = performOperation(operand1, operand2, token.charAt(0));
                
                operandStack.push(result);
            }
        }
        
        if (operandStack.size() != 1) {
            throw new IllegalArgumentException("Invalid expression");
        }
        
        return operandStack.pop();
    }
    
    private boolean isNumber(String token) {
        try {
            Double.parseDouble(token);
            return true;
        } catch (NumberFormatException e) {
            return false;
        }
    }
    
    private boolean isOperator(char c) {
        return "+-*/^".indexOf(c) != -1;
    }
    
    private double performOperation(double operand1, double operand2, char operator) {
        switch (operator) {
            case '+': return operand1 + operand2;
            case '-': return operand1 - operand2;
            case '*': return operand1 * operand2;
            case '/': 
                if (operand2 == 0) throw new ArithmeticException("Division by zero");
                return operand1 / operand2;
            case '^': return Math.pow(operand1, operand2);
            default: throw new IllegalArgumentException("Unknown operator: " + operator);
        }
    }
}
```

**求值过程图解：**

```plain
计算后缀表达式：3 4 2 * + 1 -

步骤1：读取 '3'
栈：[3]

步骤2：读取 '4'
栈：[3, 4]

步骤3：读取 '2'
栈：[3, 4, 2]

步骤4：读取 '*'
弹出 2 和 4，计算 4 * 2 = 8，结果入栈
栈：[3, 8]

步骤5：读取 '+'
弹出 8 和 3，计算 3 + 8 = 11，结果入栈
栈：[11]

步骤6：读取 '1'
栈：[11, 1]

步骤7：读取 '-'
弹出 1 和 11，计算 11 - 1 = 10，结果入栈
栈：[10]

最终结果：10
```

### 3. 中缀表达式直接求值
**核心思想：** 使用两个栈（操作数栈和运算符栈）同时处理

```java
/**
 * 中缀表达式直接求值器
 */
public class InfixEvaluator {
    
    private static final Map<Character, Integer> PRECEDENCE = Map.of(
        '+', 1, '-', 1,
        '*', 2, '/', 2,
        '^', 3
    );
    
    public double evaluate(String expression) {
        Deque<Double> operandStack = new ArrayDeque<>();
        Deque<Character> operatorStack = new ArrayDeque<>();
        
        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            
            if (Character.isWhitespace(c)) {
                continue;
            }
            
            if (Character.isDigit(c)) {
                // 解析完整的数字
                StringBuilder number = new StringBuilder();
                while (i < expression.length() && 
                       (Character.isDigit(expression.charAt(i)) || 
                        expression.charAt(i) == '.')) {
                    number.append(expression.charAt(i++));
                }
                i--; // 回退一位
                operandStack.push(Double.parseDouble(number.toString()));
                
            } else if (c == '(') {
                operatorStack.push(c);
                
            } else if (c == ')') {
                // 计算直到遇到左括号
                while (!operatorStack.isEmpty() && operatorStack.peek() != '(') {
                    performOperation(operandStack, operatorStack);
                }
                operatorStack.pop(); // 弹出左括号
                
            } else if (isOperator(c)) {
                // 处理运算符优先级
                while (!operatorStack.isEmpty() && 
                       hasHigherPrecedence(operatorStack.peek(), c)) {
                    performOperation(operandStack, operatorStack);
                }
                operatorStack.push(c);
            }
        }
        
        // 处理剩余的运算符
        while (!operatorStack.isEmpty()) {
            performOperation(operandStack, operatorStack);
        }
        
        return operandStack.pop();
    }
    
    private void performOperation(Deque<Double> operandStack, 
                                 Deque<Character> operatorStack) {
        if (operandStack.size() < 2 || operatorStack.isEmpty()) {
            throw new IllegalArgumentException("Invalid expression");
        }
        
        double operand2 = operandStack.pop();
        double operand1 = operandStack.pop();
        char operator = operatorStack.pop();
        
        double result = calculate(operand1, operand2, operator);
        operandStack.push(result);
    }
    
    private double calculate(double operand1, double operand2, char operator) {
        switch (operator) {
            case '+': return operand1 + operand2;
            case '-': return operand1 - operand2;
            case '*': return operand1 * operand2;
            case '/': 
                if (operand2 == 0) throw new ArithmeticException("Division by zero");
                return operand1 / operand2;
            case '^': return Math.pow(operand1, operand2);
            default: throw new IllegalArgumentException("Unknown operator: " + operator);
        }
    }
    
    private boolean isOperator(char c) {
        return PRECEDENCE.containsKey(c);
    }
    
    private boolean hasHigherPrecedence(char stackTop, char current) {
        if (stackTop == '(') return false;
        
        int stackPrec = PRECEDENCE.getOrDefault(stackTop, 0);
        int currentPrec = PRECEDENCE.getOrDefault(current, 0);
        
        return stackPrec >= currentPrec;
    }
}
```

### 4. 带函数的表达式求值
```java
/**
 * 支持函数的表达式求值器
 */
public class FunctionExpressionEvaluator {
    
    private static final Map<String, Function<Double, Double>> FUNCTIONS = Map.of(
        "sin", Math::sin,
        "cos", Math::cos,
        "tan", Math::tan,
        "log", Math::log,
        "sqrt", Math::sqrt,
        "abs", Math::abs
    );
    
    public double evaluate(String expression) {
        Deque<Double> operandStack = new ArrayDeque<>();
        Deque<Object> operatorStack = new ArrayDeque<>(); // 可以存储运算符或函数
        
        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            
            if (Character.isWhitespace(c)) {
                continue;
            }
            
            if (Character.isDigit(c)) {
                // 解析数字
                i = parseNumber(expression, i, operandStack) - 1;
                
            } else if (Character.isLetter(c)) {
                // 解析函数名
                i = parseFunction(expression, i, operatorStack) - 1;
                
            } else if (c == '(') {
                operatorStack.push(c);
                
            } else if (c == ')') {
                // 处理括号内的表达式
                while (!operatorStack.isEmpty() && 
                       !operatorStack.peek().equals('(')) {
                    performOperation(operandStack, operatorStack);
                }
                operatorStack.pop(); // 弹出左括号
                
                // 检查是否有函数需要执行
                if (!operatorStack.isEmpty() && 
                    operatorStack.peek() instanceof String) {
                    performFunction(operandStack, operatorStack);
                }
                
            } else if (isOperator(c)) {
                while (!operatorStack.isEmpty() && 
                       hasHigherPrecedence(operatorStack.peek(), c)) {
                    performOperation(operandStack, operatorStack);
                }
                operatorStack.push(c);
            }
        }
        
        while (!operatorStack.isEmpty()) {
            performOperation(operandStack, operatorStack);
        }
        
        return operandStack.pop();
    }
    
    private int parseNumber(String expression, int start, Deque<Double> operandStack) {
        StringBuilder number = new StringBuilder();
        int i = start;
        
        while (i < expression.length() && 
               (Character.isDigit(expression.charAt(i)) || 
                expression.charAt(i) == '.')) {
            number.append(expression.charAt(i++));
        }
        
        operandStack.push(Double.parseDouble(number.toString()));
        return i;
    }
    
    private int parseFunction(String expression, int start, Deque<Object> operatorStack) {
        StringBuilder function = new StringBuilder();
        int i = start;
        
        while (i < expression.length() && Character.isLetter(expression.charAt(i))) {
            function.append(expression.charAt(i++));
        }
        
        String funcName = function.toString();
        if (FUNCTIONS.containsKey(funcName)) {
            operatorStack.push(funcName);
        } else {
            throw new IllegalArgumentException("Unknown function: " + funcName);
        }
        
        return i;
    }
    
    private void performFunction(Deque<Double> operandStack, Deque<Object> operatorStack) {
        if (operandStack.isEmpty() || operatorStack.isEmpty()) {
            throw new IllegalArgumentException("Invalid function call");
        }
        
        String funcName = (String) operatorStack.pop();
        double operand = operandStack.pop();
        
        Function<Double, Double> function = FUNCTIONS.get(funcName);
        double result = function.apply(operand);
        
        operandStack.push(result);
    }
    
    private void performOperation(Deque<Double> operandStack, Deque<Object> operatorStack) {
        if (operandStack.size() < 2 || operatorStack.isEmpty()) {
            return;
        }
        
        Object op = operatorStack.pop();
        if (op instanceof Character) {
            double operand2 = operandStack.pop();
            double operand1 = operandStack.pop();
            char operator = (Character) op;
            
            double result = calculate(operand1, operand2, operator);
            operandStack.push(result);
        }
    }
    
    private double calculate(double operand1, double operand2, char operator) {
        switch (operator) {
            case '+': return operand1 + operand2;
            case '-': return operand1 - operand2;
            case '*': return operand1 * operand2;
            case '/': 
                if (operand2 == 0) throw new ArithmeticException("Division by zero");
                return operand1 / operand2;
            case '^': return Math.pow(operand1, operand2);
            default: throw new IllegalArgumentException("Unknown operator: " + operator);
        }
    }
    
    private boolean isOperator(char c) {
        return "+-*/^".indexOf(c) != -1;
    }
    
    private boolean hasHigherPrecedence(Object stackTop, char current) {
        if (!(stackTop instanceof Character) || stackTop.equals('(')) {
            return false;
        }
        
        char stackOp = (Character) stackTop;
        return getPrecedence(stackOp) >= getPrecedence(current);
    }
    
    private int getPrecedence(char operator) {
        switch (operator) {
            case '+': case '-': return 1;
            case '*': case '/': return 2;
            case '^': return 3;
            default: return 0;
        }
    }
}
```

### 1. 表达式语法树构建
```java
/**
 * 表达式语法树节点
 */
class ExpressionNode {
    String value;
    ExpressionNode left;
    ExpressionNode right;
    
    ExpressionNode(String value) {
        this.value = value;
    }
    
    boolean isOperator() {
        return "+-*/^".contains(value);
    }
}

/**
 * 从后缀表达式构建语法树
 */
public class ExpressionTreeBuilder {
    
    public ExpressionNode buildFromPostfix(String postfix) {
        Deque<ExpressionNode> stack = new ArrayDeque<>();
        String[] tokens = postfix.split("\\s+");
        
        for (String token : tokens) {
            ExpressionNode node = new ExpressionNode(token);
            
            if (node.isOperator()) {
                // 运算符节点：弹出两个操作数作为子节点
                node.right = stack.pop();
                node.left = stack.pop();
            }
            
            stack.push(node);
        }
        
        return stack.pop();
    }
    
    /**
     * 从语法树求值
     */
    public double evaluate(ExpressionNode root) {
        if (root == null) return 0;
        
        if (!root.isOperator()) {
            // 叶子节点：返回数值
            return Double.parseDouble(root.value);
        }
        
        // 内部节点：递归计算子树
        double leftVal = evaluate(root.left);
        double rightVal = evaluate(root.right);
        
        switch (root.value.charAt(0)) {
            case '+': return leftVal + rightVal;
            case '-': return leftVal - rightVal;
            case '*': return leftVal * rightVal;
            case '/': return leftVal / rightVal;
            case '^': return Math.pow(leftVal, rightVal);
            default: throw new IllegalArgumentException("Unknown operator");
        }
    }
    
    /**
     * 语法树可视化
     */
    public void printTree(ExpressionNode root, String prefix, boolean isLast) {
        if (root == null) return;
        
        System.out.println(prefix + (isLast ? "└── " : "├── ") + root.value);
        
        if (root.left != null || root.right != null) {
            if (root.left != null) {
                printTree(root.left, prefix + (isLast ? "    " : "│   "), 
                         root.right == null);
            }
            if (root.right != null) {
                printTree(root.right, prefix + (isLast ? "    " : "│   "), true);
            }
        }
    }
}
```

### 2. 表达式优化器
```java
/**
 * 表达式优化器
 */
public class ExpressionOptimizer {
    
    /**
     * 常量折叠优化
     */
    public ExpressionNode constantFolding(ExpressionNode root) {
        if (root == null || !root.isOperator()) {
            return root;
        }
        
        // 递归优化子树
        root.left = constantFolding(root.left);
        root.right = constantFolding(root.right);
        
        // 如果两个子节点都是常量，则计算结果
        if (!root.left.isOperator() && !root.right.isOperator()) {
            double leftVal = Double.parseDouble(root.left.value);
            double rightVal = Double.parseDouble(root.right.value);
            double result = calculate(leftVal, rightVal, root.value.charAt(0));
            
            return new ExpressionNode(String.valueOf(result));
        }
        
        return root;
    }
    
    /**
     * 代数简化
     */
    public ExpressionNode algebraicSimplification(ExpressionNode root) {
        if (root == null || !root.isOperator()) {
            return root;
        }
        
        // 递归简化子树
        root.left = algebraicSimplification(root.left);
        root.right = algebraicSimplification(root.right);
        
        char op = root.value.charAt(0);
        
        // 应用简化规则
        switch (op) {
            case '+':
                // x + 0 = x, 0 + x = x
                if (isZero(root.left)) return root.right;
                if (isZero(root.right)) return root.left;
                break;
                
            case '-':
                // x - 0 = x
                if (isZero(root.right)) return root.left;
                // x - x = 0
                if (areEqual(root.left, root.right)) {
                    return new ExpressionNode("0");
                }
                break;
                
            case '*':
                // x * 0 = 0, 0 * x = 0
                if (isZero(root.left) || isZero(root.right)) {
                    return new ExpressionNode("0");
                }
                // x * 1 = x, 1 * x = x
                if (isOne(root.left)) return root.right;
                if (isOne(root.right)) return root.left;
                break;
                
            case '/':
                // x / 1 = x
                if (isOne(root.right)) return root.left;
                // x / x = 1
                if (areEqual(root.left, root.right)) {
                    return new ExpressionNode("1");
                }
                break;
                
            case '^':
                // x ^ 0 = 1
                if (isZero(root.right)) return new ExpressionNode("1");
                // x ^ 1 = x
                if (isOne(root.right)) return root.left;
                break;
        }
        
        return root;
    }
    
    private boolean isZero(ExpressionNode node) {
        return !node.isOperator() && "0".equals(node.value);
    }
    
    private boolean isOne(ExpressionNode node) {
        return !node.isOperator() && "1".equals(node.value);
    }
    
    private boolean areEqual(ExpressionNode node1, ExpressionNode node2) {
        if (node1.isOperator() != node2.isOperator()) {
            return false;
        }
        
        if (!node1.isOperator()) {
            return node1.value.equals(node2.value);
        }
        
        return node1.value.equals(node2.value) &&
               areEqual(node1.left, node2.left) &&
               areEqual(node1.right, node2.right);
    }
    
    private double calculate(double left, double right, char operator) {
        switch (operator) {
            case '+': return left + right;
            case '-': return left - right;
            case '*': return left * right;
            case '/': return left / right;
            case '^': return Math.pow(left, right);
            default: throw new IllegalArgumentException("Unknown operator");
        }
    }
}
```

### 3. 表达式求导器
```java
/**
 * 符号微分计算器
 */
public class ExpressionDerivative {
    
    /**
     * 对表达式求导
     * @param root 表达式树根节点
     * @param variable 求导变量
     * @return 导数表达式树
     */
    public ExpressionNode derivative(ExpressionNode root, String variable) {
        if (root == null) {
            return new ExpressionNode("0");
        }
        
        if (!root.isOperator()) {
            // 常量的导数为0，变量的导数为1
            return root.value.equals(variable) ? 
                   new ExpressionNode("1") : new ExpressionNode("0");
        }
        
        char op = root.value.charAt(0);
        ExpressionNode left = root.left;
        ExpressionNode right = root.right;
        
        switch (op) {
            case '+':
            case '-':
                // (u ± v)' = u' ± v'
                ExpressionNode result = new ExpressionNode(String.valueOf(op));
                result.left = derivative(left, variable);
                result.right = derivative(right, variable);
                return result;
                
            case '*':
                // (u * v)' = u' * v + u * v'
                ExpressionNode term1 = new ExpressionNode("*");
                term1.left = derivative(left, variable);
                term1.right = copyNode(right);
                
                ExpressionNode term2 = new ExpressionNode("*");
                term2.left = copyNode(left);
                term2.right = derivative(right, variable);
                
                ExpressionNode sum = new ExpressionNode("+");
                sum.left = term1;
                sum.right = term2;
                return sum;
                
            case '/':
                // (u / v)' = (u' * v - u * v') / v^2
                ExpressionNode numerator = new ExpressionNode("-");
                
                ExpressionNode leftTerm = new ExpressionNode("*");
                leftTerm.left = derivative(left, variable);
                leftTerm.right = copyNode(right);
                
                ExpressionNode rightTerm = new ExpressionNode("*");
                rightTerm.left = copyNode(left);
                rightTerm.right = derivative(right, variable);
                
                numerator.left = leftTerm;
                numerator.right = rightTerm;
                
                ExpressionNode denominator = new ExpressionNode("^");
                denominator.left = copyNode(right);
                denominator.right = new ExpressionNode("2");
                
                ExpressionNode quotient = new ExpressionNode("/");
                quotient.left = numerator;
                quotient.right = denominator;
                return quotient;
                
            case '^':
                // 简化情况：u^n，其中n是常量
                if (!containsVariable(right, variable)) {
                    // (u^n)' = n * u^(n-1) * u'
                    ExpressionNode coefficient = copyNode(right);
                    
                    ExpressionNode newExponent = new ExpressionNode("-");
                    newExponent.left = copyNode(right);
                    newExponent.right = new ExpressionNode("1");
                    
                    ExpressionNode power = new ExpressionNode("^");
                    power.left = copyNode(left);
                    power.right = newExponent;
                    
                    ExpressionNode product1 = new ExpressionNode("*");
                    product1.left = coefficient;
                    product1.right = power;
                    
                    ExpressionNode product2 = new ExpressionNode("*");
                    product2.left = product1;
                    product2.right = derivative(left, variable);
                    
                    return product2;
                }
                break;
        }
        
        throw new UnsupportedOperationException("Derivative not implemented for: " + op);
    }
    
    private ExpressionNode copyNode(ExpressionNode node) {
        if (node == null) return null;
        
        ExpressionNode copy = new ExpressionNode(node.value);
        copy.left = copyNode(node.left);
        copy.right = copyNode(node.right);
        return copy;
    }
    
    private boolean containsVariable(ExpressionNode node, String variable) {
        if (node == null) return false;
        
        if (!node.isOperator()) {
            return node.value.equals(variable);
        }
        
        return containsVariable(node.left, variable) || 
               containsVariable(node.right, variable);
    }
}
```

```java
/**
 * 通用表达式处理框架
 */
public class ExpressionProcessor {
    
    private final TokenParser tokenParser;
    private final ExpressionEvaluator evaluator;
    private final ExpressionOptimizer optimizer;
    
    public ExpressionProcessor() {
        this.tokenParser = new TokenParser();
        this.evaluator = new ExpressionEvaluator();
        this.optimizer = new ExpressionOptimizer();
    }
    
    /**
     * 完整的表达式处理流程
     */
    public ProcessResult process(String expression) {
        try {
            // 1. 词法分析
            List<Token> tokens = tokenParser.parse(expression);
            
            // 2. 语法分析
            ExpressionNode ast = buildAST(tokens);
            
            // 3. 语义分析
            validateSemantics(ast);
            
            // 4. 优化
            ExpressionNode optimized = optimizer.optimize(ast);
            
            // 5. 求值
            double result = evaluator.evaluate(optimized);
            
            return new ProcessResult(true, result, optimized);
            
        } catch (Exception e) {
            return new ProcessResult(false, 0, null, e.getMessage());
        }
    }
    
    private ExpressionNode buildAST(List<Token> tokens) {
        // 使用调度场算法构建AST
        Deque<ExpressionNode> operandStack = new ArrayDeque<>();
        Deque<Token> operatorStack = new ArrayDeque<>();
        
        for (Token token : tokens) {
            switch (token.type) {
                case NUMBER:
                    operandStack.push(new ExpressionNode(token.value));
                    break;
                    
                case OPERATOR:
                    while (!operatorStack.isEmpty() && 
                           shouldPop(operatorStack.peek(), token)) {
                        popAndCreateNode(operandStack, operatorStack);
                    }
                    operatorStack.push(token);
                    break;
                    
                case LEFT_PAREN:
                    operatorStack.push(token);
                    break;
                    
                case RIGHT_PAREN:
                    while (!operatorStack.isEmpty() && 
                           operatorStack.peek().type != TokenType.LEFT_PAREN) {
                        popAndCreateNode(operandStack, operatorStack);
                    }
                    operatorStack.pop(); // 弹出左括号
                    break;
            }
        }
        
        while (!operatorStack.isEmpty()) {
            popAndCreateNode(operandStack, operatorStack);
        }
        
        return operandStack.pop();
    }
    
    private void popAndCreateNode(Deque<ExpressionNode> operandStack, 
                                 Deque<Token> operatorStack) {
        Token operator = operatorStack.pop();
        ExpressionNode right = operandStack.pop();
        ExpressionNode left = operandStack.pop();
        
        ExpressionNode node = new ExpressionNode(operator.value);
        node.left = left;
        node.right = right;
        
        operandStack.push(node);
    }
    
    private boolean shouldPop(Token stackTop, Token current) {
        if (stackTop.type == TokenType.LEFT_PAREN) return false;
        return stackTop.precedence >= current.precedence;
    }
    
    private void validateSemantics(ExpressionNode ast) {
        // 语义检查：除零、定义域等
        validateNode(ast);
    }
    
    private void validateNode(ExpressionNode node) {
        if (node == null || !node.isOperator()) return;
        
        validateNode(node.left);
        validateNode(node.right);
        
        // 检查特定运算符的语义约束
        if ("/".equals(node.value)) {
            if (!node.right.isOperator() && "0".equals(node.right.value)) {
                throw new ArithmeticException("Division by zero");
            }
        }
    }
    
    static class ProcessResult {
        final boolean success;
        final double result;
        final ExpressionNode ast;
        final String error;
        
        ProcessResult(boolean success, double result, ExpressionNode ast) {
            this(success, result, ast, null);
        }
        
        ProcessResult(boolean success, double result, ExpressionNode ast, String error) {
            this.success = success;
            this.result = result;
            this.ast = ast;
            this.error = error;
        }
    }
    
    static class Token {
        final TokenType type;
        final String value;
        final int precedence;
        
        Token(TokenType type, String value, int precedence) {
            this.type = type;
            this.value = value;
            this.precedence = precedence;
        }
    }
    
    enum TokenType {
        NUMBER, OPERATOR, LEFT_PAREN, RIGHT_PAREN, FUNCTION
    }
}
```

```java
/**
 * 高性能表达式求值器
 */
public class OptimizedExpressionEvaluator {
    
    // 预编译的表达式缓存
    private final Map<String, CompiledExpression> cache = new ConcurrentHashMap<>();
    
    // 对象池减少GC压力
    private final ObjectPool<StackFrame> framePool = new ObjectPool<>(StackFrame::new);
    
    public double evaluate(String expression, Map<String, Double> variables) {
        CompiledExpression compiled = cache.computeIfAbsent(expression, this::compile);
        return compiled.evaluate(variables);
    }
    
    private CompiledExpression compile(String expression) {
        // 编译为字节码指令序列
        List<Instruction> instructions = compileToInstructions(expression);
        return new CompiledExpression(instructions);
    }
    
    private List<Instruction> compileToInstructions(String expression) {
        List<Instruction> instructions = new ArrayList<>();
        String postfix = convertToPostfix(expression);
        
        for (String token : postfix.split("\\s+")) {
            if (isNumber(token)) {
                instructions.add(new PushInstruction(Double.parseDouble(token)));
            } else if (isVariable(token)) {
                instructions.add(new LoadInstruction(token));
            } else if (isOperator(token)) {
                instructions.add(new OperatorInstruction(token.charAt(0)));
            }
        }
        
        return instructions;
    }
    
    static class CompiledExpression {
        private final List<Instruction> instructions;
        
        CompiledExpression(List<Instruction> instructions) {
            this.instructions = instructions;
        }
        
        double evaluate(Map<String, Double> variables) {
            double[] stack = new double[instructions.size()]; // 预分配栈
            int top = -1;
            
            for (Instruction instruction : instructions) {
                top = instruction.execute(stack, top, variables);
            }
            
            return stack[top];
        }
    }
    
    interface Instruction {
        int execute(double[] stack, int top, Map<String, Double> variables);
    }
    
    static class PushInstruction implements Instruction {
        private final double value;
        
        PushInstruction(double value) { this.value = value; }
        
        @Override
        public int execute(double[] stack, int top, Map<String, Double> variables) {
            stack[++top] = value;
            return top;
        }
    }
    
    static class LoadInstruction implements Instruction {
        private final String variable;
        
        LoadInstruction(String variable) { this.variable = variable; }
        
        @Override
        public int execute(double[] stack, int top, Map<String, Double> variables) {
            stack[++top] = variables.getOrDefault(variable, 0.0);
            return top;
        }
    }
    
    static class OperatorInstruction implements Instruction {
        private final char operator;
        
        OperatorInstruction(char operator) { this.operator = operator; }
        
        @Override
        public int execute(double[] stack, int top, Map<String, Double> variables) {
            double right = stack[top--];
            double left = stack[top];
            
            switch (operator) {
                case '+': stack[top] = left + right; break;
                case '-': stack[top] = left - right; break;
                case '*': stack[top] = left * right; break;
                case '/': stack[top] = left / right; break;
                case '^': stack[top] = Math.pow(left, right); break;
            }
            
            return top;
        }
    }
}
```
