# 84题最大矩形;二维数据的数据转化和单调栈

总结的学习内容和学习思想

这是一道很典型的体型;放在这里加强对于单调递增栈的理解

[算法优化思想-滚动数组与增量更新](https://www.yuque.com/zhangshun-xxqvr/vg2bou/godye2xang6g7ugk)

```java
class Solution {
    public int maximalRectangle(char[][] matrix) {
        if(null == matrix || 0 == matrix.length || 0 == matrix[0].length){
            return 0;
        }
        int rowSize = matrix.length;
        int kuan = matrix[0].length;
        int[] heights = new int[kuan];
        int max = 0;
        for(int i=0;i<rowSize;i++){
            // 更新每一行代表的最大高度,把二维数组转化为类似前缀和的逻辑,一维数组是上述表述1的高度的累加;
            updateHeights(heights,matrix[i]);
            // 处理最大高度获取到对应的max值
            max = Math.max(max,findMax(heights));
        }
        return max;
    }

    private int findMax(int[] heights){
        int sum = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        for(int i=0;i<=heights.length/*heights.length作为边界的哨兵 */;i++){
            int value = (i == heights.length?0:heights[i]);
            while(!stack.isEmpty() && /*递增单调栈被中断*/heights[stack.peek()] > value){
                int hn = heights[stack.pop()];
                int wn = (stack.isEmpty()? /*递增栈空白了,i就是最矮的,宽度是i-0,等价于stack.push(-1)然后不做判断*/i:/**/i - stack.peek() - 1);
                sum = Math.max(sum , hn * wn);
            }
            stack.push(i);
        }
        return sum;
    }

    private void updateHeights(int[] heights,char[] row){
        for(int i=0;i<row.length;i++){
            if('1' == row[i]){
                // 连续的时候一直从上往下累加;
                heights[i]++;
            }else{
                // 不连续了
                heights[i]=0;
            }
        }
    }
}
```
