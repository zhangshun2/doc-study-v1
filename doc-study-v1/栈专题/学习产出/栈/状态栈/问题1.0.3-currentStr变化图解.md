# 问题1.0.3 - currentStr变化图解
## 🎯 **示例分析：**`"3[a2[c]]"`
让我们通过详细的图示来观察 `currentStr` 在整个遍历过程中的变化。

## 📊 **完整变化过程**
```plain
输入字符串: "3[a2[c]]"
           ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑
           0 1 2 3 4 5 6 7
```

### **Step 1: 处理字符 '3'**
```plain
当前字符: '3'
操作: 累积数字

┌─────────────────┐
│ num = 3         │
│ currentStr = "" │
└─────────────────┘

numStack: []
strStack: []
```

### **Step 2: 处理字符 '['**
```plain
当前字符: '['
操作: 保存状态，进入下一层

保存前状态:
┌─────────────────┐
│ num = 3         │
│ currentStr = "" │
└─────────────────┘

保存操作:
numStack.push(3)   ──→  numStack: [3]
strStack.push("") ──→  strStack: [""]

重置后状态:
┌─────────────────┐
│ num = 0         │
│ currentStr = "" │ ← 重置为空字符串
└─────────────────┘
```

### **Step 3: 处理字符 'a'**
```plain
当前字符: 'a'
操作: 累积字符

┌─────────────────┐
│ num = 0         │
│ currentStr = "a"│ ← 从 "" 变为 "a"
└─────────────────┘

numStack: [3]
strStack: [""]
```

### **Step 4: 处理字符 '2'**
```plain
当前字符: '2'
操作: 累积数字

┌─────────────────┐
│ num = 2         │
│ currentStr = "a"│ ← 保持不变
└─────────────────┘

numStack: [3]
strStack: [""]
```

### **Step 5: 处理字符 '['**
```plain
当前字符: '['
操作: 保存状态，进入下一层

保存前状态:
┌─────────────────┐
│ num = 2         │
│ currentStr = "a"│
└─────────────────┘

保存操作:
numStack.push(2)   ──→  numStack: [3, 2]
strStack.push("a") ──→  strStack: ["", "a"]

重置后状态:
┌─────────────────┐
│ num = 0         │
│ currentStr = "" │ ← 再次重置为空字符串
└─────────────────┘
```

### **Step 6: 处理字符 'c'**
```plain
当前字符: 'c'
操作: 累积字符

┌─────────────────┐
│ num = 0         │
│ currentStr = "c"│ ← 从 "" 变为 "c"
└─────────────────┘

numStack: [3, 2]
strStack: ["", "a"]
```

### **Step 7: 处理字符 ']' (第一个)**
```plain
当前字符: ']'
操作: 恢复状态，执行合并

恢复操作:
repeatTimes = numStack.pop() = 2  ──→  numStack: [3]
prevStr = strStack.pop() = "a"    ──→  strStack: [""]

合并计算:
currentStr = prevStr + currentStr.repeat(repeatTimes)
currentStr = "a" + "c".repeat(2)
currentStr = "a" + "cc"
currentStr = "acc"

合并后状态:
┌─────────────────┐
│ num = 0         │
│ currentStr="acc"│ ← 从 "c" 变为 "acc"
└─────────────────┘
```

### **Step 8: 处理字符 ']' (第二个)**
```plain
当前字符: ']'
操作: 恢复状态，执行合并

恢复操作:
repeatTimes = numStack.pop() = 3  ──→  numStack: []
prevStr = strStack.pop() = ""     ──→  strStack: []

合并计算:
currentStr = prevStr + currentStr.repeat(repeatTimes)
currentStr = "" + "acc".repeat(3)
currentStr = "" + "accaccacc"
currentStr = "accaccacc"

最终状态:
┌─────────────────────┐
│ num = 0             │
│ currentStr="accaccacc"│ ← 从 "acc" 变为 "accaccacc"
└─────────────────────┘
```

## 🔄 **currentStr 变化轨迹**
```plain
步骤    字符    currentStr变化    说明
────────────────────────────────────────────
 1      '3'     ""              数字不影响currentStr
 2      '['     "" → ""         重置为空字符串
 3      'a'     "" → "a"        累积字符
 4      '2'     "a"             数字不影响currentStr
 5      '['     "a" → ""        再次重置为空字符串
 6      'c'     "" → "c"        累积字符
 7      ']'     "c" → "acc"     合并: "a" + "c"*2
 8      ']'     "acc" → "accaccacc"  合并: "" + "acc"*3
```

## 🎯 **关键观察点**
### **1. 重置时机**
```plain
遇到 '[' 时，currentStr 总是被重置为 ""
这确保了每一层都从干净的状态开始
```

### **2. 累积过程**
```plain
遇到字母时，currentStr 逐步累积字符
这是当前层的"工作成果"
```

### **3. 合并机制**
```plain
遇到 ']' 时，currentStr 参与合并计算
合并公式: prevStr + currentStr.repeat(times)
合并后的结果重新赋值给 currentStr
```

### **4. 层级隔离**
```plain
每一层的 currentStr 都是独立的
通过栈保存/恢复机制实现层级间的状态传递
```

## 💡 **深度理解**
### **currentStr 的三种状态**
#### ***� 工作状态**
```plain
正在累积当前层的字符
例: "" → "a" → "ab" → "abc"
```

#### ***� 保存状态**
```plain
当前层的工作成果被保存到 strStack
例: strStack.push("abc")
```

#### ***� 合并状态**
```plain
从栈中恢复上层状态，与当前层结果合并
例: "prev" + "current".repeat(3)
```

## 🚀 **核心洞察**
1. **currentStr 是当前层的"工作台"**
    - 每层都有自己独立的工作空间
    - 通过重置实现层级隔离
2. **栈是层级间的"传送带"**
    - 保存上层的半成品状态
    - 在合适时机恢复并合并
3. **合并是"向上传递"的过程**
    - 内层结果传递给外层
    - 最终在最外层得到完整结果

这种设计巧妙地将嵌套问题转化为线性处理，每一步都清晰可见！
