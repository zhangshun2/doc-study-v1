## 栈的核心特性分析
### 1. LIFO特性的算法价值
**后进先出（Last In, First Out）** 这一特性使栈在以下场景中具有天然优势：

```java
// LIFO特性示例
public class LifoDemo {
    public static void demonstrateLIFO() {
        Deque<String> stack = new ArrayDeque<>();
        
        // 按顺序压入
        stack.push("第一步");
        stack.push("第二步");
        stack.push("第三步");
        
        // 按相反顺序弹出
        while (!stack.isEmpty()) {
            System.out.println("撤销：" + stack.pop());
        }
        // 输出：撤销：第三步 → 撤销：第二步 → 撤销：第一步
    }
}
```

### 2. 栈的算法特性总结
| 特性 | 描述 | 算法应用 |
| --- | --- | --- |
| **逆序处理** | 自然实现元素的逆序访问 | 字符串反转、路径回溯 |

```java
public class BracketMatcher {
    /**
     * 检查括号是否匹配
     * 核心思想：左括号入栈，右括号出栈匹配
     */
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Character> pairs = Map.of(')', '(', ']', '[', '}', '{');
        
        for (char c : s.toCharArray()) {
            if (pairs.containsValue(c)) {
                // 左括号：压栈
                stack.push(c);
            } else if (pairs.containsKey(c)) {
                // 右括号：检查匹配
                if (stack.isEmpty() || stack.pop() != pairs.get(c)) {
                    return false;
                }
            }
        }
        
        return stack.isEmpty();
    }
    
    /**
     * 扩展：找出最长有效括号长度
     */
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1); // 哨兵
        int maxLen = 0;
        
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i); // 新的起点
                } else {
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        
        return maxLen;
    }
}
```

#### 1.2 表达式求值
```java
public class ExpressionEvaluator {
    /**
     * 基本计算器（支持 +, -, *, /）
     * 核心思想：用栈处理运算符优先级
     */
    public int calculate(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        char operator = '+';
        int num = 0;
        
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            }
            
            if (c == '+' || c == '-' || c == '*' || c == '/' || i == s.length() - 1) {
                switch (operator) {
                    case '+': stack.push(num); break;
                    case '-': stack.push(-num); break;
                    case '*': stack.push(stack.pop() * num); break;
                    case '/': stack.push(stack.pop() / num); break;
                }
                operator = c;
                num = 0;
            }
        }
        
        return stack.stream().mapToInt(Integer::intValue).sum();
    }
    
    /**
     * 支持括号的计算器
     */
    public int calculateWithParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();
        
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            
            if (Character.isDigit(c)) {
                int num = 0;
                while (i < s.length() && Character.isDigit(s.charAt(i))) {
                    num = num * 10 + (s.charAt(i) - '0');
                    i++;
                }
                i--; // 回退一位
                stack.push(num);
            } else if (c == '(') {
                ops.push(c);
            } else if (c == ')') {
                while (!ops.isEmpty() && ops.peek() != '(') {
                    stack.push(applyOperation(ops.pop(), stack.pop(), stack.pop()));
                }
                ops.pop(); // 移除 '('
            } else if (c == '+' || c == '-' || c == '*' || c == '/') {
                while (!ops.isEmpty() && hasPrecedence(c, ops.peek())) {
                    stack.push(applyOperation(ops.pop(), stack.pop(), stack.pop()));
                }
                ops.push(c);
            }
        }
        
        while (!ops.isEmpty()) {
            stack.push(applyOperation(ops.pop(), stack.pop(), stack.pop()));
        }
        
        return stack.pop();
    }
    
    private boolean hasPrecedence(char op1, char op2) {
        if (op2 == '(' || op2 == ')') return false;
        if ((op1 == '*' || op1 == '/') && (op2 == '+' || op2 == '-')) return false;
        return true;
    }
    
    private int applyOperation(char op, int b, int a) {
        switch (op) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            case '/': return a / b;
        }
        return 0;
    }
}
```

#### 2.1 二叉树遍历
```java
public class TreeTraversal {
    /**
     * 前序遍历（迭代版本）
     * 核心思想：根节点先处理，右子树先入栈
     */
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;
        
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.add(node.val);
            
            // 先压右子树，再压左子树（保证左子树先处理）
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
        
        return result;
    }
    
    /**
     * 中序遍历（迭代版本）
     * 核心思想：一直向左走到底，然后处理节点
     */
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode current = root;
        
        while (current != null || !stack.isEmpty()) {
            // 一直向左走，压栈
            while (current != null) {
                stack.push(current);
                current = current.left;
            }
            
            // 处理栈顶节点
            current = stack.pop();
            result.add(current.val);
            current = current.right;
        }
        
        return result;
    }
    
    /**
     * 后序遍历（双栈法）
     * 核心思想：用两个栈实现逆序
     */
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;
        
        Deque<TreeNode> stack1 = new ArrayDeque<>();
        Deque<TreeNode> stack2 = new ArrayDeque<>();
        
        stack1.push(root);
        
        while (!stack1.isEmpty()) {
            TreeNode node = stack1.pop();
            stack2.push(node);
            
            if (node.left != null) stack1.push(node.left);
            if (node.right != null) stack1.push(node.right);
        }
        
        while (!stack2.isEmpty()) {
            result.add(stack2.pop().val);
        }
        
        return result;
    }
}
```

#### 2.2 图的深度优先搜索
```java
public class GraphDFS {
    /**
     * 图的DFS遍历
     * 核心思想：用栈模拟递归的深度优先搜索
     */
    public List<Integer> dfsIterative(int[][] graph, int start) {
        List<Integer> result = new ArrayList<>();
        boolean[] visited = new boolean[graph.length];
        Deque<Integer> stack = new ArrayDeque<>();
        
        stack.push(start);
        
        while (!stack.isEmpty()) {
            int node = stack.pop();
            
            if (!visited[node]) {
                visited[node] = true;
                result.add(node);
                
                // 逆序添加邻居（保证按顺序访问）
                for (int i = graph[node].length - 1; i >= 0; i--) {
                    int neighbor = graph[node][i];
                    if (!visited[neighbor]) {
                        stack.push(neighbor);
                    }
                }
            }
        }
        
        return result;
    }
    
    /**
     * 岛屿数量问题
     * 核心思想：用栈进行DFS，标记连通区域
     */
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        
        int count = 0;
        int rows = grid.length, cols = grid[0].length;
        
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == '1') {
                    count++;
                    dfsMarkIsland(grid, i, j);
                }
            }
        }
        
        return count;
    }
    
    private void dfsMarkIsland(char[][] grid, int startRow, int startCol) {
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{startRow, startCol});
        
        int[][] directions = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        
        while (!stack.isEmpty()) {
            int[] pos = stack.pop();
            int row = pos[0], col = pos[1];
            
            if (row < 0 || row >= grid.length || col < 0 || col >= grid[0].length || 
                grid[row][col] != '1') {
                continue;
            }
            
            grid[row][col] = '0'; // 标记为已访问
            
            // 添加四个方向的邻居
            for (int[] dir : directions) {
                stack.push(new int[]{row + dir[0], col + dir[1]});
            }
        }
    }
}
```

### 3. 回溯和状态管理类
#### 3.1 路径回溯
```java
public class PathBacktracking {
    /**
     * 二叉树的所有路径
     * 核心思想：用栈保存当前路径，回溯时弹出
     */
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        if (root == null) return result;
        
        Deque<TreeNode> nodeStack = new ArrayDeque<>();
        Deque<String> pathStack = new ArrayDeque<>();
        
        nodeStack.push(root);
        pathStack.push(String.valueOf(root.val));
        
        while (!nodeStack.isEmpty()) {
            TreeNode node = nodeStack.pop();
            String path = pathStack.pop();
            
            // 叶子节点：添加路径
            if (node.left == null && node.right == null) {
                result.add(path);
            }
            
            // 继续探索子节点
            if (node.left != null) {
                nodeStack.push(node.left);
                pathStack.push(path + "->" + node.left.val);
            }
            
            if (node.right != null) {
                nodeStack.push(node.right);
                pathStack.push(path + "->" + node.right.val);
            }
        }
        
        return result;
    }
    
    /**
     * 迷宫路径查找
     * 核心思想：用栈保存路径，遇到死路时回溯
     */
    public boolean hasPath(int[][] maze, int[] start, int[] destination) {
        Deque<int[]> stack = new ArrayDeque<>();
        boolean[][] visited = new boolean[maze.length][maze[0].length];
        
        stack.push(start);
        
        int[][] directions = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
        
        while (!stack.isEmpty()) {
            int[] pos = stack.pop();
            
            if (pos[0] == destination[0] && pos[1] == destination[1]) {
                return true;
            }
            
            if (visited[pos[0]][pos[1]]) continue;
            visited[pos[0]][pos[1]] = true;
            
            for (int[] dir : directions) {
                int newRow = pos[0];
                int newCol = pos[1];
                
                // 一直滚动到撞墙或边界
                while (newRow >= 0 && newRow < maze.length && 
                       newCol >= 0 && newCol < maze[0].length && 
                       maze[newRow][newCol] == 0) {
                    newRow += dir[0];
                    newCol += dir[1];
                }
                
                // 回退一步（撞墙前的位置）
                newRow -= dir[0];
                newCol -= dir[1];
                
                if (!visited[newRow][newCol]) {
                    stack.push(new int[]{newRow, newCol});
                }
            }
        }
        
        return false;
    }
}
```

```java
public class StateMachineParser {
    /**
     * 简单的JSON解析器
     * 核心思想：用栈管理嵌套状态
     */
    public boolean isValidJSON(String json) {
        Deque<Character> stack = new ArrayDeque<>();
        boolean inString = false;
        
        for (int i = 0; i < json.length(); i++) {
            char c = json.charAt(i);
            
            if (c == '"' && (i == 0 || json.charAt(i - 1) != '\\')) {
                inString = !inString;
            } else if (!inString) {
                if (c == '{' || c == '[') {
                    stack.push(c);
                } else if (c == '}') {
                    if (stack.isEmpty() || stack.pop() != '{') return false;
                } else if (c == ']') {
                    if (stack.isEmpty() || stack.pop() != '[') return false;
                }
            }
        }
        
        return stack.isEmpty() && !inString;
    }
    
    /**
     * 目录路径简化
     * 核心思想：用栈处理 . 和 .. 操作
     */
    public String simplifyPath(String path) {
        Deque<String> stack = new ArrayDeque<>();
        String[] parts = path.split("/");
        
        for (String part : parts) {
            if (part.equals("..")) {
                if (!stack.isEmpty()) {
                    stack.pop(); // 返回上级目录
                }
            } else if (!part.equals(".") && !part.isEmpty()) {
                stack.push(part); // 进入目录
            }
            // "." 和空字符串忽略
        }
        
        return "/" + String.join("/", stack);
    }
}
```

### 4. 单调栈应用
#### 4.1 下一个更大元素
```java
public class MonotonicStack {
    /**
     * 下一个更大元素
     * 核心思想：维护单调递减栈
     */
    public int[] nextGreaterElement(int[] nums) {
        int[] result = new int[nums.length];
        Deque<Integer> stack = new ArrayDeque<>(); // 存储索引
        
        for (int i = nums.length - 1; i >= 0; i--) {
            // 弹出所有小于等于当前元素的值
            while (!stack.isEmpty() && nums[stack.peek()] <= nums[i]) {
                stack.pop();
            }
            
            result[i] = stack.isEmpty() ? -1 : nums[stack.peek()];
            stack.push(i);
        }
        
        return result;
    }
    
    /**
     * 柱状图中最大的矩形
     * 核心思想：单调递增栈找到每个柱子的边界
     */
    public int largestRectangleInHistogram(int[] heights) {
        Deque<Integer> stack = new ArrayDeque<>();
        int maxArea = 0;
        
        for (int i = 0; i <= heights.length; i++) {
            int currentHeight = (i == heights.length) ? 0 : heights[i];
            
            while (!stack.isEmpty() && heights[stack.peek()] > currentHeight) {
                int height = heights[stack.pop()];
                int width = stack.isEmpty() ? i : i - stack.peek() - 1;
                maxArea = Math.max(maxArea, height * width);
            }
            
            stack.push(i);
        }
        
        return maxArea;
    }
    
    /**
     * 每日温度
     * 核心思想：单调递减栈找到下一个更高温度
     */
    public int[] dailyTemperatures(int[] temperatures) {
        int[] result = new int[temperatures.length];
        Deque<Integer> stack = new ArrayDeque<>();
        
        for (int i = 0; i < temperatures.length; i++) {
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int prevIndex = stack.pop();
                result[prevIndex] = i - prevIndex;
            }
            stack.push(i);
        }
        
        return result;
    }
}
```

## 栈算法的选择标准
### 1. 何时使用栈？
#### ✅ 适合使用栈的场景
+ **嵌套结构处理**：括号、标签、引号匹配
+ **逆序操作**：需要按相反顺序处理元素
+ **临时状态保存**：需要保存中间状态以便回溯
+ **递归转迭代**：将递归算法改写为迭代形式
+ **深度优先搜索**：树、图的DFS遍历
+ **表达式解析**：中缀、后缀表达式求值
+ **单调性问题**：寻找下一个更大/更小元素

#### ❌ 不适合使用栈的场景
+ **随机访问**：需要访问中间元素
+ **广度优先搜索**：应该使用队列
+ **排序算法**：通常需要其他数据结构
+ **双端操作**：需要从两端操作时考虑双端队列

### 2. 栈算法的复杂度特征
| 操作类型 | 时间复杂度 | 空间复杂度 | 典型应用 |
| --- | --- | --- | --- |
| 基本操作 | O(1) | O(1) | push, pop, peek |
| 遍历处理 | O(n) | O(n) | 括号匹配、表达式求值 |
| 树遍历 | O(n) | O(h) | 二叉树遍历（h为树高） |
| 图DFS | O(V+E) | O(V) | 图的深度优先搜索 |
| 单调栈 | O(n) | O(n) | 下一个更大元素 |

```java
public class SafeStackOperations {
    public static <T> T safePop(Deque<T> stack) {
        if (stack.isEmpty()) {
            throw new IllegalStateException("Cannot pop from empty stack");
        }
        return stack.pop();
    }
    
    public static <T> T safePeek(Deque<T> stack) {
        if (stack.isEmpty()) {
            return null; // 或抛出异常
        }
        return stack.peek();
    }
}
```
