# 栈+哈希表结构原理详解
## 📚 栈+哈希表的基本概念
### 什么是栈+哈希表结构？
栈+哈希表（Stack + HashMap）是一种**混合数据结构**，它结合了：

+ **栈的LIFO特性**：维护元素的顺序关系
+ **哈希表的O(1)查找**：快速定位和访问元素

这种组合特别适合需要**快速查找**同时**维护顺序**的场景。

### 核心设计思想
```plain
栈+哈希表结构示意图：

栈部分：                    哈希表部分：
┌─────┐                    ┌─────────────────┐
│  C  │ ← 栈顶            │ Key  │  Value   │
├─────┤                    ├─────────────────┤
│  B  │                    │  A   │   0     │
├─────┤                    │  B   │   1     │
│  A  │ ← 栈底            │  C   │   2     │
└─────┘                    └─────────────────┘

特点：
- 栈维护元素顺序
- 哈希表记录元素位置/状态
- 两者协同工作
```

## 🔧 栈+哈希表的核心模式
### 1. 位置记录模式
**核心思想：** 栈存储元素，哈希表记录元素在栈中的位置

```java
/**
 * 支持O(1)查找的栈
 */
public class IndexedStack<T> {
    private List<T> stack;                    // 使用List模拟栈
    private Map<T, Integer> indexMap;         // 元素 -> 索引映射
    
    public IndexedStack() {
        stack = new ArrayList<>();
        indexMap = new HashMap<>();
    }
    
    /**
     * 入栈操作
     */
    public void push(T element) {
        // 如果元素已存在，先移除旧位置
        if (indexMap.containsKey(element)) {
            remove(element);
        }
        
        // 添加到栈顶
        stack.add(element);
        indexMap.put(element, stack.size() - 1);
    }
    
    /**
     * 出栈操作
     */
    public T pop() {
        if (stack.isEmpty()) {
            throw new RuntimeException("栈为空");
        }
        
        T element = stack.remove(stack.size() - 1);
        indexMap.remove(element);
        return element;
    }
    
    /**
     * O(1)查找元素是否存在
     */
    public boolean contains(T element) {
        return indexMap.containsKey(element);
    }
    
    /**
     * O(1)获取元素位置
     */
    public int indexOf(T element) {
        return indexMap.getOrDefault(element, -1);
    }
    
    /**
     * O(1)移除指定元素
     */
    public boolean remove(T element) {
        if (!indexMap.containsKey(element)) {
            return false;
        }
        
        int index = indexMap.get(element);
        
        // 移除元素
        stack.remove(index);
        indexMap.remove(element);
        
        // 更新后续元素的索引
        for (int i = index; i < stack.size(); i++) {
            indexMap.put(stack.get(i), i);
        }
        
        return true;
    }
    
    /**
     * 查看栈顶元素
     */
    public T peek() {
        if (stack.isEmpty()) {
            throw new RuntimeException("栈为空");
        }
        return stack.get(stack.size() - 1);
    }
    
    /**
     * 获取栈大小
     */
    public int size() {
        return stack.size();
    }
    
    /**
     * 检查栈是否为空
     */
    public boolean isEmpty() {
        return stack.isEmpty();
    }
}
```

**操作过程图解：**

```plain
初始状态：
栈：[]
哈希表：{}

操作1：push("A")
栈：["A"]
哈希表：{"A": 0}

操作2：push("B")
栈：["A", "B"]
哈希表：{"A": 0, "B": 1}

操作3：push("C")
栈：["A", "B", "C"]
哈希表：{"A": 0, "B": 1, "C": 2}

操作4：contains("B") → O(1)查找
结果：true（直接从哈希表查找）

操作5：remove("B")
移除前：栈：["A", "B", "C"]，哈希表：{"A": 0, "B": 1, "C": 2}
移除后：栈：["A", "C"]，哈希表：{"A": 0, "C": 1}
（注意：C的索引从2更新为1）

操作6：push("A") → 重复元素
先移除旧的A：栈：["C"]，哈希表：{"C": 0}
再添加新的A：栈：["C", "A"]，哈希表：{"C": 0, "A": 1}
```

### 2. 状态记录模式
**核心思想：** 栈存储元素，哈希表记录元素的状态信息

```java
/**
 * 带状态的栈结构
 */
public class StatefulStack<T> {
    private Deque<T> stack;
    private Map<T, ElementState> stateMap;
    
    public StatefulStack() {
        stack = new ArrayDeque<>();
        stateMap = new HashMap<>();
    }
    
    /**
     * 元素状态枚举
     */
    public enum ElementState {
        ACTIVE,     // 活跃状态
        PROCESSED,  // 已处理
        MARKED,     // 已标记
        LOCKED      // 锁定状态
    }
    
    /**
     * 入栈并设置状态
     */
    public void push(T element, ElementState state) {
        stack.push(element);
        stateMap.put(element, state);
    }
    
    /**
     * 入栈（默认活跃状态）
     */
    public void push(T element) {
        push(element, ElementState.ACTIVE);
    }
    
    /**
     * 出栈
     */
    public T pop() {
        if (stack.isEmpty()) {
            throw new RuntimeException("栈为空");
        }
        
        T element = stack.pop();
        stateMap.remove(element);
        return element;
    }
    
    /**
     * 更新元素状态
     */
    public boolean updateState(T element, ElementState newState) {
        if (!stateMap.containsKey(element)) {
            return false;
        }
        stateMap.put(element, newState);
        return true;
    }
    
    /**
     * 获取元素状态
     */
    public ElementState getState(T element) {
        return stateMap.get(element);
    }
    
    /**
     * 检查元素是否在栈中且为指定状态
     */
    public boolean isInState(T element, ElementState state) {
        return stateMap.getOrDefault(element, null) == state;
    }
    
    /**
     * 获取指定状态的所有元素
     */
    public List<T> getElementsByState(ElementState state) {
        return stateMap.entrySet().stream()
                .filter(entry -> entry.getValue() == state)
                .map(Map.Entry::getKey)
                .collect(Collectors.toList());
    }
    
    /**
     * 弹出指定状态的栈顶元素
     */
    public T popByState(ElementState state) {
        while (!stack.isEmpty()) {
            T top = stack.peek();
            if (stateMap.get(top) == state) {
                return pop();
            } else {
                // 如果栈顶不是目标状态，暂时移除
                T temp = pop();
                // 这里可以根据需求决定如何处理
            }
        }
        return null;
    }
}
```

### 3. 频率统计模式
**核心思想：** 栈维护元素顺序，哈希表统计元素频率

```java
/**
 * 频率统计栈
 */
public class FrequencyStack {
    private Map<Integer, Integer> frequency;      // 元素 -> 频率
    private Map<Integer, Deque<Integer>> groups;  // 频率 -> 该频率的元素栈
    private int maxFrequency;                     // 当前最大频率
    
    public FrequencyStack() {
        frequency = new HashMap<>();
        groups = new HashMap<>();
        maxFrequency = 0;
    }
    
    /**
     * 入栈操作
     */
    public void push(int val) {
        // 更新频率
        int freq = frequency.getOrDefault(val, 0) + 1;
        frequency.put(val, freq);
        
        // 更新最大频率
        maxFrequency = Math.max(maxFrequency, freq);
        
        // 将元素加入对应频率的栈
        groups.computeIfAbsent(freq, k -> new ArrayDeque<>()).push(val);
    }
    
    /**
     * 出栈操作（弹出频率最高的元素）
     */
    public int pop() {
        if (maxFrequency == 0) {
            throw new RuntimeException("栈为空");
        }
        
        // 从最高频率栈中弹出元素
        Deque<Integer> maxFreqStack = groups.get(maxFrequency);
        int val = maxFreqStack.pop();
        
        // 更新频率
        frequency.put(val, frequency.get(val) - 1);
        
        // 如果最高频率栈为空，降低最大频率
        if (maxFreqStack.isEmpty()) {
            maxFrequency--;
        }
        
        return val;
    }
    
    /**
     * 获取元素频率
     */
    public int getFrequency(int val) {
        return frequency.getOrDefault(val, 0);
    }
    
    /**
     * 获取当前最大频率
     */
    public int getMaxFrequency() {
        return maxFrequency;
    }
    
    /**
     * 显示当前状态
     */
    public void showState() {
        System.out.println("频率映射: " + frequency);
        System.out.println("频率分组: " + groups);
        System.out.println("最大频率: " + maxFrequency);
    }
}
```

```plain
步骤1：push(5)
```

### 1. 有效括号的最近匹配
**问题描述：** 找到每个右括号对应的最近左括号位置

```java
/**
 * 括号匹配问题的栈+哈希表解法
 */
public class BracketMatcher {
    
    /**
     * 找到每个右括号对应的左括号位置
     */
    public int[] findMatchingBrackets(String s) {
        int n = s.length();
        int[] result = new int[n];
        Arrays.fill(result, -1);
        
        Deque<Integer> stack = new ArrayDeque<>();  // 存储左括号位置
        Map<Character, Character> pairs = new HashMap<>();
        pairs.put(')', '(');
        pairs.put(']', '[');
        pairs.put('}', '{');
        
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            
            if (ch == '(' || ch == '[' || ch == '{') {
                // 左括号入栈
                stack.push(i);
            } else if (pairs.containsKey(ch)) {
                // 右括号匹配
                if (!stack.isEmpty()) {
                    int leftPos = stack.pop();
                    if (s.charAt(leftPos) == pairs.get(ch)) {
                        result[i] = leftPos;  // 记录匹配位置
                    }
                }
            }
        }
        
        return result;
    }
    
    /**
     * 检查括号是否有效并返回详细信息
     */
    public BracketInfo validateBrackets(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Integer> count = new HashMap<>();
        
        for (char ch : s.toCharArray()) {
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push(ch);
                count.put(ch, count.getOrDefault(ch, 0) + 1);
            } else {
                char expected = getMatchingLeft(ch);
                if (stack.isEmpty() || stack.pop() != expected) {
                    return new BracketInfo(false, count, stack.size());
                }
            }
        }
        
        return new BracketInfo(stack.isEmpty(), count, stack.size());
    }
    
    private char getMatchingLeft(char right) {
        switch (right) {
            case ')': return '(';
            case ']': return '[';
            case '}': return '{';
            default: return ' ';
        }
    }
    
    static class BracketInfo {
        boolean isValid;
        Map<Character, Integer> bracketCount;
        int unmatchedCount;
        
        BracketInfo(boolean isValid, Map<Character, Integer> count, int unmatched) {
            this.isValid = isValid;
            this.bracketCount = count;
            this.unmatchedCount = unmatched;
        }
    }
}
```

### 2. 下一个更大元素的位置记录
**问题描述：** 对于数组中每个元素，找到它右边第一个更大元素的位置

```java
/**
 * 下一个更大元素问题的增强版
 */
public class NextGreaterElementTracker {
    
    /**
     * 找到下一个更大元素及其位置
     */
    public Map<Integer, ElementInfo> findNextGreaterWithInfo(int[] nums) {
        Map<Integer, ElementInfo> result = new HashMap<>();
        Deque<Integer> stack = new ArrayDeque<>();  // 存储索引
        Map<Integer, Integer> valueToIndex = new HashMap<>();  // 值到索引的映射
        
        for (int i = 0; i < nums.length; i++) {
            // 处理栈中小于当前元素的所有元素
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                int index = stack.pop();
                int value = nums[index];
                
                result.put(value, new ElementInfo(
                    nums[i],           // 下一个更大元素
                    i,                 // 下一个更大元素位置
                    i - index          // 距离
                ));
            }
            
            stack.push(i);
            valueToIndex.put(nums[i], i);
        }
        
        // 处理没有下一个更大元素的情况
        while (!stack.isEmpty()) {
            int index = stack.pop();
            int value = nums[index];
            result.put(value, new ElementInfo(-1, -1, -1));
        }
        
        return result;
    }
    
    static class ElementInfo {
        int nextGreater;     // 下一个更大元素值
        int position;        // 下一个更大元素位置
        int distance;        // 距离
        
        ElementInfo(int nextGreater, int position, int distance) {
            this.nextGreater = nextGreater;
            this.position = position;
            this.distance = distance;
        }
        
        @Override
        public String toString() {
            return String.format("NextGreater: %d, Position: %d, Distance: %d", 
                               nextGreater, position, distance);
        }
    }
}
```

### 3. 滑动窗口最大值
**问题描述：** 在滑动窗口中维护最大值

```java
/**
 * 滑动窗口最大值的栈+哈希表实现
 */
public class SlidingWindowMaximum {
    private Deque<Integer> deque;           // 单调递减双端队列
    private Map<Integer, Integer> count;    // 元素计数
    
    public SlidingWindowMaximum() {
        deque = new ArrayDeque<>();
        count = new HashMap<>();
    }
    
    /**
     * 添加元素到窗口
     */
    public void addElement(int val) {
        // 维护单调递减性
        while (!deque.isEmpty() && deque.peekLast() < val) {
            int removed = deque.pollLast();
            count.put(removed, count.get(removed) - 1);
            if (count.get(removed) == 0) {
                count.remove(removed);
            }
        }
        
        deque.offerLast(val);
        count.put(val, count.getOrDefault(val, 0) + 1);
    }
    
    /**
     * 从窗口移除元素
     */
    public void removeElement(int val) {
        if (count.containsKey(val)) {
            count.put(val, count.get(val) - 1);
            if (count.get(val) == 0) {
                count.remove(val);
                deque.remove(val);  // 从双端队列中移除
            }
        }
    }
    
    /**
     * 获取当前窗口最大值
     */
    public int getMaximum() {
        return deque.isEmpty() ? Integer.MIN_VALUE : deque.peekFirst();
    }
    
    /**
     * 滑动窗口最大值主方法
     */
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums.length == 0 || k == 0) return new int[0];
        
        int[] result = new int[nums.length - k + 1];
        SlidingWindowMaximum window = new SlidingWindowMaximum();
        
        // 初始化第一个窗口
        for (int i = 0; i < k; i++) {
            window.addElement(nums[i]);
        }
        result[0] = window.getMaximum();
        
        // 滑动窗口
        for (int i = k; i < nums.length; i++) {
            window.removeElement(nums[i - k]);  // 移除窗口左边元素
            window.addElement(nums[i]);         // 添加窗口右边元素
            result[i - k + 1] = window.getMaximum();
        }
        
        return result;
    }
}
```

## 🔍 栈+哈希表的设计模式
### 1. 设计原则
| 模式类型 | 栈的作用 | 哈希表的作用 | 适用场景 |
| --- | --- | --- | --- |
| **位置记录** | 维护顺序 | 记录位置 | 快速定位、去重 |
| **状态管理** | 存储元素 | 记录状态 | 状态机、流程控制 |
| **频率统计** | 分组存储 | 统计频率 | 频率相关问题 |
| **缓存优化** | LRU顺序 | 快速查找 | 缓存系统 |


### 2. 实现模板
```java
/**
 * 栈+哈希表通用模板
 */
public class StackHashMapTemplate<K, V> {
    private Deque<K> stack;
    private Map<K, V> hashMap;
    
    public StackHashMapTemplate() {
        stack = new ArrayDeque<>();
        hashMap = new HashMap<>();
    }
    
    // 核心操作：保持栈和哈希表同步
    public void push(K key, V value) {
        // 1. 处理重复元素（根据需求）
        if (hashMap.containsKey(key)) {
            handleDuplicate(key, value);
        }
        
        // 2. 更新栈
        stack.push(key);
        
        // 3. 更新哈希表
        hashMap.put(key, value);
        
        // 4. 维护一致性
        maintainConsistency();
    }
    
    public K pop() {
        if (stack.isEmpty()) {
            throw new RuntimeException("栈为空");
        }
        
        K key = stack.pop();
        hashMap.remove(key);
        return key;
    }
    
    // 快速查找
    public boolean contains(K key) {
        return hashMap.containsKey(key);
    }
    
    public V getValue(K key) {
        return hashMap.get(key);
    }
    
    // 根据具体需求实现
    protected void handleDuplicate(K key, V value) {
        // 默认实现：移除旧元素
        stack.remove(key);
    }
    
    protected void maintainConsistency() {
        // 确保栈和哈希表的一致性
        assert stack.size() == hashMap.size();
    }
}
```

## 🚀 性能分析与优化
### 时间复杂度
+ **基本操作**：O(1) - 入栈、出栈、查找
+ **删除中间元素**：O(n) - 需要重建索引
+ **批量操作**：O(n) - 线性时间

### 空间复杂度
+ **额外空间**：O(n) - 哈希表存储
+ **总空间**：O(2n) - 栈+哈希表

### 优化策略
1. **延迟删除**：标记删除而非立即删除
2. **批量更新**：积累操作后批量处理
3. **内存池**：重用对象减少GC压力
4. **压缩存储**：使用更紧凑的数据结构

## 💡 学习要点与最佳实践
### 1. 设计要点
+ **同步维护**：确保栈和哈希表的一致性
+ **重复处理**：明确重复元素的处理策略

+ **状态不一致**：栈和哈希表状态不同步

栈+哈希表结构通过巧妙结合两种数据结构的优势，为解决复杂的查找和顺序维护问题提供了高效的解决方案。掌握这种混合数据结构的设计思想，将大大提升处理复杂算法问题的能力！
