# LeetCode 739 - 每日温度
## 题目描述
**难度：中等**

给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

### 示例
**示例 1：**

```plain
输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,1,4,2,1,1,0,0]
解释:
第0天: 73°C，第1天是74°C，更高，所以答案是1
第1天: 74°C，第2天是75°C，更高，所以答案是1  
第2天: 75°C，第6天是76°C，更高，所以答案是4
第3天: 71°C，第5天是72°C，更高，所以答案是2
第4天: 69°C，第5天是72°C，更高，所以答案是1
第5天: 72°C，第6天是76°C，更高，所以答案是1
第6天: 76°C，之后没有更高的温度，所以答案是0
第7天: 73°C，之后没有更高的温度，所以答案是0
```

**示例 2：**

```plain
输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]
```

**示例 3：**

```plain
输入: temperatures = [30,60,90]
输出: [1,1,0]
```

### 约束条件
+ `1 <= temperatures.length <= 10^5`
+ `30 <= temperatures[i] <= 100`

## 解题思路
这道题是**单调栈**的经典应用，属于"下一个更大元素"问题的变种。核心思想是维护一个单调递减的栈来快速找到每个元素右侧第一个更大的元素。

### 核心思想：单调递减栈
使用栈来存储数组的索引，栈中的索引对应的温度值保持单调递减：

+ **栈顶**：当前未找到更高温度的最近一天
+ **栈底**：当前未找到更高温度的最远一天

### 算法步骤
1. **初始化**：创建结果数组和单调栈
2. **遍历数组**：
    - **栈不为空且当前温度 > 栈顶温度**：找到了栈顶元素的答案
        * 弹出栈顶索引，计算天数差
        * 重复此过程直到栈为空或当前温度 ≤ 栈顶温度
    - **将当前索引压入栈**：等待寻找更高温度
3. **返回结果**：栈中剩余元素对应的答案都是0

### 单调栈的性质
```plain
单调递减栈的特点:
1. 栈底到栈顶：温度值单调递减
2. 新元素入栈前：弹出所有小于当前元素的栈顶元素
3. 弹出元素时：当前元素就是被弹出元素的"下一个更大元素"

栈的状态变化:
[73] → [74] → [75] → [75,71] → [75,71,69] → [75,72] → [76] → [76,73]
```

## 代码实现
### 方法一：单调栈解法（推荐）
```java
public class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] result = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        
        for (int i = 0; i < n; i++) {
            // 当前温度大于栈顶温度时，找到了栈顶元素的答案
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int prevIndex = stack.pop();
                result[prevIndex] = i - prevIndex;
            }
            // 将当前索引入栈
            stack.push(i);
        }
        
        return result;
    }
}
```

### 方法二：暴力解法（对比参考）
```java
public class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] result = new int[n];
        
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (temperatures[j] > temperatures[i]) {
                    result[i] = j - i;
                    break;
                }
            }
        }
        
        return result;
    }
}
```

### 方法三：逆向遍历优化
```java
public class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] result = new int[n];
        
        for (int i = n - 2; i >= 0; i--) {
            int j = i + 1;
            // 利用已计算的结果跳跃查找
            while (j < n && temperatures[j] <= temperatures[i]) {
                if (result[j] == 0) {
                    j = n; // 没有更高温度
                } else {
                    j += result[j]; // 跳跃到下一个可能的位置
                }
            }
            if (j < n) {
                result[i] = j - i;
            }
        }
        
        return result;
    }
}
```

### 方法四：数组模拟栈（空间优化）
```java
public class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] result = new int[n];
        int[] stack = new int[n]; // 用数组模拟栈
        int top = -1; // 栈顶指针
        
        for (int i = 0; i < n; i++) {
            // 栈不为空且当前温度大于栈顶温度
            while (top >= 0 && temperatures[i] > temperatures[stack[top]]) {
                int prevIndex = stack[top--];
                result[prevIndex] = i - prevIndex;
            }
            // 当前索引入栈
            stack[++top] = i;
        }
        
        return result;
    }
}
```

## 复杂度分析
### 时间复杂度
+ **单调栈解法**：O(n)，每个元素最多入栈和出栈一次
+ **暴力解法**：O(n²)，双重循环遍历
+ **逆向遍历**：O(n)，平均情况下每个元素访问常数次
+ **数组模拟栈**：O(n)，与单调栈解法相同

### 空间复杂度
+ **单调栈解法**：O(n)，栈的最大空间
+ **暴力解法**：O(1)，只使用常数额外空间
+ **逆向遍历**：O(1)，只使用常数额外空间
+ **数组模拟栈**：O(n)，用数组模拟栈

## 关键点总结
### 1. 单调栈的核心思想
+ **单调性维护**：栈中元素保持单调递减
+ **及时处理**：遇到更大元素时立即处理栈中的小元素
+ **索引存储**：栈中存储索引而不是值，便于计算距离

### 2. 算法设计的巧妙之处
+ **一次遍历**：只需要一次遍历就能解决问题
+ **延迟处理**：暂时无法确定答案的元素放入栈中等待
+ **即时更新**：找到答案时立即更新结果

### 3. 栈操作的时机
+ **入栈时机**：当前元素小于等于栈顶元素
+ **出栈时机**：当前元素大于栈顶元素
+ **结果计算**：出栈时计算距离差

### 4. 边界情况处理
+ **空栈判断**：避免空栈时的peek操作
+ **最后元素**：栈中剩余元素的答案都是0
+ **单调序列**：递减序列的特殊处理

### 5. 单调栈模板
```java
// 单调栈通用模板（寻找下一个更大元素）
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();
    
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && nums[i] > nums[stack.peek()]) {
            int index = stack.pop();
            result[index] = i - index; // 或者 nums[i]
        }
        stack.push(i);
    }
    
    return result;
}
```
