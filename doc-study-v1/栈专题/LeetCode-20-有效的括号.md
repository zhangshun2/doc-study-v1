# LeetCode 20 - 有效的括号
## 题目描述
**难度：简单**

给定一个只包含 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

### 示例
**示例 1：**

```plain
输入：s = "()"
输出：true
```

**示例 2：**

```plain
输入：s = "()[]{}"
输出：true
```

**示例 3：**

```plain
输入：s = "(]"
输出：false
```

**示例 4：**

```plain
输入：s = "([)]"
输出：false
```

**示例 5：**

```plain
输入：s = "{[]}"
输出：true
```

### 约束条件
+ `1 <= s.length <= 10^4`
+ `s` 仅由括号 `'()[]{}'` 组成

## 解题思路
### 核心思想
这是一个典型的**栈应用问题**。括号匹配问题的本质是：

+ **左括号**：需要等待对应的右括号来匹配
+ **右括号**：需要找到最近的未匹配的左括号

栈的**后进先出（LIFO）**特性完美契合这个需求：

+ 遇到左括号时，将其压入栈中等待匹配
+ 遇到右括号时，检查栈顶是否为对应的左括号

### 算法步骤
1. **初始化栈**：创建一个空栈用于存储左括号
2. **遍历字符串**：逐个处理每个字符
3. **左括号处理**：遇到 `(`、`[`、`{` 时压入栈
4. **右括号处理**：遇到 `)`、`]`、`}` 时：
    - 检查栈是否为空（无对应左括号）
    - 弹出栈顶元素，检查是否匹配
5. **最终检查**：遍历结束后栈必须为空

### 图解分析
以字符串 `"{[()]}"` 为例：

```plain
步骤 1: 遇到 '{'
栈: ['{']
说明: 左括号入栈

步骤 2: 遇到 '['  
栈: ['{', '[']
说明: 左括号入栈

步骤 3: 遇到 '('
栈: ['{', '[', '(']
说明: 左括号入栈

步骤 4: 遇到 ')'
栈: ['{', '[']
说明: ')' 与栈顶 '(' 匹配，弹出

步骤 5: 遇到 ']'
栈: ['{']
说明: ']' 与栈顶 '[' 匹配，弹出

步骤 6: 遇到 '}'
栈: []
说明: '}' 与栈顶 '{' 匹配，弹出

结果: 栈为空，字符串有效
```

### 错误情况分析
**情况1：右括号多于左括号**

```plain
输入: "())"
步骤1: '(' 入栈 -> [('']
步骤2: ')' 匹配 -> []
步骤3: ')' 时栈为空 -> 无法匹配，返回false
```

**情况2：左括号多于右括号**

```plain
输入: "((("
步骤1-3: 三个'('入栈 -> ['(', '(', '(']
结束: 栈非空 -> 返回false
```

**情况3：括号类型不匹配**

```plain
输入: "(]"
步骤1: '(' 入栈 -> ['(']
步骤2: ']' 与栈顶'('不匹配 -> 返回false
```

## 代码实现
### 方法一：使用栈 + 哈希表
```java
public class Solution {
    public boolean isValid(String s) {
        // 奇数长度的字符串不可能有效
        if (s.length() % 2 == 1) {
            return false;
        }
        
        // 使用哈希表存储括号对应关系
        Map<Character, Character> pairs = new HashMap<Character, Character>() {{
            put(')', '(');
            put(']', '[');
            put('}', '{');
        }};
        
        Deque<Character> stack = new LinkedList<Character>();
        
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            
            if (pairs.containsKey(ch)) {
                // 遇到右括号
                if (stack.isEmpty() || stack.peek() != pairs.get(ch)) {
                    return false;
                }
                stack.pop();
            } else {
                // 遇到左括号
                stack.push(ch);
            }
        }
        
        return stack.isEmpty();
    }
}
```

### 方法二：优化版本（直接判断）
```java
public class Solution {
    public boolean isValid(String s) {
        int n = s.length();
        if (n % 2 == 1) {
            return false;
        }

        Deque<Character> stack = new LinkedList<Character>();
        
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            
            if (ch == '(' || ch == '[' || ch == '{') {
                stack.push(ch);
            } else {
                if (stack.isEmpty()) {
                    return false;
                }
                
                char top = stack.pop();
                if (ch == ')' && top != '(' || 
                    ch == ']' && top != '[' || 
                    ch == '}' && top != '{') {
                    return false;
                }
            }
        }
        
        return stack.isEmpty();
    }
}
```

### 方法三：字符替换法（另类思路）
```java
public class Solution {
    public boolean isValid(String s) {
        int n = s.length();
        if (n % 2 == 1) {
            return false;
        }

        while (s.contains("()") || s.contains("[]") || s.contains("{}")) {
            s = s.replace("()", "");
            s = s.replace("[]", "");
            s = s.replace("{}", "");
        }
        
        return s.isEmpty();
    }
}
```

## 复杂度分析
### 时间复杂度
+ **方法一和二**：O(n)，其中 n 是字符串的长度。需要遍历字符串一次。
+ **方法三**：O(n²)，最坏情况下需要进行 n/2 次替换，每次替换需要 O(n) 时间。

### 空间复杂度
+ **方法一和二**：O(n)，栈的空间复杂度取决于字符串中左括号的数量，最坏情况下为 O(n)。
+ **方法三**：O(n)，字符串替换过程中需要额外空间。

## 关键点总结
### 1. 栈的应用场景
+ **匹配问题**：括号、标签、引号等成对出现的符号
+ **嵌套结构**：需要记住"最近"的未匹配元素
+ **后进先出**：最后遇到的左括号应该最先被匹配

### 2. 边界条件处理
+ **空字符串**：返回 true
+ **奇数长度**：必然无效，直接返回 false
+ **栈为空时遇到右括号**：无对应左括号，返回 false
+ **遍历结束栈非空**：有未匹配的左括号，返回 false

### 3. 优化技巧
+ **提前判断**：奇数长度直接返回 false
+ **哈希表优化**：避免多个 if-else 判断
+ **数据结构选择**：LinkedList 作为栈的实现

### 4. 常见错误
+ **忘记检查栈是否为空**：在弹出元素前必须检查
+ **最终不检查栈状态**：遍历结束后必须确保栈为空
+ **括号类型判断错误**：确保左右括号类型匹配
