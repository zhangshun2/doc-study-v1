## 题解概述（算法选择与理由）
核心思想：为每个字符串构造“签名（signature）”，使得同一组异位词具有相同签名，然后用哈希表按签名分组。

两种常用签名构造：
- 排序签名：对字符串字符排序后得到的序列作为键（简单直观）。
- 计数签名：统计 26 个小写字母的出现次数，序列化为字符串作为键（更高效）。

推荐策略：
- 数据量大、字符串长度中等及以上：优先“计数签名”（时间 `O(N·L)`）。
- 快速实现、字符串较短：可用“排序签名”（时间 `O(N·L log L)`）。

## 模板步骤（排序签名法）
1) 初始化 `Map<String, List<String>> groups`。
2) 遍历每个字符串 `s`：将 `s` 转为字符数组并排序，`key = new String(sorted)`。
3) `groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s)`。
4) 返回 `new ArrayList<>(groups.values())`。

### Java代码（排序签名）
```java
import java.util.*;

class SolutionSortKey {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            char[] arr = s.toCharArray();
            Arrays.sort(arr); // O(L log L)
            String key = new String(arr);
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```

## 模板步骤（计数签名法，推荐）
1) 初始化 `Map<String, List<String>> groups`。
2) 遍历每个字符串 `s`：统计 26 个小写字母频次到 `int[26] count`。
3) 将频次向量序列化为字符串键 `key`（固定顺序 + 明确分隔符，如 `#`），如：`#c0#c1#c2...#c25`。
4) `groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s)`。
5) 返回 `new ArrayList<>(groups.values())`。

### Java代码（计数签名，推荐）
```java
import java.util.*;

class SolutionCountKey {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            int[] count = new int[26];
            for (char ch : s.toCharArray()) {
                count[ch - 'a']++;
            }
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < 26; i++) {
                sb.append('#'); // 分隔符避免歧义
                sb.append(count[i]);
            }
            String key = sb.toString();
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```

## 正确性要点
- 排序签名：异位词排序结果完全一致；非异位词排序后不同。
- 计数签名：同组字符串的每个字母出现次数相同；不同组至少一个字母频次不同。
- 哈希表按键聚合，最终每个键对应一个分组，覆盖全部输入。

## 时间与空间复杂度
- 排序签名：
  - 时间：`O(N · L log L)`（对每个字符串排序）。
  - 空间：`O(N · L)`（存储分组与键），排序可能用到 `O(L)` 额外空间。
- 计数签名：
  - 时间：`O(N · L)`（统计频次）。
  - 空间：`O(N · L)`（存储分组与键），频次数组为 `O(26)`。

## 易错点 Checklist
- 键序列化遗漏分隔符，导致不同向量序列化后粘连产生歧义。
- 未固定序列化顺序（必须 0..25 统一顺序）。
- 忘记处理空串 `""`（频次均为 0，仍需归为一组）。
- 字母集假设错误（若包含大写或非英文字符，需扩展计数维度或改签名方案）。
- 误用对象作为键（如直接用 `int[]` 作为 `Map` 键，比较按引用而非值）。

## 记忆卡片（快速回忆）
- “签名分组”：为每个元素构造可比较的签名，哈希表聚合。
- 排序法：简单、直观；适合快速实现。
- 计数法：高效、稳定；适合大数据量，需注意序列化键。
