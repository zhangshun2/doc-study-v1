# 微模板与易错点卡片｜49 字母异位词分组

## 微模板（Java）

### 1) 排序签名（简单上手）
```java
List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] arr = s.toCharArray();
        Arrays.sort(arr);            // O(L log L)
        String key = new String(arr);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```

### 2) 计数签名（更高效）
```java
List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        int[] cnt = new int[26];
        for (char ch : s.toCharArray()) {
            cnt[ch - 'a']++;        // 仅限小写 a-z
        }
        // 序列化：固定顺序 + 分隔符，避免歧义
        StringBuilder sb = new StringBuilder(26 * 2);
        for (int i = 0; i < 26; i++) {
            sb.append('#').append(cnt[i]);
        }
        String key = sb.toString(); // O(L)
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```

## 易错点卡片
- 计数签名必须固定顺序并加分隔符，否则出现 "1,11" 与 "11,1" 歧义。
- 不要用 `int[]` 直接作为 `Map` 的键；需序列化为 `String` 或封装成不可变对象并重写 `hashCode/equals`。
- 输入若包含非小写字母（大写/符号），需扩容计数或预处理统一到小写，否则会越界。
- 大数据时计数签名更优（`O(L)`），排序签名在 `L` 较大时可能变慢（`O(L log L)`）。
- 注意 `computeIfAbsent` 的使用，避免 `NullPointerException` 与重复 `put`。
