# 题解2.0.1-字母异位词分组（易于记忆的官方题解）

## 思路概述（易懂版）
- 核心：对每个字符串排序后的结果作为签名，哈希分组。
- 流程：
  1) 遍历字符串数组，对每个字符串排序得到 `key`
  2) 使用 `Map<String, List<String>>` 将相同 `key` 的字符串聚合
  3) 返回 `map.values()`

## 复杂度
- 时间：O(n * L log L)（L为字符串平均长度）
- 空间：O(n * L)

## 代码（Java，排序签名）
```java
import java.util.*;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            char[] arr = s.toCharArray();
            Arrays.sort(arr);
            String key = new String(arr);
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```

## 记忆要点
- “排序即签名”最直观：相同字母的重排排序后必相等。
- 计数签名更快但更抽象；排序签名更易懂更通用。
