# 题解2.0.1-最小覆盖子串（易于记忆的官方题解）

## 思路概述（易懂版）
- 核心：维护两个 `Map<Character,Integer>`：`need`（t计数）与 `win`（窗口计数），以及 `formed`（已满足计数的字符种类数）。
- 流程：
  1) 预处理 `need`，统计 `required = need.size()`
  2) 右指针右移，更新 `win`，当某字符计数达到 `need` 时 `formed++`
  3) 当 `formed == required`，尝试左缩：更新最优答案；左缩使某字符计数低于 `need` 时，`formed--`，停止左缩

## 复杂度
- 时间：O(n)
- 空间：O(字符种类数)

## 代码（Java，Map计数 + formed）
```java
import java.util.*;

class Solution {
    public String minWindow(String s, String t) {
        if (t.length() == 0 || s.length() < t.length()) return "";
        Map<Character, Integer> need = new HashMap<>();
        for (char c : t.toCharArray()) need.put(c, need.getOrDefault(c, 0) + 1);
        int required = need.size();

        Map<Character, Integer> win = new HashMap<>();
        int formed = 0;
        int left = 0;
        int bestLen = Integer.MAX_VALUE, bestL = 0;

        for (int r = 0; r < s.length(); r++) {
            char c = s.charAt(r);
            win.put(c, win.getOrDefault(c, 0) + 1);
            if (need.containsKey(c) && win.get(c).intValue() == need.get(c).intValue()) {
                formed++;
            }
            while (formed == required) {
                if (r - left + 1 < bestLen) {
                    bestLen = r - left + 1;
                    bestL = left;
                }
                char lc = s.charAt(left);
                win.put(lc, win.get(lc) - 1);
                if (need.containsKey(lc) && win.get(lc).intValue() < need.get(lc).intValue()) {
                    formed--;
                }
                left++;
            }
        }
        return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestL, bestL + bestLen);
    }
}
```

## 记忆要点
- `formed == required` 即窗口满足覆盖；左缩保持覆盖同时尽量短。
- 用 `Map` 更贴近官方思路，便于理解“满足计数”的语义。
