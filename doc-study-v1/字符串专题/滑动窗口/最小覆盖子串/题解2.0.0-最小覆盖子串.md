# 题解2.0.0-最小覆盖子串

## 概述
技巧：滑动窗口 + 计数匹配。
核心：右扩直到覆盖 `t`，左缩剔除无关或过量字符，维护最短长度。

## 解法讲解
1. 统计 `t` 的需求计数 `need[]`
2. 右指针移动，更新 `window[]`，当某字符计数达到需求时增加 `match`
3. 当 `match == needDistinct`（或覆盖条件成立）时，尝试左缩：
   - 更新最优答案
   - 左指针剔除，若使某字符计数低于需求，则覆盖失效，停止左缩

## 复杂度
- 时间：O(n)
- 空间：O(1)（常数字符集）

## 代码（Java）
```java
class Solution {
    public String minWindow(String s, String t) {
        if (t.length() == 0 || s.length() < t.length()) return "";
        int[] need = new int[128];
        int needKinds = 0;
        for (char c : t.toCharArray()) {
            if (need[c] == 0) needKinds++;
            need[c]++;
        }
        int[] win = new int[128];
        int match = 0;
        int left = 0;
        int bestLen = Integer.MAX_VALUE;
        int bestL = 0;
        for (int r = 0; r < s.length(); r++) {
            char c = s.charAt(r);
            win[c]++;
            if (need[c] > 0 && win[c] == need[c]) {
                match++;
            }
            while (match == needKinds) {
                if (r - left + 1 < bestLen) {
                    bestLen = r - left + 1;
                    bestL = left;
                }
                char lc = s.charAt(left);
                if (need[lc] > 0 && win[lc] == need[lc]) {
                    match--;
                }
                win[lc]--;
                left++;
            }
        }
        return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestL, bestL + bestLen);
    }
}
```

## 边界与陷阱
- 需求字符可能重复：用计数而非集合判断覆盖
- 左缩过程中更新 `match` 的时机与条件必须正确
