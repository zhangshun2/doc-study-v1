# 微模板与易错点卡片｜76 最小覆盖子串

## 微模板（Java）
```java
String minWindow(String s, String t) {
    int[] need = new int[256];
    int required = 0;
    for (char c : t.toCharArray()) { if (need[c]++ == 0) required++; }

    int[] win = new int[256];
    int formed = 0;
    int l = 0, bestLen = Integer.MAX_VALUE, bestL = 0;

    for (int r = 0; r < s.length(); r++) {
        char c = s.charAt(r);
        if (need[c] > 0 && ++win[c] == need[c]) formed++;

        while (formed == required) {             // 窗口已满足覆盖
            if (r - l + 1 < bestLen) { bestLen = r - l + 1; bestL = l; }
            char d = s.charAt(l++);
            if (need[d] > 0 && --win[d] < need[d]) formed--; // 失去满足性
        }
    }
    return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestL, bestL + bestLen);
}
```

## 易错点卡片
- `formed == required` 才能收缩；不要把“窗口包含所有字符”误写成“某个计数为正”。
- 仅对 `need[c] > 0` 的字符维护 `win` 与 `formed`，不需要为无关字符检查。
- 更新答案在收缩循环内部进行，避免遗漏更短窗口。
- 计数比较使用 `==` 或 `<` 时机要准确：失去满足性条件为 `--win[d] < need[d]`。
