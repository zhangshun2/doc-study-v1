# 问题1.0.0-最小覆盖子串

## 概述
LeetCode 76：给定字符串 `s` 与 `t`，求 `s` 中最短的子串，包含 `t` 的全部字符（计数要求）。
链接：https://leetcode.cn/problems/minimum-window-substring/

## 输入与输出
- 输入：字符串 `s`、`t`
- 输出：字符串，最短覆盖子串；若不存在返回空串

## 特征提炼
- 窗口约束为“窗口内字符计数覆盖 `t` 的全部需求”
- 典型“可变窗口”：右扩满足约束，左缩尽量短
- 需要双计数结构：`need`（目标计数）、`window`（窗口计数）

## 引导思路
- 如何判断当前窗口“已满足覆盖”？（匹配计数 vs. 覆盖条件）
- 左缩时哪些字符的计数会影响覆盖状态？
- 如何在遍历过程中记录并更新最优答案？

## 可能涉及的知识点
- 滑动窗口（计数型）
- 哈希表/数组计数
- 双指针（左右边界收缩与扩展）
