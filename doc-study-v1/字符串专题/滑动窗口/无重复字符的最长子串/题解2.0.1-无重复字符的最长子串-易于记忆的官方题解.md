# 题解2.0.1-无重复字符的最长子串（易于记忆的官方题解）

## 思路概述（易懂版）
- 核心：用一个 `HashSet` 维护当前窗口内的字符集合；右指针向右扩展，遇到重复就移动左指针并从集合中移除左侧字符，直到不重复。
- 模板化：
  1) `while (右指针未到尽头)`：尝试加入 `s[r]`
  2) 若 `s[r]` 已在集合中：`while (重复)` 左指针前进并移除左侧字符
  3) 更新最长长度

## 复杂度
- 时间：O(n)
- 空间：O(min(n, 字符集大小))

## 代码（Java，窗口+集合）
```java
import java.util.*;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> set = new HashSet<>();
        int n = s.length();
        int left = 0, ans = 0;
        for (int r = 0; r < n; r++) {
            char c = s.charAt(r);
            while (set.contains(c)) {
                set.remove(s.charAt(left));
                left++;
            }
            set.add(c);
            ans = Math.max(ans, r - left + 1);
        }
        return ans;
    }
}
```

## 记忆要点
- 集合只存“当前窗口”的元素；重复就“缩左”直到合法。
- 每次右指针加入新字符后，窗口长度可更新。
