# 微模板与易错点卡片｜3 无重复字符的最长子串

## 微模板（Java）

### 1) 计数数组版本（直观）
```java
int lengthOfLongestSubstring(String s) {
    int[] freq = new int[256];
    int l = 0, ans = 0;
    for (int r = 0; r < s.length(); r++) {
        char c = s.charAt(r);
        freq[c]++;
        while (freq[c] > 1) {           // 窗口内出现重复
            freq[s.charAt(l)]--;
            l++;
        }
        ans = Math.max(ans, r - l + 1); // 更新答案在收缩之后
    }
    return ans;
}
```

### 2) 下标哈希版本（更常用）
```java
int lengthOfLongestSubstring(String s) {
    int[] last = new int[256];
    Arrays.fill(last, -1);
    int l = 0, ans = 0;
    for (int r = 0; r < s.length(); r++) {
        char c = s.charAt(r);
        if (last[c] >= l) {             // c 在当前窗口内出现过
            l = last[c] + 1;            // 跳到重复字符的下一个位置
        }
        last[c] = r;
        ans = Math.max(ans, r - l + 1);
    }
    return ans;
}
```

## 易错点卡片
- 更新答案时机：应在窗口满足“无重复”后再更新，否则会统计到非法窗口。
- 计数数组与下标数组不同：前者用 `while` 收缩，后者通过跳跃 `l = last[c] + 1`。
- 字符范围：如含 Unicode，高位字符可能超出 `256`，需改用 `Map<Character, Integer>`。
- 初始值：`last` 数组需要初始化为 `-1`，避免将字符默认认作在索引 `0` 出现过。
