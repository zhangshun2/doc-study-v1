## 概述
技巧：滑动窗口 + 哈希（字符最后出现位置）。
核心：右指针遍历，左指针依据重复字符的上次位置跳转，维持窗口“无重复”。

## 解法讲解
1. 使用数组 `last[128]` 记录字符上次出现位置，初始化为 `-1`
2. 遍历 `s` 的右指针 `r`：
   - 若 `last[c] >= left`，说明当前字符 `c` 在窗口内重复，更新 `left = last[c] + 1`
   - 更新 `last[c] = r`
   - 更新答案 `ans = max(ans, r - left + 1)`

## 复杂度
- 时间：O(n)
- 空间：O(1)（常数 128/256）

## 代码（Java）
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[128];
        for (int i = 0; i < 128; i++) last[i] = -1;
        int left = 0, ans = 0;
        for (int r = 0; r < s.length(); r++) {
            char c = s.charAt(r);
            if (last[c] >= left) {
                left = last[c] + 1;
            }
            last[c] = r;
            ans = Math.max(ans, r - left + 1);
        }
        return ans;
    }
}
```

## 正确性要点（不变式）
- 窗口区间 `[left..r]` 内字符不重复，作为循环不变式维持
- 当遇到字符 `c` 重复出现位置在窗口内时，左边界跳转到 `last[c] + 1` 保证不重复
- 左边界单调不减，窗口不会后退，整体线性扫描

## 边界与陷阱
- 连续重复字符：确保左指针跳转到“上次位置+1”而非递增 1
- 字符集：若包含非ASCII，可改用 `Map<Character,Integer>`
- 更新答案时机：每次右指针推进后，使用当前合法窗口长度 `r - left + 1`
- Set 写法需 `while` 收缩左侧直到合法；索引写法只需一次跳转
