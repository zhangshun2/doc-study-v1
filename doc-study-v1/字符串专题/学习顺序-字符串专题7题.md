## 套路速通与骨架

### 哈希分组（49）
- 核心：为每个字符串构造“签名（signature）”，同签名聚一组。
- 两法：
  - 排序签名：对字符排序后作为键（简单，单串 `O(L log L)`）。
  - 计数签名：`int[26]` 统计频次并序列化为键（高效，单串 `O(L)`）。
- 先修：`ch - 'a'` 索引映射，见概念文档。

### 滑动窗口（3、76）
- 骨架：
  - `for (r) { add(s[r]); while (条件满足) { update ans; remove(s[l]); l++; } }`
- 3 题关键：窗口内不能重复，常用 `Set/Map` 维护计数；条件是“出现次数 <= 1”。
- 76 题关键：
  - 维护 `need`（目标字符计数）与 `window`（当前窗口计数）。
  - `valid` 表示窗口是否满足所有 `need`。
  - 满足后尽量收缩以取最短。

### 中心扩展（647、5）
- 骨架：
  - `expand(l, r) { while (l>=0 && r<n && s[l]==s[r]) { l--; r++; } }`
- 647：枚举所有中心（奇/偶），扩展时每次找到回文就计数。
- 5：同样扩展，但维护 `[bestL, bestR]` 最长区间。

### 字符串DP（72、10）
- 72 编辑距离：
  - `dp[i][j]`：`s[0..i)` 到 `p[0..j)` 的最少操作数。
  - 转移：`min( dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1]+cost )`，`cost=0/1`（相等/替换）。
- 10 正则匹配：
  - `dp[i][j]`：`s[0..i)` 是否匹配 `p[0..j)`。
  - 非 `*`：`dp[i][j] = match(s[i-1], p[j-1]) && dp[i-1][j-1]`。
  - `*`：`dp[i][j] = dp[i][j-2] || ( match(s[i-1], p[j-2]) && dp[i-1][j] )`。
  - 初始化空串：`dp[0][0]=true`；`dp[0][j]` 仅当前缀形如 `a*b*c*`。

## 常见坑与校验
- 滑动窗口：何时收缩、何时更新答案，条件写反最常见。
- 中心扩展：奇偶中心都要覆盖；越界检查要完整。
- 哈希键序列化：频次向量必须加分隔符（如 `#`），避免歧义。
- DP 初始化：空串/空模式的边界，尤其正则的 `*`。
