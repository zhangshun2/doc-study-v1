# 题解2.0.1-最长回文子串（易于记忆的官方题解）

## 思路概述（易懂版）
- 核心：以每个位置为中心做“左右扩展”，同时考虑奇偶中心（`i,i` 与 `i,i+1`）。
- 流程：
  1) 遍历所有中心，分别扩展得到长度 `len1`（奇数）、`len2`（偶数）
  2) 取最大长度，更新全局最优的左右边界

## 复杂度
- 时间：O(n^2)
- 空间：O(1)

## 代码（Java，中心扩展）
```java
class Solution {
    public String longestPalindrome(String s) {
        int n = s.length();
        if (n < 2) return s;
        int start = 0, end = 0;
        for (int i = 0; i < n; i++) {
            int len1 = expand(s, i, i);     // 奇数中心
            int len2 = expand(s, i, i + 1); // 偶数中心
            int len = Math.max(len1, len2);
            if (len > end - start + 1) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }
        return s.substring(start, end + 1);
    }

    private int expand(String s, int l, int r) {
        int n = s.length();
        while (l >= 0 && r < n && s.charAt(l) == s.charAt(r)) {
            l--; r++;
        }
        return r - l - 1; // 退出时多走了一步
    }
}
```

## 记忆要点
- 奇偶中心都要扩；长度转坐标的公式要熟悉。
- 边界判断统一用 `while (l>=0 && r<n && s[l]==s[r])`。
