# 问题1.0.0-最长回文子串

## 概述
LeetCode 5：给定字符串 `s`，返回其最长回文子串。
链接：https://leetcode.cn/problems/longest-palindromic-substring/

## 输入与输出
- 输入：字符串 `s`
- 输出：字符串，最长回文子串

## 特征提炼
- 回文的核心性质：关于某中心对称（奇偶两类中心）
- 典型双指针中心扩展：从中心向两边扩展，直到不满足回文
- 可选DP：通过区间DP预判 `s[i..j]` 是否回文

## 引导思路
- 需要枚举哪些中心？奇数与偶数中心如何处理？
- 如何更新全局最优（最长长度与起止位置）？
- 与DP的关系：何时适合用中心扩展，何时适合DP？

## 可能涉及的知识点
- 双指针（中心扩展）
- 字符串
- 动态规划（可选）
