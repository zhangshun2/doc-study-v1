## 这题到底在求什么？
- 回文子串：左右对称的连续片段，比如 `"aba"`、`"abba"`。
- 目标：在字符串 `s` 中找到长度最长的那一段回文子串，返回具体子串。

## 为什么用“中心扩展”？
- 每个回文都有一个中心：v
  - 奇数长度的回文（如 `racecar`），中心是某个字符（这里是 `e`）。
  - 偶数长度的回文（如 `abba`），中心在两个字符之间（这里在 `b|b` 之间）。
- 把每个位置都当作中心，向两边比对字符，能覆盖所有回文子串；只要扩不动了，当前中心能得到的最长回文就确定了。

## 步骤图解（手撕过程）
以 `s = "babad"` 为例：
1. i=0（字符 'b'）：
   - 奇中心 (0,0)：'b' → 左右比对失败 → 回文长度 1
   - 偶中心 (0,1)：'b'|"a" 不等 → 长度 0
2. i=1（字符 'a'）：
   - 奇中心 (1,1)：'a' → 左右扩到 `(0,2)`，得到 `"bab"`，长度 3
   - 偶中心 (1,2)：'a'|"b" 不等 → 长度 0
3. i=2（字符 'b'）：
   - 奇中心 (2,2)：'b' → 左右扩到 `(1,3)`，得到 `"aba"`，长度 3
   - 偶中心 (2,3)：'b'|"a" 不等 → 长度 0
最终答案是长度 3 的 `"bab"` 或 `"aba"`（返回哪个取决于起点计算）。

更多例子：
- `"cbbd"` → `"bb"`（只能偶中心抓到）
- `"aaaa"` → `"aaaa"`（每个中心都能扩到全串）
- `"abc"` → `"a"`（没有长度>1的回文，只能返回任意单字符）
- `"racecar"` → `"racecar"`（奇中心的经典例子）
- `"abba"` → `"abba"`（偶中心的经典例子）

## Java 代码（逐行注释）
```java
class Solution {
    public String longestPalindrome(String s) {
        // 空串或 1 个字符，直接是答案
        if (s == null || s.length() < 2) return s;

        int start = 0;   // 最优子串的起点
        int maxLen = 1;  // 最优子串的长度（至少为 1）

        // 遍历每一个可能的中心位置 i
        for (int i = 0; i < s.length(); i++) {
            // 以 i 为奇数中心扩展
            int len1 = expand(s, i, i);
            // 以 i 和 i+1 为偶数中心扩展
            int len2 = expand(s, i, i + 1);
            int len = Math.max(len1, len2); // 本次最大的回文长度

            if (len > maxLen) {
                maxLen = len;
                // 根据中心 i 和长度 len 计算起点：统一公式
                // 例：i=2, len=3 -> 起点 = 2 - (3-1)/2 = 1（对应 "aba"）
                // 例：i=1, len=4 -> 起点 = 1 - (4-1)/2 = 0（对应 "abba"）
                start = i - (len - 1) / 2;
            }
        }
        // 截取并返回答案
        return s.substring(start, start + maxLen);
    }

    // 从 (l, r) 作为中心向两边扩展，返回能扩到的最大回文长度
    private int expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--; // 左指针左移
            r++; // 右指针右移
        }
        // 退出时 (l, r) 已经不合法或字符不等，回文区间是 (l+1, r-1)
        // 长度为 r - l - 1（两端各收缩了一格）
        return r - l - 1;
    }
}
```

## 为什么退出时区间是 `(l+1, r-1)`
- 核心原因：循环退出时，当前左右指针 `l` 和 `r` 已经“越过了”能匹配的那一对边界，因此真正的回文边界是它们各自回退一格的区间，也就是闭区间 `[l+1, r-1]`。
- 直觉解释：
  - 循环条件是 `while (l >= 0 && r < n && s.charAt(l) == s.charAt(r)) { l--; r++; }`。
  - 每次匹配成功都会向外扩一格（`l--, r++`），所以当退出时只能因为越界或不相等，退出时的 `(l, r)` 不属于回文边界。
  - 最后一次仍然匹配成功的边界就是它们各自回退一格，即 `l+1` 和 `r-1`。
- 两个例子：
  - `s = "aba"`，奇中心 `(i=1)`：
    - 初始 `l=1, r=1`；匹配 `b==b` → 扩到 `l=0, r=2`
    - 匹配 `a==a` → 扩到 `l=-1, r=3`；停止（越界）
    - 有效区间是 `l+1=0` 到 `r-1=2`，即 `"aba"`。
  - `s = "cbbd"`，偶中心 `(i=1, i+1=2)`：
    - 初始 `l=1, r=2`；匹配 `b==b` → 扩到 `l=0, r=3`
    - 比较 `c!=d` → 停止（不相等）
    - 有效区间是 `l+1=1` 到 `r-1=2`，即 `"bb"`。
- 不变式视角：
  - 每次进入循环时都有不变式：`s[l+1..r-1]` 是回文。
  - 一次成功匹配后，回文的边界扩大为新的 `s[(l-1)+1 .. (r+1)-1] == s[l .. r]`。
  - 当下一次循环不满足条件（越界/不等）时，上一次的回文边界仍然是 `s[l+1..r-1]`，这是在当前中心下能扩到的最大范围。
- 结论与长度公式：
  - 退出时有效回文区间是 `[l+1, r-1]`（闭区间）。
  - 长度为 `r - l - 1`（右边界 `r-1` 减去左边界 `l+1` 再加 1，化简即 `r - l - 1`）。
  - 这也解释了为什么 `expand` 返回写成 `return r - l - 1;`，且循环条件需要包含等号 `l >= 0` 才能扩到第 0 位。

## 起点公式详解（为什么用 `start = i - (len - 1) / 2`）
- 目标：已知“中心位置 `i`”和“回文长度 `len`”，反推出左起点 `start`。
- 奇数长度回文：令可扩步数为 `k`，则 `len = 2k + 1`，中心是字符 `i`，起点应为 `i - k`。
  - 由于 `(len - 1) / 2 = (2k + 1 - 1) / 2 = k`，统一公式给出 `start = i - (len - 1) / 2 = i - k`，正确。
- 偶数长度回文：令可扩步数为 `k`，则 `len = 2k`，中心在 `i|i+1` 之间（取左中心为 `i`），起点应为 `i - (k - 1)`。
  - 由于 `(len - 1) / 2 = (2k - 1) / 2 = k - 1`（整数除法向下取整），统一公式给出 `start = i - (len - 1) / 2 = i - (k - 1)`，正确。
- 结论：`start = i - (len - 1) / 2` 同时适用于奇、偶两种回文长度，依赖整数除法的向下取整特性。
- 常见误区：不要写成 `start = i - len / 2`。对于偶数长度（如 `len = 4`），`len / 2 = 2`，会多退一位导致起点偏左。
- 快速验证：
  - `"aba"`：取中心 `i = 1`（'b'），`len = 3` → `start = 1 - (3 - 1) / 2 = 0`，得到 `s[0..2] = "aba"`。
  - `"abba"`：取左中心 `i = 1`（左侧 'b'），`len = 4` → `start = 1 - (4 - 1) / 2 = 0`，得到 `s[0..3] = "abba"`。
  - `"cbbd"` 的 `"bb"`：取左中心 `i = 1`（左侧 'b'），`len = 2` → `start = 1 - (2 - 1) / 2 = 1`，得到 `s[1..2] = "bb"`。
  - `"racecar"`：取中心 `i = 3`（'e'），`len = 7` → `start = 3 - (7 - 1) / 2 = 0`，得到整串。
- 一句记忆：奇数退半，偶数退半再“加一”——统一公式已经隐含这个“加一”，直接用即可。

## 复杂度直觉
- 每个中心扩展最多走到头，近似 O(n)；中心有 n 个 → 总体近似 O(n^2)。
- 只用常数个指针和整数变量 → 空间 O(1)。

## 易错点 Checklist
- 偶中心 `(i, i+1)` 不能忘（否则抓不到 `"bb"`、`"abba"`）。
- 起点统一用 `start = i - (len - 1) / 2`，不要写成 `i - len / 2`。
- 扩展时先判断越界再访问字符，防止数组越界。
- 返回一个最长即可；若要返回所有最长，需要另外收集和去重。

## 思维旁注（小卡片）
- 路线选择：先做“返回长度”，再做“返回子串”。原因：先把扩展逻辑和最大长度跑通，减少一次性处理起点计算的心智负担。
- 中心枚举口诀：奇中心 `(i, i)`；偶中心 `(i, i+1)`。写循环时就按这个节奏敲，避免忘偶中心导致错过 `"bb"`、`"abba"`。
- 起点公式一条龙：`start = i - (len - 1) / 2`，奇偶统一；不要写成 `i - len / 2`。
- 扩展不变式：扩到任何一步时 `(l+1, r-1)` 保持为回文；退出后长度就是 `r - l - 1`。
- 调试套路：打印 `i, len1, len2, len, start, maxLen`，用 `"cbbd"` 和 `"abba"` 快速验证偶中心是否覆盖。
- 边界心法：空串直接返回；全相同（例如 `"aaaa"`）整串是回文；全不同（例如 `"abcdef"`）最大长度为 1。

### 版本 A：只返回最长回文的长度（练手版）
```java
class SolutionA {
    public int longestPalindromeLen(String s) {
        if (s == null || s.length() < 2) return s == null ? 0 : s.length();
        int maxLen = 1;
        for (int i = 0; i < s.length(); i++) {
            int len1 = expand(s, i, i);       // 奇中心
            int len2 = expand(s, i, i + 1);   // 偶中心
            maxLen = Math.max(maxLen, Math.max(len1, len2));
        }
        return maxLen;
    }

    private int expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--; r++;
        }
        return r - l - 1;
    }
}
```

### 版本 B：返回具体子串（正式版）

class SolutionB {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) return s;
        int start = 0, maxLen = 1;
        for (int i = 0; i < s.length(); i++) {
            int len1 = expand(s, i, i);

}

## Python 对照版（逐行注释）
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        # 空串或长度为 1，直接返回自身
        if s is None or len(s) < 2:
            return s

        start = 0      # 最优子串起点
        max_len = 1    # 最优子串长度

        # 遍历每一个中心位置 i
        for i in range(len(s)):
            # 奇中心：以 i 为中心扩展
            len1 = self.expand(s, i, i)
            # 偶中心：以 i 和 i+1 为中心扩展
            len2 = self.expand(s, i, i + 1)
            curr = max(len1, len2)

            if curr > max_len:
                max_len = curr
                # 统一公式：奇偶都适用；Python 用整数整除 //
                start = i - (curr - 1) // 2

        # 截取并返回答案
        return s[start:start + max_len]

    def expand(self, s: str, l: int, r: int) -> int:
        # 从中心 (l, r) 向两侧扩展，只要左右字符相等就继续
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1
            r += 1
        # 退出时有效回文区间是 (l+1, r-1)，长度为 r - l - 1
        return r - l - 1
```
