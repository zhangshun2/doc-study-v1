## 概述
技巧：双指针中心扩展。
核心：枚举每个位置作为奇/偶中心，向两边扩展，记录最长区间。

## 解法讲解
1. 定义扩展函数 `expand(l, r)`：当 `s[l] == s[r]` 时左右扩展，返回区间长度
2. 对每个索引 `i`：
   - 奇数中心：`len1 = expand(i, i)`
   - 偶数中心：`len2 = expand(i, i+1)`
   - 取最大长度，更新最佳起点与长度

## 复杂度
- 时间：O(n^2)（最坏情况下）
- 空间：O(1)

## 代码（Java，含详细注释）
```java
class Solution {
    public String longestPalindrome(String s) {
        // 边界：空串或长度为 1，直接返回自身
        if (s == null || s.length() < 2) return s;

        // 记录最长回文子串的起点与长度
        int start = 0, maxLen = 1;

        // 枚举每一个中心位置 i
        for (int i = 0; i < s.length(); i++) {
            // 奇数长度回文：中心在 i（例如 "racecar" 的中心是 'e'）
            int len1 = expand(s, i, i);
            // 偶数长度回文：中心在 i 和 i+1 之间（例如 "abba" 的中心在 b|b 之间）
            int len2 = expand(s, i, i + 1);
            // 取两者较大者作为以 i 为中心能得到的最长回文长度
            int len = Math.max(len1, len2);
            // 如果更长，则更新答案区间的起点和长度
            if (len > maxLen) {
                maxLen = len;
                // 关键：根据中心 i 和长度 len 反推起点
                // 当 len 为奇数，如 7：起点 = i - (7 - 1) / 2 = i - 3
                // 当 len 为偶数，如 4：起点 = i - (4 - 1) / 2 = i - 1（此公式也适用于偶中心）
                start = i - (len - 1) / 2;
            }
        }
        // 返回从起点开始、长度为 maxLen 的子串
        return s.substring(start, start + maxLen);
    }

    private int expand(String s, int l, int r) {
        // 从中心 (l, r) 向两侧扩展，只要左右字符相等就继续
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            l--; // 左指针向左移动
            r++; // 右指针向右移动
        }
        // 退出循环时，(l, r) 已经越界或字符不相等
        // 有效的回文区间是 (l+1, r-1)，长度为 r - l - 1
        return r - l - 1;
    }
}
```

## 示例与演示
- 示例1：`"babad"` → 最长回文可能为 `"bab"` 或 `"aba"`
  - i=0:'b' 以 (0,0) 扩展：b → 不能继续；以 (0,1) 扩展：b|a 不等；当前最佳 `len=1`
  - i=1:'a' 以 (1,1) 扩展：a → b a b，可扩到 `(0,2)`，`len1=3`；以 (1,2) 扩展：a|b 不等；更新最佳为 `start=0,len=3`
  - i=2:'b' 以 (2,2) 扩展：b a b，可扩到 `(1,3)`，`len1=3`；以 (2,3) 扩展：b|a 不等；最佳保持
- 示例2：`"cbbd"` → 最长回文为 `"bb"`
  - i=1:'b' 与 i=2:'b' 之间偶中心 (1,2) 扩展：b|b → 左右扩失败后长度=2，更新最佳 `start=1,len=2`
- 示例3：`"aaaa"` → 最长回文为 `"aaaa"`
  - 多个中心都会扩展到整串，最终 `start=0,len=4`
- 示例4：`"abc"` → 任意单字符都是回文，最长为 `"a"`、`"b"` 或 `"c"`，代码返回 `"a"`
- 示例5：`"racecar"`（奇中心） → 以 'e' 为中心扩展得到整串，长度 7
- 示例6：`"abba"`（偶中心） → 以 b|b 为中心扩展得到整串，长度 4

## 正确性要点（不变式）
- 扩展不变式：在扩展过程中始终保持区间 `(l+1, r-1)` 为回文。
- 覆盖性：每个字符作为中心都被考虑到，奇偶两类中心保证不会遗漏任何可能的最长回文。
- 起点计算公式的统一性：`start = i - (len - 1) / 2` 同时适用于奇、偶长度回文。

## 边界与陷阱
- 偶数中心必须从 `(i, i+1)` 开始，别遗漏（否则错过如 `"abba"`）。
- 所有字符相同（如 `"aaaa"`）或全不相同（如 `"abc"`）的边界情况要能正确处理。
- 起点计算常见误区：用 `start = i - len / 2` 会在偶数长度时出错，统一使用 `start = i - (len - 1) / 2`。
- 扩展时先检查越界再比较字符，避免 `IndexOutOfBoundsException`。
- 若需要返回首次出现的最长回文，当前写法即满足；若需要返回所有最长回文，需要额外收集。
