# 微模板与易错点卡片｜5 最长回文子串

## 微模板（Java）
```java
String longestPalindrome(String s) {
    int n = s.length(), bestL = 0, bestR = 0;
    for (int center = 0; center < n; center++) {
        int[] a = expand(s, center, center);
        int[] b = expand(s, center, center + 1);
        if (a[1] - a[0] > bestR - bestL) { bestL = a[0]; bestR = a[1]; }
        if (b[1] - b[0] > bestR - bestL) { bestL = b[0]; bestR = b[1]; }
    }
    return s.substring(bestL, bestR + 1);
}

int[] expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return new int[]{ l + 1, r - 1 }; // 回到有效区间
}
```

## 易错点卡片
- 返回区间是闭区间 `[L,R]`，截取时使用 `substring(L, R+1)`。
- 比较长度时使用 `R-L`，避免 off-by-one。
- 两类中心都要尝试，尤其字符串中存在重复字符时偶数中心很常见。
