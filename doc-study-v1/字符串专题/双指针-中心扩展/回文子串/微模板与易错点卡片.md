# 微模板与易错点卡片｜647 回文子串

## 微模板（Java）
```java
int countSubstrings(String s) {
    int n = s.length(), ans = 0;
    for (int center = 0; center < n; center++) {
        ans += expand(s, center, center);     // 奇数长度
        ans += expand(s, center, center + 1); // 偶数长度
    }
    return ans;
}

int expand(String s, int l, int r) {
    int cnt = 0;
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        cnt++; l--; r++;
    }
    return cnt;
}
```

## 易错点卡片
- 奇/偶中心都要枚举，否则会漏掉偶数长度回文。
- 扩展边界严格检查：`l >= 0 && r < n`；字符比较必须在边界内。
- 计数逻辑是“每次匹配成功即 +1”，不要只记录最长导致漏计。
