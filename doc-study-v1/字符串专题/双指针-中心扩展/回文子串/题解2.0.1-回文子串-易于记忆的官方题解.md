# 题解2.0.1-回文子串（易于记忆的官方题解）

## 思路概述（易懂版）
- 核心：以每个位置为中心，统计能扩出的回文次数（奇偶中心都算）。
- 流程：
  1) 枚举中心 `i`，调用一次奇数扩展与一次偶数扩展
  2) 累加扩展过程中每次成功匹配的次数，即为回文子串总数

## 复杂度
- 时间：O(n^2)
- 空间：O(1)

## 代码（Java，中心计数）
```java
class Solution {
    public int countSubstrings(String s) {
        int n = s.length();
        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans += expandCount(s, i, i);     // 奇数中心
            ans += expandCount(s, i, i + 1); // 偶数中心
        }
        return ans;
    }

    private int expandCount(String s, int l, int r) {
        int n = s.length();
        int cnt = 0;
        while (l >= 0 && r < n && s.charAt(l) == s.charAt(r)) {
            cnt++;
            l--; r++;
        }
        return cnt;
    }
}
```

## 记忆要点
- 统计的是“扩展次数”，不需要存具体子串。
- 奇偶中心都要统计，否则会漏解。
