# 题解2.0.0-回文子串

## 概述
技巧：双指针中心扩展（统计型）。
核心：枚举所有中心，扩展一次计数一次，累加为总回文个数。

## 解法讲解
1. 遍历每个索引 `i`，统计：
   - 奇数中心：以 `(i, i)` 扩展
   - 偶数中心：以 `(i, i+1)` 扩展
2. 扩展函数每成功一次（字符相等），即增加计数

## 复杂度
- 时间：O(n^2)
- 空间：O(1)

## 代码（Java）
```java
class Solution {
    public int countSubstrings(String s) {
        int n = s.length();
        int count = 0;
        for (int i = 0; i < n; i++) {
            count += expand(s, i, i);     // 奇数中心
            count += expand(s, i, i + 1); // 偶数中心
        }
        return count;
    }

    private int expand(String s, int l, int r) {
        int ans = 0;
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
            ans++;
            l--; r++;
        }
        return ans;
    }
}
```

## 边界与陷阱
- 单个字符本身是回文，确保奇数中心统计覆盖
- 偶数中心可能越界，注意边界判断
