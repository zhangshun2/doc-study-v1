# 问题1.0.0-回文子串

## 概述
LeetCode 647：给定字符串 `s`，返回其中回文子串的个数。
链接：https://leetcode.cn/problems/palindromic-substrings/

## 输入与输出
- 输入：字符串 `s`
- 输出：整数，回文子串总数量

## 特征提炼
- 与最长回文子串相似，但统计“所有中心”的回文扩展次数
- 对每个中心（奇/偶）扩展，累加有效回文计数

## 引导思路
- 扩展一次意味着新增一个回文；如何正确统计奇/偶中心？
- 是否需要DP？何时DP更具优势？

## 可能涉及的知识点
- 双指针（中心扩展）
- 动态规划（可选）
