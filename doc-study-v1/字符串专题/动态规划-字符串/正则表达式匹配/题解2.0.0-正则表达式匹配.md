# 题解2.0.0-正则表达式匹配

## 概述

本题解采用经典的动态规划（DP）方法解决正则表达式匹配问题。核心思想是构建一个二维 `dp` 数组，`dp[i][j]` 表示字符串 `s` 的前 `i` 个字符与模式串 `p` 的前 `j` 个字符是否能够完全匹配。通过自底向上的方式，逐步推导出最终结果。

## 解法讲解

### 1. DP 状态的定义

我们定义 `dp[i][j]` 为一个布尔值，表示：
*   字符串 `s` 的前 `i` 个字符（即 `s[0...i-1]`）
*   与模式串 `p` 的前 `j` 个字符（即 `p[0...j-1]`）
*   是否能够完全匹配。

这里的 `i` 和 `j` 都是长度，所以 `dp` 数组的大小会是 `(s.length() + 1) x (p.length() + 1)`。
> 您好！关于您对 dp[i][j] 的理解，它并不是传统意义上的“key-value”对，而是动态规划中非常常见的 子问题状态定> 义 。
> 
> 让我来详细解释一下：
> 
> - dp[i][j] 的含义 ：它是一个布尔值，表示 字符串 s 的前 i 个字符 （即 s[0...i-1] ）是否能与 模式串 p 的> 前 j 个字符 （即 p[0...j-1] ）完全匹配。
> - i 和 j 的作用 ：
>   
>   - i 代表了我们正在考虑的 s 字符串的 前缀长度 。当 i=0 时，表示空字符串 s ；当 i=s.length() 时，表示整> 个字符串 s 。
>   - j 代表了我们正在考虑的 p 模式串的 前缀长度 。当 j=0 时，表示空模式串 p ；当 j=p.length() 时，表示整> 个模式串 p 。
> 所以， dp[i][j] 存储的是一个 子问题的答案 ： s 的这个特定前缀和 p 的这个特定前缀是否匹配。
> 
> 您可以把 i 和 j 理解为 子问题的“坐标”或“参数” ，它们共同定义了一个唯一的子问题。而 dp[i][j] 中存储的布尔> 值，就是这个子问题的**“解”**。
> 
> 例如：
> 
> - dp[1][1] 表示 s 的第一个字符是否与 p 的第一个字符匹配。
> - dp[3][5] 表示 s 的前三个字符是否与 p 的前五个字符匹配。
> 通过这种方式，我们从 dp[0][0] （空字符串匹配空模式串）这个最简单的子问题开始，逐步推导出所有子问题的答> > 案，直到最终得到 dp[s.length()][p.length()] ，也就是整个 s 和整个 p 是否匹配的答案。

> 这种二维数组的结构，正是动态规划中用来存储和复用子问题解的“备忘录”或“查找表”。
### 2. 初始化

*   **`dp[0][0] = true`**: 这表示当 `s` 和 `p` 都是空字符串时，它们是匹配的。这是我们所有后续计算的起点。

*   **`dp[0][j]` 的处理**: 当 `s` 是空字符串（`i=0`），而 `p` 不是空字符串时，`dp[0][j]` 只有在 `p` 的前 `j` 个字符能够匹配空字符串时才为 `true`。这种情况只发生在 `p` 的形式为 `X*Y*Z*...` 这种可以匹配零个字符的模式。
    *   具体来说，如果 `p[j-1]` 是 `*`，并且 `p` 的前 `j-2` 个字符（即 `X*` 中的 `X` 之前的模式）能够匹配空字符串，那么 `X*` 可以匹配零次，整个 `p` 的前 `j` 个字符就能匹配空字符串。
    *   因此，`dp[0][j]` 为 `true` 的条件是 `p.charAt(j-1) == '*'` 并且 `dp[0][j-2]` 为 `true`。

### 3. 状态转移方程（核心逻辑）

我们需要遍历 `s` 的每个字符和 `p` 的每个字符，根据 `p` 的当前字符 `p[j-1]` 来决定 `dp[i][j]` 的值。

**辅助函数 `match(char sc, char pc)`**: 
这个函数用于判断 `s` 的当前字符 `sc` 和 `p` 的当前字符 `pc` 是否匹配。
*   如果 `pc` 是 `.`，则 `sc` 可以匹配任何字符，返回 `true`。
*   如果 `pc` 是普通字符，则 `sc` 必须等于 `pc`，返回 `true`，否则返回 `false`。

现在，我们分两种情况讨论 `p.charAt(j-1)`：

**情况一：`p.charAt(j-1)` 不是 `*` (即是普通字符或 `.` )**

*   在这种情况下，`p` 的当前字符 `p[j-1]` 必须与 `s` 的当前字符 `s[i-1]` 匹配。
*   如果它们匹配（通过 `match(s.charAt(i-1), p.charAt(j-1))` 判断），那么 `dp[i][j]` 的值就取决于 `s` 的前 `i-1` 个字符和 `p` 的前 `j-1` 个字符是否匹配。
*   所以，状态转移方程为：
    `dp[i][j] = dp[i-1][j-1] && match(s.charAt(i-1), p.charAt(j-1))`

**情况二：`p.charAt(j-1)` 是 `*`**

这是最复杂的情况，因为 `*` 可以匹配零次或多次它前面的字符 `X`（即 `p.charAt(j-2)`）。

*   **`X*` 匹配零次**: 
    *   如果 `X*` 匹配零次，那么 `p` 的 `p[j-2]` 和 `p[j-1]` (即 `X*`) 相当于被忽略了。
    *   此时，`dp[i][j]` 的值就取决于 `s` 的前 `i` 个字符是否能与 `p` 的前 `j-2` 个字符匹配。
    *   对应状态：`dp[i][j-2]`

*   **`X*` 匹配一次或多次**: 
    *   如果 `X*` 匹配一次或多次，那么 `s` 的当前字符 `s[i-1]` 必须与 `X` (即 `p.charAt(j-2)`) 匹配。
    *   如果 `s[i-1]` 和 `X` 匹配（通过 `match(s.charAt(i-1), p.charAt(j-2))` 判断），那么 `X*` 至少匹配了一次 `s[i-1]`。
    *   接下来，`s` 的前 `i-1` 个字符需要与 `p` 的前 `j` 个字符（`X*` 仍然存在，因为它可能匹配更多次）匹配。
    *   对应状态：`dp[i-1][j] && match(s.charAt(i-1), p.charAt(j-2))`

*   **综合两种情况**: 
    *   `dp[i][j]` 为 `true`，只要 `X*` 匹配零次或者匹配一次或多次中的任意一种情况为 `true` 即可。
    *   所以，状态转移方程为：
        `dp[i][j] = dp[i][j-2] || (dp[i-1][j] && match(s.charAt(i-1), p.charAt(j-2)))`

### 4. 最终结果

在填充完整个 `dp` 数组后，`dp[s.length()][p.length()]` 就是最终的答案，它表示 `s` 的全部字符是否能与 `p` 的全部字符匹配。

## 代码（Java）

```java
class Solution {
    public boolean isMatch(String s, String p) {
        int n = s.length(), m = p.length();
        boolean[][] dp = new boolean[n + 1][m + 1];
        dp[0][0] = true; // s和p都为空时匹配

        // 初始化 dp[0][j]：s为空，p不为空的情况
        // 只有当p为 "X*Y*Z*..." 这种形式时才能匹配空字符串
        for (int j = 2; j <= m; j++) {
            if (p.charAt(j - 1) == '*' && dp[0][j - 2]) {
                dp[0][j] = true;
            }
        }

        // 填充dp数组
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                char pc = p.charAt(j - 1); // p的当前字符

                if (pc == '*') {
                    char prev = p.charAt(j - 2); // * 前面的字符 X
                    // 情况一：X* 匹配零次 (dp[i][j-2])
                    // 情况二：X* 匹配一次或多次 (dp[i-1][j] && match(s.charAt(i-1), prev))
                    // 只有当s的当前字符能和X匹配时，才能考虑X*匹配一次或多次
                    dp[i][j] = dp[i][j - 2] || (dp[i - 1][j] && match(s.charAt(i - 1), prev));
                } else {
                    // pc不是*，即为普通字符或.
                    // 只有当s的当前字符能和pc匹配，并且s的前i-1个字符能和p的前j-1个字符匹配时，才为true
                    dp[i][j] = dp[i - 1][j - 1] && match(s.charAt(i - 1), pc);
                }
            }
        }
        return dp[n][m];
    }

    // 辅助函数：判断s的字符sc和p的字符pc是否匹配
    private boolean match(char sc, char pc) {
        return pc == '.' || pc == sc;
    }
}
```

## 复杂度

*   **时间复杂度**: `O(N * M)`，其中 `N` 是字符串 `s` 的长度，`M` 是模式串 `p` 的长度。因为我们需要填充一个 `N x M` 的 `dp` 数组，每个单元格的计算都是常数时间。
*   **空间复杂度**: `O(N * M)`，用于存储 `dp` 数组。

## 边界与陷阱

*   `*` 不可作为首字符，处理时需访问 `j-2`。
*   连续 `*` 的情况按题意不会出现，但实现需稳健。
*   **索引越界**: 在访问 `s.charAt(i-1)` 或 `p.charAt(j-1)` 之前，务必检查 `i-1` 或 `j-1` 是否越界。
