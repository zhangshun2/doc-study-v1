# 微模板与易错点卡片｜10 正则表达式匹配

## 微模板（Java）

### 1) DP 状态机模板
```java
boolean isMatch(String s, String p) {
    int n = s.length(), m = p.length();
    boolean[][] dp = new boolean[n + 1][m + 1];
    dp[0][0] = true;
    for (int j = 2; j <= m; j++) {
        if (p.charAt(j - 1) == '*') dp[0][j] = dp[0][j - 2];
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            char pc = p.charAt(j - 1);
            if (pc == '*') {
                dp[i][j] = dp[i][j - 2] ||
                    ((p.charAt(j - 2) == '.' || p.charAt(j - 2) == s.charAt(i - 1)) && dp[i - 1][j]);
            } else {
                dp[i][j] = (pc == '.' || pc == s.charAt(i - 1)) && dp[i - 1][j - 1];
            }
        }
    }
    return dp[n][m];
}
```

### 2) DFS + 记忆化模板
```java
boolean isMatch(String s, String p) { return dfs(0, 0, s, p, new Integer[s.length()+1][p.length()+1]); }
boolean dfs(int i, int j, String s, String p, Integer[][] memo) {
    if (memo[i][j] != null) return memo[i][j] == 1;
    boolean res;
    if (j == p.length()) res = (i == s.length());
    else {
        boolean first = (i < s.length()) && (p.charAt(j) == s.charAt(i) || p.charAt(j) == '.');
        if (j + 1 < p.length() && p.charAt(j + 1) == '*') {
            res = dfs(i, j + 2, s, p, memo) || (first && dfs(i + 1, j, s, p, memo));
        } else {
            res = first && dfs(i + 1, j + 1, s, p, memo);
        }
    }
    memo[i][j] = res ? 1 : -1; return res;
}
```

## 易错点卡片
- `*` 依赖前一个字符：DP 中访问 `j-2`；必须保证 `j>=2` 才能访问。
- 空串初始化：`dp[0][j]` 仅当前缀形如 `X*Y*...` 才可能为 `true`。
- DFS 分支完整：零次（跳过两个字符）与多次（匹配一个并停留）两分支缺一不可。
- 辅助匹配函数：`match(sc, pc)` 逻辑统一（`.` 或相等），避免在多处重复判断造成不一致。
