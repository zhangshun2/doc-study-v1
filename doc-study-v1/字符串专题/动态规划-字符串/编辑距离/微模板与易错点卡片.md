# 微模板与易错点卡片｜72 编辑距离

## 微模板（Java）
```java
int minDistance(String a, String b) {
    int n = a.length(), m = b.length();
    int[][] dp = new int[n + 1][m + 1];
    for (int i = 0; i <= n; i++) dp[i][0] = i;      // 删除到空
    for (int j = 0; j <= m; j++) dp[0][j] = j;      // 插入到目标
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            int cost = (a.charAt(i - 1) == b.charAt(j - 1)) ? 0 : 1;
            dp[i][j] = Math.min(
                Math.min(dp[i - 1][j] + 1,     // 删除 a[i-1]
                         dp[i][j - 1] + 1),    // 插入 b[j-1]
                dp[i - 1][j - 1] + cost        // 替换或保持
            );
        }
    }
    return dp[n][m];
}
```

## 易错点卡片
- 初始化是核心：`dp[i][0]=i` 与 `dp[0][j]=j` 分别对应全删与全插入。
- 索引语义是“长度 i/j”，访问字符用 `i-1/j-1`，避免越界。
- 替换的 `cost` 取决于字符相等与否，不要忘记 0/1 的区分。
