# 问题1.0.0-编辑距离

## 概述
LeetCode 72：给定两个单词 `word1` 与 `word2`，返回将 `word1` 转换为 `word2` 所需的最少操作数（插入、删除、替换）。
链接：https://leetcode.cn/problems/edit-distance/

## 输入与输出
- 输入：字符串 `word1`、`word2`
- 输出：整数，最少编辑次数

## 特征提炼
- 典型字符串DP：区间含义明确、操作集合固定
- 状态定义：`dp[i][j]` 表示 `word1[0..i)` 转换为 `word2[0..j)` 的最少操作数

## 引导思路
- 三种操作对应的转移如何构造？
- 初始边界（空串到非空串）如何设置？
- 是否可做空间优化（滚动数组）？

## 可能涉及的知识点
- 动态规划（编辑距离）
- 状态转移与边界初始化
- 滚动数组优化
