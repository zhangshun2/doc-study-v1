# 题解2.0.0-编辑距离

## 概述
技巧：动态规划（编辑距离）。
核心：`dp[i][j]` 表示将 `word1[0..i)` 转换到 `word2[0..j)` 的最少操作数，按末尾字符是否相同分类转移。

## 解法讲解
1. 初始化：`dp[i][0] = i`（删除 `i` 次），`dp[0][j] = j`（插入 `j` 次）
2. 转移：
   - 若末尾字符相同：`dp[i][j] = dp[i-1][j-1]`
   - 若不同：
     - 插入：`dp[i][j-1] + 1`
     - 删除：`dp[i-1][j] + 1`
     - 替换：`dp[i-1][j-1] + 1`
   - 三者取最小

## 复杂度
- 时间：O(n*m)
- 空间：O(n*m)（可优化为 O(min(n,m))）

## 代码（Java）
```java
class Solution {
    public int minDistance(String word1, String word2) {
        int n = word1.length(), m = word2.length();
        int[][] dp = new int[n + 1][m + 1];
        for (int i = 0; i <= n; i++) dp[i][0] = i;
        for (int j = 0; j <= m; j++) dp[0][j] = j;
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.min(
                        Math.min(dp[i][j - 1] + 1, dp[i - 1][j] + 1),
                        dp[i - 1][j - 1] + 1
                    );
                }
            }
        }
        return dp[n][m];
    }
}
```

## 边界与陷阱
- 空串到非空串的初始化不可遗漏
- 空间优化时注意索引对应与覆盖顺序
