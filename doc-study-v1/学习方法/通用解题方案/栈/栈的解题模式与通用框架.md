## 🎯 栈的基本概念与特性
### 核心特性
```java
/**
 * 栈的核心特性：LIFO (Last In, First Out)
 * 
 * 基本操作：
 * - push(item): 入栈
 * - pop(): 出栈
 * - peek()/top(): 查看栈顶
 * - isEmpty(): 判断是否为空
 * - size(): 获取栈大小
 */
public interface StackInterface<T> {
    void push(T item);
    T pop();
    T peek();
    boolean isEmpty();
    int size();
}
```

## 🔍 栈的解题模式分类
### 1. 基础栈操作模式
**适用场景：** 简单的入栈出栈操作，括号匹配等

**核心思想：** 利用栈的LIFO特性进行配对或状态管理

**典型问题：**

+ LeetCode 20 - 有效的括号
+ LeetCode 155 - 最小栈
+ LeetCode 232 - 用栈实现队列

**解题模板：**

```java
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    
    for (char c : s.toCharArray()) {
        if (isOpenBracket(c)) {
            stack.push(c);
        } else if (isCloseBracket(c)) {
            if (stack.isEmpty() || !isMatching(stack.pop(), c)) {
                return false;
            }
        }
    }
    
    return stack.isEmpty();
}
```

### 2. 单调栈模式
**适用场景：** 寻找下一个更大/更小元素，最值问题

**核心思想：** 维护栈的单调性，快速找到满足条件的元素

**典型问题：**

+ LeetCode 496 - 下一个更大元素 I
+ LeetCode 739 - 每日温度
+ LeetCode 84 - 柱状图中最大的矩形

**解题模板：**

```java
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Deque<Integer> stack = new ArrayDeque<>();  // 存储索引
    
    // 从右到左遍历（或从左到右，根据需求）
    for (int i = n - 1; i >= 0; i--) {
        // 维护单调递减栈
        while (!stack.isEmpty() && nums[stack.peek()] <= nums[i]) {
            stack.pop();
        }
        
        result[i] = stack.isEmpty() ? -1 : nums[stack.peek()];
        stack.push(i);
    }
    
    return result;
}
```

### 3. 栈+哈希表模式
**适用场景：** 需要快速查找和栈操作结合的问题

**核心思想：** 用哈希表加速查找，用栈维护顺序

**典型问题：**

+ LeetCode 496 - 下一个更大元素 I
+ LeetCode 739 - 每日温度（优化版）

**解题模板：**

```java
public int[] nextGreaterElement(int[] nums1, int[] nums2) {
    Map<Integer, Integer> nextGreaterMap = new HashMap<>();
    Deque<Integer> stack = new ArrayDeque<>();
    
    // 构建下一个更大元素的映射
    for (int num : nums2) {
        while (!stack.isEmpty() && stack.peek() < num) {
            nextGreaterMap.put(stack.pop(), num);
        }
        stack.push(num);
    }
    
    // 查询结果
    int[] result = new int[nums1.length];
    for (int i = 0; i < nums1.length; i++) {
        result[i] = nextGreaterMap.getOrDefault(nums1[i], -1);
    }
    
    return result;
}
```

### 4. 递归栈模拟模式
**适用场景：** 将递归转换为迭代，避免栈溢出

**核心思想：** 用显式栈模拟递归调用栈

**典型问题：**

+ LeetCode 94 - 二叉树的中序遍历
+ LeetCode 341 - 扁平化嵌套列表迭代器

**解题模板：**

```java
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode current = root;
    
    while (current != null || !stack.isEmpty()) {
        // 一直向左走到底
        while (current != null) {
            stack.push(current);
            current = current.left;
        }
        
        // 处理当前节点
        current = stack.pop();
        result.add(current.val);
        
        // 转向右子树
        current = current.right;
    }
    
    return result;
}
```

### 5. 表达式栈模式
**适用场景：** 表达式求值，计算器实现

**核心思想：** 用栈处理操作符优先级和括号

**典型问题：**

+ LeetCode 150 - 逆波兰表达式求值
+ LeetCode 224 - 基本计算器

**解题模板：**

```java
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    int num = 0;
    char operator = '+';
    
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        
        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');
        }
        
        if (c == '+' || c == '-' || c == '*' || c == '/' || i == s.length() - 1) {
            switch (operator) {
                case '+': stack.push(num); break;
                case '-': stack.push(-num); break;
                case '*': stack.push(stack.pop() * num); break;
                case '/': stack.push(stack.pop() / num); break;
            }
            operator = c;
            num = 0;
        }
    }
    
    return stack.stream().mapToInt(Integer::intValue).sum();
}
```

### 6. 状态栈模式
**适用场景：** 需要记录和恢复状态的问题

**核心思想：** 用栈保存状态信息，支持状态回溯

**典型问题：**

+ LeetCode 394 - 字符串解码
+ LeetCode 636 - 函数的独占时间

**解题模板：**

```java
public String decodeString(String s) {
    Deque<Integer> countStack = new ArrayDeque<>();
    Deque<StringBuilder> stringStack = new ArrayDeque<>();
    StringBuilder currentString = new StringBuilder();
    int count = 0;
    
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            count = count * 10 + (c - '0');
        } else if (c == '[') {
            // 保存当前状态
            countStack.push(count);
            stringStack.push(currentString);
            // 重置状态
            count = 0;
            currentString = new StringBuilder();
        } else if (c == ']') {
            // 恢复状态并处理
            StringBuilder temp = currentString;
            currentString = stringStack.pop();
            int repeatCount = countStack.pop();
            for (int i = 0; i < repeatCount; i++) {
                currentString.append(temp);
            }
        } else {
            currentString.append(c);
        }
    }
    
    return currentString.toString();
}
```

### 7. 栈的综合应用模式
**适用场景：** 复杂的几何问题，多种技巧结合

**核心思想：** 结合单调栈、动态规划等多种技巧

**典型问题：**

+ LeetCode 42 - 接雨水
+ LeetCode 85 - 最大矩形

**解题模板：**

```java
public int maximalRectangle(char[][] matrix) {
    if (matrix == null || matrix.length == 0) return 0;
    
    int rows = matrix.length;
    int cols = matrix[0].length;
    int[] heights = new int[cols];
    int maxArea = 0;
    
    for (int i = 0; i < rows; i++) {
        // 更新高度数组
        for (int j = 0; j < cols; j++) {
            heights[j] = (matrix[i][j] == '1') ? heights[j] + 1 : 0;
        }
        
        // 应用单调栈算法
        maxArea = Math.max(maxArea, largestRectangleArea(heights));
    }
    
    return maxArea;
}

private int largestRectangleArea(int[] heights) {
    Deque<Integer> stack = new ArrayDeque<>();
    int maxArea = 0;
    
    for (int i = 0; i <= heights.length; i++) {
        int currentHeight = (i == heights.length) ? 0 : heights[i];
        
        while (!stack.isEmpty() && currentHeight < heights[stack.peek()]) {
            int height = heights[stack.pop()];
            int width = stack.isEmpty() ? i : i - stack.peek() - 1;
            maxArea = Math.max(maxArea, height * width);
        }
        
        stack.push(i);
    }
    
    return maxArea;
}
```

```java
/**
 * 基础栈操作通用框架
 * 适用于：括号匹配、简单状态管理等
 */
public class BasicStackFramework<T> {
    
    public boolean solve(T[] input) {
        Deque<T> stack = new ArrayDeque<>();
        
        for (T item : input) {
            if (shouldPush(item)) {
                stack.push(transform(item));
            } else if (shouldPop(item)) {
                if (stack.isEmpty() || !isValid(stack.pop(), item)) {
                    return false;
                }
            } else {
                // 其他处理逻辑
                handleOther(item, stack);
            }
        }
        
        return isValidFinalState(stack);
    }
    
    // 需要子类实现的方法
    protected abstract boolean shouldPush(T item);
    protected abstract boolean shouldPop(T item);
    protected abstract T transform(T item);
    protected abstract boolean isValid(T stackItem, T currentItem);
    protected abstract void handleOther(T item, Deque<T> stack);
    protected abstract boolean isValidFinalState(Deque<T> stack);
}
```

```java
/**
 * 单调栈通用框架
 * 适用于：下一个更大元素、最值问题等

public class MonotonicStackFramework {
    
    public int[] solve(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        
        for (int i = getStartIndex(n); isValidIndex(i, n); i = getNextIndex(i)) {
            // 维护单调性
            while (!stack.isEmpty() && shouldPop(nums, stack.peek(), i)) {
                int index = stack.pop();
                result[index] = processResult(nums, index, i);
            }
            
            // 处理当前元素
            processCurrentElement(result, i, stack);
            stack.push(i);
        }
        
        // 处理剩余元素
        while (!stack.isEmpty()) {
            int index = stack.pop();
            result[index] = getDefaultValue();
        }
        
        return result;
    }
    
    // 需要子类实现的方法
    protected abstract int getStartIndex(int n);
    protected abstract boolean isValidIndex(int i, int n);
    protected abstract int getNextIndex(int i);
    protected abstract boolean shouldPop(int[] nums, int stackIndex, int currentIndex);
    protected abstract int processResult(int[] nums, int stackIndex, int currentIndex);
    protected abstract void processCurrentElement(int[] result, int index, Deque<Integer> stack);
    protected abstract int getDefaultValue();
}
```

### 框架3：状态栈通用框架
```java
/**
 * 状态栈通用框架
 * 适用于：状态管理、回溯等
 */
public class StateStackFramework<T, S> {
    
    public T solve(String input) {
        Deque<S> stateStack = new ArrayDeque<>();
        T currentResult = initializeResult();
        S currentState = initializeState();
        
        for (char c : input.toCharArray()) {
            if (isStateTransition(c)) {
                // 保存当前状态
                stateStack.push(saveState(currentState, currentResult));
                // 重置状态
                currentState = resetState();
                currentResult = resetResult();
            } else if (isStateRestore(c)) {
                // 恢复状态
                S savedState = stateStack.pop();
                currentResult = restoreAndProcess(savedState, currentResult);
                currentState = restoreState(savedState);
            } else {
                // 处理普通字符
                currentResult = processCharacter(c, currentResult, currentState);
                currentState = updateState(c, currentState);
            }
        }
        
        return currentResult;
    }
    
    // 需要子类实现的方法
    protected abstract T initializeResult();
    protected abstract S initializeState();
    protected abstract boolean isStateTransition(char c);
    protected abstract boolean isStateRestore(char c);
    protected abstract S saveState(S currentState, T currentResult);
    protected abstract S resetState();
    protected abstract T resetResult();
    protected abstract T restoreAndProcess(S savedState, T currentResult);
    protected abstract S restoreState(S savedState);
    protected abstract T processCharacter(char c, T currentResult, S currentState);
    protected abstract S updateState(char c, S currentState);
}
```

```java
    public boolean isValid(String s) {
        if (s == null || s.length() % 2 == 1) return false;
        
        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Character> pairs = Map.of(')', '(', ']', '[', '}', '{');
        
        for (char c : s.toCharArray()) {
            if (pairs.containsValue(c)) {
                stack.push(c);
            } else if (pairs.containsKey(c)) {
                if (stack.isEmpty() || stack.pop() != pairs.get(c)) {

                }
            }
        }
        
        return stack.isEmpty();
    }
```

```java
public class ExpressionCalculatorTemplate {
    
    // 基本计算器模板（支持 +, -, *, /, 括号）
    public int calculate(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        int num = 0;
        char operator = '+';
        
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '(') {
                // 递归处理括号内的表达式
                int count = 1;
                int start = i + 1;
                while (count > 0) {
                    i++;
                    if (s.charAt(i) == '(') count++;
                    else if (s.charAt(i) == ')') count--;
                }
                num = calculate(s.substring(start, i));
            }
            
            if (isOperator(c) || i == s.length() - 1) {
                switch (operator) {
                    case '+': stack.push(num); break;
                    case '-': stack.push(-num); break;
                    case '*': stack.push(stack.pop() * num); break;
                    case '/': stack.push(stack.pop() / num); break;
                }
                operator = c;
                num = 0;
            }
        }
        
        return stack.stream().mapToInt(Integer::intValue).sum();
    }
    
    private boolean isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/';
    }
}
```

```java
public class RecursionToIterationTemplate {
    
    // 二叉树中序遍历模板
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode current = root;
        
        while (current != null || !stack.isEmpty()) {
            while (current != null) {
                stack.push(current);
                current = current.left;
            }
            
            current = stack.pop();
            result.add(current.val);
            current = current.right;
        }
        
        return result;
    }

    public void dfsIterative(TreeNode root) {
        if (root == null) return;
        
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            
            // 处理当前节点
            process(node);
            
            // 添加子节点（注意顺序）
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
    }
    
    private void process(TreeNode node) {
        // 处理节点的逻辑
        System.out.println(node.val);
    }
}
```

```java
            return new ArrayList<>();  // 支持随机访问
        } else if (expectedSize > 1000) {
            return new ArrayDeque<>();  // 大数据量，性能更好
        } else {
            return new LinkedList<>();  // 小数据量，内存效率高
        }
    }
    
    // 2. 避免不必要的对象创建
    public int[] optimizedNextGreaterElement(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        int[] stack = new int[n];  // 使用数组模拟栈
        int top = -1;
        
        for (int i = n - 1; i >= 0; i--) {
            while (top >= 0 && nums[stack[top]] <= nums[i]) {
                top--;
            }
            result[i] = (top >= 0) ? nums[stack[top]] : -1;
            stack[++top] = i;
        }
        
        return result;
    }
    
    // 3. 提前终止优化
    public boolean hasValidParentheses(String s) {
        if (s.length() % 2 == 1) return false;  // 提前终止
        
        int count = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                count++;
            } else if (c == ')') {
                count--;
                if (count < 0) return false;  // 提前终止
            }
        }
        
        return count == 0;
    }
}
```

```java
/**

public class StackDebuggingTips {
    
    // 1. 栈状态可视化
    public void visualizeStack(Deque<Integer> stack, String operation) {

    public int[] debugMonotonicStack(int[] nums) {

        int[] result = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        
        System.out.println("单调栈调试信息:");
        for (int i = 0; i < n; i++) {
            System.out.printf("处理元素 nums[%d] = %d\n", i, nums[i]);
            
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                int index = stack.pop();
                result[index] = nums[i];
                System.out.printf("  找到答案: nums[%d] = %d 的下一个更大元素是 nums[%d] = %d\n", 
                                index, nums[index], i, nums[i]);
            }
            
            stack.push(i);
            visualizeStack(stack, "push " + i);
        }
        
        return result;
    }
    
    // 3. 状态栈调试模板
    public String debugStateStack(String s) {
        Deque<Integer> countStack = new ArrayDeque<>();
        Deque<StringBuilder> stringStack = new ArrayDeque<>();
        StringBuilder currentString = new StringBuilder();
        int count = 0;
        
        System.out.println("状态栈调试信息:");
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            System.out.printf("处理字符 '%c' (位置 %d)\n", c, i);
            
            if (Character.isDigit(c)) {
                count = count * 10 + (c - '0');
                System.out.printf("  更新计数: %d\n", count);
            } else if (c == '[') {
                countStack.push(count);
                stringStack.push(currentString);
                System.out.printf("  保存状态: count=%d, string='%s'\n", count, currentString);
                count = 0;
                currentString = new StringBuilder();
            } else if (c == ']') {
                StringBuilder temp = currentString;
                currentString = stringStack.pop();
                int repeatCount = countStack.pop();
                System.out.printf("  恢复状态: repeatCount=%d, string='%s', temp='%s'\n", 
                                repeatCount, currentString, temp);
                for (int j = 0; j < repeatCount; j++) {
                    currentString.append(temp);
                }
                System.out.printf("  重复后: '%s'\n", currentString);
            } else {
                currentString.append(c);
                System.out.printf("  添加字符: '%s'\n", currentString);
            }
        }
        
        return currentString.toString();
    }
```

## ⚠️ 常见陷阱与优化
### 陷阱1：栈空判断遗漏
```java
// ❌ 错误：没有检查栈是否为空
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    // ... 处理逻辑
    return stack.pop();  // 可能抛出异常
}

// ✅ 正确：检查栈状态
public int calculate(String s) {
    Deque<Integer> stack = new ArrayDeque<>();
    // ... 处理逻辑
    return stack.isEmpty() ? 0 : stack.pop();
}
```

### 陷阱2：索引越界
```java
// ❌ 错误：没有边界检查
public int[] nextGreaterElement(int[] nums) {

    }
    // ...

// ✅ 正确：添加边界检查
public int[] nextGreaterElement(int[] nums) {
    if (nums == null || nums.length == 0) return new int[0];
```

### 陷阱3：单调性维护错误
```java
// ❌ 错误：条件判断错误
while (!stack.isEmpty() && nums[stack.peek()] <= nums[i]) {  // 应该是 <
    stack.pop();

// ✅ 正确：根据需求选择正确的比较符

    stack.pop();
}
```

### 优化技巧
1. **使用ArrayDeque替代Stack**

```java
// ✅ 推荐
Deque<Integer> stack = new ArrayDeque<>();

Stack<Integer> stack = new Stack<>();
```

2. **预分配容量**

```java
// 如果知道大概的数据量，预分配容量
```

3. **避免装箱拆箱**

