# 二叉树遍历通用模式
## 概述
二叉树遍历是算法面试中的高频考点，掌握通用的解题模式可以快速解决各种变种问题。本文档总结了二叉树遍历的通用解题思路和代码模板。

## 核心思想
### 1. 递归三要素
+ **递归终止条件**：通常是节点为空
+ **递归函数功能**：明确当前递归层要做什么
+ **递归调用**：如何缩小问题规模

### 2. 迭代的栈模拟
+ **栈的作用**：保存递归调用的上下文
+ **入栈顺序**：决定了访问顺序
+ **出栈时机**：决定了何时处理节点

```java
// 递归遍历通用模板
public void traverseRecursive(TreeNode root) {
    // 1. 递归终止条件
    if (root == null) {
        return;
    }
    
    // 2. 处理当前节点（前序位置）
    process(root);
    
    // 3. 递归处理左子树
    traverseRecursive(root.left);
    
    // 4. 处理当前节点（中序位置）
    process(root);
    
    // 5. 递归处理右子树
    traverseRecursive(root.right);
    
    // 6. 处理当前节点（后序位置）
    process(root);
}
```

### 迭代模板
#### 前序遍历模板
```java
public List<Integer> preorderTemplate(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    
    Stack<TreeNode> stack = new Stack<>();
    stack.push(root);
    
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        
        // 处理当前节点
        result.add(node.val);
        
        // 先右后左入栈（保证左子树先处理）
        if (node.right != null) stack.push(node.right);
        if (node.left != null) stack.push(node.left);
    }
    
    return result;
}
```

#### 中序遍历模板
```java
public List<Integer> inorderTemplate(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Stack<TreeNode> stack = new Stack<>();
    TreeNode current = root;
    
    while (current != null || !stack.isEmpty()) {
        // 一直向左走，压栈
        while (current != null) {
            stack.push(current);
            current = current.left;
        }
        
        // 处理栈顶节点
        current = stack.pop();
        result.add(current.val);
        
        // 转向右子树
        current = current.right;
    }
    
    return result;
}
```

#### 后序遍历模板
```java
// 方法一：单栈 + 标记
public List<Integer> postorderTemplate1(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    
    Stack<TreeNode> stack = new Stack<>();
    TreeNode lastVisited = null;
    TreeNode current = root;
    
    while (current != null || !stack.isEmpty()) {
        if (current != null) {
            stack.push(current);
            current = current.left;
        } else {
            TreeNode peekNode = stack.peek();
            if (peekNode.right != null && lastVisited != peekNode.right) {
                current = peekNode.right;
            } else {
                result.add(peekNode.val);
                lastVisited = stack.pop();
            }
        }
    }
    
    return result;
}

// 方法二：双栈法
public List<Integer> postorderTemplate2(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    
    Stack<TreeNode> stack1 = new Stack<>();
    Stack<TreeNode> stack2 = new Stack<>();
    
    stack1.push(root);
    
    while (!stack1.isEmpty()) {
        TreeNode node = stack1.pop();
        stack2.push(node);
        
        if (node.left != null) stack1.push(node.left);
        if (node.right != null) stack1.push(node.right);
    }
    
    while (!stack2.isEmpty()) {
        result.add(stack2.pop().val);
    }
    
    return result;
}
```

## 常见变种问题及解法
### 1. 路径问题
```java
// 模板：从根到叶子的所有路径
public List<String> binaryTreePaths(TreeNode root) {
    List<String> result = new ArrayList<>();
    if (root == null) return result;
    
    dfs(root, "", result);
    return result;
}

private void dfs(TreeNode node, String path, List<String> result) {
    if (node == null) return;
    
    path += node.val;
    
    // 叶子节点
    if (node.left == null && node.right == null) {
        result.add(path);
        return;
    }
    
    path += "->";
    dfs(node.left, path, result);
    dfs(node.right, path, result);
}
```

### 2. 层序遍历变种
```java
// 模板：按层遍历
public List<List<Integer>> levelOrderTemplate(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>();
        
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        
        result.add(level);
    }
    
    return result;
}
```

### 3. 树的构造问题
```java
// 模板：根据前序和中序构造二叉树
public TreeNode buildTreeTemplate(int[] preorder, int[] inorder) {
    Map<Integer, Integer> inorderMap = new HashMap<>();
    for (int i = 0; i < inorder.length; i++) {
        inorderMap.put(inorder[i], i);
    }
    
    return buildHelper(preorder, 0, preorder.length - 1,
                      inorder, 0, inorder.length - 1, inorderMap);
}

private TreeNode buildHelper(int[] preorder, int preStart, int preEnd,
                           int[] inorder, int inStart, int inEnd,
                           Map<Integer, Integer> inorderMap) {
    if (preStart > preEnd) return null;
    
    int rootVal = preorder[preStart];
    TreeNode root = new TreeNode(rootVal);
    
    int rootIndex = inorderMap.get(rootVal);
    int leftSize = rootIndex - inStart;
    
    root.left = buildHelper(preorder, preStart + 1, preStart + leftSize,
                           inorder, inStart, rootIndex - 1, inorderMap);
    root.right = buildHelper(preorder, preStart + leftSize + 1, preEnd,
                            inorder, rootIndex + 1, inEnd, inorderMap);
    
    return root;
}
```

## 解题技巧
### 1. 数据结构选择指南
#### 栈实现的最佳选择
| 数据结构 | 内存开销 | 性能 | 推荐度 | 使用场景 |
| --- | --- | --- | --- | --- |
| `Stack<T>` | 中等 | 差 | ❌ | 避免使用 |
| `LinkedList<T>` | 高 | 差 | ❌ | 避免使用 |
| `ArrayDeque<T>` | 低 | 优 | ✅ | **首选方案** |
| `ArrayList<T>` | 最低 | 优 | ⚠️ | 手动实现栈操作 |


#### 详细对比分析
**❌**** 避免使用Stack**

```java
// 不推荐：过时的设计
Stack<TreeNode> stack = new Stack<>();
```

+ 继承自Vector，携带同步开销
+ 单线程环境下性能损失约15-25%
+ 官方已不推荐使用

**❌**** 避免使用LinkedList**

```java
// 不推荐：内存开销大
Deque<TreeNode> stack = new LinkedList<>();
```

+ 每个元素额外36-40字节开销
+ 内存分散，缓存命中率低
+ 适合频繁中间插入的场景，不适合栈操作

**✅**** 推荐使用ArrayDeque**

```java
// 推荐：性能最佳
Deque<TreeNode> stack = new ArrayDeque<>();
// 更好：预估容量
Deque<TreeNode> stack = new ArrayDeque<>(expectedDepth);
```

+ 无同步开销，性能最佳
+ 数组实现，内存连续，缓存友好
+ 动态扩容策略优化

**⚠️**** 特殊情况：ArrayList手动实现**

```java
// 极致性能优化
List<TreeNode> stack = new ArrayList<>(expectedDepth);

// 手动实现栈操作
public void push(TreeNode node) {
    stack.add(node);
}

public TreeNode pop() {
    return stack.remove(stack.size() - 1);
}

public boolean isEmpty() {
    return stack.isEmpty();
}
```

### 2. 内存性能优化策略
#### 容量预估
```java
// 根据树的特征预估栈深度
public int estimateStackDepth(TreeNode root) {
    if (root == null) return 0;
    
    // 对于平衡树：深度约为 log2(n)
    // 对于链式树：深度约为 n
    // 保守估计：使用 sqrt(n) 作为初始容量
    int nodeCount = countNodes(root);
    return Math.max(16, (int) Math.sqrt(nodeCount));
}

// 使用预估容量
int capacity = estimateStackDepth(root);
Deque<TreeNode> stack = new ArrayDeque<>(capacity);
```

#### 内存使用监控
```java
public class MemoryAwareTraversal {
    private static final int MAX_STACK_SIZE = 10000;
    
    public List<Integer> safePreorder(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        
        if (root != null) stack.push(root);
        
        while (!stack.isEmpty()) {
            // 防止栈溢出
            if (stack.size() > MAX_STACK_SIZE) {
                throw new RuntimeException("树深度过大，可能导致栈溢出");
            }
            
            TreeNode node = stack.pop();
            result.add(node.val);
            
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
        
        return result;
    }
}
```

### 3. 空间复杂度优化
#### Morris遍历（O(1)空间）
```java
// 中序Morris遍历
public List<Integer> morrisInorder(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    TreeNode current = root;
    
    while (current != null) {
        if (current.left == null) {
            result.add(current.val);
            current = current.right;
        } else {
            // 找到前驱节点
            TreeNode predecessor = current.left;
            while (predecessor.right != null && predecessor.right != current) {
                predecessor = predecessor.right;
            }
            
            if (predecessor.right == null) {
                // 建立线索
                predecessor.right = current;
                current = current.left;
            } else {
                // 恢复树结构
                predecessor.right = null;
                result.add(current.val);
                current = current.right;
            }
        }
    }
    
    return result;
}
```

## 常见陷阱
### 1. 空指针异常
```java
// 错误写法
if (root.left != null) {
    // 忘记检查root是否为null
}

// 正确写法
if (root != null && root.left != null) {
    // 先检查root，再检查子节点
}
```

### 2. 栈溢出
```java
// 对于极深的树，递归可能导致栈溢出
// 解决方案：使用迭代或增加JVM栈大小
```

### 3. 修改原树结构
```java
// 错误：在遍历过程中修改树结构
public void wrongTraversal(TreeNode root) {
    if (root == null) return;
    
    // 错误：修改了原树结构
    TreeNode temp = root.left;
    root.left = root.right;
    root.right = temp;
    
    wrongTraversal(root.left);
    wrongTraversal(root.right);
}
```

## 性能对比

| --- | --- | --- | --- | --- |
| 递归 | O(n) | O(h) | 代码简洁 | 可能栈溢出 |
