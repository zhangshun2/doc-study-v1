## 🎯 位运算核心技巧
### 🔑 基础位运算操作
1. **与运算(&)**：两位都为1时结果为1
2. **或运算(|)**：有一位为1时结果为1
3. **异或运算(^)**：两位不同时结果为1
4. **非运算(~)**：位取反
5. **左移(<<)**：向左移动指定位数
6. **右移(>>)**：向右移动指定位数

### 📝 常用位运算技巧
1. **判断奇偶**：`n & 1 == 1` 为奇数
2. **交换两数**：`a ^= b; b ^= a; a ^= b;`
3. **清除最低位1**：`n & (n-1)`
4. **获取最低位1**：`n & (-n)`
5. **判断2的幂**：`n > 0 && (n & (n-1)) == 0`
6. **计算绝对值**：`(n ^ (n >> 31)) - (n >> 31)`

## 1️⃣ 只出现一次的数字 (LeetCode 136)
### 📝 题目描述
给你一个 **非空** 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

**示例 1：**

```plain
输入：nums = [2,2,1]
输出：1
```

**示例 2：**

```plain
输入：nums = [4,1,2,1,2]
输出：4
```

**示例 3：**

```plain
输入：nums = [1]
输出：1
```

### 🔧 基础解法：哈希表
```java
class Solution {
    public int singleNumber(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        
        for (int num : nums) {
            if (seen.contains(num)) {
                seen.remove(num);
            } else {
                seen.add(num);
            }
        }
        
        return seen.iterator().next();
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(n)

### 🚀 进阶解法：数学方法
```java
class Solution {
    public int singleNumber(int[] nums) {
        Set<Integer> uniqueNums = new HashSet<>();
        int sumOfUnique = 0;
        int sumOfAll = 0;
        
        for (int num : nums) {
            uniqueNums.add(num);
            sumOfAll += num;
        }
        
        for (int num : uniqueNums) {
            sumOfUnique += num;
        }
        
        // 2 * (a + b + c) - (a + a + b + b + c) = c
        return 2 * sumOfUnique - sumOfAll;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(n)

### 🚀 最优解法：异或运算
```java
class Solution {
    public int singleNumber(int[] nums) {
        int result = 0;
        
        for (int num : nums) {
            result ^= num;
        }
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

**核心思想：**

+ 异或运算的性质：`a ^ a = 0`，`a ^ 0 = a`
+ 异或运算满足交换律和结合律
+ 所有出现两次的数字异或后为0，最后剩下只出现一次的数字

## 2️⃣ 比特位计数 (LeetCode 338)
### 📝 题目描述
给你一个整数 `n` ，对于 `0 <= i <= n` 中的每个 `i` ，计算其二进制表示中 **1 的个数** ，返回一个长度为 `n + 1` 的数组 `ans` 作为答案。

**示例 1：**

```plain
输入：n = 2
输出：[0,1,1]
解释：
0 --> 0
1 --> 1
2 --> 10
```

**示例 2：**

```plain
输入：n = 5
输出：[0,1,1,2,1,2]
解释：
0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
5 --> 101
```

### 🔧 基础解法：暴力计算
```java
class Solution {
    public int[] countBits(int n) {
        int[] result = new int[n + 1];
        
        for (int i = 0; i <= n; i++) {
            result[i] = countOnes(i);
        }
        
        return result;
    }
    
    private int countOnes(int num) {
        int count = 0;
        
        while (num != 0) {
            count++;
            num &= (num - 1); // 清除最低位的1
        }
        
        return count;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n log n)
+ 空间复杂度：O(1)

### 🚀 进阶解法：动态规划（最高有效位）
```java
class Solution {
    public int[] countBits(int n) {
        int[] result = new int[n + 1];
        int highestBit = 0;
        
        for (int i = 1; i <= n; i++) {
            // 更新最高有效位
            if ((i & (i - 1)) == 0) {
                highestBit = i;
            }
            
            // dp[i] = dp[i - highestBit] + 1
            result[i] = result[i - highestBit] + 1;
        }
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

### 🚀 最优解法：动态规划（最低有效位）
```java
class Solution {
    public int[] countBits(int n) {
        int[] result = new int[n + 1];
        
        for (int i = 1; i <= n; i++) {
            // dp[i] = dp[i >> 1] + (i & 1)
            result[i] = result[i >> 1] + (i & 1);
        }
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

**核心思想：**

+ `i >> 1` 相当于去掉最低位
+ `i & 1` 表示最低位是否为1
+ `dp[i] = dp[i/2] + i%2`

### 🚀 另一种DP解法：清除最低位1
```java
class Solution {
    public int[] countBits(int n) {
        int[] result = new int[n + 1];
        
        for (int i = 1; i <= n; i++) {
            // dp[i] = dp[i & (i-1)] + 1
            result[i] = result[i & (i - 1)] + 1;
        }
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

**核心思想：**

+ `i & (i-1)` 清除i的最低位1
+ 清除一个1后，1的个数减1

## 3️⃣ 汉明距离 (LeetCode 461)
### 📝 题目描述
两个整数之间的 **汉明距离** 指的是这两个数字对应二进制位不同的位置的数目。

给你两个整数 `x` 和 `y`，计算并返回它们之间的汉明距离。

**示例 1：**

```plain
输入：x = 1, y = 4
输出：2
解释：
1   (0 0 0 1)
4   (0 1 0 0)
       ↑   ↑
上面的箭头指出了对应二进制位不同的位置。
```

**示例 2：**

```plain
输入：x = 3, y = 1
输出：1
```

### 🔧 基础解法：逐位比较
```java
class Solution {
    public int hammingDistance(int x, int y) {
        int distance = 0;
        
        while (x != 0 || y != 0) {
            if ((x & 1) != (y & 1)) {
                distance++;
            }
            
            x >>= 1;
            y >>= 1;
        }
        
        return distance;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(log max(x,y))
+ 空间复杂度：O(1)

### 🚀 进阶解法：异或+计数
```java
class Solution {
    public int hammingDistance(int x, int y) {
        int xor = x ^ y;
        int distance = 0;
        
        while (xor != 0) {
            distance++;
            xor &= (xor - 1); // 清除最低位的1
        }
        
        return distance;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(1)，最多32次循环
+ 空间复杂度：O(1)

### 🚀 最优解法：内置函数
```java
class Solution {
    public int hammingDistance(int x, int y) {
        return Integer.bitCount(x ^ y);
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(1)
+ 空间复杂度：O(1)

### 🚀 手动实现bitCount
```java
class Solution {
    public int hammingDistance(int x, int y) {
        return bitCount(x ^ y);
    }
    
    private int bitCount(int n) {
        // Brian Kernighan算法
        int count = 0;
        while (n != 0) {
            count++;
            n &= (n - 1);
        }
        return count;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(1)
+ 空间复杂度：O(1)

## 4️⃣ 丢失的数字 (LeetCode 268)
### 📝 题目描述
给定一个包含 `[0, n]` 中 `n` 个数的数组 `nums` ，找出 `[0, n]` 这个范围内没有出现在数组中的那个数。

**示例 1：**

```plain
输入：nums = [3,0,1]
输出：2
解释：n = 3，因为有 3 个数字，所以所有的数字都在范围 [0,3] 内。2 是丢失的数字，因为它没有出现在 nums 中。
```

**示例 2：**

```plain
输入：nums = [0,1]
输出：2
解释：n = 2，因为有 2 个数字，所以所有的数字都在范围 [0,2] 内。2 是丢失的数字，因为它没有出现在 nums 中。
```

**示例 3：**

```plain
输入：nums = [9,6,4,2,3,5,7,0,1]
输出：8
解释：n = 9，因为有 9 个数字，所以所有的数字都在范围 [0,9] 内。8 是丢失的数字，因为它没有出现在 nums 中。
```

### 🔧 基础解法：哈希表
```java
class Solution {
    public int missingNumber(int[] nums) {
        Set<Integer> numSet = new HashSet<>();
        
        for (int num : nums) {
            numSet.add(num);
        }
        
        for (int i = 0; i <= nums.length; i++) {
            if (!numSet.contains(i)) {
                return i;
            }
        }
        
        return -1; // 不会到达这里
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(n)

### 🚀 进阶解法：排序
```java
class Solution {
    public int missingNumber(int[] nums) {
        Arrays.sort(nums);
        
        // 检查0是否丢失
        if (nums[0] != 0) {
            return 0;
        }
        
        // 检查中间是否有丢失
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[i - 1] + 1) {
                return nums[i - 1] + 1;
            }
        }
        
        // 丢失的是最后一个数
        return nums.length;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n log n)
+ 空间复杂度：O(1)

### 🚀 数学解法：求和
```java
class Solution {
    public int missingNumber(int[] nums) {
        int n = nums.length;
        int expectedSum = n * (n + 1) / 2;
        int actualSum = 0;
        
        for (int num : nums) {
            actualSum += num;
        }
        
        return expectedSum - actualSum;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

### 🚀 最优解法：异或运算
```java
class Solution {
    public int missingNumber(int[] nums) {
        int missing = nums.length;
        
        for (int i = 0; i < nums.length; i++) {
            missing ^= i ^ nums[i];
        }
        
        return missing;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

**核心思想：**

+ 将索引和数组元素一起异或
+ 相同的数字异或后为0
+ 最后剩下的就是丢失的数字

### 🚀 另一种异或写法
```java
class Solution {
    public int missingNumber(int[] nums) {
        int result = 0;
        
        // 异或所有索引
        for (int i = 0; i <= nums.length; i++) {
            result ^= i;
        }
        
        // 异或所有数组元素
        for (int num : nums) {
            result ^= num;
        }
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

## 5️⃣ 位1的个数 (LeetCode 191)
### 📝 题目描述
编写一个函数，输入是一个无符号整数（以二进制串的形式），返回其二进制表达式中数字位数为 '1' 的个数（也被称为汉明重量）。

**提示：**

+ 请注意，在某些语言（如 Java）中，没有无符号整数类型。在这种情况下，输入和输出都将被指定为有符号整数类型，并且不应影响您的实现，因为无论整数是有符号的还是无符号的，其内部的二进制表示形式都是相同的。
+ 在 Java 中，编译器使用二进制补码记法来表示有符号整数。因此，在上面的 示例 3 中，输入表示有符号整数 -3。

**示例 1：**

```plain
输入：00000000000000000000000000001011
输出：3
解释：输入的二进制串 00000000000000000000000000001011 中，共有三位为 '1'。
```

**示例 2：**

```plain
输入：00000000000000000000000010000000
输出：1
解释：输入的二进制串 00000000000000000000000010000000 中，共有一位为 '1'。
```

**示例 3：**

```plain
输入：11111111111111111111111111111101
输出：31
解释：输入的二进制串 11111111111111111111111111111101 中，共有 31 位为 '1'。
```

### 🔧 基础解法：逐位检查
```java
public class Solution {
    // you need to treat n as an unsigned value
    public int hammingWeight(int n) {
        int count = 0;
        
        for (int i = 0; i < 32; i++) {
            if ((n & (1 << i)) != 0) {
                count++;
            }
        }
        
        return count;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(1)，固定32次循环
+ 空间复杂度：O(1)

### 🚀 进阶解法：右移检查
```java
public class Solution {
    public int hammingWeight(int n) {
        int count = 0;
        
        while (n != 0) {
            count += n & 1;
            n >>>= 1; // 无符号右移
        }
        
        return count;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(1)
+ 空间复杂度：O(1)

### 🚀 最优解法：Brian Kernighan算法
```java
public class Solution {
    public int hammingWeight(int n) {
        int count = 0;
        
        while (n != 0) {
            count++;
            n &= (n - 1); // 清除最低位的1
        }
        
        return count;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(1)，最多循环1的个数次
+ 空间复杂度：O(1)

**核心思想：**

+ `n & (n-1)` 可以清除n的最低位1
+ 每次清除一个1，计数器加1
+ 直到n变为0

### 🚀 内置函数解法
```java
public class Solution {
    public int hammingWeight(int n) {
        return Integer.bitCount(n);
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(1)
+ 空间复杂度：O(1)

### 🚀 查表法
```java
public class Solution {
    // 预计算0-255每个数的1的个数
    private static final int[] BIT_COUNT = new int[256];
    
    static {
        for (int i = 0; i < 256; i++) {
            BIT_COUNT[i] = (i & 1) + BIT_COUNT[i >> 1];
        }
    }
    
    public int hammingWeight(int n) {
        return BIT_COUNT[n & 0xFF] + 
               BIT_COUNT[(n >> 8) & 0xFF] + 
               BIT_COUNT[(n >> 16) & 0xFF] + 
               BIT_COUNT[(n >> 24) & 0xFF];
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(1)
+ 空间复杂度：O(1)

## 📚 位运算专题总结

#### 1. 基础位运算
+ **与运算(&)**：用于清零特定位、判断奇偶性

+ **非运算(~)**：用于位取反

#### 2. 常用位运算技巧
+ **判断奇偶**：`n & 1`
+ **清除最低位1**：`n & (n-1)`

+ **交换两数**：使用异或运算

+ **交换律**：`a ^ b = b ^ a`
+ **结合律**：`(a ^ b) ^ c = a ^ (b ^ c)`
+ **自反性**：`a ^ a = 0`，`a ^ 0 = a`
+ **分配律**：`a & (b | c) = (a & b) | (a & c)`

#### 4. 高级应用
