 所以我们需要获得什么

1. 数组的length
2. 对重复元素进行分组,并且找到重复元素最多的那一个的重复数量作为m 获取m-1
3. 找到间隔n 获取n+1
4. 找到重复元素最多的是否有相同的最多的,如果有,得到更多的对应的数量x

 最后Math.max(length,(n+1) * (m-1) + 1+ x);



```java
class Solution {
    public int leastInterval(char[] tasks, int n) {
        Map<Character,Integer> map = new hashMap();
        int length = tasks.length;
        int max = 0;
        for(int i=0;i<length;i++){
            int count = map.getOrDefault(tasks[i] , 0) +1;
            map.put(tasks[i],count);
            max = Math.max(max,count);
        }
        List<Integer> list = new ArrayList<>();
        for(Map.Entry<Character,Integer> entry:map.entry()){
            if(max == entry.getValue()){
                list.add(entry.getKey());
            }
        }
        // Math.max(length,(n+1) * (m-1) + 1+ x)
        return Math.max(length , (n+1) * (max-1) + 1 + (list.size()-1));
    }
}
```
