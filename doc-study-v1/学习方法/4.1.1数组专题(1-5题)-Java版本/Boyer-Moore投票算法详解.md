# Boyer-Moore投票算法详解
## 算法概述
Boyer-Moore投票算法（Boyer-Moore Majority Vote Algorithm），也被称为摩尔投票算法或多数投票算法，是一个用于找到数组中多数元素的高效算法。

## 算法实现
```java
class Solution {
    public int majorityElement(int[] nums) {
        int candidate = nums[0];
        int count = 1;
        
        // Boyer-Moore投票算法
        for (int i = 1; i < nums.length; i++) {
            if (count == 0) {
                candidate = nums[i];
                count = 1;
            } else if (nums[i] == candidate) {
                count++;
            } else {
                count--;
            }
        }
        
        return candidate;
    }
}
```

## 算法核心思想
**投票机制**：把数组中的每个元素看作一个"候选人"，通过投票的方式找出多数元素。

### 算法步骤详解
1. **初始化**：
    - `candidate = nums[0]`：将第一个元素作为候选人
    - `count = 1`：候选人的票数为1
2. **遍历投票**：
    - 如果 `count == 0`：说明之前的候选人票数被抵消完了，选择当前元素作为新候选人
    - 如果当前元素等于候选人：给候选人投票，`count++`
    - 如果当前元素不等于候选人：投反对票，`count--`

## 算法正确性分析
### 数学原理
**多数元素的定义**：出现次数 > ⌊n/2⌋ 的元素

这意味着：

+ 在长度为n的数组中，多数元素至少出现 ⌊n/2⌋ + 1 次
+ 所有非多数元素的总数 < ⌊n/2⌋

### "数量占优"的体现
#### 1. **数量优势保证最终胜出**
```plain
多数元素数量 > 所有其他元素数量之和
```

即使在"对抗"过程中：

+ 多数元素可能暂时被"抵消"（count = 0）
+ 但由于数量优势，它总能"东山再起"
+ 最终必然成为最后的候选人

#### 2. **具体例子说明**
假设数组：`[2, 2, 1, 1, 1, 2, 2]`

+ 多数元素：2（出现4次）
+ 非多数元素：1（出现3次）
+ 4 > 3，满足数量占优

**算法执行过程**：

```plain
元素: 2  2  1  1  1  2  2
候选: 2  2  2  2  2  2  2
计数: 1  2  1  0  1  2  3
```

关键观察：

+ 即使在第4步count变为0（候选人被完全抵消）
+ 但多数元素2仍有剩余，继续参与"选举"
+ 最终count = 3 > 0，2胜出

#### 3. **理论保证**
**核心洞察**：多数元素与所有非多数元素"一对一抵消"后，多数元素仍有剩余。

**数学证明**：

+ 设多数元素出现m次，非多数元素总共出现k次
+ 由定义：m > k
+ 经过"抵消"后：剩余 = m - k > 0
+ 因此多数元素必然是最后的候选人

## 算法优势
+ **时间复杂度**：O(n) - 只需要一次遍历
+ **空间复杂度**：O(1) - 只使用常数额外空间
+ **优雅简洁**：不需要排序或哈希表，是最优解
