# 归并排序详解：稳定高效的分治算法
## 📚 什么是归并排序
归并排序（Merge Sort）是一种基于**分治思想**的稳定排序算法，由约翰·冯·诺伊曼在1945年发明。它的核心思想是"分而治之"：将大问题分解为小问题，解决小问题后再合并结果。

### 核心思想
1. **分解（Divide）**：将数组从中间分成两个子数组
2. **解决（Conquer）**：递归地对两个子数组进行归并排序
3. **合并（Combine）**：将两个已排序的子数组合并成一个有序数组

### 算法特点
+ **时间复杂度**：始终 O(n log n)（最好、平均、最坏都相同）
+ **空间复杂度**：O(n)（需要额外数组空间）
+ **稳定性**：稳定排序
+ **原地排序**：否（需要额外空间）
+ **分治算法**：典型的分治算法实现

## 🎯 何时使用归并排序
### 适用场景
1. **需要稳定排序**：保持相等元素的相对位置不变
2. **要求时间复杂度稳定**：无论什么数据都保证 O(n log n)
3. **大数据量排序**：对于大型数据集表现优秀
4. **外部排序**：处理无法完全加载到内存的大文件
5. **链表排序**：归并排序特别适合链表结构
6. **并行计算**：容易并行化实现

### 优势特点
```java
// 示例：需要稳定排序的场景
class Student {
    String name;
    int score;
    int id;  // 学号
}

// 按分数排序，分数相同时保持学号顺序
// 归并排序能保证稳定性
Student[] students = {
    new Student("Alice", 85, 1001),
    new Student("Bob", 90, 1002),
    new Student("Charlie", 85, 1003)  // 与Alice分数相同
};
// 排序后Charlie仍在Alice后面
```

### 不适用场景
1. **内存受限**：需要额外的 O(n) 空间
2. **小数据量**：对于小数组，插入排序可能更快
3. **原地排序需求**：如果必须原地排序，选择快速排序或堆排序

## 💻 归并排序通用代码模板
### 基础递归版本
```java
public class MergeSort {
    public void mergeSort(int[] arr) {
        if (arr == null || arr.length <= 1) {
            return;
        }
        
        int[] temp = new int[arr.length];
        mergeSort(arr, temp, 0, arr.length - 1);
    }
    
    private void mergeSort(int[] arr, int[] temp, int left, int right) {
        if (left >= right) {
            return;
        }
        
        // 分解：找到中点
        int mid = left + (right - left) / 2;
        
        // 递归排序左半部分
        mergeSort(arr, temp, left, mid);
        // 递归排序右半部分
        mergeSort(arr, temp, mid + 1, right);
        
        // 合并两个已排序的部分
        merge(arr, temp, left, mid, right);
    }
    
    private void merge(int[] arr, int[] temp, int left, int mid, int right) {
        // 复制到临时数组
        for (int i = left; i <= right; i++) {
            temp[i] = arr[i];
        }
        
        int i = left;      // 左半部分的指针
        int j = mid + 1;   // 右半部分的指针
        int k = left;      // 合并后数组的指针
        
        // 合并两个有序数组
        while (i <= mid && j <= right) {
            if (temp[i] <= temp[j]) {
                arr[k++] = temp[i++];
            } else {
                arr[k++] = temp[j++];
            }
        }
        
        // 复制剩余元素
        while (i <= mid) {
            arr[k++] = temp[i++];
        }
        while (j <= right) {
            arr[k++] = temp[j++];
        }
    }
}
```

### 优化版本（减少数组复制）
```java
public class MergeSortOptimized {
    public void mergeSort(int[] arr) {
        if (arr == null || arr.length <= 1) {
            return;
        }
        
        int[] aux = arr.clone();  // 辅助数组
        mergeSort(aux, arr, 0, arr.length - 1);
    }
    
    private void mergeSort(int[] src, int[] dst, int left, int right) {
        if (left >= right) {
            return;
        }
        
        int mid = left + (right - left) / 2;
        
        // 注意：递归时交换src和dst
        mergeSort(dst, src, left, mid);
        mergeSort(dst, src, mid + 1, right);
        
        merge(src, dst, left, mid, right);
    }
    
    private void merge(int[] src, int[] dst, int left, int mid, int right) {
        int i = left, j = mid + 1;
        
        for (int k = left; k <= right; k++) {
            if (i > mid) {
                dst[k] = src[j++];
            } else if (j > right) {
                dst[k] = src[i++];
            } else if (src[i] <= src[j]) {
                dst[k] = src[i++];
            } else {
                dst[k] = src[j++];
            }
        }
    }
}
```

### 迭代版本（自底向上）
```java
public class MergeSortIterative {
    public void mergeSort(int[] arr) {
        int n = arr.length;
        int[] temp = new int[n];
        
        // 子数组大小从1开始，每次翻倍
        for (int size = 1; size < n; size *= 2) {
            // 合并相邻的子数组
            for (int left = 0; left < n - size; left += 2 * size) {
                int mid = left + size - 1;
                int right = Math.min(left + 2 * size - 1, n - 1);
                merge(arr, temp, left, mid, right);
            }
        }
    }
    
    // merge方法同上
}
```

## 🌟 简单例题：数组排序
### 题目
给定一个整数数组 `[38, 27, 43, 3, 9, 82, 10]`，使用归并排序将其升序排列。

### 完整解答
```java
public class MergeSortExample {
    public static void main(String[] args) {
        int[] arr = {38, 27, 43, 3, 9, 82, 10};
        System.out.println("排序前: " + Arrays.toString(arr));
        
        mergeSort(arr);
        
        System.out.println("排序后: " + Arrays.toString(arr));
    }
    
    public static void mergeSort(int[] arr) {
        if (arr.length <= 1) return;
        
        int[] temp = new int[arr.length];
        mergeSort(arr, temp, 0, arr.length - 1);
    }
    
    private static void mergeSort(int[] arr, int[] temp, int left, int right) {
        if (left >= right) return;
        
        int mid = left + (right - left) / 2;
        
        System.out.printf("分解: [%d, %d] -> [%d, %d] 和 [%d, %d]\n", 
                         left, right, left, mid, mid + 1, right);
        
        mergeSort(arr, temp, left, mid);
        mergeSort(arr, temp, mid + 1, right);
        
        merge(arr, temp, left, mid, right);
        
        System.out.printf("合并: [%d, %d] 结果: ", left, right);
        for (int i = left; i <= right; i++) {
            System.out.print(arr[i] + " ");
        }
        System.out.println();
    }
    
    private static void merge(int[] arr, int[] temp, int left, int mid, int right) {
        // 复制到临时数组
        for (int i = left; i <= right; i++) {
            temp[i] = arr[i];
        }
        
        int i = left, j = mid + 1, k = left;
        
        while (i <= mid && j <= right) {
            if (temp[i] <= temp[j]) {
                arr[k++] = temp[i++];
            } else {
                arr[k++] = temp[j++];
            }
        }
        
        while (i <= mid) arr[k++] = temp[i++];
        while (j <= right) arr[k++] = temp[j++];
    }
}
```

```plain
分解过程：
```

## 📊 复杂度分析详解
### 时间复杂度：O(n log n)
#### 分治树分析
```plain
层数分析：
- 每次将数组分成两半，直到只剩一个元素
- 数组长度从 n -> n/2 -> n/4 -> ... -> 1
- 总共需要 log₂ n 层

每层工作量：
- 第1层：合并操作处理 n 个元素
- 第2层：合并操作处理 n 个元素
- ...
- 第log n层：合并操作处理 n 个元素

总时间复杂度：
T(n) = log n × n = O(n log n)
```

#### 递推关系
```java
// 归并排序的递推关系
T(n) = 2T(n/2) + O(n)

// 其中：
// 2T(n/2) 表示递归处理两个子数组的时间
// O(n) 表示合并两个子数组的时间

// 根据主定理，解得：T(n) = O(n log n)
```

### 空间复杂度：O(n)
```java
// 需要额外的临时数组存储合并结果
int[] temp = new int[arr.length];  // O(n) 空间

// 递归调用栈深度为 log n
// 但主要空间消耗是临时数组，所以总空间复杂度为 O(n)
```

## 🔄 归并排序的变种
### 1. 自然归并排序
```java
// 利用数组中已存在的有序子序列
public void naturalMergeSort(int[] arr) {
    int n = arr.length;
    int[] temp = new int[n];
    
    while (true) {
        int runCount = 0;
        int left = 0;
        
        while (left < n) {
            // 找到一个自然有序的run
            int right = left;
            while (right + 1 < n && arr[right] <= arr[right + 1]) {
                right++;
            }
            
            if (right == n - 1) break;  // 整个数组已有序
            
            // 找到下一个run并合并
            int nextLeft = right + 1;
            int nextRight = nextLeft;
            while (nextRight + 1 < n && arr[nextRight] <= arr[nextRight + 1]) {
                nextRight++;
            }
            
            merge(arr, temp, left, right, Math.min(nextRight, n - 1));
            left = nextRight + 1;
            runCount++;
        }
        
        if (runCount == 0) break;  // 没有合并操作，排序完成
    }
}
```

### 2. 多路归并排序
```java
// 将数组分成k个部分，然后k路归并
public void kWayMergeSort(int[] arr, int k) {
    if (arr.length <= 1) return;
    
    // 分成k个子数组
    List<int[]> subArrays = new ArrayList<>();
    int size = arr.length / k;
    
    for (int i = 0; i < k; i++) {
        int start = i * size;
        int end = (i == k - 1) ? arr.length : (i + 1) * size;
        int[] subArray = Arrays.copyOfRange(arr, start, end);
        mergeSort(subArray);  // 递归排序子数组
        subArrays.add(subArray);
    }
    
    // k路归并
    kWayMerge(subArrays, arr);
}
```

## ⚡ 性能优化技巧
### 1. 小数组优化
```java
private static final int INSERTION_SORT_THRESHOLD = 10;

private void mergeSort(int[] arr, int[] temp, int left, int right) {
    if (right - left <= INSERTION_SORT_THRESHOLD) {
        // 小数组使用插入排序
        insertionSort(arr, left, right);
        return;
    }
    
    int mid = left + (right - left) / 2;
    mergeSort(arr, temp, left, mid);
    mergeSort(arr, temp, mid + 1, right);
    
    // 如果已经有序，跳过合并
    if (arr[mid] <= arr[mid + 1]) {
        return;
    }
    
    merge(arr, temp, left, mid, right);
}
```

### 2. 减少数组复制
```java
// 使用双缓冲技术，避免每次都复制数组
public void mergeSortNoCopy(int[] arr) {
    int[] aux = arr.clone();
    mergeSortNoCopy(aux, arr, 0, arr.length - 1);
}

private void mergeSortNoCopy(int[] src, int[] dst, int left, int right) {
    if (right - left <= INSERTION_SORT_THRESHOLD) {
        insertionSort(dst, left, right);
        return;
    }
    
    int mid = left + (right - left) / 2;
    
    // 交换源数组和目标数组
    mergeSortNoCopy(dst, src, left, mid);
    mergeSortNoCopy(dst, src, mid + 1, right);
    
    merge(src, dst, left, mid, right);
}
```

### 3. 并行归并排序
```java
public void parallelMergeSort(int[] arr) {
    ForkJoinPool pool = new ForkJoinPool();
    pool.invoke(new MergeSortTask(arr, 0, arr.length - 1));
}

class MergeSortTask extends RecursiveAction {
    private static final int THRESHOLD = 1000;
    private int[] arr;
    private int left, right;
    
    public MergeSortTask(int[] arr, int left, int right) {
        this.arr = arr;
        this.left = left;
        this.right = right;
    }
    
    @Override
    protected void compute() {
        if (right - left <= THRESHOLD) {
            // 小任务直接排序
            Arrays.sort(arr, left, right + 1);
        } else {
            int mid = left + (right - left) / 2;
            
            // 并行执行左右两部分
            MergeSortTask leftTask = new MergeSortTask(arr, left, mid);
            MergeSortTask rightTask = new MergeSortTask(arr, mid + 1, right);
            
            invokeAll(leftTask, rightTask);
            
            // 合并结果
            merge(arr, left, mid, right);
        }
    }
}
```

## 🎯 学习要点总结
1. **理解分治思想**：分解、解决、合并三个步骤
2. **掌握稳定性**：归并排序是稳定的，适合需要保持相对顺序的场景
3. **记住时间复杂度保证**：无论什么情况都是 O(n log n)
4. **了解空间代价**：需要额外的 O(n) 空间
5. **学会优化技巧**：小数组优化、减少复制、并行化
6. **掌握应用场景**：外部排序、链表排序、需要稳定性的场合

归并排序是理解分治算法的经典例子，也是实际应用中非常重要的排序算法！
