# 快速排序详解：从基础到快速选择
## 📚 什么是快速排序
快速排序（Quick Sort）是一种基于**分治思想**的高效排序算法，由英国计算机科学家托尼·霍尔在1960年提出。

### 核心思想
1. **选择基准元素（Pivot）**：从数组中选择一个元素作为基准
2. **分区操作（Partition）**：将数组重新排列，使得：
    - 所有小于基准的元素放在基准左边
    - 所有大于基准的元素放在基准右边
    - 基准元素处于最终排序位置
3. **递归处理**：对基准左右两个子数组分别进行快速排序

### 算法特点
+ **时间复杂度**：平均 O(n log n)，最坏 O(n²)
+ **空间复杂度**：O(log n)（递归栈空间）
+ **稳定性**：不稳定排序
+ **原地排序**：是

## 🎯 何时使用快速排序
### 适用场景
1. **大数据量排序**：当数据量较大时，快速排序平均性能优秀
2. **内存受限**：原地排序，空间复杂度低
3. **随机数据**：对于随机分布的数据，快速排序表现很好
4. **不要求稳定性**：当不需要保持相等元素的相对位置时

### 不适用场景
1. **已排序或接近排序的数据**：可能退化到 O(n²)
2. **需要稳定排序**：快速排序不是稳定的
3. **小数据量**：插入排序可能更快
4. **最坏情况不能接受**：如果必须保证 O(n log n)，选择归并排序

## 💻 快速排序通用代码模板
### 基础版本
```java
public class QuickSort {
    public void quickSort(int[] arr, int low, int high) {
        if (low < high) {
            // 分区操作，返回基准元素的正确位置
            int pivotIndex = partition(arr, low, high);
            
            // 递归排序基准左边的子数组
            quickSort(arr, low, pivotIndex - 1);
            // 递归排序基准右边的子数组
            quickSort(arr, pivotIndex + 1, high);
        }
    }
    
    private int partition(int[] arr, int low, int high) {
        // 选择最后一个元素作为基准
        int pivot = arr[high];
        int i = low - 1; // 小于基准的元素的索引
        
        for (int j = low; j < high; j++) {
            // 如果当前元素小于等于基准
            if (arr[j] <= pivot) {
                i++;
                swap(arr, i, j);
            }
        }
        
        // 将基准放到正确位置
        swap(arr, i + 1, high);
        return i + 1;
    }
    
    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

### 优化版本（随机基准）
```java
public class QuickSortOptimized {
    private Random random = new Random();
    
    public void quickSort(int[] arr, int low, int high) {
        if (low < high) {
            // 随机选择基准，避免最坏情况
            int randomIndex = low + random.nextInt(high - low + 1);
            swap(arr, randomIndex, high);
            
            int pivotIndex = partition(arr, low, high);
            quickSort(arr, low, pivotIndex - 1);
            quickSort(arr, pivotIndex + 1, high);
        }
    }
    
    // partition 和 swap 方法同上
}
```

## 🌟 简单例题：数组排序
### 题目
给定一个整数数组 `[3, 6, 8, 10, 1, 2, 1]`，使用快速排序将其升序排列。

### 完整解答
```java
public class QuickSortExample {
    public static void main(String[] args) {
        int[] arr = {3, 6, 8, 10, 1, 2, 1};
        System.out.println("排序前: " + Arrays.toString(arr));
        
        quickSort(arr, 0, arr.length - 1);
        
        System.out.println("排序后: " + Arrays.toString(arr));
    }
    
    public static void quickSort(int[] arr, int low, int high) {
        if (low < high) {
            int pivotIndex = partition(arr, low, high);
            quickSort(arr, low, pivotIndex - 1);
            quickSort(arr, pivotIndex + 1, high);
        }
    }
    
    private static int partition(int[] arr, int low, int high) {
        int pivot = arr[high]; // 选择最后一个元素作为基准
        int i = low - 1;
        
        for (int j = low; j < high; j++) {
            if (arr[j] <= pivot) {
                i++;
                swap(arr, i, j);
            }
        }
        
        swap(arr, i + 1, high);
        return i + 1;
    }
    
    private static void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

### 执行过程演示
```plain
初始数组: [3, 6, 8, 10, 1, 2, 1]
选择基准: 1 (最后一个元素)
分区后: [1, 6, 8, 10, 3, 2, 1] -> [1, 1, 8, 10, 3, 2, 6] -> [1, 1, 2, 10, 3, 8, 6] -> [1, 1, 2, 3, 10, 8, 6]
继续递归处理子数组...
最终结果: [1, 1, 2, 3, 6, 8, 10]
```

## ⚡ 快速选择算法：为什么时间复杂度是 O(n)
### 快速排序 vs 快速选择
| 算法 | 目标 | 时间复杂度 | 原因 |
| --- | --- | --- | --- |
| 快速排序 | 排序整个数组 | O(n log n) | 需要处理所有子数组 |
| 快速选择 | 找第k大/小元素 | O(n) | 只处理包含目标的一侧 |


### 为什么快速选择是 O(n)？
#### 1. 关键差异
```java
// 快速排序：处理两侧
quickSort(arr, low, pivotIndex - 1);  // 左侧
quickSort(arr, pivotIndex + 1, high); // 右侧

// 快速选择：只处理一侧
if (k < pivotIndex) {
    return quickSelect(arr, low, pivotIndex - 1, k);  // 只处理左侧
} else {
    return quickSelect(arr, pivotIndex + 1, high, k); // 只处理右侧
}
```

#### 2. 工作量分析
**快速排序的工作量：**

+ 第1层：处理 n 个元素
+ 第2层：处理 n/2 + n/2 = n 个元素
+ 第3层：处理 n/4 + n/4 + n/4 + n/4 = n 个元素
+ ...
+ 总共 log n 层，每层 n 个元素
+ **总工作量：n × log n = O(n log n)**

**快速选择的工作量：**

+ 第1层：处理 n 个元素
+ 第2层：处理 n/2 个元素（只选一侧）
+ 第3层：处理 n/4 个元素（只选一侧）
+ ...
+ **总工作量：n + n/2 + n/4 + n/8 + ... = 2n = O(n)**

#### 3. 数学证明
```plain
快速选择的总工作量 = n + n/2 + n/4 + n/8 + ...
这是一个几何级数，公比为 1/2
根据几何级数求和公式：S = a/(1-r) = n/(1-1/2) = 2n
因此时间复杂度为 O(n)
```

### 快速选择代码示例
```java
public int quickSelect(int[] nums, int left, int right, int k) {
    if (left == right) {
        return nums[left];
    }
    
    // 随机选择基准，避免最坏情况
    Random random = new Random();
    int pivotIndex = left + random.nextInt(right - left + 1);
    
    // 分区操作
    pivotIndex = partition(nums, left, right, pivotIndex);
    
    if (k == pivotIndex) {
        return nums[k];  // 找到目标
    } else if (k < pivotIndex) {
        return quickSelect(nums, left, pivotIndex - 1, k);  // 只处理左侧
    } else {
        return quickSelect(nums, pivotIndex + 1, right, k); // 只处理右侧
    }
}
```

## 📊 复杂度对比总结
### 时间复杂度对比
| 场景 | 快速排序 | 快速选择 | 原因 |
| --- | --- | --- | --- |
| 平均情况 | O(n log n) | O(n) | 选择算法只处理一侧 |
| 最坏情况 | O(n²) | O(n²) | 基准选择不当时 |
| 最好情况 | O(n log n) | O(n) | 基准总是中位数时 |


### 核心区别
1. **快速排序**：需要完全排序，必须处理所有子数组
2. **快速选择**：只需找到第k个元素，可以丢弃一半数据
3. **关键优化**：每次递归只处理包含目标的那一侧

## 🎯 学习要点总结
1. **掌握分治思想**：快速排序的核心是分区操作
2. **理解基准选择**：随机基准可以避免最坏情况
3. **区分应用场景**：排序用快速排序，查找第k个元素用快速选择
4. **复杂度分析**：理解为什么快速选择是O(n)而快速排序是O(n log n)
5. **代码模板**：熟练掌握partition函数的实现

通过理解这些核心概念，你就能灵活运用快速排序及其变种算法来解决各种问题！
