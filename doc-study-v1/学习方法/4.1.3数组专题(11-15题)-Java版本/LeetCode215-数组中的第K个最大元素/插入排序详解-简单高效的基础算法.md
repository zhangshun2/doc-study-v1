# 插入排序详解：简单高效的基础算法
## 📚 什么是插入排序
插入排序（Insertion Sort）是一种简单直观的排序算法，其工作原理类似于我们整理扑克牌的过程：将每张牌插入到已排序牌组的正确位置。

### 核心思想
1. **从第二个元素开始**：假设第一个元素已经排序
2. **逐个插入**：将当前元素插入到前面已排序序列的正确位置
3. **向后移动**：比较并移动元素，为新元素腾出位置
4. **重复过程**：直到所有元素都被正确插入

### 算法特点
+ **时间复杂度**：最好 O(n)，平均 O(n²)，最坏 O(n²)
+ **空间复杂度**：O(1)
+ **稳定性**：稳定排序
+ **原地排序**：是
+ **自适应性**：对部分有序数据表现优秀

## 🎯 何时使用插入排序
### 适用场景
1. **小数据量**：当数组长度小于50时，插入排序通常比快速排序更快
2. **部分有序数据**：对于已经基本排序的数据，插入排序接近线性时间
3. **在线算法**：可以在接收数据的同时进行排序
4. **需要稳定排序**：保持相等元素的相对位置不变
5. **作为混合算法的一部分**：许多高级排序算法在小数组时切换到插入排序

### 优势场景
```java
// 示例：部分有序数据
int[] partiallysorted = {1, 2, 3, 5, 4, 6, 7, 8}; // 只有一个元素位置错误
// 插入排序只需要很少的操作就能完成排序
```

### 不适用场景
1. **大数据量**：当数组长度超过1000时，性能明显下降
2. **完全随机数据**：需要大量的比较和移动操作
3. **对性能要求极高**：O(n²) 的最坏情况可能不可接受

## 💻 插入排序通用代码模板
### 基础版本
```java
public class InsertionSort {
    public void insertionSort(int[] arr) {
        int n = arr.length;
        
        // 从第二个元素开始（索引1）
        for (int i = 1; i < n; i++) {
            int key = arr[i];  // 当前要插入的元素
            int j = i - 1;     // 已排序部分的最后一个元素索引
            
            // 向右移动所有大于key的元素
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }
            
            // 插入key到正确位置
            arr[j + 1] = key;
        }
    }
}
```

### 优化版本（二分查找插入位置）
```java
public class BinaryInsertionSort {
    public void binaryInsertionSort(int[] arr) {
        int n = arr.length;
        
        for (int i = 1; i < n; i++) {
            int key = arr[i];
            
            // 使用二分查找找到插入位置
            int insertPos = binarySearch(arr, 0, i - 1, key);
            
            // 移动元素
            for (int j = i - 1; j >= insertPos; j--) {
                arr[j + 1] = arr[j];
            }
            
            // 插入元素
            arr[insertPos] = key;
        }
    }
    
    private int binarySearch(int[] arr, int left, int right, int key) {
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (arr[mid] > key) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }
}
```

### 泛型版本
```java
public class GenericInsertionSort {
    public <T extends Comparable<T>> void insertionSort(T[] arr) {
        int n = arr.length;
        
        for (int i = 1; i < n; i++) {
            T key = arr[i];
            int j = i - 1;
            
            while (j >= 0 && arr[j].compareTo(key) > 0) {
                arr[j + 1] = arr[j];
                j--;
            }
            
            arr[j + 1] = key;
        }
    }
}
```

## 🌟 简单例题：数组排序
### 题目
给定一个整数数组 `[5, 2, 4, 6, 1, 3]`，使用插入排序将其升序排列。

### 完整解答
```java
public class InsertionSortExample {
    public static void main(String[] args) {
        int[] arr = {5, 2, 4, 6, 1, 3};
        System.out.println("排序前: " + Arrays.toString(arr));
        
        insertionSort(arr);
        
        System.out.println("排序后: " + Arrays.toString(arr));
    }
    
    public static void insertionSort(int[] arr) {
        int n = arr.length;
        
        for (int i = 1; i < n; i++) {
            int key = arr[i];
            int j = i - 1;
            
            System.out.printf("第%d轮：插入元素 %d\n", i, key);
            System.out.println("插入前: " + Arrays.toString(arr));
            
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }
            
            arr[j + 1] = key;
            System.out.println("插入后: " + Arrays.toString(arr));
            System.out.println();
        }
    }
}
```

## 📊 复杂度分析详解
### 时间复杂度分析
#### 最好情况：O(n)
```java

// 每个元素只需要比较一次，不需要移动
for (int i = 1; i < n; i++) {
    // while循环条件 arr[j] > key 永远为false
    // 只执行一次比较，总共n-1次比较
}
```

#### 最坏情况：O(n²)
```java
// 数组逆序排列：[5, 4, 3, 2, 1]
// 第i个元素需要与前面所有i个元素比较
// 比较次数：1 + 2 + 3 + ... + (n-1) = n(n-1)/2 = O(n²)
```

#### 平均情况：O(n²)
```java
// 随机数组：平均每个元素需要与前面一半的元素比较
// 比较次数：约为 n²/4 = O(n²)
```

### 空间复杂度：O(1)
```java
// 只使用了常数个额外变量：key, i, j
// 不需要额外的数组空间
```

## 🔄 插入排序的变种
### 1. 希尔排序（Shell Sort）
```java
// 插入排序的改进版本，使用间隔序列
public void shellSort(int[] arr) {
    int n = arr.length;
    
    // 从大间隔开始，逐渐减小间隔
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // 对每个间隔进行插入排序
        for (int i = gap; i < n; i++) {
            int key = arr[i];
            int j = i;
            
            while (j >= gap && arr[j - gap] > key) {
                arr[j] = arr[j - gap];
                j -= gap;
            }
            
            arr[j] = key;
        }
    }
}
```

## ⚡ 性能优化技巧
### 1. 哨兵优化
```java
public void insertionSortWithSentinel(int[] arr) {
    // 将最小元素放在第一位作为哨兵
    int minIndex = 0;
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] < arr[minIndex]) {
            minIndex = i;
        }
    }
    swap(arr, 0, minIndex);
    
    // 现在可以省略边界检查 j >= 0
    for (int i = 2; i < arr.length; i++) {
        int key = arr[i];
        int j = i - 1;
        
        while (arr[j] > key) {  // 不需要检查 j >= 0
            arr[j + 1] = arr[j];
            j--;
        }
        
        arr[j + 1] = key;
    }
}
```

### 2. 提前终止优化
```java
public void insertionSortEarlyTermination(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        int key = arr[i];
        
        // 如果当前元素已经大于等于前一个元素，跳过
        if (key >= arr[i - 1]) {
            continue;
        }
        
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

```java
// Timsort（Python默认排序）中的应用
// 对小的run使用插入排序
public void timSort(int[] arr) {
    int minRun = computeMinRun(arr.length);
    
    for (int i = 0; i < arr.length; i += minRun) {
        int end = Math.min(i + minRun, arr.length);
        insertionSort(arr, i, end);  // 小段使用插入排序
    }
    
    // 然后合并这些已排序的段
}
```

### 3. 在线数据处理
```java
// 实时接收数据并保持排序状态
public class OnlineSorter {
    private List<Integer> sortedList = new ArrayList<>();
    
    public void addElement(int element) {
        // 使用插入排序的思想插入新元素
        int insertPos = Collections.binarySearch(sortedList, element);
        if (insertPos < 0) {
            insertPos = -insertPos - 1;
        }
        sortedList.add(insertPos, element);
    }
}
```
