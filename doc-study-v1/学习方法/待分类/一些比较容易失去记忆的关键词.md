# 一些比较容易失去记忆的关键词



处理链表的后续节点要要声明一个临时节点ListNode temp去处理;不处理链表本身

处理二叉树的结构要先分清楚需要处理的性质,然后梳理出需要的处理代码,递归不是手段,递归是传递处理代码的手段

先入先出是队列

后入先出是栈

遇到需要依赖于正序特性的,队列是需要的

遇到需要左右对称验证的,或者从某个点开始需要验证顺序的,大概率是栈

遇到局部验证顺序的,大概率是根堆

遇到需要复杂度On的排序,或者空间复杂度够低的,大概率是归并思想的排序

遇到需要时间复杂度Ologn的,大概率是涉及到二分,或者不断的左右遍历的二叉树
