# 题解：LeetCode 1249 - 移除无效的括号

## 1. 问题分析

这道题要求从字符串中删除最少数目的无效括号，使得结果字符串的括号是匹配的。本质上，这是一个**识别并移除无效括号**的问题，非常适合使用**栈+哈希表**来解决。

### 问题特点：
- 需要识别哪些括号是无效的
- 要求删除最少数量的括号
- 字符串中包含字母和括号
- 需要保留所有字母

## 2. 栈+哈希表解决方案

### 2.1 核心思路

使用**栈**来匹配括号，使用**哈希表(Set)**来记录需要删除的括号位置：

1. 使用栈存储左括号的索引
2. 遇到右括号时尝试匹配栈顶的左括号
3. 无法匹配的括号都是无效的，记录它们的索引
4. 最后根据记录的索引构建有效字符串

### 2.2 算法流程

1. 初始化一个空栈和一个哈希表(Set)
2. 第一次遍历字符串：
   - 遇到左括号：将索引压入栈
   - 遇到右括号：
     - 如果栈不为空，弹出栈顶（匹配成功）
     - 如果栈为空，记录当前索引为无效右括号
   - 遇到字母：直接跳过
3. 处理栈中剩余的左括号：
   - 栈中剩余的都是无效左括号，记录它们的索引
4. 第二次遍历字符串：
   - 跳过所有记录在哈希表中的无效括号索引
   - 构建最终的有效字符串

## 3. 代码实现

```java
public String minRemoveToMakeValid(String s) {
    // 第一步：使用栈找出所有无效括号的索引
    Set<Integer> invalidIndices = new HashSet<>();
    Stack<Integer> stack = new Stack<>();
    
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        
        if (c == '(') {
            // 左括号入栈
            stack.push(i);
        } else if (c == ')') {
            if (!stack.isEmpty()) {
                // 匹配成功，弹出左括号
                stack.pop();
            } else {
                // 无法匹配的右括号
                invalidIndices.add(i);
            }
        }
        // 字母直接跳过
    }
    
    // 栈中剩余的都是无效的左括号
    while (!stack.isEmpty()) {
        invalidIndices.add(stack.pop());
    }
    
    // 第二步：构建结果字符串
    StringBuilder result = new StringBuilder();
    for (int i = 0; i < s.length(); i++) {
        if (!invalidIndices.contains(i)) {
            result.append(s.charAt(i));
        }
    }
    
    return result.toString();
}
```

## 4. 优化方案

### 4.1 两次遍历优化版

可以通过两次遍历来避免使用哈希表，减少空间使用：

```java
public String minRemoveToMakeValid(String s) {
    // 第一次遍历：从左到右，移除无效的右括号
    StringBuilder firstPass = new StringBuilder();
    int leftCount = 0;
    
    for (char c : s.toCharArray()) {
        if (c == '(') {
            firstPass.append(c);
            leftCount++;
        } else if (c == ')') {
            if (leftCount > 0) {
                firstPass.append(c);
                leftCount--;
            }
            // 否则跳过这个无效的右括号
        } else {
            firstPass.append(c);
        }
    }
    
    // 第二次遍历：从右到左，移除多余的左括号
    StringBuilder result = new StringBuilder();
    int rightCount = 0;
    
    for (int i = firstPass.length() - 1; i >= 0; i--) {
        char c = firstPass.charAt(i);
        
        if (c == ')') {
            result.append(c);
            rightCount++;
        } else if (c == '(') {
            if (rightCount > 0) {
                result.append(c);
                rightCount--;
            }
            // 否则跳过这个多余的左括号
        } else {
            result.append(c);
        }
    }
    
    return result.reverse().toString();
}
```

### 4.2 计数法

另一种优化方法是使用计数法，只需要一次遍历就能确定需要删除的括号数量：

```java
public String minRemoveToMakeValid(String s) {
    char[] chars = s.toCharArray();
    int openCount = 0;
    
    // 第一次遍历：处理多余的右括号
    for (int i = 0; i < chars.length; i++) {
        if (chars[i] == '(') {
            openCount++;
        } else if (chars[i] == ')') {
            if (openCount == 0) {
                // 无效的右括号，标记为删除
                chars[i] = '*';
            } else {
                openCount--;
            }
        }
    }
    
    // 第二次遍历：处理多余的左括号（从右到左）
    openCount = 0;
    for (int i = chars.length - 1; i >= 0; i--) {
        if (chars[i] == ')') {
            openCount++;
        } else if (chars[i] == '(') {
            if (openCount == 0) {
                // 无效的左括号，标记为删除
                chars[i] = '*';
            } else {
                openCount--;
            }
        }
    }
    
    // 构建结果
    StringBuilder result = new StringBuilder();
    for (char c : chars) {
        if (c != '*') {
            result.append(c);
        }
    }
    
    return result.toString();
}
```

## 5. 复杂度分析

### 栈+哈希表解法：
- **时间复杂度**：O(n)，其中n是字符串的长度。需要两次遍历字符串。
- **空间复杂度**：O(n)，最坏情况下所有括号都无效，需要存储所有索引。

### 两次遍历优化版：
- **时间复杂度**：O(n)，需要三次遍历（两次正向，一次反转）。
- **空间复杂度**：O(n)，需要两个StringBuilder来存储中间结果。

### 计数法：
- **时间复杂度**：O(n)，需要两次遍历。
- **空间复杂度**：O(n)，需要一个字符数组来标记删除位置。

## 6. 总结

### 6.1 解题关键点

1. **识别无效括号**：使用栈来匹配括号，无法匹配的括号就是无效的
2. **记录需要删除的位置**：使用哈希表或其他方法记录无效括号的位置
3. **构建有效字符串**：跳过无效括号，保留其他字符

### 6.2 栈+哈希表应用特点

这道题展示了栈+哈希表的典型应用场景：
- 栈用于处理括号匹配问题
- 哈希表用于快速查找和标记需要处理的元素
- 两者结合可以高效地识别和处理无效括号
