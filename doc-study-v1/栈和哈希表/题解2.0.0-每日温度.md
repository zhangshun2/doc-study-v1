# 题解：LeetCode 739 - 每日温度

## 1. 问题分析

这道题目要求我们找出每一天需要等待多少天才能遇到更高的温度。本质上，这是一个**寻找下一个更大元素**的问题，非常适合使用**单调栈**来解决。

### 问题特点：
- 需要找出数组中每个元素右侧第一个比它大的元素的位置
- 关注的是元素之间的相对位置（天数差）
- 如果没有更大元素，结果为0

## 2. 单调栈解决方案

### 2.1 核心思路

使用**单调递减栈**（从栈底到栈顶温度递减）来解决这个问题：
1. 遍历温度数组
2. 对于当前温度，如果它大于栈顶温度，则找到了栈顶温度的"下一个更高温度"
3. 计算两者的下标差值，即等待天数
4. 重复比较直到栈为空或当前温度不大于栈顶温度
5. 将当前温度入栈，继续处理下一个温度

### 2.2 算法流程

1. 初始化一个空栈和一个长度为n的结果数组（初始值全为0）
2. 从左到右遍历温度数组：
   - 当栈不为空且当前温度大于栈顶温度对应的温度时：
     - 弹出栈顶元素（下标）
     - 计算当前下标与弹出下标的差值，更新结果数组
     - 继续比较栈顶
   - 将当前下标入栈
3. 返回结果数组

## 3. 代码实现

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        // 单调栈，存储下标
        Stack<Integer> stack = new Stack<>();
        
        for (int i = 0; i < n; i++) {
            // 当前温度大于栈顶温度，找到了栈顶温度的下一个更高温度
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int prevIndex = stack.pop();
                // 计算等待天数
                answer[prevIndex] = i - prevIndex;
            }
            // 将当前下标入栈
            stack.push(i);
        }
        
        return answer;
    }
}
```

## 4. 复杂度分析

- **时间复杂度**: O(n)，其中n是温度数组的长度。虽然有嵌套循环，但每个元素最多入栈和出栈一次，所以总操作次数是线性的。
- **空间复杂度**: O(n)，最坏情况下（温度递减序列），栈会存储所有元素的下标。

## 5. 优化思路

### 5.1 数组模拟栈

可以使用数组来模拟栈，避免Java中Stack类的额外开销：

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        // 用数组模拟栈，top表示栈顶位置
        int[] stack = new int[n];
        int top = -1;
        
        for (int i = 0; i < n; i++) {
            while (top >= 0 && temperatures[i] > temperatures[stack[top]]) {
                int prevIndex = stack[top--];
                answer[prevIndex] = i - prevIndex;
            }
            stack[++top] = i;
        }
        
        return answer;
    }
}
```

### 5.2 逆序遍历

也可以从右向左遍历，利用已计算的结果：

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        
        // 从右向左遍历
        for (int i = n - 2; i >= 0; i--) {
            int j = i + 1;
            while (j < n && temperatures[j] <= temperatures[i]) {
                // 如果下一天温度不高于今天，跳到下一个更高温度的那天
                if (answer[j] > 0) {
                    j += answer[j];
                } else {
                    // 如果没有更高温度，直接结束
                    j = n;
                }
            }
            // 如果找到了更高温度，计算天数差
            if (j < n) {
                answer[i] = j - i;
            }
        }
        
        return answer;
    }
}
```

## 6. 总结

### 6.1 解题关键点

1. **识别问题类型**：寻找下一个更大元素，适合使用单调栈
2. **选择正确的单调栈类型**：单调递减栈（从栈底到栈顶递减）
3. **存储下标而非值**：便于计算天数差
4. **结果初始化为0**：处理没有更高温度的情况

### 6.2 单调栈应用特点

这道题展示了单调栈的典型应用场景：
- 寻找数组中元素的下一个更大/更小元素
- 关注元素之间的相对位置关系
- O(n)时间复杂度解决看似需要O(n²)的问题

这种"寻找下一个更大元素"的模式在很多问题中都有应用，如：

掌握单调栈的核心思想，可以解决一系列相关问题。
