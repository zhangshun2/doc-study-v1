# 演示负4这种补码最后一位是1的加1之后的反码

当然可以。下面我将详细说明如何用32位表示法表示整数 `-4` 的原码、反码和补码。

### 1. 原码（Original Code）
原码是最简单的表示方法，直接将数字的二进制形式表示出来。对于正数，原码就是其二进制表示；对于负数，原码在最高位（符号位）为1，其余位为该数的二进制表示。

+ **正数4的原码**：
    - 二进制表示：`0000 0000 0000 0000 0000 0000 0000 0100`
+ **负数-4的原码**：
    - 符号位为1，其余位为4的二进制表示：`1000 0000 0000 0000 0000 0000 0000 0100`

### 2. 反码（One's Complement）
反码是将原码的符号位保持不变，其余位取反（0变1，1变0）。

+ **正数4的反码**：
    - 与原码相同：`0000 0000 0000 0000 0000 0000 0000 0100`
+ **负数-4的反码**：
    - 符号位保持为1，其余位取反：`1111 1111 1111 1111 1111 1111 1111 1011`

### 3. 补码（Two's Complement）
补码是在反码的基础上加1得到的。补码是计算机中广泛使用的表示负数的方法，因为它简化了加法和减法运算。

+ **正数4的补码**：
    - 与原码相同：`0000 0000 0000 0000 0000 0000 0000 0100`
+ **负数-4的补码**：
    - 反码：`1111 1111 1111 1111 1111 1111 1111 1011`
    - 加1：`1111 1111 1111 1111 1111 1111 1111 1011 + 0000 0000 0000 0000 0000 0000 0000 0001 = 1111 1111 1111 1111 1111 1111 1111 1100`

### 总结
| 表示方法 | 正数4 (4) | 负数-4 (-4) |
| --- | --- | --- |
| 原码 | `0000 0000 0000 0000 0000 0000 0000 0100` | `1000 0000 0000 0000 0000 0000 0000 0100` |
| 反码 | `0000 0000 0000 0000 0000 0000 0000 0100` | `1111 1111 1111 1111 1111 1111 1111 1011` |
| 补码 | `0000 0000 0000 0000 0000 0000 0000 0100` | `1111 1111 1111 1111 1111 1111 1111 1100` |


### 示例代码
下面是一个Java代码示例，演示如何查看整数 `-4` 的原码、反码和补码表示：

```java
public class BinaryRepresentation {
    public static void main(String[] args) {
        int number = -4;

        // 获取原码
        String originalCode = Integer.toBinaryString(number);
        System.out.println("Original Code: " + number + " -> Binary: " + originalCode);

        // 获取反码
        String oneComplement = Integer.toBinaryString(~number);
        System.out.println("One's Complement: " + number + " -> Binary: " + oneComplement);

        // 获取补码（Java中直接使用原码表示负数）
        String twoComplement = String.format("%32s", Integer.toBinaryString(number)).replace(' ', '0');
        System.out.println("Two's Complement: " + number + " -> 32-bit Binary: " + twoComplement);
    }
}
```
