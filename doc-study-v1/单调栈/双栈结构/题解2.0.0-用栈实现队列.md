# 题解2.0.0 - 用栈实现队列

## 解题思路

要用两个栈实现队列，关键在于理解栈和队列的特性差异：
- 栈：后进先出(LIFO)，只能在一端操作
- 队列：先进先出(FIFO)，一端进，另一端出

我们可以通过两个栈的配合，将后进先出的特性转换为先进先出。

### 核心思想

使用两个栈，分别担任不同角色：
- **输入栈(inStack)**：负责处理入队操作
- **输出栈(outStack)**：负责处理出队操作

通过在两个栈之间适时转移元素，实现队列的先进先出特性。

### 图解工作原理

#### 1. 入队操作(push)
![入队操作](https://excalidraw.com/#json=5TgCXJXYJZZXHGJnXQVJx,Wd-Yd5Hy-Yd9Ld-Yd5Hy-Yd9L)

入队时，直接将元素压入输入栈(inStack)顶部。

```
// 示意图
输入栈: [1, 2, 3] ← 新元素4
输出栈: []

push(4)后:
输入栈: [1, 2, 3, 4]
输出栈: []
```

#### 2. 出队操作(pop/peek)
![出队操作](https://excalidraw.com/#json=5TgCXJXYJZZXHGJnXQVJx,Wd-Yd5Hy-Yd9Ld-Yd5Hy-Yd9L)

出队时，我们需要获取最先入队的元素：

1. 如果输出栈为空，将输入栈的所有元素依次弹出并压入输出栈
   - 这个过程会将元素顺序反转，使最先入队的元素位于输出栈顶部
2. 从输出栈顶弹出元素（对于peek操作，只查看不弹出）

```
// 示意图
初始状态:
输入栈: [1, 2, 3, 4]
输出栈: []

转移元素:
输入栈: []
输出栈: [4, 3, 2, 1] ← 栈顶是1(最先入队的元素)

pop()操作:
输入栈: []
输出栈: [4, 3, 2] ← 弹出1
返回: 1
```

## 代码实现

下面是Java实现，附带详细注释：

```java
class MyQueue {
    private Stack<Integer> inStack;  // 输入栈：处理入队操作
    private Stack<Integer> outStack; // 输出栈：处理出队操作

    public MyQueue() {
        inStack = new Stack<>();
        outStack = new Stack<>();
    }
    
    // 入队操作：将元素添加到队列末尾
    public void push(int x) {
        // 直接压入输入栈，O(1)时间复杂度
        inStack.push(x);
    }
    
    // 出队操作：移除并返回队列开头的元素
    public int pop() {
        // 确保输出栈有元素
        ensureOutStackNotEmpty();
        // 从输出栈弹出栈顶元素，O(1)时间复杂度
        return outStack.pop();
    }
    
    // 查看队首元素：返回队列开头的元素但不移除
    public int peek() {
        // 确保输出栈有元素
        ensureOutStackNotEmpty();
        // 查看输出栈栈顶元素，O(1)时间复杂度
        return outStack.peek();
    }
    
    // 判断队列是否为空
    public boolean empty() {
        // 只有当两个栈都为空时，队列才为空
        return inStack.isEmpty() && outStack.isEmpty();
    }
    
    // 辅助方法：确保输出栈不为空
    private void ensureOutStackNotEmpty() {
        // 只有当输出栈为空时，才需要从输入栈转移元素
        if (outStack.isEmpty()) {
            // 将输入栈的所有元素依次弹出并压入输出栈
            // 这个过程会将元素顺序反转
            while (!inStack.isEmpty()) {
                outStack.push(inStack.pop());
            }
        }
    }
}
```

## 复杂度分析

### 时间复杂度

- **push操作**：O(1)，直接压入输入栈
- **pop/peek操作**：
  - 最坏情况：O(n)，当输出栈为空时，需要将n个元素从输入栈转移到输出栈
  - 平摊分析：O(1)，每个元素最多被转移一次，n个操作的总时间复杂度是O(n)，所以平均每个操作是O(1)

### 空间复杂度

- O(n)，其中n是队列中的元素数量，需要两个栈来存储所有元素

## 优化思考

这个实现已经是比较优化的版本，关键优化点在于：

1. **懒惰转移**：只在需要时（输出栈为空）才进行元素转移，避免不必要的操作
2. **批量转移**：一次性将输入栈的所有元素转移到输出栈，而不是每次出队都转移
3. **平摊复杂度**：虽然单次操作可能是O(n)，但平均下来每个元素只会被转移一次，使得平摊复杂度为O(1)

## 关键思路总结

1. **角色分工**：输入栈负责入队，输出栈负责出队
2. **顺序反转**：通过栈的LIFO特性，两次反转实现FIFO
3. **懒惰计算**：只在必要时才进行元素转移，提高效率
4. **状态维护**：通过两个栈的状态组合，表示队列的完整状态

这种实现方式巧妙地利用了两个栈的特性，将两个LIFO结构组合成一个FIFO结构，是数据结构设计中的经典案例。
