# 双栈结构原理详解
## 📚 双栈的基本概念
### 什么是双栈？
双栈（Dual Stack）是指在算法中**同时使用两个栈**来解决问题的数据结构组合。根据使用方式的不同，双栈可以分为以下几种类型：

1. **协作型双栈**：两个栈协同工作，共同完成一个任务
2. **分工型双栈**：两个栈分别处理不同类型的数据
3. **镜像型双栈**：两个栈在同一数组中相向增长
4. **转换型双栈**：利用两个栈实现数据结构转换

### 双栈的核心思想
```plain
协作型双栈示意图：

栈A          栈B
┌─────┐    ┌─────┐
│  3  │    │  6  │ ← 栈顶
├─────┤    ├─────┤
│  2  │    │  5  │
├─────┤    ├─────┤
│  1  │    │  4  │
└─────┘    └─────┘

特点：两栈协同工作，数据在栈间流转
```

```plain
镜像型双栈示意图：

数组：[1, 2, 3, _, _, _, 6, 5, 4]
      ↑           ↑           ↑
    栈A底       中间        栈B底
    
栈A: [1, 2, 3] → 向右增长
栈B: [4, 5, 6] → 向左增长

特点：共享存储空间，相向增长
```

## 🔧 双栈的核心类型详解
### 1. 协作型双栈 - 队列实现
**核心思想：** 使用两个栈模拟队列的FIFO特性

```java
/**
 * 用两个栈实现队列
 */
public class QueueUsingTwoStacks<T> {
    private Deque<T> inputStack;   // 输入栈
    private Deque<T> outputStack;  // 输出栈
    
    public QueueUsingTwoStacks() {
        inputStack = new ArrayDeque<>();
        outputStack = new ArrayDeque<>();
    }
    
    /**
     * 入队操作
     */
    public void enqueue(T element) {
        inputStack.push(element);
    }
    
    /**
     * 出队操作
     */
    public T dequeue() {
        // 如果输出栈为空，将输入栈的所有元素转移到输出栈
        if (outputStack.isEmpty()) {
            transferElements();
        }
        
        if (outputStack.isEmpty()) {
            throw new RuntimeException("队列为空");
        }
        
        return outputStack.pop();
    }
    
    /**
     * 查看队头元素
     */
    public T peek() {
        if (outputStack.isEmpty()) {
            transferElements();
        }
        
        if (outputStack.isEmpty()) {
            throw new RuntimeException("队列为空");
        }
        
        return outputStack.peek();
    }
    
    /**
     * 转移元素：从输入栈到输出栈
     */
    private void transferElements() {
        while (!inputStack.isEmpty()) {
            outputStack.push(inputStack.pop());
        }
    }
    
    /**
     * 检查队列是否为空
     */
    public boolean isEmpty() {
        return inputStack.isEmpty() && outputStack.isEmpty();
    }
    
    /**
     * 获取队列大小
     */
    public int size() {
        return inputStack.size() + outputStack.size();
    }
}
```

```plain
输出栈：[]

输入栈：[3, 2, 1]

转移过程：

3 → 输出栈：[3, 2, 1]，输入栈：[]

```

### 2. 镜像型双栈 - 共享空间
**核心思想：** 两个栈在同一数组中相向增长，最大化空间利用率

```java
/**
 * 镜像型双栈实现
 */
public class MirrorDualStack<T> {
    private Object[] array;
    private int capacity;
    private int top1;  // 栈1的栈顶指针
    private int top2;  // 栈2的栈顶指针
    
    public MirrorDualStack(int capacity) {
        this.capacity = capacity;
        this.array = new Object[capacity];
        this.top1 = -1;              // 栈1从左边开始
        this.top2 = capacity;        // 栈2从右边开始
    }
    
    /**
     * 栈1入栈
     */
    public void push1(T element) {
        if (isFull()) {
            throw new RuntimeException("栈已满");
        }
        array[++top1] = element;
    }
    
    /**
     * 栈2入栈
     */
    public void push2(T element) {
        if (isFull()) {
            throw new RuntimeException("栈已满");
        }
        array[--top2] = element;
    }
    
    /**
     * 栈1出栈
     */
    @SuppressWarnings("unchecked")
    public T pop1() {
        if (isEmpty1()) {
            throw new RuntimeException("栈1为空");
        }
        T element = (T) array[top1];
        array[top1--] = null;
        return element;
    }
    
    /**
     * 栈2出栈
     */
    @SuppressWarnings("unchecked")
    public T pop2() {
        if (isEmpty2()) {
            throw new RuntimeException("栈2为空");
        }
        T element = (T) array[top2];
        array[top2++] = null;
        return element;
    }
    
    /**
     * 检查是否已满
     */
    public boolean isFull() {
        return top1 + 1 == top2;
    }
    
    /**
     * 检查栈1是否为空
     */
    public boolean isEmpty1() {
        return top1 == -1;
    }
    
    /**
     * 检查栈2是否为空
     */
    public boolean isEmpty2() {
        return top2 == capacity;
    }
    
    /**
     * 获取栈1大小
     */
    public int size1() {
        return top1 + 1;
    }
    
    /**
     * 获取栈2大小
     */
    public int size2() {
        return capacity - top2;
    }
    
    /**
     * 显示当前状态
     */
    public void showState() {
        System.out.println("数组状态: " + Arrays.toString(array));
        System.out.println("top1: " + top1 + ", top2: " + top2);
        System.out.println("栈1大小: " + size1() + ", 栈2大小: " + size2());
        System.out.println("剩余空间: " + (top2 - top1 - 1));
    }
}
```

```plain
      0  1  2  3  4  5  6  7
top1: -1, top2: 8

操作1：push1(A)
数组：[A, _, _, _, _, _, _, _]
      0  1  2  3  4  5  6  7
top1: 0, top2: 8

数组：[A, _, _, _, _, _, _, X]
      0  1  2  3  4  5  6  7

      0  1  2  3  4  5  6  7
top1: 1, top2: 7
```

### 3. 分工型双栈 - 表达式求值
**核心思想：** 一个栈存储操作数，另一个栈存储操作符

```java
/**
 * 表达式求值的双栈实现
 */
public class ExpressionEvaluator {
    private Deque<Integer> operandStack;   // 操作数栈
    private Deque<Character> operatorStack; // 操作符栈
    
    public ExpressionEvaluator() {
        operandStack = new ArrayDeque<>();
        operatorStack = new ArrayDeque<>();
    }
    
    /**
     * 计算表达式
     */
    public int evaluate(String expression) {
        for (int i = 0; i < expression.length(); i++) {
            char ch = expression.charAt(i);
            
            if (ch == ' ') continue;  // 跳过空格
            
            // 处理数字
            if (Character.isDigit(ch)) {
                int num = 0;
                while (i < expression.length() && 
                       Character.isDigit(expression.charAt(i))) {
                    num = num * 10 + (expression.charAt(i) - '0');
                    i++;
                }
                i--; // 回退一位
                operandStack.push(num);
            }
            // 处理左括号
            else if (ch == '(') {
                operatorStack.push(ch);
            }
            // 处理右括号
            else if (ch == ')') {
                while (!operatorStack.isEmpty() && 
                       operatorStack.peek() != '(') {
                    processOperation();
                }
                operatorStack.pop(); // 弹出左括号
            }
            // 处理操作符
            else if (isOperator(ch)) {
                while (!operatorStack.isEmpty() && 
                       precedence(operatorStack.peek()) >= precedence(ch)) {
                    processOperation();
                }
                operatorStack.push(ch);
            }
        }
        
        // 处理剩余操作符
        while (!operatorStack.isEmpty()) {
            processOperation();
        }
        
        return operandStack.pop();
    }
    
    /**
     * 执行一次运算
     */
    private void processOperation() {
        if (operandStack.size() < 2 || operatorStack.isEmpty()) {
            throw new RuntimeException("表达式错误");
        }
        
        int b = operandStack.pop();
        int a = operandStack.pop();
        char op = operatorStack.pop();
        
        int result = calculate(a, b, op);
        operandStack.push(result);
    }
    
    /**
     * 计算两个数的运算结果
     */
    private int calculate(int a, int b, char op) {
        switch (op) {
            case '+': return a + b;
            case '-': return a - b;
            case '*': return a * b;
            case '/': return a / b;
            default: throw new RuntimeException("未知操作符: " + op);
        }
    }
    
    /**
     * 判断是否为操作符
     */
    private boolean isOperator(char ch) {
        return ch == '+' || ch == '-' || ch == '*' || ch == '/';
    }
    
    /**
     * 获取操作符优先级
     */
    private int precedence(char op) {
        switch (op) {
            case '+':
            case '-':
                return 1;
            case '*':
            case '/':
                return 2;
            default:
                return 0;
        }
    }
}
```

**计算过程图解：**

```plain
表达式："3 + 5 * 2 - 1"

步骤1：读取3
操作数栈：[3]
操作符栈：[]

步骤2：读取+
操作数栈：[3]
操作符栈：[+]

步骤3：读取5
操作数栈：[5, 3]
操作符栈：[+]

步骤4：读取*
比较优先级：*(2) > +(1)，直接入栈
操作数栈：[5, 3]
操作符栈：[*, +]

步骤5：读取2
操作数栈：[2, 5, 3]
操作符栈：[*, +]

步骤6：读取-
比较优先级：-(1) < *(2)，先计算*
计算：5 * 2 = 10
操作数栈：[10, 3]
操作符栈：[+]

比较优先级：-(1) = +(1)，计算+
计算：3 + 10 = 13
操作数栈：[13]
操作符栈：[-]

步骤7：读取1
操作数栈：[1, 13]
操作符栈：[-]

步骤8：表达式结束，计算剩余操作
计算：13 - 1 = 12
操作数栈：[12]
操作符栈：[]

最终结果：12
```

## 🎯 双栈的典型应用场景
### 1. 浏览器前进后退功能
```java
/**
 * 浏览器历史记录管理
 */
public class BrowserHistory {
    private Deque<String> backStack;     // 后退栈
    private Deque<String> forwardStack;  // 前进栈
    private String currentPage;
    
    public BrowserHistory(String homepage) {
        backStack = new ArrayDeque<>();
        forwardStack = new ArrayDeque<>();
        currentPage = homepage;
    }
    
    /**
     * 访问新页面
     */
    public void visit(String url) {
        if (currentPage != null) {
            backStack.push(currentPage);
        }
        currentPage = url;
        forwardStack.clear(); // 清空前进历史
    }
    
    /**
     * 后退
     */
    public String back(int steps) {
        for (int i = 0; i < steps && !backStack.isEmpty(); i++) {
            forwardStack.push(currentPage);
            currentPage = backStack.pop();
        }
        return currentPage;
    }
    
    /**
     * 前进
     */
    public String forward(int steps) {
        for (int i = 0; i < steps && !forwardStack.isEmpty(); i++) {
            backStack.push(currentPage);
            currentPage = forwardStack.pop();
        }
        return currentPage;
    }
}
```

### 2. 撤销重做功能
```java
/**
 * 文本编辑器的撤销重做功能
 */
public class TextEditor {
    private StringBuilder content;
    private Deque<String> undoStack;   // 撤销栈
    private Deque<String> redoStack;   // 重做栈
    
    public TextEditor() {
        content = new StringBuilder();
        undoStack = new ArrayDeque<>();
        redoStack = new ArrayDeque<>();
    }
    
    /**
     * 执行操作
     */
    public void execute(String operation) {
        // 保存当前状态到撤销栈
        undoStack.push(content.toString());
        
        // 执行操作
        applyOperation(operation);
        
        // 清空重做栈
        redoStack.clear();
    }
    
    /**
     * 撤销操作
     */
    public void undo() {
        if (!undoStack.isEmpty()) {
            redoStack.push(content.toString());
            content = new StringBuilder(undoStack.pop());
        }
    }
    
    /**
     * 重做操作
     */
    public void redo() {
        if (!redoStack.isEmpty()) {
            undoStack.push(content.toString());
            content = new StringBuilder(redoStack.pop());
        }
    }
    
    private void applyOperation(String operation) {
        // 简化的操作应用逻辑
        content.append(operation);
    }
}
```

### 3. 最小栈实现
```java
/**
 * 支持获取最小值的栈
 */
public class MinStack {
    private Deque<Integer> dataStack;  // 数据栈
    private Deque<Integer> minStack;   // 最小值栈
    
    public MinStack() {
        dataStack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }
    
    /**
     * 入栈
     */
    public void push(int val) {
        dataStack.push(val);
        
        // 维护最小值栈
        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
    }
    
    /**
     * 出栈
     */
    public void pop() {
        if (dataStack.isEmpty()) return;
        
        int val = dataStack.pop();
        
        // 如果弹出的是最小值，同时弹出最小值栈
        if (!minStack.isEmpty() && val == minStack.peek()) {
            minStack.pop();
        }
    }
    
    /**
     * 获取栈顶元素
     */
    public int top() {
        return dataStack.peek();
    }
    
    /**
     * 获取最小值
     */
    public int getMin() {
        return minStack.peek();
    }
}
```

## 🚀 双栈的优势与复杂度
### 时间复杂度分析
+ **基本操作**：O(1) - 单次入栈出栈
+ **批量转移**：O(n) - 栈间数据转移
+ **摊还分析**：多数情况下仍为O(1)

### 空间复杂度分析
+ **协作型**：O(n) - 两倍空间开销
+ **镜像型**：O(n) - 空间利用率最高
+ **分工型**：O(n) - 根据数据分布而定

### 优势特点
1. **功能增强**：单栈无法实现的功能
2. **逻辑清晰**：职责分离，代码可读性好
3. **灵活性高**：可根据需求调整栈的作用
4. **扩展性强**：易于添加新功能

### 注意事项
1. **空间开销**：通常需要额外空间
2. **同步复杂**：需要维护栈间状态一致性
3. **边界处理**：多个栈的边界情况更复杂
4. **性能权衡**：在功能和性能间找平衡
