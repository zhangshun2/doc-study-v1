# 单调栈基本模板

## 什么是单调栈

单调栈是一种特殊的栈，在这个栈中的元素都保持一定的单调性（递增或递减）。单调栈主要用于解决"下一个更大/更小元素"或"前一个更大/更小元素"等问题，通常能将暴力O(n²)的解法优化到O(n)。

## 单调栈的两种类型

1. **单调递增栈**：从栈底到栈顶元素严格递增
2. **单调递减栈**：从栈底到栈顶元素严格递减

## 基本模板

### 单调递增栈模板（Java）

```java
// 单调递增栈：找下一个更小元素
public int[] nextSmallerElement(int[] arr) {
    int n = arr.length;
    int[] result = new int[n]; // 存储每个元素的下一个更小元素
    Arrays.fill(result, -1);   // 默认值为-1，表示没有下一个更小元素
    
    Stack<Integer> stack = new Stack<>(); // 存储元素索引
    
    for (int i = 0; i < n; i++) {
        // 当栈不为空，且当前元素小于栈顶元素时
        // 说明找到了栈顶元素的下一个更小元素
        while (!stack.isEmpty() && arr[i] < arr[stack.peek()]) {
            int idx = stack.pop();
            result[idx] = arr[i]; // 记录下一个更小元素
        }
        
        // 当前索引入栈
        stack.push(i);
    }
    
    return result;
}
```

## 变体：找前一个更大/更小元素

如果要找前一个更大/更小元素，只需要从右向左遍历数组即可。

### 前一个更大元素模板（Java）

```java
// 单调递减栈：找前一个更大元素
public int[] prevGreaterElement(int[] arr) {
    int n = arr.length;
    int[] result = new int[n]; // 存储每个元素的前一个更大元素
    Arrays.fill(result, -1);   // 默认值为-1，表示没有前一个更大元素
    
    Stack<Integer> stack = new Stack<>(); // 存储元素索引
    
    // 从右向左遍历
    for (int i = n - 1; i >= 0; i--) {
        // 当栈不为空，且当前元素大于栈顶元素时
        // 说明找到了栈顶元素的前一个更大元素
        while (!stack.isEmpty() && arr[i] > arr[stack.peek()]) {
            int idx = stack.pop();
            result[idx] = arr[i]; // 记录前一个更大元素
        }
        
        // 当前索引入栈
        stack.push(i);
    }
    
    return result;
}
```

## 环形数组的处理

对于环形数组，我们可以通过"数组拼接"的技巧来处理，即将数组遍历两次。

```java
// 环形数组中的下一个更大元素
public int[] nextGreaterElementCircular(int[] arr) {
    int n = arr.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    
    Stack<Integer> stack = new Stack<>();
    
    // 遍历两次数组
    for (int i = 0; i < n * 2; i++) {
        int idx = i % n; // 实际索引
        
        while (!stack.isEmpty() && arr[idx] > arr[stack.peek()]) {
            int prevIdx = stack.pop();
            result[prevIdx] = arr[idx];
        }
        
        // 只在第一次遍历时将索引入栈
        if (i < n) {
            stack.push(idx);
        }
    }
    
    return result;
}
```

## 单调栈的应用场景

1. **下一个更大/更小元素**：如LeetCode 496、503、739等
2. **前一个更大/更小元素**：如LeetCode 84中的柱状图问题
3. **接雨水问题**：LeetCode 42
4. **柱状图中最大的矩形**：LeetCode 84
5. **最大矩形**：LeetCode 85

## 单调栈的选择原则

1. **单调递增栈**：
   - 当需要找下一个更小元素时
   - 当需要找前一个更小元素时

2. **单调递减栈**：
   - 当需要找下一个更大元素时
   - 当需要找前一个更大元素时

## 单调栈的核心思想

单调栈的核心思想是**维护一个单调的序列**，当遇到破坏单调性的元素时，进行出栈操作，同时在出栈过程中处理我们关心的问题（如记录下一个更大/更小元素）。

## 单调栈的实现技巧

1. **存储索引而非值**：通常在栈中存储元素的索引而非元素值，这样可以方便地获取元素的位置信息
2. **预处理结果数组**：通常使用一个数组来存储结果，并初始化为默认值（如-1）
3. **循环条件**：出栈的循环条件通常是"栈不为空且当前元素破坏了栈的单调性"
4. **入栈时机**：在处理完所有需要出栈的元素后，将当前元素入栈

## 单调栈解题步骤

1. **确定需要的单调栈类型**：根据问题确定使用单调递增栈还是单调递减栈
2. **初始化栈和结果数组**：创建一个空栈和存储结果的数组
3. **遍历数组**：从左到右（或从右到左）遍历数组
4. **维护单调性**：当遇到破坏单调性的元素时，进行出栈操作，同时处理问题
5. **元素入栈**：将当前元素入栈
6. **处理剩余元素**：遍历结束后，处理栈中剩余的元素（如果需要）

## 常见错误和注意事项

1. **栈为空的检查**：在访问栈顶元素前，一定要检查栈是否为空
2. **索引与值的混淆**：明确栈中存储的是索引还是值，避免混淆
3. **边界条件**：注意处理数组为空、只有一个元素等边界情况
4. **循环条件**：确保出栈循环的条件正确，避免漏掉元素或过度出栈
5. **结果初始化**：根据问题要求，正确初始化结果数组的默认值

## 总结

单调栈是一种强大的数据结构，能够在O(n)时间内解决许多看似需要O(n²)的问题。掌握单调栈的基本模板和应用场景，能够帮助我们更高效地解决"下一个更大/更小元素"等类型的问题。
