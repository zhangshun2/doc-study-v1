# 单调栈思考：值关系与应用

## 单调栈的本质

单调栈是一种特殊的栈结构，其核心特点是栈中的元素保持单调递增或单调递减的顺序。单调栈的真正价值不在于存储的元素本身，而在于**入栈和出栈过程中元素之间的比较关系**。这种数据结构能够在O(n)的时间复杂度内解决"下一个更大/更小元素"或"前一个更大/更小元素"等问题。

## 单调递增栈的工作原理

### 基本定义

单调递增栈是指栈中元素从栈底到栈顶保持递增顺序的栈。

### 入栈规则

- 如果栈为空或当前元素大于等于栈顶元素，则直接入栈
- 如果当前元素小于栈顶元素，则弹出栈顶元素，直到栈为空或当前元素大于等于新的栈顶元素，然后将当前元素入栈

### 关键值关系

当元素被弹出栈时，会产生两个重要的关系：

1. **右边界关系**：当前准备入栈的元素是被弹出元素右边第一个比它小的元素
2. **左边界关系**：弹出后的新栈顶元素（如果存在）是被弹出元素左边第一个比它小的元素

这两个关系是单调栈最核心的价值所在，它们使我们能够在一次遍历中同时找到每个元素左右两边的第一个更小元素。

## 柱状图最大矩形问题中的应用

在柱状图最大矩形问题（LeetCode 84）中，单调递增栈的应用尤为典型：

### 问题转化

对于每个柱子，我们需要找到：
- 左边第一个比它矮的柱子（左边界）
- 右边第一个比它矮的柱子（右边界）

这样就可以确定以当前柱子高度为高的最大矩形的宽度。

### 算法步骤

1. 维护一个单调递增栈，栈中存储柱子的索引
2. 遍历柱子高度数组：
   - 如果栈为空或当前柱子高度大于等于栈顶索引对应的高度，将当前索引入栈
   - 如果当前柱子高度小于栈顶索引对应的高度，弹出栈顶元素：
     - 弹出的索引对应的高度作为矩形的高
     - 右边界是当前遍历到的索引
     - 左边界是新的栈顶索引（如果栈为空，则为-1）
     - 计算面积并更新最大值
3. 在数组末尾添加一个高度为0的哨兵元素，确保所有元素都能被处理

### 宽度计算

当弹出栈顶元素计算面积时，宽度的计算公式为：
```
width = stack.isEmpty() ? i : i - stack.peek() - 1
```

这个公式包含两种情况：
- 如果栈为空：说明被弹出元素左边没有更小的元素，宽度为当前索引i
- 如果栈不为空：宽度为右边界(i)减去左边界(stack.peek())再减1

减1是因为我们计算的是两个边界之间的距离，不包括边界本身。

### 哨兵元素的作用

在数组末尾添加一个高度为0的元素（哨兵）有两个重要作用：

1. 确保所有元素都被处理：对于单调递增的数组，如果不添加哨兵，栈中的元素可能永远不会被弹出
2. 简化边界处理：避免了在遍历结束后额外处理栈中剩余元素的代码

## 单调栈的本质思考

1. **关注边界而非极值**：单调栈关注的是数据的变化点（第一个更大/更小的元素），而不是极值
2. **维护单调性的价值**：通过维护栈的单调性，我们能够在元素入栈和出栈时获取重要的关系信息
3. **O(n)时间复杂度的保证**：每个元素最多入栈和出栈一次，保证了O(n)的时间复杂度
4. **比较关系的重要性**：单调栈的核心不是存储的值本身，而是入栈和出栈过程中元素之间的比较关系
