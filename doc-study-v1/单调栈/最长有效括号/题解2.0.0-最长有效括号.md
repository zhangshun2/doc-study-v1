# LeetCode 32. 最长有效括号 - 题解

## 解题思路

这道题要求找出最长的有效括号子串的长度，我们可以使用栈来解决。关键是理解"连续"和"最长"的概念。

### 栈方法详解

我们使用栈来存储括号的下标（不是括号字符本身），这样可以方便计算有效子串的长度。

**算法步骤：**

1. 初始化一个栈，并放入-1作为特殊标记（这是为了方便计算长度）
2. 遍历字符串中的每个字符：
   - 如果是左括号'('，将其下标入栈
   - 如果是右括号')'：
     - 弹出栈顶元素（匹配一个左括号）
     - 如果栈为空，说明没有匹配的左括号，将当前右括号的下标入栈作为新的参考点
     - 如果栈不为空，计算当前有效子串的长度（当前下标减去栈顶下标）
3. 返回最大长度

### 为什么要在栈底放入-1？

这是一个技巧，用于简化计算。当我们遇到第一个能够匹配的右括号时，如果栈中只有一个左括号，弹出后栈为空，此时我们需要一个参考点来计算长度。

例如，对于字符串"()"：
- 初始栈：[-1]
- 遇到'('，入栈：[-1, 0]
- 遇到')'，弹出栈顶：[-1]
- 计算长度：1 - (-1) = 2

## 代码实现

```java
class Solution {
    public int longestValidParentheses(String s) {
        // 使用栈来匹配括号，栈中存储的是字符的索引
        Deque<Integer> stack = new ArrayDeque<>();
        // 初始时放入-1，便于计算长度
        stack.push(-1);
        int maxLen = 0;
        
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') {
                // 左括号的索引入栈
                stack.push(i);
            } else { // c == ')'
                // 遇到右括号，先弹出栈顶
                stack.pop();
                if (stack.isEmpty()) {
                    // 如果栈为空，说明没有匹配的左括号，将当前右括号的索引入栈
                    stack.push(i);
                } else {
                    // 计算当前有效括号的长度
                    maxLen = Math.max(maxLen, i - stack.peek());
                }
            }
        }
        
        return maxLen;
    }
}
```

## 与你原始代码的区别

你的原始代码有几个问题：

1. **概念理解**：你的代码似乎是在尝试移除无效括号，而不是找最长有效子串
2. **栈的使用**：你的栈存储的是字符而不是下标，这样无法计算长度
3. **返回值**：你返回的是`array.length-stack.size()`，这不是最长有效子串的长度

## 其他解法

除了栈方法外，还有动态规划方法可以解决这个问题：

1. 定义dp[i]表示以第i个字符结尾的最长有效括号子串的长度
2. 当s[i]='('时，dp[i]=0（以左括号结尾的子串不可能是有效括号串）
3. 当s[i]=')'时：
   - 如果s[i-1]='('，则dp[i]=dp[i-2]+2
   - 如果s[i-1]=')'且s[i-dp[i-1]-1]='('，则dp[i]=dp[i-1]+2+dp[i-dp[i-1]-2]

## 总结

1. 这道题的关键是理解"连续"和"最长"的概念
2. 使用栈存储下标而不是字符本身，可以方便计算长度
3. 在栈底放入-1作为特殊标记，简化计算
4. 遇到右括号时，需要考虑栈是否为空的情况
