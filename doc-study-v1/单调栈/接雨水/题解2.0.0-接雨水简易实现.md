# 接雨水问题 - 简易实现与思路解析

## 问题描述

给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例:**
```
输入: [0,1,0,2,1,0,1,3,2,1,2,1]
输出: 6
```

## 问题理解

想象一下，当雨水落在柱子之间的空隙时，水会被两侧较高的柱子挡住而积累起来。对于每个位置，能接的雨水量取决于：

1. 这个位置左边最高的柱子高度
2. 这个位置右边最高的柱子高度
3. 这两个高度中的较小值减去当前位置的柱子高度

如果当前位置的柱子高度已经超过了左右两边最高柱子的较小值，那么这个位置就无法接水。

## 单调栈解法 - 简易思路

单调栈是解决这个问题的一种高效方法。我们使用单调递减栈（从栈底到栈顶高度递减）来找到形成"凹槽"的位置。

### 核心思想

1. 维护一个单调递减栈，栈中存储柱子的索引
2. 当遇到一个比栈顶元素高的柱子时，说明找到了一个可能的凹槽右边界
3. 弹出栈顶元素作为凹槽底部，新的栈顶元素作为凹槽左边界
4. 计算这个凹槽能接的水量 = 宽度 × 高度差

### 简易代码实现

```java
class Solution {
    public int trap(int[] height) {
        // 如果数组为空或长度小于3，无法接雨水
        if (height == null || height.length < 3) {
            return 0;
        }
        
        int totalWater = 0;  // 总雨水量
        Stack<Integer> stack = new Stack<>();  // 用于存储柱子索引的栈
        
        // 遍历每个柱子
        for (int current = 0; current < height.length; current++) {
            // 当栈不为空，且当前柱子高度大于栈顶柱子高度时
            // 说明找到了一个可能的凹槽
            while (!stack.isEmpty() && height[current] > height[stack.peek()]) {
                // 弹出栈顶元素，这是凹槽的底部
                int bottom = stack.pop();
                
                // 如果栈为空，说明没有左边界，无法形成凹槽
                if (stack.isEmpty()) {
                    break;
                }
                
                // 左边界是新的栈顶，右边界是当前柱子
                int left = stack.peek();
                int right = current;
                
                // 计算凹槽的宽度和高度
                int width = right - left - 1;  // 不包括左右边界
                int height_diff = Math.min(height[left], height[right]) - height[bottom];
                
                // 计算这个凹槽能接的水量，并累加
                totalWater += width * height_diff;
            }
            
            // 将当前柱子入栈
            stack.push(current);
        }
        
        return totalWater;
    }
}
```

## 代码详解

1. **初始检查**：确保数组至少有3个元素，否则无法形成凹槽接水。

2. **单调栈**：使用栈来存储柱子的索引，栈中元素对应的柱子高度是从栈底到栈顶递减的。

3. **遍历过程**：
   - 对于每个柱子，我们检查它是否比栈顶元素高
   - 如果是，说明找到了一个可能的凹槽右边界
   - 弹出栈顶元素作为凹槽底部
   - 如果栈为空，说明没有左边界，无法形成凹槽
   - 否则，计算这个凹槽能接的水量

4. **计算水量**：
   - 宽度 = 右边界索引 - 左边界索引 - 1
     - 减1是因为我们只计算两个边界之间的空间，不包括边界柱子本身
   - 高度差 = min(左边界高度, 右边界高度) - 凹槽底部高度
     - 取较小值是因为水的高度受限于较矮的那个边界（木桶效应）
     - 减去凹槽底部高度是因为那部分是柱子而不是水
   - 水量 = 宽度 × 高度差

5. **入栈**：将当前柱子入栈，作为可能的凹槽左边界或底部。

## 示例演示

以 `[4,2,0,3,2,5]` 为例：

1. 遍历索引0（值为4）：栈为空，直接入栈 → 栈：[0]
2. 遍历索引1（值为2）：2 < 4，直接入栈 → 栈：[0,1]
3. 遍历索引2（值为0）：0 < 2，直接入栈 → 栈：[0,1,2]
4. 遍历索引3（值为3）：
   - 3 > 0，弹出索引2
   - 新栈顶是索引1（值为2）
   - 计算水量：宽度 = 3-1-1 = 1，高度差 = min(2,3)-0 = 2，水量 = 1×2 = 2
   - 3 > 2，继续弹出索引1
   - 新栈顶是索引0（值为4）
   - 计算水量：宽度 = 3-0-1 = 2，高度差 = min(4,3)-2 = 1，水量 = 2×1 = 2
   - 3 < 4，停止弹出
   - 入栈索引3 → 栈：[0,3]
5. 遍历索引4（值为2）：2 < 3，直接入栈 → 栈：[0,3,4]
6. 遍历索引5（值为5）：
   - 5 > 2，弹出索引4
   - 计算水量：宽度 = 5-3-1 = 1，高度差 = min(3,5)-2 = 1，水量 = 1×1 = 1
   - 5 > 3，继续弹出索引3
   - 计算水量：宽度 = 5-0-1 = 4，高度差 = min(4,5)-3 = 1，水量 = 4×1 = 4
   - 5 > 4，继续弹出索引0
   - 栈为空，无法形成凹槽
   - 入栈索引5 → 栈：[5]

总雨水量 = 2 + 2 + 1 + 4 = 9

## 时间和空间复杂度

- **时间复杂度**：O(n)，其中 n 是数组的长度。每个元素最多被入栈和出栈一次。
- **空间复杂度**：O(n)，栈的大小最多为 n。

## 总结

单调栈解法通过维护一个单调递减栈，巧妙地找到了形成凹槽的位置，并计算每个凹槽能接的水量。这种方法的核心在于：

1. 当遇到一个比栈顶元素高的柱子时，说明找到了一个可能的凹槽右边界
2. 弹出栈顶元素作为凹槽底部，新的栈顶元素作为凹槽左边界
3. 计算这个凹槽能接的水量，并累加到总水量中

这种解法直观且高效，是解决接雨水问题的优秀方法之一。
