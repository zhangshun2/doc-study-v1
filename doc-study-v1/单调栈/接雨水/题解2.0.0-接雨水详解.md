# LeetCode 42: 接雨水问题详解

## 问题描述

给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1:**
```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。
```

**示例 2:**
```
输入：height = [4,2,0,3,2,5]
输出：9
```

## 问题分析

### 问题特征

1. 我们需要计算每个位置能够接多少雨水，然后求和
2. 一个位置能接的雨水量取决于它左右两侧的最高柱子的较小值减去当前位置的高度
3. 如果当前位置比它左右两侧的最高柱子的较小值还高，则无法接雨水

### 解题思路

接雨水问题有多种解法，包括：
1. 暴力解法
2. 动态规划
3. 双指针
4. 单调栈

我们将重点讨论单调栈解法，因为它与前面讨论的柱状图最大矩形问题有相似之处，都是单调栈的经典应用。

## 单调栈解法

### 核心思想

在接雨水问题中，我们使用**单调递减栈**（从栈底到栈顶高度递减）。当遇到一个高度大于栈顶元素的柱子时，就可以计算栈顶元素能接的雨水量。

### 算法步骤

1. 维护一个单调递减栈，栈中存储柱子的索引
2. 遍历高度数组：
   - 如果栈为空或当前柱子高度小于等于栈顶索引对应的高度，将当前索引入栈
   - 如果当前柱子高度大于栈顶索引对应的高度，弹出栈顶元素：
     - 如果栈为空，无法形成凹槽，不计算雨水
     - 如果栈不为空，计算能接的雨水量：
       - 宽度 = 当前索引 - 新栈顶索引 - 1
       - 高度 = min(当前柱子高度, 新栈顶对应的高度) - 弹出的柱子高度
       - 雨水量 = 宽度 * 高度
     - 继续检查栈顶元素，重复上述过程

### 代码实现

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        if (n <= 2) return 0; // 至少需要3个柱子才能接雨水
        
        Stack<Integer> stack = new Stack<>();
        int water = 0;
        
        for (int i = 0; i < n; i++) {
            // 当栈不为空且当前高度大于栈顶高度时
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                // 弹出栈顶元素
                int top = stack.pop();
                
                // 如果栈为空，无法形成凹槽
                if (stack.isEmpty()) {
                    break;
                }
                
                // 计算宽度
                int width = i - stack.peek() - 1;
                
                // 计算高度（取左右两边较小值，减去凹槽高度）
                int boundedHeight = Math.min(height[i], height[stack.peek()]) - height[top];
                
                // 累加雨水量
                water += width * boundedHeight;
            }
            
            // 当前索引入栈
            stack.push(i);
        }
        
        return water;
    }
}
```

### 代码详解

让我们逐行分析这个解法：

1. **初始检查**：
   ```java
   int n = height.length;
   if (n <= 2) return 0; // 至少需要3个柱子才能接雨水
   ```
   这里我们首先检查数组长度，因为要形成凹槽至少需要3个柱子。

2. **初始化变量**：
   ```java
   Stack<Integer> stack = new Stack<>();
   int water = 0;
   ```
   我们使用一个栈来存储索引，并初始化雨水总量为0。

3. **遍历数组**：
   ```java
   for (int i = 0; i < n; i++) {
   ```
   我们遍历每个柱子。

4. **处理凹槽**：
   ```java
   while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
   ```
   当栈不为空且当前柱子高度大于栈顶柱子高度时，说明找到了一个可能形成凹槽的右边界。

5. **弹出栈顶元素**：
   ```java
   int top = stack.pop();
   ```
   弹出栈顶元素，这个元素是凹槽的底部。

6. **检查是否有左边界**：
   ```java
   if (stack.isEmpty()) {
       break;
   }
   ```
   如果弹出后栈为空，说明没有左边界，无法形成凹槽。

7. **计算宽度**：
   ```java
   int width = i - stack.peek() - 1;
   ```
   宽度等于右边界索引减去左边界索引再减1。

8. **计算高度**：
   ```java
   int boundedHeight = Math.min(height[i], height[stack.peek()]) - height[top];
   ```
   高度等于左右边界高度的较小值减去凹槽底部的高度。

9. **累加雨水量**：
   ```java
   water += width * boundedHeight;
   ```
   雨水量等于宽度乘以高度。

10. **入栈**：
    ```java
    stack.push(i);
    ```
    将当前索引入栈，维护单调递减栈。

## 示例演示

让我们以示例 `[4,2,0,3,2,5]` 为例，演示算法的执行过程：

1. 初始状态：栈为空，water = 0
2. 遍历到索引0（值为4）：栈为空，直接入栈。栈：[0]
3. 遍历到索引1（值为2）：2 < 4，直接入栈。栈：[0,1]
4. 遍历到索引2（值为0）：0 < 2，直接入栈。栈：[0,1,2]
5. 遍历到索引3（值为3）：
   - 3 > 0，弹出索引2（值为0）
   - 新栈顶是索引1（值为2）
   - 计算雨水：宽度 = 3 - 1 - 1 = 1，高度 = min(3,2) - 0 = 2，雨水量 = 1 * 2 = 2
   - 3 > 2，继续弹出索引1（值为2）
   - 新栈顶是索引0（值为4）
   - 计算雨水：宽度 = 3 - 0 - 1 = 2，高度 = min(3,4) - 2 = 1，雨水量 = 2 * 1 = 2
   - 3 < 4，停止弹出
   - 入栈索引3。栈：[0,3]
6. 遍历到索引4（值为2）：2 < 3，直接入栈。栈：[0,3,4]
7. 遍历到索引5（值为5）：
   - 5 > 2，弹出索引4（值为2）
   - 新栈顶是索引3（值为3）
   - 计算雨水：宽度 = 5 - 3 - 1 = 1，高度 = min(5,3) - 2 = 1，雨水量 = 1 * 1 = 1
   - 5 > 3，继续弹出索引3（值为3）
   - 新栈顶是索引0（值为4）
   - 计算雨水：宽度 = 5 - 0 - 1 = 4，高度 = min(5,4) - 3 = 1，雨水量 = 4 * 1 = 4
   - 5 > 4，继续弹出索引0（值为4）
   - 栈为空，停止计算
   - 入栈索引5。栈：[5]

总雨水量 = 2 + 2 + 1 + 4 = 9，与预期输出一致。

## 与柱状图最大矩形问题的对比

接雨水问题和柱状图最大矩形问题都是单调栈的经典应用，但有一些关键区别：

### 相似之处

1. 都使用单调栈来找到左右边界
2. 都是O(n)的时间复杂度
3. 都需要计算某种形式的"面积"

### 不同之处

1. **单调栈类型**：
   - 柱状图最大矩形问题使用单调递增栈（从栈底到栈顶高度递增）
   - 接雨水问题使用单调递减栈（从栈底到栈顶高度递减）

2. **计算逻辑**：
   - 柱状图最大矩形问题计算的是以某个高度为高的最大矩形面积
   - 接雨水问题计算的是凹槽能接的雨水量

3. **哨兵元素**：
   - 柱状图最大矩形问题通常在数组末尾添加一个高度为0的哨兵元素，确保所有元素都被弹出
   - 接雨水问题不需要添加哨兵元素，因为我们只关心凹槽

## 时间复杂度分析

- 时间复杂度：O(n)，其中n是数组的长度。每个元素最多入栈和出栈一次。
- 空间复杂度：O(n)，栈的大小最多为n。

## 总结

接雨水问题是单调栈的经典应用之一。通过维护一个单调递减栈，我们可以在O(n)的时间内找到所有可能形成凹槽的位置，并计算出总的雨水量。

关键点是理解：
1. 单调递减栈的作用是找到可能形成凹槽的左右边界
2. 当遇到一个比栈顶元素高的柱子时，我们可以确定栈顶元素能接的雨水量
3. 雨水量的计算公式是：宽度 * 高度，其中高度是左右边界高度的较小值减去凹槽底部的高度

这种方法不仅高效，而且思路清晰，是解决此类问题的优秀策略。
