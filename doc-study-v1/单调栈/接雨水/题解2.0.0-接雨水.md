# LeetCode 42: 接雨水问题题解

## 问题描述

给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1:**
```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。
```

**示例 2:**
```
输入：height = [4,2,0,3,2,5]
输出：9
```

## 问题分析

### 问题特征

1. 我们需要计算每个位置能够接多少雨水，然后求和
2. 一个位置能接的雨水量取决于它左右两侧的最高柱子的较小值减去当前位置的高度
3. 如果当前位置比它左右两侧的最高柱子的较小值还高，则无法接雨水

### 解题思路

接雨水问题有多种解法，包括：
1. 暴力解法
2. 动态规划
3. 双指针
4. 单调栈

我们将重点讨论单调栈解法，因为它与前面讨论的柱状图最大矩形问题有相似之处，都是单调栈的经典应用。

## 单调栈解法

### 核心思想

在接雨水问题中，我们使用**单调递减栈**（从栈底到栈顶高度递减）。当遇到一个高度大于栈顶元素的柱子时，就可以计算栈顶元素能接的雨水量。

### 算法步骤

1. 维护一个单调递减栈，栈中存储柱子的索引
2. 遍历高度数组：
   - 如果栈为空或当前柱子高度小于等于栈顶索引对应的高度，将当前索引入栈
   - 如果当前柱子高度大于栈顶索引对应的高度，弹出栈顶元素：
     - 如果栈为空，无法形成凹槽，不计算雨水
     - 如果栈不为空，计算能接的雨水量：
       - 宽度 = 当前索引 - 新栈顶索引 - 1
       - 高度 = min(当前柱子高度, 新栈顶对应的高度) - 弹出的柱子高度
       - 雨水量 = 宽度 * 高度
     - 继续检查栈顶元素，重复上述过程

### 代码实现

```java
class Solution {
    public int trap(int[] height) {
        int n = height.length;
        if (n <= 2) return 0; // 至少需要3个柱子才能接雨水
        
        Stack<Integer> stack = new Stack<>();
        int water = 0;
        
        for (int i = 0; i < n; i++) {
            // 当栈不为空且当前高度大于栈顶高度时
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                // 弹出栈顶元素
                int top = stack.pop();
                
                // 如果栈为空，无法形成凹槽
                if (stack.isEmpty()) {
                    break;
                }
                
                // 计算宽度
                int width = i - stack.peek() - 1;
                
                // 计算高度（取左右两边较小值，减去凹槽高度）
                int boundedHeight = Math.min(height[i], height[stack.peek()]) - height[top];
                
                // 累加雨水量
                water += width * boundedHeight;
            }
            
            // 当前索引入栈
            stack.push(i);
        }
        
        return water;
    }
}
```

## 与柱状图最大矩形问题的对比

接雨水问题和柱状图最大矩形问题都是单调栈的经典应用，但有一些关键区别：

### 相似之处

1. 都需要找到左右两边的边界
2. 都可以用O(n)时间复杂度解决
3. 都需要计算面积（矩形面积或水量）

### 不同之处

1. **单调栈类型**：
   - 柱状图问题：使用单调递增栈（寻找左右两边第一个比当前柱子矮的柱子）
   - 接雨水问题：使用单调递减栈（寻找左右两边第一个比当前柱子高的柱子）

2. **计算逻辑**：
   - 柱状图问题：计算以当前柱子高度为高的最大矩形面积
   - 接雨水问题：计算当前凹槽能接的雨水量

3. **哨兵元素**：
   - 柱状图问题：通常在数组末尾添加0作为哨兵
   - 接雨水问题：通常不需要特殊的哨兵元素

## 单调栈在接雨水问题中的工作原理

让我们通过一个例子来说明单调栈在接雨水问题中的工作原理：

以 `height = [0,1,0,2,1,0,1,3,2,1,2,1]` 为例：

1. i=0, height[0]=0：栈为空，直接入栈，栈=[0]
2. i=1, height[1]=1：1>0，弹出栈顶0
   - 栈为空，无法形成凹槽，不计算雨水
   - 1入栈，栈=[1]
3. i=2, height[2]=0：0<1，直接入栈，栈=[1,2]
4. i=3, height[3]=2：2>0，弹出栈顶2
   - 栈不为空，可以计算雨水
   - 宽度 = 3 - 1 - 1 = 1
   - 高度 = min(2, 1) - 0 = 1
   - 雨水量 += 1 * 1 = 1
   - 2>1，继续弹出栈顶1
   - 栈为空，无法形成凹槽
   - 3入栈，栈=[3]
5. i=4, height[4]=1：1<2，直接入栈，栈=[3,4]
6. i=5, height[5]=0：0<1，直接入栈，栈=[3,4,5]
7. i=6, height[6]=1：1>0，弹出栈顶5
   - 栈不为空，可以计算雨水
   - 宽度 = 6 - 4 - 1 = 1
   - 高度 = min(1, 1) - 0 = 1
   - 雨水量 += 1 * 1 = 2
   - 1=1，不继续弹出
   - 6入栈，栈=[3,4,6]
8. i=7, height[7]=3：3>1，弹出栈顶6
   - 栈不为空，可以计算雨水
   - 宽度 = 7 - 4 - 1 = 2
   - 高度 = min(3, 1) - 1 = 0
   - 雨水量 += 2 * 0 = 2
   - 3>1，继续弹出栈顶4
   - 栈不为空，可以计算雨水
   - 宽度 = 7 - 3 - 1 = 3
   - 高度 = min(3, 2) - 1 = 1
   - 雨水量 += 3 * 1 = 5
   - 3>2，继续弹出栈顶3
   - 栈为空，无法形成凹槽
   - 7入栈，栈=[7]

... 继续处理剩余元素 ...

最终计算得到的雨水总量为6。

## 单调栈的本质理解

在接雨水问题中，单调栈的本质是找到每个位置左右两边第一个比它高的柱子，这两个柱子形成了一个"凹槽"，可以接雨水。

当我们遇到一个高度大于栈顶元素的柱子时，说明找到了栈顶元素右边第一个比它高的柱子。而栈顶元素下面的元素（如果存在）是栈顶元素左边第一个比它高的柱子。这样，我们就找到了一个凹槽，可以计算这个凹槽能接多少雨水。

## 时间复杂度分析

- 时间复杂度：O(n)，每个元素最多入栈和出栈一次
- 空间复杂度：O(n)，栈的大小最多为n

## 总结

接雨水问题是单调栈的另一个经典应用。与柱状图最大矩形问题相比，它使用的是单调递减栈而非单调递增栈，但核心思想类似：通过维护栈的单调性，在元素入栈和出栈时获取重要的关系信息。

理解了这两个问题，基本上就掌握了单调栈的核心应用场景。单调栈的强大之处在于它能够在O(n)的时间复杂度内解决需要找"下一个更大/更小元素"或"前一个更大/更小元素"的问题。
