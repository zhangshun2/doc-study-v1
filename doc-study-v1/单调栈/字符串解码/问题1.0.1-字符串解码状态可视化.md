# 字符串解码问题 - 状态可视化分析

## 🎯 问题描述

给定一个经过编码的字符串，返回它解码后的字符串。编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 k 次。

**核心特点**: 嵌套结构 + 延迟处理 + 状态保存恢复

## 🔄 状态机模型

### 四种核心状态
```
状态1: READING_NUMBER    (读取数字)
状态2: READING_CHAR      (读取普通字符) 
状态3: ENTERING_BRACKET  (进入括号，保存状态)
状态4: EXITING_BRACKET   (退出括号，恢复状态)
```

### 状态转换图
```
     数字        字符
  ┌─────────┐ ┌─────────┐
  │         │ │         │
  ▼         │ ▼         │
READING_NUMBER ──────► READING_CHAR
  │                      │
  │ '['                  │ '['
  ▼                      ▼
ENTERING_BRACKET ◄──────┘
  │
  │ 处理完成
  ▼
EXITING_BRACKET
  │
  │ ']'
  ▼
回到上一层状态
```

## 🔍 关键步骤详细分析

### 步骤7: 第一个 ']' 的处理
```
触发条件: 遇到 ']'
当前状态: numStack=[3,2], strStack=["","a"], currentStr="c"

处理过程:
1. repeatTimes = numStack.pop() = 2
2. prevStr = strStack.pop() = "a"  
3. currentStr = "a" + "c".repeat(2) = "a" + "cc" = "acc"

结果状态: numStack=[3], strStack=[""], currentStr="acc"
```

### 步骤8: 第二个 ']' 的处理
```
触发条件: 遇到 ']'
当前状态: numStack=[3], strStack=[""], currentStr="acc"

处理过程:
1. repeatTimes = numStack.pop() = 3
2. prevStr = strStack.pop() = ""
3. currentStr = "" + "acc".repeat(3) = "accaccacc"

结果状态: numStack=[], strStack=[], currentStr="accaccacc"
```

## 💡 核心洞察

### 栈的本质作用
1. **状态保存**: 每遇到 `[` 就保存当前的 `(num, currentStr)` 状态
2. **状态隔离**: 每一层的处理都是独立的，不会相互干扰
3. **延迟处理**: 只有遇到 `]` 才触发计算和状态恢复
4. **自动回溯**: 利用LIFO特性自动回到上一层状态

### 为什么需要双栈
- **numStack**: 保存每一层的重复次数
- **strStack**: 保存每一层进入前的字符串状态
- **分离关注点**: 数字和字符串的生命周期不同，需要独立管理

### 状态机的优势
- **清晰的状态转换**: 每个字符都有明确的处理逻辑
- **自然的嵌套处理**: 栈天然适合处理嵌套结构
- **错误处理**: 状态机模式便于添加错误检查和边界处理

## 🚀 实现要点

```java
public String decodeString(String s) {
    Stack<Integer> numStack = new Stack<>();
    Stack<String> strStack = new Stack<>();
    int num = 0;
    String currentStr = "";
    
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');  // 🔵 数字累积
        } else if (c == '[') {
            numStack.push(num);          // 🟡 状态保存
            strStack.push(currentStr);
            num = 0;                     // 重置状态
            currentStr = "";
        } else if (c == ']') {
            int repeatTimes = numStack.pop();     // 🔴 状态恢复
            String prevStr = strStack.pop();
            currentStr = prevStr + currentStr.repeat(repeatTimes);
        } else {
            currentStr += c;             // 🟢 字符累积
        }
    }
    
    return currentStr;
}
```

这种可视化方法让复杂的嵌套处理变得清晰可见！
