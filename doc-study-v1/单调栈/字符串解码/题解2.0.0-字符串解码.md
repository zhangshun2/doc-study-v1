# 题解2.0.0-字符串解码

## 🎯 **解题核心思路**

字符串解码问题的本质是**嵌套结构的状态管理**，需要用栈来保存和恢复不同层级的状态。

### **关键洞察**
1. **双栈设计**: 分别管理数字和字符串
2. **状态保存**: 遇到 `[` 时保存当前状态到栈中
3. **状态恢复**: 遇到 `]` 时从栈中恢复状态并计算结果
4. **逐字符处理**: 根据字符类型执行不同操作

## 🚀 **完整实现**

```java
class Solution {
    public String decodeString(String s) {
        Stack<Integer> numStack = new Stack<>();    // 存储重复次数
        Stack<String> strStack = new Stack<>();     // 存储字符串状态
        
        int num = 0;                                // 当前累积的数字
        String currentStr = "";                     // 当前构建的字符串
        
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 处理数字字符，支持多位数
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                // 遇到左括号，保存当前状态
                numStack.push(num);
                strStack.push(currentStr);
                // 重置状态，准备处理新的层级
                num = 0;
                currentStr = "";
            } else if (c == ']') {
                // 遇到右括号，恢复状态并计算结果
                int repeatTimes = numStack.pop();      // 获取重复次数
                String prevStr = strStack.pop();       // 获取前面的字符串
                // 计算当前层级的结果
                currentStr = prevStr + currentStr.repeat(repeatTimes);
            } else {
                // 普通字符，直接拼接到当前字符串
                currentStr += c;
            }
        }
        
        return currentStr;
    }
}
```

## 💡 **关键技术点解析**

### **1. 多位数字处理**
```java
// 支持多位数字的累积
num = num * 10 + (c - '0');

// 示例: "12[a]"
// '1': num = 0 * 10 + 1 = 1
// '2': num = 1 * 10 + 2 = 12
```

### **2. 状态保存机制**
```java
// 遇到 '[' 时的状态保存
numStack.push(num);        // 保存当前数字
strStack.push(currentStr); // 保存当前字符串
num = 0;                   // 重置数字
currentStr = "";           // 重置字符串
```

### **3. 状态恢复与计算**
```java
// 遇到 ']' 时的状态恢复
int repeatTimes = numStack.pop();    // 恢复重复次数
String prevStr = strStack.pop();     // 恢复前面的字符串
// 计算: 前面的字符串 + 当前字符串重复指定次数
currentStr = prevStr + currentStr.repeat(repeatTimes);
```

## 🎨 **算法优化与变体**

### **优化版本 - 使用StringBuilder**
```java
class Solution {
    public String decodeString(String s) {
        Stack<Integer> numStack = new Stack<>();
        Stack<StringBuilder> strStack = new Stack<>();
        
        int num = 0;
        StringBuilder currentStr = new StringBuilder();
        
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                numStack.push(num);
                strStack.push(currentStr);
                num = 0;
                currentStr = new StringBuilder();
            } else if (c == ']') {
                int repeatTimes = numStack.pop();
                StringBuilder prevStr = strStack.pop();
                String repeated = currentStr.toString().repeat(repeatTimes);
                currentStr = prevStr.append(repeated);
            } else {
                currentStr.append(c);
            }
        }
        
        return currentStr.toString();
    }
}
```

### **递归解法**
```java
class Solution {
    private int index = 0;
    
    public String decodeString(String s) {
        return decode(s);
    }
    
    private String decode(String s) {
        StringBuilder result = new StringBuilder();
        int num = 0;
        
        while (index < s.length()) {
            char c = s.charAt(index++);
            
            if (Character.isDigit(c)) {
                num = num * 10 + (c - '0');
            } else if (c == '[') {
                String decoded = decode(s);  // 递归处理内层
                for (int i = 0; i < num; i++) {
                    result.append(decoded);
                }
                num = 0;
            } else if (c == ']') {
                return result.toString();
            } else {
                result.append(c);
            }
        }
        
        return result.toString();
    }
}
```

## 📊 **复杂度分析**

### **时间复杂度: O(n)**
- 每个字符最多被访问常数次
- 字符串拼接操作的总时间与最终结果长度成正比

### **空间复杂度: O(n)**
- 栈的最大深度等于嵌套层数
- 字符串存储空间与输入长度成正比

## 🧠 **思维模式总结**

### **栈的使用场景识别**
- **嵌套结构**: 需要保存和恢复状态
- **后进先出**: 最近的状态最先处理
- **递归模拟**: 用栈模拟递归过程

### **状态管理策略**
- **及时保存**: 遇到分界符时立即保存状态
- **正确恢复**: 按照相反顺序恢复状态
- **状态分离**: 不同类型的状态用不同的栈管理

这个问题完美展示了栈在处理嵌套结构时的威力，是掌握"状态保存与恢复"模式的经典案例！
