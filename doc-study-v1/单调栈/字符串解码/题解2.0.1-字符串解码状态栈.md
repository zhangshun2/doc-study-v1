# 题解2.0.1 - 字符串解码（状态栈方法）

## 📋 **问题描述**

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。

**示例：**
- 输入：`s = "3[a2[c]]"`
- 输出：`"accaccacc"`

## 🎯 **核心思路**

这是一个典型的**状态栈问题**，具有以下特征：
- **嵌套结构**：方括号可以嵌套
- **状态依赖**：内层处理完后需要回到外层
- **延迟处理**：遇到 `]` 才开始计算当前层

## 🔍 **状态栈分析**

### **变量生命周期分析**

#### **实时工作变量**
```java
int num = 0;           // 当前累积的数字
String currentStr = ""; // 当前累积的字符串
```
- **生命周期**：整个处理过程
- **作用**：实时反映当前层的处理状态

#### **状态保存变量**
```java
Stack<Integer> numStack = new Stack<>();  // 保存各层的重复次数
Stack<String> strStack = new Stack<>();   // 保存各层的字符串状态
```
- **生命周期**：从 `[` 保存到对应 `]` 恢复
- **作用**：跨层状态传递，维护嵌套关系

#### **临时计算变量**
```java
int repeatTimes = numStack.pop();    // 当前层重复次数
String prevStr = strStack.pop();     // 上层字符串状态
```
- **生命周期**：单次计算周期
- **作用**：执行合并操作

## ⚙️ **算法流程**

### **状态转换机制**

```
字符类型     →  操作
─────────────────────────────
数字         →  累积到 num
字母         →  累积到 currentStr  
'['         →  保存状态，重置变量
']'         →  恢复状态，执行合并
```

### **详细处理逻辑**

#### **1. 遇到数字**
```java
if (Character.isDigit(c)) {
    num = num * 10 + (c - '0');
}
```
- 累积多位数字

#### **2. 遇到字母**
```java
else if (Character.isLetter(c)) {
    currentStr += c;
}
```
- 累积当前层的字符串

#### **3. 遇到 '['**
```java
else if (c == '[') {
    // 保存当前状态到栈
    numStack.push(num);
    strStack.push(currentStr);
    
    // 重置工作变量，准备处理下一层
    num = 0;
    currentStr = "";
}
```
- **状态保存**：将当前层的 `num` 和 `currentStr` 压入栈
- **状态重置**：清空工作变量，准备处理内层

#### **4. 遇到 ']'**
```java
else if (c == ']') {
    // 恢复上层状态
    int repeatTimes = numStack.pop();
    String prevStr = strStack.pop();
    
    // 合并：上层字符串 + 当前层字符串重复
    currentStr = prevStr + currentStr.repeat(repeatTimes);
}
```
- **状态恢复**：从栈中取出上层的状态
- **结果合并**：将当前层结果重复后拼接到上层

## 📊 **执行过程追踪**

以 `"3[a2[c]]"` 为例：

| 字符 | num | currentStr | numStack | strStack | 操作说明 |
|------|-----|------------|----------|----------|----------|
| '3'  | 3   | ""         | []       | []       | 累积数字 |
| '['  | 0   | ""         | [3]      | [""]     | 保存状态，重置变量 |
| 'a'  | 0   | "a"        | [3]      | [""]     | 累积字符 |
| '2'  | 2   | "a"        | [3]      | [""]     | 累积数字 |
| '['  | 0   | ""         | [3,2]    | ["","a"] | 保存状态，重置变量 |
| 'c'  | 0   | "c"        | [3,2]    | ["","a"] | 累积字符 |
| ']'  | 0   | "acc"      | [3]      | [""]     | 恢复状态：a + c*2 |
| ']'  | 0   | "accaccacc"| []       | []       | 恢复状态："" + acc*3 |

## 💻 **完整代码实现**

```java
public class Solution {
    public String decodeString(String s) {
        Stack<Integer> numStack = new Stack<>();
        Stack<String> strStack = new Stack<>();
        int num = 0;
        String currentStr = "";
        
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                // 累积数字（处理多位数）
                num = num * 10 + (c - '0');
                
            } else if (c == '[') {
                // 进入下一层：保存当前状态
                numStack.push(num);
                strStack.push(currentStr);
                
                // 重置工作变量
                num = 0;
                currentStr = "";
                
            } else if (c == ']') {
                // 退出当前层：恢复上层状态并合并
                int repeatTimes = numStack.pop();
                String prevStr = strStack.pop();
                
                // 合并结果
                currentStr = prevStr + currentStr.repeat(repeatTimes);
                
            } else {
                // 累积字符
                currentStr += c;
            }
        }
        
        return currentStr;
    }
}
```

## 🔧 **关键技巧**

### **1. 双栈设计**
- **numStack**：存储重复次数
- **strStack**：存储字符串状态
- **分离关注点**：数字和字符串有不同的生命周期

### **2. 状态管理**
- **保存时机**：遇到 `[` 立即保存
- **恢复时机**：遇到 `]` 立即恢复
- **自动回溯**：栈的LIFO特性保证正确顺序

### **3. 边界处理**
- **多位数字**：`num = num * 10 + (c - '0')`
- **空字符串**：用 `""` 作为初始占位符
- **字符串重复**：使用 `repeat()` 方法

## 📈 **复杂度分析**

- **时间复杂度**：O(n)，其中 n 是字符串长度
  - 每个字符只遍历一次
  - 栈操作都是 O(1)
  
- **空间复杂度**：O(n)
  - 栈的深度最多为嵌套层数
  - 字符串拼接需要额外空间

## 🎯 **核心洞察**

### **为什么用栈？**
1. **自然匹配**：`[` 和 `]` 的配对关系
2. **状态隔离**：每层处理互不干扰
3. **自动回溯**：LIFO保证正确的处理顺序
4. **延迟处理**：遇到 `]` 才计算，符合问题特性

### **状态栈的威力**
- **化递归为迭代**：避免栈溢出
- **状态可视化**：每一步都清晰可见
- **逻辑简洁**：线性处理，易于理解
