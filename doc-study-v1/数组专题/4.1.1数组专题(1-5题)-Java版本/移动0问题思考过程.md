# 移动0问题思考过程





[283. 移动零 - 力扣（LeetCode）](https://leetcode.cn/problems/move-zeroes/)



```latex
我需要把左边变成非0,右边变成0,也就是遇到0的话把0右移

0 1 0 3 12
0 1 0 3 12
遇到第一个非0
0 1 0 3 12 -> 1 0 0 3 12 这时候左边非0的坐标从0变成了1
继续遍历到index=3;
遇到第二个非0
1 0 0 3 12 -> 1 3 0 0 12 这时候左边非0的坐标从1变成了2
我们继续遍历到index=4;
1 3 0 0 12 -> 1 3 12 0 0 这时候index=nums.length-1了,结束

我们也把左右两边的分区处理结束了
我们需要一个左指针用来处理非0分区
需要一个右指针用来遍历数据
如果为0则countinue
否则
获取当前数据,跟记录的为0的左坐标置换位置


这时候还有个问题
第一个坐标可能是0,也可能不是0
所以我们的右坐标不是从left+1开始的
左右都是从0开始的




```

秒了

```latex
class Solution {
    public void moveZeroes(int[] nums) {
        if(1 == nums.length){
            return;
        }
        int left = 0;
        int right = 0;
        while(right < nums.length){
            if (nums[right] != 0){
                int temp = nums[right];
                nums[right] = nums[left];
                nums[left] = temp;
                left++;
            }
            right++;
        }
    }
}
```
