# 找到所有数组中消失的数字思考过程

[448. 找到所有数组中消失的数字 - 力扣（LeetCode）](https://leetcode.cn/problems/find-all-numbers-disappeared-in-an-array/description/)



```latex
给你一个含 n 个整数的数组 nums ，
其中 nums[i] 在区间 [1, n] 内。
请你找出所有在 [1, n] 范围内但没有出现在 nums 中的数字，
并以数组的形式返回结果。

长度=n
数据范围是1-n
那数组本身的存储特性还有下表作为标记都可以使用了

如果数字i出现过,则在nums[i]的地方标记为负数
最后一次遍历,找到不是负数的数字.输出i


```



```latex
class Solution {
    public List<Integer> findDisappearedNumbers(int[] nums) {
        List<Integer> list = new ArrayList<>();
        for(int i=0;i<nums.length;i++){
            int index = Math.abs(nums[i]) - 1;
            if(nums[index] > 0){
                nums[index] = -nums[index];
            }
            
        }
        for(int i=0;i<nums.length;i++){
            if (0 < nums[i]){
                list.add(new Integer(i+1));
            }
        }
        return list;
    }
}
```
