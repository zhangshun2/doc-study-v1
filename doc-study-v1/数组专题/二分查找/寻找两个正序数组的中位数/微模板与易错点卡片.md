# 微模板与易错点卡片｜4 寻找两个正序数组的中位数

## 微模板（Java，划分二分）
```java
double findMedianSortedArrays(int[] A, int[] B) {
    if (A.length > B.length) return findMedianSortedArrays(B, A);
    int n = A.length, m = B.length, total = n + m, half = (total + 1) / 2;
    int lo = 0, hi = n;
    while (lo <= hi) {
        int i = (lo + hi) / 2;        // A 左半长度
        int j = half - i;             // B 左半长度
        int Aleft = (i == 0 ? Integer.MIN_VALUE : A[i - 1]);
        int Aright = (i == n ? Integer.MAX_VALUE : A[i]);
        int Bleft = (j == 0 ? Integer.MIN_VALUE : B[j - 1]);
        int Bright = (j == m ? Integer.MAX_VALUE : B[j]);
        if (Aleft <= Bright && Bleft <= Aright) {
            if (total % 2 == 1) return Math.max(Aleft, Bleft);
            return (Math.max(Aleft, Bleft) + Math.min(Aright, Bright)) / 2.0;
        } else if (Aleft > Bright) hi = i - 1; else lo = i + 1;
    }
    return 0.0;
}
```

## 易错点卡片
- 统一用较短数组做二分，防止越界；边界用 `MIN/MAX_VALUE` 哨兵。
- 奇偶总长度分支，返回左侧最大或左右均值。
- 分区条件是 `Aleft<=Bright && Bleft<=Aright`，不要写反。
