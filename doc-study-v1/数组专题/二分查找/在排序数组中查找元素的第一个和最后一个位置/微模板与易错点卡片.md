# 微模板与易错点卡片｜34 查找第一个和最后一个位置

## 微模板（Java）
```java
int[] searchRange(int[] a, int x) {
    int left = lowerBound(a, x), right = upperBound(a, x) - 1;
    if (left == a.length || a[left] != x) return new int[]{-1, -1};
    return new int[]{left, right};
}
int lowerBound(int[] a, int x) {
    int l = 0, r = a.length;
    while (l < r) {
        int m = (l + r) >>> 1;
        if (a[m] >= x) r = m; else l = m + 1;
    }
    return l;
}
int upperBound(int[] a, int x) {
    int l = 0, r = a.length;
    while (l < r) {
        int m = (l + r) >>> 1;
        if (a[m] > x) r = m; else l = m + 1;
    }
    return l;
}
```

## 易错点卡片
- 返回右边界为 `upperBound-1`；注意空区间判断。
- 上下界比较符不同：`>=x` 与 `>x`；写反会无限循环或错位。
- 若数组为空或不存在目标值，应返回 `[-1,-1]`。
