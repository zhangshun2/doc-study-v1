# 微模板与易错点卡片｜283 移动零

## 微模板（Java）
```java
void moveZeroes(int[] a) {
    int slow = 0;
    for (int fast = 0; fast < a.length; fast++) {
        if (a[fast] != 0) a[slow++] = a[fast];
    }
    while (slow < a.length) a[slow++] = 0;
}
```

## 易错点卡片
- 稳定性：非零元素相对顺序保持不变；不要用交换版本破坏顺序。
- 收尾填充零：写完非零后统一置零，避免多余移动。
- 若需原地交换实现，需额外判断以减少写操作次数。
