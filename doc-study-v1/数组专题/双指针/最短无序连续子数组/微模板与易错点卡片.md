# 微模板与易错点卡片｜581 最短无序连续子数组

## 微模板（Java，O(n))
```java
int findUnsortedSubarray(int[] a) {
    int n = a.length, max = Integer.MIN_VALUE, min = Integer.MAX_VALUE;
    int end = -1, start = -1;
    for (int i = 0; i < n; i++) { // 从左到右，追踪最大值，找右边界
        if (a[i] < max) end = i; else max = a[i];
    }
    for (int i = n - 1; i >= 0; i--) { // 从右到左，追踪最小值，找左边界
        if (a[i] > min) start = i; else min = a[i];
    }
    return end == -1 ? 0 : (end - start + 1);
}
```

## 易错点卡片
- 全局已排好时应返回 0；判定条件是 `end==-1`。
- 边界更新方向：左向最小、右向最大，避免写反比较符。
- 排序版解法易错在相等元素的处理；O(n) 双扫描更稳健。
