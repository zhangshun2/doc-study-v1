# 微模板与易错点卡片｜11 盛最多水的容器

## 微模板（Java）
```java
int maxArea(int[] h) {
    int l = 0, r = h.length - 1, ans = 0;
    while (l < r) {
        ans = Math.max(ans, Math.min(h[l], h[r]) * (r - l));
        if (h[l] < h[r]) l++; else r--;
    }
    return ans;
}
```

## 易错点卡片
- 指针移动规则：移动短板才能期望更大面积；移动长板无益。
- 面积计算：宽度为 `r - l`；注意越界与乘法顺序。
- 边界：数组长度 < 2 返回 0。
