# 微模板与易错点卡片｜75 颜色分类

## 微模板（Java）
```java
void sortColors(int[] a) {
    int l = 0, i = 0, r = a.length - 1;
    while (i <= r) {
        if (a[i] == 0) swap(a, l++, i++);
        else if (a[i] == 2) swap(a, i, r--);
        else i++;
    }
}
void swap(int[] a, int x, int y) { int t = a[x]; a[x] = a[y]; a[y] = t; }
```

## 易错点卡片
- 处理 `2` 时不递增 `i`，因交换后需检查新来的元素。
- 三指针不变量：`[0..l-1]=0`，`[l..i-1]=1`，`[r+1..n-1]=2`。
- 输入不一定只含 0/1/2 时需额外校验；本题默认三色。
