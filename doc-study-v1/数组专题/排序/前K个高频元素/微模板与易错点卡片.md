# 微模板与易错点卡片｜347 前K个高频元素

## 微模板（Java，小顶堆）
```java
int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> cnt = new HashMap<>();
    for (int x : nums) cnt.put(x, cnt.getOrDefault(x, 0) + 1);
    PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[1] - b[1]); // [值,频次]
    for (Map.Entry<Integer,Integer> e : cnt.entrySet()) {
        pq.offer(new int[]{e.getKey(), e.getValue()});
        if (pq.size() > k) pq.poll();
    }
    int[] res = new int[k];
    for (int i = k - 1; i >= 0; i--) res[i] = pq.poll()[0];
    return res;
}
```

## 易错点卡片
- 堆排序方向：用小顶堆保留前 K 大频次；大顶堆需额外控制大小。
- Map 计数时注意整数溢出与默认值；频次比较取值 `a[1]-b[1]`。
- 若需返回按频次排序的列表，出堆后再反转或使用大顶堆收集。
