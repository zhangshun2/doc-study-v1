# 微模板与易错点卡片｜215 数组中的第K个最大元素

## 微模板（Java，Quickselect）
```java
int findKthLargest(int[] a, int k) {
    int n = a.length, target = n - k; // 第k大对应升序下标 n-k
    int l = 0, r = n - 1;
    while (l <= r) {
        int p = partition(a, l, r);
        if (p == target) return a[p];
        else if (p < target) l = p + 1; else r = p - 1;
    }
    return -1;
}
int partition(int[] a, int l, int r) {
    int pivot = a[r], i = l;
    for (int j = l; j < r; j++) {
        if (a[j] <= pivot) swap(a, i++, j);
    }
    swap(a, i, r); return i;
}
void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }
```

## 易错点卡片
- “第k大”索引换算：升序下标为 `n-k`；写错会返回错误元素。
- 分区选择 `<= pivot` 保证收敛；避免全相等导致死循环。
- 需要平均 O(n)；最坏 O(n^2) 可用随机化 pivot 缓解。
