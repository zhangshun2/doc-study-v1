# 060前K个高频元素

[https://leetcode.cn/problems/g5c51o/description/](https://leetcode.cn/problems/g5c51o/description/)



转map;然后用小根堆

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
    
        int[] result = new int[k];
        Map<Integer,Integer> map = new HashMap<>();
        for(int num : nums){
            map.put(num,map.getOrDefault(num,0) + 1);
        }
        PriorityQueue<int[]> queue = new PriorityQueue<>(
            new Comparator<int[]>(){
                public int compare(int[] m,int[] n){
                    return m[1] -n[1];
                }
            }
        );

        for(Map.Entry<Integer,Integer> entry : map.entrySet()){
            int key = entry.getKey();
            int value = entry.getValue();
            if(queue.size() < k){
                queue.offer(new int[]{key,value});
            }else{
                if(queue.peek()[1] < value){
                    queue.poll();
                    queue.offer(new int[]{key,value});
                }
            }
        }

        for(int i=0;i<k;i++){
            result[i] = queue.poll()[0];
        }

        return result;
    }
}

```



路人大佬的写法

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        int minc = Integer.MAX_VALUE ;
        int maxc = Integer.MIN_VALUE ;
        for(int i : nums) {
            minc = Math.min(i , minc) ;
            maxc = Math.max(i , maxc) ;
        }
        int[] count = new int[maxc - minc + 1] ;
        for(int i : nums) {
            count[i - minc]++ ;
        }
        int index = 0 ;
        int[] ans = new int[k] ;
        while(index < k) {
            int maxCount = 0 ;
            for(int i : count) {
                maxCount = Math.max(maxCount , i) ;
            }
            for(int i = 0 ; i < count.length ; i++ ) {
                if(maxCount == count[i]) {
                    ans[index] = i + minc ;
                    count[i] = 0 ;
                    index++ ;
                }
            }
        }
        return ans ;
        
        
    }
}
```

## 📊 "路人大佬"写法分析
### 🔍 算法思路
这个"路人大佬"的写法采用了**计数数组 + 多次查找最大值**的策略：

1. **范围压缩**：通过 `minc` 和 `maxc` 确定数组元素范围
2. **频次统计**：使用 `count[maxc - minc + 1]` 数组统计每个元素出现次数
3. **逐个提取**：重复K次查找最大频次并提取对应元素

### ⚡ 核心逻辑
```java
// 1. 找到数值范围
int minc = Integer.MAX_VALUE;
int maxc = Integer.MIN_VALUE;

// 2. 建立映射：nums[i] -> count[nums[i] - minc]
int[] count = new int[maxc - minc + 1];

// 3. K次循环，每次找最大频次
while(index < k) {
    int maxCount = 0;
    // 找当前最大频次
    for(int i : count) {
        maxCount = Math.max(maxCount, i);
    }
    // 提取所有具有最大频次的元素
    for(int i = 0; i < count.length; i++) {
        if(maxCount == count[i]) {
            ans[index] = i + minc;  // 还原原始值
            count[i] = 0;           // 标记已使用
            index++;
        }
    }
}
```

### 📊 复杂度分析
+ **时间复杂度**：O(K × (maxc - minc))
    - 外层循环K次
    - 每次需要遍历整个count数组两遍
+ **空间复杂度**：O(maxc - minc)
    - count数组的大小取决于数值范围

### ✅ 优点
1. **思路直观**：逻辑简单易懂
2. **适用特定场景**：当数值范围较小时效率不错
3. **无需额外数据结构**：只用基本数组

### ⚠️ 缺点
1. **效率问题**：每次都要重新遍历整个count数组
2. **空间浪费**：当数值范围很大但元素很少时，count数组会很稀疏
3. **不适合大范围**：如果 `maxc - minc` 很大，空间和时间开销都很高

### 🆚 与主流解法对比
| 解法 | 时间复杂度 | 空间复杂度 | 适用场景 |
| --- | --- | --- | --- |
| **此解法** | O(K × range) | O(range) | 数值范围小 |
| **堆排序** | O(N log K) | O(N + K) | 通用 |
| **快速选择** | O(N) 平均 | O(N) | 通用 |
| **桶排序** | O(N + K) | O(N) | 频次范围小 |


### 💡 改进建议
可以考虑使用 `HashMap<Integer, Integer>` 替代计数数组，避免稀疏数组的空间浪费，或者使用优先队列来避免重复遍历。
