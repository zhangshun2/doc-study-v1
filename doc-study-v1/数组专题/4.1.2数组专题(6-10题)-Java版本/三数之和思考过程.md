# 三数之和思考过程



[LCR 007. 三数之和 - 力扣（LeetCode）](https://leetcode.cn/problems/1fGaJU/)

```latex
-1,0,1,2,-1,-4
-4,-1,-1,0,1,2

-4=a
遍历
b=a+1,c=length-1
如果>0,c左移
如果<=,b右移
直到b<c不成立
```



```latex
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        
        if(null == nums || nums.length == 1){
            return new ArrayList<>();
        }

        Arrays.sort(nums);
        List<List<Integer>> result = new ArrayList<>();
        
        for(int a = 0 ; a<nums.length-2;a++){
            int b = a+1;
            int c= nums.length-1;
            while(b < c){
                if(nums[b]+nums[c]+nums[a] < 0){
                    b++;
                }else if (nums[b]+nums[c]+nums[a] > 0){
                    c--;
                }else{
                    List<Integer> list = new ArrayList<>();
                    list.add(nums[a]);list.add(nums[b]);list.add(nums[c]);
                    list.stream().sorted();
                    if(!result.contains(list)){
                        result.add(list);
                    }
                    b++;
                    c--;
                }
            }
        }
        return result;
    }
}
```
