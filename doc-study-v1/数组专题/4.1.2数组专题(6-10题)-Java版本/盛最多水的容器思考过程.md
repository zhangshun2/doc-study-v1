```latex
给定一个长度为 n 的整数数组 height 。
有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

找最大值
找关键词,dp,贪婪,选举,等等
```

```latex
class Solution {
    public int maxArea(int[] height) {
        int left=0;
        int right=height.length-1;
        int max=Math.min(height[height.length-1],height[0]) * (height.length-1);
        while(left < right){
            if(height[left] < height[right]){
                left++;
            }else{
                right--;
            }
            max = Math.max(max , Math.min(height[right],height[left]) * (right-left));
        }
        return max;
    }
}
```



问题在于

双指针的逻辑我不好判断一开始就是从0,1往length去走

还是说从0,length往left>=right去走



这个以后要多换思路想一想

如果一开始就是0,length的思路去想,不管怎么想,只要选择了短边,都会变小

所以我要忽略短边

如果左边更短就左边右移

如果右边更短就右边左移

而且从0,1开始移动的话,纵坐标一直在变大,我不好判断极值,只要去暴力

如果是从0,length开始往中间移动的话,纵坐标在一直变小,我只要判断高度关系就好了
