## 🎯 滑动窗口核心思想
### 🔑 什么是滑动窗口？
滑动窗口是一种算法思想，通过维护一个窗口在数组或字符串上滑动，来解决一些查找满足一定条件的连续区间的问题。

### 📝 滑动窗口的特点
1. **窗口内维护一定的性质**：如无重复字符、字符频次等
2. **动态调整窗口大小**：根据条件扩大或缩小窗口
3. **高效的时间复杂度**：通常为O(n)，避免重复计算
4. **双指针实现**：使用左右指针维护窗口边界

### 🔄 滑动窗口的基本模板
```java
public int slidingWindow(String s) {
    Map<Character, Integer> window = new HashMap<>();
    
    int left = 0, right = 0;
    int result = 0;
    
    while (right < s.length()) {
        // 扩大窗口
        char c = s.charAt(right);
        right++;
        // 更新窗口内数据
        window.put(c, window.getOrDefault(c, 0) + 1);
        
        // 判断左侧窗口是否要收缩
        while (window needs shrink) {
            // 更新结果
            result = Math.max(result, right - left);
            
            // 缩小窗口
            char d = s.charAt(left);
            left++;
            // 更新窗口内数据
            window.put(d, window.get(d) - 1);
            if (window.get(d) == 0) {
                window.remove(d);
            }
        }
    }
    
    return result;
}
```

## 1️⃣ 无重复字符的最长子串 (LeetCode 3)
### 📝 题目描述
给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长子串** 的长度。

**示例 1:**

```plain
输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。
```

**示例 2:**

```plain
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3:**

```plain
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
```

### 🔧 基础解法：暴力枚举
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int n = s.length();
        int maxLength = 0;
        
        for (int i = 0; i < n; i++) {
            Set<Character> seen = new HashSet<>();
            
            for (int j = i; j < n; j++) {
                char c = s.charAt(j);
                
                if (seen.contains(c)) {
                    break;
                }
                
                seen.add(c);
                maxLength = Math.max(maxLength, j - i + 1);
            }
        }
        
        return maxLength;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n³)，两层循环加上HashSet查找
+ 空间复杂度：O(min(m,n))，m是字符集大小

### 🚀 进阶解法：滑动窗口（HashSet）
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> window = new HashSet<>();
        int left = 0, right = 0;
        int maxLength = 0;
        
        while (right < s.length()) {
            char c = s.charAt(right);
            
            // 如果窗口中有重复字符，缩小窗口
            while (window.contains(c)) {
                window.remove(s.charAt(left));
                left++;
            }
            
            // 扩大窗口
            window.add(c);
            right++;
            
            // 更新最大长度
            maxLength = Math.max(maxLength, right - left);
        }
        
        return maxLength;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，每个字符最多被访问两次
+ 空间复杂度：O(min(m,n))，m是字符集大小

### 🚀 最优解法：滑动窗口（HashMap优化）
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> window = new HashMap<>();
        int left = 0;
        int maxLength = 0;
        
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            
            // 如果字符在窗口中，更新左边界
            if (window.containsKey(c)) {
                left = Math.max(left, window.get(c) + 1);
            }
            
            // 更新字符位置
            window.put(c, right);
            
            // 更新最大长度
            maxLength = Math.max(maxLength, right - left + 1);
        }
        
        return maxLength;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，只需要一次遍历
+ 空间复杂度：O(min(m,n))，m是字符集大小

**核心思想：**

+ 使用HashMap记录字符的最新位置
+ 当遇到重复字符时，直接跳转到重复字符的下一个位置
+ 避免了逐个移动左指针的过程

### 🚀 数组优化版本（ASCII字符）
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] index = new int[128]; // ASCII字符集
        Arrays.fill(index, -1);
        
        int left = 0;
        int maxLength = 0;
        
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            
            // 如果字符在窗口中，更新左边界
            if (index[c] >= left) {
                left = index[c] + 1;
            }
            
            // 更新字符位置
            index[c] = right;
            
            // 更新最大长度
            maxLength = Math.max(maxLength, right - left + 1);
        }
        
        return maxLength;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)，固定大小的数组

## 2️⃣ 找到字符串中所有字母异位词 (LeetCode 438)
### 📝 题目描述
给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**异位词** 指由相同字母重排列形成的字符串（包括相同的字符串）。

**示例 1:**

```plain
输入: s = "abab", p = "ab"
输出: [0,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```

**示例 2:**

```plain
输入: s = "abacabad", p = "aaab"
输出: [0,1,4]
解释:
起始索引等于 0 的子串是 "abac", 它是 "aaab" 的异位词。
起始索引等于 1 的子串是 "baca", 它是 "aaab" 的异位词。
起始索引等于 4 的子串是 "abad", 它是 "aaab" 的异位词。
```

### 🔧 基础解法：暴力枚举
```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        
        if (s.length() < p.length()) {
            return result;
        }
        
        for (int i = 0; i <= s.length() - p.length(); i++) {
            String substring = s.substring(i, i + p.length());
            if (isAnagram(substring, p)) {
                result.add(i);
            }
        }
        
        return result;
    }
    
    private boolean isAnagram(String s1, String s2) {
        if (s1.length() != s2.length()) {
            return false;
        }
        
        int[] count = new int[26];
        
        for (int i = 0; i < s1.length(); i++) {
            count[s1.charAt(i) - 'a']++;
            count[s2.charAt(i) - 'a']--;
        }
        
        for (int c : count) {
            if (c != 0) {
                return false;
            }
        }
        
        return true;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n * m)，n是s的长度，m是p的长度
+ 空间复杂度：O(1)

### 🚀 进阶解法：滑动窗口（HashMap）
```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        
        if (s.length() < p.length()) {
            return result;
        }
        
        Map<Character, Integer> need = new HashMap<>();
        Map<Character, Integer> window = new HashMap<>();
        
        // 统计p中字符频次
        for (char c : p.toCharArray()) {
            need.put(c, need.getOrDefault(c, 0) + 1);
        }
        
        int left = 0, right = 0;
        int valid = 0; // 窗口中满足条件的字符个数
        
        while (right < s.length()) {
            // 扩大窗口
            char c = s.charAt(right);
            right++;
            
            if (need.containsKey(c)) {
                window.put(c, window.getOrDefault(c, 0) + 1);
                if (window.get(c).equals(need.get(c))) {
                    valid++;
                }
            }
            
            // 判断是否需要收缩窗口
            while (right - left >= p.length()) {
                // 检查是否找到异位词
                if (valid == need.size()) {
                    result.add(left);
                }
                
                // 缩小窗口
                char d = s.charAt(left);
                left++;
                
                if (need.containsKey(d)) {
                    if (window.get(d).equals(need.get(d))) {
                        valid--;
                    }
                    window.put(d, window.get(d) - 1);
                }
            }
        }
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n + m)，n是s的长度，m是p的长度
+ 空间复杂度：O(m)

### 🚀 最优解法：滑动窗口（数组优化）
```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        
        if (s.length() < p.length()) {
            return result;
        }
        
        int[] pCount = new int[26];
        int[] sCount = new int[26];
        
        // 统计p中字符频次
        for (char c : p.toCharArray()) {
            pCount[c - 'a']++;
        }
        
        int windowSize = p.length();
        
        // 初始化第一个窗口
        for (int i = 0; i < windowSize; i++) {
            sCount[s.charAt(i) - 'a']++;
        }
        
        // 检查第一个窗口
        if (Arrays.equals(pCount, sCount)) {
            result.add(0);
        }
        
        // 滑动窗口
        for (int i = windowSize; i < s.length(); i++) {
            // 添加新字符
            sCount[s.charAt(i) - 'a']++;
            
            // 移除旧字符
            sCount[s.charAt(i - windowSize) - 'a']--;
            
            // 检查当前窗口
            if (Arrays.equals(pCount, sCount)) {
                result.add(i - windowSize + 1);
            }
        }
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)，n是s的长度
+ 空间复杂度：O(1)

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();
        
        if (s.length() < p.length()) {
            return result;
        }
        
        int[] count = new int[26];
        int matches = 0;
        
        // 统计p中字符频次（负数）
        for (char c : p.toCharArray()) {
            count[c - 'a']--;
        }
        
        int windowSize = p.length();
        
        // 处理第一个窗口
        for (int i = 0; i < windowSize; i++) {
            int index = s.charAt(i) - 'a';
            count[index]++;
            if (count[index] == 0) {
                matches++;
            } else if (count[index] == 1) {
                matches--;
            }
        }
        
        if (matches == 26) {
            result.add(0);
        }
        
        // 滑动窗口
        for (int i = windowSize; i < s.length(); i++) {
            // 添加新字符
            int newIndex = s.charAt(i) - 'a';
            count[newIndex]++;
            if (count[newIndex] == 0) {
                matches++;
            } else if (count[newIndex] == 1) {
                matches--;
            }
            
            // 移除旧字符
            int oldIndex = s.charAt(i - windowSize) - 'a';
            count[oldIndex]--;
            if (count[oldIndex] == 0) {
                matches++;
            } else if (count[oldIndex] == -1) {
                matches--;
            }
            
            if (matches == 26) {
                result.add(i - windowSize + 1);
            }
        }
        
        return result;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(1)

## 3️⃣ 和为K的子数组 (LeetCode 560)
### 📝 题目描述
给你一个整数数组 `nums` 和一个整数 `k` ，请你统计并返回 **该数组中和为 **`k`** 的连续子数组的个数** 。

**示例 1：**

```plain
输入：nums = [1,1,1], k = 2
输出：2
```

**示例 2：**

```plain
输入：nums = [1,2,3], k = 3
输出：2
```

### 🔧 基础解法：暴力枚举
```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        int count = 0;
        
        for (int i = 0; i < nums.length; i++) {
            int sum = 0;
            
            for (int j = i; j < nums.length; j++) {
                sum += nums[j];
                
                if (sum == k) {
                    count++;
                }
            }
        }
        
        return count;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n²)
+ 空间复杂度：O(1)

### 🚀 进阶解法：前缀和
```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        int count = 0;
        int[] prefixSum = new int[nums.length + 1];
        
        // 计算前缀和
        for (int i = 0; i < nums.length; i++) {
            prefixSum[i + 1] = prefixSum[i] + nums[i];
        }
        
        // 枚举所有子数组
        for (int i = 0; i < nums.length; i++) {
            for (int j = i; j < nums.length; j++) {
                // 子数组[i,j]的和 = prefixSum[j+1] - prefixSum[i]
                if (prefixSum[j + 1] - prefixSum[i] == k) {
                    count++;
                }
            }
        }
        
        return count;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n²)
+ 空间复杂度：O(n)

### 🚀 最优解法：前缀和+哈希表
```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> prefixSumCount = new HashMap<>();
        prefixSumCount.put(0, 1); // 前缀和为0的情况
        
        int count = 0;
        int prefixSum = 0;
        
        for (int num : nums) {
            prefixSum += num;
            
            // 查找是否存在前缀和为 prefixSum - k
            if (prefixSumCount.containsKey(prefixSum - k)) {
                count += prefixSumCount.get(prefixSum - k);
            }
            
            // 更新当前前缀和的计数
            prefixSumCount.put(prefixSum, 
                prefixSumCount.getOrDefault(prefixSum, 0) + 1);
        }
        
        return count;
    }
}
```

**复杂度分析：**

+ 时间复杂度：O(n)
+ 空间复杂度：O(n)

**核心思想：**

+ 如果存在子数组[i,j]的和为k，那么 `prefixSum[j] - prefixSum[i-1] = k`
+ 即 `prefixSum[i-1] = prefixSum[j] - k`
+ 使用哈希表记录每个前缀和出现的次数
+ 遍历数组时，查找是否存在 `prefixSum - k` 的前缀和

### 🚀 滑动窗口解法（仅适用于正数数组）
```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        // 注意：此方法仅适用于所有元素都为正数的情况
        // 对于包含负数的数组，滑动窗口不适用
        
        if (k <= 0) return 0;
        
        int count = 0;
        int left = 0;
        int sum = 0;
        
        for (int right = 0; right < nums.length; right++) {
            sum += nums[right];
            
            while (sum > k && left <= right) {
                sum -= nums[left];
                left++;
            }
            
            if (sum == k) {
                count++;
                // 继续寻找下一个可能的子数组
                sum -= nums[left];
                left++;
            }
        }
        
        return count;
    }
}
```

**注意：** 此方法仅适用于所有元素都为正数的特殊情况，对于包含负数的一般情况，应使用前缀和+哈希表的方法。

### 🚀 优化的前缀和解法

+ 时间复杂度：O(n)

## 📚 滑动窗口专题总结
### 🎯 核心知识点回顾
#### 1. 滑动窗口的本质
+ **双指针技术**：使用左右指针维护窗口边界
+ **动态调整**：根据条件动态扩大或缩小窗口
+ **状态维护**：在窗口滑动过程中维护必要的状态信息
+ **高效计算**：避免重复计算，实现O(n)时间复杂度

#### 2. 滑动窗口的类型
##### 固定大小窗口
+ 窗口大小固定，只需要滑动窗口位置
+ 典型应用：找到字符串中所有字母异位词
+ 实现方式：维护固定长度的窗口，逐步移动

##### 可变大小窗口
+ 窗口大小根据条件动态调整
+ 典型应用：无重复字符的最长子串
+ 实现方式：根据条件扩大或缩小窗口

#### 3. 滑动窗口的应用场景
1. **子串/子数组问题**：查找满足条件的连续区间
2. **字符串匹配**：模式匹配、异位词检测
3. **数组统计**：连续元素的统计分析
4. **优化问题**：最长、最短、最大、最小等优化目标

#### 4. 常用的数据结构
1. **HashMap/HashSet**：记录字符频次、去重
2. **数组**：固定字符集的频次统计
3. **双端队列**：维护窗口内的最值
4. **前缀和**：快速计算区间和
