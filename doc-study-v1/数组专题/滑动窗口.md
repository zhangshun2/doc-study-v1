# 滑动窗口

![1755447018449-8a3a3741-b7a7-41c8-b582-4c522ed3390c.png](./img/Lk1PIc-0IRU01HNA/1755447018449-8a3a3741-b7a7-41c8-b582-4c522ed3390c-331045.png)



1. 本质是双指针
2. 关于范式的逻辑
    1. 不断右移,因为满足条件的时候,不管左边还是右边朝内移动,都满足条件,所以要不断右移
    2. 满足之后移动左指针 因为从左指针固定开始的最大区间已经结束了
    3. while里的内容是边界条件
    4. 判断是不是滑动窗口的方式是连续
    5. 由此得到如上的代码范式

```java
T function(Vector<V> list0){

// 初始化结果对应的过程值和结果;
    foreach {
        用右指针初始化结果
        while(满足c,也就是便捷条件){
            满足条件的在while里面统计
            还原原先左指针的影响
            左指针++
        }
        不满足条件的再while外面统计
    }
}
```
