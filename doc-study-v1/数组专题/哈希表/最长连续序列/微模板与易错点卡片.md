# 微模板与易错点卡片｜128 最长连续序列

## 微模板（Java）
```java
int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int x : nums) set.add(x);
    int best = 0;
    for (int x : set) {
        if (!set.contains(x - 1)) { // 序列起点
            int y = x;
            while (set.contains(y)) y++;
            best = Math.max(best, y - x);
        }
    }
    return best;
}
```

## 易错点卡片
- 起点判定：只从“不存在前驱”的元素开始扩展，避免 O(n^2)。
- 重复元素：用 `Set` 去重，防止重复计数。
- 空数组返回 0；注意整型边界时 `x-1` 的溢出（一般数据范围安全）。
