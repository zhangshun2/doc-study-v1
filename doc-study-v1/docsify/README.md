# 算法学习笔记

> 系统整理算法与计算机基础笔记，问题与题解分离，便于快速定位与复盘

---

## 📖 项目简介

本仓库用于整理日常学习的算法与计算机基础笔记，重点围绕：

- **单调栈**：基础模板、原理选择、哨兵元素、经典题目
- **搜索与回溯**：递归回溯、全排列、组合总和等
- **栈与哈希表**：每日温度、括号匹配等
- **算法优化思想**：滚动数组、增量更新

所有题目均遵循"**问题与题解分离**"的规范，便于系统学习与复盘。

---

## 🗺️ 学习路线概览

```
入门基础 → 专题深入 → 实战练习 → 总结复盘
   ↓           ↓          ↓          ↓
基础模板    单调栈     经典题目    题解总览
学习方法    搜索回溯   LeetCode    知识梳理
```

### 推荐学习路径

1. **基础阶段**：阅读基础模板与原理详解
2. **理解阶段**：学习哨兵机制与记忆思考笔记
3. **实战阶段**：按专题刷经典题目
4. **复盘阶段**：对比多种解法，总结优化思路
