# LeetCode-31 下一个排列

- 难度：中等
- 链接：https://leetcode.cn/problems/next-permutation/

## 问题描述
实现获取下一个排列的函数，算法需要将给定数字序列重新排列成字典序中下一个更大的排列。如果不存在下一个更大的排列，则将数字重新排列成最小的排列（即升序排列）。必须原地修改，只允许使用额外常数级别的额外空间。

例如：
- `1,2,3` → `1,3,2`
- `3,2,1` → `1,2,3`
- `1,1,5` → `1,5,1`

## 题解一：经典算法（两次扫描 + 一次反转）
- 思路：
  1. 从右向左找到第一个 `nums[i] < nums[i+1]` 的位置 `i`（找到第一个下降点）
  2. 从右向左找到第一个 `nums[j] > nums[i]` 的位置 `j`
  3. 交换 `nums[i]` 和 `nums[j]`
  4. 反转 `i+1` 到末尾的部分
- 复杂度：时间 O(n)，空间 O(1)

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        int i = n - 2;
        // 步骤 1：从右向左找第一个 nums[i] < nums[i+1]
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        
        if (i >= 0) {
            // 步骤 2：从右向左找第一个 nums[j] > nums[i]
            int j = n - 1;
            while (j >= 0 && nums[j] <= nums[i]) j--;
            // 步骤 3：交换
            swap(nums, i, j);
        }
        // 步骤 4：反转 i+1 到末尾
        reverse(nums, i + 1, n - 1);
    }
    
    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
    
    private void reverse(int[] nums, int i, int j) {
        while (i < j) swap(nums, i++, j--);
    }
}
```

## 题解二：理解版（分步解释）
- 直觉：下一个排列 = 找到尽可能靠右的位置进行最小幅度的增大
  1. 高位尽量不变，只改动低位
  2. 在必须改动的位置，选择比当前值大的最小值
  3. 改动后，右侧部分按升序排列以保证是最小的下一个

## 总结思路
- 核心是找到"第一个可以被增大的位置"，然后在该位置选择"比当前大的最小值"，最后将右侧重置为升序
- 如果整个序列是降序，说明已经是最大排列，直接反转为升序
