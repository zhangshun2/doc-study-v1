# LeetCode-136 只出现一次的数字

- 难度：简单
- 链接：https://leetcode.cn/problems/single-number/

## 问题描述
给定一个非空整数数组，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现一次的元素。要求线性时间且不使用额外空间。

## 题解一：官方经典（按位异或）
- 思路：利用 `x ^ x = 0` 和 `x ^ 0 = x`，将所有元素异或，成对元素抵消，剩下的即为只出现一次的数。
- 复杂度：时间 O(n)，空间 O(1)。

```java
class Solution {
    public int singleNumber(int[] nums) {
        int x = 0;
        for (int v : nums) x ^= v;
        return x;
    }
}
```

## 题解二：通用解法（哈希或数学）
- 标签：位运算、哈希
- 思路：哈希计数或用集合与求和关系（`2*sum(set) - sum(array)`）也可求出结果，但不满足空间 O(1)。

## 总结思路
- 位运算最优且简洁，是该题的标准解法。
