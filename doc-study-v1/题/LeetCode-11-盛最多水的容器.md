# LeetCode-11 盛最多水的容器

- 难度：中等
- 链接：https://leetcode.cn/problems/container-with-most-water/

## 问题描述
给定长度为 `n` 的数组 `height`，每两个下标组成容器，容量为短板高度乘以宽度；返回最大容量。

## 题解一：官方经典（双指针夹逼）
- 思路：左右指针初始在两端，每次移动短板指针以期找到更高的短板；过程中更新最大容量。
- 复杂度：时间 O(n)，空间 O(1)。

```java
class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1, ans = 0;
        while (l < r) {
            int h = Math.min(height[l], height[r]);
            ans = Math.max(ans, h * (r - l));
            if (height[l] < height[r]) l++; else r--;
        }
        return ans;
    }
}
```

## 题解二：通用解法（枚举宽度 + 早剪枝）
- 标签：数组、双指针、贪心
- 思路：可理解为在枚举宽度的同时试图提高短板，双指针策略就是一种贪心剪枝，避免无效枚举。

## 题解三：最好理解（“短板决定容量，上移短板”）
- 直觉：容量由短板决定；每次上移短板才有可能提升容量，移动长板只会让宽度变小而短板不变。

## 总结思路
- 双指针的核心是“短板决定容量”的贪心依据；实现简洁高效。
