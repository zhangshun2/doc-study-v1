# 5.1.3 Java变量赋值逻辑详解 - DP中的变量切换技巧 (Java版本)

## 🎯 您的困惑很常见！
### 😵 常见困惑点
1. **从右到左的赋值逻辑**：`a = b + c` 先算右边，再赋给左边
2. **多行连续赋值**：变量之间相互依赖，顺序很重要
3. **临时变量切换**：三个变量轮换，容易搞混
4. **状态更新顺序**：哪个先更新，哪个后更新

**不用担心，这里有简单有效的理解方法！**

## 🔍 Java赋值的本质理解
### 📋 基础原理：从右到左
```java
// 赋值语句的执行顺序
int a = b + c;
// 步骤1：计算右边表达式 b + c
// 步骤2：将结果赋值给左边变量 a
```

**记忆口诀：**

> 📝 "先算右边，再给左边"
>

### 🎯 可视化理解方法
#### 方法1：箭头法
```java
int current = prev1 + prev2;  // ← 计算结果流向current
prev2 = prev1;                // ← prev1的值流向prev2
prev1 = current;              // ← current的值流向prev1
```

#### 方法2：表格法
| 执行前 | 语句 | 执行后 |
| --- | --- | --- |
| prev1=2, prev2=1 | `current = prev1 + prev2` | current=3 |
| prev1=2, prev2=1, current=3 | `prev2 = prev1` | prev2=2 |
| prev1=2, prev2=2, current=3 | `prev1 = current` | prev1=3 |

## 🎯 DP中变量切换的5种理解方法
### 🔧 方法1："传递链"思维
**核心思想：** 把变量更新想象成接力赛

```java
// 爬楼梯DP的变量更新
int current = prev1 + prev2;  // 🏃 新选手current准备好了
prev2 = prev1;                // 🏃 prev1传棒给prev2
prev1 = current;              // 🏃 current传棒给prev1
```

**记忆技巧：**

> 🏃‍♂️ "新人算好 → 老二接棒 → 老大接棒"
>

### 🔧 方法2："快照"思维
**核心思想：** 先拍照保存，再逐个更新

```java
// 第一步：拍快照（计算新值）
int current = prev1 + prev2;  // 📸 拍下新值的快照

// 第二步：按顺序更新
prev2 = prev1;                // 📝 更新历史记录
prev1 = current;              // 📝 更新当前记录
```

**记忆技巧：**

> 📸 "先拍照，再更新"
>

### 🔧 方法3："时间轴"思维
**核心思想：** 按时间顺序理解状态变化

```java
// 时间轴：过去 ← 现在 ← 未来
// prev2   prev1   current

// 时间推进：所有状态向前移动一格
int current = prev1 + prev2;  // ⏰ 计算未来状态
prev2 = prev1;                // ⏰ 现在变成过去
prev1 = current;              // ⏰ 未来变成现在
```

**记忆技巧：**

> ⏰ "时光机：未来→现在→过去"
>

### 🔧 方法4："队列"思维
**核心思想：** 想象成排队系统

```java
// 队列：[prev2] [prev1] [current]
//       老二    老大    新人

int current = prev1 + prev2;  // 🎫 新人拿号排队
prev2 = prev1;                // 🚶 老大变老二
prev1 = current;              // 🚶 新人变老大
```

**记忆技巧：**

> 🎫 "新人排队，大家前移"
>

### 🔧 方法5："变量角色"思维
**核心思想：** 给变量分配固定角色

```java
// 角色分工：
// prev2 = 爷爷（最老的值）
// prev1 = 爸爸（较新的值）
// current = 儿子（最新的值）

int current = prev1 + prev2;  // 👶 儿子 = 爸爸 + 爷爷
prev2 = prev1;                // 👴 爷爷 = 爸爸（爸爸变爷爷）
prev1 = current;              // 👨 爸爸 = 儿子（儿子变爸爸）
```

**记忆技巧：**

> 👨‍👦‍👦 "三代同堂，代代相传"
>

## 🎯 实战演练：逐步分解
### 📚 例题：爬楼梯（n=5）
#### 🔍 完整执行过程可视化
```java
public int climbStairs(int n) {
    if (n <= 2) return n;
    
    int prev2 = 1;  // dp[1] = 1
    int prev1 = 2;  // dp[2] = 2
    
    for (int i = 3; i <= n; i++) {
        // 使用"快照"思维理解
        int current = prev1 + prev2;  // 📸 拍快照
        prev2 = prev1;                // 📝 更新历史
        prev1 = current;              // 📝 更新当前
    }
    
    return prev1;
}
```

#### 📊 执行过程表格（推荐记忆方式）
| 轮次 | 执行前状态 | 计算过程 | 执行后状态 | 记忆口诀 |
| --- | --- | --- | --- | --- |
| i=3 | prev2=1, prev1=2 | current=2+1=3 | prev2=2, prev1=3 | "算新值，老二变老大" |
| i=4 | prev2=2, prev1=3 | current=3+2=5 | prev2=3, prev1=5 | "算新值，老二变老大" |
| i=5 | prev2=3, prev1=5 | current=5+3=8 | prev2=5, prev1=8 | "算新值，老二变老大" |


#### 🎬 动画式理解（推荐）
```plain
初始状态：
┌─────┬─────┬─────┐
│prev2│prev1│  ?  │
│  1  │  2  │     │
└─────┴─────┴─────┘

i=3执行：
步骤1：current = prev1 + prev2 = 2 + 1 = 3
┌─────┬─────┬─────┐
│prev2│prev1│current
│  1  │  2  │  3  │
└─────┴─────┴─────┘

步骤2：prev2 = prev1 (1变成2)
┌─────┬─────┬─────┐
│prev2│prev1│current
│  2  │  2  │  3  │
└─────┴─────┴─────┘

步骤3：prev1 = current (2变成3)
┌─────┬─────┬─────┐
│prev2│prev1│current
│  2  │  3  │  3  │
└─────┴─────┴─────┘

结果：prev2=2, prev1=3 ✅
```

## 🎯 常见错误与避免技巧
### ❌ 错误1：更新顺序搞反
```java
// ❌ 错误写法
int current = prev1 + prev2;
prev1 = current;    // 先更新prev1
prev2 = prev1;      // 再更新prev2（此时prev1已经变了！）

// ✅ 正确写法
int current = prev1 + prev2;
prev2 = prev1;      // 先保存prev1到prev2
prev1 = current;    // 再更新prev1
```

**避免技巧：**

> 🔄 "先保存历史，再更新现在"
>

### ❌ 错误2：忘记临时变量
```java
// ❌ 错误写法（没有临时变量）
prev1 = prev1 + prev2;  // prev1变了
prev2 = prev1;          // 用的是新的prev1，错了！

// ✅ 正确写法（使用临时变量）
int current = prev1 + prev2;  // 先保存结果
prev2 = prev1;                // 再更新
prev1 = current;
```

**避免技巧：**

> 💾 "先算先存，避免覆盖"
>

### ❌ 错误3：变量含义混乱
```java
// ❌ 混乱的命名
int a = b + c;
b = c;
c = a;

// ✅ 清晰的命名
int current = prev1 + prev2;
prev2 = prev1;
prev1 = current;
```

**避免技巧：**

> 📝 "语义化命名，一目了然"
>

## 🎯 快速记忆的5个小技巧
### 💡 技巧1：口诀记忆法
**万能口诀：**

> 🎵 "先算新值存起来，老二接棒老大位，老大接棒新值位"
>

```java
int current = prev1 + prev2;  // 先算新值存起来
prev2 = prev1;                // 老二接棒老大位
prev1 = current;              // 老大接棒新值位
```

### 💡 技巧2：手势记忆法
**用手指表示变量：**

+ 👆 食指 = prev2（最老）
+ 🖕 中指 = prev1（较新）
+ 👍 拇指 = current（最新）

**手势动作：**

1. 👍 = 🖕 + 👆 （拇指 = 中指 + 食指）
2. 👆 ← 🖕 （食指接收中指的值）
3. 🖕 ← 👍 （中指接收拇指的值）

### 💡 技巧3：颜色记忆法
```java
// 🔴 红色 = 最老的值（prev2）
// 🟡 黄色 = 较新的值（prev1）
// 🟢 绿色 = 最新的值（current）

int 🟢 = 🟡 + 🔴;  // 绿 = 黄 + 红
🔴 = 🟡;            // 红 ← 黄
🟡 = 🟢;            // 黄 ← 绿
```

### 💡 技巧4：数字位置法
**把变量想象成数字位置：**

```java
// 位置：  [2] [1] [0]
// 含义：  老  新  最新
// 变量：prev2 prev1 current

// 更新就是所有数字向右移动一位
int current = prev1 + prev2;  // 计算位置[0]
prev2 = prev1;                // [2] ← [1]
prev1 = current;              // [1] ← [0]
```

### 💡 技巧5：模板记忆法
**固定模板，直接套用：**

```java
// 🎯 DP空间优化万能模板
```

## 🎯 实战练习：其他DP问题
### 📚 练习1：打家劫舍
```java
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    
    // 使用"角色"思维
    int 爷爷 = nums[0];                    // 最远的房子
    int 爸爸 = Math.max(nums[0], nums[1]); // 较近的房子
    
    for (int i = 2; i < nums.length; i++) {
        // 👶 儿子 = max(不偷当前, 偷当前+爷爷)
        int 儿子 = Math.max(爸爸, 爷爷 + nums[i]);
        
        // 🔄 三代传承
        爷爷 = 爸爸;   // 爸爸变爷爷
        爸爸 = 儿子;   // 儿子变爸爸
    }
    
    return 爸爸;
}
```

### 📚 练习2：斐波那契数列
```java
public int fib(int n) {
    if (n <= 1) return n;
    
    // 使用"队列"思维
    int 队尾 = 0;  // fib(0)
    int 队头 = 1;  // fib(1)
    
    for (int i = 2; i <= n; i++) {
        // 🎫 新人入队
        int 新人 = 队头 + 队尾;
        
        // 🚶 队列前移
        队尾 = 队头;   // 队头变队尾
        队头 = 新人;   // 新人变队头
    }
    
    return 队头;
}
```

## 🎯 总结：掌握变量切换的关键
### ✅ 核心要点
1. **理解赋值方向**：从右到左，先算右边
2. **掌握更新顺序**：先保存历史，再更新当前
3. **使用临时变量**：避免值被覆盖
4. **语义化命名**：让代码自解释
5. **固定模板**：减少思考负担
