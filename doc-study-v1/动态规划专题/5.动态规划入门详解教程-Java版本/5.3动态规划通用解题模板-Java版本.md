## 🎯 通用DP四步解题法
通过前面的爬楼梯和打家劫舍例题，我们可以总结出DP问题的通用解题步骤：

### 📋 第一步：状态定义
**问题：** dp[i] 代表什么？

**思考要点：**

+ 通常 dp[i] 表示「到第i个位置/第i个元素时的某种最优值」
+ 状态定义要能够表达问题的本质
+ 状态定义要便于建立递推关系

**常见模式：**

```java
// 一维DP
int[] dp = new int[n];  // dp[i] = 到第i个位置的最优值

// 二维DP
int[][] dp = new int[m][n];  // dp[i][j] = 到位置(i,j)的最优值
```

### 📋 第二步：状态转移方程
**问题：** dp[i] 如何从之前的状态得出？

**思考要点：**

+ 分析在第i步有哪些决策选择
+ 每种选择对应一个状态转移
+ 通常取所有选择中的最优值

**常见模式：**

```java
// 累加型（如爬楼梯）
dp[i] = dp[i-1] + dp[i-2];

// 最优化型（如打家劫舍）
dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]);

// 最小化型
dp[i] = Math.min(dp[i-1], dp[i-2]) + cost[i];
```

### 📋 第三步：边界条件
**问题：** 最小的几个状态如何初始化？

**思考要点：**

+ 通常是 dp[0], dp[1] 等最小状态
+ 边界条件要符合问题的实际意义
+ 边界条件要能支撑后续的状态转移

**常见模式：**

```java
// 单个边界
dp[0] = initialValue;

// 多个边界
dp[0] = value0;
dp[1] = value1;
```

### 📋 第四步：计算顺序
**问题：** 按什么顺序计算各个状态？

**思考要点：**

+ 通常是从小到大的顺序
+ 确保计算 dp[i] 时，所依赖的状态已经计算过
+ 一维DP通常是线性顺序，二维DP通常是逐行或逐列

## 🔧 Java DP代码模板
### 模板1：基础一维DP
```java
public class Solution {
    public int dpSolution(int[] nums) {
        // 1. 边界检查
        if (nums == null || nums.length == 0) {
            return 0; // 或其他默认值
        }
        
        int n = nums.length;
        
        // 2. 特殊情况处理
        if (n == 1) {
            return nums[0]; // 或其他逻辑
        }
        
        // 3. 创建DP数组
        int[] dp = new int[n];
        
        // 4. 设置边界条件
        dp[0] = nums[0]; // 根据具体问题设置
        dp[1] = Math.max(nums[0], nums[1]); // 根据具体问题设置
        
        // 5. 状态转移
        for (int i = 2; i < n; i++) {
            dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]); // 根据具体问题设置
        }
        
        // 6. 返回结果
        return dp[n-1];
    }
}
```

### 模板2：空间优化版本
```java
public class Solution {
    public int dpSolutionOptimized(int[] nums) {
        // 1. 边界检查
        if (nums == null || nums.length == 0) {
            return 0;
        }
        
        // 2. 特殊情况处理
        if (nums.length == 1) {
            return nums[0];
        }
        
        // 3. 只保存必要的前置状态
        int prev2 = nums[0];  // dp[i-2]
        int prev1 = Math.max(nums[0], nums[1]);  // dp[i-1]
        
        // 4. 状态转移
        for (int i = 2; i < nums.length; i++) {
            int current = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = current;
        }
        
        // 5. 返回结果
        return prev1;
    }
}
```

### 模板3：二维DP
```java
public class Solution {
    public int dpSolution2D(int[][] grid) {
        // 1. 边界检查
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }
        
        int m = grid.length;
        int n = grid[0].length;
        
        // 2. 创建DP数组
        int[][] dp = new int[m][n];
        
        // 3. 设置边界条件
        dp[0][0] = grid[0][0];
        
        // 初始化第一行
        for (int j = 1; j < n; j++) {
            dp[0][j] = dp[0][j-1] + grid[0][j];
        }
        
        // 初始化第一列
        for (int i = 1; i < m; i++) {
            dp[i][0] = dp[i-1][0] + grid[i][0];
        }
        
        // 4. 状态转移
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = Math.min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
            }
        }
        
        // 5. 返回结果
        return dp[m-1][n-1];
    }
}
```

## 🎯 常见错误及避免方法
### ❌ 错误1：边界条件设置错误
```java
// 错误示例
dp[0] = 0; // 应该根据具体问题设置

// 正确示例
dp[0] = nums[0]; // 符合问题实际意义
```

### ❌ 错误2：状态转移方程错误
```java
// 错误示例
dp[i] = dp[i-1] + nums[i]; // 没有考虑所有选择

// 正确示例
dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]); // 考虑所有选择
```

### ❌ 错误3：数组越界
```java
// 错误示例
for (int i = 0; i < n; i++) {
    dp[i] = dp[i-1] + dp[i-2]; // i=0,1时会越界
}

// 正确示例
for (int i = 2; i < n; i++) {
    dp[i] = dp[i-1] + dp[i-2]; // 从i=2开始
}
```

### ❌ 错误4：忘记处理特殊情况
```java
// 错误示例
public int solve(int[] nums) {
    int[] dp = new int[nums.length]; // nums可能为空
    // ...
}

// 正确示例
public int solve(int[] nums) {
    if (nums == null || nums.length == 0) {
        return 0;
    }
    // ...
}
```
