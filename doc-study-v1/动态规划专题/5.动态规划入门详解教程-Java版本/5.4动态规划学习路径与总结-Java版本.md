## 🎯 Java DP编程最佳实践总结
### 🔧 代码结构
```java
public class Solution {
    /**
     * 问题描述和解题思路
     * 
     * 状态定义：dp[i] = ...
     * 状态转移：dp[i] = ...
     * 边界条件：dp[0] = ...
     * 
     * 时间复杂度：O(...)
     * 空间复杂度：O(...)
     */
    public int solve(int[] nums) {
        // 1. 输入验证
        if (nums == null || nums.length == 0) {
            return 0;
        }
        
        // 2. 特殊情况处理
        if (nums.length == 1) {
            return nums[0];
        }
        
        // 3. DP数组初始化
        int n = nums.length;
        int[] dp = new int[n];
        
        // 4. 边界条件设置
        dp[0] = nums[0];
        dp[1] = Math.max(nums[0], nums[1]);
        
        // 5. 状态转移
        for (int i = 2; i < n; i++) {
            dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]);
        }
        
        // 6. 返回结果
        return dp[n-1];
    }
}
```

### 🔧 性能优化技巧
#### 1. 空间优化
```java
// 原始版本：O(n)空间
int[] dp = new int[n];
for (int i = 2; i < n; i++) {
    dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]);
}

// 优化版本：O(1)空间
int prev2 = nums[0];
int prev1 = Math.max(nums[0], nums[1]);
for (int i = 2; i < n; i++) {
    int current = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1;
    prev1 = current;
}
```

## ❌ 常见错误总结
### 1. 状态定义不清晰
```java
// ❌ 错误：状态定义模糊
// dp[i] = 第i个数的某个值

// ✅ 正确：状态定义明确
// dp[i] = 到第i个房子时能偷到的最大金额
```

### 2. 边界条件错误
```java
// ❌ 错误：边界条件不符合实际
dp[0] = 0;  // 应该是nums[0]

// ✅ 正确：边界条件符合问题定义
dp[0] = nums[0];
dp[1] = Math.max(nums[0], nums[1]);
```

### 3. 状态转移方程错误
```java
// ❌ 错误：没有考虑所有选择
dp[i] = dp[i-1] + nums[i];

// ✅ 正确：考虑所有可能的选择
dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]);
```

### 4. 数组越界
```java
// ❌ 错误：没有检查数组边界
for (int i = 0; i < n; i++) {
    dp[i] = dp[i-1] + dp[i-2];  // i=0,1时越界
}

// ✅ 正确：正确处理边界
for (int i = 2; i < n; i++) {
    dp[i] = dp[i-1] + dp[i-2];
}
```

### 5. 忘记处理特殊情况
```java
// ❌ 错误：没有处理空数组
public int solve(int[] nums) {
    int[] dp = new int[nums.length];  // nums可能为null
}

// ✅ 正确：完整的输入验证
public int solve(int[] nums) {
    if (nums == null || nums.length == 0) {
        return 0;
    }
    if (nums.length == 1) {
        return nums[0];
    }
    // 正常逻辑
}
```
