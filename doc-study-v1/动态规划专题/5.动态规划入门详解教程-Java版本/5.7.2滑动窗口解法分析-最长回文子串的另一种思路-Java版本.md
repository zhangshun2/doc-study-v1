# 5.7.2 滑动窗口解法分析-最长回文子串的另一种思路-Java版本
## 📋 问题回顾
**LeetCode 5. 最长回文子串 (Longest Palindromic Substring)**

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

---

## 🤔 滑动窗口可行性分析
### 传统滑动窗口的特点
**滑动窗口适用场景：**

1. **连续子数组/子串问题**
2. **单调性质**：窗口扩展/收缩有明确的条件
3. **优化目标**：通常是求和、计数等可累积的指标
4. **时间复杂度**：通常能达到 O(n) 或 O(n log n)

**经典应用：**

+ 最长无重复字符子串
+ 最小覆盖子串
+ 固定长度子数组的最大和
+ 满足条件的子数组计数

### 回文串问题的特殊性
**回文串的特点：**

1. **对称性**：需要检查首尾字符的对应关系
2. **非单调性**：无法通过简单的扩展/收缩来维护回文性质
3. **全局性**：判断回文需要检查整个子串，不能局部累积

**为什么传统滑动窗口不适用：**

```java
// 传统滑动窗口的思路
int left = 0, right = 0;
while (right < s.length()) {
    // 扩展窗口
    right++;
    
    // 收缩窗口的条件是什么？
    while (/* 什么条件? */) {
        left++;
    }
    
    // 如何快速判断 s[left...right] 是否为回文？
    // 这里无法避免 O(n) 的回文检查
}
```

**核心问题：**

+ 无法定义明确的窗口收缩条件
+ 回文判断本身需要 O(n) 时间，无法优化
+ 缺乏可累积的状态信息

---

## 💡 变种思路：固定长度滑动窗口
### 思路分析
虽然传统的动态滑动窗口不适用，但我们可以考虑**固定长度的滑动窗口**：

1. **枚举所有可能的长度** len (从长到短)
2. **对于每个长度**，用固定长度为 len 的窗口滑动
3. **检查每个窗口内的子串是否为回文**
4. **找到第一个回文串就是最长的**

### 代码实现
```java
public class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }
        
        int n = s.length();
        
        // 从最长可能的长度开始枚举
        for (int len = n; len >= 1; len--) {
            // 固定长度为len的滑动窗口
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                if (isPalindrome(s, i, j)) {
                    return s.substring(i, j + 1);
                }
            }
        }
        
        return "";  // 理论上不会到达这里
    }
    
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

### 复杂度分析
**时间复杂度：** O(n³)

+ 外层循环：O(n) 种长度
+ 内层循环：O(n) 个窗口位置
+ 回文检查：O(n) 时间
+ 总体：O(n) × O(n) × O(n) = O(n³)

**空间复杂度：** O(1)

+ 只使用常数额外空间

**结论：** 这种方法本质上就是暴力枚举，并没有比传统方法更优。

## 🚀 优化思路：滑动窗口 + 哈希
### 核心思想
利用**滚动哈希**来快速判断回文，结合固定长度滑动窗口：

1. **预计算前缀哈希和后缀哈希**
2. **对于任意子串**，通过哈希值快速判断是否为回文
3. **结合二分查找**优化长度枚举

### 代码实现
```java
public class Solution {
    private static final int MOD = 1000000007;
    private static final int BASE = 31;
    
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }
        
        int n = s.length();
        
        // 预计算前缀哈希
        long[] prefixHash = new long[n + 1];
        long[] power = new long[n + 1];
        power[0] = 1;
        
        for (int i = 0; i < n; i++) {
            prefixHash[i + 1] = (prefixHash[i] * BASE + s.charAt(i)) % MOD;
            power[i + 1] = (power[i] * BASE) % MOD;
        }
        
        // 预计算后缀哈希
        long[] suffixHash = new long[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            suffixHash[n - i] = (suffixHash[n - i - 1] * BASE + s.charAt(i)) % MOD;
        }
        
        // 二分查找最长回文长度
        int left = 1, right = n;
        String result = s.substring(0, 1);
        
        while (left <= right) {
            int mid = (left + right) / 2;
            String palindrome = findPalindromeOfLength(s, mid, prefixHash, suffixHash, power);
            
            if (palindrome != null) {
                result = palindrome;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        
        return result;
    }
    
    private String findPalindromeOfLength(String s, int len, long[] prefixHash, 
                                         long[] suffixHash, long[] power) {
        int n = s.length();
        
        for (int i = 0; i <= n - len; i++) {
            if (isPalindromeByHash(i, i + len - 1, prefixHash, suffixHash, power, n)) {
                return s.substring(i, i + len);
            }
        }
        
        return null;
    }
    
    private boolean isPalindromeByHash(int left, int right, long[] prefixHash, 
                                      long[] suffixHash, long[] power, int n) {
        // 计算子串的前缀哈希
        long leftHash = (prefixHash[right + 1] - prefixHash[left] * power[right - left + 1] % MOD + MOD) % MOD;
        
        // 计算子串的后缀哈希
        int suffixStart = n - right - 1;
        int suffixEnd = n - left - 1;
        long rightHash = (suffixHash[suffixEnd + 1] - suffixHash[suffixStart] * power[right - left + 1] % MOD + MOD) % MOD;
        
        return leftHash == rightHash;
    }
}
```

### 复杂度分析
**时间复杂度：** O(n log n)

+ 预处理哈希：O(n)
+ 二分查找：O(log n)
+ 每次长度检查：O(n)
+ 总体：O(n log n)

**空间复杂度：** O(n)

+ 哈希数组：O(n)

**注意：** 哈希方法存在哈希冲突的风险，理论上可能出现误判。

## 🎯 核心结论
### 滑动窗口的适用性分析
**❌**** 传统滑动窗口不适用的原因：**

1. **缺乏单调性**：无法定义明确的窗口扩展/收缩条件
2. **回文判断的全局性**：需要检查整个子串，无法局部累积
3. **无法避免重复计算**：每次都需要完整的回文检查

**✅**** 可以考虑的变种思路：**

1. **固定长度滑动窗口**：枚举长度 + 滑动检查
2. **滑动窗口 + 哈希优化**：快速回文判断
3. **滑动窗口 + 二分查找**：优化长度枚举

### 实际应用建议
**对于最长回文子串问题：**

1. **面试推荐**：中心扩展法（简洁、高效、易理解）
2. **学习目的**：动态规划（理解区间DP思想）
3. **性能要求**：Manacher算法（线性时间）
4. **特殊场景**：哈希方法（多次查询时预处理有优势）

**滑动窗口更适合的问题：**

+ 最长无重复字符子串
+ 最小覆盖子串
+ 滑动窗口最大值
+ 子数组和等于K的个数

## 📚 相关问题扩展
### 滑动窗口的经典应用
1. **最长无重复字符子串（LeetCode 3）**

```java
public int lengthOfLongestSubstring(String s) {
    Set<Character> window = new HashSet<>();
    int left = 0, maxLen = 0;
    
    for (int right = 0; right < s.length(); right++) {
        while (window.contains(s.charAt(right))) {
            window.remove(s.charAt(left++));
        }
        window.add(s.charAt(right));
        maxLen = Math.max(maxLen, right - left + 1);
    }
    
    return maxLen;
}
```

2. **最小覆盖子串（LeetCode 76）**

```java
public String minWindow(String s, String t) {
    Map<Character, Integer> need = new HashMap<>();
    Map<Character, Integer> window = new HashMap<>();
    
    for (char c : t.toCharArray()) {
        need.put(c, need.getOrDefault(c, 0) + 1);
    }
    
    int left = 0, right = 0;
    int valid = 0;
    int start = 0, len = Integer.MAX_VALUE;
    
    while (right < s.length()) {
        char c = s.charAt(right);
        right++;
        
        if (need.containsKey(c)) {
            window.put(c, window.getOrDefault(c, 0) + 1);
            if (window.get(c).equals(need.get(c))) {
                valid++;
            }
        }
        
        while (valid == need.size()) {
            if (right - left < len) {
                start = left;
                len = right - left;
            }
            
            char d = s.charAt(left);
            left++;
            
            if (need.containsKey(d)) {
                if (window.get(d).equals(need.get(d))) {
                    valid--;
                }
                window.put(d, window.get(d) - 1);
            }
        }
    }
    
    return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
}
```
