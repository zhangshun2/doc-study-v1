# 5.1 动态规划入门 - 爬楼梯例题详解 (Java版本)
> 从最简单的DP题目开始，详细讲解动态规划的思考过程
>

## 🎯 为什么从爬楼梯开始？
很多人觉得动态规划难，主要原因是：

1. **抽象思维**：需要将问题抽象成状态和转移
2. **递推关系**：需要找到当前状态与之前状态的关系
3. **边界条件**：需要正确设置初始状态

但是，动态规划其实有固定的思考模式，掌握了就不难了！

---

## 📚 题目：70-爬楼梯 (最简单的DP入门)
### 🔍 题目描述
假设你正在爬楼梯。需要 n 阶你才能到达楼顶。  
每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**示例：**

+ 输入：n = 2
+ 输出：2
+ 解释：有两种方法可以爬到楼顶
    1. 1 阶 + 1 阶
    2. 2 阶

### 🤔 第一步：理解问题本质
**关键问题：到达第n阶有多少种方法？**

让我们从小规模开始思考：

+ n=1：只有1种方法 (直接爬1阶)
+ n=2：有2种方法 (1+1 或 直接爬2阶)
+ n=3：有几种方法？

**重要发现：**  
要到达第3阶，只能从两个地方来：

1. 从第1阶爬2步
2. 从第2阶爬1步

所以：`到达第3阶的方法数 = 到达第1阶的方法数 + 到达第2阶的方法数`

### 💡 第二步：找到递推关系
**核心发现：**

```plain
到达第n阶的方法数 = 到达第(n-1)阶的方法数 + 到达第(n-2)阶的方法数
```

**为什么？**

+ 要到第n阶，最后一步只能是爬1阶或爬2阶
+ 如果最后爬1阶，那么之前必须在第(n-1)阶
+ 如果最后爬2阶，那么之前必须在第(n-2)阶

**数学表达式：**

```plain
f(n) = f(n-1) + f(n-2)
```

### 🎯 第三步：确定边界条件
**基础情况：**

+ f(1) = 1 (只有1种方法)
+ f(2) = 2 (有2种方法)

**验证：**

+ f(3) = f(2) + f(1) = 2 + 1 = 3
    - 方法1：1+1+1
    - 方法2：1+2
    - 方法3：2+1
+ f(4) = f(3) + f(2) = 3 + 2 = 5
    - 方法1：1+1+1+1
    - 方法2：1+1+2
    - 方法3：1+2+1
    - 方法4：2+1+1
    - 方法5：2+2

### 🔧 第四步：代码实现
#### 方法1：递归（会超时，但帮助理解）
```java
public class Solution {
    public int climbStairs(int n) {
        // 边界条件
        if (n == 1) {
            return 1;
        }
        if (n == 2) {
            return 2;
        }
        
        // 递推关系
        return climbStairs(n - 1) + climbStairs(n - 2);
    }
}
```

**问题：**这种方法会重复计算很多子问题，时间复杂度是O(2^n)，太慢了！

#### 方法2：动态规划（推荐）
```java
public class Solution {
    public int climbStairs(int n) {
        // 特殊情况处理
        if (n == 1) {
            return 1;
        }
        if (n == 2) {
            return 2;
        }
        
        // 创建dp数组
        int[] dp = new int[n + 1];
        
        // 设置边界条件
        dp[1] = 1;
        dp[2] = 2;
        
        // 填充dp数组
        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        
        return dp[n];
    }
}
```

#### 方法3：空间优化（最优）
```java
public class Solution {
    public int climbStairs(int n) {
        if (n == 1) {
            return 1;
        }
        if (n == 2) {
            return 2;
        }
        
        // 只需要记录前两个状态
        int prev2 = 1;  // f(n-2)
        int prev1 = 2;  // f(n-1)
        
        for (int i = 3; i <= n; i++) {
            int current = prev1 + prev2;  // f(n) = f(n-1) + f(n-2)
            prev2 = prev1;  // 更新f(n-2)
            prev1 = current;  // 更新f(n-1)
        }
        
        return prev1;
    }
}
```

### 📊 复杂度分析
+ **时间复杂度：** O(n)
+ **空间复杂度：** O(1) (优化后)

---

## 🎯 关键思路总结
### 💡 DP四步解题法
1. **状态定义**：dp[i] = 到达第i阶的方法数
2. **状态转移**：dp[i] = dp[i-1] + dp[i-2]
3. **边界条件**：dp[1] = 1, dp[2] = 2
4. **计算顺序**：从小到大

### 🔧 Java编程要点
1. **边界检查**：处理n=1, n=2的特殊情况
2. **空间优化**：只保存必要的前置状态
3. **代码风格**：清晰的变量命名和注释
