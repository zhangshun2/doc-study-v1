## 🎯 DP到底是什么？
### 💡 DP的全称和基本含义
**DP = Dynamic Programming（动态规划）**

+ **Dynamic（动态）**：不是指"运行时动态"，而是指"阶段性决策"
+ **Programming（规划）**：不是指"编程"，而是指"规划、计划"
+ **整体含义**：通过阶段性的最优决策来解决复杂问题的方法

### 🔍 DP的历史由来
**创始人：** Richard Bellman（1950年代）

**命名原因：**

+ Bellman在兰德公司工作时，需要一个听起来"高大上"的名字
+ "Dynamic"听起来很现代化
+ "Programming"在当时指的是"规划"而非"编程"
+ 这个名字能让政府官员觉得这是重要的数学研究

**有趣事实：** 如果按现代理解，DP更应该叫"递推优化"或"记忆化计算"！

## 🎯 DP vs 动态规划：是同一个概念吗？
### ✅ 答案：是的，完全相同
**DP就是动态规划的英文缩写：**

+ DP = Dynamic Programming
+ 动态规划 = DP的中文翻译
+ 在算法竞赛和编程中，通常直接说"DP"

### 📚 为什么大家更喜欢说"DP"？
1. **简洁性**：DP比"动态规划"更短更方便
2. **国际化**：算法竞赛中英文术语更通用
3. **专业性**：DP听起来更专业
4. **习惯性**：程序员习惯用英文缩写

### 🔧 常见的DP相关术语
```java
// 这些说法都是指同一个东西：
"DP"           = "动态规划"
"DP数组"       = "动态规划数组"
"DP状态"       = "动态规划状态"
"DP转移"       = "状态转移方程"
"DP优化"       = "动态规划优化"
```

## 🎯 DP的分类体系
### 📋 按问题维度分类
#### 1. **一维DP（线性DP）**
```java
// 例子：爬楼梯、打家劫舍
int[] dp = new int[n];
for (int i = 1; i < n; i++) {
    dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]);
}
```

#### 2. **二维DP**
```java
// 例子：最小路径和、编辑距离
int[][] dp = new int[m][n];
for (int i = 1; i < m; i++) {
    for (int j = 1; j < n; j++) {
        dp[i][j] = Math.min(dp[i-1][j], dp[i][j-1]) + grid[i][j];
    }
}
```

#### 3. **三维及高维DP**
```java
// 例子：背包问题的变种
int[][][] dp = new int[n][w][k];
// dp[i][j][k] = 前i个物品，重量不超过j，选择不超过k个的最大价值
```

### 📋 按状态表示分类
#### 1. **普通DP**
```java
// 状态用数组下标直接表示
dp[i] = 到第i个位置的最优值
```

#### 2. **状态压缩DP（状压DP）**
```java
// 状态用二进制位表示
dp[mask] = 状态为mask时的最优值
// mask的每一位表示某个元素是否被选择
```

## 🎯 状压DP详解
### 💡 什么是状压DP？
**状压DP = 状态压缩动态规划**

**核心思想：**

+ 用二进制数的每一位来表示某个元素的状态（选择/不选择）
+ 将复杂的状态组合压缩成一个整数
+ 适用于元素数量较少（通常≤20）的问题

### 🔍 状压DP的应用场景
1. **集合问题**：需要记录哪些元素被选择
2. **排列组合**：需要记录哪些位置被占用
3. **图论问题**：需要记录哪些节点被访问
4. **棋盘问题**：需要记录棋盘的某种状态

### 🔧 状压DP的基本操作
#### 1. **状态表示**
```java
// 假设有4个元素，用4位二进制表示
// 1010 表示选择了第1和第3个元素（从右往左数，从0开始）
int mask = 0b1010;  // 二进制表示
int mask = 10;      // 十进制表示
```

#### 2. **位运算操作**
```java
// 检查第i位是否为1（元素i是否被选择）
boolean isSelected = (mask & (1 << i)) != 0;

// 将第i位设为1（选择元素i）
int newMask = mask | (1 << i);

// 将第i位设为0（取消选择元素i）
int newMask = mask & ~(1 << i);

// 翻转第i位
int newMask = mask ^ (1 << i);

// 获取mask中1的个数（被选择的元素个数）
int count = Integer.bitCount(mask);
```

### 📚 状压DP经典例题
#### 例题1：旅行商问题（TSP）
```java
public class TSP {
    public int tsp(int[][] dist) {
        int n = dist.length;
        // dp[mask][i] = 访问了mask中的城市，当前在城市i的最小代价
        int[][] dp = new int[1 << n][n];
        
        // 初始化
        Arrays.fill(dp[0], Integer.MAX_VALUE);
        dp[1][0] = 0;  // 从城市0开始
        
        // 状态转移
        for (int mask = 1; mask < (1 << n); mask++) {
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) == 0) continue;
                
                for (int j = 0; j < n; j++) {
                    if (i == j || (mask & (1 << j)) == 0) continue;
                    
                    int prevMask = mask ^ (1 << i);
                    if (dp[prevMask][j] != Integer.MAX_VALUE) {
                        dp[mask][i] = Math.min(dp[mask][i], 
                                             dp[prevMask][j] + dist[j][i]);
                    }
                }
            }
        }
        
        // 返回访问所有城市回到起点的最小代价
        int result = Integer.MAX_VALUE;
        int allVisited = (1 << n) - 1;
        for (int i = 1; i < n; i++) {
            if (dp[allVisited][i] != Integer.MAX_VALUE) {
                result = Math.min(result, dp[allVisited][i] + dist[i][0]);
            }
        }
        
        return result;
    }
}
```

#### 例题2：分配任务
```java
public class AssignTasks {
    public int assignTasks(int[][] cost) {
        int n = cost.length;
        // dp[mask] = 分配了mask中的任务的最小代价
        int[] dp = new int[1 << n];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        
        for (int mask = 0; mask < (1 << n); mask++) {
            if (dp[mask] == Integer.MAX_VALUE) continue;
            
            int person = Integer.bitCount(mask);  // 当前分配到第几个人
            if (person >= n) continue;
            
            for (int task = 0; task < n; task++) {
                if ((mask & (1 << task)) == 0) {  // 任务task还没被分配
                    int newMask = mask | (1 << task);
                    dp[newMask] = Math.min(dp[newMask], 
                                          dp[mask] + cost[person][task]);
                }
            }
        }
        
        return dp[(1 << n) - 1];  // 所有任务都被分配
    }
}
```

### 📊 状压DP的复杂度分析
**时间复杂度：** O(2^n × n × 转移复杂度)  
**空间复杂度：** O(2^n × 状态维度)

**适用范围：** n ≤ 20（因为2^20 ≈ 100万）

### 🔧 3. 树形DP
```java
public class TreeDP {
    public int treeDP(TreeNode root) {
        if (root == null) return 0;
        
        // dp[0] = 不选择当前节点的最大值
        // dp[1] = 选择当前节点的最大值
        int[] result = dfs(root);
        return Math.max(result[0], result[1]);
    }
    
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};
        
        int[] left = dfs(node.left);
        int[] right = dfs(node.right);
        
        int notSelect = Math.max(left[0], left[1]) + Math.max(right[0], right[1]);
        int select = node.val + left[0] + right[0];
        
        return new int[]{notSelect, select};
    }
}
```

### 🔧 4. 区间DP
```java
public class IntervalDP {
    public int intervalDP(int[] nums) {
        int n = nums.length;
        // dp[i][j] = 区间[i,j]的最优值
        int[][] dp = new int[n][n];
        
        // 按区间长度从小到大计算
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;
                for (int k = i; k < j; k++) {
                    dp[i][j] = Math.max(dp[i][j], 
                                       dp[i][k] + dp[k+1][j] + cost(i, k, j));
                }
            }
        }
        
        return dp[0][n-1];
    }
}
```

## 🎯 DP学习建议
### 📚 学习顺序
1. **基础线性DP**：爬楼梯、打家劫舍
2. **二维DP**：路径问题、编辑距离
3. **背包DP**：0-1背包、完全背包
4. **状压DP**：集合问题、排列问题
5. **树形DP**：树上问题
6. **区间DP**：区间合并问题

### 🔧 掌握要点
1. **状态设计**：如何定义状态才能覆盖所有情况
2. **转移方程**：如何从子问题推导出当前问题
3. **边界处理**：如何正确设置初始状态
4. **优化技巧**：如何降低时间和空间复杂度

### 💡 常见误区
1. **状态定义不清**：dp[i]到底表示什么要明确
2. **转移遗漏**：没有考虑所有可能的转移情况
3. **边界错误**：初始状态设置不正确
4. **优化过度**：为了优化而优化，导致代码难懂
