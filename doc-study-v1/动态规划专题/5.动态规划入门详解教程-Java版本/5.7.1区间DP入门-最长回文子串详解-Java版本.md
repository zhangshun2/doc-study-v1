# 5.7.1 区间DP入门-最长回文子串详解-Java版本
## 📋 题目描述
**LeetCode 5. 最长回文子串 (Longest Palindromic Substring)**

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

**回文串定义：** 如果字符串正着读和倒着读都一样，那么这个字符串就是回文串。

### 示例
**示例 1：**

```plain
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

**示例 2：**

```plain
输入：s = "cbbd"
输出："bb"
```

**示例 3：**

```plain
输入：s = "a"
输出："a"
```

**约束条件：**

+ `1 <= s.length <= 1000`
+ `s` 仅由数字和英文字母组成

---

## 🔍 问题分析与解法概览
### 问题特点
1. **子串问题**：需要考虑所有可能的子串
2. **回文特性**：具有对称性质
3. **最优化目标**：找到最长的满足条件的子串

### 解法对比
| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
| --- | --- | --- | --- |
| 暴力枚举 | O(n³) | O(1) | 简单直接，效率低 |
| 中心扩展 | O(n²) | O(1) | 直观易懂，空间最优 |
| 动态规划 | O(n²) | O(n²) | 区间DP经典应用 |
| Manacher算法 | O(n) | O(n) | 最优解，实现复杂 |

## 💻 方法一：动态规划（区间DP）
### 核心思想
**区间DP的特点：**

+ 状态表示一个区间的性质
+ 通过较小区间推导较大区间
+ 适合处理子串、子序列问题

### 六步分析法
#### 第一步：问题具体化
**关键观察：**

+ 回文串的子串去掉首尾字符后仍是回文串
+ 单个字符一定是回文串
+ 两个相同字符组成的字符串是回文串

#### 第二步：递归思维分解
**递归关系：**

```plain
isP(i, j) = {
    true,                           if i >= j
    s[i] == s[j] && isP(i+1, j-1), if i < j
}
```

#### 第三步：状态定义
**状态选择：**  
`dp[i][j]` = 字符串 `s` 从索引 `i` 到 `j` 的子串是否为回文串

**状态含义：**

+ `dp[i][j] = true`：`s[i...j]` 是回文串
+ `dp[i][j] = false`：`s[i...j]` 不是回文串

#### 第四步：状态转移方程
**核心转移：**

```java
if (s.charAt(i) == s.charAt(j)) {
    if (j - i <= 2) {
        dp[i][j] = true;  // 长度为1、2、3的特殊情况
    } else {
        dp[i][j] = dp[i+1][j-1];  // 依赖内部子串
    }
} else {
    dp[i][j] = false;  // 首尾不同，必不是回文
}
```

#### 第五步：边界条件
1. **单字符**：`dp[i][i] = true`（长度为1）
2. **双字符**：`dp[i][i+1] = (s[i] == s[i+1])`（长度为2）
3. **三字符**：`dp[i][i+2] = (s[i] == s[i+2])`（长度为3）

#### 第六步：计算顺序与结果提取
**计算顺序：**

+ 按子串长度从小到大计算
+ 或者按对角线方向计算
+ 保证计算 `dp[i][j]` 时，`dp[i+1][j-1]` 已计算

**结果提取：**

+ 在计算过程中记录最长回文子串的起始位置和长度

### 代码实现
```java
public class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }
        
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        
        // 记录最长回文子串的起始位置和长度
        int start = 0;
        int maxLen = 1;
        
        // 初始化：所有单字符都是回文
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;
        }
        
        // 按子串长度递增的顺序计算
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i <= n - len; i++) {
                int j = i + len - 1;  // 子串结束位置
                
                if (s.charAt(i) == s.charAt(j)) {
                    if (len <= 3) {
                        // 长度为2或3的特殊情况
                        dp[i][j] = true;
                    } else {
                        // 依赖内部子串
                        dp[i][j] = dp[i + 1][j - 1];
                    }
                    
                    // 更新最长回文子串
                    if (dp[i][j] && len > maxLen) {
                        start = i;
                        maxLen = len;
                    }
                } else {
                    dp[i][j] = false;
                }
            }
        }
        
        return s.substring(start, start + maxLen);
    }
}
```

### 优化版本（按对角线计算）
```java
public class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }
        
        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        int start = 0, maxLen = 1;
        
        // 按对角线方向计算
        for (int gap = 0; gap < n; gap++) {
            for (int i = 0; i + gap < n; i++) {
                int j = i + gap;
                
                if (gap == 0) {
                    // 单字符
                    dp[i][j] = true;
                } else if (gap == 1) {
                    // 双字符
                    dp[i][j] = (s.charAt(i) == s.charAt(j));
                } else {
                    // 多字符
                    dp[i][j] = (s.charAt(i) == s.charAt(j)) && dp[i + 1][j - 1];
                }
                
                // 更新最长回文子串
                if (dp[i][j] && gap + 1 > maxLen) {
                    start = i;
                    maxLen = gap + 1;
                }
            }
        }
        
        return s.substring(start, start + maxLen);
    }
}
```

## 💻 方法二：中心扩展法
### 核心思想
**观察：** 回文串具有中心对称性，可以从中心向两边扩展

**两种情况：**

1. **奇数长度回文**：以单个字符为中心
2. **偶数长度回文**：以两个字符之间为中心

### 代码实现
```java
public class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }
        
        int start = 0, maxLen = 1;
        
        for (int i = 0; i < s.length(); i++) {
            // 奇数长度回文：以i为中心
            int len1 = expandAroundCenter(s, i, i);
            // 偶数长度回文：以i和i+1之间为中心
            int len2 = expandAroundCenter(s, i, i + 1);
            
            int len = Math.max(len1, len2);
            if (len > maxLen) {
                maxLen = len;
                start = i - (len - 1) / 2;
            }
        }
        
        return s.substring(start, start + maxLen);
    }
    
    private int expandAroundCenter(String s, int left, int right) {
        while (left >= 0 && right < s.length() && 
               s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;  // 返回回文长度
    }
}
```

## 💻 方法三：Manacher算法（进阶）
### 核心思想
**预处理：** 在每个字符间插入特殊字符，统一处理奇偶长度  
**优化：** 利用回文的对称性，避免重复计算

### 代码实现
```java
public class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }
        
        // 预处理：插入特殊字符
        String processed = preprocess(s);
        int n = processed.length();
        int[] P = new int[n];  // P[i]表示以i为中心的回文半径
        int center = 0, right = 0;  // 当前回文的中心和右边界
        
        int maxLen = 0, centerIndex = 0;
        
        for (int i = 0; i < n; i++) {
            // 利用对称性
            int mirror = 2 * center - i;
            
            if (i < right) {
                P[i] = Math.min(right - i, P[mirror]);
            }
            
            // 尝试扩展
            try {
                while (processed.charAt(i + P[i] + 1) == 
                       processed.charAt(i - P[i] - 1)) {
                    P[i]++;
                }
            } catch (StringIndexOutOfBoundsException e) {
                // 边界处理
            }
            
            // 更新中心和右边界
            if (i + P[i] > right) {
                center = i;
                right = i + P[i];
            }
            
            // 更新最长回文
            if (P[i] > maxLen) {
                maxLen = P[i];
                centerIndex = i;
            }
        }
        
        // 提取原始字符串中的回文
        int start = (centerIndex - maxLen) / 2;
        return s.substring(start, start + maxLen);
    }
    
    private String preprocess(String s) {
        StringBuilder sb = new StringBuilder();
        sb.append('^');  // 开始标记
        for (char c : s.toCharArray()) {
            sb.append('#').append(c);
        }
        sb.append('#').append('$');  // 结束标记
        return sb.toString();
    }
}
```

## 🧠 区间DP的核心思想
### 什么是区间DP？
**定义：** 区间动态规划是一种特殊的动态规划方法，用于解决区间上的最优化问题。

**特点：**

1. **状态表示区间**：`dp[i][j]` 表示区间 `[i,j]` 的某种性质
2. **区间合并**：大区间的解由小区间的解合并得到
3. **计算顺序**：按区间长度从小到大计算

### 区间DP的通用模板
```java
// 初始化
for (int i = 0; i < n; i++) {
    dp[i][i] = baseCase;  // 长度为1的区间
}

// 按区间长度递增
for (int len = 2; len <= n; len++) {
    for (int i = 0; i <= n - len; i++) {
        int j = i + len - 1;
        
        // 状态转移
        for (int k = i; k < j; k++) {
            dp[i][j] = optimize(dp[i][j], 
                              combine(dp[i][k], dp[k+1][j]));
        }
    }
}
```

### 区间DP的经典应用
1. **最长回文子串**：判断区间是否为回文
2. **矩阵链乘法**：最优加括号方案
3. **石子合并**：最小合并代价
4. **回文子序列**：最长回文子序列长度
5. **括号匹配**：合法括号序列计数

### 1. 回文子序列（LeetCode 516）
```java
public int longestPalindromeSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    
    // 单字符的回文长度为1
    for (int i = 0; i < n; i++) {
        dp[i][i] = 1;
    }
    
    // 按区间长度递增
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            
            if (s.charAt(i) == s.charAt(j)) {
                dp[i][j] = dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }
    
    return dp[0][n - 1];
}
```

### 2. 分割回文串（LeetCode 131）
```java
public List<List<String>> partition(String s) {
    int n = s.length();
    boolean[][] isPalindrome = new boolean[n][n];
    
    // 预处理：计算所有子串是否为回文
    for (int len = 1; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            if (len == 1) {
                isPalindrome[i][j] = true;
            } else if (len == 2) {
                isPalindrome[i][j] = (s.charAt(i) == s.charAt(j));
            } else {
                isPalindrome[i][j] = (s.charAt(i) == s.charAt(j)) && 
                                    isPalindrome[i + 1][j - 1];
            }
        }
    }
    
    List<List<String>> result = new ArrayList<>();
    backtrack(s, 0, new ArrayList<>(), result, isPalindrome);
    return result;
}

private void backtrack(String s, int start, List<String> path, 
                      List<List<String>> result, boolean[][] isPalindrome) {
    if (start == s.length()) {
        result.add(new ArrayList<>(path));
        return;
    }
    
    for (int end = start; end < s.length(); end++) {
        if (isPalindrome[start][end]) {
            path.add(s.substring(start, end + 1));
            backtrack(s, end + 1, path, result, isPalindrome);
            path.remove(path.size() - 1);
        }
    }
}
```

### 3. 最短回文串（LeetCode 214）
```java
public String shortestPalindrome(String s) {
    if (s == null || s.length() <= 1) {
        return s;
    }
    
    // 找到从开头开始的最长回文前缀
    int end = findLongestPalindromePrefix(s);
    
    // 将后缀反转后添加到前面
    String suffix = s.substring(end + 1);
    String reversedSuffix = new StringBuilder(suffix).reverse().toString();
    
    return reversedSuffix + s;
}

private int findLongestPalindromePrefix(String s) {
    int n = s.length();
    for (int end = n - 1; end >= 0; end--) {
        if (isPalindrome(s, 0, end)) {
            return end;
        }
    }
    return 0;
}

private boolean isPalindrome(String s, int left, int right) {
    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
```

## ⚠️ 常见错误与注意事项
### 1. 状态转移边界处理
**错误示例：**

```java
// ❌ 没有处理长度为2和3的特殊情况
if (s.charAt(i) == s.charAt(j)) {
    dp[i][j] = dp[i + 1][j - 1];  // 当j-i=1时，i+1>j-1
}
```

**正确处理：**

```java
// ✅ 正确处理边界
if (s.charAt(i) == s.charAt(j)) {
    if (j - i <= 2) {
        dp[i][j] = true;  // 长度≤3时直接判断
    } else {
        dp[i][j] = dp[i + 1][j - 1];
    }
}
```

### 2. 计算顺序错误
**错误示例：**

```java
// ❌ 错误的计算顺序
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        dp[i][j] = dp[i + 1][j - 1];  // dp[i+1][j-1]可能未计算
    }
}
```

**正确顺序：**

```java
// ✅ 按长度递增计算
for (int len = 2; len <= n; len++) {
    for (int i = 0; i <= n - len; i++) {
        int j = i + len - 1;
        // 此时dp[i+1][j-1]已经计算过
    }
}
```

### 3. 中心扩展的边界检查
**错误示例：**

```java
// ❌ 缺少边界检查
while (s.charAt(left) == s.charAt(right)) {
    left--;
    right++;  // 可能越界
}
```

**正确处理：**

```java
// ✅ 完整的边界检查
while (left >= 0 && right < s.length() && 
       s.charAt(left) == s.charAt(right)) {
    left--;
    right++;
}
```
