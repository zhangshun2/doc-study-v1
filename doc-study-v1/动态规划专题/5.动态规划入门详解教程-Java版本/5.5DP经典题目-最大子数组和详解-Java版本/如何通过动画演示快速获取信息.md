很遗憾，**VisuAlgo（https://visualgo.net/）不支持用户上传或运行自定义代码**。它是一个**预设算法教学可视化平台**，只提供内置算法（如排序、图遍历、最大子数组等）的固定演示，你无法粘贴自己的 Kadane 算法实现让它动态跑。

但它对 **“最大子数组和”** 有专门的可视化模块，你可以手动输入数组，看到标准 Kadane 算法的执行过程（包括 `current` 和 `globalMax` 的变化），这已经非常接近你想看的“蛇形断尾重生”效果。

### ✅ 如何使用 VisuAlgo 查看最大子数组动画？

1. 打开：[https://visualgo.net/en](https://visualgo.net/en)
2. 在顶部菜单选择 **"Maximum Subarray"**（可能在 "Others" 分类下）
   - 或直接访问（如果链接有效）：  
     https://visualgo.net/en/maxsubarray
3. 点击 **"Create"** 输入你的数组，例如：`[-2, 1, -3, 4, -1, 2, 1, -5, 4]`
4. 点击 **"Run"** 或逐步点击 **"Next"**，你会看到：
   - 当前窗口（以 i 结尾的子数组）
   - `current_sum` 和 `best_sum` 的实时更新
   - 高亮显示当前最优子数组

> 💡 这就是你所说的“current 像一条蛇”——当 `current_sum < 0` 时，它会“重置起点”，视觉上就像蛇断掉旧尾巴，从新位置开始生长。

### 🔁 如果你想**运行自己的代码并可视化**，可以考虑以下替代方案：

#### 方案 1：用 Python + Matplotlib 自制动画（推荐！）
你可以写一个带打印/绘图的 Kadane 实现，每一步输出状态：

```python
def kadane_visual(nums):
    current = nums[0]
    global_max = nums[0]
    print(f"i=0: num={nums[0]}, current={current}, global_max={global_max}")
    
    for i in range(1, len(nums)):
        if current < 0:
            print(f"  -> current < 0, restart from {nums[i]}")
        current = max(nums[i], current + nums[i])
        global_max = max(global_max, current)
        print(f"i={i}: num={nums[i]}, current={current}, global_max={global_max}")

# 测试
kadane_visual([-2, 1, -3, 4, -1, 2, 1, -5, 4])
```

输出示例：
```
i=0: num=-2, current=-2, global_max=-2
  -> current < 0, restart from 1
i=1: num=1, current=1, global_max=1
  -> current > 0, extend
i=2: num=-3, current=-2, global_max=1
  -> current < 0, restart from 4
i=3: num=4, current=4, global_max=4
...
```

这种“叙事式输出”能让你清晰看到决策点，比背代码有意义得多。
