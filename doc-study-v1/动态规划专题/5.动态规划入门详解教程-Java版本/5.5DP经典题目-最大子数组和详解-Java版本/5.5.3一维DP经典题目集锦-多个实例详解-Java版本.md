## 🏠 题目1：打家劫舍 (LeetCode 198)
### 题目描述
你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你**不触动警报装置的情况下**，一夜之间能够偷窃到的最高金额。

```plain
示例 1：
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。

示例 2：
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

### 六步分析法
#### 第一步：题目具体化
+ **目标**：最大金额
+ **约束**：不能偷相邻房屋
+ **操作**：每个房屋选择偷或不偷

#### 第二步：递归分解
考虑第i个房屋：

+ 偷第i个：不能偷第i-1个，最大金额 = dp[i-2] + nums[i]
+ 不偷第i个：可以偷第i-1个，最大金额 = dp[i-1]

#### 第三步：状态定义
```java
dp[i] = 考虑前i个房屋能偷到的最大金额
```

#### 第四步：状态转移方程
```java
dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i])
```

#### 第五步：边界条件
```java
dp[0] = nums[0]
dp[1] = Math.max(nums[0], nums[1])
```

#### 第六步：代码实现
```java
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    
    int[] dp = new int[nums.length];
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);
    
    for (int i = 2; i < nums.length; i++) {
        dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]);
    }
    
    return dp[nums.length - 1];
}

// 空间优化版本
public int robOptimized(int[] nums) {
    if (nums.length == 1) return nums[0];
    
    int prev2 = nums[0];
    int prev1 = Math.max(nums[0], nums[1]);
    
    for (int i = 2; i < nums.length; i++) {
        int current = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = current;
    }
    
    return prev1;
}
```

## 🔢 题目2：解码方法 (LeetCode 91)
### 题目描述
一条包含字母 A-Z 的消息通过以下映射进行了编码：

```plain
'A' -> "1"
'B' -> "2"
...
'Z' -> "26"
```

要解码已编码的消息，所有数字必须基于上述映射的方法，反向映射回字母（可能有多种方法）。给你一个只含数字的非空字符串 s ，请计算并返回解码方法的总数。

```plain
示例 1：
输入：s = "12"
输出：2
解释：它可以解码为 "AB"（1 2）或者 "L"（12）。

示例 2：
输入：s = "226"
输出：3
解释：它可以解码为 "BZ" (2 26), "VF" (22 6), 或者 "BBF" (2 2 6) 。
```

### 六步分析法
#### 第一步：题目具体化
+ **目标**：解码方法总数
+ **约束**：数字1-26对应字母A-Z
+ **操作**：选择单个数字或两个数字组合

#### 第二步：递归分解
考虑字符串s[0...i]：

+ 单独解码s[i]：如果s[i] != '0'，方法数 = dp[i-1]
+ 组合解码s[i-1]s[i]：如果10 <= s[i-1]s[i] <= 26，方法数 = dp[i-2]

#### 第三步：状态定义
```java
dp[i] = 字符串s[0...i]的解码方法数
```

#### 第四步：状态转移方程
```java
dp[i] = 0;
if (s[i] != '0') dp[i] += dp[i-1];  // 单独解码
if (s[i-1] != '0' && Integer.parseInt(s.substring(i-1, i+1)) <= 26) {
    dp[i] += dp[i-2];  // 组合解码
}
```

#### 第五步：边界条件
```java
dp[0] = s[0] != '0' ? 1 : 0;
```

#### 第六步：代码实现
```java
public int numDecodings(String s) {
    if (s.charAt(0) == '0') return 0;
    
    int n = s.length();
    int[] dp = new int[n];
    dp[0] = 1;
    
    for (int i = 1; i < n; i++) {
        // 单独解码当前字符
        if (s.charAt(i) != '0') {
            dp[i] += dp[i-1];
        }
        
        // 组合解码前两个字符
        int twoDigit = Integer.parseInt(s.substring(i-1, i+1));
        if (twoDigit >= 10 && twoDigit <= 26) {
            dp[i] += (i >= 2) ? dp[i-2] : 1;
        }
    }
    
    return dp[n-1];
}
```

## 📈 题目3：乘积最大子数组 (LeetCode 152)
### 题目描述
给你一个整数数组 nums ，请你找出数组中乘积最大的连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

```plain
示例 1:
输入: [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。

示例 2:
输入: [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是子数组。
```

### 六步分析法
#### 第一步：题目具体化
+ **目标**：最大乘积
+ **约束**：连续子数组
+ **特殊性**：负数乘负数变正数

#### 第二步：递归分解
考虑以nums[i]结尾的子数组：

+ 需要同时维护最大值和最小值（负数可能变最大）

#### 第三步：状态定义
```java
maxDP[i] = 以nums[i]结尾的最大乘积
minDP[i] = 以nums[i]结尾的最小乘积
```

#### 第四步：状态转移方程
```java
if (nums[i] >= 0) {
    maxDP[i] = Math.max(nums[i], maxDP[i-1] * nums[i]);
    minDP[i] = Math.min(nums[i], minDP[i-1] * nums[i]);
} else {
    maxDP[i] = Math.max(nums[i], minDP[i-1] * nums[i]);
    minDP[i] = Math.min(nums[i], maxDP[i-1] * nums[i]);
}
```

#### 第五步：边界条件
```java
maxDP[0] = nums[0];
minDP[0] = nums[0];
```

#### 第六步：代码实现
```java
public int maxProduct(int[] nums) {
    int n = nums.length;
    int maxDP = nums[0], minDP = nums[0];
    int result = nums[0];
    
    for (int i = 1; i < n; i++) {
        if (nums[i] < 0) {
            // 交换最大最小值
            int temp = maxDP;
            maxDP = minDP;
            minDP = temp;
        }
        
        maxDP = Math.max(nums[i], maxDP * nums[i]);
        minDP = Math.min(nums[i], minDP * nums[i]);
        
        result = Math.max(result, maxDP);
    }
    
    return result;
}
```

## 📊 题目4：最长递增子序列 (LeetCode 300)
### 题目描述
给你一个整数数组 nums ，找到其中最长严格递增子序列的长度。

```plain
示例 1：
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,18]，因此长度为 4 。

示例 2：
输入：nums = [0,1,0,3,2,3]
输出：4
```

### 六步分析法
#### 第一步：题目具体化
+ **目标**：最长长度
+ **约束**：严格递增
+ **操作**：选择或跳过元素

#### 第二步：递归分解
考虑以nums[i]结尾的最长递增子序列：

+ 遍历所有j < i，如果nums[j] < nums[i]，可以接在后面

#### 第三步：状态定义
```java
dp[i] = 以nums[i]结尾的最长递增子序列长度
```

#### 第四步：状态转移方程
```java
dp[i] = 1;  // 至少包含自己
for (int j = 0; j < i; j++) {
    if (nums[j] < nums[i]) {
        dp[i] = Math.max(dp[i], dp[j] + 1);
    }
}
```

#### 第五步：边界条件
```java
dp[0] = 1;  // 第一个元素
```

#### 第六步：代码实现
```java
public int lengthOfLIS(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    Arrays.fill(dp, 1);
    
    int maxLength = 1;
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLength = Math.max(maxLength, dp[i]);
    }
    
    return maxLength;
}

// 优化版本：二分查找 O(n log n)
public int lengthOfLISOptimized(int[] nums) {
    List<Integer> tails = new ArrayList<>();
    
    for (int num : nums) {
        int left = 0, right = tails.size();
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (tails.get(mid) < num) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        
        if (left == tails.size()) {
            tails.add(num);
        } else {
            tails.set(left, num);
        }
    }
    
    return tails.size();
}
```

## 💰 题目5：买卖股票的最佳时机 (LeetCode 121)
### 题目描述
给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择某一天买入这只股票，并选择在未来的某一天卖出该股票。设计一个算法来计算你所能获取的最大利润。

```plain
示例 1：
输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
```

### 六步分析法
#### 第一步：题目具体化
+ **目标**：最大利润
+ **约束**：先买后卖，只能交易一次
+ **操作**：选择买入和卖出时机

#### 第二步：递归分解
对于第i天：

+ 可以选择卖出（如果之前买入了）
+ 需要知道之前的最低价格

#### 第三步：状态定义
```java
minPrice = 到第i天为止的最低价格
maxProfit = 到第i天为止的最大利润
```

#### 第四步：状态转移方程
```java
minPrice = Math.min(minPrice, prices[i]);
maxProfit = Math.max(maxProfit, prices[i] - minPrice);
```

#### 第五步：边界条件
```java
minPrice = prices[0];
maxProfit = 0;
```

#### 第六步：代码实现
```java
public int maxProfit(int[] prices) {
    int minPrice = prices[0];
    int maxProfit = 0;
    
    for (int i = 1; i < prices.length; i++) {
        minPrice = Math.min(minPrice, prices[i]);
        maxProfit = Math.max(maxProfit, prices[i] - minPrice);
    }
    
    return maxProfit;
}
```

## 🎯 总结与模式识别
### 常见状态定义模式
| 模式 | 定义 | 适用题目 |
| --- | --- | --- |
| 以i结尾 | `dp[i] = 以第i个元素结尾的最优解` | 最大子数组和、最长递增子序列 |
| 考虑前i个 | `dp[i] = 考虑前i个元素的最优解` | 打家劫舍、爬楼梯 |
| 到达i位置 | `dp[i] = 到达第i个位置的最优解` | 解码方法、股票问题 |
| 维护多状态 | `max[i], min[i] = 第i个位置的最大/最小值` | 乘积最大子数组 |


### 转移方程类型
1. **选择型**：`dp[i] = Math.max(选择, 不选择)`
2. **累加型**：`dp[i] = dp[i-1] + dp[i-2]`
3. **比较型**：`dp[i] = Math.max(dp[i], dp[j] + value)`
4. **更新型**：`dp[i] = update(dp[i-1], current)`

### 学习建议
1. **掌握模式**：识别题目属于哪种类型
2. **状态定义**：明确dp[i]的含义
3. **转移推导**：分析所有可能的转移
4. **边界处理**：注意特殊情况
5. **空间优化**：考虑是否可以优化空间复杂度

通过这些经典题目的练习，你将建立起扎实的一维DP基础！
