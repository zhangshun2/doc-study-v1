## 🔍 DP空间优化的演进过程
### 📋 第一步：标准DP数组（完整版本）
```java
public class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        
        // 完整的DP数组，存储所有状态
        int[] dp = new int[n + 1];
        dp[1] = 1;
        dp[2] = 2;
        
        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i-1] + dp[i-2];
        }
        
        return dp[n];
    }
}
```

**特点：**

+ 空间复杂度：O(n)
+ 保存了所有中间状态
+ 可以查询任意位置的值

### 📋 第二步：滚动数组优化（您的dp[3]思路）
```java
public class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        
        // 只用3个位置的数组，循环使用
        int[] dp = new int[3];
        dp[1] = 1;  // 对应dp[1]
        dp[2] = 2;  // 对应dp[2]
        
        for (int i = 3; i <= n; i++) {
            dp[0] = dp[1] + dp[2];  // 计算新值
            dp[1] = dp[2];          // 更新dp[i-2]
            dp[2] = dp[0];          // 更新dp[i-1]
        }
        
        return dp[2];  // 最终结果
    }
}
```

**特点：**

+ 空间复杂度：O(1)
+ 只保留必要的3个状态
+ 通过位置轮换实现状态更新

### 📋 第三步：变量优化（最简版本）
```java
public class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        
        // 用变量代替数组
        int prev2 = 1;  // dp[i-2]
        int prev1 = 2;  // dp[i-1]
        
        for (int i = 3; i <= n; i++) {
            int current = prev1 + prev2;  // dp[i] = dp[i-1] + dp[i-2]
            prev2 = prev1;                // 更新dp[i-2]
            prev1 = current;              // 更新dp[i-1]
        }
        
        return prev1;
    }
}
```

**特点：**

+ 空间复杂度：O(1)
+ 代码最简洁
+ 语义最清晰

## 🎯 三种方法的本质对比
### 📊 状态转移对比
| 方法 | 状态表示 | 状态转移 | 空间复杂度 |
| --- | --- | --- | --- |
| 完整DP | `dp[i]` | `dp[i] = dp[i-1] + dp[i-2]` | O(n) |
| 滚动数组 | `dp[i%3]` | `dp[i%3] = dp[(i-1)%3] + dp[(i-2)%3]` | O(1) |
| 变量优化 | `prev1, prev2` | `current = prev1 + prev2` | O(1) |


### 🔍 执行过程对比（以n=5为例）
#### 完整DP数组：
```plain
初始: dp = [0, 1, 2, 0, 0, 0]
i=3:  dp = [0, 1, 2, 3, 0, 0]  (dp[3] = dp[2] + dp[1] = 2 + 1 = 3)
i=4:  dp = [0, 1, 2, 3, 5, 0]  (dp[4] = dp[3] + dp[2] = 3 + 2 = 5)
i=5:  dp = [0, 1, 2, 3, 5, 8]  (dp[5] = dp[4] + dp[3] = 5 + 3 = 8)
结果: dp[5] = 8
```

#### 滚动数组（您的dp[3]思路）：
```plain
初始: dp = [0, 1, 2]
i=3:  dp = [3, 2, 3]  (dp[0] = dp[1] + dp[2], 然后轮换)
i=4:  dp = [5, 3, 5]  (dp[0] = dp[1] + dp[2], 然后轮换)
i=5:  dp = [8, 5, 8]  (dp[0] = dp[1] + dp[2], 然后轮换)
结果: dp[2] = 8
```

#### 变量优化：
```plain
初始: prev2=1, prev1=2
i=3:  current=3, prev2=2, prev1=3
i=4:  current=5, prev2=3, prev1=5
i=5:  current=8, prev2=5, prev1=8
结果: prev1 = 8
```

## 🎯 空间优化的通用原理
### 💡 核心思想
**观察依赖关系：**

+ 计算`dp[i]`只需要`dp[i-1]`和`dp[i-2]`
+ 不需要`dp[i-3]`及更早的状态
+ 因此可以只保留最近的几个状态

**优化策略：**

1. **识别依赖**：当前状态依赖哪些前置状态？
2. **最小保留**：只保留必要的前置状态
3. **状态更新**：计算新状态后更新保留的状态

### 🔧 通用优化模板
#### 原始DP模板：
```java
public int dpOriginal(int n) {
    int[] dp = new int[n + 1];
    // 设置边界条件
    dp[0] = base0;
    dp[1] = base1;
    
    // 状态转移
    for (int i = 2; i <= n; i++) {
        dp[i] = transition(dp[i-1], dp[i-2]);
    }
    
    return dp[n];
}
```

#### 空间优化模板：
```java
public int dpOptimized(int n) {
    if (n == 0) return base0;
    if (n == 1) return base1;
    
    // 只保留必要的前置状态
    int prev2 = base0;  // dp[i-2]
    int prev1 = base1;  // dp[i-1]
    
    for (int i = 2; i <= n; i++) {
        int current = transition(prev1, prev2);
        prev2 = prev1;    // 更新dp[i-2]
        prev1 = current;  // 更新dp[i-1]
    }
    
    return prev1;
}
```

## 🎯 您的dp[3]方案的具体实现
### 🔧 方案A：固定位置轮换
```java
public class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        
        int[] dp = new int[3];
        dp[1] = 1;  // 边界条件1
        dp[2] = 2;  // 边界条件2
        
        for (int i = 3; i <= n; i++) {
            // 计算新值并存储到dp[0]
            dp[0] = dp[1] + dp[2];
            
            // 状态轮换：0->1->2->0
            dp[1] = dp[2];
            dp[2] = dp[0];
        }
        
        return dp[2];  // 最终结果
    }
}
```

### 🔧 方案B：取模轮换
```java
public class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        
        int[] dp = new int[3];
        dp[1] = 1;  // dp[1]
        dp[2] = 2;  // dp[2]
        
        for (int i = 3; i <= n; i++) {
            dp[i % 3] = dp[(i-1) % 3] + dp[(i-2) % 3];
        }
        
        return dp[n % 3];
    }
}
```

### 🔧 方案C：语义化命名
```java
public class Solution {
    public int climbStairs(int n) {
        if (n <= 2) return n;
        
        int[] dp = new int[3];
        int PREV2 = 0, PREV1 = 1, CURRENT = 2;
        
        dp[PREV2] = 1;  // 边界条件1
        dp[PREV1] = 2;  // 边界条件2
        
        for (int i = 3; i <= n; i++) {
            dp[CURRENT] = dp[PREV1] + dp[PREV2];
            
            // 轮换索引
            int temp = PREV2;
            PREV2 = PREV1;
            PREV1 = CURRENT;
            CURRENT = temp;
        }
        
        return dp[PREV1];  // 最终结果在PREV1位置
    }
}
```

## 🎯 空间优化的适用场景
### ✅ 适合空间优化的DP
1. **线性DP**：当前状态只依赖前面固定数量的状态

```java
dp[i] = f(dp[i-1], dp[i-2], ..., dp[i-k])
```

2. **滚动数组DP**：二维DP中当前行只依赖上一行

```java
dp[i][j] = f(dp[i-1][j], dp[i-1][j-1], ...)
```

### ❌ 不适合空间优化的DP
1. **需要回溯路径**：需要保存完整状态来重构解
2. **随机访问**：需要访问任意位置的历史状态
3. **复杂依赖**：当前状态依赖大量不规律的历史状态

## 🎯 实际应用示例
### 📚 例题1：打家劫舍（空间优化）
```java
// 原始版本
public int rob(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);
    
    for (int i = 2; i < n; i++) {
        dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]);
    }
    return dp[n-1];
}

// 空间优化版本
public int rob(int[] nums) {
    if (nums.length == 1) return nums[0];
    
    int prev2 = nums[0];
    int prev1 = Math.max(nums[0], nums[1]);
    
    for (int i = 2; i < nums.length; i++) {
        int current = Math.max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = current;
    }
    return prev1;
}
```

```java
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    
    // 初始化和状态转移...
    return dp[m-1][n-1];

// 滚动数组优化
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[] dp = new int[n];  // 只保留一行
    
    // 初始化第一行
    dp[0] = grid[0][0];
    for (int j = 1; j < n; j++) {
        dp[j] = dp[j-1] + grid[0][j];
    }
    
    // 逐行更新
    for (int i = 1; i < m; i++) {
        dp[0] += grid[i][0];  // 第一列
        for (int j = 1; j < n; j++) {
            dp[j] = Math.min(dp[j], dp[j-1]) + grid[i][j];
        }
    }
    
    return dp[n-1];
}
```

## 🎯 优化技巧总结
### 💡 识别优化机会
1. **依赖分析**：画出状态依赖图
2. **访问模式**：观察状态的访问顺序
3. **生命周期**：确定状态的有效期

### 🔧 实现技巧
1. **变量命名**：使用有意义的变量名（prev1, prev2, current）
2. **边界处理**：特殊情况单独处理
3. **状态更新**：确保更新顺序正确
4. **测试验证**：用小规模数据验证正确性

### 📊 权衡考虑
| 因素 | 完整DP | 空间优化 |
| --- | --- | --- |
| 空间复杂度 | O(n) | O(1) |
| 代码复杂度 | 简单 | 中等 |
| 调试难度 | 容易 | 较难 |
| 可扩展性 | 好 | 一般 |
| 性能提升 | 无 | 显著 |
