## 🎯 为什么动态规划这么难？
很多人觉得动态规划难，主要原因是：

1. **抽象思维**：需要将问题抽象成状态和转移
2. **递推关系**：需要找到当前状态与之前状态的关系
3. **边界条件**：需要正确设置初始状态

但是，动态规划其实有固定的思考模式，掌握了就不难了！

## 📚 第一题：70-爬楼梯 (最简单的DP入门)
### 🔍 题目描述
假设你正在爬楼梯。需要 n 阶你才能到达楼顶。  
每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**示例：**

+ 输入：n = 2
+ 输出：2
+ 解释：有两种方法可以爬到楼顶
    1. 1 阶 + 1 阶
    2. 2 阶

### 🤔 第一步：理解问题本质
**关键问题：到达第n阶有多少种方法？**

让我们从小规模开始思考：

+ n=1：只有1种方法 (直接爬1阶)
+ n=2：有2种方法 (1+1 或 直接爬2阶)
+ n=3：有几种方法？

**重要发现：**  
要到达第3阶，只能从两个地方来：

1. 从第1阶爬2步
2. 从第2阶爬1步

所以：`到达第3阶的方法数 = 到达第1阶的方法数 + 到达第2阶的方法数`

### 💡 第二步：找到递推关系
**核心发现：**

```plain
到达第n阶的方法数 = 到达第(n-1)阶的方法数 + 到达第(n-2)阶的方法数
```

**为什么？**

+ 要到第n阶，最后一步只能是爬1阶或爬2阶
+ 如果最后爬1阶，那么之前必须在第(n-1)阶
+ 如果最后爬2阶，那么之前必须在第(n-2)阶

**数学表达式：**

```plain
f(n) = f(n-1) + f(n-2)
```

### 🎯 第三步：确定边界条件
**基础情况：**

+ f(1) = 1 (只有1种方法)
+ f(2) = 2 (有2种方法)

**验证：**

+ f(3) = f(2) + f(1) = 2 + 1 = 3
    - 方法1：1+1+1
    - 方法2：1+2
    - 方法3：2+1
+ f(4) = f(3) + f(2) = 3 + 2 = 5
    - 方法1：1+1+1+1
    - 方法2：1+1+2
    - 方法3：1+2+1
    - 方法4：2+1+1
    - 方法5：2+2

### 🔧 第四步：代码实现
#### 方法1：递归（会超时，但帮助理解）
```java
public class Solution {
    public int climbStairs(int n) {
        // 边界条件
        if (n == 1) {
            return 1;
        }
        if (n == 2) {
            return 2;
        }
        
        // 递推关系
        return climbStairs(n - 1) + climbStairs(n - 2);
    }
}
```

**问题：**这种方法会重复计算很多子问题，时间复杂度是O(2^n)，太慢了！

#### 方法2：动态规划（推荐）
```java
public class Solution {
    public int climbStairs(int n) {
        // 特殊情况处理
        if (n == 1) {
            return 1;
        }
        if (n == 2) {
            return 2;
        }
        
        // 创建dp数组
        int[] dp = new int[n + 1];
        
        // 设置边界条件
        dp[1] = 1;
        dp[2] = 2;
        
        // 填充dp数组
        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }
        
        return dp[n];
    }
}
```

#### 方法3：空间优化（最优）
```java
public class Solution {
    public int climbStairs(int n) {
        if (n == 1) {
            return 1;
        }
        if (n == 2) {
            return 2;
        }
        
        // 只需要记录前两个状态
        int prev2 = 1;  // f(n-2)
        int prev1 = 2;  // f(n-1)
        
        for (int i = 3; i <= n; i++) {
            int current = prev1 + prev2;  // f(n) = f(n-1) + f(n-2)
            prev2 = prev1;  // 更新f(n-2)
            prev1 = current;  // 更新f(n-1)
        }
        
        return prev1;
    }
}
```

### 📊 复杂度分析
+ **时间复杂度：** O(n)
+ **空间复杂度：** O(1) (优化后)

## 🚀 第二题：198-打家劫舍 (应用相同思路)
### 🔍 题目描述
你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

给定一个代表每个房屋存放金额的非负整数数组，计算你不触动警报装置的情况下，一夜之间能够偷窃到的最高金额。

**示例：**

+ 输入：nums = [2,7,9,3,1]
+ 输出：12
+ 解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。偷窃到的最高金额 = 2 + 9 + 1 = 12 。

### 🤔 用爬楼梯的思路来分析
**关键问题：到第i个房子时，能偷到的最大金额是多少？**

**思考过程：**

1. **状态定义：** dp[i] = 到第i个房子时能偷到的最大金额
2. **决策分析：** 对于第i个房子，我有两个选择：
    - **偷第i个房子：** 那么第i-1个房子就不能偷，最大金额 = dp[i-2] + nums[i]
    - **不偷第i个房子：** 最大金额 = dp[i-1]
3. **递推关系：** dp[i] = max(dp[i-1], dp[i-2] + nums[i])

### 💡 详细推导过程
以 nums = [2,7,9,3,1] 为例：

**手工计算：**

+ dp[0] = 2 (只有第0个房子，必须偷)
+ dp[1] = max(dp[0], nums[1]) = max(2, 7) = 7 (偷第1个房子更划算)
+ dp[2] = max(dp[1], dp[0] + nums[2]) = max(7, 2+9) = 11 (偷第0和第2个房子)
+ dp[3] = max(dp[2], dp[1] + nums[3]) = max(11, 7+3) = 11 (不偷第3个房子)
+ dp[4] = max(dp[3], dp[2] + nums[4]) = max(11, 11+1) = 12 (偷第4个房子)

**验证：**  
最优方案是偷第0、2、4个房子：2 + 9 + 1 = 12 ✓

### 🔧 代码实现
#### 完整版本
```java
public class Solution {
    public int rob(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }
        if (nums.length == 1) {
            return nums[0];
        }
        
        int n = nums.length;
        int[] dp = new int[n];
        
        // 边界条件
        dp[0] = nums[0];
        dp[1] = Math.max(nums[0], nums[1]);
        
        // 填充dp数组
        for (int i = 2; i < n; i++) {
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
        }
        
        return dp[n - 1];
    }
}
```

#### 空间优化版本
```java
public class Solution {
    public int rob(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }
        if (nums.length == 1) {
            return nums[0];
        }
        
        // 只需要记录前两个状态
        int prev2 = nums[0];  // dp[i-2]
        int prev1 = Math.max(nums[0], nums[1]);  // dp[i-1]
        
        for (int i = 2; i < nums.length; i++) {
            int current = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = current;
        }
        
        return prev1;
    }
}
```

## 🎯 从爬楼梯到打家劫舍的思路迁移
### 🔄 相同点
1. **都是线性DP**：状态按顺序推进
2. **都有选择**：爬楼梯选择爬1步或2步，打家劫舍选择偷或不偷
3. **都有约束**：爬楼梯每次最多2步，打家劫舍不能偷相邻房子
4. **都有递推关系**：当前状态依赖于前面的状态

### 🔄 不同点
1. **状态含义**：
    - 爬楼梯：到达第n阶的方法数
    - 打家劫舍：到第i个房子的最大金额
2. **递推关系**：
    - 爬楼梯：f(n) = f(n-1) + f(n-2) (加法)
    - 打家劫舍：dp[i] = max(dp[i-1], dp[i-2] + nums[i]) (取最大值)

### 🎯 思路迁移的关键
1. **明确状态定义**：dp[i]代表什么？
2. **分析决策选择**：在第i步有哪些选择？
3. **找出约束条件**：什么情况下不能选择？
4. **建立递推关系**：当前状态如何从之前状态得出？

## 🛠️ 动态规划通用解题模板
### 📋 四步解题法
#### 第一步：确定状态定义
```plain
问自己：dp[i] 代表什么含义？
- 必须明确、具体
- 能够表示问题的子结构
```

#### 第二步：找出状态转移方程
```plain
问自己：dp[i] 如何从 dp[i-1], dp[i-2], ... 推导出来？
- 分析所有可能的选择
- 考虑约束条件
```

#### 第三步：确定边界条件
```plain
问自己：最简单的情况是什么？
- dp[0], dp[1] 等初始状态
- 特殊情况的处理
```

#### 第四步：确定计算顺序
```plain
问自己：应该从哪里开始计算？
- 通常是从小到大
- 确保计算dp[i]时，所需的前置状态已经计算完成
```

## 💡 常见错误和避免方法
### ❌ 常见错误
1. **状态定义不清晰**：不知道dp[i]代表什么
2. **边界条件错误**：没有正确处理初始状态
3. **状态转移错误**：递推关系不正确
4. **数组越界**：没有检查边界
5. **Java特有错误**：
    - 忘记检查null数组
    - 使用错误的Math.max()语法
    - 数组长度用length而不是length()

### ✅ 避免方法
1. **画图理解**：用小例子画出状态转移图
2. **手工验证**：用小数据手工计算验证
3. **逐步调试**：打印中间状态检查
4. **边界检查**：仔细处理特殊情况
5. **Java最佳实践**：
    - 总是检查数组是否为null
    - 熟练使用Math.max()和Math.min()
    - 注意数组长度的正确写法

## 🚀 总结
### 🎯 核心思想
动态规划就是：

1. **把大问题分解成小问题**
2. **找到小问题之间的关系**
3. **从最小的问题开始，逐步解决大问题**

### 💡 记忆口诀
```plain
状态定义要明确，
转移方程是关键，
边界条件别忘记，
计算顺序要正确。
```
