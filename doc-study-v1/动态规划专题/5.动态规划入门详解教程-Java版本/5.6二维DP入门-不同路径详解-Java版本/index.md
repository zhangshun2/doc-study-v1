## 📋 题目描述
**LeetCode 62. 不同路径 (Unique Paths)**

一个机器人位于一个 `m x n` 网格的左上角（起始点在下图中标记为 "Start" ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 "Finish" ）。

问总共有多少条不同的路径？

### 示例
```plain
示例 1：
输入：m = 3, n = 7
输出：28

示例 2：
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下

示例 3：
输入：m = 7, n = 3
输出：28

示例 4：
输入：m = 3, n = 3
输出：6
```

### 约束条件
+ `1 <= m, n <= 100`
+ 题目数据保证答案小于等于 `2 * 10^9`

## 🔍 问题分析
### 可视化理解
以 `m=3, n=3` 为例：

```plain
Start → → Finish
  ↓   ↓     ↓
  ↓   ↓     ↓  
  ↓   ↓     ↓
```

机器人只能向右(→)或向下(↓)移动，要从左上角到达右下角。

### 核心观察
1. **路径特性**：每条路径都需要 `(m-1)` 次向下 + `(n-1)` 次向右
2. **递推关系**：到达某个位置的路径数 = 从上方来的路径数 + 从左方来的路径数
3. **边界条件**：第一行和第一列只有一种到达方式

## 🎯 六步分析法
### 第一步：题目具体化分析
+ **目标**：路径总数
+ **约束**：只能向右或向下移动
+ **范围**：m×n 网格
+ **操作**：每一步选择方向（右或下）

### 第二步：问题分解与递归思考
**递归思路：**

```java
// 到达位置(i,j)的路径数
int uniquePaths(int i, int j) {
    if (i == 0 || j == 0) return 1;  // 边界：第一行或第一列
    return uniquePaths(i-1, j) + uniquePaths(i, j-1);
}
```

**问题：** 存在大量重复计算，需要用DP优化。

### 第三步：状态定义
```java
dp[i][j] = 从起点(0,0)到达位置(i,j)的不同路径数
```

**状态空间：** `dp[m][n]` 二维数组

### 第四步：状态转移方程
```java
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

**解释：**

+ `dp[i-1][j]`：从上方位置来的路径数
+ `dp[i][j-1]`：从左方位置来的路径数

### 第五步：边界条件
```java
// 第一行：只能一直向右
for (int j = 0; j < n; j++) {
    dp[0][j] = 1;
}

// 第一列：只能一直向下
for (int i = 0; i < m; i++) {
    dp[i][0] = 1;
}
```

### 第六步：计算顺序与结果提取
+ **计算顺序**：从左到右，从上到下
+ **结果提取**：`dp[m-1][n-1]`

## 💻 代码实现
### 方法一：标准二维DP
```java
public class Solution {
    public int uniquePaths(int m, int n) {
        // 创建二维DP数组
        int[][] dp = new int[m][n];
        
        // 初始化边界条件
        // 第一行：只能向右
        for (int j = 0; j < n; j++) {
            dp[0][j] = 1;
        }
        
        // 第一列：只能向下
        for (int i = 0; i < m; i++) {
            dp[i][0] = 1;
        }
        
        // 填充DP表
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
            }
        }
        
        return dp[m-1][n-1];
    }
}
```

### 方法二：空间优化版本（一维数组）
```java
public class Solution {
    public int uniquePaths(int m, int n) {
        // 只需要一行的空间
        int[] dp = new int[n];
        
        // 初始化第一行
        Arrays.fill(dp, 1);
        
        // 逐行更新
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] = dp[j] + dp[j-1];
                //     上方    左方
            }
        }
        
        return dp[n-1];
    }
}
```

### 方法三：数学公式解法
```java
public class Solution {
    public int uniquePaths(int m, int n) {
        // 总共需要走 (m-1) + (n-1) = m+n-2 步
        // 其中向下走 m-1 步，向右走 n-1 步
        // 问题转化为：从 m+n-2 个位置中选择 m-1 个位置向下
        // 答案是 C(m+n-2, m-1)
        
        long result = 1;
        int total = m + n - 2;
        int choose = Math.min(m - 1, n - 1);  // 选择较小的避免溢出
        
        for (int i = 0; i < choose; i++) {
            result = result * (total - i) / (i + 1);
        }
        
        return (int) result;
    }
}
```

## 🔍 执行过程详解
以 `m=3, n=4` 为例，展示DP表的填充过程：

### 初始化边界
```plain
dp = [
  [1, 1, 1, 1],  // 第一行全为1
  [1, ?, ?, ?],  // 第一列为1
  [1, ?, ?, ?]   // 第一列为1
]
```

### 逐步填充
**第1步：** 计算 `dp[1][1]`

```plain
dp[1][1] = dp[0][1] + dp[1][0] = 1 + 1 = 2

dp = [
  [1, 1, 1, 1],
  [1, 2, ?, ?],
  [1, ?, ?, ?]
]
```

**第2步：** 计算 `dp[1][2]`

```plain
dp[1][2] = dp[0][2] + dp[1][1] = 1 + 2 = 3

dp = [
  [1, 1, 1, 1],
  [1, 2, 3, ?],
  [1, ?, ?, ?]
]
```

**第3步：** 计算 `dp[1][3]`

```plain
dp[1][3] = dp[0][3] + dp[1][2] = 1 + 3 = 4

dp = [
  [1, 1, 1, 1],
  [1, 2, 3, 4],
  [1, ?, ?, ?]
]
```

**继续填充第2行：**

```plain
dp[2][1] = dp[1][1] + dp[2][0] = 2 + 1 = 3
dp[2][2] = dp[1][2] + dp[2][1] = 3 + 3 = 6
dp[2][3] = dp[1][3] + dp[2][2] = 4 + 6 = 10

最终结果：
dp = [
  [1, 1, 1, 1],
  [1, 2, 3, 4],
  [1, 3, 6, 10]
]
```

**答案：** `dp[2][3] = 10`

## 📊 复杂度分析
| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
| --- | --- | --- | --- |
| 二维DP | O(m×n) | O(m×n) | 直观易懂 |
| 一维DP | O(m×n) | O(n) | 空间优化 |
| 数学公式 | O(min(m,n)) | O(1) | 最优解 |


## 🎨 空间优化详解
### 为什么可以优化到一维？
观察状态转移方程：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`

+ `dp[i-1][j]`：上一行的同一列
+ `dp[i][j-1]`：当前行的前一列

**关键洞察：** 计算当前行时，只需要上一行的数据和当前行已计算的数据。

### 优化过程
```java
// 原始二维更新
dp[i][j] = dp[i-1][j] + dp[i][j-1];

// 一维优化后
dp[j] = dp[j] + dp[j-1];
//      上方    左方
```

**解释：**

+ `dp[j]`（右侧）：更新后的值
+ `dp[j]`（左侧）：更新前的值（来自上一行）
+ `dp[j-1]`：当前行左边的值

## 🧠 扩展思考
### 变体1：有障碍物的路径
```java
// LeetCode 63. 不同路径 II
public int uniquePathsWithObstacles(int[][] obstacleGrid) {
    int m = obstacleGrid.length;
    int n = obstacleGrid[0].length;
    
    if (obstacleGrid[0][0] == 1) return 0;
    
    int[] dp = new int[n];
    dp[0] = 1;
    
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (obstacleGrid[i][j] == 1) {
                dp[j] = 0;  // 有障碍物，路径数为0
            } else if (j > 0) {
                dp[j] += dp[j-1];
            }
        }
    }
    
    return dp[n-1];
}
```

### 变体2：最小路径和
```java
// LeetCode 64. 最小路径和
public int minPathSum(int[][] grid) {
    int m = grid.length;
    int n = grid[0].length;
    
    int[] dp = new int[n];
    dp[0] = grid[0][0];
    
    // 初始化第一行
    for (int j = 1; j < n; j++) {
        dp[j] = dp[j-1] + grid[0][j];
    }
    
    // 逐行更新
    for (int i = 1; i < m; i++) {
        dp[0] += grid[i][0];  // 第一列
        for (int j = 1; j < n; j++) {
            dp[j] = Math.min(dp[j], dp[j-1]) + grid[i][j];
        }
    }
    
    return dp[n-1];
}
```

### 变体3：三角形最小路径和
```java
// LeetCode 120. 三角形最小路径和
public int minimumTotal(List<List<Integer>> triangle) {
    int n = triangle.size();
    int[] dp = new int[n];
    
    // 从底部开始
    for (int i = 0; i < n; i++) {
        dp[i] = triangle.get(n-1).get(i);
    }
    
    // 自底向上
    for (int i = n-2; i >= 0; i--) {
        for (int j = 0; j <= i; j++) {
            dp[j] = Math.min(dp[j], dp[j+1]) + triangle.get(i).get(j);
        }
    }
    
    return dp[0];
}
```

## 🎯 学习要点总结
### 二维DP的核心思想
1. **状态定义**：明确二维数组每个位置的含义
2. **转移方程**：分析当前状态与相邻状态的关系
3. **边界处理**：正确初始化第一行和第一列
4. **计算顺序**：确保依赖的状态已经计算

### 空间优化技巧
1. **观察依赖**：分析状态转移只依赖哪些位置
2. **滚动数组**：如果只依赖上一行，可以用一维数组
3. **原地更新**：合理安排更新顺序，避免覆盖需要的数据

### 常见错误
1. **边界条件错误**：忘记初始化第一行或第一列
2. **数组越界**：访问 `dp[i-1][j]` 时 `i=0`
3. **更新顺序错误**：空间优化时覆盖了需要的数据
4. **状态定义不清**：混淆"到达位置"和"从位置出发"

### 学习建议
1. **画图理解**：用网格图可视化状态转移过程
2. **手工计算**：用小例子验证算法正确性
3. **逐步优化**：先写出二维版本，再考虑空间优化
4. **举一反三**：尝试解决相关的路径问题
