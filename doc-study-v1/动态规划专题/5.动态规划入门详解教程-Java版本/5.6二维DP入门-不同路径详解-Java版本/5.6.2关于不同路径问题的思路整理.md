# 5.6.2 关于不同路径问题的思路整理
## 📋 问题理解
**核心问题：** 找总数，向右或者向下移动，横坐标小于m，纵坐标小于n

## 🔍 思路推导过程
### 边界情况分析
```plain
m=1, n=1 → dp=1
m=2, n=1 → dp=1  
m=1, n=2 → dp=1
m=2, n=2 → dp=2
```

### 状态转移方程推导
通过分析 `m=2, n=2` 的情况：

```plain
dp[2][2] = dp[i-1][j] + dp[i][j-1]
```

**核心转移方程：**

```plain
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

**状态定义：** `dp[i][j]` 表示到达位置 `(i,j)` 的路径总数

## 💻 代码实现思路
```java
int fc(int[][] num) {

    }
    
    // 初始化第一行
    for (j) {
        dp[0][j] = 1;
    }
    
    // 填充DP表
    for (i = 1; i++; ) {
        for (j = 1; j++; ) {
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
        }
    }
    
    return dp[dp.length-1][num[0].length-1];
}
```

## 🎯 思路总结
### 核心理解
1. **问题本质**：路径计数问题
2. **移动限制**：只能向右或向下
3. **状态转移**：当前位置的路径数 = 上方路径数 + 左方路径数
4. **边界处理**：第一行和第一列都只有一种到达方式

### 算法步骤
1. 处理特殊情况（空数组、单行、单列）
2. 初始化边界条件（第一行和第一列为1）
3. 使用状态转移方程填充DP表
4. 返回右下角的值作为结果

### 关键洞察
+ 到达任意位置的路径数等于到达其上方位置和左方位置的路径数之和
+ 边界位置（第一行和第一列）只有一种到达方式
+ 问题具有最优子结构，适合用动态规划解决
