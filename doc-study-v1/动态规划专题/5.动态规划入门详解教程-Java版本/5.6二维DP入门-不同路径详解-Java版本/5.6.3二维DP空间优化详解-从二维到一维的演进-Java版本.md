# 5.6.3 二维DP空间优化详解-从二维到一维的演进-Java版本
## 📋 问题背景
在二维DP问题中，我们通常使用二维数组来存储状态：

```java
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

**核心问题：** 如何优化空间复杂度？能否将 `O(m×n)` 的空间复杂度降低到 `O(n)` 甚至 `O(1)`？

## 🔍 空间优化分析
### 状态依赖关系分析
**原始状态转移：**

```java
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

**参与计算的变量：**

1. `dp[i][j]` - 当前要计算的位置
2. `dp[i-1][j]` - 上方位置（上一行同列）
3. `dp[i][j-1]` - 左方位置（当前行前一列）

**关键观察：**

+ 计算第 `i` 行时，只需要第 `i-1` 行的数据
+ 计算 `dp[i][j]` 时，只需要上方和左方的值
+ 一旦计算完第 `i` 行，第 `i-2` 行及之前的数据就不再需要

### 空间优化的可行性
**为什么可以优化？**

1. **局部依赖性**：每个状态只依赖于相邻的状态
2. **顺序计算**：按行从左到右计算，保证依赖关系
3. **数据复用**：可以用新值覆盖不再需要的旧值

**为什么不能简单缩减为三个变量？**

+ 计算当前行时，需要整个上一行的数据
+ 不能只保存三个变量，因为上一行的每个位置都可能被当前行的某个位置需要

## 💻 空间优化方案
### 方案一：二维优化为一维（推荐）
**核心思想：** 用一维数组 `dp[j]` 表示当前正在计算的行

```java
public int uniquePaths(int m, int n) {
    // 只需要一维数组
    int[] dp = new int[n];
    
    // 初始化第一行，所有位置都是1
    Arrays.fill(dp, 1);
    
    // 逐行更新
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            // dp[j] 更新前：表示上一行第j列的值 dp[i-1][j]
            // dp[j-1]：表示当前行第j-1列的值 dp[i][j-1]
            dp[j] = dp[j] + dp[j-1];
        }
        // 第一列始终为1，无需更新
    }
    
    return dp[n-1];
}
```

**状态转移对比：**

```java
// 二维版本
dp[i][j] = dp[i-1][j] + dp[i][j-1];

// 一维优化版本
dp[j] = dp[j] + dp[j-1];
//       ↑       ↑
//   上一行j列  当前行j-1列
```

### 方案二：滚动数组优化
**核心思想：** 只保留两行数据，交替使用

```java
public int uniquePaths(int m, int n) {
    // 只需要两行数据
    int[][] dp = new int[2][n];
    
    // 初始化第一行
    Arrays.fill(dp[0], 1);
    
    for (int i = 1; i < m; i++) {
        int curr = i % 2;      // 当前行索引
        int prev = 1 - curr;   // 上一行索引
        
        dp[curr][0] = 1;  // 第一列始终为1
        
        for (int j = 1; j < n; j++) {
            dp[curr][j] = dp[prev][j] + dp[curr][j-1];
        }
    }
    
    return dp[(m-1) % 2][n-1];
}
```

### 方案三：数学公式（终极优化）
**核心思想：** 路径计数问题本质是组合数学

```java
public int uniquePaths(int m, int n) {
    // 总共需要走 (m-1) + (n-1) = m+n-2 步
    // 其中向下走 m-1 步，向右走 n-1 步
    // 问题转化为：从 m+n-2 个位置中选择 m-1 个位置向下走
    // 答案是组合数 C(m+n-2, m-1)
    
    long result = 1;
    int total = m + n - 2;
    int choose = Math.min(m - 1, n - 1); // 选择较小的数避免溢出
    
    for (int i = 0; i < choose; i++) {
        result = result * (total - i) / (i + 1);
    }
    
    return (int) result;
}
```

## 🎯 详细执行过程演示
### 一维优化版本执行过程
以 `m=3, n=4` 为例：

**初始状态：**

```plain
dp = [1, 1, 1, 1]  // 第一行
```

**第二行计算（i=1）：**

```plain
计算前：dp = [1, 1, 1, 1]

j=1: dp[1] = dp[1] + dp[0] = 1 + 1 = 2
     dp = [1, 2, 1, 1]
     
j=2: dp[2] = dp[2] + dp[1] = 1 + 2 = 3
     dp = [1, 2, 3, 1]
     
j=3: dp[3] = dp[3] + dp[2] = 1 + 3 = 4
     dp = [1, 2, 3, 4]
```

**第三行计算（i=2）：**

```plain
计算前：dp = [1, 2, 3, 4]

j=1: dp[1] = dp[1] + dp[0] = 2 + 1 = 3
     dp = [1, 3, 3, 4]
     
j=2: dp[2] = dp[2] + dp[1] = 3 + 3 = 6
     dp = [1, 3, 6, 4]
     
j=3: dp[3] = dp[3] + dp[2] = 4 + 6 = 10
     dp = [1, 3, 6, 10]
```

**最终结果：** `dp[3] = 10`

### 状态更新的关键理解
**为什么 **`dp[j] = dp[j] + dp[j-1]`** 是正确的？**

1. **更新前的 **`dp[j]`：表示上一行第j列的值
2. `dp[j-1]`：表示当前行第j-1列的值（已更新）
3. **更新后的 **`dp[j]`：表示当前行第j列的值

**更新顺序的重要性：**

+ 必须从左到右更新，保证 `dp[j-1]` 是当前行的值
+ 如果从右到左更新，`dp[j-1]` 仍是上一行的值，会导致错误

## 📊 复杂度对比分析
| 方案 | 时间复杂度 | 空间复杂度 | 优缺点 |
| --- | --- | --- | --- |
| 标准二维DP | O(m×n) | O(m×n) | 直观易懂，便于调试 |
| 一维优化 | O(m×n) | O(n) | 空间优化显著，代码简洁 |
| 滚动数组 | O(m×n) | O(n) | 思路清晰，易于扩展 |
| 数学公式 | O(min(m,n)) | O(1) | 最优解，但仅适用于特定问题 |

## 🧠 空间优化的通用原理
### 适用条件
1. **局部依赖性**：状态只依赖于相邻的少数状态
2. **顺序计算**：可以按某种顺序计算，保证依赖关系
3. **数据时效性**：旧数据在计算新数据后不再需要

### 优化策略
1. **降维优化**：二维→一维，三维→二维
2. **滚动数组**：只保留必要的历史数据
3. **原地更新**：在不影响后续计算的前提下覆盖旧值
4. **数学优化**：寻找问题的数学本质，直接计算

### 注意事项
1. **更新顺序**：确保依赖的数据在使用时是正确的
2. **边界处理**：优化后的边界条件可能需要特殊处理
3. **可读性权衡**：过度优化可能影响代码可读性

## 🎨 扩展应用
### 1. 最小路径和的空间优化
```java
public int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[] dp = new int[n];
    
    // 初始化第一行
    dp[0] = grid[0][0];
    for (int j = 1; j < n; j++) {
        dp[j] = dp[j-1] + grid[0][j];
    }
    
    // 逐行更新
    for (int i = 1; i < m; i++) {
        dp[0] += grid[i][0];  // 第一列
        for (int j = 1; j < n; j++) {
            dp[j] = grid[i][j] + Math.min(dp[j], dp[j-1]);
        }
    }
    
    return dp[n-1];
}
```

### 2. 编辑距离的空间优化
```java
public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[] dp = new int[n + 1];
    
    // 初始化
    for (int j = 0; j <= n; j++) {
        dp[j] = j;
    }
    
    for (int i = 1; i <= m; i++) {
        int prev = dp[0];  // 保存dp[i-1][j-1]
        dp[0] = i;         // dp[i][0] = i
        
        for (int j = 1; j <= n; j++) {
            int temp = dp[j];  // 保存dp[i-1][j]
            
            if (word1.charAt(i-1) == word2.charAt(j-1)) {
                dp[j] = prev;  // dp[i-1][j-1]
            } else {
                dp[j] = 1 + Math.min(Math.min(dp[j], dp[j-1]), prev);
            }
            
            prev = temp;  // 更新dp[i-1][j-1]
        }
    }
    
    return dp[n];
}
```

### 3. 最长公共子序列的空间优化
```java
public int longestCommonSubsequence(String text1, String text2) {
    int m = text1.length(), n = text2.length();
    
    // 确保n是较小的维度
    if (m < n) {
        return longestCommonSubsequence(text2, text1);
    }
    
    int[] dp = new int[n + 1];
    
    for (int i = 1; i <= m; i++) {
        int prev = 0;  // dp[i-1][j-1]
        for (int j = 1; j <= n; j++) {
            int temp = dp[j];  // 保存dp[i-1][j]
            
            if (text1.charAt(i-1) == text2.charAt(j-1)) {
                dp[j] = prev + 1;
            } else {
                dp[j] = Math.max(dp[j], dp[j-1]);
            }
            
            prev = temp;
        }
    }
    
    return dp[n];
}
```

## ⚠️ 常见错误与调试技巧
### 1. 更新顺序错误
**错误示例：**

```java
// ❌ 从右到左更新
for (int j = n-1; j >= 1; j--) {
    dp[j] = dp[j] + dp[j-1];  // dp[j-1]仍是上一行的值
}
```

**正确做法：**

```java
// ✅ 从左到右更新
for (int j = 1; j < n; j++) {
    dp[j] = dp[j] + dp[j-1];  // dp[j-1]是当前行的值
}
```

### 2. 边界条件遗漏
**错误示例：**

```java
// ❌ 忘记处理第一列
for (int j = 0; j < n; j++) {
    dp[j] = dp[j] + dp[j-1];  // j=0时dp[j-1]越界
}
```

**正确做法：**

```java
// ✅ 正确处理边界
for (int j = 1; j < n; j++) {  // 从j=1开始
    dp[j] = dp[j] + dp[j-1];
}
// 第一列dp[0]保持不变或单独处理
```
