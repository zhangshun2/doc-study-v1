# 5.6 二维DP进阶-最小路径和详解-Java版本
## 📋 题目描述
**LeetCode 64. 最小路径和 (Minimum Path Sum)**

给定一个包含非负整数的 `m x n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明**：每次只能向下或者向右移动一步。

### 示例
**示例 1：**

```plain
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。
```

**示例 2：**

```plain
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

**约束条件：**

+ `m == grid.length`
+ `n == grid[i].length`
+ `1 <= m, n <= 200`
+ `0 <= grid[i][j] <= 100`

---

## 🔍 六步分析法详解
### 第一步：问题具体化
**关键词提取：**

+ "最小路径和" → 优化问题
+ "从左上角到右下角" → 起点终点确定
+ "只能向下或向右" → 移动限制
+ "路径上数字总和" → 累积计算

**问题本质：**  
这是一个典型的**路径优化问题**，需要在所有可能路径中找到代价最小的那条。

### 第二步：递归思维分解
**核心观察：**  
要到达位置 `(i,j)`，只能从两个位置来：

+ 从上方 `(i-1,j)` 向下移动
+ 从左方 `(i,j-1)` 向右移动

**递归关系：**

```plain
minPathSum(i,j) = grid[i][j] + min(
    minPathSum(i-1,j),  // 从上方来
    minPathSum(i,j-1)   // 从左方来
)
```

### 第三步：状态定义
**状态选择：**  
`dp[i][j]` = 从起点 `(0,0)` 到位置 `(i,j)` 的最小路径和

**状态特点：**

+ **清晰性**：明确表示到达某点的最优解
+ **完整性**：覆盖所有可能的子问题
+ **最优性**：便于状态转移和结果提取

### 第四步：状态转移方程
**核心转移：**

```java
dp[i][j] = grid[i][j] + Math.min(dp[i-1][j], dp[i][j-1])
```

**转移逻辑：**

+ 当前位置的最小路径和 = 当前格子值 + 上方和左方的最小值
+ 体现了"最优子结构"：局部最优导致全局最优

### 第五步：边界条件
**边界分析：**

1. **起点**：`dp[0][0] = grid[0][0]`
2. **第一行**：只能从左边来，`dp[0][j] = dp[0][j-1] + grid[0][j]`
3. **第一列**：只能从上边来，`dp[i][0] = dp[i-1][0] + grid[i][0]`

### 第六步：计算顺序与结果提取
**计算顺序：**

+ 从左到右，从上到下
+ 保证计算 `dp[i][j]` 时，`dp[i-1][j]` 和 `dp[i][j-1]` 已计算

**结果提取：**

+ `dp[m-1][n-1]` 即为所求答案

## 💻 代码实现
### 方法一：标准二维DP
```java
public class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        
        // 创建DP表
        int[][] dp = new int[m][n];
        
        // 初始化起点
        dp[0][0] = grid[0][0];
        
        // 初始化第一行
        for (int j = 1; j < n; j++) {
            dp[0][j] = dp[0][j-1] + grid[0][j];
        }
        
        // 初始化第一列
        for (int i = 1; i < m; i++) {
            dp[i][0] = dp[i-1][0] + grid[i][0];
        }
        
        // 填充DP表
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = grid[i][j] + Math.min(dp[i-1][j], dp[i][j-1]);
            }
        }
        
        return dp[m-1][n-1];
    }
}
```

### 方法二：空间优化版本
```java
public class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        
        // 只需要一维数组
        int[] dp = new int[n];
        
        // 初始化第一行
        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++) {
            dp[j] = dp[j-1] + grid[0][j];
        }
        
        // 逐行更新
        for (int i = 1; i < m; i++) {
            // 更新第一列
            dp[0] += grid[i][0];
            
            // 更新其他列
            for (int j = 1; j < n; j++) {
                dp[j] = grid[i][j] + Math.min(dp[j], dp[j-1]);
            }
        }
        
        return dp[n-1];
    }
}
```

### 方法三：原地修改版本
```java
public class Solution {

        int m = grid.length;
        int n = grid[0].length;
        
        // 初始化第一行
        for (int j = 1; j < n; j++) {
            grid[0][j] += grid[0][j-1];
        }
        
        // 初始化第一列
        for (int i = 1; i < m; i++) {
            grid[i][0] += grid[i-1][0];
        }

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                grid[i][j] += Math.min(grid[i-1][j], grid[i][j-1]);
            }
        }
        
        return grid[m-1][n-1];
    }
}
```

dp[0][0] = 1

**步骤2：填充第一行**

```plain
dp[0][1] = dp[0][0] + grid[0][1] = 1 + 3 = 4
dp[0][2] = dp[0][1] + grid[0][2] = 4 + 1 = 5

DP表：
1  4  5

```

**步骤3：填充第一列**

```plain
dp[1][0] = dp[0][0] + grid[1][0] = 1 + 1 = 2
dp[2][0] = dp[1][0] + grid[2][0] = 2 + 4 = 6

DP表：
1  4  5
2  ?  ?
6  ?  ?
```

**步骤4：填充其余位置**

```plain
dp[1][1] = grid[1][1] + min(dp[0][1], dp[1][0]) = 5 + min(4, 2) = 7
dp[1][2] = grid[1][2] + min(dp[0][2], dp[1][1]) = 1 + min(5, 7) = 6
dp[2][1] = grid[2][1] + min(dp[1][1], dp[2][0]) = 2 + min(7, 6) = 8
dp[2][2] = grid[2][2] + min(dp[1][2], dp[2][1]) = 1 + min(6, 8) = 7

最终DP表：
1  4  5
2  7  6
6  8  7
```

**最优路径：** `1 → 3 → 1 → 1 → 1`，总和为 `7`

## 🎨 空间优化详解
### 优化思路
**关键观察：**  
计算 `dp[i][j]` 时，只需要：

+ `dp[i-1][j]`（上方）
+ `dp[i][j-1]`（左方）

**优化策略：**  
使用一维数组 `dp[j]` 表示当前行的状态：

+ `dp[j]` 更新前：表示上一行第j列的值
+ `dp[j-1]`：表示当前行第j-1列的值

### 状态转移对比
```java
// 二维版本
dp[i][j] = grid[i][j] + Math.min(dp[i-1][j], dp[i][j-1]);

// 一维优化版本
dp[j] = grid[i][j] + Math.min(dp[j], dp[j-1]);
//                              ↑      ↑
//                           上一行   当前行左边
```

## 📊 复杂度分析
### 时间复杂度
+ **所有方法**：`O(m × n)`
+ 需要遍历整个网格一次

### 空间复杂度
+ **标准DP**：`O(m × n)` - 需要二维DP表
+ **空间优化**：`O(n)` - 只需一维数组
+ **原地修改**：`O(1)` - 直接修改输入数组

## 🧠 算法变体与扩展
### 1. 返回最优路径
```java
public List<int[]> minPathWithPath(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    
    // 填充DP表（同标准版本）
    // ...
    
    // 回溯构建路径
    List<int[]> path = new ArrayList<>();
    int i = m - 1, j = n - 1;
    
    while (i > 0 || j > 0) {
        path.add(new int[]{i, j});
        
        if (i == 0) {
            j--; // 只能向左
        } else if (j == 0) {
            i--; // 只能向上
        } else {
            // 选择较小的前驱
            if (dp[i-1][j] < dp[i][j-1]) {
                i--;
            } else {
                j--;
            }
        }
    }
    
    path.add(new int[]{0, 0});
    Collections.reverse(path);
    return path;
}
```

### 2. 支持四个方向移动
```java
public int minPathSumFourDirections(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    
    // 初始化为最大值
    for (int i = 0; i < m; i++) {
        Arrays.fill(dp[i], Integer.MAX_VALUE);
    }
    
    dp[0][0] = grid[0][0];
    
    // 多轮迭代直到收敛
    boolean changed = true;
    int[][] dirs = {{-1,0}, {1,0}, {0,-1}, {0,1}};
    
    while (changed) {
        changed = false;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                for (int[] dir : dirs) {
                    int ni = i + dir[0], nj = j + dir[1];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n) {
                        int newVal = dp[i][j] + grid[ni][nj];
                        if (newVal < dp[ni][nj]) {
                            dp[ni][nj] = newVal;
                            changed = true;
                        }
                    }
                }
            }
        }
    }
    
    return dp[m-1][n-1];
}
```

### 3. 带权重的路径问题
```java
public int minPathSumWithWeight(int[][] grid, int[][] weight) {
    int m = grid.length, n = grid[0].length;
    int[][] dp = new int[m][n];
    
    dp[0][0] = grid[0][0] * weight[0][0];
    
    // 第一行
    for (int j = 1; j < n; j++) {
        dp[0][j] = dp[0][j-1] + grid[0][j] * weight[0][j];
    }
    
    // 第一列
    for (int i = 1; i < m; i++) {
        dp[i][0] = dp[i-1][0] + grid[i][0] * weight[i][0];
    }
    
    // 其余位置
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = grid[i][j] * weight[i][j] + 
                      Math.min(dp[i-1][j], dp[i][j-1]);
        }
    }
    
    return dp[m-1][n-1];
}
```

## ⚠️ 常见错误与注意事项
### 1. 边界条件处理
**错误示例：**

```java
// ❌ 忘记处理边界
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        dp[i][j] = grid[i][j] + Math.min(dp[i-1][j], dp[i][j-1]);
        // 当i=0或j=0时会数组越界
    }
}
```

**正确处理：**

```java
// ✅ 正确处理边界
if (i == 0 && j == 0) {
    dp[i][j] = grid[i][j];
} else if (i == 0) {
    dp[i][j] = dp[i][j-1] + grid[i][j];
} else if (j == 0) {
    dp[i][j] = dp[i-1][j] + grid[i][j];
} else {
    dp[i][j] = grid[i][j] + Math.min(dp[i-1][j], dp[i][j-1]);
}
```

### 2. 空间优化中的更新顺序
**错误示例：**

```java
// ❌ 错误的更新顺序
for (int j = 0; j < n; j++) {
    dp[j] = grid[i][j] + Math.min(dp[j], dp[j-1]);
    // 当j=0时，dp[j-1]会越界
}
```

**正确处理：**

```java
// ✅ 正确处理第一列
dp[0] += grid[i][0]; // 第一列特殊处理
for (int j = 1; j < n; j++) {
    dp[j] = grid[i][j] + Math.min(dp[j], dp[j-1]);
}
```

### 3. 原地修改的副作用
**注意事项：**

+ 原地修改会改变输入数组
+ 如果需要保持原数组不变，不要使用原地修改
+ 在面试中要询问是否可以修改输入

## 📚 总结与学习建议
### 🎯 核心思想
1. **最优子结构**：到达某点的最优路径包含到达前驱点的最优路径
2. **状态转移**：当前状态由有限个前驱状态决定
3. **边界处理**：第一行和第一列需要特殊初始化
4. **空间优化**：利用状态转移的局部性减少空间复杂度
