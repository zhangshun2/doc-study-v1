# LeetCode 96 - 不同的二叉搜索树解题思路
## 题目描述
给你一个整数 n，求恰由 n 个节点组成且节点值从 1 到 n 互不相同的二叉搜索树有多少种？

## 核心思想
这道题的核心思想是**用子问题的解来构建更大问题的解**。我们使用动态规划的方法，通过计算较小规模的子问题来解决原问题。

### 状态定义
+ `dp[i]` 表示有 i 个节点时能构成的不同BST数量
+ 对于 n 个节点，我们尝试每个节点作为根节点，然后计算左右子树的组合数

## BST的核心原则
当选择节点 j 作为根节点时：

+ 左子树包含节点 1 到 j-1（共 j-1 个节点）
+ 右子树包含节点 j+1 到 i（共 i-j 个节点）
+ 左右子树的结构是独立的，所以总数 = 左子树数量 × 右子树数量

## 具体示例：构建 dp[3]
让我们通过计算 dp[3] 来理解这个过程：

### 情况1：选择节点1作为根
+ 左子树：0个节点 → dp[0] = 1种（空树）
+ 右子树：2个节点 → dp[2] = 2种
+ 组合数：1 × 2 = 2种

### 情况2：选择节点2作为根
+ 左子树：1个节点 → dp[1] = 1种
+ 右子树：1个节点 → dp[1] = 1种
+ 组合数：1 × 1 = 1种

### 情况3：选择节点3作为根
+ 左子树：2个节点 → dp[2] = 2种
+ 右子树：0个节点 → dp[0] = 1种（空树）
+ 组合数：2 × 1 = 2种

### 最终结果
dp[3] = 2 + 1 + 2 = 5种

## 递推关系
```plain
dp[i] = Σ(dp[j-1] * dp[i-j])  其中 j 从 1 到 i
```

这个公式的含义是：

+ 对于每个可能的根节点 j
+ 左子树有 j-1 个节点，方案数为 dp[j-1]
+ 右子树有 i-j 个节点，方案数为 dp[i-j]
+ 将所有可能的根节点情况累加起来

## Base Cases（边界条件）
+ `dp[0] = 1`：空树只有一种情况
+ `dp[1] = 1`：单节点树只有一种情况

## 算法实现
```java
public int numTrees(int n) {
    int[] dp = new int[n + 1];
    
    // 边界条件
    dp[0] = 1;
    dp[1] = 1;
    
    // 从小到大计算
    for (int i = 2; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            dp[i] += dp[j - 1] * dp[i - j];
        }
    }
    
    return dp[n];
}
```

## 计算流程
从小到大计算：dp[0] → dp[1] → dp[2] → ... → dp[n]

### 完整计算过程示例
+ dp[0] = 1
+ dp[1] = 1
+ dp[2] = dp[0] × dp[1] + dp[1] × dp[0] = 1×1 + 1×1 = 2
+ dp[3] = dp[0] × dp[2] + dp[1] × dp[1] + dp[2] × dp[0] = 1×2 + 1×1 + 2×1 = 5
+ dp[4] = dp[0] × dp[3] + dp[1] × dp[2] + dp[2] × dp[1] + dp[3] × dp[0] = 1×5 + 1×2 + 2×1 + 5×1 = 14

## 复杂度分析
+ **时间复杂度**：O(n²) - 两层嵌套循环
+ **空间复杂度**：O(n) - 使用一维数组存储dp值

## 数学背景
这个解法实际上计算的是**卡特兰数（Catalan Number）**，是一个经典的组合数学问题。卡特兰数的第n项表示：

```plain
C(n) = (2n)! / ((n+1)! × n!)
```

卡特兰数在很多问题中都会出现，比如：

+ 不同的二叉搜索树数量
+ 有效的括号组合数量
+ 出栈序列的数量
+ 凸多边形三角剖分的方案数

## 关键要点
1. **子问题分解**：将大问题分解为左右子树的子问题
2. **状态转移**：通过枚举根节点来建立状态转移关系
3. **独立性**：左右子树的结构选择是相互独立的
4. **累加原理**：不同根节点对应的方案数需要累加
5. **边界处理**：正确处理空树和单节点树的情况

通过动态规划，我们避免了重复计算，将指数级的时间复杂度优化到了多项式级别。
