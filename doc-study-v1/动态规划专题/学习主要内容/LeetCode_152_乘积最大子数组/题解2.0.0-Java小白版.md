# 题解（LeetCode 152）- 乘积最大子数组（Java 小白版）

## 先说结论

这题是动态规划。

但它和“最大子数组和”最大的不同是：

- 加法里，当前大的继续加，通常还是更有希望变大。
- 乘法里，`负数 * 负数 = 正数`，情况会突然翻转。

所以这题不能只记“到当前位置为止的最大乘积”，还必须同时记“到当前位置为止的最小乘积”。

也就是常说的：

- `maxDp[i]`：以 `i` 结尾的连续子数组里，乘积最大的值
- `minDp[i]`：以 `i` 结尾的连续子数组里，乘积最小的值

为什么最小值也要记？

因为它可能是一个很小的负数，下一步一旦乘上负数，就会直接变成很大的正数。

---

## 一、为什么暴力不合适

最直接的做法，是枚举所有连续子数组，再算每一段的乘积。

连续子数组一共有大约 `n^2` 段，如果每一段再去算乘积，复杂度会更高。即使边枚举边累乘，整体也还是 `O(n^2)`。

而这题 `n` 最多到 `2 * 10^4`，`O(n^2)` 一般就不稳了。

所以我们需要 `O(n)` 的做法。

---

## 二、先观察：为什么只记录最大值不够

看这个例子：

```text
nums = [2, 3, -2, 4]
```

如果你只想记录“以当前位置结尾的最大乘积”，前两步没问题：

- 到 `2`：最大乘积是 `2`
- 到 `3`：最大乘积是 `2 * 3 = 6`

但到了 `-2`：

- 原来的最大值 `6` 乘上 `-2`，变成 `-12`
- 当前单独开一段是 `-2`

这时最大值变成 `-2`

你会发现，原来很大的正数，乘上负数之后，反而变成了很小的负数。

再看另一个例子：

```text
nums = [-2, 3, -4]
```

到下标 `1` 时：

- 以 `1` 结尾的最大乘积是 `3`
- 以 `1` 结尾的最小乘积是 `-6`

接着乘上 `-4`：

- `3 * -4 = -12`
- `-6 * -4 = 24`

注意这里，真正变成最大值的是“之前的最小值”。

这就是这题的核心：

`当前最大值` 可能来自 `上一步最小值 * 当前数`

所以，最大值和最小值要一起维护。

---

## 三、状态定义

设当前元素是 `nums[i]`。

我们定义：

- `maxDp[i]`：必须以 `nums[i]` 结尾的连续子数组中，乘积最大的值
- `minDp[i]`：必须以 `nums[i]` 结尾的连续子数组中，乘积最小的值

注意“必须以 `i` 结尾”这几个字非常重要。

因为动态规划一般都要把问题缩小成“最后一步是什么”。  
这里最后一步就是：子数组一定要包含 `nums[i]`，并且结束在这里。

最后真正的答案不是某一个 `maxDp[i]`，而是：

```text
max(maxDp[0], maxDp[1], ..., maxDp[n - 1])
```

因为乘积最大的子数组，可能结束在任何位置。

---

## 四、转移方程是怎么推出来的

这是整题最关键的部分。

### 1. 以 `i` 结尾的子数组，只可能有两种来源

任何一个“以 `i` 结尾”的连续子数组，都只有两种可能：

- 只包含当前元素自己，也就是 `[nums[i]]`
- 在某个“以 `i - 1` 结尾”的连续子数组后面，再乘上 `nums[i]`

所以，我们只需要考虑：

- 当前数自己单独开一段
- 把前一位置的某个结果接过来

### 2. 为什么只需要看“前一位的最大值和最小值”

假设当前数是 `x = nums[i]`。

如果我们要从“以 `i - 1` 结尾”的所有子数组里选一个，再乘上 `x`，那到底选谁最好？

分情况：

- 如果 `x > 0`，那当然更希望前面的乘积越大越好
- 如果 `x < 0`，那反而希望前面的乘积越小越好，因为负负得正

也就是说：

- 求新的最大值时，只可能来自这三种情况：
  - `x`
  - `maxDp[i - 1] * x`
  - `minDp[i - 1] * x`
- 求新的最小值时，也只可能来自这三种情况：
  - `x`
  - `maxDp[i - 1] * x`
  - `minDp[i - 1] * x`

于是统一写成：

```text
maxDp[i] = max(nums[i], maxDp[i - 1] * nums[i], minDp[i - 1] * nums[i])
minDp[i] = min(nums[i], maxDp[i - 1] * nums[i], minDp[i - 1] * nums[i])
```

这就是最终转移方程。

## 五、把转移方程再讲白一点

设 `x = nums[i]`。

### 情况 1：`x` 是正数

比如 `x = 4`

- 想得到更大的结果，应该拿之前的最大正数来乘
- 想得到更小的结果，应该拿之前的最小负数来乘

所以：

- 新最大值可能来自 `maxDp[i - 1] * x`
- 新最小值可能来自 `minDp[i - 1] * x`

### 情况 2：`x` 是负数

比如 `x = -4`

- 想得到更大的结果，应该拿之前最小的负数来乘
- 想得到更小的结果，应该拿之前最大的正数来乘

所以：

- 新最大值可能来自 `minDp[i - 1] * x`
- 新最小值可能来自 `maxDp[i - 1] * x`

### 情况 3：`x` 是 0

那不管前面是多少，乘完都会变成 `0`。

也就是说：

- 以当前位置结尾的最大值会变成 `0`
- 以当前位置结尾的最小值也会变成 `0`

这相当于从下一位开始，重新开一段。

所以把三种情况统一到同一个公式里，就是最稳妥的写法。

---

## 六、初始状态怎么定

当 `i = 0` 时，数组里只有第一个数。

那“以 0 结尾的连续子数组”只能是它自己，所以：

```text
maxDp[0] = nums[0]
minDp[0] = nums[0]
ans = nums[0]
```

## 七、拿示例完整走一遍

示例：

```text
nums = [2, 3, -2, 4]
```

初始：

```text
maxDp[0] = 2
minDp[0] = 2
ans = 2
```

### i = 1, nums[i] = 3

候选值有三个：

- `3`
- `maxDp[0] * 3 = 2 * 3 = 6`
- `minDp[0] * 3 = 2 * 3 = 6`

所以：

```text
maxDp[1] = 6
minDp[1] = 3
ans = 6
```

### i = 2, nums[i] = -2

候选值：

- `-2`
- `maxDp[1] * -2 = 6 * -2 = -12`
- `minDp[1] * -2 = 3 * -2 = -6`

所以：

```text
maxDp[2] = -2
minDp[2] = -12
ans = 6
```

### i = 3, nums[i] = 4

候选值：

- `4`
- `maxDp[2] * 4 = -2 * 4 = -8`
- `minDp[2] * 4 = -12 * 4 = -48`

所以：

```text
maxDp[3] = 4
minDp[3] = -48
ans = 6
```

最后答案是 `6`。

## 八、Java 版本写法一：数组版，最适合初学者

这个版本最容易看懂，因为 `maxDp[i]` 和 `minDp[i]` 都完整保留下来了。

```java
class Solution {
    public int maxProduct(int[] nums) {
        int n = nums.length;

        int[] maxDp = new int[n];
        int[] minDp = new int[n];

        maxDp[0] = nums[0];
        minDp[0] = nums[0];

        int ans = nums[0];

        for (int i = 1; i < n; i++) {
            int x = nums[i];

            int candidate1 = x;
            int candidate2 = maxDp[i - 1] * x;
            int candidate3 = minDp[i - 1] * x;

            maxDp[i] = Math.max(candidate1, Math.max(candidate2, candidate3));
            minDp[i] = Math.min(candidate1, Math.min(candidate2, candidate3));

            ans = Math.max(ans, maxDp[i]);
        }

        return ans;
    }
}
```

### 代码解释

- `maxDp[i]` 记录以 `i` 结尾的最大乘积
- `minDp[i]` 记录以 `i` 结尾的最小乘积
- `candidate1` 表示“从当前位置重新开始”
- `candidate2` 表示“接在前一位最大乘积后面”
- `candidate3` 表示“接在前一位最小乘积后面”
- 每一步更新完 `maxDp[i]` 后，都要尝试更新全局答案 `ans`

## 九、Java 版本写法二：空间优化版

你会发现：

- 第 `i` 位只会用到第 `i - 1` 位

所以数组其实可以压缩成两个变量。

```java
class Solution {
    public int maxProduct(int[] nums) {
        int maxEnd = nums[0];
        int minEnd = nums[0];
        int ans = nums[0];

        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];

            int prevMax = maxEnd;
            int prevMin = minEnd;

            maxEnd = Math.max(x, Math.max(prevMax * x, prevMin * x));
            minEnd = Math.min(x, Math.min(prevMax * x, prevMin * x));

            ans = Math.max(ans, maxEnd);
        }

        return ans;
    }
}
```

### 为什么这里要先保存 `prevMax` 和 `prevMin`

因为如果你先更新了 `maxEnd`，再去算 `minEnd`，那 `minEnd` 用到的就不是“上一轮的值”，而是“已经被本轮改过的值”了。

这会把状态转移搞乱。

所以要先存一下旧值，再统一计算。

## 十、还有一种常见写法：遇到负数先交换

因为：

- 当前数是正数时，最大乘积通常从“前最大”转来
- 当前数是负数时，最大乘积通常从“前最小”转来

所以有些人会先在 `x < 0` 时交换最大值和最小值，再继续更新：

```java
class Solution {
    public int maxProduct(int[] nums) {
        int maxEnd = nums[0];
        int minEnd = nums[0];
        int ans = nums[0];

        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];

            if (x < 0) {
                int temp = maxEnd;
                maxEnd = minEnd;
                minEnd = temp;
            }

            maxEnd = Math.max(x, maxEnd * x);
            minEnd = Math.min(x, minEnd * x);

            ans = Math.max(ans, maxEnd);
        }

        return ans;
    }
}
```

这个写法也对，而且代码更短。

但如果你现在还是在理解阶段，我更建议先掌握上面的“三个候选值”版本，因为它更容易看出转移方程是怎么来的。

---

## 十一、复杂度分析

数组版和空间优化版的时间复杂度都一样：

- 时间复杂度：`O(n)`
- 空间复杂度：
  - 数组版：`O(n)`
  - 空间优化版：`O(1)`

---

## 十二、小白最容易错的地方

### 1. 只维护最大值，不维护最小值

这是最常见错误。

因为负数会把“最小”翻成“最大”，所以最小值必须保留。

### 2. 把题目看成“最大子数组和”

这题不是加法，不能直接套 Kadane 模板。

### 3. 忘了“必须连续”

像 `[-2, 0, -1]` 这个例子，`[-2, -1]` 的乘积虽然是 `2`，但它们不连续，所以不能选。

### 4. 空间优化时，直接覆盖旧值

更新 `maxEnd` 和 `minEnd` 前，一定要先把旧值保存起来。

### 5. 只返回最后一位的结果

最大乘积子数组不一定恰好结束在最后一个位置，所以必须用 `ans` 维护全局最大值。

---

## 十三、这题你真正要记住的核心

你可以只记这一句话：

> 以 `i` 结尾的最大乘积，不只可能来自前一位的最大乘积，也可能来自前一位的最小乘积。

再记住这两个状态：

- `maxDp[i]`：以 `i` 结尾的最大乘积
- `minDp[i]`：以 `i` 结尾的最小乘积

最后记住统一转移：

```text
maxDp[i] = max(nums[i], maxDp[i - 1] * nums[i], minDp[i - 1] * nums[i])
minDp[i] = min(nums[i], maxDp[i - 1] * nums[i], minDp[i - 1] * nums[i])
```

这题就拿下了。
