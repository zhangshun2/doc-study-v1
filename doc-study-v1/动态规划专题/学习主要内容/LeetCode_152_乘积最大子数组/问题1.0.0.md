# 问题（LeetCode 152）- 乘积最大子数组

## 题目描述

给你一个整数数组 `nums`，请你找出数组中乘积最大的非空连续子数组，并返回这个子数组的乘积。

这里有两个关键词一定要先看清：

- `连续子数组`：必须是数组里连续的一段，不能跳着选。
- `非空`：至少要选一个元素。

## 示例 1

```text
输入：nums = [2,3,-2,4]
输出：6
解释：乘积最大的连续子数组是 [2,3]，乘积为 6。
```

## 示例 2

```text
输入：nums = [-2,0,-1]
输出：0
解释：结果不能是 2，因为 [-2,-1] 不是连续子数组。
```

## 示例 3

```text
输入：nums = [-2]
输出：-2
```

## 约束条件

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任意前缀或后缀的乘积都保证在 32 位整数范围内

## 提醒

- 这题和“最大子数组和”长得有点像，但难点更大。
- 因为有负数，所以“当前最小值”有时反而能帮助我们得到“当前最大值”。
- 遇到 `0` 时，连续乘积会被直接断开，相当于重新开始。
