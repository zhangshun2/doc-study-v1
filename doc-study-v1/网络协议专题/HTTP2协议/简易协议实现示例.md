# 简易协议实现示例

## 1. 最简单的协议实现

让我们从一个最简单的"问候协议"开始，理解协议的本质。

### 1.1 协议定义

**问候协议（Greeting Protocol）规范：**

```
1. 语法格式：
   请求：HELLO <name>
   响应：HI <name>, NICE TO MEET YOU

2. 语义规则：
   - HELLO：问候命令
   - <name>：发送者姓名
   - HI：响应标识
   - NICE TO MEET YOU：固定回复

3. 时序规则：
   - 客户端先发送HELLO
   - 服务器必须回复HI
   - 一次完整交互后连接关闭
```

### 1.2 Java实现示例

#### 服务器端实现

```java
import java.io.*;
import java.net.*;

public class GreetingServer {
    private static final int PORT = 8080;
    
    public static void main(String[] args) throws IOException {
        ServerSocket serverSocket = new ServerSocket(PORT);
        System.out.println("问候协议服务器启动，监听端口: " + PORT);
        
        while (true) {
            Socket clientSocket = serverSocket.accept();
            handleClient(clientSocket);
        }
    }
    
    private static void handleClient(Socket clientSocket) throws IOException {
        BufferedReader in = new BufferedReader(
            new InputStreamReader(clientSocket.getInputStream()));
        PrintWriter out = new PrintWriter(
            clientSocket.getOutputStream(), true);
        
        // 读取客户端请求
        String request = in.readLine();
        System.out.println("收到请求: " + request);
        
        // 协议解析和处理
        String response = processGreetingProtocol(request);
        
        // 发送响应
        out.println(response);
        System.out.println("发送响应: " + response);
        
        // 关闭连接
        clientSocket.close();
    }
    
    private static String processGreetingProtocol(String request) {
        // 协议解析：检查格式是否符合 "HELLO <name>"
        if (request == null || !request.startsWith("HELLO ")) {
            return "ERROR: INVALID FORMAT";
        }
        
        // 提取姓名
        String name = request.substring(6); // 去掉"HELLO "
        
        // 生成协议响应
        return "HI " + name + ", NICE TO MEET YOU";
    }
}
```

#### 客户端实现

```java
import java.io.*;
import java.net.*;

public class GreetingClient {
    private static final String SERVER_HOST = "localhost";
    private static final int SERVER_PORT = 8080;
    
    public static void main(String[] args) throws IOException {
        Socket socket = new Socket(SERVER_HOST, SERVER_PORT);
        
        PrintWriter out = new PrintWriter(
            socket.getOutputStream(), true);
        BufferedReader in = new BufferedReader(
            new InputStreamReader(socket.getInputStream()));
        
        // 发送问候协议请求
        String name = "Alice";
        String request = "HELLO " + name;
        out.println(request);
        System.out.println("发送请求: " + request);
        
        // 接收响应
        String response = in.readLine();
        System.out.println("收到响应: " + response);
        
        socket.close();
    }
}
```

### 1.3 协议交互过程

```
客户端                    服务器
   │                        │
   │──── HELLO Alice ────→  │  (1) 发送请求
   │                        │  (2) 解析协议
   │                        │  (3) 生成响应
   │ ←── HI Alice, NICE ──── │  (4) 发送响应
   │     TO MEET YOU        │
   │                        │
   └──── 连接关闭 ────────── │
```

## 2. 进阶协议：简易HTTP协议

### 2.1 协议规范

```
请求格式：
GET /path HTTP/1.0
Host: hostname

响应格式：
HTTP/1.0 200 OK
Content-Type: text/html
Content-Length: <length>

<html content>
```

### 2.2 实现示例

```java
public class SimpleHttpServer {
    private static final int PORT = 8080;
    
    public static void main(String[] args) throws IOException {
        ServerSocket serverSocket = new ServerSocket(PORT);
        System.out.println("简易HTTP服务器启动，端口: " + PORT);
        
        while (true) {
            Socket clientSocket = serverSocket.accept();
            handleHttpRequest(clientSocket);
        }
    }
    
    private static void handleHttpRequest(Socket clientSocket) throws IOException {
        BufferedReader in = new BufferedReader(
            new InputStreamReader(clientSocket.getInputStream()));
        PrintWriter out = new PrintWriter(
            clientSocket.getOutputStream(), true);
        
        // 读取HTTP请求行
        String requestLine = in.readLine();
        System.out.println("请求行: " + requestLine);
        
        // 读取请求头（简化处理）
        String line;
        while ((line = in.readLine()) != null && !line.isEmpty()) {
            System.out.println("请求头: " + line);
        }
        
        // 解析请求
        HttpRequest request = parseHttpRequest(requestLine);
        
        // 生成响应
        String response = generateHttpResponse(request);
        
        // 发送响应
        out.print(response);
        out.flush();
        
        clientSocket.close();
    }
    
    private static HttpRequest parseHttpRequest(String requestLine) {
        String[] parts = requestLine.split(" ");
        return new HttpRequest(parts[0], parts[1], parts[2]);
    }
    
    private static String generateHttpResponse(HttpRequest request) {
        String content = "<html><body><h1>Hello from Simple HTTP Server!</h1>" +
                        "<p>You requested: " + request.path + "</p></body></html>";
        
        return "HTTP/1.0 200 OK\r\n" +
               "Content-Type: text/html\r\n" +
               "Content-Length: " + content.length() + "\r\n" +
               "\r\n" +
               content;
    }
    
    static class HttpRequest {
        String method;
        String path;
        String version;
        
        HttpRequest(String method, String path, String version) {
            this.method = method;
            this.path = path;
            this.version = version;
        }
    }
}
```

### 3.2 状态机实现

```java
public class ProtocolStateMachine {
    enum State {
        INIT,           // 初始状态
        CONNECTED,      // 已连接
        AUTHENTICATED,  // 已认证
        DATA_TRANSFER,  // 数据传输
        CLOSED          // 已关闭
    }
    
    private State currentState = State.INIT;
    
    public void handleMessage(Message msg) {
        switch (currentState) {
            case INIT:
                if (msg.type == MessageType.CONNECT) {
                    currentState = State.CONNECTED;
                    sendConnectAck();
                }
                break;
                
            case CONNECTED:
                if (msg.type == MessageType.AUTH) {
                    if (authenticate(msg)) {
                        currentState = State.AUTHENTICATED;
                        sendAuthSuccess();
                    }
                }
                break;
                
            case AUTHENTICATED:
                if (msg.type == MessageType.DATA) {
                    currentState = State.DATA_TRANSFER;
                    processData(msg);
                }
                break;
                
            // ... 其他状态处理
        }
    }
}
```

### 3.3 错误处理机制

```java
public class ProtocolErrorHandler {
    enum ErrorCode {
        INVALID_FORMAT(400, "Invalid message format"),
        UNAUTHORIZED(401, "Authentication required"),
        NOT_FOUND(404, "Resource not found"),
        SERVER_ERROR(500, "Internal server error");
        
        private final int code;
        private final String message;
        
        ErrorCode(int code, String message) {
            this.code = code;
            this.message = message;
        }
    }
    
    public String generateErrorResponse(ErrorCode error) {
        return String.format("ERROR %d %s\r\n", error.code, error.message);
    }
}
```

## 4. 协议性能优化

### 4.1 连接复用

```java
// HTTP/1.1 的 Keep-Alive 机制
public class ConnectionPool {
    private Map<String, Socket> connections = new HashMap<>();
    
    public Socket getConnection(String host, int port) throws IOException {
        String key = host + ":" + port;
        Socket socket = connections.get(key);
        
        if (socket == null || socket.isClosed()) {
            socket = new Socket(host, port);
            connections.put(key, socket);
        }
        
        return socket;
    }
}
```

### 4.2 数据压缩

```java
// 简单的数据压缩示例
public class ProtocolCompression {
    public byte[] compress(String data) throws IOException {
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        GZIPOutputStream gzipOut = new GZIPOutputStream(baos);
        gzipOut.write(data.getBytes("UTF-8"));
        gzipOut.close();
        return baos.toByteArray();
    }
    
    public String decompress(byte[] compressed) throws IOException {
        ByteArrayInputStream bais = new ByteArrayInputStream(compressed);
        GZIPInputStream gzipIn = new GZIPInputStream(bais);
        return new String(gzipIn.readAllBytes(), "UTF-8");
    }
}
```

## 6. 小结

通过这些简易协议实现，我们可以看到：

1. **协议的本质**：定义数据格式和处理规则
2. **状态管理**：协议需要维护通信状态
3. **错误处理**：协议必须处理各种异常情况
4. **性能优化**：实际应用中需要考虑效率问题

这些基础概念为理解HTTP/2等复杂协议奠定了基础。HTTP/2在这些基本原理之上，增加了二进制分帧、多路复用等高级特性。
