# 应用层协议详解

## 1. 应用层协议概述

### 1.1 应用层的职责

应用层（第7层）是OSI模型的最高层，主要负责：

- **用户接口**：为用户应用程序提供网络服务
- **数据格式**：定义应用数据的表示和交换格式
- **会话管理**：管理应用程序之间的通信会话
- **服务质量**：提供特定的服务质量保证

### 1.2 应用层协议分类

```
┌─────────────────────────────────────────────────────────┐
│                    应用层协议族                         │
├─────────────────┬─────────────────┬─────────────────────┤
│   Web协议       │   文件传输      │   邮件通信          │
├─────────────────┼─────────────────┼─────────────────────┤
│ HTTP/HTTPS      │ FTP/SFTP        │ SMTP/POP3/IMAP      │
│ WebSocket       │ TFTP            │                     │
├─────────────────┼─────────────────┼─────────────────────┤
│   域名解析      │   网络管理      │   远程访问          │
├─────────────────┼─────────────────┼─────────────────────┤
│ DNS             │ SNMP            │ SSH/Telnet          │
```

### 2.2 HTTP消息格式

```java
public class HTTPMessage {
    /*
     * HTTP请求格式：
     * 
     * GET /index.html HTTP/1.1
     * Host: www.example.com
     * User-Agent: Mozilla/5.0
     * Accept: text/html,application/xhtml+xml
     * Connection: keep-alive
     * 
     * [请求体]
     */
    
    public static class HTTPRequest {
        // 请求行
        String method;          // GET, POST, PUT, DELETE等
        String uri;             // 请求的资源路径
        String version;         // HTTP版本
        
        // 请求头
        Map<String, String> headers = new HashMap<>();
        
        // 请求体
        byte[] body;
        
        public HTTPRequest(String method, String uri, String version) {
            this.method = method;
            this.uri = uri;
            this.version = version;
        }
        
        public void addHeader(String name, String value) {
            headers.put(name, value);
        }
        
        public String toHTTPString() {
            StringBuilder sb = new StringBuilder();
            
            // 请求行
            sb.append(method).append(" ").append(uri).append(" ").append(version).append("\r\n");
            
            // 请求头
            for (Map.Entry<String, String> header : headers.entrySet()) {
                sb.append(header.getKey()).append(": ").append(header.getValue()).append("\r\n");
            }
            
            // 空行分隔头部和体
            sb.append("\r\n");
            
            // 请求体
            if (body != null) {
                sb.append(new String(body));
            }
            
            return sb.toString();
        }
    }
    
    /*
     * HTTP响应格式：
     * 
     * HTTP/1.1 200 OK
     * Content-Type: text/html
     * Content-Length: 1234
     * Server: Apache/2.4.41
     * Date: Mon, 01 Jan 2024 12:00:00 GMT
     * 
     * <html>...</html>
     */
    
    public static class HTTPResponse {
        // 状态行
        String version;         // HTTP版本
        int statusCode;         // 状态码
        String reasonPhrase;    // 状态描述
        
        // 响应头
        Map<String, String> headers = new HashMap<>();
        
        // 响应体
        byte[] body;
        
        public HTTPResponse(String version, int statusCode, String reasonPhrase) {
            this.version = version;
            this.statusCode = statusCode;
            this.reasonPhrase = reasonPhrase;
        }
        
        public String toHTTPString() {
            StringBuilder sb = new StringBuilder();
            
            // 状态行
            sb.append(version).append(" ").append(statusCode).append(" ").append(reasonPhrase).append("\r\n");
            
            // 响应头
            for (Map.Entry<String, String> header : headers.entrySet()) {
                sb.append(header.getKey()).append(": ").append(header.getValue()).append("\r\n");
            }
            
            // 空行分隔头部和体
            sb.append("\r\n");
            
            // 响应体
            if (body != null) {
                sb.append(new String(body));
            }
            
            return sb.toString();
        }
    }
}
```

### 2.3 HTTP方法详解

```java
public class HTTPMethods {
    /*
     * HTTP方法定义：
     * 
     * 1. GET：获取资源
     * 2. POST：创建资源
     * 3. PUT：更新资源
     * 4. DELETE：删除资源
     * 5. HEAD：获取资源头信息
     * 6. OPTIONS：获取服务器支持的方法
     * 7. PATCH：部分更新资源
     * 8. TRACE：追踪请求路径
     */
    
    public class RESTfulAPI {
        public HTTPResponse handleRequest(HTTPRequest request) {
            switch (request.method) {
                case "GET":
                    return handleGet(request);
                case "POST":
                    return handlePost(request);
                case "PUT":
                    return handlePut(request);
                case "DELETE":
                    return handleDelete(request);
                case "HEAD":
                    return handleHead(request);
                case "OPTIONS":
                    return handleOptions(request);
                default:
                    return createErrorResponse(405, "Method Not Allowed");
            }
        }
        
        private HTTPResponse handleGet(HTTPRequest request) {
            // GET /users/123 - 获取用户信息
            if (request.uri.matches("/users/\\d+")) {
                String userId = extractUserId(request.uri);
                User user = userService.findById(userId);
                
                if (user != null) {
                    HTTPResponse response = new HTTPResponse("HTTP/1.1", 200, "OK");
                    response.addHeader("Content-Type", "application/json");
                    response.body = toJSON(user).getBytes();
                    return response;
                } else {
                    return createErrorResponse(404, "User Not Found");
                }
            }
            
            // GET /users - 获取用户列表
            if (request.uri.equals("/users")) {
                List<User> users = userService.findAll();
                HTTPResponse response = new HTTPResponse("HTTP/1.1", 200, "OK");
                response.addHeader("Content-Type", "application/json");
                response.body = toJSON(users).getBytes();
                return response;
            }
            
            return createErrorResponse(404, "Not Found");
        }
        
        private HTTPResponse handlePost(HTTPRequest request) {
            // POST /users - 创建新用户
            if (request.uri.equals("/users")) {
                try {
                    User newUser = fromJSON(new String(request.body), User.class);
                    User createdUser = userService.create(newUser);
                    
                    HTTPResponse response = new HTTPResponse("HTTP/1.1", 201, "Created");
                    response.addHeader("Content-Type", "application/json");
                    response.addHeader("Location", "/users/" + createdUser.getId());
                    response.body = toJSON(createdUser).getBytes();
                    return response;
                    
                } catch (Exception e) {
                    return createErrorResponse(400, "Bad Request");
                }
            }
            
            return createErrorResponse(404, "Not Found");
        }
        
        private HTTPResponse handlePut(HTTPRequest request) {
            // PUT /users/123 - 更新用户信息
            if (request.uri.matches("/users/\\d+")) {
                String userId = extractUserId(request.uri);
                
                try {
                    User updatedUser = fromJSON(new String(request.body), User.class);
                    updatedUser.setId(userId);
                    
                    User result = userService.update(updatedUser);
                    if (result != null) {
                        HTTPResponse response = new HTTPResponse("HTTP/1.1", 200, "OK");
                        response.addHeader("Content-Type", "application/json");
                        response.body = toJSON(result).getBytes();
                        return response;
                    } else {
                        return createErrorResponse(404, "User Not Found");
                    }
                    
                } catch (Exception e) {
                    return createErrorResponse(400, "Bad Request");
                }
            }
            
            return createErrorResponse(404, "Not Found");
        }
        
        private HTTPResponse handleDelete(HTTPRequest request) {
            // DELETE /users/123 - 删除用户
            if (request.uri.matches("/users/\\d+")) {
                String userId = extractUserId(request.uri);
                
                if (userService.delete(userId)) {
                    return new HTTPResponse("HTTP/1.1", 204, "No Content");
                } else {
                    return createErrorResponse(404, "User Not Found");
                }
            }
            
            return createErrorResponse(404, "Not Found");
        }
    }
}
```

### 2.4 HTTP状态码

```java
public class HTTPStatusCodes {
    /*
     * HTTP状态码分类：
     * 
     * 1xx: 信息性状态码
     * 2xx: 成功状态码
     * 3xx: 重定向状态码
     * 4xx: 客户端错误状态码
     * 5xx: 服务器错误状态码
     */
    
    public enum StatusCode {
        // 1xx 信息性
        CONTINUE(100, "Continue"),
        SWITCHING_PROTOCOLS(101, "Switching Protocols"),
        
        // 2xx 成功
        OK(200, "OK"),
        CREATED(201, "Created"),
        ACCEPTED(202, "Accepted"),
        NO_CONTENT(204, "No Content"),
        
        // 3xx 重定向
        MOVED_PERMANENTLY(301, "Moved Permanently"),
        FOUND(302, "Found"),
        NOT_MODIFIED(304, "Not Modified"),
        TEMPORARY_REDIRECT(307, "Temporary Redirect"),
        
        // 4xx 客户端错误
        BAD_REQUEST(400, "Bad Request"),
        UNAUTHORIZED(401, "Unauthorized"),
        FORBIDDEN(403, "Forbidden"),
        NOT_FOUND(404, "Not Found"),
        METHOD_NOT_ALLOWED(405, "Method Not Allowed"),
        CONFLICT(409, "Conflict"),
        
        // 5xx 服务器错误
        INTERNAL_SERVER_ERROR(500, "Internal Server Error"),
        NOT_IMPLEMENTED(501, "Not Implemented"),
        BAD_GATEWAY(502, "Bad Gateway"),
        SERVICE_UNAVAILABLE(503, "Service Unavailable");
        
        private final int code;
        private final String phrase;
        
        StatusCode(int code, String phrase) {
            this.code = code;
            this.phrase = phrase;
        }
        
        public int getCode() { return code; }
        public String getPhrase() { return phrase; }
    }
    
    public class StatusCodeHandler {
        public HTTPResponse createResponse(StatusCode status, String body) {
            HTTPResponse response = new HTTPResponse("HTTP/1.1", status.getCode(), status.getPhrase());
            
            // 根据状态码设置适当的头部
            switch (status.getCode() / 100) {
                case 2: // 成功
                    response.addHeader("Content-Type", "application/json");
                    break;
                case 3: // 重定向
                    if (status == StatusCode.MOVED_PERMANENTLY || status == StatusCode.FOUND) {
                        response.addHeader("Location", body); // body包含重定向URL
                        body = null;
                    }
                    break;
                case 4: // 客户端错误
                case 5: // 服务器错误
                    response.addHeader("Content-Type", "application/json");
                    if (body == null) {
                        body = createErrorJSON(status.getCode(), status.getPhrase());
                    }
                    break;
            }
            
            if (body != null) {
                response.body = body.getBytes();
                response.addHeader("Content-Length", String.valueOf(response.body.length));
            }
            
            return response;
        }
        
        private String createErrorJSON(int code, String message) {
            return String.format("{\"error\":{\"code\":%d,\"message\":\"%s\"}}", code, message);
        }
    }
}
```

### 2.5 HTTP缓存机制

```java
public class HTTPCaching {
    /*
     * HTTP缓存策略：
     * 
     * 1. 强缓存：Cache-Control, Expires
     * 2. 协商缓存：ETag, Last-Modified
     * 3. 缓存指令：no-cache, no-store, must-revalidate
     */
    
    public class CacheManager {
        private final Map<String, CacheEntry> cache = new HashMap<>();
        
        public HTTPResponse handleCachedRequest(HTTPRequest request) {
            String url = request.uri;
            CacheEntry entry = cache.get(url);
            
            if (entry != null) {
                // 检查强缓存
                if (isStrongCacheValid(entry)) {
                    HTTPResponse response = entry.response.clone();
                    response.addHeader("X-Cache", "HIT");
                    return response;
                }
                
                // 检查协商缓存
                if (shouldRevalidate(request, entry)) {
                    HTTPResponse revalidationResponse = revalidateWithServer(request, entry);
                    if (revalidationResponse.statusCode == 304) {
                        // 资源未修改，使用缓存
                        HTTPResponse response = entry.response.clone();
                        response.addHeader("X-Cache", "REVALIDATED");
                        updateCacheEntry(entry, revalidationResponse);
                        return response;
                    } else {
                        // 资源已修改，更新缓存
                        updateCache(url, revalidationResponse);
                        return revalidationResponse;
                    }
                }
            }
            
            // 缓存未命中，从服务器获取
            HTTPResponse response = fetchFromServer(request);
            if (isCacheable(response)) {
                updateCache(url, response);
            }
            
            response.addHeader("X-Cache", "MISS");
            return response;
        }
        
        private boolean isStrongCacheValid(CacheEntry entry) {
            // 检查Cache-Control max-age
            String cacheControl = entry.response.headers.get("Cache-Control");
            if (cacheControl != null) {
                int maxAge = extractMaxAge(cacheControl);
                if (maxAge > 0) {
                    long age = (System.currentTimeMillis() - entry.timestamp) / 1000;
                    return age < maxAge;
                }
            }
            
            // 检查Expires
            String expires = entry.response.headers.get("Expires");
            if (expires != null) {
                long expiresTime = parseHTTPDate(expires);
                return System.currentTimeMillis() < expiresTime;
            }
            
            return false;
        }
        
        private HTTPResponse revalidateWithServer(HTTPRequest request, CacheEntry entry) {
            HTTPRequest revalidationRequest = request.clone();
            
            // 添加条件请求头
            String etag = entry.response.headers.get("ETag");
            if (etag != null) {
                revalidationRequest.addHeader("If-None-Match", etag);
            }
            
            String lastModified = entry.response.headers.get("Last-Modified");
            if (lastModified != null) {
                revalidationRequest.addHeader("If-Modified-Since", lastModified);
            }
            
            return fetchFromServer(revalidationRequest);
        }
        
        private boolean isCacheable(HTTPResponse response) {
            // 检查状态码
            if (response.statusCode != 200 && response.statusCode != 301 && response.statusCode != 404) {
                return false;
            }
            
            // 检查Cache-Control指令
            String cacheControl = response.headers.get("Cache-Control");
            if (cacheControl != null) {
                if (cacheControl.contains("no-store") || cacheControl.contains("private")) {
                    return false;
                }
            }
            
            // 检查是否有缓存相关头部
            return response.headers.containsKey("Cache-Control") ||
                   response.headers.containsKey("Expires") ||
                   response.headers.containsKey("ETag") ||
                   response.headers.containsKey("Last-Modified");
        }
        
        static class CacheEntry {
            HTTPResponse response;
            long timestamp;
            
            CacheEntry(HTTPResponse response) {
                this.response = response;
                this.timestamp = System.currentTimeMillis();
            }
        }
    }
}
```

## 3. HTTPS协议详解

### 3.1 HTTPS安全机制

```java
public class HTTPSProtocol {
    /*
     * HTTPS (HTTP Secure) 特性：
     * 
     * 1. 加密传输：使用TLS/SSL加密
     * 2. 身份验证：服务器证书验证
     * 3. 数据完整性：防止数据篡改
     * 4. 前向安全：密钥泄露不影响历史通信
     */
    
    public class TLSHandshake {
        public void performHandshake(Socket socket) throws Exception {
            // 1. Client Hello
            TLSMessage clientHello = createClientHello();
            sendTLSMessage(socket, clientHello);
            
            // 2. Server Hello + Certificate + Server Hello Done
            TLSMessage serverHello = receiveTLSMessage(socket);
            TLSMessage certificate = receiveTLSMessage(socket);
            TLSMessage serverHelloDone = receiveTLSMessage(socket);
            
            // 3. 验证服务器证书
            if (!verifyCertificate(certificate)) {
                throw new SecurityException("Certificate verification failed");
            }
            
            // 4. Client Key Exchange
            byte[] preMasterSecret = generatePreMasterSecret();
            byte[] encryptedPMS = encryptWithServerPublicKey(preMasterSecret, certificate);
            TLSMessage clientKeyExchange = createClientKeyExchange(encryptedPMS);
            sendTLSMessage(socket, clientKeyExchange);
            
            // 5. 生成会话密钥
            byte[] masterSecret = generateMasterSecret(preMasterSecret, clientHello, serverHello);
            SessionKeys keys = deriveSessionKeys(masterSecret);
            
            // 6. Change Cipher Spec + Finished
            sendChangeCipherSpec(socket);
            sendFinished(socket, keys);
            
            // 7. 接收服务器的Change Cipher Spec + Finished
            receiveChangeCipherSpec(socket);
            receiveFinished(socket, keys);
            
            // 握手完成，开始加密通信
            enableEncryption(socket, keys);
        }
        
        private TLSMessage createClientHello() {
            TLSMessage clientHello = new TLSMessage();
            clientHello.type = TLSMessageType.CLIENT_HELLO;
            clientHello.version = TLSVersion.TLS_1_2;
            clientHello.random = generateRandomBytes(32);
            clientHello.cipherSuites = getSupportedCipherSuites();
            clientHello.compressionMethods = getSupportedCompressions();
            return clientHello;
        }
        
        private boolean verifyCertificate(TLSMessage certificate) {
            try {
                X509Certificate cert = parseCertificate(certificate.data);
                
                // 验证证书链
                if (!verifyCertificateChain(cert)) {
                    return false;
                }
                
                // 验证证书有效期
                cert.checkValidity();
                
                // 验证主机名
                if (!verifyHostname(cert, targetHostname)) {
                    return false;
                }
                
                // 验证证书签名
                return verifyCertificateSignature(cert);
                
            } catch (Exception e) {
                return false;
            }
        }
    }
    
    public class HTTPSClient {
        public HTTPResponse sendHTTPSRequest(HTTPRequest request, String hostname, int port) {
            try {
                // 建立TLS连接
                SSLSocketFactory factory = SSLSocketFactory.getDefault();
                SSLSocket socket = (SSLSocket) factory.createSocket(hostname, port);
                
                // 配置TLS参数
                socket.setEnabledProtocols(new String[]{"TLSv1.2", "TLSv1.3"});
                socket.setEnabledCipherSuites(getSecureCipherSuites());
                
                // 开始TLS握手
                socket.startHandshake();
                
                // 验证服务器证书
                Certificate[] certs = socket.getSession().getPeerCertificates();
                if (!validateCertificates(certs, hostname)) {
                    throw new SecurityException("Certificate validation failed");
                }
                
                // 发送HTTP请求
                OutputStream out = socket.getOutputStream();
                out.write(request.toHTTPString().getBytes());
                out.flush();
                
                // 接收HTTP响应
                InputStream in = socket.getInputStream();
                HTTPResponse response = parseHTTPResponse(in);
                
                socket.close();
                return response;
                
            } catch (Exception e) {
                throw new RuntimeException("HTTPS request failed", e);
            }
        }
        
        private String[] getSecureCipherSuites() {
            return new String[]{
                "TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384",
                "TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256",
                "TLS_ECDHE_RSA_WITH_AES_256_CBC_SHA384",
                "TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA256"
            };
        }
    }
}
```

```java
public class FTPProtocol {
    /*
     * FTP (File Transfer Protocol) 特性：
     * 
     * 1. 双连接：控制连接 + 数据连接

     * 3. 文本协议：命令和响应都是文本格式

    public enum FTPMode {
        ACTIVE,     // 主动模式：服务器主动连接客户端
        PASSIVE     // 被动模式：客户端连接服务器
    }
    
    public enum TransferType {
        ASCII,      // ASCII模式：文本文件传输
        BINARY      // 二进制模式：二进制文件传输
    }
}
```

### 4.2 FTP命令和响应

```java
public class FTPCommands {
    /*
     * FTP命令格式：
     * 
     * USER username
     * PASS password
     * PWD
     * CWD directory
     * LIST
     * RETR filename
     * STOR filename
     * QUIT
     */
    
    public class FTPClient {
        private Socket controlSocket;
        private BufferedReader controlReader;
        private PrintWriter controlWriter;
        private FTPMode mode = FTPMode.PASSIVE;
        private TransferType transferType = TransferType.BINARY;
        
        public boolean connect(String hostname, int port) {
            try {
                controlSocket = new Socket(hostname, port);
                controlReader = new BufferedReader(new InputStreamReader(controlSocket.getInputStream()));
                controlWriter = new PrintWriter(controlSocket.getOutputStream(), true);
                
                // 读取服务器欢迎消息
                FTPResponse welcome = readResponse();
                return welcome.code == 220; // Service ready
                
            } catch (IOException e) {
                return false;
            }
        }
        
        public boolean login(String username, String password) {
            // 发送用户名
            sendCommand("USER " + username);
            FTPResponse userResponse = readResponse();
            
            if (userResponse.code == 331) { // User name okay, need password
                // 发送密码
                sendCommand("PASS " + password);
                FTPResponse passResponse = readResponse();
                return passResponse.code == 230; // User logged in
            }
            
            return userResponse.code == 230; // User logged in (no password needed)
        }
        
        public String getCurrentDirectory() {
            sendCommand("PWD");
            FTPResponse response = readResponse();
            
            if (response.code == 257) { // Pathname created
                // 解析路径：257 "/home/user" is current directory
                String message = response.message;
                int start = message.indexOf('"') + 1;
                int end = message.indexOf('"', start);
                return message.substring(start, end);
            }
            
            return null;
        }
        
        public boolean changeDirectory(String directory) {
            sendCommand("CWD " + directory);
            FTPResponse response = readResponse();
            return response.code == 250; // Requested file action okay
        }
        
        public List<String> listFiles() {
            // 建立数据连接
            Socket dataSocket = establishDataConnection();
            if (dataSocket == null) {
                return null;
            }
            
            // 发送LIST命令
            sendCommand("LIST");
            FTPResponse response = readResponse();
            
            if (response.code == 150 || response.code == 125) { // Data connection already open
                try {
                    BufferedReader dataReader = new BufferedReader(
                        new InputStreamReader(dataSocket.getInputStream()));
                    
                    List<String> files = new ArrayList<>();
                    String line;
                    while ((line = dataReader.readLine()) != null) {
                        files.add(line);
                    }
                    
                    dataSocket.close();
                    
                    // 读取传输完成响应
                    FTPResponse completeResponse = readResponse();
                    if (completeResponse.code == 226) { // Transfer complete
                        return files;
                    }
                    
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            
            return null;
        }
        
        public boolean downloadFile(String remoteFile, String localFile) {
            // 设置二进制传输模式
            setTransferType(TransferType.BINARY);
            
            // 建立数据连接
            Socket dataSocket = establishDataConnection();
            if (dataSocket == null) {
                return false;
            }
            
            // 发送RETR命令
            sendCommand("RETR " + remoteFile);
            FTPResponse response = readResponse();
            
            if (response.code == 150 || response.code == 125) { // Data connection already open
                try (FileOutputStream fos = new FileOutputStream(localFile);
                     InputStream dataStream = dataSocket.getInputStream()) {
                    
                    byte[] buffer = new byte[8192];
                    int bytesRead;
                    while ((bytesRead = dataStream.read(buffer)) != -1) {
                        fos.write(buffer, 0, bytesRead);
                    }
                    
                    dataSocket.close();
                    
                    // 读取传输完成响应
                    FTPResponse completeResponse = readResponse();
                    return completeResponse.code == 226; // Transfer complete
                    
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            
            return false;
        }
        
        public boolean uploadFile(String localFile, String remoteFile) {
            // 设置二进制传输模式
            setTransferType(TransferType.BINARY);
            
            // 建立数据连接
            Socket dataSocket = establishDataConnection();
            if (dataSocket == null) {
                return false;
            }
            
            // 发送STOR命令
            sendCommand("STOR " + remoteFile);
            FTPResponse response = readResponse();
            
            if (response.code == 150 || response.code == 125) { // Data connection already open
                try (FileInputStream fis = new FileInputStream(localFile);
                     OutputStream dataStream = dataSocket.getOutputStream()) {
                    
                    byte[] buffer = new byte[8192];
                    int bytesRead;
                    while ((bytesRead = fis.read(buffer)) != -1) {
                        dataStream.write(buffer, 0, bytesRead);
                    }
                    
                    dataSocket.close();
                    
                    // 读取传输完成响应
                    FTPResponse completeResponse = readResponse();
                    return completeResponse.code == 226; // Transfer complete
                    
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            
            return false;
        }
        
        private Socket establishDataConnection() {
            if (mode == FTPMode.PASSIVE) {
                return establishPassiveConnection();
            } else {
                return establishActiveConnection();
            }
        }
        
        private Socket establishPassiveConnection() {
            // 发送PASV命令
            sendCommand("PASV");
            FTPResponse response = readResponse();
            
            if (response.code == 227) { // Entering passive mode
                // 解析响应：227 Entering Passive Mode (192,168,1,1,20,21)
                String message = response.message;
                int start = message.indexOf('(') + 1;
                int end = message.indexOf(')', start);
                String[] parts = message.substring(start, end).split(",");
                
                String ip = parts[0] + "." + parts[1] + "." + parts[2] + "." + parts[3];
                int port = Integer.parseInt(parts[4]) * 256 + Integer.parseInt(parts[5]);
                
                try {
                    return new Socket(ip, port);
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
            
            return null;
        }
        
        private void setTransferType(TransferType type) {
            String command = (type == TransferType.ASCII) ? "TYPE A" : "TYPE I";
            sendCommand(command);
            readResponse(); // 忽略响应
        }
        
        private void sendCommand(String command) {
            controlWriter.println(command);
        }
        
        private FTPResponse readResponse() {
            try {
                String line = controlReader.readLine();
                if (line != null && line.length() >= 3) {
                    int code = Integer.parseInt(line.substring(0, 3));
                    String message = line.substring(4);
                    return new FTPResponse(code, message);
                }
            } catch (IOException | NumberFormatException e) {
                e.printStackTrace();
            }
            
            return new FTPResponse(0, "");
        }
    }
    
    static class FTPResponse {
        int code;
        String message;
        
        FTPResponse(int code, String message) {
            this.code = code;
            this.message = message;
        }
    }
```

### 5.2 DNS消息格式

```java
public class DNSMessage {
    /*
     * DNS消息格式：
     * 
     * +--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+
     * |                      ID                       |
     * +--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+
     * |QR|   Opcode  |AA|TC|RD|RA|   Z    |   RCODE   |
     * +--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+
     * |                    QDCOUNT                    |
     * +--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+
     * |                    ANCOUNT                    |
     * +--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+
     * |                    NSCOUNT                    |
     * +--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+
     * |                    ARCOUNT                    |
     * +--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+--+
     */
    
    public static class DNSHeader {
        short id;           // 查询标识
        boolean qr;         // 查询/响应标志
        byte opcode;        // 操作码
        boolean aa;         // 权威答案
        boolean tc;         // 截断标志
        boolean rd;         // 期望递归
        boolean ra;         // 递归可用
        byte rcode;         // 响应码
        
        short qdcount;      // 问题数
        short ancount;      // 答案数
        short nscount;      // 权威记录数
        short arcount;      // 附加记录数
        
        public byte[] toBytes() {
            ByteBuffer buffer = ByteBuffer.allocate(12);
            
            buffer.putShort(id);
            
            // 标志字段
            int flags = 0;
            if (qr) flags |= 0x8000;
            flags |= (opcode & 0x0F) << 11;
            if (aa) flags |= 0x0400;
            if (tc) flags |= 0x0200;
            if (rd) flags |= 0x0100;
            if (ra) flags |= 0x0080;
            flags |= rcode & 0x0F;
            buffer.putShort((short) flags);
            
            buffer.putShort(qdcount);
            buffer.putShort(ancount);
            buffer.putShort(nscount);
            buffer.putShort(arcount);
            
            return buffer.array();
        }
    }
    
    public static class DNSQuestion {
        String qname;       // 查询名称
        short qtype;        // 查询类型
        short qclass;       // 查询类别 (通常为1，表示Internet)
        
        public DNSQuestion(String domain, DNSRecordType type) {
            this.qname = domain;
            this.qtype = (short) type.getValue();
            this.qclass = 1; // IN (Internet)
        }
        
        public byte[] toBytes() {
            ByteArrayOutputStream baos = new ByteArrayOutputStream();
            
            // 编码域名
            String[] labels = qname.split("\\.");
            for (String label : labels) {
                baos.write(label.length());
                baos.write(label.getBytes(), 0, label.length());
            }
            baos.write(0); // 结束标志
            
            // 添加类型和类别
            ByteBuffer buffer = ByteBuffer.allocate(4);
            buffer.putShort(qtype);
            buffer.putShort(qclass);
            baos.write(buffer.array(), 0, 4);
            
            return baos.toByteArray();
        }
    }
    
    public static class DNSRecord {
        String name;        // 记录名称
        short type;         // 记录类型
        short rclass;       // 记录类别
        int ttl;            // 生存时间
        short rdlength;     // 数据长度
        byte[] rdata;       // 记录数据
        
        public static DNSRecord createARecord(String name, String ipAddress, int ttl) {
            DNSRecord record = new DNSRecord();
            record.name = name;
            record.type = (short) DNSRecordType.A.getValue();
            record.rclass = 1;
            record.ttl = ttl;
            
            // 将IP地址转换为字节数组
            String[] parts = ipAddress.split("\\.");
            record.rdata = new byte[4];
            for (int i = 0; i < 4; i++) {
                record.rdata[i] = (byte) Integer.parseInt(parts[i]);
            }
            record.rdlength = 4;
            
            return record;
        }
        
        public String getIPAddress() {
            if (type == DNSRecordType.A.getValue() && rdata.length == 4) {
                return String.format("%d.%d.%d.%d",
                    rdata[0] & 0xFF, rdata[1] & 0xFF,
                    rdata[2] & 0xFF, rdata[3] & 0xFF);
            }
            return null;
        }
    }
}
```

### 5.3 DNS客户端实现

```java
public class DNSClient {
    private final String dnsServer;
    private final int dnsPort;
    private final Random random = new Random();
    
    public DNSClient(String dnsServer, int dnsPort) {
        this.dnsServer = dnsServer;
        this.dnsPort = dnsPort;
    }
    
    public List<String> resolveA(String domain) {
        try {
            // 构造DNS查询
            DNSMessage.DNSHeader header = new DNSMessage.DNSHeader();
            header.id = (short) random.nextInt(65536);
            header.rd = true; // 期望递归查询
            header.qdcount = 1;
            
            DNSMessage.DNSQuestion question = new DNSMessage.DNSQuestion(domain, DNSRecordType.A);
            
            // 组装查询消息
            ByteArrayOutputStream queryStream = new ByteArrayOutputStream();
            queryStream.write(header.toBytes());
            queryStream.write(question.toBytes());
            byte[] queryData = queryStream.toByteArray();
            
            // 发送UDP查询
            try (DatagramSocket socket = new DatagramSocket()) {
                DatagramPacket queryPacket = new DatagramPacket(
                    queryData, queryData.length,
                    InetAddress.getByName(dnsServer), dnsPort);
                socket.send(queryPacket);
                
                // 接收响应
                byte[] responseBuffer = new byte[512];
                DatagramPacket responsePacket = new DatagramPacket(responseBuffer, responseBuffer.length);
                socket.setSoTimeout(5000); // 5秒超时
                socket.receive(responsePacket);
                
                // 解析响应
                return parseDNSResponse(responsePacket.getData(), responsePacket.getLength());
            }
            
        } catch (Exception e) {
            e.printStackTrace();
            return new ArrayList<>();
        }
    }
    
    private List<String> parseDNSResponse(byte[] data, int length) {
        List<String> addresses = new ArrayList<>();
        ByteBuffer buffer = ByteBuffer.wrap(data, 0, length);
        
        // 解析头部
        short id = buffer.getShort();
        short flags = buffer.getShort();
        short qdcount = buffer.getShort();
        short ancount = buffer.getShort();
        short nscount = buffer.getShort();
        short arcount = buffer.getShort();
        
        // 检查响应码
        int rcode = flags & 0x0F;
        if (rcode != 0) {
            System.err.println("DNS query failed with rcode: " + rcode);
            return addresses;
        }
        
        // 跳过问题部分
        for (int i = 0; i < qdcount; i++) {
            skipDNSName(buffer);
            buffer.getShort(); // qtype
            buffer.getShort(); // qclass
        }
        
        // 解析答案部分
        for (int i = 0; i < ancount; i++) {
            skipDNSName(buffer);
            short type = buffer.getShort();
            short rclass = buffer.getShort();
            int ttl = buffer.getInt();
            short rdlength = buffer.getShort();
            
            if (type == DNSRecordType.A.getValue() && rdlength == 4) {
                // 读取IPv4地址
                byte[] addr = new byte[4];
                buffer.get(addr);
                String ipAddress = String.format("%d.%d.%d.%d",
                    addr[0] & 0xFF, addr[1] & 0xFF,
                    addr[2] & 0xFF, addr[3] & 0xFF);
                addresses.add(ipAddress);
            } else {
                // 跳过其他类型的记录
                buffer.position(buffer.position() + rdlength);
            }
        }
        
        return addresses;
    }
    
    private void skipDNSName(ByteBuffer buffer) {
        while (true) {
            byte length = buffer.get();
            if (length == 0) break;
            
            if ((length & 0xC0) == 0xC0) {
                // 压缩指针
                buffer.get(); // 跳过低字节
                break;
            } else {
                // 普通标签
                buffer.position(buffer.position() + length);
            }
        }
    }
}
```

```java
public class SMTPProtocol {
    /*
     * SMTP (Simple Mail Transfer Protocol) 特性：
     * 
     * 1. 推送协议：发送邮件到服务器
     * 2. 文本协议：命令和响应都是文本

    public class SMTPClient {

        private PrintWriter writer;
        
        public boolean connect(String smtpServer, int port) {
            try {
                socket = new Socket(smtpServer, port);
                reader = new BufferedReader(new InputStreamReader(socket.getInputStream()));
                writer = new PrintWriter(socket.getOutputStream(), true);
                
                // 读取服务器欢迎消息
                String response = reader.readLine();
                return response.startsWith("220");
                
            } catch (IOException e) {
                return false;
            }
        }
        
        public boolean sendEmail(String from, String to, String subject, String body) {
            try {
                // HELO命令
                writer.println("HELO client.example.com");
                if (!readResponse().startsWith("250")) return false;
                
                // MAIL FROM命令
                writer.println("MAIL FROM:<" + from + ">");
                if (!readResponse().startsWith("250")) return false;
                
                // RCPT TO命令
                writer.println("RCPT TO:<" + to + ">");
                if (!readResponse().startsWith("250")) return false;
                
                // DATA命令
                writer.println("DATA");
                if (!readResponse().startsWith("354")) return false;
                
                // 发送邮件内容
                writer.println("From: " + from);
                writer.println("To: " + to);
                writer.println("Subject: " + subject);
                writer.println("Date: " + new Date());
                writer.println("Content-Type: text/plain; charset=UTF-8");
                writer.println();
                writer.println(body);
                writer.println("."); // 结束标志
                
                if (!readResponse().startsWith("250")) return false;
                
                // QUIT命令
                writer.println("QUIT");
                readResponse();
                
                return true;
                
            } catch (IOException e) {
                return false;
            } finally {
                closeConnection();
            }
        }
        
        private String readResponse() throws IOException {
            return reader.readLine();
        }
        
        private void closeConnection() {
            try {
                if (socket != null) socket.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    }
```

```java
public class HTTPOptimization {
    /*
     * HTTP性能优化技术：
     * 
     * 1. 连接复用：Keep-Alive
     * 2. 压缩传输：Gzip, Brotli
     * 3. 缓存策略：强缓存、协商缓存
     * 4. 资源合并：CSS/JS合并
     * 5. CDN加速：内容分发网络
     */
    
    public class ConnectionPooling {
        private final Map<String, Queue<Socket>> connectionPool = new HashMap<>();
        private final int maxConnectionsPerHost = 10;
        private final long connectionTimeout = 30000; // 30秒
        
        public Socket getConnection(String host, int port) {
            String key = host + ":" + port;
            Queue<Socket> connections = connectionPool.get(key);
            
            if (connections != null && !connections.isEmpty()) {
                Socket socket = connections.poll();
                if (isConnectionValid(socket)) {
                    return socket;
                }
            }
            
            // 创建新连接
            try {
                Socket socket = new Socket(host, port);
                socket.setKeepAlive(true);
                socket.setSoTimeout((int) connectionTimeout);
                return socket;
            } catch (IOException e) {
                return null;
            }
        }
        
        public void returnConnection(String host, int port, Socket socket) {
            String key = host + ":" + port;
            Queue<Socket> connections = connectionPool.computeIfAbsent(key, k -> new LinkedList<>());
            
            if (connections.size() < maxConnectionsPerHost && isConnectionValid(socket)) {
                connections.offer(socket);
            } else {
                try {
                    socket.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
        
        private boolean isConnectionValid(Socket socket) {
            return socket != null && socket.isConnected() && !socket.isClosed();
        }
    }
    
    public class CompressionHandler {
        public byte[] compressResponse(byte[] data, String acceptEncoding) {
            if (acceptEncoding != null) {
                if (acceptEncoding.contains("gzip")) {
                    return gzipCompress(data);
                } else if (acceptEncoding.contains("deflate")) {
                    return deflateCompress(data);
                }
            }
            return data;
        }
        
        private byte[] gzipCompress(byte[] data) {
            try (ByteArrayOutputStream baos = new ByteArrayOutputStream();
                 GZIPOutputStream gzipOut = new GZIPOutputStream(baos)) {
                
                gzipOut.write(data);
                gzipOut.finish();
                return baos.toByteArray();
                
            } catch (IOException e) {
                return data; // 压缩失败，返回原数据
            }
        }
    }
```

### 7.2 DNS优化

```java
public class DNSOptimization {
    /*
     * DNS优化技术：
     * 
     * 1. DNS缓存：减少查询次数
     * 2. 预解析：提前解析域名
     * 3. 负载均衡：多IP轮询
     * 4. 故障转移：备用DNS服务器
     */
    
    public class DNSCache {
        private final Map<String, CacheEntry> cache = new ConcurrentHashMap<>();
        private final ScheduledExecutorService cleanupExecutor = Executors.newScheduledThreadPool(1);
        
        public DNSCache() {
            // 定期清理过期缓存
            cleanupExecutor.scheduleAtFixedRate(this::cleanupExpiredEntries, 60, 60, TimeUnit.SECONDS);
        }
        
        public List<String> resolve(String domain) {
            CacheEntry entry = cache.get(domain);
            
            if (entry != null && !entry.isExpired()) {
                return new ArrayList<>(entry.addresses);
            }
            
            // 缓存未命中或已过期，执行DNS查询
            List<String> addresses = performDNSQuery(domain);
            if (!addresses.isEmpty()) {
                cache.put(domain, new CacheEntry(addresses, calculateTTL(domain)));
            }
            
            return addresses;
        }
        
        public void preResolve(List<String> domains) {
            // 预解析域名
            for (String domain : domains) {
                CompletableFuture.runAsync(() -> resolve(domain));
            }
        }
        
        private void cleanupExpiredEntries() {
            cache.entrySet().removeIf(entry -> entry.getValue().isExpired());
        }
        
        static class CacheEntry {
            final List<String> addresses;
            final long expiryTime;
            
            CacheEntry(List<String> addresses, int ttl) {
                this.addresses = new ArrayList<>(addresses);
                this.expiryTime = System.currentTimeMillis() + ttl * 1000L;
            }
            
            boolean isExpired() {
                return System.currentTimeMillis() > expiryTime;
            }
        }
    }
```

- **远程管理**：SSH（安全）或Telnet（简单）

### 8.3 性能优化要点
1. **连接复用**：减少连接建立开销
2. **数据压缩**：减少传输数据量
3. **缓存机制**：减少重复请求
4. **负载均衡**：提高系统可用性
5. **安全传输**：保护数据安全

应用层协议直接为用户应用提供服务，是网络协议栈的最终体现。
